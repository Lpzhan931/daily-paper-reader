## 摘要
投机解码通过使用轻量级草稿模型提出多个 token，并由目标模型并行验证，从而加速自回归生成。然而，标准接受规则关注精确分布校正，当草稿模型分配了过高概率时，会拒绝那些在目标模型下仍然高度合理的 token。这种保守验证限制了每次验证前向传播后保留的草稿 token 数量。我们提出核投机解码（Nucleus Speculative Decoding, NSD），一种将目标模型合理性纳入投机解码的宽松验证方法。NSD 接受一个草稿 token，如果它满足标准接受规则，或者属于目标模型的核。我们从理论上刻画了该方法引入的分布偏差，并表明单步误差完全由草稿模型在目标核内的超额概率决定。我们进一步推导了序列级保真度界，量化局部偏差如何在自回归解码中累积。在多种目标模型和提议机制上的实验表明，NSD 在保持有竞争力的任务性能的同时，持续提升投机解码效率。我们的方法相比自回归解码实现了最高 5.16 倍的吞吐量加速，相比标准投机解码实现了最高 3.15 倍的加速。这些提升伴随着更长的接受长度，使更多输出 token 能够分担每次目标验证传递的成本。分析表明，合理性感知验证为宽松验证和投机解码效率提供了一种有效途径。我们的代码见 https://github.com/EIT-NLP/Nucleus-Speculative-Decoding。

## Abstract
Speculative decoding accelerates autoregressive generation by using a lightweight draft model to propose multiple tokens that are verified by a target model in parallel. However, the standard acceptance rule focuses on exact distribution correction and rejects tokens that remain highly plausible under the target model when the draft model assigns excess probability. This conservative verification limits the number of draft tokens retained after each verification forward pass. We introduce Nucleus Speculative Decoding (NSD), a relaxed verification method that incorporates target-model plausibility into speculative decoding. NSD accepts a draft token if it satisfies the standard acceptance rule or belongs to the target model's nucleus. We theoretically characterize the distributional deviation introduced by our method and show that the single-step error is exactly determined by the draft model's excess probability within the target nucleus. We further derive sequence-level fidelity bounds that quantify how local deviations accumulate over autoregressive decoding. Experiments across multiple target models and proposal mechanisms demonstrate that NSD consistently improves speculative decoding efficiency while maintaining competitive task performance. Our method achieves throughput speedups of up to $5.16\times$ over autoregressive decoding and up to $3.15\times$ over standard speculative decoding. These improvements coincide with longer accepted lengths, allowing more output tokens to share the cost of each target verification pass. Analysis shows that plausibility-aware verification provides an effective approach for relaxed verification and speculative decoding efficiency. Our code is available at https://github.com/EIT-NLP/Nucleus-Speculative-Decoding.

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：大语言模型自回归（AR）解码本质上是串行且昂贵的。投机解码（Speculative Decoding, SD）通过轻量草稿模型一次提议多个 token、再由目标模型并行验证来加速生成，其加速比取决于每次验证能保留多少草稿 token。
- **核心痛点**：标准 SD 的接受规则为 $\min\{1, p(x)/q(x)\}$，目标是**精确保持目标分布**。该规则只比较目标与草稿的相对概率，而非 token 在目标分布下的绝对合理性。因此当 $q(x) > p(x)$ 时，即便 token 在目标模型下排名极高，也会被拒绝；一旦首个 token 被拒，后续提议全部作废。
- **实证证据**：
  - 目标验证占总墙钟时间的 **57.1%–78.1%**（图 1a），是主要瓶颈。
  - 被拒绝 token 中 **81.5%** 仍位于目标模型 top-10 排名内（图 1b）。
  - 在常用 Top-P=0.95 设置下，**52.6%** 的被拒 token 仍落在目标核（nucleus）内（图 1c）。
- **整体含义**：验证环节存在明显低效——它在为“精确分布”付出代价的同时，丢弃了大量目标模型本身认为高度合理的候选。论文主张采用**合理性感知（plausibility-aware）的宽松验证**，在不改动草稿机制的前提下提升接受长度与吞吐。

## 2. 方法论

### 2.1 核心思想
- **NSD 判定规则**：对每个验证位置的草稿 token $x_i$，
  $$b_i = \mathbb{1}\{\,u_i \le a^{\text{SD}}_i(x_i)\ \lor\ x_i \in S_i(\theta)\,\}$$
  即“**满足标准随机接受规则**”**或**“**属于目标模型核**”即接受；否则按原 SD 的残差分布重采样。
- 关键设计：NSD **不修改**提议机制、残差修正（$[p-q]^+$ 归一化）与 bonus 采样，仅**追加一个基于目标核的接受条件**，因此可与多种投机解码范式正交组合（DSpark、DFlash、EAGLE-3、MTP、Nemotron 自推测等）。

### 2.2 关键技术细节
- **核的定义**：$S_i(\theta)=\{v_{i,(1)},\dots,v_{i,(k_i(\theta))}\}$，其中 $k_i(\theta)=\min\{k:\sum_{j\le k} p_i(v_{i,(j)})\ge\theta\}$，即按目标概率降序累积达到阈值 $\theta$ 的最小集合。核随每个位置的目标分布自适应变化；**不在核内重新归一化 $p$ 或 $q$**；同分 token 采用固定排序，可共享归属。
- **算法流程（Algorithm 1，单次验证周期）**：
  1. 草稿机制生成 $x_{1:K}$，保留真实条件提议分布 $q_{1:K}$；
  2. 一次目标前向并行计算 $p_i=p(\cdot\mid h_0,x_{<i})$，$i=1,\dots,K+1$；
  3. 逐位置构造 $S_i(\theta)$，采样 $u_i\sim U(0,1)$，计算 $a^{\text{SD}}_i$；
  4. 若 $u_i\le a^{\text{SD}}_i$ **或** $x_i\in S_i(\theta)$ 则接受并继续；否则从残差 $\rho_i(v)=[p_i(v)-q_i(v)]^+/\sum_w[p_i(w)-q_i(w)]^+$ 采样并返回；
  5. 全部接受则从 $p_{K+1}$ 采 bonus token。遇 EOS 或长度预算则停止并丢弃未提交缓存。

### 2.3 理论刻画（分布保真度）
- 定义拒绝概率 $R=\mathrm{DTV}(q,p)=\sum_v[q(v)-p(v)]^+$，核内草稿超额质量 $E_S=\sum_{v\in S}[q(v)-p(v)]^+$。
- **接受增益**：$\bar a^{\text{NSD}}-\bar a^{\text{SD}}=E_S$，即 $E_S$ 恰为“被标准 SD 拒绝但被 NSD 接受”的概率。
- **单步输出分布**：$\tilde p(v)=\min\{p(v),q(v)\}+\mathbb{1}_{S}(v)[q(v)-p(v)]^+ +(R-E_S)\rho(v)$。
- **精确误差定理（Theorem A.1）**：$\mathrm{DTV}(\tilde p,p)=E_S=\bar a^{\text{NSD}}-\bar a^{\text{SD}}\le R$——**新增的接受质量等于新增的分布偏差**，且不超过 SD 自身的拒绝概率。
- **精确性条件（Corollary A.2）**：$\tilde p=p \iff E_S=0$（即核内处处 $q\le p$）；$S=\varnothing$ 退化为标准 SD，$S=V$ 则 $\tilde p=q$；核扩张时 $E_S$ 单调不减。
- **序列级耦合界（Theorem A.3）**：若每步条件核满足 $\mathrm{DTV}(K_t,p_t)\le\epsilon_t$，则
  $$\mathrm{DTV}(P^{(T)}_{\text{NSD}},P^{(T)}_p)\le 1-\prod_{t=1}^{T}(1-\epsilon_t)\le \sum_t\epsilon_t,$$
  且存在耦合使两序列完全一致的概率 $\ge\prod_t(1-\epsilon_t)$；均匀界下 $\ge(1-\epsilon)^T\ge 1-T\epsilon$。示例：$\epsilon\le10^{-3},T=32$ 时一致概率 $\approx0.9685$。
- **注意事项**：块解码中需将提议选择、恢复、bonus 采样、缓存回滚状态全部纳入“下一输出核”方可套用该界；诊断性统计平均不能直接给出所需的均匀界。

## 6. 主要结论与发现

- **吞吐**：NSD 在所有对比中取得最高加速。相对 AR 平均加速 3.70×–4.63×，最高 **5.16×**（Nemotron-14B / GSM8K）；相对标准 SD 最高约 **3.15×**；30 组配对平均提升 AR 323.0%、SD 84.98%。
- **接受长度**：$\tau$ 全面提升，例如 Nemotron-3B/8B/14B 从 SD 的 6.29/4.98/4.67 提升至 9.54/11.82/11.54；Qwen3-4B/8B/14B 从 5.36/5.41/5.38 提升至 6.60/6.69/6.68。
- **任务性能**：6 个模型中 5 个整体精度高于 SD（+0.05 至 +1.32 个百分点），Qwen3-4B 例外（68.65%→67.66%，同时加速比 3.13×→4.00×）；30 组中 15 胜 1 平 14 负，平均高 **0.40 个百分点**，差异区间 −1.58 至 +4.14 个百分点。
- **消融**：块长 $K$ 从 8 增至 32 普遍提升加速比与 $\tau$（GSM8K 上 Nemotron-8B 2.92×→4.87×，14B 2.91×→5.16×），但在 MBPP 上边际收益递减甚至为负；阈值 $\theta$ 的影响**模型/任务相关、非单调**，存在质量—效率权衡（如 14B 降 $\theta$ 提升精度但降速；8B 在 GSM8K 上 $\theta=0.90$ 同时改善两者）。最高吞吐配置（$K=32$）并非最高精度配置（MBPP 最优为 $K=16,\theta=0.85$）。
- **机制分析**：
  - 额外接受的 token 中 **86.65% 位于目标核核心区**（累积概率 <0.9），**79.30%** 同时满足低失配条件（$Y<2$）；
  - **33.4%** 是目标 rank-1 token，**72.9%** 位于 top-2，**94.1%** 位于 top-5，**98.5%** 位于 top-10；
  - 草稿分布更集中（额外接受处草稿熵 0.865 vs 目标熵 1.101，70.30% 情形目标熵更高，Pearson $r=0.668$）；
  - 验证时间从 5.26 ms/output token 降至 2.72 ms（**↓48.3%**），优于 Cactus/ASD/MARS 的 3.44/3.37/3.29 ms；**验证调用次数/output token 从 0.1600 降至 0.0835（↓47.81%）**，而单次目标执行时间变化 <1%（32.551 vs 32.266 ms）。
- **结论**：NSD 的效率收益主要来自**将每次目标验证成本摊薄到更多输出 token**，而非降低单次调用开销；合理性感知验证是提升投机解码效率的有效方向。

## 7. 优点

- **方法极简且免训练**：仅在验证阶段追加一个核成员判定，不改动提议、残差修正与 bonus 采样，可插拔地兼容自推测、DSpark、DFlash、EAGLE-3、MTP 等多种范式，工程落地成本低。
- **理论刻画干净且强**：证明单步 TV 偏差**恰等于** $E_S$，把“多接受的量”与“偏离目标分布的量”严格绑定，并给出 $\mathrm{DTV}(\tilde p,p)\le R$ 的上界；序列级耦合界给出可解释的保真度退化规律，并明确指出适用条件（需状态感知的输出核界）。
- **动机由数据驱动**：

- **动机由数据驱动**：先用三项统计（验证占 57.1%–78.1% 墙钟时间、81.5% 被拒 token 仍在目标 top-10、52.6% 被拒 token 仍在目标核内）把“验证低效”量化，再据此设计规则，问题—证据—方法链条完整，说服力强。
- **实验覆盖面广且机制分析深入**：跨 Nemotron 与 Qwen3 两个模型家族、自推测/DSpark/DFlash/EAGLE-3/MTP 五类提议机制、数学与代码五类 benchmark，共 30 组 model-benchmark 配对；消融同时扫描核阈值与块长；机制分析进一步给出额外接受 token 的目标排名分布、草稿/目标熵对比、失配 $Y=\log(q/p)$ 分布，以及验证时间与验证调用次数分解，能够解释“为什么快”而不只是“快了多少”。
- **对效率来源的归因清晰**：区分了“单次目标前向成本”与“验证调用次数/output token”，证明 NSD 的收益来自摊销而非加速单次前向，这一区分对后续系统优化具有直接指导意义。
- **与同类宽松验证方法的横向对比**：在统一设置下与 MARS、ASD、Cactus 比较，并报告验证时间（NSD 2.72 ms vs 3.44/3.37/3.29 ms），提供了可复现的相对位置。

## 8. 局限与可改进之处

- **不再是精确采样**：NSD 以 $E_S$ 的 TV 偏差换取接受长度，$\mathrm{DTV}(\tilde p,p)=E_S$。对需要严格保持目标分布的应用（如可验证的采样、重要性加权、某些统计推断或对齐敏感场景），这一偏差不可忽略；论文虽给出上界与序列级耦合界，但并未给出“何种任务可容忍多大 $E_S$”的实用判据。
- **阈值 $\theta$ 需人工设定且行为非单调**：$\theta$ 对精度与速度的影响随模型、任务变化，甚至出现“降 $\theta$ 提精度但降速”“某配置同时改善两者”等不一致现象。这意味着实际部署仍需逐场景调参，削弱了“免训练即插即用”的便利性。
- **序列级理论界依赖较强假设**：Theorem A.3 要求每步条件核满足均匀 TV 界 $\epsilon_t$，且块解码中必须把提议选择、恢复、bonus 采样与缓存回滚全部纳入“下一输出核”。论文也承认诊断性统计平均不能直接给出所需均匀界，因此该界更偏解释性而非可直接验证的保证。
- **模型规模与硬件覆盖有限**：目标模型均 ≤14B，作者自述受硬件与 checkpoint 可得性限制；未验证 30B/70B 级或 MoE 架构下的行为。核的构造与验证成本随词表/模型规模的变化也未讨论。
- **资源报告不充分**：仅说明使用 NVIDIA Pro5000，未给出 GPU 数量、总 GPU 小时、评测总时长与能耗；对希望复现或估算部署成本的研究者不够友好。
- **统计严谨性不足**：AIME 类 benchmark 题量小，精度差异易受噪声影响；任务性能未报告多次运行方差或置信区间；30 组配对中 15 胜 1 平 14 负、平均仅 +0.40 个百分点，精度“不降”的结论证据强度有限，Qwen3-4B 还出现 68.65%→67.66% 的下降。
- **部分吞吐数据可比性存疑**：作者自述 DFlash seed 30 运行异常缓慢、非无争用条件下的测量，虽已声明，但仍影响该组结论的稳健性。
- **对比基线可能不完全对等**：MARS、ASD、Cactus 的实现细节、调参预算与是否使用相同块长/核阈值未在正文充分说明，存在“NSD 调参更充分”的潜在不公平风险。
- **未讨论失败模式与安全性**：宽松验证在开放式生成、长文本、重复退化或对抗性草稿分布下的行为未评估；核内接受可能放大草稿的系统性偏好（如更集中、熵更低的分布），论文虽观察到草稿熵更低，但未分析其长期累积效应。

## 9. 对读者的启示与可借鉴之处

- **验证阶段是投机解码中被低估的优化维度**：多数工作聚焦草稿模型质量或块长，本文表明在不改动草稿的前提下，仅放宽验证判定即可获得显著吞吐提升，提示后续研究可继续探索“验证规则设计”这一空间。
- **“精确分布”与“任务可用性”可解耦**：NSD 用核成员判定把“目标模型认为合理”这一语义引入接受条件，为在保真度与效率之间做显式、可控的权衡提供了范式；其误差—收益严格绑定的理论工具（$E_S$、TV 等式、耦合界）可迁移到其他宽松采样/验证方法。
- **可插拔设计值得效仿**：只追加一个接受条件、不触碰提议与残差修正，使方法天然兼容多种 SD 变体，这种“最小侵入式”改造思路在工程上更易被采纳。
- **机制分析应成为加速方法的标配**：通过验证调用次数、单次前向时间、额外接受 token 排名分布等指标定位收益来源，比单纯报告端到端加速比更有解释力，也更容易指导下一步优化。
- **可延伸方向**：自适应选择 $\theta$（按任务/位置/熵动态调整）、将核接受与草稿训练联合优化、把 $E_S$ 作为可监控的在线保真度指标、以及在更大模型与长上下文场景下验证摊销收益是否持续。
