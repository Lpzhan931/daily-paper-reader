## 摘要
循环 Transformer 在多个循环深度上复用同一个共享块，使得自回归解码开销高昂，因为每个生成的 token 都需要多次顺序的循环传递。自推测解码器通过在早期深度进行草拟并在完整深度进行验证来降低这一开销，但通常将草拟计算绑定到来自同一循环深度的前缀表示。我们发现，查询和键比值更早接近其最终深度表示，而受控的前缀通道干预表明，成熟的值能显著改善浅层草拟预测。受这种不对称性启发，我们提出了深度异步自推测（DAS），它将草拟计算的深度与其读取的已验证前缀表示的深度解耦。其成熟值（Mature-V）原语让浅层查询无需额外循环计算即可检索完整深度的前缀值。我们进一步开发了 DAS-Wave，它将深度异步前缀读取与携带式并行细化、渐进式块增长以及独立的完整深度验证器相结合。在四个循环模型检查点以及数学和代码工作负载上，DAS-Wave 在同一推理栈中相比配对的完整深度自回归解码实现了 4.00--6.96 倍的平均吞吐量加速。这些结果将前缀信息深度确定为循环自推测的一个有效设计轴。

## Abstract
Looped Transformers reuse a shared block across recurrent depths, making autoregressive decoding expensive because every generated token requires many sequential recurrent passes. Self-speculative decoders reduce this cost by drafting at an early depth and verifying at full depth, but typically bind draft computation to prefix representations from the same recurrent depth. We find that queries and keys approach their final-depth representations earlier than values, and controlled prefix-channel interventions show that mature values substantially improve shallow draft predictions. Motivated by this asymmetry, we introduce Depth-Asynchronous Self-Speculation (DAS), which decouples the depth of draft computation from the depth of verified-prefix representations it reads. Its Mature-V primitive lets shallow queries retrieve full-depth prefix values without additional recurrent computation. We further develop DAS-Wave, which combines depth-asynchronous prefix reads with carried parallel refinement, progressive block growth, and an independent full-depth verifier. Across four recurrent-model checkpoints and mathematics and code workloads, DAS-Wave achieves 4.00--6.96$\times$ mean throughput speedup over paired full-depth autoregressive decoding in the same inference stack. These results identify prefix-information depth as an effective design axis for recurrent self-speculation.

## 1. 核心问题与整体含义
- **背景**：循环 Transformer（Looped Transformers）通过重复使用共享块增加有效深度，但自回归解码时每个 token 都要经过多次顺序循环传递，深度越大延迟越高。
- **现有自推测解码的局限**：通常用浅层 draft 提出候选 token、用全深度 target 验证；但 draft 读取的已验证前缀表示往往被绑定在同一或相近循环深度，即“draft 计算深度”与“prefix 表示深度”耦合。
- **关键发现**：注意力通道成熟速度不同步——Query/Key 较早接近最终深度表示，而 Value 较晚成熟；受控前缀通道替换显示，成熟 Value 能显著提升浅层 draft 与全深度 target 的一致性。
- **整体含义**：论文提出将“前缀信息深度”作为循环自推测的新设计轴，解耦 draft 的计算深度与其读取的 prefix 表示深度，从而在不增加 draft 循环计算的情况下提升 draft 质量，并转化为端到端解码加速。

## 2. 方法论
### 2.1 核心思想
- 提出 **Depth-Asynchronous Self-Speculation, DAS**：draft 仍可在浅层计算，但读取已验证前缀的 K/V 时，可分别选择不同深度。
- 提出 **Mature-V**：浅层 draft query 读取全深度 prefix V，而 K 仍与 draft 深度对齐；由于 prefix 已由 target 验证并物化，不需要额外循环计算。
- 进一步构建 **DAS-Wave**：将深度异步前缀读取与携带式并行细化、渐进块增长、独立全深度验证器结合。

### 2.2 DAS 的注意力读取
- 对核心层 ℓ，已验证前缀为 C，当前 draft 活跃位置为 U。DAS 显式指定 prefix key 读取深度 κ 和 value 读取深度 ν。
- 注意力权重：`softmax(Q_cur [K^κ_C; K^cur_U]^T / sqrt(d_h) + M)`，输出为 `Π_C V^ν_C + Π_U V^cur_U`。
- 读取策略：
  - Aligned：`(κ, ν) = (r, r)`；
  - Mature-V / Deep V：`(κ, ν) = (r, R)`；
  - Deep K：`(κ, ν) = (R, r)`；
  - Deep K/V：`(κ, ν) = (R, R)`。
- 其中 R 为全深度，r 为浅层 draft 深度。DAS 只改变已验证 prefix 的读取深度，draft 侧 K/V 仍由当前 draft 计算产生。

### 2.3 DAS-Wave 流程
- 以最后提交 token `x_t` 为固定 anchor，活跃宽度逐步增长：`W_j = min(γ, W_init + j)`。
- 每轮并行细化活跃位置，执行 k 次 recurrent draft 更新，读取全深度已验证 prefix K/V（Deep K/V）。
- 关键机制是 **latent carry**：候选 token 猜测可被修订，但对应 latent state 跨轮保留并累积计算；临时 draft K/V 在轮间丢弃。
- 最终将 anchor 与若干候选交给独立全深度 target 验证。按顺序接受匹配提案；首个不匹配处输出 target argmax，并丢弃后续 draft 后缀。
- 验证产生的全深度 K/V 成为下一轮 mature prefix cache。该方法不改变 target 模型和标准推测验证规则，贪婪解码下保持目标输出。
