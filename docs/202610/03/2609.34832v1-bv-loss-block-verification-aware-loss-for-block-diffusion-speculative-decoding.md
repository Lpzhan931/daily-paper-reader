## 摘要
扩散草稿模型通过并行提出多个 token 来加速投机解码。尽管近期通过序列级起草与验证在投机解码方面取得了进展，现有训练目标在很大程度上仍围绕 token 级验证设计。为解决这一不匹配，我们引入块验证感知损失（BV损失），一种旨在最大化草稿序列期望接受长度的训练目标。BV损失直接从块验证接受规则推导而来，在草稿模型训练目标与序列级推理时验证机制之间建立了原理性联系。在数学、代码和聊天基准上，对于 DFlash 和 DSpark 搭配 Qwen3-4B 和 Qwen3-8B，在不改变推理过程的情况下，BV损失相较于交叉熵损失训练，将块验证下每次验证调用平均接受的 token 数提高了 13.0--21.0%。BV损失也优于 TV损失和 LK损失等逐 token 接受目标，其增益还扩展到 token 验证和贪心解码。这些结果表明，使用与序列级验证对齐的目标来训练块扩散草稿模型，而非独立优化每个 token，是有益的。

## Abstract
Diffusion drafters accelerate speculative decoding by proposing multiple tokens in parallel. Despite recent advances in speculative decoding through sequence-level drafting and verification, existing training objectives remain largely designed around token-level verification. To address this mismatch, we introduce Block Verification-aware loss (BV loss), a training objective designed to maximize the expected acceptance length of a drafted sequence. BV loss is directly derived from the block verification acceptance rule, providing a principled connection between the drafter training objective and the inference-time verification mechanism at the sequence level. Across math, code, and chat benchmarks, BV loss increases the mean number of tokens accepted per verification call under block verification by 13.0--21.0\% over cross-entropy loss training for DFlash and DSpark with Qwen3-4B and Qwen3-8B without changing the inference procedure. BV loss also outperforms tokenwise acceptance objectives such as TV loss and LK loss, and its gains extend to token verification and greedy decoding. These results demonstrate the benefit of training block diffusion drafters with an objective aligned with sequence-level verification, rather than optimizing each token independently.

## 1. 核心问题与整体含义（研究动机与背景）

- **投机解码的效率瓶颈**：投机解码（Speculative Decoding）使用轻量 drafter 并行提出候选 token，再由大目标模型验证。整体加速比高度依赖“每次验证调用能接受多少 token”。
- **验证侧出现序列级新范式**：传统 token 验证（token verification）逐 token 顺序接受，一旦某个 token 被拒绝，后续草稿 token 全部丢弃；而 **块验证（Block Verification, Sun et al. 2025）** 采用序列级接受准则，对候选序列的联合概率进行拒绝采样，允许后续位置的高概率比补偿前面位置的低概率比，从而保留原本会被丢弃的 token，且额外推理开销可忽略。
- **训练目标与验证机制错配**：现有 drafter 训练目标仍以 token 级为主，例如 CE、KL/RKL、TV、LK。其中 TV 损失由 token 验证下的单 token 接受概率推导，LK 是 token 级接受概率的负对数。它们与块验证的序列级接受规则不匹配。
- **论文目标**：提出 **Block Verification-aware loss（BV loss）**，直接从块验证接受规则推导，最大化草稿序列的期望接受长度，使 drafter 训练目标与推理时序列级验证机制对齐。

## 2. 方法论

### 2.1 核心思想

- BV loss 是 **序列级目标**，直接优化“草稿块在块验证下被接受的期望长度”，而非独立优化每个 token 的似然或接受率。
- 它可视为 TV loss 的序列级对应物：TV 来自 token 级拒绝采样的接受概率，BV 来自块验证诱导的接受长度。
- 理论性质：当块大小 \(B=1\) 时，BV loss 退化为 TV loss；完全整合的 block-log 形式在单 token 情形下恢复 LK loss。

### 2.2 关键公式与流程

- **块验证接受规则**：  
  \[
  \alpha_i(y_{1:i})=\min\{1,\ \alpha_{i-1}(y_{1:i-1})\,p_i(y_i)/q_i(y_i)\},\quad \alpha_0=1
  \]  
  其中 \(p_i,q_i\) 分别为目标与草稿在位置 \(i\) 的条件概率。
- **期望接受长度**：令 \(\tau\) 为被接受草稿 token 数，则  
  \[
  \mathbb{E}_{BV}[\tau]=\sum_{i=1}^B \Pr\nolimits_{BV}(\tau\ge i)=\sum_{i=1}^B \mathbb{E}_{BV}[\alpha_i]
  \]
- **目标路径上的可训练估计**：由于训练数据来自目标模型生成路径 \(y'_{1:B}\sim p\)，定义累计比  
  \[
  r_i=\prod_{j=1}^i q_j(y'_j)/p_j(y'_j),\quad r_0=1
  \]  
  并定义接受分数  
  \[
  \tilde\alpha_i=r_i\alpha_i=\min\{1,r_1,\dots,r_i\}
  \]  
  在“训练路径来自目标条件、\(q_i\) 为推理 proposal、\(p_i\) 在 \(q_i\) 非零处有支撑”的假设下，\(\mathbb{E}_{y'\sim p}[\tilde\alpha_i]=\mathbb{E}_{BV}[\alpha_i]\)，因此 \(\sum_i \tilde\alpha_i\) 的期望等于 \(\mathbb{E}_{BV}[\tau]\)。
- **BV loss 定义**：  
  \[
  \mathcal{L}_{BV}=1-\frac{1}{B}\mathbb{E}_{BV}[\tau]
  \]  
  最小化 BV loss 等价于最大化期望块接受长度。
- **训练代理**：在目标生成块上以 minibatch 平均估计 \(1-\frac{1}{B}\sum_i\tilde\alpha_i\)，无需对草稿采样或验证过程求导。

### 2.3 梯度分析与训练技巧

- **梯度问题**：\(\tilde\alpha_i\) 的梯度大小受前缀接受分数缩放，低接受率时整体梯度很小。
- **Log BV 目标**：  
  \[
  \mathcal{L}_{\log BV}=\log B-\log \mathbb{E}_{BV}[\tau]
  \]  
  保持最优解与改进方向不变，同时消除整体小接受因子。
- **退火聚合**：为加强低接受前缀的早期学习信号，定义功率平均目标  
  \[
  \mathcal{L}_{annealBV}(\beta)=-\log\left[\frac{1}{B}\sum_{i=1}^B \tilde\alpha_i^\beta\right]^{1/\beta},\quad 0<\beta\le 1
  \]  
  \(\beta\to 0\) 为各前缀等权的几何平均（逐前缀 log 损失平均），\(\beta=1\) 为算术平均的负对数（blockwise log 代理）。主实验前三个 epoch 将 \(\beta\) 从 0 线性增至 1，后三个 epoch 固定 \(\beta=1\)。
- **词汇整合估计**：主 BV 实验使用 vocabulary-integrated 长度估计，对当前位置 token 积分而保持采样前缀固定，以利用完整目标分布并保留前缀依赖。
