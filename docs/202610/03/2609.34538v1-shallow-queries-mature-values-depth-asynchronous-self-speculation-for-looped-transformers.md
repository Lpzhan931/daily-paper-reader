## 摘要
循环 Transformer 在多个循环深度上复用共享块，使得自回归解码代价高昂，因为每生成一个 token 都需要多次顺序循环传递。自推测解码器通过在较早深度起草并在全深度验证来降低这一成本，但通常将草稿计算绑定到来自同一循环深度的前缀表示。我们发现，查询和键比值更早接近其最终深度表示，而受控的前缀通道干预表明，成熟的值能显著改善浅层草稿预测。受这种不对称性启发，我们提出深度异步自推测（DAS），它将草稿计算的深度与其读取的已验证前缀表示的深度解耦。其 Mature-V 原语使浅层查询无需额外循环计算即可检索全深度前缀值。我们进一步开发了 DAS-Wave，它将深度异步前缀读取与携带式并行细化、渐进式块增长以及独立全深度验证器相结合。在四个循环模型检查点以及数学和代码工作负载上，DAS-Wave 在相同推理栈中相较于配对的全程深度自回归解码实现了 4.00--6.96 倍的平均吞吐加速。这些结果将前缀信息深度确定为循环自推测的一种有效设计轴。

## Abstract
Looped Transformers reuse a shared block across recurrent depths, making autoregressive decoding expensive because every generated token requires many sequential recurrent passes. Self-speculative decoders reduce this cost by drafting at an early depth and verifying at full depth, but typically bind draft computation to prefix representations from the same recurrent depth. We find that queries and keys approach their final-depth representations earlier than values, and controlled prefix-channel interventions show that mature values substantially improve shallow draft predictions. Motivated by this asymmetry, we introduce Depth-Asynchronous Self-Speculation (DAS), which decouples the depth of draft computation from the depth of verified-prefix representations it reads. Its Mature-V primitive lets shallow queries retrieve full-depth prefix values without additional recurrent computation. We further develop DAS-Wave, which combines depth-asynchronous prefix reads with carried parallel refinement, progressive block growth, and an independent full-depth verifier. Across four recurrent-model checkpoints and mathematics and code workloads, DAS-Wave achieves 4.00--6.96$\times$ mean throughput speedup over paired full-depth autoregressive decoding in the same inference stack. These results identify prefix-information depth as an effective design axis for recurrent self-speculation.

## 1. 核心问题与研究背景

- **循环 Transformer 的解码瓶颈**：Looped/Recurrent-depth Transformer 通过反复复用同一共享块来扩展"有效深度"（推理时算力），无需增加参数量。但自回归生成时，每生成一个 token 都必须串行执行全部 R 次循环（文中 R = 32），串行递归成为延迟的主要来源。
- **自推测解码的既有思路**：用廉价草稿（drafter）提出多个候选 token，再由全深度目标模型并行验证。对循环模型而言，中间循环状态天然可作为草稿来源（如 LoopSpec）。
- **被忽视的耦合**：现有自推测方法默认把"草稿计算深度"与"草稿所读取的已验证前缀表示深度"绑定在同一层循环深度上（depth-aligned）。作者指出，这一耦合只是实现上的便利，并非推测验证所必需。
- **关键观察（论文的核心动机）**：注意力各通道的"成熟速度"不一致——Query 和 Key 在较早循环深度就接近最终深度表示，而 Value 成熟得晚。受控前缀通道替换实验显示，把浅层草稿读到的前缀 V 换成全深度 V，能显著提升草稿与全深度目标的一致性，且**不增加草稿自身的循环计算**。
- **整体含义**：论文把"前缀信息深度"确立为循环自推测的一个独立设计轴，说明草稿计算成本与所读信息质量可以解耦、分别优化。

## 2. 方法论

### 2.1 核心思想：深度异步自推测（DAS）
- 解耦两件事：草稿在哪个循环深度 `r` 上计算（浅层、廉价），与它读取的已验证前缀 K/V 取自哪个深度（可以取全深度 `R`）。
- 由于跨深度读取**仅限已验证前缀 token**，这些全深度表示已由目标验证过程物化（materialized）并缓存，因此不产生额外循环计算。

### 2.2 关键技术细节：Mature-V 与读深度策略
- 注意力计算中，把前缀读深度显式参数化为：key 深度 `κ`、value 深度 `ν`：
  - 注意力权重：`[Π_C, Π_U] = softmax( Q_cur,ℓ · [K^κ,ℓ_C ; K^cur,ℓ_U]^T / √d_h + M )`
  - 输出：`O_ℓ = Π_C · V^ν,ℓ_C + Π_U · V^cur,ℓ_U`
  - 其中 C 为已验证前缀、U 为当前草稿侧位置，M 为因果掩码，两侧共享同一次 softmax 归一化。
- 四种前缀读取策略（2×2 设计空间）：
  - **Aligned**：(κ, ν) = (r, r)
  - **Mature-V / Deep V**：(κ, ν) = (r, R)——浅层查询 + 成熟 value，即最小干预原语，训练无关（training-free）
  - **Deep K**：(κ, ν) = (R, r)
  - **Deep K/V**：(κ, ν) = (R, R)——DAS-Wave 全系统的固定策略
- 草稿侧 K/V 始终由当前草稿计算产生，DAS 只改前缀读取深度。

### 2.3 DAS-Wave：端到端解码器
- **携带式并行精炼（carried parallel refinement）**：借鉴 recurrent Parallel Samplers，每轮并行精炼多个候选位置，并把 latent state 跨轮携带（而非每轮重初始化）；token 猜测与 latent 状态分离，latent 状态附着于输入位置、累积多轮计算。
- **渐进式窗口增长**：`W_j = min(γ, W_init + j)`，每轮新增一个活跃位置；默认 `W_init = 2`（锚点 + 1 个临时输入），γ 为验证器容量。
- **每轮更新**：对活跃位置做 k 次循环草稿更新，再做"移位读出"（第 i 个位置的读出更新第 i+1 个候选 token）。
- **临时草稿 K/V 每轮丢弃**，仅保留携带的 latent state 与已验证前缀的全深度缓存。
- **独立全深度验证**：验证器用目标模型标准初始化与全 R 步计算，接收 `[x_t, y_1, …, y_{w−1}]`，按贪心顺序接受直到首次不匹配，输出目标 argmax 并丢弃剩余推测后缀；被接受输入的全深度 K/V 成为下一块的成熟前缀缓存。文中给出**贪心目标保持（greedy target preservation）**命题及归纳法证明：在精确算术下，推测验证输出序列与目标自回归贪心序列一致，与草稿轨迹无关。

## 6. 主要结论与发现

- **表征成熟度不对称**：首次循环时对最终深度的平均余弦相似度，Huginn 上 Q/K/V 分别为 0.79/0.84/0.57，Raven-Llama 上为 0.96/0.97/0.79——Query/Key 明显早熟，Value 晚熟。
- **成熟 value 的因果作用**：在草稿深度 r = 1 时，仅替换前缀 V 为全深度，Huginn 草稿–目标一致率从 47.22% 升至 66.93%（仅替换 K 为 46.83%）；Raven-Llama 从 83.99% 升至 87.96%。说明浅层草稿的主要短板在"读到的内容"而非"查询形成"。
- **系统级加速**：DAS-Wave 在 16 个设置中相对配对全深度 AR 取得 **4.00–6.96× 平均吞吐加速**，并取得最长的接受块；GSM8K 上每次验证接受 15.6–18.1 个草稿 token，远高于调优后的顺序自推测基线（5.2–12.2）。
- **增益的分解**：顺序草稿下，Deep K/V 已优于 Aligned（如 Huginn/GSM8K 加速从 1.54× 到 2.26×，A 从 2.80 到 4.92），说明成熟前缀信息本身有效；在携带式并行精炼下，**carry 与 Deep K/V 强互补**（Huginn/GSM8K：两者单独为 0.71× 与 0.93×，组合达 4.11×），因此全系统采用联合 Deep K/V 而非仅 Deep V。
- **成本–接受度权衡**：更多精炼不必然更快——Huginn 每轮更新从 2 增到 8，A 从 16.49 升到 19.56，但加速比从 4.33× 降到 2.37×；容量从 8 增到 32，加速比从 1.98× 升到 4.33×（Huginn）。性能由"接受工作量与提案成本的平衡"决定，而非单看接受长度或容量。
- **理论保证**：贪心解码下，DAS 只改提案构造与前缀读取，不改目标计算与验证规则，故保持与目标 AR 一致的输出序列（精确算术下）。

## 7. 优点

- **观察—机制—系统三层递进**：从 Q/K/V 成熟度的表征层面观察出发，用受控通道替换验证因果性，再落地为可训练无关使用的原语（Mature-V）与完整解码器（DAS-Wave），逻辑链完整。
- **训练无关、即插即用**：Mature-V 可直接嵌入常规顺序自推测而无需改动验证流程，不增加草稿循环深度，也无需重训练或微调。
- **设计轴新颖且明确**：把"前缀信息深度"从"草稿计算深度"中解耦，为循环模型自推测提供了与"草稿深度"正交的新维度。
- **消融设计扎实**：完整的 carry × K × V 八组因子实验并量化三阶交互项，说明为何系统最终选 Deep K/V；另有独立重调优对照，检验弱策略能否靠不同预算追平（答案是不能）。
- **实验公平性较好**：配对基线、同推理栈、同 prompt、同计时会话，10,000 次 bootstrap 置信区间；对并行机制与深度异步读取的贡献做了明确分离。
- **工程细节清晰**：给出状态/缓存生命周期、单块算法流程、容量与活跃宽度的区分、贪心保持性证明，可复现性较好。

## 8. 不足与局限

- **评测规模有限**：仅 4 个循环模型检查点，
