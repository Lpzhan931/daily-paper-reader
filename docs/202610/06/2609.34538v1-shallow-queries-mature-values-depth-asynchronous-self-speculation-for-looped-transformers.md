## 摘要
循环 Transformer 在循环深度上复用共享块，使得自回归解码开销高昂，因为每生成一个 token 都需要多次顺序循环传递。自推测解码器通过在早期深度起草并在全深度验证来降低这一开销，但通常将起草计算绑定到来自同一循环深度的前缀表示。我们发现，查询和键比值更早接近其最终深度表示，并且受控的前缀通道干预表明，成熟的值能显著改善浅层起草预测。受这种不对称性启发，我们提出深度异步自推测（Depth-Asynchronous Self-Speculation, DAS），它将起草计算的深度与其读取的已验证前缀表示的深度解耦。其 Mature-V 原语使浅层查询无需额外循环计算即可检索全深度前缀值。我们进一步开发了 DAS-Wave，它将深度异步前缀读取与携带式并行细化、渐进式块增长以及独立的全深度验证器相结合。在四个循环模型检查点以及数学和代码工作负载上，DAS-Wave 在同一推理栈中相比配对的完整深度自回归解码实现了 4.00--6.96 倍的平均吞吐加速。这些结果将前缀信息深度确定为循环自推测的一个有效设计轴。

## Abstract
Looped Transformers reuse a shared block across recurrent depths, making autoregressive decoding expensive because every generated token requires many sequential recurrent passes. Self-speculative decoders reduce this cost by drafting at an early depth and verifying at full depth, but typically bind draft computation to prefix representations from the same recurrent depth. We find that queries and keys approach their final-depth representations earlier than values, and controlled prefix-channel interventions show that mature values substantially improve shallow draft predictions. Motivated by this asymmetry, we introduce Depth-Asynchronous Self-Speculation (DAS), which decouples the depth of draft computation from the depth of verified-prefix representations it reads. Its Mature-V primitive lets shallow queries retrieve full-depth prefix values without additional recurrent computation. We further develop DAS-Wave, which combines depth-asynchronous prefix reads with carried parallel refinement, progressive block growth, and an independent full-depth verifier. Across four recurrent-model checkpoints and mathematics and code workloads, DAS-Wave achieves 4.00--6.96$\times$ mean throughput speedup over paired full-depth autoregressive decoding in the same inference stack. These results identify prefix-information depth as an effective design axis for recurrent self-speculation.

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：循环 Transformer（Looped Transformers）通过在不同循环深度上重复应用同一共享块来提升推理时计算量，而不显著增加参数量。但这也使自回归（AR）解码极为昂贵——每生成一个 token 都要串行执行多次循环传递，循环深度越大，解码延迟越高。
- **已有方案**：自推测解码（self-speculative decoding）用目标模型自身的更廉价执行作为草稿器，在浅层深度起草、在全深度验证。对循环 Transformer 而言，中间循环状态天然提供了草稿来源。
- **核心问题**：现有自推测通常把"草稿计算深度"与"草稿读取的前缀表示深度"绑定在一起——浅层草稿只能读取同样浅层的前缀 K/V 表示。论文提出一个互补问题：**早期草稿应当被允许读取哪个深度的前缀信息？**
- **关键观察**：注意力各通道成熟速度并不一致。查询（Q）和键（K）比数值（V）更早接近其最终深度表示（Huginn 首轮 Q/K/V 对最终深度余弦相似度为 0.79/0.84/0.57；Raven-Llama 为 0.96/0.97/0.79）。受控干预显示，仅把浅层草稿可用的前缀 V 替换为全深度 V，就能显著提升草稿与全深度目标的一致性（Huginn 从 47.22% 升至 66.93%）。
- **整体含义**：论文指出"前缀信息深度"是循环自推测的一个独立且有效的设计轴——草稿计算深度与所读前缀表示深度可以解耦，从而用廉价草稿计算搭配目标验证已产出的成熟信息。

## 2. 方法论

### 2.1 核心思想
- 提出 **深度异步自推测（DAS）**：解耦草稿计算的循环深度与其读取的已验证前缀表示的深度。
- 实例化为 **Mature-V** 原语：训练无关，让浅层草稿查询检索已验证前缀的全深度 V（这些表示已由目标验证过程物化，无需额外循环计算）。
- 进一步构建 **DAS-Wave**：把深度异步前缀读取与携带式并行精炼、渐进块增长、独立全深度验证器结合。

### 2.2 关键技术细节
- **深度异步前缀读取**：对核心层 ℓ，设 C 为已验证前缀、U 为草稿侧活跃位置，引入键读深度 κ、值读深度 ν：
  - 注意力权重：`[Π_C, Π_U] = softmax(Q^{cur,ℓ}[K^{κ,ℓ}_C ; K^{cur,ℓ}_U]^T / √d_h + M)`
  - 注意力输出：`O^ℓ = Π_C V^{ν,ℓ}_C + Π_U V^{cur,ℓ}_U`
  - 只改变已验证前缀的读取深度，草稿侧 K/V 始终由当前草稿计算产生。
- **2×2 读取策略设计空间**：
  - Aligned: (κ, ν) = (r, r)
  - Mature-V / Deep V: (κ, ν) = (r, R)
  - Deep K: (κ, ν) = (R, r)
  - Deep K/V: (κ, ν) = (R, R)
- **DAS-Wave 的携带式并行精炼**（继承自 Parallel Samplers 的提案结构）：
  - 以最后提交 token 为固定锚点，活跃宽度逐轮增长：`W_j = min(γ, W_init + j)`，j = 0,…,J−1
  - 每轮所有活跃位置并行执行 k 次循环更新，再做移位 token 读出：`z^{(j+1)}_{i+1} = argmax_v [H(h^{(j+1)}_i)]_v`
  - 关键区别：**潜在状态（latent state）跨轮携带**，token 猜测可被修正；新激活位置才从初始状态开始；临时草稿 K/V 每轮丢弃，而携带的潜在状态与全深度前缀缓存保留。
  - 超参：J（精炼轮数）、γ（验证器宽度容量）、W_init（初始活跃宽度，默认 2）、k（每轮循环更新数）。
- **独立全深度验证**：目标模型对 `[x_t, y_1, …, y_{w−1}]` 执行全部 R 步循环，产生移位条件概率；贪心解码下按序接受，首个不匹配处发出目标预测并丢弃剩余草稿后缀；接受位置的全深度 K/V 保留为已验证前缀。
- **理论保证**：由于只修改提案构造与前缀读取，目标计算与验证规则不变，贪心目标保持性（greedy target preservation）沿标准推测解码论证成立（精确算术下）。

## 6. 主要结论与发现

- DAS-Wave 在四个循环检查点、四个数学与代码任务上取得 **4.00–6.96× 平均吞吐加速**，在全部 16 个设置中均为最大加速，且接受块最长（GSM8K 上每次验证接受 15.6–18.1 个草稿 token，对比顺序自推测基线的 5.2–12.2）。
- **成熟前缀复用本身有效**：Mature-Spec（仅把顺序草稿的前缀读取改为固定 Deep K/V）在全部 16 个设置中均优于传统顺序自推测。
- **成熟读取与潜在携带互补**：单独使用任一方提升有限（Huginn/GSM8K：Deep K/V 无携带 0.93×、携带但 Aligned 0.71×），二者结合达 4.11×（A = 15.60）。
- **携带机制偏好联合成熟 K/V**：在携带下，Aligned / Deep V / Deep K/V 分别为 0.71×、1.07×、4.11×；三阶交互效应 E_cKV 在所有评估设置中为正，说明携带强化了成熟 K 与 V 的互补性。
- **成本–接受量权衡**：更多精炼计算提高接受长度但未必更快（Huginn 每轮更新 2→8，A 从 16.49 升至 19.56，但加速从 4.33× 降至 2.37×）；容量 γ 从 8 增至 32 可提升加速（Huginn 1.98×→4.33×），但需精炼调度配合激活位置。
- **总体论断**：前缀信息深度是循环自推测的一个有效设计轴，提案成本与前缀信息质量可被独立优化。

## 7. 优点

- **洞察新颖且可解释**：通过 Q/K/V 成熟速度不对称的实证观察（余弦相似度 + 受控通道替换干预）导出方法，动机链条清晰，而非纯经验调参。
- **训练无关、即插即用**：Mature-V 只改变草稿读取的前缀表示深度，不修改目标模型与标准推测验证规则，可迁移到任意具备中间预测与深度索引 K/V 缓存的循环模型。
- **理论与系统闭环**：给出贪心目标保持性命题与证明；DAS-Wave 中全深度验证器既决定输出又物化下一轮所需的成熟前缀缓存，形成自洽循环。
- **消融设计细致**：区分"深度异步读取"与"潜在携带"两个机制并做因子化分析，解释为何全系统采用联合 Deep K/V 而非单独的 Deep V。
- **实验规范**：同一推理栈配对计时、95% bootstrap 置信区间、独立调参对照、成本诊断，减少不公平比较风险。

## 8. 不足与局限

- **硬件与规模受限**：仅单张 L20X、batch size 1，未验证批量推理、多卡或更大模型上的表现；未报告能耗、显存占用等系统指标。
- **解码策略单一**：主结果全部为贪心解码，未评估采样（temperature / top-p）或 beam search 下的加速与分布保持性；论文也承认有限精度下可能引入数值差异。
- **任务与数据覆盖有限**：仅数学（GSM8K、MATH-500）与代码（HumanEval、MBPP）四类任务，每组 40 条提示，缺少长文本、多语言、开放域对话等场景；部分消融提示数更少（8–20 条）。
- **模型覆盖**：四个循环模型检查点均为 R = 32，未探索不同循环深度、不同共享块结构下的泛化性。
- **机制解释仍有缺口**：虽然观察到 V 通道主导顺序草稿收益、携带下 K/V 互补，但对"为何携带会改变 K 的作用"缺乏更深层理论解释；三阶交互仅以数值报告，未给出机制性推导。
- **超参依赖**：J、γ、k、W_init 等调度参数需按模型选择（Huginn k = 2，Raven k = 1），且 W_init 未显示明确最优，说明系统对调度较敏感，跨模型迁移成本未充分讨论。
- **效率边界**：部分组件配置加速小于 1×（如并行无携带 Aligned 在 Huginn/GSM8K 为 0.65×），表明方法收益高度依赖携带与成熟读取的协同，单独组件可能反而变慢。
