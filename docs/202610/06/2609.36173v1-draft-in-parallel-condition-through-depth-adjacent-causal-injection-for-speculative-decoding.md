## 摘要
并行投机草稿在一次主干前向传播中生成多个候选，但独立的词元选择可能产生不一致的续写，从而缩短被接受的草稿前缀。现有方法大多将条件解码交给主干之后的轻量模块，这限制了前驱信息向后继的流动。我们对 DFlash 的分析表明，早期位置在浅层中已形成可恢复的预测，而准确的相邻前驱在更早进入时对后继帮助更大。因此，我们提出 DSpine，一种在主干各层中贯穿注入因果条件的草稿模型：在每一层，门控相邻注入将每个前驱的预测特征写入其后继，使得因果条件链随网络深度展开，同时所有位置并行更新。基于目标模型输出嵌入构建的统一迁移空间，将逐层注入与前驱条件解码统一起来，而逐层输出嵌入监督则促进浅层中预测特征的形成。融合内核与转移缓存使其在 SGLang 中高效并行执行。在七个数学、代码与对话基准上，DSpine 在 Qwen3-4B 和 Qwen3-8B 上于两种温度下均取得最长接受长度。在 Qwen3-8B 的温度为零时，它将七基准均值从 DFlash 的 3.77 提升至 4.82（+27.8%）；在 SGLang 服务测试中，其吞吐量平均比 DFlash 高 23.3%。

## Abstract
Parallel speculative drafting generates multiple candidates in one backbone pass, but independent token selection can produce inconsistent continuations that shorten the accepted prefix. Existing methods mostly leave conditional decoding to a lightweight module after the backbone, which limits the flow of predecessor information to successors. Our analysis of DFlash shows that early positions already form recoverable predictions in shallow layers, and that accurate adjacent predecessors help successors more when they enter earlier. We therefore propose DSpine, a drafter with causal conditioning injection throughout the backbone: at every layer, gated adjacent injection writes each predecessor's predicted feature into its successor, so the causal conditioning chain unfolds over network depth while all positions update in parallel. A unified transfer space built from the target model's output embeddings unifies layer-wise injection with predecessor-conditioned decoding, and layer-wise output-embedding supervision promotes the formation of predicted features in shallow layers. Fused kernels and a transition cache execute both efficiently in parallel within SGLang. Across seven math, code, and chat benchmarks, DSpine achieves the longest acceptance length at both temperatures on Qwen3-4B and Qwen3-8B. At temperature zero on Qwen3-8B, it raises the seven-benchmark mean from DFlash's 3.77 to 4.82 (+27.8%); in SGLang serving tests, it delivers 23.3% higher throughput than DFlash on average.

## 1. 核心问题与整体含义

- **背景**：自回归解码是大模型推理延迟的主要来源。投机解码通过“轻量草稿模型提出候选、目标模型一次验证”来无损加速，核心指标是每轮平均接受长度 \(\tau\) 与草稿成本。
- **并行草稿的瓶颈**：DFlash 类方法在一次骨干前向中并行预测一个 masked block，避免逐 token 串行草稿。但各位置在预测时并不知道前驱最终会选择哪个 token，因此候选组合可能不一致；目标模型按前缀顺序验证，一处不一致就会截断后续草稿，导致大量并行草稿未被接受。
- **现有方法局限**：Domino、DSpark、DFlash2 等主要在骨干之后做轻量条件解码或候选选择，前驱信息被限制在最终层词表空间，难以与中间层特征结合，也无法在浅层及时影响后继表示形成。
- **论文动机**：作者对 DFlash 的分析发现：浅层早期位置已包含可恢复的预测信息；准确的相邻前驱对后继帮助很大，且越早注入越有效。因此，DSpine 的核心含义是：**让因果条件链沿网络深度展开，而不是等到骨干之后才条件化；所有位置仍在一次并行前向中更新**。

## 2. 方法论：DSpine 的核心思想与关键技术

- **核心思想**：在草稿骨干的每一层，将每个位置的直接前驱的“预测特征”门控注入到后继位置；解码阶段再用同一注入路径，把已确定的前驱 token 写入后继，完成前驱条件解码。
- **统一迁移空间**：
  - 从目标模型 LM head 的输出嵌入构建固定嵌入表 \(C\)：对 LM head 行向量做 \(\ell_2\) 归一化、PCA 白化、保留 \(r\) 个主方向、再归一化。
  - 未确定 token 的前驱贡献“预测特征”：\(z_{\ell,t}=\sqrt{r}\,\text{normalize}(R_\ell u_{\ell,t})\)，其中 \(u_{\ell,t}\) 是第 \(\ell\) 层 Transformer 输出，\(R_\ell\) 是逐层可学习投影。
  - 已知 token 直接以 \(\sqrt{r}C_x\) 进入同一空间。这样“层内注入预测特征”和“解码时注入已选 token”共用一条路径。
- **逐层门控相邻注入**：
  - 第 \(\ell\) 层后，位置 \(t\) 只接收直接前驱 \(t-1\) 的消息。
  - 门控由接收者特征 \(z_{\ell,t}\) 与前驱特征 \(z_{\ell,t-1}\) 共同决定：  
    \(g_{\ell,t}=\sigma(G_q z_{\ell,t}+G_p z_{\ell,t-1}+b)\)。
  - 消息为 \(m_{\ell,t}=A z_{\ell,t-1}\)。
  - 写回残差流：\(h_{\ell,t}=u_{\ell,t}+\text{RMS}(u_{\ell,t})W_\ell(g_{\ell,t}\odot m_{\ell,t})\)。
  - 所有消息使用更新前特征，因此层内注入可跨位置并行；anchor 位置保持不变。
- **块因果注意力**：与 DFlash 的双向块注意力不同，DSpine 在全部骨干层使用 block-causal attention，位置 \(t\) 只关注目标上下文 K/V 与块内 \(0,\dots,t\)。注意力与注入方向一致，且训练时注入的正确信息不会回流到更早位置。
- **深度传播**：从第 1 层开始注入，前一层收到的消息会影响下一层发送给后继的预测特征，从而形成“沿深度展开的因果条件链”。
- **前驱条件解码与转移缓存**：
  - 最终层先得到各位置 top-K 候选。
  - 对已解码前驱 token \(s\)，用 \(\sqrt{r}C_s\) 替换预测特征 \(z_{L,t-1}\)，重新执行最终层写回，称为 last-write refinement，再从缓存状态 \(u_{L,t}\) 得到条件分数。
  - 为避免逐位置串行计算，转移缓存预计算所有相邻候选对的分数 \(T_t[i,j]=S_t(v_{t-1,i},v_{t,j})\)，即 \(K\times K\) 个转移分数一次并行算出，随后按左到右串行选择即可。论文中 \(K=16\)。
- **逐层输出嵌入监督**：
  - 对每层注入后状态读出的 \(e_{\ell,i}=f_\ell(h_{\ell,i})\)，与正确 token 嵌入 \(C_{y_i}\) 做余弦对齐：  
    \(\mathcal L_{emb}=\sum_\ell\sum_i w_i[1-\cos(e_{\ell,i},C_{y_i})]\)，位置越靠后权重 \(w_i\) 越小。
  - 该损失促进浅层预测特征形成，并缩小预测特征与解码时 token 嵌入的差距；只约束低维投影方向，不限制完整隐状态。
- **训练目标**：
  - 冻结目标模型、共享输入嵌入和 LM head。
  - 同时监督普通最终层输出与 last-write refinement 输出。
  - 分布损失为 token 交叉熵与概率 \(\ell_1\) 距离的加权混合，混合权重 \(\alpha=0.1\)，并加入逐层嵌入余弦损失：\(\mathcal L=\mathcal L_{dist}+\lambda\mathcal L_{emb}\)。
  - 使用 correct-predecessor curriculum：训练早期以一定概率把浅层前驱特征替换为正确 token 嵌入，再逐步退火，缓解早期预测特征不可靠的问题。
- **工程优化**：融合归一化、投影、门控和残差写回为少量 CUDA kernel；层内注入与转移缓存均在 SGLang 的 CUDA graph 内执行。
