## 摘要
视觉语言模型（VLM）会产生可观的推理成本，因为每个视觉 token 都会经过每个解码器层的注意力与 MLP 投影处理，即使在许多深度上并不需要针对特定 token 的视觉计算。我们提出 Patch-to-Prune（P2P），其灵感来自机制可解释性，是一个无需训练的框架，将激活修补从诊断工具转化为推理时的计算旁路。P2P 执行验证引导的前向与后向层扫描，以识别出这样的解码器区域：在用户指定的精度容差内，其视觉 token 投影输出可被固定的中性代理激活向量替换。与传统 token 剪枝方法不同，P2P 保留序列长度、token 顺序、位置信息、注意力掩码和残差路径，从而在不移除 token 或修改预训练模型权重的情况下剪枝计算。我们在来自 Qwen2.5-VL 和 LLaVA 系列的四个 VLM 上，使用互不相交的校准、验证和测试划分，在七个多模态基准上评估 P2P。在 3% 容差下，P2P 保留了约 94% 的稠密准确率，同时将 FLOPs 降低 55%。除了这些效率收益外，我们的逐层分析表明，VLM 中的视觉处理在解码器深度上分布不均匀：早期和晚期层通常几乎不需要针对特定 token 的视觉计算，而中间层似乎执行了大多数与任务相关的视觉整合，使后续推理能够主要依赖已嵌入共享残差和文本表示中的视觉信息。这使 P2P 既是一个高效推理框架，也是洞察 VLM 中视觉信息处理的因果透镜。

## Abstract
Vision language models (VLMs) incur substantial inference cost because every visual token is processed by the attention and MLP projections of every decoder layer, even when token-specific visual computation is unnecessary at many depths. We introduce Patch-to-Prune (P2P), inspired by Mechanistic Interpretability, a training-free framework that converts activation patching from a diagnostic tool into an inference-time computation bypass. P2P performs validation-guided forward and backward layer sweeps to identify decoder regions whose visual-token projection outputs can be replaced by fixed neutral proxy activation vectors within a user-specified accuracy tolerance. Unlike conventional token-pruning methods, P2P preserves the sequence length, token order, positional information, attention mask, and residual pathways, thereby pruning computation without removing tokens or modifying the pretrained model weights. We evaluate P2P on four VLMs from the Qwen2.5-VL and LLaVA families across seven multi-modal benchmarks using mutually disjoint calibration, validation, and test partitions. P2P at a 3% tolerance retains around 94% of dense accuracy while reducing FLOPs by 55%. Beyond these efficiency gains, our layer-wise analysis suggests that visual processing in VLMs is non-uniformly distributed across decoder depth: early and late layers often require little token-specific visual computation, whereas intermediate layers appear to perform most task-relevant visual integration, enabling later reasoning to rely largely on visual information already embedded in shared residual and textual representations. This makes P2P both an efficient inference framework and a causal lens into visual information processing in VLMs.

## 1. 核心问题与整体含义（研究动机与背景）

- **核心痛点**：视觉语言模型（VLM）中，一张图像通常被编码为数百至数千个视觉 token，这些 token 会被每一个解码器层反复经过注意力与 MLP 投影处理，使语言解码器成为 VLM 推理的主要计算瓶颈。
- **现有方法的局限**：以 FastV、PyramidDrop 为代表的免训练加速方法主要通过"剪 token"来降低计算——依据早期注意力或相似度评分永久丢弃部分视觉 token。这种做法存在两个问题：
  - 忽略了视觉信息在深度方向上真实流动的方式；
  - 假设 token 重要性单调递减，但早期看似不重要的 token 可能在后续层变得关键。
- **论文的出发点**：既然"哪些 token 重要"未必单调，那么更本质的问题是——**哪些层真正负责处理视觉 token？** 论文通过激活修补（activation patching）做层敏感性分析，发现解码器中的视觉计算冗余并非均匀分布，而是系统性地集中在早期与晚期层。
- **整体含义**：论文将激活修补从纯粹的机制可解释性诊断工具，转化为一种实际可用的推理时计算旁路机制（P2P），同时充当理解 VLM 视觉信息处理的因果透镜。

## 2. 方法论：核心思想与关键技术细节

### 2.1 核心思想

- **从"修补"到"剪枝"**：P2P 不改权重、不删 token、不改结构，而是把某些解码器层中**视觉 token 的投影输出**替换为预先缓存的固定中性代理激活向量，从而**跳过对应的矩阵乘法计算**。
- **保留完整序列结构**：序列长度、token 顺序、位置信息、注意力掩码、残差路径全部保留，仅剪枝"计算"而非"token"。

### 2.2 关键步骤与流程

**（1）符号与模块定义**

- 冻结的 VLM 语言骨干含 N 个解码器层；每层含 7 个线性投影模块：$W_Q, W_K, W_V, W_O$（注意力）与 $W_{gate}, W_{up}, W_{down}$（门控 MLP）。
- 对层 ℓ、模块 m、token 位置 t，记输出激活为 $a_{\ell,m}(t)$。

**（2）模态条件激活统计（构建代理原型）**

- 在一个与评估数据完全不相交的统计集 $D_{stat}$（$N_{stat}$ 个样本）上，对每层 ℓ、每模块 m、每个流 s ∈ {img, txt}，记录样本级平均激活：

$$\mu_{\ell,m,s} = \frac{1}{N_{stat}} \sum_{n=1}^{N_{stat}} \frac{1}{|P_s^{(n)}|} \sum_{t \in P_s^{(n)}} a_{\ell,m}^{(n)}(t)$$

- 每个样本等权贡献，避免长序列或大图像主导估计。

**（3）累积层干预与双向扫描**

- 在独立验证集上做累积扫描，分三种流设置：仅图像、仅文本、双流。
- **前向扫描**：修补层集 $\{0,\dots,L\}$，L 从输入侧逐渐增大；
- **后向扫描**：修补层集 $\{L,\dots,N-1\}$，L 从输出侧逐渐减小；
- 记录每个 L 处的准确率下降，定位各模态在给定深度贡献了多少 token 特定信息。

**（4）安全层选择（容差控制）**

- 给定容差 τ，寻找可接受的修补层索引 L，使累积修补后验证准确率满足 $Acc(L) \geq (1-\tau) \cdot Acc_0$。
- 前向搜索中逐步增大 L，直到连续两次不可接受，取 $L^*_{fwd}=L-1$；后向搜索对称处理。
- 最终安全集为前缀与后缀的并集：$S^*_\tau = \{0,\dots,L^*_{fwd}\} \cup \{L^*_{bwd},\dots,N-1\}$，选定后在测试时固定不变。

**（5）计算旁路推理**

- 测试时，在安全层对视觉 token 直接跳过注意力与三个 MLP 模块的矩阵乘法，用缓存原型 $\mu_{vl,m}$ 填充输出；文本 token 及其他层仍走完整计算。

**（6）P2P-aware 微调（可选）**

- 在安全层插入 LoRA 适配器，并在**与推理相同的 P2P 修补计算图下**训练，避免训练/测试不匹配；
- 被修补位置不传梯度，适配器仅通过未修补的文本 token 及安全层外的模块优化；
- 损失为仅对答案 token 计算的教师强制因果语言建模交叉熵。

## 6. 主要结论与发现

- **效率-精度权衡**：
  - 1% 容差：LLaVA-7B 保留 97.7% 稠密准确率，FLOPs 降 43.2%；LLaVA-13B 保留 98.1%，FLOPs 降 32.8%；

  - 5% 容差：FLOPs 进一步降至 10.1T / 18.8T（降 67.2% / 68.2%），但准确率降至 0.574 / 0.605。
  - 跨 4 模型 8 数据集平均：**FLOPs 降 55%、延迟降 22%、保留 94% 稠密准确率**。
- **延迟表现**：3% 容差下 LLaVA-7B 平均延迟降 15.4%，LLaVA-13B 降 25.4%，且快于 FastV 与 PyramidDrop（后者因排序、索引与序列重组开销，延迟甚至高于 Vanilla）。
- **视觉处理的深度非均匀性**：早期与晚期层对视觉 token 投影输出的替换高度容忍，中间层（约第 14–21 层）最为敏感，承担主要的任务相关视觉整合。
- **文本流不可替代**：修补文本 token 计算在各深度均普遍造成损害，说明冗余主要存在于视觉流。
- **LoRA 微调可恢复精度**：P2P-aware LoRA 在 1% 容差下恢复约 75% 的精度差距，3% 下约 100%，5% 下约 59%。
- **代理选择**：均值激活优于零向量、噪声与随机 token；100 个统计样本已足以稳定估计。

## 7. 优点

- **机制新颖**：将机制可解释性中的激活修补从诊断工具升级为推理加速机制，打通了"可解释性 → 效率"的路径。
- **不破坏结构**：不删 token、不改权重、不改架构、无需训练，保留序列长度、顺序、位置、注意力掩码与残差路径，避免了 token 剪枝的不可逆决策问题。
- **单一可调旋钮**：容差 τ 提供可解释、可控制的精度-效率权衡，用户可按需求选择运行点。
- **实验严谨**：校准/验证/测试三集互不相交，跨两个模型家族、三种参数规模、七类任务验证泛化性。
- **可解释性副产品**：层敏感性分析本身提供了关于 VLM 视觉信息流动的因果洞察。
- **与 token 剪枝正交**：P2P 剪的是"深度维度的计算"，token 剪枝剪的是"序列维度的 token"，二者可互补结合。
- **内存开销小**：每层每模块仅缓存一个激活向量，与序列长度和 batch size 无关。

## 8. 不足与局限

- **算力信息缺失**：未报告 GPU 型号、数量、训练时长，影响复现性与成本评估。
- **精度并非全面领先**：在相同 FLOPs 下，P2P 的平均准确率低于 FastV 与 PyramidDrop，提供的是"更低计算、略低精度"的不同运行点，而非支配性优势。
- **测试集精度下降可能超出容差**：论文自承在某些数据集上全测试集精度下降会超过设定的容差，说明验证集上的安全层选择并非总能严格泛化。
- **任务依赖性明显**：TextVQA、CV-Bench 等任务对激进剪枝更敏感；5% 容差下 Qwen2.5-VL-3B 在 TextVQA 上准确率骤降至 0.182，鲁棒性存疑。
- **延迟非单调**：每个被修补层带有固定修补开销，更高容差可能降低 FLOPs 却增加延迟，最低 FLOPs 配置并非最快配置。
- **微调恢复不一致**：5% 容差下 LoRA 仅恢复约 59% 的精度差距，激进剪枝后的恢复能力有限。
- **文本流不可剪**：方法只对视觉流有效，对文本 token 无加速作用，适用场景限于视觉 token 占主导的 VLM 推理。
- **超参敏感性**：默认 3% 容差基于 Qwen2.5-VL-3B 的容差扫描选定，是否对全部模型与任务最优未充分验证。
