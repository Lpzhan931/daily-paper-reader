## 摘要
循环Transformer在多个循环深度上复用共享块，使得自回归解码代价高昂，因为每生成一个token都需要多次顺序的循环传递。自推测解码器通过在早期深度进行草稿生成、在完整深度进行验证来降低这一开销，但通常将草稿计算绑定到同一循环深度的前缀表示上。我们发现，查询和键比值更早接近其最终深度的表示，而受控的前缀通道干预表明，成熟的值能显著改善浅层草稿预测。受这种不对称性的启发，我们提出深度异步自推测（DAS），它将草稿计算的深度与其所读取的已验证前缀表示的深度解耦。其Mature-V原语使浅层查询能够检索完整深度的前缀值，而无需额外的循环计算。我们进一步开发了DAS-Wave，它将深度异步前缀读取与携带式并行精化、渐进式块增长以及独立的完整深度验证器相结合。在四个循环模型检查点以及数学和代码工作负载上，DAS-Wave在相同推理栈中相较于配对的完整深度自回归解码实现了4.00--6.96$\times$的平均吞吐加速。这些结果将前缀信息深度确定为循环自推测的一个有效设计轴。

## Abstract
Looped Transformers reuse a shared block across recurrent depths, making autoregressive decoding expensive because every generated token requires many sequential recurrent passes. Self-speculative decoders reduce this cost by drafting at an early depth and verifying at full depth, but typically bind draft computation to prefix representations from the same recurrent depth. We find that queries and keys approach their final-depth representations earlier than values, and controlled prefix-channel interventions show that mature values substantially improve shallow draft predictions. Motivated by this asymmetry, we introduce Depth-Asynchronous Self-Speculation (DAS), which decouples the depth of draft computation from the depth of verified-prefix representations it reads. Its Mature-V primitive lets shallow queries retrieve full-depth prefix values without additional recurrent computation. We further develop DAS-Wave, which combines depth-asynchronous prefix reads with carried parallel refinement, progressive block growth, and an independent full-depth verifier. Across four recurrent-model checkpoints and mathematics and code workloads, DAS-Wave achieves 4.00--6.96$\times$ mean throughput speedup over paired full-depth autoregressive decoding in the same inference stack. These results identify prefix-information depth as an effective design axis for recurrent self-speculation.

## 1. 核心问题与整体含义
- **研究背景**：循环 Transformer（Looped Transformers）在多个递归深度上复用同一共享块，以增加推理时计算而不显著增加参数量。但其自回归解码代价高，因为每生成一个 token 都需要多次串行递归传递。
- **现有问题**：自推测解码（self-speculative decoding）可用浅层草稿加速、全深验证保证输出，但通常将草稿计算深度与其读取的前缀表示深度绑定，即浅层草稿只能读取同深度或相近浅层的前缀 K/V。
- **关键发现**：在递归深度演化中，查询 Q 和键 K 比値 V 更早接近最终深度表示。受控前缀通道干预表明，将已验证前缀的 V 替换为全深 V 可显著提升浅层草稿与全深目标的一致性，而无需增加草稿自身递归深度。
- **整体含义**：论文提出“前缀信息深度”可作为循环自推测的独立设计轴，使草稿计算成本与前缀信息质量解耦，从而在保持目标验证规则不变的前提下提升解码吞吐。

## 2. 方法论
### 2.1 核心思想
- 提出 **深度异步自推测（Depth-Asynchronous Self-Speculation, DAS）**：解耦草稿计算的递归深度与草稿读取的已验证前缀表示深度。
- 实例化为 **Mature-V** 原语：浅层草稿查询可读取全深前缀的成熟 V 值，但草稿自身仍保持浅层计算。
- 进一步构建 **DAS-Wave**：将深度异步前缀读取与携带式并行精化、渐进式块增长、独立全深验证器结合。

### 2.2 关键技术细节
- 对核心层 ℓ，设已验证前缀为 C，当前草稿侧位置为 U。DAS 显式指定前缀 K 的读取深度 κ 与 V 的读取深度 ν。
- 注意力权重：
  - `[Π_C, Π_U] = softmax(Q_cur,ℓ [K^κ,ℓ_C; K^cur,ℓ_U]^T / sqrt(d_h) + M)`
- 注意力输出：
  - `O_ℓ = Π_C V^ν,ℓ_C + Π_U V^cur,ℓ_U`
- 前缀读取策略：
  - Aligned：`(κ, ν) = (r, r)`
  - Mature-V / Deep V：`(κ, ν) = (r, R)`
  - Deep K：`(κ, ν) = (R, r)`
  - Deep K/V：`(κ, ν) = (R, R)`
- 由于跨深度读取仅限已验证前缀 token，其全深表示已由目标验证物化，无需额外递归计算。

### 2.3 DAS-Wave 流程
- 设最后已提交 token 为锚点 x_t。第 j 轮精化时，活动宽度增长：
  - `W_j = min(γ, W_init + j)`，其中 γ 为验证器容量，W_init 初始宽度，J 为精化轮数。
- 每轮所有活动位置并行进行 k 次递归草稿更新，并使用 Deep K/V 读取已验证前缀缓存。
- 采用“移位 token 读出”：位置 i 的读出更新候选 i+1 的 token 猜测。
- **携带式潜在状态（carry）**：潜在状态跨精化轮保留，即使 token 猜测被修订，计算历史仍累积；仅新激活位置从新状态开始。
- 临时草稿 K/V 在轮间丢弃，已验证全深前缀缓存保留。
- 最终精化后，锚点与候选 y_1…y_{w-1} 输入独立全深目标验证器；目标执行全部 R 步递归，产生移位条件分布。
- 贪心验证：按序接受匹配候选，首个不匹配处输出目标 argmax 并丢弃剩余后缀；若全部匹配且存在未用条件，可额外输出一个目标 token。
- 验证器不使用草稿携带状态，仅保留已接受物化输入对应的全深 K/V 作为下一轮前缀缓存。
- 论文证明：在精确算术下，贪心目标保持性成立，DAS 不改变目标计算与验证规则。

## 6. 主要结论与发现
- DAS-Wave 在四个循环模型检查点和数学/代码任务上，相对配对全深 AR 取得 **4.00–6.96× 平均吞吐加速**，并在全部 16 个设置中取得最大加速与最长接受块。
- GSM8K 上 DAS-Wave 每次验证接受 **15.6–18.1** 个草稿 token，显著高于顺序自推测基线的 5.2–12.2。
- Mature-Spec 在全部 16 个设置中均优于常规顺序自推测，说明成熟前缀信息在顺序草稿中已有收益。
- 并行控制实验显示：**carry 与 Deep K/V 前缀读取强互补**。单独干预收益有限，组合后增益大幅提升。例如 Huginn/GSM8K 上，Aligned/no-carry 为 0.65×，Deep K/V 无 carry 为 0.93×，carry + Aligned 为 0.71×，而 carry + Deep K/V 达 4.11×，A = 15.60。
- 在 carry 下，联合 Deep K/V 优于仅 Deep V，说明改变提案轨迹后成熟 K 与 V 互补性增强。
- 精化成本与接受长度存在权衡：增加每轮递归更新可提高 A，但可能降低速度；验证器容量增加只有在精化调度能充分利用时才有效。
- 总体结论：**前缀信息深度**是循环自推测的有效设计轴，草稿计算成本与前缀信息质量可独立优化。

## 7. 优点
- **机制驱动、发现清晰**：从 Q/K/V 成熟度不对称出发，提出 Mature-V 最小干预，并用受控通道替换验证因果效应。

- **系统设计完整**：DAS-Wave 将深度异步前缀读取、携带式并行精化、渐进块增长和独立全深验证器结合，兼顾提案质量与验证效率。

- **工程可行性**：跨深度读取仅使用已验证前缀已物化的全深 K/V，不需要额外递归传递，便于在现有推理栈中实现。

## 8. 不足与局限
- **应用范围受限**：方法针对循环/递归深度 Transformer，依赖中间递归预测与深度索引 K/V 缓存；对普通非循环 Transformer 不直接适用。
