## 摘要
并行推测起草能在一次骨干网络前向中生成多个候选，但独立的词元选择可能产生不一致的延续，从而缩短被接受的前缀。现有方法大多将条件解码留给骨干网络之后的轻量级模块，这限制了前驱信息向后继的流动。我们对 DFlash 的分析表明，早期位置在浅层中已经形成可恢复的预测，并且准确的相邻前驱在更早进入时对后继帮助更大。因此我们提出 DSpine，一种在骨干网络全程注入因果条件的起草器：在每一层，门控相邻注入将每个前驱的预测特征写入其后继，从而使因果条件链随网络深度展开，同时所有位置并行更新。由目标模型输出嵌入构建的统一传输空间将逐层注入与前驱条件解码统一起来，而逐层输出嵌入监督促进浅层中预测特征的形成。融合内核和转移缓存使二者能在 SGLang 中高效并行执行。在七个数学、代码和聊天基准上，DSpine 在 Qwen3-4B 和 Qwen3-8B 上于两种温度下均取得最长的接受长度。在 Qwen3-8B 的温度零下，它将七基准均值从 DFlash 的 3.77 提高到 4.82（+27.8%）；在 SGLang 服务测试中，其吞吐量平均比 DFlash 高 23.3%。

## Abstract
Parallel speculative drafting generates multiple candidates in one backbone pass, but independent token selection can produce inconsistent continuations that shorten the accepted prefix. Existing methods mostly leave conditional decoding to a lightweight module after the backbone, which limits the flow of predecessor information to successors. Our analysis of DFlash shows that early positions already form recoverable predictions in shallow layers, and that accurate adjacent predecessors help successors more when they enter earlier. We therefore propose DSpine, a drafter with causal conditioning injection throughout the backbone: at every layer, gated adjacent injection writes each predecessor's predicted feature into its successor, so the causal conditioning chain unfolds over network depth while all positions update in parallel. A unified transfer space built from the target model's output embeddings unifies layer-wise injection with predecessor-conditioned decoding, and layer-wise output-embedding supervision promotes the formation of predicted features in shallow layers. Fused kernels and a transition cache execute both efficiently in parallel within SGLang. Across seven math, code, and chat benchmarks, DSpine achieves the longest acceptance length at both temperatures on Qwen3-4B and Qwen3-8B. At temperature zero on Qwen3-8B, it raises the seven-benchmark mean from DFlash's 3.77 to 4.82 (+27.8%); in SGLang serving tests, it delivers 23.3% higher throughput than DFlash on average.

## 1. 核心问题与整体含义

- **研究背景**：自回归解码是 LLM 推理延迟的主要来源之一。推测解码通过“轻量起草器提出多个候选 + 目标模型一次前向验证”来无损加速，其收益取决于每轮接受长度与起草成本。
- **核心问题**：DFlash 等并行起草器可在一次骨干前向中生成一个候选块，但各位置独立预测、在生成时不知道前驱实际会选哪个 token，因此容易产生局部合理但组合不一致的候选。由于验证按前缀顺序接受，一次不一致会截断后续候选，浪费并行起草的低成本优势。
- **现有方法局限**：Domino、DSpark、DFlash2 等主要在骨干网络之后用轻量模块做条件解码或候选选择；DFlash2 在骨干内用局部卷积混合相邻隐状态，但未明确区分“前驱的预测信息”与其余状态。前驱信息因此受限于最终层词表空间或后处理模块，难以在骨干各层中充分流向后续位置。
- **关键实证洞察**：
  - 浅层中较早位置已经包含可恢复的 token 预测信息。
  - 准确相邻前驱对后继预测帮助很大，并且越早进入后继计算，增益越明显。
- **整体含义**：论文提出 DSpine，将因果条件链从“骨干后处理”改为“贯穿骨干深度”的相邻注入，使所有位置仍可并行更新，但后继能在每一层吸收前驱当前预测特征，从而提升并行草稿的一致性与接受长度。

## 2. 方法论

### 2.1 核心思想

- 在每一层 Transformer 之后，让位置 \(t\) 接收其直接前驱 \(t-1\) 的预测特征，通过门控方式写入自身残差流。
- 所有位置在同一层内仍并行更新；但条件信息随网络深度逐层传播，形成“深度方向展开的因果条件链”。
- 同一套“统一转移空间”同时承载骨干内的预测特征注入与解码阶段已确定 token 的条件解码。

### 2.2 统一转移空间

- 利用目标模型 LM head 的输出嵌入构建 token 可解释空间：
  - 对 LM head 行做 \(\ell_2\) 归一化；
  - PCA 白化，保留 \(r\) 个主方向，再归一化，得到固定嵌入表 \(C\)。
- 两类信息进入同一空间：
  - **未确定前驱**：第 \(\ell\) 层预注入状态 \(u_{\ell,t}\) 经层特定投影 \(R_\ell\) 得到预测特征 \(z_{\ell,t}=f_\ell(u_{\ell,t})\)。
  - **已知 token**：直接使用其嵌入 \(\sqrt r C_x\)，如 anchor 或已解码前驱。
- 这样，骨干内可传递“预测特征”，解码时可传递“已决定 token”，路径统一。

### 2.3 相邻因果注入

- 第 \(\ell\) 层后，位置 \(t\) 只接收前驱 \(t-1\) 的消息。
- 门控由接收者特征 \(z_{\ell,t}\) 与前驱特征 \(z_{\ell,t-1}\) 共同决定：
  \[
  g_{\ell,t}=\sigma(G_q z_{\ell,t}+G_p z_{\ell,t-1}+b)
  \]
- 前驱消息：
  \[
  m_{\ell,t}=A z_{\ell,t-1}
  \]
- 写入后继残差流：
  \[
  h_{\ell,t}=u_{\ell,t}+\mathrm{RMS}(u_{\ell,t}) W_\ell(g_{\ell,t}\odot m_{\ell,t})
  \]
- 注入使用层内更新前特征，因此层内可并行；anchor 保持不变。
- 使用 **block-causal attention**：位置 \(t\) 只能关注目标上下文 K/V 和块内 \(0,\dots,t\)，与注入方向一致，防止训练时正确信息回流到更早位置。

### 2.4 前驱条件解码与转移缓存

- 最终层先得到每个位置 top-\(K\) 候选。
- **last-write refinement**：一旦前驱 token \(s\) 被选定，就用其嵌入 \(\sqrt r C_s\) 替换最终层预测特征 \(z_{L,t-1}\)，重新执行最终层注入，从缓存预注入状态 \(u_{L,t}\) 得到条件化输出与分数。
- **转移缓存**：因为每个位置分数依赖前驱选择，直接计算是串行的。DSpine 预先并行计算所有前驱候选与后继候选之间的转移分数：
  \[
  T_t[i,j]=S_t(v_{t-1,i},v_{t,j})
  \]
  再串行选择路径。论文中 \(K=16\)，以少量额外打分换取更短串行依赖链。

### 2.5 逐层输出嵌入监督

- 对每层注入后的读特征 \(e_{\ell,i}=f_\ell(h_{\ell,i})\)，与正确 token 嵌入 \(C_{y_i}\) 做余弦对齐：
  \[
  \mathcal L_{emb}=\sum_{\ell=1}^{L}\sum_i w_i[1-\cos(e_{\ell,i},C_{y_i})]
  \]
  其中 \(w_i=\exp(-(t_i-1)/\gamma)\) 为位置衰减权重。
- 目的：
  - 促进浅层形成可用的预测特征；
  - 缩小骨干内预测特征与解码时 token 嵌入之间的差距；
  - 只约束低维投影方向，不限制完整隐状态的上下文计算。

### 2.6 训练目标与流程

- 冻结目标模型、共享输入嵌入与 LM head。
- 监督两个输出：
  - 普通最终层输出，决定 top-\(K\) 候选；
  - last-write refinement 输出，限制在 top-\(K\) 候选内，训练前驱条件解码。
- 损失为 token 交叉熵与概率 \(\ell_1\) 距离的加权混合，类似 DSpark：
  \[
  \mathcal L_{dist}=\sum_i w_i[-\alpha\log q_i(y_i)+(1-\alpha)\|q_i-p_i\|_1]
  \]
- 总损失：
  \[
  \mathcal L=\mathcal L_{dist}+\lambda\mathcal L_{emb}
  \]
- 训练早期以一定概率用正确 token 嵌入替换浅层前驱特征，并逐渐退火，以缓解预测特征不可靠的问题。
