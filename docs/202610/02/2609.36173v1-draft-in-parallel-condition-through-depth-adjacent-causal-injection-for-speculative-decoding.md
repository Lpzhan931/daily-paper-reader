## 摘要
并行推测草拟在一次主干网络前向传播中生成多个候选，但独立的词元选择可能产生不一致的延续，从而缩短被接受前缀。现有方法大多将条件解码留给主干网络之后的轻量级模块，这限制了前驱信息向后继的流动。我们对DFlash的分析表明，早期位置在浅层已形成可恢复的预测，并且准确的相邻前驱越早进入，对后继的帮助越大。因此，我们提出DSpine，一种在主干网络中贯穿因果条件注入的草拟器：在每一层，门控相邻注入将每个前驱的预测特征写入其后继，从而使因果条件链沿网络深度展开，同时所有位置并行更新。由目标模型输出嵌入构建的统一迁移空间，将逐层注入与前驱条件解码统一起来，而逐层输出嵌入监督促进浅层中预测特征的形成。融合内核和转移缓存可在SGLang内高效并行执行二者。在七个数学、代码和聊天基准上，DSpine在Qwen3-4B和Qwen3-8B上于两种温度下均实现了最长接受长度。在Qwen3-8B上温度为零时，它将七个基准的平均值从DFlash的3.77提升至4.82（+27.8%）；在SGLang服务测试中，其平均吞吐量比DFlash高23.3%。

## Abstract
Parallel speculative drafting generates multiple candidates in one backbone pass, but independent token selection can produce inconsistent continuations that shorten the accepted prefix. Existing methods mostly leave conditional decoding to a lightweight module after the backbone, which limits the flow of predecessor information to successors. Our analysis of DFlash shows that early positions already form recoverable predictions in shallow layers, and that accurate adjacent predecessors help successors more when they enter earlier. We therefore propose DSpine, a drafter with causal conditioning injection throughout the backbone: at every layer, gated adjacent injection writes each predecessor's predicted feature into its successor, so the causal conditioning chain unfolds over network depth while all positions update in parallel. A unified transfer space built from the target model's output embeddings unifies layer-wise injection with predecessor-conditioned decoding, and layer-wise output-embedding supervision promotes the formation of predicted features in shallow layers. Fused kernels and a transition cache execute both efficiently in parallel within SGLang. Across seven math, code, and chat benchmarks, DSpine achieves the longest acceptance length at both temperatures on Qwen3-4B and Qwen3-8B. At temperature zero on Qwen3-8B, it raises the seven-benchmark mean from DFlash's 3.77 to 4.82 (+27.8%); in SGLang serving tests, it delivers 23.3% higher throughput than DFlash on average.

## 1. 核心问题与整体含义

- **背景**：自回归解码是 LLM 推理延迟的主要来源。推测解码通过轻量 drafter 提议多个候选、目标模型一次前向验证来加速，且不改变目标模型输出。
- **核心问题**：并行推测草拟（如 DFlash）能在一次骨干前向中生成多个候选，但各位置独立预测、独立选词，容易产生前后不一致的续写。由于验证按前缀顺序接受，一个不一致会截断后续草稿，导致接受前缀变短。
- **现有方法局限**：Domino、DSpark、DFlash2 等大多把前驱条件化放在骨干网络之后，例如后处理校正分支、顺序头或路径选择器。这限制了前驱信息向后继的流动，且信息多局限于最终层词汇空间，无法利用中间层特征。
- **关键洞察**：
  - DFlash 浅层中，较早位置已经形成可恢复的 token 预测信息。
  - 准确的相邻前驱对后继预测帮助很大；并且前驱特征越早进入网络，对后继帮助越明显。
- **整体含义**：DSpine 主张在并行草拟中把因果条件链从“骨干后处理”改为“贯穿骨干各层”，让所有位置仍可并行更新，但依赖关系沿网络深度逐步展开，从而提升接受长度与服务吞吐。

## 2. 方法论：核心思想与关键技术

- **核心思想**：在每一层 Transformer 后，用门控相邻注入把前驱的预测特征写入后继；所有位置在同一层内并行计算，但因果条件链沿深度传播。最终再通过同一注入路径完成前驱条件解码。
- **统一迁移空间**：
  - 从目标模型 LM head 输出嵌入构建固定嵌入表 \(C\)：对 LM head 行做 ℓ2 归一化、PCA 白化、保留 \(r\) 个主方向、再归一化。
  - 未确定 token 的前驱贡献预测特征：\(z_{\ell,t}=f_\ell(u_{\ell,t})=\sqrt{r}\,\text{normalize}(R_\ell u_{\ell,t})\)。
  - 已知 token（锚点或已解码前驱）直接使用 \(\sqrt{r} C_x\)。
  - 预测特征与已决 token 嵌入处于同一空间，因此同一路径既能传递预测，也能传递确定 token。
- **相邻因果注入**：
  - 每层位置 \(t\) 只接收相邻前驱 \(t-1\) 的消息。
  - 门控由接收者特征与前驱特征共同决定：\(g_{\ell,t}=\sigma(G_q z_{\ell,t}+G_p z_{\ell,t-1}+b)\)。
  - 消息为 \(m_{\ell,t}=A z_{\ell,t-1}\)，写回残差：\(h_{\ell,t}=u_{\ell,t}+\text{RMS}(u_{\ell,t})W_\ell(g_{\ell,t}\odot m_{\ell,t})\)。
  - \(A,G_q,G_p,b\) 跨层共享，\(W_\ell\) 每层独立；写矩阵和门控初始化为零，使注入初始接近恒等映射。
- **块因果注意力**：所有骨干层使用块因果注意力，位置 \(t\) 只关注目标上下文和块内 \(0,\dots,t\)。注意力方向与注入方向一致，避免训练时正确信息回流到更早位置。
- **传播与并行**：注入从第 1 层开始，前驱在第 \(\ell\) 层收到的信息可影响其在第 \(\ell+1\) 层发给后继的消息，形成沿深度的因果条件链；同层内所有位置仍并行更新。
- **前驱条件解码与 last-write refinement**：
  - 最终层输出先给出各位置 top-K 候选。
  - 选定前驱 token \(s\) 后，用 \(\sqrt{r} C_s\) 替换预测特征 \(z_{L,t-1}\)，重做最终层写入，得到条件分数 \(S_t(s,v)\)。
- **转移缓存**：
  - 由于每个位置分数只依赖前驱选择，可预先并行计算所有相邻候选对的分数 \(T_t[i,j]=S_t(v_{t-1,i},v_{t,j})\)。
  - 选择阶段再串行遍历缓存，避免串行矩阵运算；实践中 \(K=16\)。
- **逐层输出嵌入监督**：
  - 对每层后注入状态读出 \(e_{\ell,i}=f_\ell(h_{\ell,i})\)，与正确 token 嵌入 \(C_{y_i}\) 做余弦对齐。
  - 损失：\(L_{\text{emb}}=\sum_\ell\sum_i w_i[1-\cos(e_{\ell,i},C_{y_i})]\)，\(w_i=\exp(-(t_i-1)/\gamma)\)。
  - 该监督促进浅层预测特征形成，并缩小预测特征与解码时 token 嵌入的差距；只约束低维投影方向，不限制完整隐状态。
- **训练目标**：
  - 冻结目标模型、共享输入嵌入与 LM head。
  - 两个输出受监督：普通最终层输出；last-write refinement 输出（使用正确前驱 token，仅对 top-K 候选预测）。
  - 分布损失：\(L_{\text{dist}}=\sum_i w_i[-\alpha\log q_i(y_i)+(1-\alpha)\|q_i-p_i\|_1]\)，\(\alpha=0.1\)。
  - 总损失：\(L=L_{\text{dist}}+\lambda L_{\text{emb}}\)，\(\lambda=\beta_t\,\text{sg}(CE_{bb})\)，\(\beta_t\) 前 146 步从 0 线性升至 0.5。
  - 正确前驱课程：浅层 1–3 以概率 \(p\) 使用正确 token 嵌入替代预测特征，\(p\) 在前 1/6 训练为 0.5，到 1/3 时衰减为 0。
- **工程优化**：融合投影、两个融合内核、CUDA graph；层内注入并行执行。
