## 摘要
自推测解码通过从目标模型自身草拟 token 来加速大语言模型（LLM）推理，但在草稿质量与成本之间面临尖锐权衡。早退方法通过在中间层终止计算来低成本地生成草稿，但放弃了后续层提供的更深层表示，因而草稿质量受损。多 token 预测通过从模型的最终隐藏状态生成 token 来保持草稿质量，但每个草拟步骤都要付出一次完整前向传播的代价来产生这些状态。我们提出自推测编码器-解码器（SEED），一种自推测方法，通过复用验证期间已经计算出的深层上下文表示，以低成本获得高质量草稿。我们将标准仅解码器 Transformer 重新解释为隐式编码器-解码器：前若干层（编码器）构建深层上下文表示，最后几层（解码器）基于这些表示生成 token。编码与验证合并为单一步骤：验证由完整的编码器-解码器执行，已验证前缀的上下文表示被缓存，以便在草拟期间复用。因此草拟非常快：在两次验证之间，轻量级解码器自回归地草拟多个 token，每个 token 都以缓存的表示和先前的草稿为条件。在多个基准上的实验表明，SEED 在 4B 规模模型上实现了最高 2.7× 的平均加速，优于早退和 MTP 风格的自推测基线，并且比最先进的 EAGLE-3 快 28%，同时保持甚至提升标准自回归微调的生成质量。代码可在 https://github.com/lhk2004/SEED 获取。

## Abstract
Self-speculative decoding accelerates large language model (LLM) inference by drafting tokens from the target model itself, but faces a sharp tradeoff between the quality and cost of the draft. Early-exit methods produce drafts cheaply by terminating computation at intermediate layers, but forgo the deeper representations that later layers provide and thus suffer in draft quality. Multi-token prediction preserves draft quality by emitting from the model's final hidden states, but pays for a full forward pass to produce those states at every drafting step. We propose self-speculative encoder-decoder (SEED), a self-speculative method that obtains high-quality drafts cheaply by reusing the deep contextual representations already computed during verification. We reinterpret the standard decoder-only transformer as an implicit encoder-decoder: the first layers (encoder) build deep contextual representations, and the last few layers (decoder) emit tokens from them. Encoding and verification are merged into a single step: verification is performed by the full encoder-decoder, and the contextual representations of the verified prefix are cached for reuse during drafting. Drafting is therefore very fast: between verifications, the lightweight decoder drafts multiple tokens autoregressively, each conditioned on the cached representations and on preceding drafts. Experiments across multiple benchmarks show that SEED achieves up to 2.7$\times$ average speedup on 4B-scale models, outperforming both early-exit and MTP-style self-speculative baselines and running 28% faster than the state-of-the-art EAGLE-3, while preserving or even improving the generation quality of standard autoregressive fine-tuning. Code is available at https://github.com/lhk2004/SEED.

# SEED：通过隐式编码器-解码器的自推测解码 — 论文总结

## 1. 核心问题与研究动机

- **背景**：LLM 推理是内存带宽受限而非计算受限——生成每个 token 都需要完整前向传播，却只产出一个输出，GPU 并行算力被严重浪费。推测解码通过廉价草稿模型提出候选 token、由目标模型并行验证来摊薄成本，但维护一个独立且对齐良好的草稿模型会显著增加部署复杂度。
- **自推测解码**：在单一统一模型内同时完成草稿与验证，避免额外草稿模型。但其面临**草稿质量与草稿成本的尖锐权衡**：
  - **早退/跳层方法**（LayerSkip、SWIFT、DEL 等）：在中间层终止计算，草稿廉价，但只能基于浅层表示预测，草稿质量受限。
  - **多 token 预测（MTP）方法**（Apple MTP 等）：从模型最终隐藏状态生成草稿，保留表示深度，但每个草拟步骤都要一次完整前向传播。
- **核心问题**：能否让草稿既拥有完整模型的表示深度，又只付出少数几层的计算代价？

## 2. 方法论

### 2.1 核心思想：解码器 Transformer 即隐式编码器-解码器

- 将标准仅解码器 Transformer 的 $l$ 层在 $l'$ 层处划分：
  - **编码器** $f_{enc}=f_{1:l'}$（如 28 层中的前 26 层）：构建前缀的深层上下文表示。
  - **解码器** $f_{dec}=f_{l'+1:l}$（如最后 2 层）：从这些表示自回归地生成下一个 token。
- 该分解与标准自回归解码**完全等价**，但显式暴露了结构不对称性：编码器占绝大部分计算，解码器只是薄薄几层。

### 2.2 关键观察：验证本身已完成编码工作

- 验证一批草稿时，完整编码器-解码器前向传播会产生 $KV^{dec}_{<n}$，即截至最后已验证草稿 token 的深层上下文表示。
- **验证与编码合并为单一步骤**：一次完整前向传播同时完成草稿验证与深层缓存刷新，无需单独运行编码器。

### 2.3 廉价草拟

- 两次验证之间，解码器无需再调用编码器：将最新 token 的原始嵌入 $H^0_n = W_{in}X_n$ 直接输入解码器，通过"交叉注意力"（即对 KV 缓存的标准自注意力，查询来自原始嵌入、键值来自编码器产生的深层缓存）预测下一 token。
- 每个草稿 token 仅需一次薄解码器前向传播，却条件于验证器的全深度前缀表示。

### 2.4 训练算法

- **标准自回归目标**（保留生成质量）：
  $$\mathcal{L}_{CE} = \mathbb{E}_{X\sim D}\left[\sum_{j=1}^{|X|}-\log f_{dec}(X_j \mid H^{l'}_{j-1}, KV^{dec}_{<(j-1)})\right]$$
- **推测草拟目标**：让解码器学会仅凭原始 token 嵌入 + 缓存深层 KV 来预测未来 token：
  $$\mathcal{L}_{spec} = \mathbb{E}_{X\sim D}\left[\sum_{j=1}^{|X|}-\log f_{dec}(X_j \mid H^0_{n'\le\cdot\le(j-1)}, KV^{dec}_{<n'})\right]$$
- **块注意力训练**：将训练序列划分为长度 $b$ 的连续非重叠块（主实验 $b=10$），块内 token 通过因果自注意力仅看原始嵌入，并交叉注意力到所有前序块的深层 KV 缓存；块边界 $n'$ 在块内保持一致，使所有块可并行处理。
- **最终目标**：$\mathcal{L} = \frac{\mathcal{L}_{CE} + \lambda\mathcal{L}_{spec}}{1+\lambda}$，主实验 $\lambda=1.0$。
- 训练流程分两阶段：先用完整编码器-解码器计算 $\mathcal{L}_{CE}$ 并缓存所有位置的解码器 KV；再用块注意力掩码让解码器并行处理所有块计算 $\mathcal{L}_{spec}$。

### 2.5 推理算法

- **固定长度草拟**：解码器自回归生成 $d$ 个草稿 token（交叉注意力到上次验证缓存的深层 KV），再由完整模型一次前向并行验证，接受最长匹配前缀并附加一个奖励 token。
- **自适应草拟 + 树式验证**：
  - 基于置信度阈值 $\tau$ 的动态停止规则（主实验 GSM8K/KodCode/ScienceQA 取 0.7，CNN/Daily Mail 取 0.5）。
  - 每步按 top-p 规则扩展候选数 $k$：$p_0>0.95$ 取 1，$0.8<p_0\le0.95$ 取 3，$0.5<p_0\le0.8$ 取 5，否则取 10。
  - 树式注意力掩码：每个候选 token 仅注意已验证前缀和自身祖先路径上的候选，从而在一次前向中并行验证多条分支。

## 6. 主要结论与发现

- **加速效果**：Qwen3-1.7B-Base 上平均加速 2.6×，Qwen3-4B-Base 上平均 2.7×，优于所有自推测基线，比 SOTA 的 EAGLE-3 快 28%（尽管 EAGLE-3 使用独立训练草稿网络）。

- **草稿质量来源**：

## 7. 优点

- **极简性**：不改变模型架构，仅在标准 SFT 上增加一个辅助损失，易于集成到现有微调流程。
- **无独立草稿模块**：避免额外系统复杂度，草稿器与验证器共享参数，分布天然对齐。
- **验证与编码合一**：巧妙复用验证时已产生的深层 KV 缓存，使草稿几乎"免费"获得全深度上下文。
- **质量-效率双赢**：不仅加速，还通过规划前瞻效应提升任务表现。
- **工程适配性**：自适应草拟 + 树式验证与 SEED 特性高度契合（草稿廉价、共享参数使置信度可靠）。
- **分析扎实**：线性探针、CKA、成本模型、参数共享消融等多角度验证机制解释。
