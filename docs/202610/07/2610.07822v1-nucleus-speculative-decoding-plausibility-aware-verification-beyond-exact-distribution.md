## 摘要
投机解码通过使用轻量级草稿模型提出多个 token，并由目标模型并行验证，从而加速自回归生成。然而，标准接受规则侧重于精确分布校正，当草稿模型分配了超额概率时，会拒绝那些在目标模型下仍然高度合理的 token。这种保守验证限制了每次验证前向传播后保留的草稿 token 数量。我们提出 Nucleus 投机解码（NSD），一种将目标模型合理性纳入投机解码的松弛验证方法。NSD 接受一个草稿 token，如果它满足标准接受规则或属于目标模型的 nucleus。我们从理论上刻画了该方法引入的分布偏差，并表明单步误差恰好由草稿模型在目标 nucleus 内的超额概率决定。我们进一步推导了序列级保真度界，量化了局部偏差在自回归解码过程中如何累积。在多个目标模型和提议机制上的实验表明，NSD 在保持有竞争力的任务性能的同时，持续提升投机解码效率。我们的方法相较于自回归解码实现了最高 5.16 倍的吞吐量加速，相较于标准投机解码实现了最高 3.15 倍的加速。这些改进伴随着更长的接受长度，使更多输出 token 能够分摊每次目标验证传递的成本。分析表明，合理性感知验证为松弛验证和提升投机解码效率提供了一种有效途径。我们的代码可在 https://github.com/EIT-NLP/Nucleus-Speculative-Decoding 获取。

## Abstract
Speculative decoding accelerates autoregressive generation by using a lightweight draft model to propose multiple tokens that are verified by a target model in parallel. However, the standard acceptance rule focuses on exact distribution correction and rejects tokens that remain highly plausible under the target model when the draft model assigns excess probability. This conservative verification limits the number of draft tokens retained after each verification forward pass. We introduce Nucleus Speculative Decoding (NSD), a relaxed verification method that incorporates target-model plausibility into speculative decoding. NSD accepts a draft token if it satisfies the standard acceptance rule or belongs to the target model's nucleus. We theoretically characterize the distributional deviation introduced by our method and show that the single-step error is exactly determined by the draft model's excess probability within the target nucleus. We further derive sequence-level fidelity bounds that quantify how local deviations accumulate over autoregressive decoding. Experiments across multiple target models and proposal mechanisms demonstrate that NSD consistently improves speculative decoding efficiency while maintaining competitive task performance. Our method achieves throughput speedups of up to $5.16\times$ over autoregressive decoding and up to $3.15\times$ over standard speculative decoding. These improvements coincide with longer accepted lengths, allowing more output tokens to share the cost of each target verification pass. Analysis shows that plausibility-aware verification provides an effective approach for relaxed verification and speculative decoding efficiency. Our code is available at https://github.com/EIT-NLP/Nucleus-Speculative-Decoding.

# Nucleus Speculative Decoding 论文总结

## 1. 核心问题与整体含义

- **研究背景**：大语言模型（LLM）自回归解码是顺序生成，推理成本高。投机解码（Speculative Decoding, SD）用轻量草稿模型一次提议多个 token，再由目标模型并行验证，从而加速生成。
- **核心瓶颈**：标准 SD 的接受规则是  
  \[
  a_i^{SD}(x_i)=\min\{1,p_i(x_i)/q_i(x_i)\}
  \]
  其目标是保持目标分布精确性。当草稿分布给某 token 分配了比目标模型更高的概率，即 \(q(x)>p(x)\) 时，即使该 token 在目标模型下仍排名很高、属于高概率区域，也可能被拒绝。
- **实证动机**：
  - 目标验证占总墙钟时间的 57.1%–78.1%。
  - 被拒绝 token 中，81.5% 仍位于目标模型 top-10；在 Top-P=0.95 时，52.6% 仍属于目标 nucleus。
- **整体含义**：作者认为标准 SD 验证过于保守，提出 **Nucleus Speculative Decoding（NSD）**，在保留标准接受规则的同时，额外接受属于目标模型 nucleus 的草稿 token，以“合理性感知”替代部分“精确分布校正”，从而提升接受长度和吞吐。

## 2. 方法论

### 2.1 核心思想

- NSD 不改变草稿提议机制，也不改变拒绝后的残差校正与 bonus sampling。
- 在每个验证位置，除了标准 SD 接受条件外，增加一个条件：若草稿 token 属于目标模型当前分布的 nucleus，则接受。
- 判定规则：
  \[
  b_i=1\{u_i\le a_i^{SD}(x_i)\ \lor\ x_i\in S_i(\theta)\}
  \]
  其中 \(S_i(\theta)\) 是目标分布 \(p_i\) 的 nucleus。

### 2.2 关键技术细节

- **目标 nucleus 构造**：按目标概率从高到低排序，取累计概率首次达到阈值 \(\theta\in(0,1)\) 的最小集合：
  \[
  S_i(\theta)=\{v_{i,(1)},\dots,v_{i,(k_i(\theta))}\},\quad
  k_i(\theta)=\min\{k:\sum_{j=1}^k p_i(v_{i,(j)})\ge\theta\}
  \]
- **不重归一化**：NSD 不把 \(p_i\) 或 \(q_i\) 在 nucleus 上重新归一化，只把 nucleus 成员资格作为额外接受条件。
- **拒绝处理**：若标准规则和 nucleus 规则都不满足，仍按标准 SD 的残差分布重采样：
  \[
  \rho_i(v)=\frac{[p_i(v)-q_i(v)]^+}{\sum_w [p_i(w)-q_i(w)]^+}
  \]
- **算法流程**：
  1. 草稿模型生成 \(K\) 个候选 token，并保留提议分布 \(q_{1:K}\)；
  2. 目标模型一次前向计算 \(p_1,\dots,p_{K+1}\)；
  3. 对每个位置构造目标 nucleus \(S_i(\theta)\)；
  4. 采样 \(u_i\)，若标准接受或 \(x_i\in S_i(\theta)\)，则接受；
  5. 否则从残差分布重采样并返回；
  6. 若全部接受，则从 \(p_{K+1}\) 采样 bonus token。

### 2.3 理论分析

- 定义拒绝概率 \(R=D_{TV}(q,p)\)，以及草稿在目标 nucleus 内的超额概率：
  \[
  E_S=\sum_{v\in S}[q(v)-p(v)]^+
  \]
- 单步输出分布偏差：
  \[
  D_{TV}(\tilde p,p)=E_S=\bar a_{NSD}-\bar a_{SD}\le R
  \]
  即 NSD 额外接受的概率恰好等于其单步分布偏差。
- 序列级保真度：若每步 \(D_{TV}(K_t,p_t)\le\epsilon_t\)，则
  \[
  D_{TV}(P_{NSD}^{(T)},P_p^{(T)})\le 1-\prod_{t=1}^T(1-\epsilon_t)\le \sum_{t=1}^T\epsilon_t
  \]
  均匀误差 \(\epsilon\) 下，序列一致概率至少为 \((1-\epsilon)^T\ge 1-T\epsilon\)。
- 示例：若 \(\epsilon\le 10^{-3}\)，\(T=32\)，则一致概率至少约 \(0.9685\)。
