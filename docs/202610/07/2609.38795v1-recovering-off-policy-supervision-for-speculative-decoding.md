## 摘要
投机解码中的块级草稿器通常由外部模型生成的语料训练，其中单个离策略 token 就会使一个块中所有后续槽位的监督失效。现有方法丢弃这些偏离槽位，造成严重的监督损失。为在保留训练语料的同时解决该问题，我们提出一种基于 rollout 的训练框架，通过两个互补组件恢复完整监督。第一个组件为锚点标签重标注（Anchor-Label Relabelling, ALR），用来自贪婪目标 rollout 的分布替换语料标签，从而恢复所有预测槽位上的有效监督。第二个组件为 Rollout 内锚点（In-Rollout Anchors, IRA），将草稿块直接置于这些 rollout 内，使草稿器接触目标生成的上下文，并复用预计算的 rollout 特征，且不产生额外目标模型开销。在固定的视觉-语言和文本语料上，我们的框架相比 DFlash 将贪婪接受长度最多提升 36.5%，并持续优于擦除基线。值得注意的是，我们的方法仅一个 epoch 就超过了最佳擦除调度。三个 epoch 后，其接受长度与在目标模型重新生成的响应上训练相匹配。这些结果表明，我们的框架提供了一种有效且计算高效的方法，可在不修改原始文本的情况下，在固定语料上训练投机草稿器。代码见 https://github.com/js-lee-AI/ALR-IRA。

## Abstract
Block drafters for speculative decoding are commonly trained on corpora written by external models, where a single off-policy token invalidates supervision for all subsequent slots in a block. Existing approaches discard these divergent slots, resulting in severe supervision loss. To resolve this problem while preserving the training corpus, we propose a rollout-based training framework that recovers full supervision through two complementary components. The first component, Anchor-Label Relabelling (ALR), replaces corpus labels with distributions from greedy target rollouts, restoring valid supervision across all predicted slots. The second component, In-Rollout Anchors (IRA), places draft blocks directly inside these rollouts to expose the drafter to target-generated context, reusing precomputed rollout features at no additional target cost. Across fixed vision-language and text corpora, our framework increases greedy accepted length by up to 36.5% over DFlash and consistently outperforms erasing baselines. Notably, a single epoch of our method surpasses the best erase schedules. After three epochs, it matches the acceptance length of training on target-regenerated responses. These results show that our framework provides an effective and compute-efficient approach for training speculative drafters on fixed corpora without modifying the original text. Code is available at https://github.com/js-lee-AI/ALR-IRA.

# 论文总结：Recovering Off-Policy Supervision for Speculative Decoding

## 1. 核心问题与整体含义

- **背景**：投机解码（Speculative Decoding）通过小型草稿模型（drafter）并行提出候选 token，再由目标模型（target）一次前向验证，从而在不改变目标分布的前提下降低自回归生成延迟。其加速效果取决于**接受长度**（每轮验证中被采纳的 token 数）。
- **核心问题**：块级草稿器（block drafter）一次前向并行预测一个块内的所有槽位（论文中 K=15），每个槽位的标签依赖块内前面的 token。当训练语料由外部更强模型（如 GPT-4V）生成时，语料对目标模型而言是**离策略（off-policy）**的——只要块内有一个 token 与目标模型的贪心选择不一致，该块后续所有槽位的监督就建立在目标模型不会生成的前缀上，变得无效。
- **现有做法的缺陷**：
  - **擦除（Erase）类方法**（如 PARD-2）：按目标模型对前缀语料 token 的概率对槽位降权，前缀一旦偏离目标分布，权重趋近于零，造成**严重监督损失**。
  - **响应重生成**：用目标模型重新生成语料，虽可避免监督损失，但**替换了原始语料**，在某些场景（如仅能使用已审计/已授权数据）不可行。
- **整体含义**：论文在**保留原始训练语料不变**的前提下，提出基于 rollout 的训练框架，恢复被丢弃的监督信号，使固定语料上训练的草稿器达到接近目标模型重生成语料的训练效果。

## 2. 方法论

### 核心思想
从语料中的每个锚点（anchor）出发，让目标模型做**短程贪心 rollout**，用 rollout 沿线的目标分布替代语料标签；同时把一部分草稿块**放进 rollout 内部**，使草稿器在训练时接触到目标模型生成的上下文。

### 关键技术细节

- **统一损失形式**：
  - 对锚点集合 A 中每个锚点 a 的每个槽位 k，损失为
    L(θ) = Σ_{a,k} ω_{a,k} · ℓ(π_{a,k}, q_k^θ(·|a)) / Σ_{a,k} ω_{a,k}
  - 其中 π 为目标分布标签，q 为草稿器预测，ℓ 为对目标 top-8 概率加一个尾部桶的软交叉熵；ω 为槽位权重，含衰减包络 w_k = e^{−(k−1)/γ}（默认 γ=2）。

- **基线 KD**：π_{a,k} = p_T(·|x_{<a+k})，ω_{a,k} = w_k，标签仍以语料续写为条件。

- **擦除基线（Erase）**：在 KD 基础上乘以生存门控
  g_{a,k} = Π_{1≤j<k} p_T(x_{a+j} | x_{<a+j})，ω_{a,k} = w_k · g_{a,k}
  前缀偏离目标分布时权重衰减，但仍以语料续写为条件。

- **ALR（Anchor-Label Relabelling）**：
  - 从锚点 x_{≤a} 出发，目标模型贪心生成 rollout token：y*_i = argmax_v p_T(v | x_{≤a}, y*_{<i})
  - 槽位 k 的标签改为 π_{a,k} = p_T(· | x_{≤a}, y*_{<k})
  - rollout 深度 R 设为 K−1=14（IRA 需要全深度；单独 ALR 可用 R=4）
  - 草稿器输入不变（锚点 token + 语料前缀的目标特征）；ALR 不使用生存门控。

- **IRA（In-Rollout Anchors）**：
  - 保持总块数 m = min(v, 128) 不变，拆成两组：
    - ⌈m/2⌉ 个**主块**：按标准 ALR 做 rollout。
    - ⌊m/2⌋ 个**次块**：放在主块 rollout 内部偏移 j ~ U{2,...,K−1} 处，条件上下文为语料前缀特征拼接 y*_1,...,y*_{j−1} 的中间表示，slot 0 为目标生成的 y*_j，槽位 k 继承主块位置 j+k 的标签，权重 ω = w_k · 1[j+k ≤ K]。
  - **无额外目标前向开销**：rollout 特征与分布已在主块 rollout 中计算并缓存，次块直接复用。

- **实现要点**：rollout 在训练步内完成，复用目标模型对语料样本的前向 KV 缓存；所有锚点共享语料 key，每个锚点单独维护自己的 rollout key 缓冲；分组查询注意力避免重复复制 key。

## 6. 主要结论与发现

- **ALR + IRA 全面领先**：贪婪解码下接受长度相比同数据 DFlash 最高提升 **36.5%**（T=1 下 33.1%），相比擦除基线最高提升 **8.54%**（ALLaVA），在所有评测域和 benchmark 上均优于擦除。
- **加速效果**：ALLaVA 上 T=0 达 **2.82×**（擦除 2.62×），ShareGPT4V 上 2.77×；文本 7 benchmark 平均 2.80×（擦除 2.67×）。
- **单 epoch 即超过最佳擦除调度**：ALLaVA 上 1 epoch ALR + IRA 超过擦除的最佳调度（3 epoch），且训练时间少 41%。
- **三个 epoch 后匹配目标重生成**：在 ALLaVA 上，ALR + IRA 与长度匹配的目标重生成参考的接受长度差距在 **0.4%** 以内，说明无需替换原始语料即可获得重生成的收益。
- **ALR 短 rollout 足够**：R=4 在 ALLaVA 上非劣于 R=14，训练更快。
- **IRA 的增益来源**：槽位匹配对照显示 IRA 的收益不只是改变槽位权重，而是把锚点放入目标 rollout 提供目标生成上下文；其增益在**独立草稿器无法预测首 token 的困难位置**最大，且在**后续位置**（16 token 之后）持续增大。
- **标签来源比加权规则更重要**：在固定文本语料上，rollout 标签在有无生存门控两种设置下都提升接受长度；生存门控对语料标签有帮助，但对 rollout 标签增益很小。

## 7. 优点

- **问题切入准确**：清晰指出块级草稿器在离策略语料上的监督失效机制，并将其与模仿学习中的协变量偏移对应。
- **方法简洁且计算高效**：ALR 只改标签不改语料；IRA 复用 rollout 缓存的特征与分布，**不增加目标模型前向次数**，是"免费"的上下文增强。
- **保留原始语料**：在审计/许可等必须保留原始响应的场景下，提供了替代重生成的实际方案。
- **实验严谨**：
  - 预注册比较规则、多种子重复、配对 bootstrap、跨设备容差说明。
  - 设计了槽位匹配对照、数据顺序对照、独立草稿器难度分层等多种控制，能有效排除混淆因素。
  - 同时报告接受长度与墙钟速度，并用链式验证验证增益不依赖树分支。
- **跨模态与跨规模泛化验证**：VL（8B/4B）+ 文本（4B），贪婪 + 采样，多个 benchmark。
- **与重生成参考的直接对齐**：证明固定语料 + rollout 训练可达到重生成语料的接受长度水平。

- **实现限制**：方法依赖目标模型的**隐藏状态和 token 分布**，只能用于特征条件化的块草稿器（如 DFlash），对无特征访问的草稿器不适用。

- **贪心 rollout vs 采样推理**：训练标签来自贪心 rollout，而推理支持贪婪与采样两种模式；论文未构造与推理采样策略匹配的 rollout，这是作者自己指出的自然扩展方向。这意味着在 T=1 采样解码下，训练与推理之间仍存在一定程度的目标分布不匹配（尽管实验中 T=1 的增益依然显著）。
- **对块大小 K 的依赖**：完整框架（含 IRA）中，rollout 深度 R 设为 K−1=14，IRA 次块偏移范围也是 2 到 K−1；方法的设计与超参数（偏移分布、槽位继承规则、包络 γ）均围绕固定块大小 K=15 展开，论文未系统研究 K 取其他值时各超参数的迁移性。
- **锚点密度与训练开销的权衡**：每样本使用 128 个锚点，且每个锚点需要独立的 rollout key 缓冲，内存占用随锚点数线性增长；虽然论文说明通过分组查询注意力避免重复复制 key，但在更大目标模型或更长上下文下，rollout 的 KV 缓存开销仍可能成为瓶颈，论文未报告显存峰值随锚点数/序列长度的扩展曲线。
- **评测域覆盖**：评测集中在 captioning、VQA、文档问答与通用对话/代码/数学推理；对长上下文、多轮对话、结构化输出（如 JSON）、工具调用等真实部署中常见的场景覆盖有限。
- **目标模型规模上限**：最大目标模型为 8B，未验证在 30B/70B 甚至更大目标模型上，rollout 的监督信号与擦除基线的相对优势是否保持（大模型的目标分布更尖锐，离策略失配可能更严重，也可能因标签更确定而使擦除门控更少触发）。
- **短程 rollout 的信息上限**：rollout 深度最多 K−1 步，标签只在块窗口内校正；对于需要长程一致性才能正确生成的内容（如跨块的长距离依赖），该方法无法提供超出窗口的监督，仍需依赖语料本身。
- **与"替换语料"路线的定位**：论文主张保留原始语料的场景价值，但对"何时应当重生成、何时应当用 rollout 恢复"没有给出可操作的判据；重生成参考在 3 epoch 后与 ALR+IRA 接近，说明二者可能在不同数据预算/许可约束下各有优势，论文未做进一步的成本-收益决策分析。
- **软交叉熵的目标 top-8 + 尾部桶近似**：标签分布被截断为 top-8 概率加一个聚合尾部桶，这在目标分布尾部较长时可能损失细节；论文未消融 top-k 截断阈值的影响。

## 9. 总体评价与启示

- **理论定位清晰**：论文将块级草稿器在离策略语料上的监督失效，准确对应到模仿学习中的**协变量偏移（covariate shift）**问题，并把"擦除"理解为一种朴素的分布校正（按生存概率降权），把"rollout 重标注"理解为**用专家在正确状态分布上的动作替换离线数据标签**（类似 DAgger 的思想）。这一类比使方法动机具有很强的说服力。
- **工程价值**：ALR 与 IRA 都是"轻量"改动——不改变草稿器架构、不改变训练语料、不增加目标模型前向次数（IRA 复用缓存），却带来显著且一致的接受长度提升，非常适合作为现有块草稿器训练管线的即插即用增强。
- **实验可信度高**：预注册比较规则、多种子、配对 bootstrap、跨设备漂移容差、槽位匹配对照等设计，显著高于同类工作的平均严谨度；同时报告接受长度与墙钟速度，避免了"只快在指标上"的质疑。
- **可扩展方向**：作者自己指出的采样策略匹配 rollout（如按推理温度采样 rollout token）是最自然的后续工作；此外，将 rollout 深度自适应化（按位置难度动态决定 R）、把 IRA 的偏移分布从均匀改为难度感知、以及将该框架推广到多步/树状草稿器，都是值得探索的方向。
- **一句话总结**：论文证明，在固定（离策略）训练语料下，与其丢弃失配的监督，不如用目标模型的短程 rollout 把监督"搬回"目标分布上，并以几乎零额外前向开销的方式让草稿器在目标生成的上下文中学习——这是块级投机解码训练中一个简洁而有效的范式转变。
