## 摘要
推测解码通过首先使用一个较小的模型（称为草稿模型）生成候选 token，然后由目标模型验证这些 token 以决定接受或拒绝，从而加速大语言模型（LLM，称为目标模型）的推理。先前研究主要关注推测解码的效率-效用权衡，例如有损推测解码，而对其安全影响基本未作探索。在本工作中，我们通过首次系统研究推测解码的安全影响来填补这一空白。通过大规模测量研究，我们揭示了一种显著的安全-效用不对称性：在多种有损推测解码方法中，推理效率的提升以不成比例的高安全代价换取，越狱攻击和提示注入攻击的成功率增长远快于效用下降。然后，我们提出 SecureSD，一种新的理论引导的推测解码方法，在保持效率和效用的同时增强安全性。具体而言，我们的理论分析表明，安全性下降主要源于草稿模型生成的早期 token。受此启发，SecureSD 对早期解码位置处的草稿模型 token 应用更严格的验证准则。在安全性和效用基准上的大量实验表明，与现有推测解码方法相比，SecureSD 在保持效率和效用的同时显著提高了安全性。

## Abstract
Speculative decoding accelerates inference for a large language model (LLM), referred to as the \emph{target model}, by first using a smaller model, referred to as the \emph{draft model}, to generate candidate tokens and then verifying them with the target model for acceptance or rejection. Prior studies primarily focused on the efficiency-utility trade-off of speculative decoding, e.g., lossy speculative decoding, leaving its security implications largely unexplored.   In this work, we bridge this gap by providing the \emph{first} systematic study of the security implications of speculative decoding. Through a large-scale measurement study, we reveal a pronounced security-utility asymmetry: across a wide range of lossy speculative decoding methods, improvements in inference efficiency come at a disproportionately high cost to security, with attack success rates for jailbreak and prompt injection attacks increasing much faster than utility degrades.   We then propose SecureSD, a new theory-guided speculative decoding method that enhances security while maintaining efficiency and utility. Specifically, our theoretical analysis reveals that security degradation primarily originates from the early tokens generated by the draft model. Motivated by this insight, SecureSD applies a stricter verification criterion to draft-model tokens at early decoding positions. Extensive experiments on both security and utility benchmarks demonstrate that SecureSD significantly improves security while preserving efficiency and utility compared to existing speculative decoding methods.

## 1. 核心问题与整体含义

- **研究背景**：推测解码（Speculative Decoding）通过小模型（草稿模型）快速生成候选 token，再由大模型（目标模型）并行验证，从而显著降低 LLM 自回归解码延迟，已被 Google、vLLM、TensorRT-LLM、SGLang 等生产系统采用。
- **核心问题**：既有研究主要优化推测解码的“效率—效用”权衡，尤其是通过放宽验证准则（lossy / relaxed verification）提高接受率与吞吐，但其在对抗输入下的安全影响未被系统研究。
- **整体含义**：放宽验证可能接受目标模型本应拒绝的草稿 token；在越狱（jailbreak）和提示注入（prompt injection）场景中，这些早期偏差会把回答从“拒绝”推向“顺从”，而传统效用基准对此几乎不可见。
- **论文主张**：首次系统研究有损推测解码的安全含义，揭示“安全—效用不对称性”，并提出理论引导的防御方法 SecureSD。

## 2. 方法论

### 2.1 统一验证器抽象

- 将推测解码验证器形式化为 `S(q, p, α, R)`：
  - `q_t(x)`：目标模型条件分布；
  - `p_t(x)`：草稿模型条件分布；
  - `α_t(x)`：接受函数，决定草稿 token 被接受的概率；
  - `R_t(x)`：拒绝后的恢复分布。
- 该抽象可统一描述 LossySD、BiLD、SpecCascade、FSD、FLy、MARS 六种放宽验证方法。

### 2.2 理论分析

- **定理 1（松弛验证器输出分布）**：  
  `q̃_t(x) = p_t(x)α_t(x) + (1 - E_{u~p_t}[α_t(u)]) R_t(x)`。
- **推论 1（标准 SD 无损性）**：当 `α_t = min{1, q_t/p_t}` 且 `R_t` 为正残差分布时，`q̃_t = q_t`，即标准验证器是零偏差基线。
- **定理 2（分布偏差分解）**：  
  `TV(q̃_t, q_t) ≤ E_{x~p_t}[|δ_t(x)|] + (1 - E[α_t]) TV(R_t, R_t^sd)`，  
  即偏差来自“接受不匹配”与“恢复不匹配”两部分。
- **定理 3（任务指标漂移界）**：  
  任务指标差距上界为 `Σ_t TV_t · osc(μ_t)`，说明性能退化取决于每步分布偏差与任务对 token 位置的敏感度 `I_t`。
- **命题 1（SecureSD 的缓解作用）**：  
  混合验证器满足 `TV(q̃_t^η, q_t) ≤ η_t TV(q̃_t, q_t) + ε_t`，其中 `ε_t` 在多数情况下为 0 或可忽略（平均仅 0.52%），因此偏差近似随 `η_t` 线性收缩。

### 2.3 SecureSD 算法

- **核心思想**：安全退化主要来自草稿模型早期 token 的偏差，因此对早期位置施加更严格的“标准验证器”校正，后期保持松弛验证以维持效率。
- **关键公式**：
  - 混合接受函数：`α_t^η = (1 - η_t) α_t^sd + η_t α_t`；
  - 混合恢复分布：`R_t^η = (1 - η_t) R_t^sd + η_t R_t`；
  - 额外 token 分布：`R_{k+1}^η = (1 - η_{t+k+1}) q_{k+1} + η_{t+k+1} R_{k+1}`。
- **校正调度 `{η_j}`**：
  - **Step 调度**：前 L 个位置 `η=0`（完全使用标准验证），之后 `η=1`（完全松弛）；
  - **Linear 调度**：`η` 随位置线性增加；
  - **Power-law 调度**：在线性基础上加曲率参数 `γ`。
- **默认配置**：Step 调度，`L=1`；Llama3 模型族建议 `L=4`；经验上 `L ≤ 8`。
- **算法流程**：草稿生成 k 个 token → 目标模型并行前向 → 对每个位置按混合接受函数接受/拒绝 → 拒绝则从混合恢复分布采样并停止 → 全部接受则额外采样一个 token。

## 6. 主要结论与发现

- **安全—效用不对称性**：
  - 有损推测解码在效用基准上 PRR 较高（Qwen3 平均 0.905，Llama3 平均 0.866），但在安全基准上 PRR 显著更低（Qwen3 平均 0.744，Llama3 平均 0.719）；
  - 安全性能下降并未换来更高 SPD，安全基准上的平均 SPD 反而低于效用基准；
  - 安全 PRR 在更低 AR（约 0.3）就开始下降，而效用 PRR 通常在 AR 约 0.7 后才明显下降。
- **早期 token 是关键**：
  - 分布偏差 `TV(q̃_t, q_t)` 集中在生成早期位置，随解码推进迅速衰减；
  - 安全任务的位置敏感度 `I_t` 集中在早期，效用任务（数学、代码）则较均匀分布；
  - 因此早期位置偏差对安全性的影响远大于对效用的影响。
- **SecureSD 的有效性**：
  - Qwen3-0.6B/8B 上平均 ΔPRR：Jailbreak +0.270，Prompt Injection +0.114；
  - Llama3-1B/8B 上平均 ΔPRR：Jailbreak +0.042（L=1），增大 L 后可达 +0.321（L=4）；
  - 效用几乎不受影响（HumanEval 平均 -0.008，GSM8K 平均 +0.046）；
  - ΔSPD 大多在 ±0.02 以内，效率开销可忽略；
  - 在 AgentDojo 上平均 PRR 从 0.696 提升到 0.808，SPD 基本不变。
- **自适应攻击下仍有防御效果**：
  - 针对“延迟恶意生成超出校正窗口”的自适应注入攻击，SecureSD 仍将 AFR 提高约 19 个百分点、PRR 提高 55.9–71.8 个百分点；
  - 早期校正形成的目标对齐前缀会降低后续草稿 token 的接受率，从而在窗口外也间接提升安全性。
- **总体结论**：推理优化可能“静默”削弱模型安全性，安全评估应纳入效率与效用的评估体系；SecureSD 提供了一种位置感知、理论可解释的防御方案。

## 7. 优点

- **首次系统研究**：填补了有损推测解码安全影响的研究空白，提出“安全—效用不对称性”这一具有实践意义的观察。
- **理论驱动**：从输出分布、TV 偏差分解到任务指标漂移界，理论链条完整，为“早期校正”提供了可解释依据。
- **方法简洁通用**：SecureSD 以验证器插值形式给出，可无缝集成到任意推测解码流程，不需要重新训练草稿模型或目标模型。
- **位置感知设计**：仅校正早期 L 个位置，避免全序列严格验证带来的效率损失，实现安全、效用、效率的良好折中。
- **实验全面**：覆盖多种模型族、模型规模、六种有损验证器、多种调度、温度、推测长度、长上下文 Agent 场景与自适应攻击。
- **工程可行性**：在 vLLM 上实现轻量层，运行时开销低于 0.001%，部分方法甚至因减少恢复 softmax 而略有加速。
- **伦理与可复现性**：使用公开基准与开源模型，不发布有害生成内容，代码与 Jailbreak-SD 基准公开。

## 8. 不足与局限

- **安全保证有限**：SecureSD 只缓解“有损推测解码额外引入”的安全退化，以目标模型标准解码为参考；不消除目标模型自身已有的漏洞，也不提供通用对抗鲁棒性。
- **自适应攻击评估较单一**：仅测试一种“前缀延迟”式自适应攻击，未覆盖更复杂的多轮、工具调用、编码混淆等攻击策略。
- **校正窗口固定**：Step 调度默认 `L=1`，Llama3 需 `L=4`；如何自动选择 L 仍需校准数据集或经验规则，缺乏理论最优性保证。
- **位置敏感度估计为近似**：`I_t` 通过 Monte Carlo 采样估计，精确计算不可行，可能引入估计误差。
- **实验范围限制**：
  - 主要针对 Qwen3 与 Llama3 系列，未覆盖其他架构或闭源模型；
  - 安全基准以英文为主，跨语言安全性未验证；
  - 默认贪心解码，温度消融虽覆盖但未深入分析采样随机性对安全的影响。
- **效率与安全的权衡**：增大 L 会带来一定 SPD 损失（如 L=8 时 Qwen3 ΔSPD 降至 -0.047），实际部署需根据安全需求调整。
