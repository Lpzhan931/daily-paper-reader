## 摘要
大型语言模型中的全自注意力机制的计算复杂度为O(N^2)，这限制了长上下文文档分析到65,536个token，并且需要昂贵的GPU集群。减少交互采样（RIS）推理引擎作为一种模型无关的架构解决了这一限制。在不修改权重的情况下，RIS利用稀疏随机几何将自注意力复杂度降低到O(N log N)，使其能够适配普通内存限制。我们在Qwen2-1.5B-Instruct上对RIS进行了两个场景的验证。在32,768个token的受控评估中（原生密集注意力作为上限），RIS-Stochastic在1%密度和70个集成种子下达到75.00%的准确率，优于原生密集基线（71.88%），而RIS-Stochastic在5%密度和10个种子下与其持平（71.88%）。这表明稀疏注意力起到了正则化作用：低密度（1%）下多个种子过滤了序列级噪声，而高密度（5%）则重新引入了干扰噪声。在最严格的预算下，RIS-Structural在1%密度和仅10个种子下达到68.75%的准确率，恢复了相对于零上下文基线（59.38%）75%的上下文差距。在65,536个token时，密集注意力触发内存不足错误，RIS的检索增益相对于零上下文基线（51.56%）提高了多达14.06个百分点，McNemar配对检验确认其边际显著（p = 0.078 < 0.10）。所有评估均在普通、非加速的CPU服务器（16-128 GB RAM）上运行，表明长上下文LLM推理可以在无GPU加速的标准学术硬件上实现。

## Abstract
Full self-attention in large language models scales as O(N^2), which limits long-context document analysis to 65,536 tokens and requires costly GPU clusters. The Reduced Interaction Sampling (RIS) inference engine addresses this constraint as a model-agnostic architecture. Without modifying weights, RIS reduces self-attention complexity to O(N log N) using sparse stochastic geometry that fits within commodity memory limits. We validate RIS on Qwen2-1.5B-Instruct across two regimes. In controlled evaluations at 32,768 tokens (where native dense attention serves as the upper bound), RIS-Stochastic at 1% density and 70 ensemble seeds achieves 75.00% accuracy, outperforming the native dense baseline (71.88%), while RIS-Stochastic at 5% density and 10 seeds matches it (71.88%). This demonstrates that sparse attention acts as a regularizer: low density (1%) over multiple seeds filters out sequence-level noise, whereas higher density (5%) reintroduces distractor noise. Under the tightest budget, RIS-Structural reaches 68.75% accuracy at 1% density with just 10 seeds, recovering 75% of the contextual gap relative to the zero-context floor (59.38%). At 65,536 tokens, where dense attention triggers out-of-memory faults, RIS yields retrieval gains of up to 14.06 percentage points over the zero-context floor (51.56%), which is confirmed as marginally significant under McNemar's paired test (p = 0.078 < 0.10). All evaluations run on commodity, unaccelerated CPU servers (16-128 GB of RAM), demonstrating that long-context LLM inference is feasible on standard academic hardware without GPU acceleration.

## 1. 核心问题与整体含义（研究动机和背景）

- **核心问题**：大语言模型中的全自注意力机制计算复杂度为 \(O(N^2)\)，导致长上下文推理（如65k tokens以上）需要昂贵的大规模 GPU 集群，普通学术机构难以负担。
- **研究动机**：提出一种模型无关的推理架构，在不修改预训练权重、不进行微调的前提下，将自注意力复杂度降低至 \(O(N \log N)\)，使得长上下文 LLM 推理能够在无 GPU 的普通 CPU 服务器上运行。
- **整体含义**：降低长上下文 LLM 推断的硬件门槛，使更广泛的研究社区能够处理大规模文档检索、跨文档综合等任务，而无需依赖 GPU 集群。

## 2. 方法论

### 核心思想
- **模型无关性**：通过运行时注入稀疏注意力掩码，不修改任何模型权重，可直接应用于 LLaMA、Qwen2 等架构。
- **稀疏随机几何**：利用随机采样构造稀疏注意力连接，将复杂度从 \(O(N^2)\) 降至 \(O(N \log N)\)。
- **集成策略**：多个独立的稀疏种子（seeds）生成不同视图，通过投票机制弥补单个视图的遗漏，覆盖率达到 \(U = 1 - (1 - d)^N\)（d 为注意力密度，N 为种子数）。

### 关键技术细节
- **两种采样模式**：
  - **Stochastic Mode（随机模式）**：对全序列均匀采样全局邻居，覆盖范围随密度与种子数线性增长。
  - **Structural Mode（结构模式）**：将序列划分为块（blocks），每块内形成全连接小团（clique），再添加部分全局冗余边。在极端稀疏（1%）下优先保证局部领域完整性。
- **流式掩码生成**：逐种子生成掩码，完成后立即丢弃，峰值内存仅由单个布尔矩阵决定，避免 \(O(N^2)\) 空间爆炸。
- **Prefusion Unified Softmax (PFUS)**：将稀疏索引的键值对与局部窗口合并后送入统一 softmax，避免分段归一化导致的信号稀释。
- **动态 RoPE 缩放**：在加载模型时自动调整位置编码因子，支持线性插值和 YaRN 两种方式，无需修改模型图。

### 算法流程简要说明
1. 计算上下文长度与模型原生位置限制的比值，确定 RoPE 缩放因子。
2. 根据选择模式（Stochastic/Structural）生成稀疏索引掩码。
3. 首 token 时计算所有种子索引的并集并缓存（随机锚点）；后续 token 仅更新局部动态窗口。
4. 合并随机锚点与局部窗口索引，提取对应 KV cache，执行缩放点积注意力与统一 softmax。
5. 输出 logits 用于判别式问答（直接比较各选项 log 概率）。

## 3. 实验设计

### 数据集/场景
- **上下文构建**：拼接四篇不同生物领域的科学论文（基因组表征、海洋甲烷氧化、蛋白质相互作用预测、蜜蜂微生物组），去除元数据、标题、摘要等。
- **窗口大小**：32,768 tokens（Qwen2 原生限制）和 65,536 tokens（2× 外推）。
- **评估任务**：多项选择问答（每道题5个选项），通过判别式 logit 分析确定答案，不生成自由文本。

### Benchmark
- **32k 窗口**：32 道题，选项均匀分布。基线：零上下文（w=0 floor）59.38%，全密集注意力（native dense）71.88%。
- **64k 窗口**：64 道题，零上下文基线 51.56%（无法运行密集注意力，因 OOM）。

### 对比方法
- **基线**：
  - Zero-context baseline（无上下文）。
  - Full dense attention（仅在 32k 下可行）。
  - 两种 RoPE 缩放方式：线性插值 vs. YaRN。
- **方法内对比**：
  - RIS-Stochastic vs. RIS-Structural 两种模式。
  - 不同注意力密度（1%、2%、5%）和集成种子数（1~100）。
  - 子 1% 密度搜索（0.1%~0.9%）及种子 50~200。
- **模型对比**：Qwen2-1.5B-Instruct 为主，TinyLlama-1.1B 用于测试位置编码外推极限。

## 5. 实验数量与充分性

- **实验数量**：覆盖 32k 和 64k 两种窗口，密度 1%/2%/5%，种子 1~100（共计 11×3=33 个配置点，每个点含 Stochastic 和 Structural 两个模式）。额外子 1% 密度搜索（0.1%~0.9%×4 种子水平，共 36 个配置）。交叉文档合成验证 6 对文本，2 个相位。TinyLlama 在 4 种窗口下的对比。

## 6. 主要结论与发现

1. **受控场景（32k）**：RIS-Stochastic 在 1% 密度、70 种子时达到 75.00% 准确率，**超过**全密集基线（71.88%），验证了稀疏注意力的正则化效应（过滤序列噪声）。RIS-Stochastic 在 5% 密度、10 种子时与密集基线持平。
2. **极端稀疏场景**：RIS-Structural 在 1% 密度、仅 10 种子下恢复 75% 的上下文差距（68.75%），表明块团结构在预算紧张时更有效。
3. **外推场景（64k）**：全密集注意力因 OOM 不可行。RIS 搭配 YaRN 缩放达到 62.50% 峰值（Structural 1% 100 种子），相对于零上下文基线提升 14.06 个百分点（McNemar p=0.078 边际显著）。
4. **RoPE 缩放关键**：线性插值在 64k 下导致位置混乱（准确率低至 15.6%），而 YaRN 保留位置几何，集成才能有效恢复检索。
5. **模型规模边界**：TinyLlama 因原生位置限制仅 2k，在 4× 以上外推时完全失效，说明 RIS 依赖宿主模型的位置编码功能。
6. **硬件可行性**：所有结果在普通 CPU 服务器上获得，证明长上下文 LLM 推理无需 GPU 即可实现。

## 7. 优点

- **模型无关性**：不修改任何权重，无需微调，即插即用，通用性强。
- **效率提升**：将注意力复杂度从 \(O(N^2)\) 降至 \(O(N \log N)\)，在 CPU 上即可处理 65k 上下文。
- **内存友好**：流式掩码生成避免 \(O(N^2)\) 空间开销，首次处理 token 后仅维护局部窗口。
- **集成策略鲁棒**：通过概率覆盖公式 \(U = 1 - (1 - d)^N\) 保证稀疏视图的综合性，避免固定模式遗漏关键词。
- **双模式互补**：Stochastic 适合全局覆盖，Structural 适合极低预算下局部保真，用户可根据资源选择。
- **全面消融**：对密度、种子数、RoPE 缩放、模式、模型规模均进行了系统探索，结论有依据。
- **开源可复现**：提供代码、数据、基准脚本，附 Zenodo 和 Code Ocean 存档。
- **低硬件要求**：在 16 GB RAM 的普通 PC 上即可运行 32k 实验，有利于学术复制。
