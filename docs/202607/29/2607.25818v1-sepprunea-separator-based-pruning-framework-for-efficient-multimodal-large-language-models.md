## 摘要
近年来的多模态大语言模型（如Qwen2.5-VL和InternVL3）为高分辨率输入生成大量视觉标记，导致计算成本显著增加。现有的视觉标记剪枝方法要么依赖于跨模态注意力，无法在预填充阶段之前进行剪枝，要么依赖于高计算开销的多样性估计。我们观察到视觉和文本标记的注意力分数在模态分隔符标记处达到峰值，这表明这些分隔符桥接了两种模态。基于这一观察，我们提出了SepPrune，一种高效、无需训练、即插即用的剪枝方法，该方法使用分隔符标记作为统一查询来排序和选择信息丰富的视觉标记。SepPrune重用LLM内置的投影参数，无需修改架构。在Qwen2.5-VL-7B上的实验表明，SepPrune实现了最先进的性能，在移除80.2%的视觉标记的同时保留了96.3%的原始准确率。

## Abstract
Recent multimodal large language models (MLLMs), such as Qwen2.5-VL and InternVL3, generate large numbers of vision tokens for high-resolution inputs, leading to substantial computational cost. Existing vision token pruning methods either depend on cross-modal attention and cannot prune before the prefill stage, or rely on diversity estimation with high computational overhead. We observe that attention scores from both vision and text tokens peak at modality separator tokens, suggesting that these separators bridge the two modalities. Based on this observation, we propose SepPrune, an efficient, training-free, plug-and-play pruning method that uses the separator token as a unified query to rank and select informative vision tokens. SepPrune reuses the LLM's built-in projection parameters and requires no architectural changes. Experiments on Qwen2.5-VL-7B show that SepPrune achieves state-of-the-art performance, retaining 96.3% of the original accuracy while removing 80.2% of vision tokens.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **核心问题**：多模态大语言模型（MLLMs）在处理高分辨率视觉输入（如4K/8K图像、高像素照片）时，视觉编码器会生成大量视觉令牌（token），导致推理阶段计算开销巨大、延迟显著增加，阻碍了模型的广泛应用。
- **现有方法不足**：现有视觉令牌剪枝方法主要分为两类：
  - **注意力驱动方法**（如FastV、FitPrune）：依赖文本-视觉跨模态注意力，但会中断计算流程（无法与FlashAttention等高效算子兼容），且不能在预填充阶段之前进行剪枝。
  - **多样性驱动方法**（如DivPrune、CDPruner）：通过计算令牌间相似度矩阵（复杂度O(N²)）来消除冗余，虽无需训练，但二次复杂度反而增加延迟。
- **关键观察**：作者通过分析Qwen2.5-VL-7B的注意力分布，发现模型浅层中，视觉和文本令牌的注意力分数在**模态分隔符令牌（separator token）**处出现峰值，且删除分隔符比删除同等数量的视觉或文本令牌造成更大的性能下降，表明分隔符不仅是边界标记，更是跨模态交互的桥梁。
- **总体含义**：基于这一洞察，作者提出一种高效、训练免费、即插即用的视觉令牌剪枝方法——SepPrune，利用分隔符作为统一的查询来评估和选择最有信息的视觉令牌，在显著减少视觉令牌数量的同时保持模型性能。

## 2. 论文提出的方法论：核心思想、关键技术细节

### 核心思想
- 利用**模态分隔符令牌**（位于视觉令牌序列之后的那个分隔符）作为全局查询，与所有视觉令牌的键向量计算注意力分数，据此选出最重要的视觉令牌进行保留，其余删除。
- 剪枝在LLM处理之前完成，无需修改模型架构，与FlashAttention等加速算子兼容。

### 关键技术细节
- **输入序列结构**：系统提示 → 左侧分隔符 → 视觉令牌 → 右侧分隔符 → 用户文本。由于因果注意力掩码，只有**右侧分隔符**能访问完整图像信息，因此被选为统一查询。
- **剪枝评分计算**：
  1. 从LLM第一层的参数中获取查询投影矩阵（q_proj）和键投影矩阵（k_proj）。
  2. 使用右侧分隔符的隐藏状态经过q_proj得到查询向量 \( Q_{sep} \)。
  3. 将每个视觉令牌的隐藏状态经过k_proj得到键向量矩阵 \( K_{visual} \)。
  4. **去除位置编码（RoPE）**：避免位置偏差干扰对令牌内容重要性的评估。
  5. 计算注意力分数：\( \text{Score}_{prune} = \text{softmax}\left( \frac{Q_{sep} K_{visual}^T}{\sqrt{d_k}} \right) \)，得到一个1×N的分数向量。
- **剪枝过程**：
  - 根据分数保留前k%的视觉令牌（保留其原始位置索引）。
  - 不保留的令牌被直接移除，后续LLM只处理缩减后的序列。
- **复杂度**：从O(N²)降低到O(N·D²)（其中D为隐藏维度），线性于视觉令牌数量N。
