## 摘要
近期多模态大语言模型（MLLMs），如Qwen2.5-VL和InternVL3，为高分辨率输入生成大量视觉标记，导致巨大的计算开销。现有的视觉标记剪枝方法要么依赖跨模态注意力，无法在预填充阶段之前进行剪枝，要么依赖高计算开销的多样性估计。我们观察到，来自视觉和文本标记的注意力分数在模态分隔符标记处达到峰值，这表明这些分隔符桥接了两种模态。基于这一观察，我们提出了SepPrune，一种高效、无需训练、即插即用的剪枝方法，使用分隔符标记作为统一查询来对信息丰富的视觉标记进行排序和选择。SepPrune重用LLM内置的投影参数，无需修改架构。在Qwen2.5-VL-7B上的实验表明，SepPrune实现了最先进的性能，在移除80.2%的视觉标记的同时保留了96.3%的原始准确率。

## Abstract
Recent multimodal large language models (MLLMs), such as Qwen2.5-VL and InternVL3, generate large numbers of vision tokens for high-resolution inputs, leading to substantial computational cost. Existing vision token pruning methods either depend on cross-modal attention and cannot prune before the prefill stage, or rely on diversity estimation with high computational overhead. We observe that attention scores from both vision and text tokens peak at modality separator tokens, suggesting that these separators bridge the two modalities. Based on this observation, we propose SepPrune, an efficient, training-free, plug-and-play pruning method that uses the separator token as a unified query to rank and select informative vision tokens. SepPrune reuses the LLM's built-in projection parameters and requires no architectural changes. Experiments on Qwen2.5-VL-7B show that SepPrune achieves state-of-the-art performance, retaining 96.3% of the original accuracy while removing 80.2% of vision tokens.

### 1. 论文的核心问题与整体含义（研究动机和背景）

- **问题背景**：近年来的多模态大语言模型（MLLMs，如 Qwen2.5-VL、InternVL3）采用了"任意分辨率"（any-res）视觉编码器结构，处理 4K/8K 高清图像或视频时会产生海量视觉 token（远超文本 token 数量），导致推理阶段计算开销巨大、延迟显著增加，制约了实际应用部署。
- **现有方法的不足**：
  - **基于注意力（attention-based）的方法**（如 FastV、FitPrune、SparseVLM）：依赖文本-视觉跨模态注意力，需要在 LLM 内部中断计算流提取分数，无法与 FlashAttention 等高效算子兼容，也**无法在 prefill 阶段之前预先剪枝**；部分方法依赖 [CLS] token，在现代视觉骨干中往往不存在，通用性受限。
  - **基于多样性（diversity-based）的方法**（如 DivPrune、CDPruner、FiCoCo-V）：通过 token 间相似度矩阵识别冗余，时间复杂度为 O(N²)，剪枝带来的收益常被额外计算开销抵消，端到端延迟改善有限。
- **核心观察（启发点）**：论文对 Qwen2.5-VL-7B 处理多图输入时的注意力分布进行可视化，发现在 LLM 浅层中，视觉和文本 token 的注意力分数在**模态分隔符（modality separator token）**处出现显著峰值，且随网络加深逐渐减弱。消融实验进一步表明：移除分隔符对性能的损害大于移除同等数量的视觉 token 或文本 token。这说明分隔符不仅是边界标记，更是**跨模态桥接（cross-modal bridge）**，负责早期模态间的对齐与融合。
- **研究意义**：提出一种高效、无需训练、即插即用的视觉 token 剪枝方案，在显著降低推理成本的同时保持模型性能，为高分辨率多模态输入的落地应用提供了一种新思路。

### 2. 论文提出的方法论

#### 核心思想
利用模态分隔符作为"统一查询"（unified query），对所有视觉 token 进行全局重要性评估，保留 top-k 信息量最高的视觉 token，从而实现剪枝。全部计算发生在 LLM 骨干网络之前，不改变模型架构。

#### 关键技术细节
- **输入序列结构**：
  X_input = [T_sys, S_left, V, S_right, T_usr]
  其中 T_sys 为系统提示 token，S_left/S_right 为视觉 token 前后的模态分隔符，V 为视觉 token 序列，T_usr 为用户文本 token。
- **两项关键简化**：
  1. **分隔符作为统一查询（Separator as Unified Query）**：受因果注意力掩码限制，只有视觉 token 之后的右侧分隔符 S_right 能访问完整图像信息，因此选用它作为查询向量 Q_sep，仅与所有视觉 token 的键向量 K_visual 交互。其注意力分数可视为对每个视觉 token 重要性的全局评估，复杂度从 O(N²) 降至 O(N)。
  2. **去除位置编码（Removing Positional Encoding）**：计算剪枝分数时故意省略 RoPE。原因是 RoPE 会引入"位置偏差"，使查询向量倾向给相邻视觉 token 更高分数，导致剪枝策略偏好保留图像底部 token、误剪上部 token。去除位置编码后可实现纯内容驱动、位置无关的重要性评估。
- **核心公式**：
  Score_prune = softmax(Q_sep · K_visual^T / √d_k)
  其中 Score_prune 为 1×N 的注意力分数向量，Q_sep 为分隔符的查询向量，K_visual 为所有视觉 token 的键矩阵。
- **算法流程**：
  1. 视觉编码器生成视觉 token 后立即应用 SepPrune；
  2. 复用 LLM 第一层的 q_proj / k_proj 投影参数，计算分隔符与各视觉 token 的注意力分数（不经过 RoPE）；
  3. 按分数排序，依据预定剪枝比例保留 top-k 视觉 token（保留其原始位置索引）；
  4. 剪枝后的短序列（含分隔符和文本 token）送入 LLM 继续处理。
- **兼容性优势**：因计算全部在 LLM 之前完成，天然兼容 FlashAttention 等加速算子，无需复杂的 KV-cache 管理，也无需训练或修改架构（直接复用 LLM 内置参数作为投影矩阵）。

### 6. 论文的主要结论与发现

- **核心发现**：模态分隔符 token 在多模态融合中扮演关键"桥梁"角色——浅层注意力峰值显著、文本/视觉 token 的交互在此汇聚；移除分隔符对性能的损害最大，证明其不可替代性。
- **方法有效性**：
  - Qwen2.5-VL-7B 上：剪枝 60.5% 保持 99.0% 性能；剪枝 80.2% 仍保持 96.3% 性能，显著优于 CDPruner（93.6%）、FastV（93.2%）、DivPrune（91.2%）；极端剪枝 90.1% 时仍有 87.2%，在 TextVQA、ChartQA 等信息密集型任务上鲁棒性突出；
  - InternVL3-8B 上：80% 剪枝时保持 93.1%，优于所有基线，验证了跨架构适应性；
  - 视频任务上：VideoMME 的 0.6/0.8 比例下均取得最佳效果，说明能有效保留时空关键信息。
- **效率结论**：时间复杂度从基线的 O(N²·D) 降至 O(N·D²)，线性复杂度使其在高分辨率输入下具有更好的可扩展性，端到端延迟最低。
