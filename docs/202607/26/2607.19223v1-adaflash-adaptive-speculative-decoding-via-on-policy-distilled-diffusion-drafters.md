## 摘要
推测解码是一种轻量级草稿模型首先生成草稿序列，然后由目标模型并行验证的范式，已成为加速大语言模型推理的流行方法。近期如DFlash等工作通过利用扩散草稿模型进一步提升了草稿生成效率，其并行去噪机制使得草稿生成仅需一次前向传播。本文揭示了扩散草稿模型的一个核心陷阱：双向注意力是一把双刃剑。一方面，它赋予模型并行生成和全局上下文建模能力；另一方面，这种固有的全局依赖性在领域级别和token级别引入了高方差：不同领域的接受率波动显著，且不同token位置的草稿质量也呈现异质性。为解决此问题，我们提出了AdaFlash框架，包含两个组件：(i) 针对扩散草稿模型定制的反向KL散度策略内蒸馏算法，带来稳定收敛并有效降低领域级方差；(ii) 自适应长度头，可动态调整候选序列长度，大幅降低目标模型的验证成本并处理token级方差。实验表明，AdaFlash在部署期间持续提升加速比，在高并发场景下增益尤为显著，比先前最先进方法吞吐量提升高达约66%。

## Abstract
Speculative decoding, in which a lightweight draft model first generates a draft sequence that is then verified in parallel by the target model, has become a prevalent paradigm for accelerating large language model inference. Recent work such as DFlash further boosts drafting efficiency by leveraging diffusion drafters, whose parallel denoising mechanism enables draft generation in a single forward pass. In this work, we uncover a central pitfall of diffusion drafters: bidirectional attention is a double-edged sword. On one hand, it endows the model with parallel generation and global contextual modeling capabilities; on the other hand, this inherent global dependency introduces high variance at both the domain-level and the token-level: acceptance rates fluctuate substantially across different domains, and draft token quality also varies heterogeneously at different token positions. To tackle this issue, we propose AdaFlash framework, comprising two components: (i) an on-policy distillation (OPD) algorithm with reverse-KL divergence tailored for diffusion drafters, bringing stable convergence and effectively reducing domain-level variance; and (ii) an adaptive length head that dynamically adjusts the candidate sequence length on the fly, substantially lowering the verification cost of the target model and handling token-level variance. Experiments demonstrate that AdaFlash consistently improves speedup rate during deployment, with especially significant gains in high-concurrency scenarios, achieving up to approximately 66% higher throughput than previous state-of-the-art methods.

### 1. 论文的核心问题与整体含义（研究动机和背景）
- **研究背景**：大语言模型（LLM）推理成本日益高昂，推测解码（Speculative Decoding）通过轻量草稿模型快速生成候选序列，再由目标模型并行验证，已成为主流加速范式。近期 DFash 等利用扩散语言模型（dLLM）作为草稿器，通过双向注意力实现单次前向传播生成所有草稿 token，大幅降低每 token 开销。
- **核心问题**：扩散草稿器的双向注意力是一把双刃剑——它在带来并行生成和全局建模能力的同时，引入了 **高方差** 问题，表现为两个层面：
  - **领域级方差**：不同任务域（对话、代码、数学）的接受率波动很大（如 DFash 在 ShareGPT 上平均接受长度 3.40，在 MathQA 上 7.09，差异约 2.1 倍）；
  - **Token 级方差**：同一个候选序列内不同位置的接受概率差异显著，末尾 token 接受概率远低于开头。
- 这种高方差导致静态系统（固定草稿器 + 固定候选长度）在部署时效率下降：领域偏移使接受率降低，固定长度浪费目标模型的计算资源。

### 2. 论文提出的方法论：核心思想、关键技术细节
- **整体框架 AdaFlash**：由两个互补组件构成，分别针对上述两种方差。
- **组件一：在线策略蒸馏（On-Policy Distillation, OPD）**  
  - **核心思想**：利用推测解码过程中天然获得的在线反馈（目标模型输出分布）持续更新草稿器，避免离线训练与部署分布的失配，从而减小领域级方差。
  - **关键技术与公式**：
    - **混合损失函数**：结合硬标签交叉熵（ℓ_hard）和**反向 KL 散度**（ℓ_rkl），以系数 α 加权。  
      反向 KL 鼓励草稿器集中到目标的高概率模式，避免正向 KL 的“模式覆盖”问题。  
      ℓ_OPD = α ℓ_hard + (1-α) ℓ_clip_rkl，其中 ℓ_hard = -1/k Σ log qw(教师 top-1 token)，ℓ_rkl = 1/k Σ KL(qw || pv)。
    - **逐项散度裁剪（Entry-wise Divergence Clipping）**：对每个 (位置 i, 词 y) 的 KL 项取 min(原值, δ) 后再求和，防止少数高发散项主导梯度，稳定训练（δ=0.01 效果最好）。
- **组件二：自适应长度头（Adaptive Length Head）**  
  - **核心思想**：预测当前候选序列的整体接受率，并动态截断长度，避免对低质量尾部 token 的无效验证，处理 token 级方差。
  - **技术细节**：
    - 在扩散草稿器输出特征上附加轻量头（线性 + SiLU + 均值池化 + 线性 + Sigmoid），输出标量 â_t ∈ [0,1]。
    - 当前验证长度 ķ_t = clamp(⌊γ·â_t·k⌋, 1, k)，γ 为缩放因子（实验中 γ=1 最优）。
    - 长度头通过目标模型验证后得到的真实接受率 a*_t 的 MSE 损失单独更新（梯度不与草稿器耦合）。
- **基础设施设计**：
  - **异步训练-推理流水线**：推理服务器采集轨迹存入缓冲区，训练服务器异步更新草稿器和长度头，参数热重载不影响推理。
  - **自适应请求调度**：利用指数移动平均动态估计可处理请求数，打包变长验证批次，防止内存溢出并最大化 GPU 利用率。
