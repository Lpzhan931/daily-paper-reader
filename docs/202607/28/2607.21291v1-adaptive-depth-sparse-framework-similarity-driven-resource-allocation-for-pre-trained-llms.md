## 摘要
大语言模型（LLMs）在生成和推理任务上表现出色，但Transformer架构带来了高昂的推理成本。现有加速方法通常依赖于任务特定的微调或从头训练，增加了适配成本并限制了跨任务可用性。我们提出自适应深度稀疏框架（AdaDSF），该框架无需完全重新训练即可将现成的预训练LLMs转换为深度稀疏模型。我们的关键洞察是各层对表示变换的贡献不均，这可以通过层输入与输出隐藏状态之间的余弦相似度来表征。基于此，AdaDSF根据相似度统计为每一层分配token保留比例，使用轻量级路由器在各层选择信息量大的token，并引入特征保留对齐目标，以匹配稀疏模型与稠密模型之间的中间和最终表示。在GPT-NeoX和Qwen2.5上进行的语言建模和常识推理任务中，AdaDSF在保持接近稠密模型性能的同时大幅降低了推理FLOPs。在可比稀疏度下，AdaDSF相较于MoD、D-LLM和DLO等强基线模型始终表现出更小的精度损失。

## Abstract
Large language models (LLMs) achieve strong generation and reasoning performance, but the Transformer architecture incurs high inference cost. Existing acceleration methods often rely on task-specific fine-tuning or training from scratch, increasing adaptation cost and limiting cross-task usability. We present an Adaptive Depth Sparse Framework (AdaDSF) that converts off-the-shelf pre-trained LLMs into depth-sparse models without full retraining. Our key insight is that layers contribute unequally to representation transformation, characterized by the cosine similarity between layer input and output hidden states. Based on this, AdaDSF assigns layer-wise token retention ratios from similarity statistics, uses a lightweight router to select informative tokens at each layer, and introduces a feature-preserving alignment objective to match intermediate and final representations between sparse and dense models. On GPT-NeoX and Qwen2.5 over language modeling and commonsense reasoning, AdaDSF substantially reduces inference FLOPs while preserving performance close to dense counterparts. Under comparable sparsity, AdaDSF consistently yields smaller accuracy degradation than strong baselines including MoD, D-LLM, and DLO.

## 1. 核心问题与整体含义（研究动机和背景）

- **问题**：大语言模型（LLM）的 Transformer 架构在推理时计算成本高，且现有加速方法（如量化、蒸馏、轻量注意力）往往需要任务特定的微调或从头训练，限制了跨任务适用性，增加了部署成本。
- **目标**：在不完全重新训练、不修改模型内部架构的前提下，将现成的预训练稠密 LLM 转换为深度稀疏模型，显著降低推理 FLOPs 的同时保持性能接近稠密版本。
- **核心思想**：不同 Transformer 层对表示变换的贡献不均。通过层输入与输出隐藏状态的余弦相似度量化每层的「变换量」，从而为各层分配不同的 token 保留比率，使计算资源集中在信息量大的层和 token 上。

## 2. 方法论：核心思想、关键技术细节、算法流程

### 核心思想
- **相似度驱动的深度分配**：利用预训练稠密模型的校准数据，计算每层输入与输出隐藏状态的余弦相似度 $s_i$，相似度越低（表示变换越大）的层应保留更多 token。
- **轻量级路由器**：在每个稀疏模块中，用一个 MLP 路由器预测 token 重要性分数，按分配的保留比率选取 Top-K 个 token，其余 token 通过残差路径跳过 Transformer 层。
- **特征保留对齐训练**：引入中间隐藏状态对齐损失和最终输出分布对齐（KL 散度）损失，使稀疏模型的表示与稠密教师模型一致，减少因 token 跳过带来的表示偏移。

### 关键技术细节
1. **相似度统计与每层保留比率生成**（4步公式）：
   - 对第 i 层：$s_i = \text{CosSim}(x_{in}^{(i)}, x_{out}^{(i)})$
   - 温度归一化：$\tilde{w}_i = \exp((s_i - \max(s))/\tau)$，$w_i = \tilde{w}_i / \sum \tilde{w}_j$
   - 偏差缩放：$z_i = \beta(\frac{1}{L}\sum w_j - w_i)$，$\beta=10$
   - Sigmoid 映射到 $[0.05, 0.95]$，再全局预算校正使平均比率为 $t$
2. **稀疏模块**：每层包含一个轻量 MLP 路由器和一个冻结的预训练 Transformer 层。路由器输出重要性分数，选择 Top-$K_i$ tokens，$K_i = \lfloor r_i \cdot s \rfloor$，未选中的 token 跳过 FFN 和注意力。
3. **对齐损失**：
   - 隐藏状态对齐：$\mathcal{L}_{hid}^{(l)} = \|\text{Softmax}(h_{sparse}^{(l)}) - \text{Softmax}(h_{dense}^{(l)})\|^2$
   - 输出分布对齐：$\mathcal{L}_{align} = \sum_{c} P_{dense}(c|x) \log\frac{P_{dense}(c|x)}{P_{sparse}(c|x)}$
   - 总损失：$\mathcal{L} = \mathcal{L}_{align} + \frac{1}{L}\sum_{l=1}^{L}\mathcal{L}_{hid}^{(l)}$
4. **训练方式**：路由器可训练，Transformer 层参数冻结；使用稠密模型作为教师，稀疏模型为 student，进行对齐训练。
