## 摘要
我们提出了MoNe，一种轻量级模块化神经记忆，可附加到任何冻结的预训练Transformer上，无需重新训练即可实现长上下文推理。MoNe通过测试时学习具有层局部梯度更新的快速权重神经记忆网络，以固定大小的段读取上下文；在推理时，记忆仅从查询词元生成键和值，无需重新读取上下文词元。这种两阶段设计将推理成本与上下文长度解耦，实现了$O(N)$预处理和$O(1)$查询成本，且峰值GPU内存不随$N$增长。在128K词元下，与ICL相比，MoNe将计算量和峰值GPU内存均降低了约80%，而参数开销仅6.4%。MoNe可泛化到远超骨干网络原生窗口的上下文长度，在RULER的“大海捞针”和词汇提取基准上取得了强劲性能，而ICL在这些情况下性能急剧下降。

## Abstract
We present MoNe, a lightweight modular neural memory that attaches to any frozen pretrained Transformer to enable long-context inference without retraining. MoNe reads context in fixed-size segments via test-time learning of fast-weight neural memory networks with layer-localized gradient updates; at inference, the memory generates keys and values from the query tokens alone, with no context tokens re-read. This two-phase design decouples inference cost from context length, achieving $O(N)$ preprocessing and $O(1)$ query cost with peak GPU memory that does not grow with $N$. At 128K tokens, MoNe reduces both compute and peak GPU memory by approximately 80% compared to ICL with only 6.4% parameter overhead. MoNe generalizes to context lengths far beyond the backbone's native window, achieving strong performance on needle-in-a-haystack and word extraction benchmarks from RULER, where ICL degrades sharply.

  - **循环模型（Mamba、TTT、Titans等）**：实现线性复杂度，但需从零设计并训练全新架构，无法无缝集成现有预训练Transformer。

## 2. 论文提出的方法论

### 2.1 核心思想

两阶段设计，将推理成本与上下文长度解耦：

- **测试时学习（Test-Time Learning）阶段**：将上下文划分为固定大小段（$T=512$），逐段输入模型；在每层的神经记忆模块上执行**层局部（layer-localized）梯度更新**，将上下文信息"印刻"到快速权重中。
- **推理阶段**：仅将查询词元投影后读取最终记忆状态，生成固定大小的记忆token作为键和值参与注意力，**不重新读取任何上下文token**。

### 2.2 关键技术细节

- **记忆模块结构**：每层挂载基于SwiGLU MLP的快速权重记忆，参数为$\{W_{in}, W_{gate}, W_{out}\}$，输入输出均为$\mathbb{R}^{d_h \times d_h}$（每快速权重头）。使用非线性网络而非线性映射，大幅提升记忆的表达容量。
- **记忆注入机制**：查询token经骨干的冻结$W_q$投影后送入记忆模块，输出经RMSNorm归一化和逐头门控缩放，再用冻结的$W_k$、$W_v$投影为KV，与查询自身注意力条目拼接：
  $$\text{out} = \text{Attention}(Q, [K \| W_k h], [V \| W_v h])$$
  记忆KV对每层固定$T$个条目，不随$N$增长。
- **关联记忆损失**：以负内积作为损失，最大化记忆输出与目标值的相似度：
  $$\ell^{(l)}_{s,j}(W^{(l)}) = -v^{(l)\top}_{s,j} M(k^{(l)}_{s,j}; W^{(l)})$$
  通过梯度步更新快速权重：$W^{(l)}_s = W^{(l)}_{s-1} - \mu^{(l)}_s$，其中$\mu$为逐token学习率与数据相关动量衰减的累积梯度。
- **层局部梯度更新**：每层梯度完全由该层自身前向激活计算，不跨层传播：
  $$\frac{\partial \ell^{(l)}_{s,j}}{\partial W^{(l')}_{s-1}} = 0 \quad \forall l' \neq l$$
  这使更新高效且真正模块化——与标准交叉熵需从输出logits反向传播到目标层形成鲜明对比。
- **位置编码方案**：使用段局部RoPE，每个token位置为$p_{\text{local}} = j \bmod T$（始终在$[0, T)$内）；查询长度$Q \ll T$也落在同一范围，因此**无需位置插值即可泛化到任意长上下文**。
- **离线元训练**：LoRA适配器（rank=128）和元参数（学习率、动量投影、输出缩放）在4K以内上下文上通过下游token生成损失离线训练，部署时冻结，快速权重更新作为固定算法运行。

## 7. 优点

- **即插即用性**：无需修改或重新训练骨干网络，仅增加6.4%参数（约每8层12.6M），可挂接任何预训练Transformer，兼容生态良好。
- **计算复杂度突破**：首次将长上下文推理的预处理和查询成本分别做到$O(N)$和$O(1)$，且峰值显存恒定——这对边缘设备部署意义重大。
- **层局部梯度更新的巧妙设计**：记忆更新不跨层传导梯度，既高效又保证模块化，是方法上的核心创新点。
- **跨长度泛化机制优雅**：段局部RoPE使位置索引始终有界，天然支持远超训练长度的外推，无需位置插值等额外技巧。
- **恒定的KV缓存**：无论上下文多长，KV对固定为$T$条目，绕开了长上下文中KV缓存膨胀的根本瓶颈。
- **实用性设计**：支持多查询复用与增量上下文扩展，贴合实际应用（如对话历史持续增长）的需求。

## 8. 不足与局限

- **实验覆盖不足**：
  - 仅验证0.5B小模型，未在更大规模骨干（如7B/70B）上验证可扩展性，结论的普适性存疑。
  - 任务仅限RULER合成检索类基准，缺乏自然长文档QA、真实对话历史、多文档综合等更贴近实际应用的验证。
- **对比范围有限**：未与更先进的长上下文方案（LongLora、上下文压缩方法、TTT系列模型等）对比，削弱了对方法定位的说服力。
- **资源信息披露缺失**：未报告GPU型号、数量、训练时长等硬件信息，不利于他人复现和评估实际部署成本。
- **潜在偏差风险**：RAG基线使用128 token分块+BGE检索，未探索更优分块策略或reranking，可能低估RAG上限；ICL作为对比基线在其窗口限制下性能崩溃是预期行为，需注意公平解读。
- **应用限制**：记忆容量固定（每个token的$d_h$维快速权重），对于需要逐字保留大量细节（如长代码、长数值序列）的任务，压缩可能导致信息丢失；当前实现依赖SwiGLU MLP，单层表达能力存在上限。
- **长上下文保留的长期性**：当上下文极长（如数百万token）时，快速权重是否会发生"记忆覆盖/遗忘"尚无实验验证。
