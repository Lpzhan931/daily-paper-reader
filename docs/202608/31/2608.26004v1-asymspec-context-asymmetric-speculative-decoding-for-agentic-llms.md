## 摘要
智能体LLM流水线在检索、工具使用和多轮交互中上下文不断累积，导致推理成本不断上升。为控制延迟，部署中通常会对输入进行压缩，但这会降低任务准确性。投机解码（SD）可以无损地加速生成，但它假设起草者与验证者共享相同上下文，这使得SD无法解决准确性-开销之间的权衡。我们提出AsymSpec，一种打破这种对称性的非对称投机解码框架：轻量级起草者读取完整输入，而大型验证者基于压缩视图运行。起草者通过对比性δ-融合的logits引导验证者，并由感知分歧的接受门控进行调节，以保持验证稳定性和高草案接受率。在四项智能体能力和两个端到端智能体基准上的评估中，AsymSpec平均达到全上下文准确率的约90%，在独立文本能力上以0.2–0.3倍的计算成本实现了1.3–1.7倍的吞吐量加速。这些结果表明，当压缩丢弃关键推理信号时，非对称上下文访问恰恰能带来实质性收益。

## Abstract
Agentic LLM pipelines face escalating inference costs as context accumulates across retrieval, tool use, and multi-turn interactions. To control latency, deployments routinely compress inputs, but this degrades task accuracy. Speculative decoding (SD) accelerates generation losslessly, yet it assumes the drafter and verifier share an identical context, preventing SD from resolving the accuracy-overhead trade-off. We propose AsymSpec, an asymmetric speculative decoding framework that breaks this symmetry: a lightweight drafter reads the full input while the large verifier operates on the compressed view. The drafter steers the verifier via a contrastive $δ$-fusion of logits, modulated by a divergence-aware acceptance gate that preserves verification stability and high draft acceptance rates. Evaluated across four agentic capabilities and two end-to-end agent benchmarks, AsymSpec reaches $\approx 90\%$ of full-context accuracy on average, delivering $1.3$--$1.7\times$ throughput speedups at $0.2$--$0.3\times$ the compute cost on isolated text capabilities. These results show that asymmetric context access yields substantial gains precisely when compression discards critical reasoning signals.

## 1. 论文的核心问题与整体含义（研究动机与背景）

- **背景**：现代 LLM 部署越来越多地以"智能体流水线"（agentic pipeline）形式运行——包括检索文档（RAG）、调用工具、维持多轮对话与记忆、处理多模态输入。在这些场景中，每一步都会产生新的上下文，导致前向传播成为延迟的主要瓶颈，上下文长度成为推理开销的首要驱动因素。
- **核心矛盾**：为了控制延迟，部署方通常会对上下文进行压缩（如对检索段落生成摘要、只传 API 签名、用短字幕替代原始图像）。压缩虽然降低了服务成本，却系统性地丢弃了对任务精度至关重要的细节，形成"高延迟-高精度"与"低延迟-低精度"不可兼得的刚性权衡。
- **现有方法的局限**：投机解码（Speculative Decoding, SD）通过轻量草稿模型提议候选 token、大型验证模型并行验证，理论上可无损加速生成，但所有现有 SD 方法都隐含一个基础约束：**草稿模型与验证模型必须处理完全相同的输入 token**。因此 SD 只能加速一个"固定"的目标分布，无法弥补压缩带来的信息损失。
- **关键观察**：每一步延迟由大型验证模型主导，而轻量草稿模型的开销可忽略不计。若能只压缩验证模型的输入，就能获得大部分延迟收益——但标准 SD 因强制相同输入而无法利用这一结构性计算不对称。
- **整体含义**：AsymSpec 打破对称性，让草稿模型读取完整输入、验证模型只看压缩视图，从而开辟了一个新的工作点：**以压缩视图的延迟成本，换取接近满上下文的准确性**。实验表明，当压缩恰好丢弃关键推理信号时，非对称上下文访问能带来显著收益。

## 2. 方法论

### 2.1 核心思想

AsymSpec 显式解耦草稿模型与验证模型的上下文访问：

- **验证模型 L（大型，如 Qwen3-32B）**：严格运行在压缩视图 x_comp 上，保证效率；
- **草稿模型 S（轻量，如 Qwen3-4B）**：读取完整输入 x_full，用于重构压缩所丢弃的信息。

### 2.2 对比性 δ-融合（Contrastive δ-fusion）

每个投机步骤执行三次前向传播：

1. **增强草稿模型**：S(x_full) 产生 logits **a**，并采样 K 个草稿 token d_1:K；
2. **基础草稿模型**：S(x_comp) 产生 logits **b**；
3. **验证模型**：L(x_comp) 并行评分所有草稿，产生 logits **t**。

定义上下文增益信号（logit 空间）：

$$\delta_i = a_i - b_i$$

用同一草稿模型在全上下文和压缩上下文下的 logits 之差，**抵消草稿模型自身的上下文无关偏好**，只保留完整输入所带来的信息增益。当草稿被拒绝时，将 δ 融合进验证模型的输出分布：

$$d'_i = \arg\max(t_i + \beta \delta_i)$$

其中 β ∈ [0,1] 控制引导强度。

### 2.3 上下文发散接受门（CDA, Context-Divergence Acceptance）

当全上下文与压缩视图差异较大时，固定接受阈值 γ 会过度拒绝草稿、浪费上下文增益信号。CDA 用逐位置的 Jensen–Shannon 散度（JSD）量化发散程度，并让阈值随发散度成比例放松：

$$\gamma_{eff}(i) = \gamma \cdot \exp(-D_i), \quad D_i = \text{JSD}(\text{softmax}(a_i) \parallel \text{softmax}(b_i))$$

选择 JSD 因其具有严格上界，保证 γ_eff ∈ [γ/2, γ]，无需裁剪或额外超参数。草稿 token d_i 被接受的条件为：

$$[\text{softmax}(t_i)]_{d_i} > \gamma_{eff}(i) \cdot [\text{softmax}(b_i)]_{d_i}$$

首次拒绝后，发射式中的 δ 融合 token。当 β=0 且 γ=1 时退化为标准验证。需要指出：**该方法不保持严格的目标分布**，而是针对贪心发射校准的"投机式引导"方案。

### 2.4 跨模态扩展

由于草稿模型与验证模型共享输出词表 V，δ 和 γ_eff 完全在输出侧计算，因此不依赖于草稿模型的输入模态。视觉-语言草稿模型可直接读取原始图像作为 x_full，而纯文本验证模型读取字幕作为 x_comp。视觉编码器每请求只运行一次并缓存，长文本生成时逐 token 开销趋近于零。

### 2.5 算法流程（Algorithm 1）

```
循环直到生成完成：
1. 从 S(x_full ⊕ y) 自回归采样 K 个草稿 token；
2. 计算 S(x_comp ⊕ y ⊕ d_1:K) 在同位置的 logits b；
3. L(x_comp ⊕ y ⊕ d_1:K) 并行评分得 logits t；
4. 逐位置计算 δ_i、D_i、γ_eff(i)；
5. 依次接受草稿；遇第一个拒绝时，发射 argmax(t_i + βδ_i)；
6. 若全部接受，发射 argmax(t_{K+1})。
```

## 6. 主要结论与发现

1. **工作点有效性**：AsymSpec 在文本智能体能力上达到满上下文准确率的 87–99%（约 90% 平均），以 Ceiling 的 0.2–0.3× FLOPs 实现 1.3–1.7× 吞吐加速——这是对称 SD 和 SCD 无法触及的权衡点。
2. **机制必要性**：CDA 门与 δ-融合缺一不可（单独 CDA 使 LongBench 从 45.0 提升到 52.8，加 δ-融合后到 59.7）；同模型跨上下文 δ 来源（a−b）比 raw-aug（a）高 2.8 分、比 SCD 风格（t−b）高 11.7 分。
3. **增益单调性**：上下文截断越严重，恢复的精度越多（500 token 预算下恢复 2/3 以上的 Floor–Ceiling 差距；接近无损时增益自然消失），为生产部署提供了清晰的判断标准。
4. **跨模态可行性**：文本验证模型搭配 VL 草稿模型在 MathVista 上达 53.9%，比对称 SD 高 10.1 分；路径依赖正确的视觉嵌入路由（无补丁时跌至 30.5%）。
5. **端到端稳健性**：在 GAIA 上达 24.2%（超过 Floor 19.4 和 Ceiling 20.0）、SimpleQA 65.0%（接近 Ceiling 66.0），在线重压缩下接受率维持 0.88–0.90。
6. **容量门槛**：草稿模型 ≥1.7B 才能可靠提取上下文增益信号；0.6B 失效。
