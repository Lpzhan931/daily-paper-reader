## 摘要
混合注意力大语言模型将全注意力与递归线性注意力相结合，以降低长上下文推理成本，然而其自回归解码仍然受限于内存带宽。树推测解码提供了一种有吸引力的加速路径，但现有的树推测系统是针对全注意力模型的键值缓存设计的。在混合模型上，它们逐分支遍历递归层，并为每个提议节点物化完整状态，导致验证延迟和瞬时内存随树大小和批大小扩展性差。我们提出了Bole，一种内核-运行时协同设计，实现了混合注意力大语言模型的高效树推测。Bole将线性注意力递归转化为树结构闭式形式，并通过资源高效的GPU内核实现，并行验证所有提议节点，将线性注意力树验证加速3.4–7.7倍。它将有损地将推测状态更新编码为令牌级因子，并仅重建采样后选择的状态，将瞬时状态内存减少82–99倍，释放GPU容量用于KV缓存。其集成到广泛部署的生产级LLM服务引擎SGLang中，将高效状态管理与针对完整混合前向传播校准的批级验证预算相结合。在四个模型、两个GPU平台和多样化数据集上，Bole相对于自回归解码提供了高达4.72倍的离线解码吞吐量，相对于最强的树推测基线提供了高达2.03倍的吞吐量。在在线智能体工作负载下，相对于最强的树推测基线，TTFT和TPOT分别降低了高达67.6%和49.9%。

## Abstract
Hybrid-attention large language models combine full attention with recurrent linear attention to reduce long-context inference costs, yet their autoregressive decoding remains memory-bound. Tree speculative decoding offers an attractive acceleration path, but existing tree-speculation systems are designed around the key--value caches of full-attention models. On hybrid models, they traverse recurrent layers branch by branch and materialize a full state for every proposal node, causing verification latency and transient memory to scale poorly with tree and batch sizes. We present Bole, a kernel--runtime co-design that enables efficient tree speculation for hybrid-attention LLMs. Bole transforms the linear-attention recurrence into a tree-structured closed form and realizes it with a resource-efficient GPU kernel, verifying all proposal nodes in parallel and accelerating linear-attention tree verification by 3.4--7.7$\times$. It losslessly encodes speculative state updates as token-level factors and reconstructs only the state selected after sampling, reducing transient state memory by 82--99$\times$ and freeing GPU capacity for KV caches. Its integration into SGLang, a widely deployed production LLM serving engine, couples efficient state management with a batch-wide verification budget calibrated to the complete hybrid forward. Across four models, two GPU platforms, and diverse datasets, Bole delivers up to $4.72\times$ the offline decode throughput of autoregressive decoding and up to $2.03\times$ that of the strongest tree-speculative baseline. Under online agent workloads, it reduces TTFT and TPOT by up to $67.6%$ and $49.9%$, respectively, over the strongest tree-speculative baseline.

### 1. 论文的核心问题与整体含义（研究动机和背景）

- **背景**：混合注意力大语言模型（如 Qwen3.5、Kimi Linear）将全注意力与循环线性注意力交替堆叠，利用固定大小的递归状态总结前缀，从而降低长上下文推理的存储与计算成本。然而，这类模型的解码仍然是**内存受限**的——每生成一个 token 都需要一次完整的目标模型前向传播。
- **现有方案的不足**：树推测解码（tree speculative decoding）是加速自回归解码的有效手段，但现有树推测系统（如 SpecInfer、DeFT、SGLang、AdaServe）均为全注意力模型设计：
  - 在混合模型的循环线性层上，它们只能**逐分支、按父→子顺序遍历**每个候选节点，无法像全注意力那样用 ancestor mask 并行打分；
  - 每个候选节点都需要**物化一份完整的线性注意力状态快照**，导致瞬时内存随树大小和批大小急剧膨胀；
  - 不同 GPU 平台上"空闲计算能力"能吸收的验证 token 数不同，现有系统缺乏**硬件感知的验证预算**控制。
- **核心含义**：论文提出 Bole，一个内核（kernel）与运行时（runtime）协同设计的系统，使混合注意力模型也能高效地执行树推测解码，同时解决并行验证、状态内存爆炸和验证成本控制三个核心瓶颈。

### 2. 论文提出的方法论

#### （1）整体架构

Bole 包含三条核心机制，分别对应三个挑战：

| 挑战 | Bole 的设计 |
|------|-------------|
| 树耦合的递归依赖（无法并行） | **并行树求解器**：将线性注意力递归转化为树结构闭式形式 |
| 分支选择前状态发散（内存爆炸） | **因子化状态生命周期**：无损的令牌级状态因子表示 |
| 耦合且依赖配置的验证成本 | **硬件感知的批级验证预算** |

#### （2）并行树求解器（Parallel Tree Solver）

- **核心思想（Theorem 1）**：对整棵提议树，所有节点的输出可以一次性从**单一的树前状态（pre-tree state）**出发联合计算，无需逐节点串行更新状态：

  \[
  O = D_P Q S_{\text{pre}} + C(I + G)^{-1}D_\beta(V - D_P K S_{\text{pre}})
  \]

- 通过三个引理完成推导：
  - **Lemma 1（路径因子化）**：每个节点的路径状态可分解为"衰减后的共享状态 + 祖先节点修正项之和"；
  - **Lemma 2（祖先掩码线性系统）**：将修正向量 U 堆叠后满足 \((I + G)U = R\)，其中 G 为严格下三角矩阵，精确保留了串行执行的依赖集；
  - **Lemma 3（深度有界幂零）**：由于节点按父→子排序且最大祖先深度为 d，有 \(G^{d+1} = 0\)，从而 \((I+G)^{-1}\) 是**有限多项式**，可展开为确定的 d 轮传播。
- **值分块 GPU 内核（Value-Tiled Kernel）**：
  - 将值维度 dv 划分为若干分块，每个 CTA 处理一个值分块、覆盖全部树节点；
  - 树相关的因子 G、C 由单独的生产者计算一次，供所有 CTA 复用；
  - 通过**有限 Neumann 序列**在片上完成传播：\(Z^{(m+1)} = -GZ^{(m)}\)，全部 d 轮在同一个 CTA 内完成，避免中间数据进出 HBM；
  - 采用二维资源分块（bv 值宽 × bk 键块），平衡每 CTA 效率与 SM 并行度；
  - 配合**融合树验证流水线**：round 级拓扑预处理 + 三个 per-layer GPU 阶段（卷积/门控准备、因子构建、值分块求解与读出）。

#### （3）因子化状态生命周期（Factorized State Lifecycle）

- 传统方案为每个分支物化完整 \(d_k \times d_v\) 状态快照；Bole 则：
  - 每请求每层仅保留**一个不可变的已提交状态**（committed state），验证期间不产生私有副本，无需回滚；
  - 候选分支仅以**令牌级因子**（P, K, U）表示，空间复杂度从 \(\Theta(T H d_k d_v)\) 降为 \(\Theta(H d_k d_v) + \Theta(T H(d_k + d_v + 1))\)；
  - 采样确定接受路径后，通过一次批量矩阵乘法重建唯一需要的状态：\(S_{\text{new}} = P_a S_{\text{pre}} + (D_a K_a)^\top U_a\)；
  - 被拒绝的分支不占用任何状态缓存槽，因子随轮次回收。

#### （4）硬件感知的批级验证预算（Hardware-Aware Verification Budget）

- **离线校准**：针对每个执行配置（模型、GPU、批大小桶、KV 长度桶、树模板），扫描验证 token 总数 N，选择满足 \(T_{\text{ver}}(N|c) \le (1+\epsilon) T_{\text{dec}}(c)\) 的最大容量作为该配置的验证预算；
- **在线分配**：预算跨请求共享，按 drafter 给出的**累积路径概率** \(\rho(v) = \prod_{u \in P(v)} p_{\text{draft}}(u | \pi(u))\) 进行全局 top-k 选择，因概率单调性自动保证所选节点前缀连通。

#### （5）生产引擎集成

- 基于 SGLang 实现（约 6.2 kLoC Python/Triton），包括：CUDA Graph 原生的**扁平不规则森林**打包执行、跨层统一状态提交、无气泡 GPU 执行流水线。

### 6. 论文的主要结论与发现

- **并行验证**：Bole 将线性注意力树验证加速 **3.4–7.7×**（随批大小增大加速比提升）；核占用率提升 3.6–7.9×，L1/shared 吞吐提升 1.8–4.1×，B=16 时每层 HBM 写入从 824 MB 降至 9.8 MB（84× 减少）。
- **状态内存压缩**：瞬时状态内存减少 **82–99×**；实测非缓存推测开销比 AdaServe 降低 74.0–88.5%，释放 6.26–18.58 GiB 供 KV 缓存使用；使 Qwen3.5-27B 在批大小 8 下避免 OOM。
- **离线吞吐**：相比 SGLang-AR 几何平均加速 **2.74×**，峰值 **4.72×**；相比最强树推测基线几何平均加速 **1.26×**，峰值 **2.03×**（GB10，27B）。
- **在线延迟**：相比最强树推测基线，TTFT 降低最高 **67.6%**，TPOT 降低最高 **49.9%**；前缀缓存命中率比 AdaServe 高 21.1–34.3 个百分点（92.6% vs 59.8%）。
- **预算硬件差异性**：验证预算的最优值因 GPU 而异（A100 为 128 token、GB10 为 256 token），单一固定预算不可靠——验证了硬件感知设计的必要性。
- 全部方法保持与串行执行**代数精确等价**，不改变目标模型的输出分布。

### 7. 优点

- **理论严谨**：从路径因子化到幂零矩阵求逆给出完整的数学推导，闭式形式与串行执行**精确等价**（无损）；
- **跨层协同设计**：算法（闭式解）—内核（值分块）—运行时（预算调度/状态提交）三层贯通，而非孤立优化；
- **可落地的生产集成**：完整实现在 SGLang 中，支持 CUDA Graphs、连续批处理、GPU-resident 状态提交，工程量扎实（6.2 kLoC）；
- **评估全面且公平**：28 种离线配置 + 4 类数据集 + 真实在线负载 + 内核隔离 + 消融 + 敏感性分析，覆盖多模型、多平台、多批大小；
- **收益维度多**：不仅报告吞吐，还从内存、延迟分布、缓存命中率、MAT 等多个角度交叉验证，增强了结论的可信度；
- **硬件感知机制**：通过离线校准完整混合前向传播的验证容量，避免了固定预算在不同 GPU 上的次优性。

### 8. 不足与局限

- **模型覆盖有限**：实验仅使用 Qwen3.5 系列，未覆盖其他混合注意力模型（如论文引言提到的 Kimi Linear、或 Mamba 类 SSM 混合模型），结论的普适性有待验证；
- **GB10 平台缺少 122B 模型结果**：Table IV 显示 122B 仅部署在 A100，GB10 上的大规模 TP 场景缺失；
- **在线实验为回放而非真实用户**：虽遵循标准方法论（Poisson 到达），但仍是离线 trace 回放，未涉及真实多租户、动态 SLO 竞争；
- **AdaServe 基线为移植版本**：其原实现不支持混合模型，移植优化可能未完全保留原系统特性；
