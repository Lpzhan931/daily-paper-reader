## 摘要
混合注意力大语言模型将全注意力与循环线性注意力相结合，以降低长上下文推理成本，但其自回归解码仍然受限于内存带宽。树结构推测解码提供了一种有吸引力的加速途径，但现有的树推测系统是为全注意力模型的键值缓存设计的。在混合模型上，它们逐分支遍历循环层，并为每个提议节点物化完整状态，导致验证延迟和瞬态内存随树大小和批大小扩展性差。我们提出了Bole，一种内核与运行时协同设计，实现了面向混合注意力LLM的高效树推测解码。Bole将线性注意力循环转化为树结构的闭式形式，并通过资源高效的GPU内核实现，并行验证所有提议节点，将线性注意力树验证加速3.4–7.7倍。它将推测状态更新无损编码为词元级因子，并仅重构采样后选择的状态，将瞬态状态内存减少82–99倍，释放GPU容量用于KV缓存。其集成到SGLang（一个广泛部署的生产级LLM服务引擎）中，将高效状态管理与面向完整混合前向传播校准的批级验证预算相结合。在四种模型、两个GPU平台和多样数据集上，Bole相比自回归解码实现了高达4.72倍的离线解码吞吐量，相比最强的树推测基线实现了高达2.03倍的吞吐量。在在线智能体工作负载下，相比最强树推测基线，TTFT和TPOT分别降低了高达67.6%和49.9%。

## Abstract
Hybrid-attention large language models combine full attention with recurrent linear attention to reduce long-context inference costs, yet their autoregressive decoding remains memory-bound. Tree speculative decoding offers an attractive acceleration path, but existing tree-speculation systems are designed around the key--value caches of full-attention models. On hybrid models, they traverse recurrent layers branch by branch and materialize a full state for every proposal node, causing verification latency and transient memory to scale poorly with tree and batch sizes. We present Bole, a kernel--runtime co-design that enables efficient tree speculation for hybrid-attention LLMs. Bole transforms the linear-attention recurrence into a tree-structured closed form and realizes it with a resource-efficient GPU kernel, verifying all proposal nodes in parallel and accelerating linear-attention tree verification by 3.4--7.7$\times$. It losslessly encodes speculative state updates as token-level factors and reconstructs only the state selected after sampling, reducing transient state memory by 82--99$\times$ and freeing GPU capacity for KV caches. Its integration into SGLang, a widely deployed production LLM serving engine, couples efficient state management with a batch-wide verification budget calibrated to the complete hybrid forward. Across four models, two GPU platforms, and diverse datasets, Bole delivers up to $4.72\times$ the offline decode throughput of autoregressive decoding and up to $2.03\times$ that of the strongest tree-speculative baseline. Under online agent workloads, it reduces TTFT and TPOT by up to $67.6%$ and $49.9%$, respectively, over the strongest tree-speculative baseline.

## 论文总结：Bole——面向混合注意力语言模型的高效树推测解码

### 1. 核心问题与整体含义（研究动机与背景）

混合注意力大语言模型（如 Qwen3.5、Kimi Linear）通过将全注意力层与循环线性注意力层（如 Gated DeltaNet）交错组合，以固定大小的循环状态替代随上下文线性增长的键值缓存，从而降低长上下文推理成本。然而，其自回归解码仍受内存带宽限制，每生成一个 token 仍需要一次完整的目标模型调用。

树推测解码（tree speculative decoding）通过让轻量级草稿模型生成候选 token 树，并由目标模型一次性并行验证，能够显著加速解码。但现有树推测系统（如 SpecInfer、DeFT、SGLang 的树路径、AdaServe）均为全注意力模型的 KV 缓存设计，无法直接迁移到混合模型：其循环线性注意力层不存在可掩码的注意力矩阵，需要逐分支传播状态，导致以下三个系统瓶颈：

- **串行递归（L1）**：逐节点执行线性注意力递归，验证延迟随树大小线性增长（当树从 8 增至 64 节点时，线性层占比从 4% 升至 27%）。
- **状态爆炸（L2）**：每个提议节点需保存完整状态快照，瞬态内存随树大小和批大小线性增长（8 个 32 节点请求在 Qwen3.5-122B-A10B 上需 36 GiB），挤占 KV 缓存容量。
- **硬件相关验证容量（L3）**：目标模型各算子的高效工作区间随 GPU、KV 长度、树形状变化，固定预算不可靠。

### 2. 方法论：核心思想与关键技术

Bole 提出内核–运行时协同设计，通过三项机制解决上述三个挑战：

**（1）并行树求解器（解决 L1）**

核心思想：推导线性注意力递归在提议树上的**闭式解**，将逐节点串行状态传播转化为所有节点可并行计算的矩阵运算。

- **定理 1**（Bole 闭式树验证）：
  O = D_P Q S_pre + C(I + G)^{-1} D_β (V − D_P K S_pre)
  即所有节点输出可从单一树前状态 S_pre 联合计算得出，无需逐节点物化状态。
- **关键步骤**：
  - 引理 1：路径因子化——每个节点的状态分解为衰减后的共享状态与祖先更新项的加和；
  - 引理 2：祖先掩码线性系统——将局部更新叠加为 (I + G)U = R 的结构化线性系统；
  - 引理 3：深度有界幂零性——G 是严格下三角矩阵，满足 G^{d+1} = 0，逆矩阵可表示为有限 Neumann 级数，深度 d 即树的最大祖先数。

**实现**：值分块 GPU 内核——树相关因子（G,C）在所有值分块间共享；每个值分块分配一个 CTA，使用定形张量核心运算执行 d 轮有限 Neumann 传播，中间结果留在片上 SRAM，不写回 HBM。

**（2）因子化状态生命周期（解决 L2）**

核心思想：保持一个不可变的状态 S_pre，候选分支只以 token 级因子（P、K、U）表示，而非完整状态快照。采样确定接受路径后，通过一次批量矩阵乘法重构唯一需要保留的状态：
S_new = P_a S_pre + (D_a K_a)ᵀ U_a

- 状态存储复杂度从 Θ(H·dk·dv·T) 降至 Θ(H·dk·dv) + Θ(T·H(dk+dv+1))，瞬态内存减少 82–99 倍。
- 状态生命周期分为三层：持久规范状态、轮级因子、层内临时工作区，便于资源复用。

**（3）硬件感知批级验证预算（解决 L3）**

- 离线校准：对每个执行配置（模型、GPU、批大小、KV 长度、树模板），扫描总验证 token 数 N，选择满足 T_ver(N) ≤ (1+ε)T_dec 的最大 N 作为批级预算。
- 在线分配：按草稿模型累计概率 ρ(v) 对候选节点跨请求全局排序，在预算内选最高评分节点；子节点概率单调不增保证每棵树的选点保持前缀连通。

**生产集成**：集成到 SGLang（约 6.2 kLoC Python/Triton），支持 CUDA Graphs、设备端稠密森林打包、统一跨层状态提交、无气泡 GPU 流水线执行。

### 6. 主要结论与发现

- **并行验证**：线性注意力树验证加速 3.4–7.7×（A100 和 GB10，批大小 1→16 时加速比增大），状态物化写入从 824 MB/层降至 9.8 MB/层（84× 减少）。

### 7. 优点

- **理论严谨性**：闭式解通过引理—定理形式严格推导，保证与顺序执行**代数精确等价**，无近似误差或分布改变。
- **内核–运行时协同**：算法（闭式分解）、内核（值分块 + 有限 Neumann）、运行时（预算调度 + 状态提交）三者环环相扣，不是简单拼凑。
- **硬件自适应性**：批量预算校准覆盖完整混合前向（全注意力 + 线性注意力 + 稠密算子），自动适配不同 GPU、批大小和 KV 长度。

- **实验严谨性**：OOM 如实标注、百亿级模型覆盖、两种算力特性差异显著的平台验证。
