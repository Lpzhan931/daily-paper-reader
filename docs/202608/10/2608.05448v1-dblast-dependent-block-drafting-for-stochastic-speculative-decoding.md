## 摘要
投机解码通过使用轻量级起草器提出多个未来标记，并由目标模型进行验证，从而加速大型语言模型的推理。虽然最近的块式和扩散式起草器可以在单次传递中预测多个位置，但它们的训练和采样过程通常针对贪婪解码进行优化，或者假设草稿块中的位置是条件独立的。在非贪婪投机解码中，这种假设变得脆弱，因为目标分布故意是随机的，并且存在多种合理的延续。我们研究了块扩散起草器的这种不匹配，并表明随着目标采样分布熵的增加，接受的草稿长度会下降。我们提出了一种基于标记位置上的低秩潜在混合的依赖块起草器，并辅以面向接受的训练目标，直接针对期望的验证长度。在GSM8K、MT-Bench、HumanEval和创意写作基准上使用Qwen3-4B和Qwen3-8B进行的实验表明，我们的方法（即DBLast）始终比独立块采样提高了接受长度，尤其是在高熵解码场景中。

## Abstract
Speculative decoding accelerates large language models' inference by using a lightweight drafter to propose multiple future tokens and a target model to verify them. While recent block and diffusion-style drafters can predict several positions in a single pass, their training and sampling procedures are typically optimized for greedy decoding or assume that positions in the draft block are conditionally independent. This assumption becomes brittle in non-greedy speculative decoding, where the target distribution is deliberately stochastic and multiple continuations become plausible. We study this mismatch for block diffusion drafters and show that the accepted draft length degrades as the entropy of the target sampling distribution increases. We propose a dependent block drafter based on a low-rank latent mixture over token positions, complemented by an acceptance-oriented training objective that directly targets the expected verified length. Experiments with Qwen3-4B and Qwen3-8B on GSM8K, MT-Bench, HumanEval, and creative-writing benchmarks show that our approach, namely DBLast, consistently improves accepted length over independent block sampling, especially in higher-entropy decoding regimes.

## 1. 论文的核心问题与整体含义

- **研究背景**：投机解码（Speculative Decoding）通过一个轻量级“起草器”（drafter）生成多个未来 token，再由目标大模型并行验证，从而加速 LLM 推理。近年出现的块式扩散起草器（如 DFlash）能够在单次前向传播中并行预测一个 token 块，显著降低起草开销。
- **核心问题**：现有并行块起草器（MTP、Medusa、DFlash 等）通常假设块内各位置的条件独立性，或仅针对贪婪解码优化。然而在**非贪婪（随机）投机采样**场景下，目标分布本身是高熵的、存在多种合理延续，目标模型的验证是**顺序的**——第 i 个草稿 token 需在已接受前缀条件下被检验。独立采样的草稿块即使每个位置边际分布准确，也难以构成一条连贯的条件轨迹，导致接受长度（accepted length）显著下降。
- **论文的贡献定位**：本文属于**方法 + 诊断**混合型贡献——不仅识别了"独立块采样 vs 顺序验证"之间的结构性错配，还提出了一种保留并行预测能力、同时建模块内依赖的起草方案，并设计了直接对齐验证行为的训练目标。

## 2. 论文提出的方法论

### 2.1 核心思想

作者提出 **DBLast**，在 DFlash 风格的块扩散起草器中注入两类改进：

1. **依赖块采样**：引入低秩潜在混合（CP 风格 latent mixture），在保持单次并行预测的同时，通过类别潜在变量诱导块内位置间的依赖关系。
2. **接受导向训练**：设计以期望验证长度（Expected Accepted Length）为动机的 log 域训练代理，直接优化验证器顺序接受行为，而非单纯最大化目标块的似然。

### 2.2 关键技术细节

**（1）依赖块分布建模**

潜在混合提议分布为：

```
q_dep(x_{1:b} | y) = Σ_{z=1}^{K} q(z | y) ∏_{i=1}^{b} q_i(x_i | y, z)
```

其中 z 为 K 类潜在类别变量。采样时先采样类别 ẑ，再从选中分支并行解码所有位置；K=1 时退化为独立基线。

**（2）推理时的确定性分支解码**

- 从学习到的类别先验中采样或确定性选择类别（可加类别温度 ZT 调节随机性）；
- 在选中分支内贪心解码各位置 token；
- 验证时通过前缀边缘化（prefix marginalization）计算 token 级条件提议分布，即类别后验随已接受前缀动态更新：
```
q(z | y, x_{<i}) ∝ q(z | y) ∏_{j<i} q_j(x_j | y, z)
```
- 整个采样-验证过程保持目标分布精确性（vanilla speculative sampling correction 依然成立）。

**（3）架构改造**

- 在 DFlash 主干最后一层输出上添加"类别隐藏扩展器"（单层线性层），将共享隐藏状态映射为 K 个类别特定分支特征：`h_{i,z} = h_i + g_z(h_i)`；
- 复用目标模型 LM head 计算各分支 token 分布；
- 增加独立的"类别先验头"，将块锚点隐藏状态映射为 K 个类别 logits；
- 以 K=4 为例：Qwen3-4B 增加 26.2M 参数（+5.2%），Qwen3-8B 增加 67.1M 参数（+6.7%）。

**（4）接受导向训练目标**

- 将期望接受长度分解为前缀接受事件的加权和，使用重要性比 r_ℓ = q(x_{1:ℓ}) / p(x_{1:ℓ}) 在目标采样前缀上评估；
- 为避免训练早期起草器与目标分布重叠过小，设计**阈值截断**机制：仅保留重要性比 r_ℓ ≥ τ（τ=0.1）的前缀；
- 最终对数域代理目标为：

```
J_AL = E_{x_{1:b}~p(·|y)} [ Σ_{ℓ∈T_τ(x_{1:b})} (log r_ℓ + log S_ℓ) ]
```

其中 S_ℓ 为子块内的条件期望接受长度，通过 log S_ℓ 注入验证器的顺序接受信号，通过 log r_ℓ 注入提议概率。该代理为**对数域非无偏**目标，但对实际训练有效。

## 6. 论文的主要结论与发现

1. **独立块采样与随机验证存在失配**：随目标采样熵升高，独立块起草的接受长度下降愈明显；创意写作诊断中，确定性最低分位区间的接受长度降幅最大，验证了"多样性场景更需要依赖感知起草"的判断。
2. **DBlast 持续超越基线**：在全部 3 个任务和 3 种目标采样设置上，DBlast 在两种模型上都取得了最高平均接受长度；Qwen3-8B 低确定性设置下宏平均增益达 **+12.1%**，中确定性 +9.2%，高确定性 +5.6%。
3. **两项创新互补**：独立 AL 训练在低确定性下增益 +5.1%，依赖 NLL 训练增益 +6.4%，两者结合增益 +12.1%，说明"依赖建模"与"接受导向目标"解决的是不同层面的问题。
4. **K=4 已足够**：更多潜在类别带来的增益递减，K=4 兼顾效果与参数开销。
5. **延迟开销可接受**：Qwen3-4B 上 K=4 的每步迭代延迟仅增加 1.4%，K=8 也仅 3.4%。
