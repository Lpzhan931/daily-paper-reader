## 摘要
多模态大语言模型（MLLMs）在多种视觉-语言任务上表现出色，但其效率受到处理大量视觉令牌成本的限制。视觉令牌剪枝可以降低该成本，但需要准确的令牌重要性估计。近期的研究表明，来自语言模型中层的文本到视觉注意力可以有效指导视觉令牌剪枝，通常使用预先定义的中层注意力来选择要保留的视觉令牌。因此，仍有两个问题。首先，我们的分析表明，对问题响应最敏感的注意力层在不同样本间差异很大，使得固定层变得次优。其次，从合适的中层获得注意力需要先通过多个语言模型层处理大量视觉令牌，此时已经消耗了大量计算。为解决这两个问题，我们提出了中层注意力预测（MAP），它使用问题对比教师选择（Question Contrastive Teacher Selection）来识别样本特定的教师层，通过对比原始问题和参考问题下的注意力来挑选，并将选定层的注意力蒸馏到一个轻量级预测器中，该预测器从多模态输入特征中估计视觉令牌的重要性。在推理时，MAP将预测的重要性分数与多样性准则相结合，在第一个语言模型层之前剪除视觉令牌。因此，MAP在剪枝时不需要注意力图，并保持与现有推理加速技术的兼容性。在LLaVA-NeXT-7B的十个基准上，MAP仅使用5.56%的视觉令牌即可保留未剪枝模型97.5%的性能，实现了3.09倍的端到端加速。

## Abstract
Multimodal large language models (MLLMs) achieve strong performance across diverse vision-language tasks, but their efficiency is limited by the cost of processing numerous visual tokens. Visual token pruning can reduce this cost, but requires accurate token importance estimates. Recent studies have demonstrated that text-to-vision attention from middle language model layers can effectively guide visual token pruning, typically using attention from a predefined middle layer to select the visual tokens to retain. Two problems therefore remain. First, our analysis shows that the layer whose attention is most responsive to the question varies substantially across samples, making a fixed layer suboptimal. Second, obtaining attention from the appropriate middle layer requires processing numerous visual tokens through several language model layers, by which point considerable computation has already been spent. To address both problems, we propose Middle-layer Attention Prediction (MAP), which uses Question Contrastive Teacher Selection to identify a sample-specific teacher layer by contrasting attention under the original and reference questions, and distills attention from the selected layer into a lightweight predictor that estimates visual token importance from multi-modal input features. During inference, MAP combines the predicted importance scores with a diversity criterion to prune visual tokens before the first language model layer. Thus, MAP requires no attention maps for pruning and remains compatible with existing inference acceleration techniques. Across ten benchmarks on LLaVA-NeXT-7B, MAP retains 97.5% of the unpruned model performance with only 5.56% of the visual tokens, yielding a 3.09x end-to-end speedup.

## 2. 论文提出的方法论

- **核心思想**：将“样本特定的中层注意力”蒸馏到一个轻量级预测器中，使模型在进入语言模型**第一层之前**就能估计视觉 token 的问答相关重要性，再结合多样性准则进行剪枝。
- **关键技术细节**：
  1. **Question Contrastive Teacher Selection（QCTS）**：
     - 对每个训练样本，分别计算输入问题和固定参考问题（“What is shown in this image?”）下各 LLM 层的文本到视觉注意力分布；
     - 对每层注意力进行多头、多问 token 平均并做 L1 归一化；
     - 使用 Jensen–Shannon 散度衡量原始问题与参考问题注意力分布的差异，选择散度最大的层作为该样本的教师层 $l^*$。差异越大，说明该层越关注当前问题特有的视觉证据。
  2. **Cross-Modal Attention Distillation**：
     - 训练一个轻量预测器：分别用两个 MLP 处理文本表示和视觉表示，再通过投影得到 query/key，加入 RoPE，计算 softmax 得到预测注意力 $\hat{p}$；
     - 以教师层注意力 $p^{l^*}$ 为监督，最小化 KL 散度训练预测器；原始 MLLM 保持冻结。
  3. **推理时剪枝**：
     - 预测注意力作为视觉 token 的重要性分数；
     - 先保留 top-$K_0$ 个 token，再贪心添加候选 token，选择同时满足“高重要性”和“高多样性”的 token；
     - 多样性通过正交基残差衡量：$i_t = \arg\max_{i\in C_{t-1}} \hat{p}_i \|v_i - B_{t-1}B_{t-1}^\top v_i\|_2$，其中 $B$ 为已选 token 构成的正交基；
     - 剪枝发生在第一个 LLM 层之前，保留 token 恢复原始顺序与位置索引后与文本 token 一起进入模型。

## 6. 论文的主要结论与发现

- **中层注意力有效但“最优层不固定”**：文本到视觉注意力在中间层能有效定位问答相关区域，但不同样本、不同任务的最优层不同，固定层策略效果有限。
- **QCTS 能选出接近理想的教师层**：QCTS 选出的层在目标覆盖率、ROI-NSS、与 ROI-Max 的层距离和命中率上均优于固定层和随机层，用于直接剪枝时也超过任何固定层。
- **蒸馏到轻量预测器可行**：预测器能直接从 LLM 前的多模态表示中估计中层注意力，推理时无需实际注意力图。
- **MAP 在多个骨干和基准上取得更优的精度-效率权衡**：
  - LLaVA-NeXT-7B 上仅保留 5.56% 视觉 token（160/2880），依然保持 97.5% 的相对性能；
  - 在较高压缩率下优势更明显，说明 MAP 能更有效地保留问题相关证据；
  - 与 FlashAttention 等优化算子兼容。
- **多样性准则在极端压缩下更重要**：token 预算充足时重要性分数已足够，预算紧张时多样性约束带来显著增益。

## 7. 优点

- **问题定位准确**：通过对比原始问题与参考问题的注意力分布来选择样本特定教师层，思想新颖且贴合“问答相关”这一真实目标。
- **解决了效率悖论**：将昂贵的中层注意力获取过程转化为轻量预测器的离线蒸馏，推理时在第一个 LLM 层前完成剪枝，计算收益大。
- **无需推理时注意力图**：避免显式物化注意力矩阵，可兼容 FlashAttention 等高效算子，实用性强。
- **剪枝准则设计合理**：将预测注意力（问答相关性）与多样性（信息互补性）结合，兼顾相关性和覆盖度。
- **实验较全面**：在三个骨干、十余个数据集、多种压缩率下验证，并进行了消融和效率分析，提供了较完整的证据链。
