## 摘要
推测性解码通过并行验证多个草稿令牌，无损加速自回归语言模型。基于扩散的草稿者通过并行预测整个令牌块进一步减少提议延迟，但其逐位置分布是边缘分布，而不是以沿每条草稿路径选择的令牌为条件。现有的循环校正沿单一草稿链纳入因果信息，而基于扩散的树构建拓宽了候选覆盖范围，但没有沿各个分支携带这种校正。我们提出了DARTree，一种无需训练的推测性解码方法，将预训练的自回归校正头从链扩展到树。DARTree首先通过在每个深度单批次扩展和评分所有节点来构建一个固定宽度的候选树，然后仅应用最佳优先剪枝来选择验证树，将自回归头推理与顺序堆操作解耦。在七个数学、代码和聊天基准测试中，DARTree在所有四种模型-温度配置中实现了最高的平均接受长度和加速比，每轮验证接受多达12.97个令牌，比相同设置下的DFlash多98.6%，比Domino多27.9%，并且相对于本地测量的自回归解码达到高达9.73倍的加速。

## Abstract
Speculative decoding losslessly accelerates autoregressive language models by verifying multiple draft tokens in parallel. Diffusion-based drafters further reduce proposal latency by predicting an entire token block in parallel, but their position-wise distributions are marginal rather than conditioned on tokens selected along each draft path. Existing recurrent correction incorporates causal information along a single draft chain, whereas diffusion-based tree construction broadens candidate coverage without carrying this correction along individual branches. We introduce DARTree, a training-free speculative decoding method that extends a pretrained AR correction head from chains to trees. DARTree first constructs a fixed-width candidate tree by expanding and scoring all nodes at each depth in a single batch, and then only applies best-first pruning to select the verification tree, decoupling AR-head inference from sequential heap operations. Across seven math, code, and chat benchmarks, DARTree achieves the highest average acceptance length and speedup in all four model--temperature configurations, accepting up to 12.97 tokens per verification round, 98.6\% more than DFlash and 27.9\% more than Domino in the same setting, and reaching up to 9.73$\times$ lossless speedup over locally measured autoregressive decoding.

# DARTree：具有自回归草稿树的推测性扩散解码——中文总结

## 1. 核心问题与整体含义

- **背景**：自回归（AR）大语言模型逐 token 顺序生成，严重受限于访存带宽（I/O-bound），硬件并行能力未被充分利用。推测性解码（Speculative Decoding）通过轻量草稿器提出多个候选 token，再由目标模型并行验证，可在保持目标分布不变的前提下加速生成。
- **扩散式草稿器的问题**：基于扩散的草稿器（如 DFlash）可一次前向预测整个 token 块，大幅降低提议延迟，但其预测的是**边际分布**，没有以同块内已选择的 token 为条件，与目标模型的条件分布存在因果不匹配。
- **现有改进的互补与缺陷**：Domino 等通过循环修正头沿**单一草稿链**恢复因果依赖；DDTree 等通过树结构扩大候选覆盖，但未将修正头沿各分支传播。将“因果修正”与“树构建”结合时，若使用堆式最佳优先搜索，每个节点扩展后都必须串行执行修正头推理和堆更新，形成严重效率瓶颈。
- **DARTree 的目标**：在**无需训练**的前提下，将预训练 AR 修正头从链推广到树，同时获得“路径条件化”和“树覆盖”的优势，并避免顺序堆操作带来的延迟开销。

## 2. 方法论

### 核心思想
采用“**逐深度批量展开 + 延迟最佳优先剪枝**”的两阶段策略：
1. 先构造一个**比验证树更宽的候选超树（supertree）**；
2. 待所有分支的修正分数计算完毕后，再以一次全局 top-B 选择得到最终验证树。

这样就将修正头推理与顺序堆操作解耦，使同一深度的多分支可以张量化并行计算。

### 关键技术细节
- **单次块并行前向**：扩散骨干网络一次前向得到共享表示 \(\{H_d\}_{d=1}^\gamma\) 和基础 logits \(\{L^base_d\}\)。
- **逐深度展开**：从根开始，对于深度 \(d\)：
  - 取每个位置 top-K 候选词 \(C_d\)；
  - 对当前所有活跃前缀 \(S_{d-1}\) **批量**应用预训练修正头 \(g\)，计算路径条件分布 \(eq_d(C_d | u_{<d})\)；
  - 按累积修正分数 \(s_\beta(u_{1:d}) = \sum_{i=1}^d \log eq_i(u_i) + \beta d\) 打分，其中 \(\beta \le 0\) 为深度惩罚；
  - 保留全局 top-W 个子前缀作为下一层 \(S_d\)，并传递对应修正状态。
- **延迟剪枝**：完整超树构建完成后，使用一次全局 top-B 选择，得到节点预算为 B 的验证树。
- **关键等价引理**：当 \(\beta \le 0\) 且平局时祖先优先，全局 top-B 选择与堆式最佳优先搜索返回相同的前缀树，因此无需在构造过程中插入逐节点堆操作。
- **验证阶段不变**：最终验证树仍由目标模型通过 tree-attention mask 单次前向并行验证，不改变原有投机解码验证流程。

- **理论保证**：给出堆式最佳优先与全局 top-B 等价的引理，剪枝策略有明确依据。

9. 总结与综合评价

DARTree 针对“扩散式草稿器 + 推测性解码”场景中一个真实且关键的矛盾——边际分布与条件分布不匹配、树覆盖需求与顺序修正头计算冲突——提出了一个优雅、无需训练的解决方案。该方法以“深度方向批量展开 + 延迟最佳优先剪枝”为核心，在理论上证明了全局 top-B 选择与堆式最佳优先搜索的等价性，将原本串行的修正头推理与堆维护操作彻底解耦，从而同时获得路径条件化（链式因果修正）与树覆盖（多候选兜底）的双重优势，并实现了可见的端到端加速（最高 9.73×，平均接受长度最高 12.97 token）。

从论文写作与实验规范来看，该工作动机清晰、理论铺垫充分、对比基线选择合理（覆盖无树扩散、无修正头扩散树、链式修正头扩散等关键消融维度），且通过跨领域基准、双温度设置、修正头迁移、超参扫描与并发服务实验构建了较为完整的证据链。即便在个别基准点上小幅落后于 DDTree，整体趋势一致且稳健地优于所有基线，结论可信。

作为一篇以推理侧优化为核心贡献的工作，DARTree 的价值不仅在于某组具体数字的提升，更在于它揭示了“树结构”与“因果修正”在扩散草稿器框架下并非互斥，而是可以通过适当的批量执行策略统一起来。它为后续研究提供了一个值得借鉴的设计模板：凡是在单链上串行计算的模块，均可考虑以“构造超树 + 延迟剪枝”的方式并行化。总体而言，这是一篇高质量、实用性强的技术性论文，在推理加速方向的工程价值和学术价值均较为突出。
