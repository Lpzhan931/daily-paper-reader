## 摘要
半结构化 $N$:$M$ 稀疏性已成为加速大型语言模型（LLMs）的实用方向。然而，现有的可学习掩码方法会带来大量的参数和内存开销，限制了其在大模型和高稀疏度场景下的可扩展性。在这项工作中，我们从兼顾效率与可扩展性的视角重新审视半结构化剪枝。我们提出重要性水库（RoI），一种轻量级半结构化剪枝框架，通过可微分子集采样学习稀疏掩码。与先前对所有可行 $N$:$M$ 模式建模完整分类分布的方法不同，RoI 引入了一种紧凑对数几率参数化用于稀疏掩码学习，并进行无放回采样以选择掩码，从而将可训练参数从组合复杂度降低到 $\mathcal{O}({M})$。因此，RoI 所需的可学习参数减少了 1.5–8.75 倍，内存成本显著降低，同时完全保持与硬件友好的稀疏模式对齐。跨 Qwen2.5 LLM 系列（0.5–7B 参数）多个规模的广泛评估表明，RoI 在强内存效率、稳定性和对更激进 $N$:$M$ 稀疏模式的可扩展性方面取得了有竞争力的性能，为高效 LLM 部署提供了一条实用途径。

## Abstract
Semi-structured $N$:$M$ sparsity has emerged as a practical direction for accelerating large language models (LLMs). However, existing learnable-mask approaches incur substantial parameter and memory overhead, limiting their scalability to large models and aggressive sparsity regimes. In this work, we revisit semi-structured pruning from a perspective that reconciles efficiency with scalability. We propose Reservoir of Importance (RoI), a lightweight semi-structured pruning framework that learns sparsity masks through differentiable subset sampling. Unlike prior methods that model full categorical distributions over all feasible $N$:$M$ patterns, RoI introduces a compact-logit parameterization for sparsity mask learning and performs sampling without replacement to select masks, thereby reducing trainable parameters from combinatorial complexity to $\mathcal{O}({M})$. As a result, RoI requires 1.5-8.75$\times$ fewer learnable parameters and significantly lower memory cost, while remaining fully aligned with hardware-friendly sparsity patterns. Extensive evaluations across multiple scales of the Qwen2.5 LLM family (0.5-7B parameters) demonstrate that RoI achieves competitive performance with strong memory efficiency, stability, and scalability to more aggressive $N$:$M$ sparsity patterns, offering a practical path toward efficient LLM deployment.

## 1. 核心问题与研究动机

- **背景**：半结构化 $N$:$M$ 稀疏性（如 2:4）能够在保持规则稀疏模式的同时实现现代加速器上的高效推理，是平衡剪枝灵活性与硬件效率的实用方案。
- **问题**：现有可学习掩码方法（如 MaskLLM）将每个剪枝组建模为所有可行 $N$:$M$ 模式上的完整分类分布，参数规模为 $\mathcal{O}\left(\binom{M}{N}\right)$，随 $M$ 增大呈组合爆炸式增长，导致训练参数、内存和优化器状态开销巨大，难以扩展到大型 LLM 和高稀疏率场景。
- **目标**：设计一种轻量级、可扩展且与硬件对齐的半结构化剪枝方法，在保持或超过现有学习式方法性能的同时，显著降低可训练参数和训练成本。

## 2. 方法论：RoI 框架

### 核心思想
- 不再为每个可行掩码分配一个参数，而是对每组 $M$ 个权重学习 $M$ 个“重要性对数几率（logits）”，通过可微分的无放回子集采样选出 $N$ 个保留项，从而获得 $N$ 个 one-hot 向量之和作为掩码。
- 理论上，这种基于“加权水库采样（WRS）+ Gumbel-Top-K”的采样方式与原问题的组合分布等价（论文给出定理 1 证明），但参数复杂度从 $\mathcal{O}\left(\binom{M}{N}\right)$ 降至 $\mathcal{O}(M)$。

### 关键技术细节
- **随机变分优化**：将离散掩码建模为随机变量，最小化交叉熵损失的变分上界；目标为对掩码分布求期望的校准损失。
- **加权水库采样（WRS）**：用无放回抽样从 $M$ 个权重中抽取 $N$ 个，概率与权重成正比，从而诱导出掩码分布。
- **Gumbel-Top-K 松弛**：对 logits 添加 Gumbel 噪声，递归调整键值并用 softmax 生成松弛化 one-hot 向量，保证梯度可传播。
- **温度退火**：引入 $\tau$（Gumbel-Softmax 温度）和 $\lambda$（采样随机性缩放）两个超参数，采用指数退火从高随机性逐步收敛到确定性掩码。
- **训练范式**：冻结原始模型参数，仅训练掩码 logits；在推理阶段使用 argtop-K 生成硬掩码。

## 6. 主要结论与发现

- RoI 在 2:4 稀疏下，Qwen2.5 全系列模型上均取得与 MaskLLM 相当或更好的准确率与困惑度，同时可训练参数降低约 33%（7B 模型下从 9.8B 降至 6.5B）。
- 在 2:8 极端稀疏下，仅学习式掩码方法能保持合理 PPL，RoI 优于 MaskLLM 且所需参数仅为后者的 28.57%。
- 从训练 token 扩展曲线看，正则化型方法（ProxSparse）早期损失下降快但后期停滞，而 RoI 与 MaskLLM 随数据增加持续改善，RoI 具有更好的数据效率和渐近性能。
- 可学习掩码方法（RoI、MaskLLM）全面优于基于显著性的剪枝方法（Magnitude、Wanda、SparseGPT），证明显式学习稀疏掩码在半结构化剪枝中的关键价值。
- RoI 的掩码结构与 MaskLLM 高度重合，表明其能以更低开销学到相似的高质量剪枝模式。
- 2:4 稀疏模型在实际部署中能带来约 1.26–1.3× 的吞吐加速（vLLM + NVIDIA B300）。

## 7. 优点

- **参数效率高**：将复杂度从组合级降到 $\mathcal{O}(M)$，在 $M$ 增大或 $N$ 接近 $M/2$ 时优势更明显。
- **理论保证**：通过定理证明子集采样参数化与原始掩码分布等价，方法有坚实的数学基础。
- **优化效率好**：与 MaskLLM 相比，RoI 的梯度通过 item-level logits 在相邻掩码间共享，改善了参数空间的几何性质，加快收敛且更稳定。
- **易于部署**：完全兼容硬件支持的 2:4 模式；使用 vLLM 即可直接获得实际推理加速。
- **可扩展性强**：从 0.5B 到 7B（以及 Gemma2-9B）均表现稳定，在更极端稀疏下优于或持平于强基线。

## 8. 不足与局限

- **硬件依赖**：半结构化稀疏的加速收益仅在支持 2:4 的特定平台（如 NVIDIA Ampere/Hopper、AMD ROCm）上能发挥，其他硬件上收益有限。
- **泛化验证不足**：仅验证英文密集模型，未覆盖多语言、MoE、代码/推理任务等更广泛场景；额外模型实验仅 Gemma2-9B，对比度有限。
- **实验公平性问题**：ProxSparse 在部分规模上失败被排除，可能导致对比矩阵不完整；2:8 压力测试虽有意义但非主流硬件指定场景。
- **未提供存储与显存占用的直接度量**：主要给出了参数量和 GPU 时间，缺乏对实际内存峰值等的量化。
- **温度/超参数敏感性**：退火调度对性能影响较大（表 7），需要一定调参成本。
