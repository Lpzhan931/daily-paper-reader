## 摘要
随着上下文在检索、工具使用和多轮交互中的累积，智能体LLM流水线的推理成本不断上升。为了控制延迟，部署通常会压缩输入，但这会降低任务准确性。投机解码（SD）无损地加速生成，但假设草稿者和验证者共享相同的上下文，这阻碍了SD解决准确性与开销之间的权衡。我们提出AsymSpec，一种打破这种对称性的不对称投机解码框架：轻量级草稿者读取完整输入，而大型验证者基于压缩视图进行操作。草稿者通过logits的对比性δ融合来引导验证者，并由一个具有发散感知的接受门调节，该门保持验证稳定性和高草稿接受率。在四个智能体能力和两个端到端智能体基准上的评估中，AsymSpec平均达到全上下文准确率的约90%，在孤立文本能力上以0.2--0.3倍的计算成本提供1.3--1.7倍的吞吐量加速。这些结果表明，当压缩丢弃关键推理信号时，不对称上下文访问恰好能带来显著收益。

## Abstract
Agentic LLM pipelines face escalating inference costs as context accumulates across retrieval, tool use, and multi-turn interactions. To control latency, deployments routinely compress inputs, but this degrades task accuracy. Speculative decoding (SD) accelerates generation losslessly, yet it assumes the drafter and verifier share an identical context, preventing SD from resolving the accuracy-overhead trade-off. We propose AsymSpec, an asymmetric speculative decoding framework that breaks this symmetry: a lightweight drafter reads the full input while the large verifier operates on the compressed view. The drafter steers the verifier via a contrastive $δ$-fusion of logits, modulated by a divergence-aware acceptance gate that preserves verification stability and high draft acceptance rates. Evaluated across four agentic capabilities and two end-to-end agent benchmarks, AsymSpec reaches $\approx 90\%$ of full-context accuracy on average, delivering $1.3$--$1.7\times$ throughput speedups at $0.2$--$0.3\times$ the compute cost on isolated text capabilities. These results show that asymmetric context access yields substantial gains precisely when compression discards critical reasoning signals.

- **现有权衡困境**：为控制开销，部署通常对上下文进行压缩（如摘要、API 签名、简短标题），但这会系统性地丢弃对任务精度关键的细粒度信息，形成“全上下文高延迟”与“压缩低精度”的刚性二选一。
- **已有方法的局限**：投机解码（SD）是无损加速的标准方案，但所有现有 SD 方法都固守一条基础约束：**草稿模型与验证模型必须处理完全相同的输入 token**。这意味着 SD 只能加速固有目标分布，无法恢复压缩所丢失的信息——要么两个模型都承担全上下文成本，要么都继承压缩损失。

### 核心洞察
- 存在一种**结构性计算不对称**：单步延迟主要由大型验证模型主导，而轻量草稿模型的额外开销几乎可忽略。若只压缩验证模型的输入，就能获得大部分延迟节省，但传统 SD 因强制输入一致而无法利用这一点。

### 整体含义
论文通过打破 SD 的对称性约束，利用轻量草稿模型处理全量上下文、验证模型处理压缩视图，成功开辟了一个新的运行点——**以压缩成本获得接近全上下文的上限精度**，为智能体推理的效率-精度权衡提供了新的解决思路。

## 2. 论文提出的方法论

### 核心思想
AsymSpec 显式解耦两个模型的上下文访问权限：
- **大型验证模型 L**：仅读取压缩视图 \(x_{comp}\)，保证效率；
- **轻量草稿模型 S**：读取完整输入 \(x_{full}\)，重建被压缩丢弃的信息，并通过对比机制引导验证模型。

### 关键技术细节

#### ① 对比性 δ-融合（Contrastive δ-fusion）
每个投机解码步骤执行三次前向传播：
1. **增强草稿**：S(\(x_{full}\)) 产生 logits \(a\)，采样 K 个候选 token；
2. **基础草稿**：S(\(x_{comp}\)) 在同一位置产生 logits \(b\)；
3. **验证**：L(\(x_{comp}\)) 并行打分，得到 logits \(t\)。

**上下文增益信号**定义为同一草稿模型在两种上下文下的 logits 之差：
\[
\delta_i = a_i - b_i
\]
关键点在于：由于 \(a\) 和 \(b\) 来自**同一模型、同一权重**，相减后可以消除草稿模型自身的上下文无关偏好，从而隔离出由额外上下文带来的纯粹信息增益。

在草稿被拒时，δ 信号融合进验证模型的 logits：
\[
d'_i = \arg\max(t_i + \beta \delta_i)
\]
其中 \(\beta \in [0,1]\) 控制引导强度。

#### ② 上下文分歧接受门（Context-Divergence Acceptance, CDA）
当全量与压缩视图分歧较大时，固定接受阈值会导致过度拒绝草稿、浪费上下文增益信号。CDA 将每位置的阈值按上下文分歧度成比例放宽：

\[
\gamma_{eff}(i) = \gamma \cdot \exp(-D_i), \quad D_i = \text{JSD}(\text{softmax}(a_i) \| \text{softmax}(b_i))
\]

- 选择 **Jensen-Shannon 散度** 是因为其严格上界 \(\ln 2\)，保证 \(\gamma_{eff} \in [\gamma/2, \gamma]\)，无需裁剪或引入额外超参数；
- 指数形式是乘性组合公理的唯一解（附录 A 给出推导）；
- 接受判定条件：\([\text{softmax}(t_i)]_{d_i} > \gamma_{eff}(i) \cdot [\text{softmax}(b_i)]_{d_i}\)；
- 首次拒绝后，发射式（2）中 δ 融合的 token。

#### ③ 跨模态扩展
由于草稿模型和验证模型共享输出词表，δ 和 \(\gamma_{eff}\) 完全在输出端计算，因此草稿模型的输入模态可以是任意的。视觉-语言草稿模型可处理原始图像，文本验证模型读标题，投机循环无需改动。视觉编码器每请求运行一次并缓存嵌入，长生成时每 token 开销趋于零。

#### 算法流程（Algorithm 1）
1. 从 S(\(x_{full}\)) 自回归采样 K 个草稿 token；
2. 计算 S(\(x_{comp}\)) 在对应位置的 logits \(b\)；
3. 验证模型 L(\(x_{comp}\)) 并行打分；
4. 计算各位置的 δ 和分歧度 \(D_i\)，推导 \(\gamma_{eff}\)；
5. 逐位置接受或拒绝；接受则继续，拒绝则发射 δ 融合 token。

## 6. 论文的主要结论与发现

1. **核心成果**：AsymSpec 在文本任务上恢复约 90% 的全上下文精度，仅消耗 0.2–0.3× FLOPs，吞吐提升 1.3–1.7×，实现了传统对称 SD 无法触及的权衡工作点。

2. **精度恢复幅度**：在长上下文多跳 QA 和工具使用上，模型关闭了 Floor–Ceiling 差距的 59–94%；残差是结构性的——验证模型仍受压缩输入约束，仅靠 logits 引导无法完全重建多跳推理链条。

3. **机制诊断**：增益与压缩信息损失直接相关——MultiChallenge 上压缩损失极小（Ceiling–Floor 仅 3.0 分），AsymSpec 几乎不增益；截断预算扫描证实恢复幅度随压缩严重程度单调增长（500 token 预算下恢复超 2/3 差距，12000 token 时增益自然消失）。

4. **对比优势**：SCD 在全部 5 个指标格上不优于 Floor，证明单一上下文的对比融合无法恢复压缩损失；RAPID 虽精度接近 Ceiling 但 FLOPs 达 1.01×，被计算轴压制。

5. **跨模态有效性**：VL 草稿 + 文本验证模型在 MathVista 上比对称 SD 高出 10.1 分；VQA 和 FQA 任务中视觉锚定与逻辑能力互补显著。

6. **端到端稳定性**：在线重压缩不侵蚀验证质量，接受率稳定在 0.88–0.90（GAIA），计算效率直接跟踪压缩强度（GAIA 0.78× FLOPs，SimpleQA 0.80×）。

7. **消融结论**：CDA 门与 δ 融合缺一不可；同模型跨上下文的 δ 源比原始增强 logits（差 2.8 分）和 SCD 风格 t-b（差 11.7 分）显著更优；草稿模型 ≥1.7B 为实际下限。

8. **可移植性**：跨模型家族 δ 融合可行但恢复幅度因模型对而异（Qwen-4B→Llama-70B 恢复 50%；Llama-3B→Qwen-32B 仅恢复 10%）。

## 7. 优点

### 方法层面
- **问题视角新颖**：首次识别并打破 SD 的“同上下文”约束，将信息论中的互信息（JSD = I(X;Z)）与解码接受门设计优雅结合；
- **理论严谨**：CDA 门有完整公理推导（从乘性组合公理唯一确定指数形式，JSD 上界消除超参数）；
- **通用性强**：压缩器视为黑箱、支持跨模态、跨模型家族迁移；
- **机制可解释**：单 token 案例（RecordHealthData）清晰展示了 δ 如何将结构化模式从全量规格恢复到压缩视图。

### 实验层面
- **评估体系完善**：覆盖文本、多模态、端到端智能体循环、跨家族、跨规模、跨压缩器等多个维度；
- **诊断机制**：截断预算扫描以连续轴验证“增益源于压缩损失”这一核心论断，消除过拟合嫌疑；
- **工程落地扎实**：vLLM 补丁细节详实（5 个补丁），并对未打补丁的对照（精度崩塌至 30.5%）如实报告。

## 8. 不足与局限

### 理论/方法局限
- **恢复上限受制于压缩视图**：验证模型仍无法访问完整输入，δ 引导存在信息瓶颈，无法完全重建复杂推理链；
- **需要访问验证模型 logits**：无法应用于仅暴露生成文本的专有 API；
- **贪心解码限定**：仅评估确定性解码（τ=0），随机采样（τ>0）时 CDA 界的推广未解决（论文提及可用 Gumbel-Softmax 扩展，但未实现）；
- **跨家族对齐成本高**：需显式词汇表对齐，且恢复效果因模型对而异（最低仅 10%）。

### 实验局限
- **硬件信息缺失**：未报告 GPU 型号、数量、绝对训练/推理时间，可复现性打折扣；
- **部分基准规模较小**：API-Bank 仅 200 例、MultiChallenge 271 例，统计功效有限；
- **API-Bank 仅测 Method A**：Method B（多调用轨迹）因复杂度未覆盖；
- **GAIA 文件子集的 Ceiling 口径不一致**：使用草稿模型单独运行而非 32B 全上下文运行，对比参照较弱；
- **吞吐量报告存在测量方差**：论文承认文本基准的 eager mode 吞吐量存在非平凡运行间方差；
- **端到端延迟包含非 LLM 开销**：实际 agent 循环中工具执行与网络 I/O 未被纳入优化范围。

### 应用限制
- 跨模态的精度上界受制于图像到文本的翻译保真度；集成直接处理原始像素的更丰富多模态草稿模型仍是未来工作。
