## 摘要
推测解码通过并行验证草稿块与目标模型来加速自回归生成。在标准贪婪验证下，解码在第一个与目标argmax不同的草稿标记处停止，丢弃剩余的目标评分后缀。虽然接受这种不匹配会改变解码轨迹，但当其标记在已实现的前缀下仍保持目标贪婪时，可以使一个连续后缀变得可重用。在本文中，我们引入了近似推测解码（ASD），一种免训练的验证器，用预算化最长前缀选择替代二元首错截断。ASD接受选定的不匹配，受局部目标logit遗憾门、每块异常上限和持久请求级遗憾预算的约束，然后重用连续的目标贪婪后缀，无需额外的近似决策或目标模型前向传播。ASD既不需要新的草稿模型，也不需要微调，当预算为零时完全退化为标准贪婪验证。实验表明，ASD在固定工作量吞吐量上比匹配的严格验证提高了3.05%–15.26%，并在七个Qwen3-14B + DSpark-14B任务上平均提升7.78%。在DeepSeek-V4-Flash（284B）与DSpark上，在FP4到FP8兼容设置中，ASD还使GSM8K和MATH-500上的验证器端接受率提高了约10%–16%。源代码公开于：https://github.com/Kissmetothemoon/ASD

## Abstract
Speculative decoding accelerates autoregressive generation by verifying a draft block with a target model in parallel. Under standard greedy verification, decoding stops at the first draft token that differs from the target argmax, discarding the remaining target-scored suffix. Although accepting such a mismatch changes the decoding trajectory, it can make a contiguous suffix reusable when its tokens remain target-greedy under the realized prefix. In this paper, we introduce \textbf{Approximate Speculative Decoding (ASD)}, a training-free verifier that replaces binary first-mismatch truncation with budgeted longest-prefix selection. ASD accepts selected mismatches subject to a local target-logit regret gate, a per-block exception cap, and a persistent request-level regret budget, then reuses the contiguous target-greedy suffix without additional approximate decisions or target-model forward passes. ASD requires neither a new draft model nor fine-tuning, and exactly reduces to standard greedy verification when the budget is zero. Experiments show that ASD improves fixed-workload throughput by $3.05\%$--$15.26\%$ over matched strict verification and averages a $7.78\%$ gain across seven Qwen3-14B + DSpark-14B tasks. On DeepSeek-V4-Flash (284B) with DSpark it also raises verifier-side acceptance by roughly $10\%$--$16\%$ on GSM8K and MATH-500 in an FP4-to-FP8 compatibility setting. The source code is publicly available at: https://github.com/Kissmetothemoon/ASD

## 1. 核心问题与研究动机

- **背景**：自回归 LLM 逐 token 生成，目标模型反复执行导致解码是主要推理瓶颈。推测解码（Speculative Decoding）通过轻量草稿模型并行提议并在目标模型中并行验证，显著提升吞吐量。
- **问题**：标准贪婪验证是**二元截断**的——一旦遇到第一个与目标 argmax 不一致的草稿 token 就立即停止，丢弃目标模型已经完成评分的后续后缀，**即使这些后缀在“已实现前缀”下可能仍是目标贪婪的**。同时，一个几乎与目标打平的 token 和一个被强烈排斥的 token 被同等对待。
- **核心洞察**：在 teacher-forced 验证中，后续目标行基于包含“早期失配”的草稿前缀计算；若接受该失配，则后续连续草稿后缀可能恰好是目标贪婪结果，可以**免费复用**，无需要额外的目标前向传播或近似决策。
- **研究意义**：ASD 在**速度与精确行为**之间提供了显式、可量化的权衡机制，而不是追求无损加速。

## 2. 方法论：近似推测解码（ASD）

### 核心思想

将“严格首失配截断”替换为**预算化最长连续前缀选择**：允许接受少量受控的“不匹配 token”，前提是这些失配满足三层约束，然后复用后续目标贪婪后缀。

### 关键技术细节

- **局部目标 logit 遗憾**（等式 3）：  
  `ri = zi(y*_i) - zi(x_i) ≥ 0`  
  衡量目标对 argmax 与草稿 token 的 log-probability 偏好差距。
- **归一化局部门限**（等式 7）：  
  `ri / qi ≤ g`，其中 `qi = K - i + 1` 是剩余提议长度。该门限允许接受**相对剩余机会而言代价较低**的早期失配。
- **持久请求级遗憾账簿**：每个请求维护 `(B, s)` 状态，`B` 为总预算，`s` 为已花费的遗憾。累计约束为 `Ct ≤ B - s`。
- **每块异常上限**：`Nt ≤ M`，防止异常在单个草稿块内过度集中。
- **可行性判定**：前缀 `x1:t` 可行当且仅当同时满足累计遗憾约束、异常数约束和局部门限约束；ASD 返回**最长可行前缀**。
- **后缀复用（命题 1）**：已接受的失配 token 之后，若后续草稿 token 等于对应目标 argmax，则它们在新历史下仍是目标贪婪的，无需再次花费预算或额外前向传播即可提交。
- **零预算退化**：`B = 0` 时完全恢复标准 token-ID 贪婪验证，即使存在最高 logit 并列也不接受。
- **向量化实现**：每位置可行性掩码 `fi` + 累计和 + 累计积即可求最长全真前缀，增加 `O(K)` 计算量，不增加目标前向传播。

## 6. 主要结论与发现

- **吞吐量收益**：ASD 在七个 Qwen3-14B + DSpark-14B 任务上提升 3.64%–11.73%（均值 **7.78%**）；全部 10 个跨家族单元为正提升 3.05%–15.26%（均值 7.52%），置信区间均严格大于零。

- **控制参数作用**：请求预算 B 是有效操作旋钮，收益在较大预算时平台化；门限 g 控制速度–精度前沿；块上限 M 防止失配集中。
- **大模型验证**：DeepSeek-V4-Flash（FP4→FP8 兼容设置）上 GSM8K 和 MATH-500 验证端接受率提升约 10%–16%。

## 7. 方法的优点

- **训练无关**：不需要重训草稿模型或微调目标模型，只修改验证器决策逻辑。
- **零成本退化**：`B=0` 时行为与严格贪婪验证完全一致，天然兼容现有系统。
- **低开销**：只需要目标最高 token 与最高 logit、以及约 `O(K)` 的累加运算，无需额外目标前向。
- **机制清晰**：三个约束分别对应局部价值（门限 g）、块级集中度（M）、请求级累计偏差（B），每个参数有明确操作含义。
- **跨架构泛化**：在 DSpark、EAGLE3、Medusa 三类草稿器中均有效，不依赖特定提议架构。
- **方法与评估分离**：吞吐量声明基于严格基准对齐，质量审计独立进行，避免混淆速度与正确性。

## 8. 不足与局限

- **不保证正确性**：ASD 不提供输出恒等性、语义保持或任务正确性保证，只限制“累计局部 logit 遗憾”，并非完整序列似然比约束。已验证质量下降较小，但无法排除在未测任务上的更大退化。
- **轨迹发散被明确接受**：哈希偏离率超 95%，意味着大多数生成轨迹与严格轨迹不同；对严格一致性有要求的场景（如可复现性、合规审计）不适用。

  - 主实验目标模型限 Qwen3 系列与 Llama-3.1-8B，未涵盖更大参数规模目标模型端到端吞吐量；
