## 摘要
多头潜在注意力（MLA）对于长上下文LLM推理日益重要，因为紧凑的潜在状态取代了不断增长的键值（KV）缓存，并减少了解码内存流量。然而，大多数强大的开放检查点使用多头或分组查询注意力（MHA/GQA），因此需要转换以获得MLA的缓存效率，而无需从头重新训练。推测解码提供了互补的加速，但其加速效果取决于草稿提议与目标验证之间的一致性。我们发现，直接的MHA/GQA到MLA的转换会显著降低这种一致性：低秩分解和RoPE处理引入了注意力函数误差，这些误差对于独立生成而言可能可以容忍，但会大幅降低草稿令牌的接受率。因此，我们将MLA草稿构建表述为功能性重建，而非缓存压缩。我们的端到端（E2E）方法优化每个转换后的MLA注意力模块，以在校准隐藏状态上重现其原始MHA/GQA对应模块的输出投影后响应。这种与转换器无关的转换后过程保留了转换后的缓存和推理图，既不需要验证器logits，也不需要验证器监督。我们评估了192种模型-转换器-后端-方法-任务配置，涵盖四个Llama/Qwen草稿-目标对、TransMLA和MHA2MLA、HF和vLLM，以及四个200提示的任务。在0.5个百分点的报告容差下，功能性重建实质性改善了64个匹配任务单元中的37个接受率，26个实际上保持不变，1个实质性下降。代码和评估工件可在 https://github.com/swyhahaha/FunctionalMLA 获取。

## Abstract
Multi-head latent attention (MLA) is increasingly important for long-context LLM inference because compact latent states replace the growing key-value (KV) cache and reduce decoding memory traffic. Yet most capable open checkpoints use multi-head or grouped-query attention (MHA/GQA), so conversion is needed to obtain MLA's cache efficiency without retraining from scratch. Speculative decoding offers complementary acceleration, but its speedup depends on agreement between draft proposals and target verification. We find that direct MHA/GQA-to-MLA conversion can sharply reduce this agreement: low-rank factorization and RoPE handling introduce attention-function errors that may be tolerable for standalone generation but substantially lower draft-token acceptance. We therefore formulate MLA draft construction as functional reconstruction rather than cache compression. Our end-to-end (E2E) method optimizes each converted MLA attention module to reproduce the post-output-projection response of its original MHA/GQA counterpart on calibration hidden states. This converter-agnostic post-conversion procedure preserves the converted cache and inference graph and requires neither verifier logits nor verifier supervision. We evaluate 192 model-converter-backend-method-task configurations spanning four Llama/Qwen draft-target pairs, TransMLA and MHA2MLA, HF and vLLM, and four 200-prompt tasks. With a 0.5-percentage-point reporting tolerance, Functional Reconstruction materially improves acceptance in 37 of 64 matched task cells, leaves 26 practically unchanged, and materially decreases one. Code and evaluation artifacts are available at https://github.com/swyhahaha/FunctionalMLA.

- **研究背景**：大语言模型（LLM）推理正日益受限于内存移动而非算术运算。自回归解码需读取不断增长的 KV 缓存，因此缓存表示效率直接影响服务延迟与吞吐。多头潜在注意力（MLA）通过缓存低维潜在向量和少量位置组件来压缩 KV 缓存，能显著降低解码内存流量。
- **核心矛盾**：多数可用的开源模型（如 Llama、Qwen）采用 MHA/GQA 架构，而非 MLA。已有的转换方法（如 TransMLA、MHA2MLA）可以将 MHA/GQA 模型迁移为 MLA 结构以实现缓存效率。**但论文发现，直接转换虽然可以得到一个可持续运行的生成模型，却无法得到好的推测解码草稿模型**。
- **问题的本质**：推测解码中，草稿模型和目标模型的分布一致性（随机采样时）或 top-1 token 一致性（贪心解码时）直接决定了 token 接受率与加速效果。转换过程中的两个关键误差——**低秩 KV 因子分解损失**与**RoPE 位置编码处理误差**——在独立生成场景下或许可以容忍，但会在推测解码中造成大量拒绝，导致草稿成为系统性开销。

## 2. 论文提出的方法论

### 2.1 核心思想

- 将 MLA 草稿构建**重新定义为功能重建（Functional Reconstruction）问题**，而非缓存压缩问题。
- 通过对每个转换后的 MLA 注意力模块进行训练，使其在**校准隐藏状态**上复现原始冻结 MHA/GQA 注意力模块的 **post-output-projection（W^O 之后）响应**，来直接优化草稿的条件分布行为。

### 2.2 方法属性

- **转换器无关（converter-agnostic）**：TransMLA 与 MHA2MLA 均可作为起点，不强依赖某一转换器的内部参数化。
- **纯后转换训练阶段（post-conversion training-only）**：不改变转换后的缓存结构和推理图。
- **无需验证器监督**：不用目标模型的 logits、激活、基准标签或生成目标。

### 2.3 技术细节与公式

- **原始 GQA 注意力**：给定隐藏状态，GQA 为每个 head 计算 query、key、value，并经过旋转位置编码（RoPE）与因果 softmax 注意力产生输出。
- **MLA 潜在 KV 瓶颈**：MLA 通过两个低秩矩阵（W^DKV 与 W^UKV）逼近累积的 K/V 映射。精确等价要求原始堆叠 K/V 矩阵的秩 ≤ r（潜在维度）。当该条件不满足时，转换必然留下残差。
- **RoPE 处理误差**：论文将 logit 误差分解为四项：保留 key 重构误差（q^T R δk）、位置路径误差（q^T(I − R)k_drop）、query 扰动项及其交互项。Softmax 将此 logit 残差映射为注意力权重误差，进而影响输出。
- **功能性重建目标函数**：
  - 对每层 ℓ，损失为：
    L^(ℓ)_E2E = E_b[ ‖ M_b ⊙ ( A^ℓ_MLA(H^ℓ_b) − sg[ A^ℓ_orig(H^ℓ_b) ] ) ‖²_F / ( D · Σ_t M_{b,t} ) ]
  - 其中：A^ℓ 表示经过注意力层及其固定输出投影（W^O）的完整输出；H^ℓ_b 为校准隐藏状态；M_b 为 valid token 掩码；sg 表示 stop-gradient。
- **训练范围**：仅更新转换器引入的 query 与 KV 投影参数；W^O 和非注意力参数冻结。E2E 意思是"从层输入到 post-output-projection 输出的完整注意力函数级重建"。

1. **功能重建显著提升草稿接受率**：在 64 个匹配单元格中，37 个实质性改善（>0.5 pp），26 个实际上不变，1 个实质性下降（−0.55 pp，Qwen-3B TransMLA vLLM 的 CNN/DM）。37 个改善中 12 个还伴随实质性吞吐提升。

3. **转换器–模型家族呈现清晰的交互模式**：
   - Llama–TransMLA：全部 16 个单元格改善；
   - Llama–MHA2MLA：全部 16 个单元格任务级持平；
   - Qwen–MHA2MLA：15/16 个单元格改善；
   - Qwen–TransMLA：6 个改善，9 个持平，1 个轻微下降。
   这表明功能重建并非对特定转换器有效，而是取决于各转换器初始化留下的可修复残差。
4. **后端依赖性具有局部性**：HF 下 20 个单元格改善、12 个持平；vLLM 下 17 个改善、14 个持平、1 个边缘退化。差异集中在 Qwen–TransMLA 路径，说明训练侧学到的修正能否"活下来"取决于后端算子实现。
5. **局部残差修复不能覆盖所有转换损伤**：严重不匹配的转换器/后端路径（如 Qwen-3B–TransMLA-vLLM 上 NQ 从 71.03% → 10.95% → 12.73%）只获得微小恢复，说明功能重建无法弥补低级秩信息丢失或不相容的张量并行/内核实现。
6. **吞吐量影响**：无需任何额外推理操作或缓存预算，接受率改善带来的吞吐增益受后端 MLA 内核成熟度和 TP 配置制约；当前实验无法给出相对于未转换 GQA 草稿的净端到端加速。

- **评估规模有限**：最大目标模型仅 8B，基准仅四类任务、各 200 提示、128 token 上限；缺少长上下文、更大模型系列、更多转换器及多种子统计评估。

- **缺少消融研究**：未对中间细节进行系统消融（如：对 Eq. (11) 的替代（不加 mask、加权重、不同校准数据量）的性能影响）。
- **应用边界**：方法无法修复低秩分配所排除的信息，也无法弥补后端不兼容的算子语义；严重不匹配的转换器–后端组合下收益有限，因此不能替代转换器质量与 MLA 内核优化。
