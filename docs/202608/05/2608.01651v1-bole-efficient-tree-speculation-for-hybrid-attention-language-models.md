## 摘要
混合注意力大语言模型将全注意力与循环线性注意力相结合，以降低长上下文推理成本，但其自回归解码仍然受内存限制。树形投机解码提供了一种有吸引力的加速路径，但现有的树推测系统是围绕全注意力模型的键值缓存设计的。在混合模型上，它们逐分支遍历循环层，并为每个提议节点实例化完整状态，导致验证延迟和瞬态内存随树和批次大小扩展性不佳。我们提出了Bole，一种内核-运行时协同设计，为混合注意力大语言模型实现高效的树推测。Bole将线性注意力递归转换为树结构闭式形式，并通过资源高效的GPU内核实现，并行验证所有提议节点，将线性注意力树验证加速了3.4到7.7倍。它无损地将推测状态更新编码为令牌级因子，并且仅重建采样后选中的状态，将瞬态状态内存减少了82到99倍，释放GPU容量给KV缓存。它集成到SGLang（一个广泛部署的生产级LLM服务引擎）中，将高效状态管理与针对完整混合前向计算的批次级验证预算相结合。在四种模型、两个GPU平台和多种数据集上，Bole实现了自回归解码离线解码吞吐量的最高4.72倍，以及最强树推测基线的最多2.03倍。在在线智能体工作负载下，与最强树推测基线相比，它分别将TTFT和TPOT降低了高达67.6%和49.9%。

## Abstract
Hybrid-attention large language models combine full attention with recurrent linear attention to reduce long-context inference costs, yet their autoregressive decoding remains memory-bound. Tree speculative decoding offers an attractive acceleration path, but existing tree-speculation systems are designed around the key--value caches of full-attention models. On hybrid models, they traverse recurrent layers branch by branch and materialize a full state for every proposal node, causing verification latency and transient memory to scale poorly with tree and batch sizes. We present Bole, a kernel--runtime co-design that enables efficient tree speculation for hybrid-attention LLMs. Bole transforms the linear-attention recurrence into a tree-structured closed form and realizes it with a resource-efficient GPU kernel, verifying all proposal nodes in parallel and accelerating linear-attention tree verification by 3.4--7.7$\times$. It losslessly encodes speculative state updates as token-level factors and reconstructs only the state selected after sampling, reducing transient state memory by 82--99$\times$ and freeing GPU capacity for KV caches. Its integration into SGLang, a widely deployed production LLM serving engine, couples efficient state management with a batch-wide verification budget calibrated to the complete hybrid forward. Across four models, two GPU platforms, and diverse datasets, Bole delivers up to $4.72\times$ the offline decode throughput of autoregressive decoding and up to $2.03\times$ that of the strongest tree-speculative baseline. Under online agent workloads, it reduces TTFT and TPOT by up to $67.6%$ and $49.9%$, respectively, over the strongest tree-speculative baseline.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **混合注意力模型趋势**：大语言模型（LLM）越来越多地服务长上下文和智能体（agent）工作负载。为降低长上下文推理成本，Qwen3.5、Kimi Linear 等混合注意力模型将全注意力（full attention）层与循环线性注意力（recurrent linear attention）层交错组合：全注意力层提供全局检索能力，线性注意力层以固定大小状态压缩前缀信息，从而降低每 token 服务成本。
- **核心瓶颈**：尽管混合注意力降低了长上下文成本，其自回归解码仍逐 token 调用目标模型，受限于内存带宽。
- **树投机解码的潜力**：树投机解码可利用内存受限解码中的闲置算力，一次验证多个候选 token 路径，显著提升解码吞吐。EAGLE-2 等方案可达 4–5.5 个平均接受 token 数和最高 5 倍加速。
- **现有方案的错位**：现有树投机系统（如 SpecInfer、DeFT、AdaServe、SGLang 的树投机路径）均围绕全注意力模型的 KV 缓存设计，不适用于混合模型的循环线性注意力。具体表现为三大瓶颈：
  - **L1 串行递归**：线性注意力层需逐分支、逐节点传播状态，验证延迟随树规模急剧增长（线性层 GPU 时间占比从 4% 升至 27%）；
  - **L2 状态爆炸**：每个候选节点需物化完整状态快照，在 Qwen3.5-122B-A10B 上 8 个 32 节点请求即消耗 36 GiB 临时内存，挤占 KV 缓存容量；
  - **L3 验证容量依赖硬件**：额外 token 是否“近乎免费”取决于 GPU 算力与内存带宽之比（A100 约 128 行即达拐点，GB10 约 256 行），固定预算不可靠。
- **论文定位**：Bole 是一个内核–运行时协同设计（kernel–runtime co-design），填补现有系统在混合注意力 LLM 上高效并行树验证与状态管理的空白。

## 2. 论文提出的方法论：核心思想、关键技术细节

### 总体架构
Bole 分离一次性离线校准（硬件感知验证容量）与循环服务流程（调度、草稿、验证、采样、状态提交），由调度器、目标模型执行引擎、采样与状态提交模块协同工作。

### 设计一：并行树求解器（解决 L1）
- **核心思想**：将线性注意力的逐节点循环递归转化为树结构闭式解，实现所有提议节点并行验证。
- **数学基础（三引理一定理）**：
  - **引理 1（路径分解状态）**：每个节点的前后状态均可分解为共享的前树状态 $S_{pre}$ 加上沿祖先路径的秩一校正项之和；
  - **引理 2（祖先掩码校正系统）**：将所有节点的校正向量堆叠，构成线性系统 $(I+G)U=R$，其中 $G$ 严格下三角、仅在祖先依赖处非零，精确对应顺序执行时的依赖关系；
  - **引理 3（深度有界幂零性）**：$G$ 是深度有界幂零矩阵（$G^{d+1}=0$），故 $(I+G)^{-1}=\sum_{m=0}^{d}(-G)^m$，逆为有限多项式；
  - **定理 1（Bole 闭式树验证）**：$O = D_P Q S_{pre} + C(I+G)^{-1}D_\beta(V - D_P K S_{pre})$，代数上精确等价于顺序执行，无需逐节点状态。
- **值平铺（value-tiled）GPU 内核**：将值维度划分为若干 tile，每个 CTA 处理一个值 tile；树因子 $G, C$ 在所有 tile 间共享；片上（on-chip）执行有限 Neumann 多项式传播（$d$ 轮固定张量核运算），中间结果不落 HBM；通过二维资源平铺（值宽度 $b_v$ + 键分块 $b_k$）平衡单 CTA 效率与 CTA 并发度。

### 设计二：分解式状态生命周期（解决 L2）
- **核心思想**：不物化每个分支的完整状态快照，而是保留一个不可变的规范状态 $S_{pre}$，以 token 级因子（P、K、U）表示所有候选分支的更新。
- **状态存储复杂度**：从 $\Theta(TH d_k d_v)$ 降至 $\Theta(H d_k d_v) + \Theta(TH(d_k + d_v + 1))$。
- **接受路径提交**：采样确定接受路径后，只需一次批量矩阵乘法 $S_{new} = P_a S_{pre} + (D_a K_a)^\top U_a$ 重建唯一所需状态。拒绝分支无需回滚或占用缓存。
- **三层生命周期划分**：规范状态持久保存；P、K、U 因子仅存至接受决策；G、C 及 Neumann 工作区仅为单层短期暂存。

### 设计三：硬件感知、批量共享的验证预算（解决 L3）
- **离线校准**：针对每个执行配置（模型、GPU、批大小桶、KV 长度桶、树模板），扫描总验证节点数，以完整混合前向延迟不超过普通解码延迟的 $(1+\epsilon)$ 倍为约束，确定批量级硬件高效验证容量 $B_{ver}(c)$。
- **批量级效用分配**：以草稿模型的累计路径概率为评分，在全局跨请求选择最高分节点填入预算，利用分数单调性保证每棵树的选定节点前缀连通。

### 生产集成（SGLang）
- CUDA Graph 原生的平铺随机森林执行（容量分桶图捕获，树拓扑每次变化但地址和内核形状固定）；
- 跨层统一状态提交（一次设备端启动完成所有线性层的接受状态重建）；
- 无气泡 GPU 执行（选择、物化、验证、采样、提交全部在 GPU 上完成，避免主机同步间隙）。

## 6. 论文的主要结论与发现

- **内核效率**：Bole 的并行树验证将线性注意力树验证加速 3.4–7.7 倍；关闭状态物化并保持核内工作，L1/共享内存吞吐提升 1.8–4.1 倍，HBM 写流量从 824 MB 降至 9.8 MB（84 倍缩减）。
- **内存效率**：分解式状态生命周期将瞬态状态内存减少 82–99 倍；在 122B 模型上，非缓存投机开销从 AdaServe 的 25.04 GiB 降至 6.52 GiB，释放大量 KV 缓存容量；使 Qwen3.5-27B 在批大小 8 时不再 OOM。
- **离线吞吐**：Bole 相对自回归解码几何平均加速 2.74 倍，相对最强投机基线几何平均加速 1.26 倍；峰值达自回归的 4.72 倍、最强基线的 2.03 倍（GB10 上）。
- **在线延迟**：相对最强投机基线，TTFT 降低最高 67.6%，TPOT 降低最高 49.9%；前缀缓存命中率 90.8%/92.6%，接近 AR 基线（89.8%/93.3%）并大幅超越其他树投机系统（约 58–70%）。
- **预算敏感性**：最优验证预算依赖具体硬件（A100 为 128 节点，GB10 为 256 节点），验证了硬件感知预算的必要性。

## 7. 优点

- **算法严格性**：通过引理–定理体系给出精确的闭式解证明，无近似损失，保留目标模型输出分布；有限 Neumann 级数深度有界，保证实现可行性。
- **内存设计优雅**：因子化状态生命周期以极小内存代价解决分支状态分歧问题，状态复杂度与状态维度解耦，在大型模型上优势显著。
- **系统集成度高**：完整集成到 SGLang 生产引擎，兼容连续批处理、CUDA Graphs、张量并行、GPU 驻留状态提交等生产特性，非玩具原型。
- **预算设计有洞察**：将验证容量从“每请求固定节点数”转变为“批量共享 + 硬件校准 + 概率效用分配”，更贴近真实服务场景。
- **实验严谨**：包含内核隔离实验、预算敏感性分析、组件消融、在线真实智能体流量回放，多维度验证了每个设计环节的贡献。
- **通用性**：解码端优化与模型无关，对所有基于 Gated DeltaNet 类循环的混合注意力模型均适用（Kimi Linear 等）。

## 8. 不足与局限

- **模型泛化性**：仅评估 Qwen3.5 模型家族，未覆盖 Kimi Linear 等其他混合注意力架构；理论虽通用，但缺少跨架构实证。
- **硬件覆盖不完整**：122B 模型仅在 A100 平台评估（GB10 内存不足可理解），但 27B 在 GB10 的可用性也表明统一内存平台上的大模型可服务性受限；此外未覆盖最新 Blackwell 数据中心 GPU（如 B200）等。
- **草稿策略单一**：仅使用模型原生 MTP 头作为草稿器，未测试 EAGLE-2 等外部草稿器的适配性。
- **预算校准的静态性**：离线校准的验证容量基于固定配置桶，无法反映运行时动态变化（如其他任务抢占 GPU、频率变化、热节流等）。
- **相关工作对比**：未直接与 STree（针对 SSM 的树投机工作，论文称其不适用于门控线性注意力）做实验对比，仅从理论层面说明差异。
- **训练/量化因素未探讨**：未涉及量化权重、投机解码与量化交互的行为。
- **开源未见**：论文未提供代码仓库链接或开源计划声明，可复现性存疑（按当前学术规范，这属于常见但值得指出的局限）。
