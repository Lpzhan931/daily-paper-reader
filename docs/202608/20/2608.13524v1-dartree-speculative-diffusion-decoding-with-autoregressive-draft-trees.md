## 摘要
投机性解码通过并行验证多个草稿令牌，无损地加速了自回归语言模型。基于扩散的草稿器通过并行预测整个令牌块进一步降低了提议延迟，但它们的逐位置分布是边缘分布，而不是根据每条草稿路径上选择的令牌进行条件化。现有的循环校正沿单一草稿链整合因果信息，而基于扩散的树构建在扩大候选覆盖范围的同时，并未沿各个分支携带这种校正。我们引入了DARTree，一种无需训练的投机性解码方法，将预训练的自回归校正头从链扩展到树。DARTree首先通过在单个批次中扩展并评分每个深度的所有节点来构建固定宽度的候选树，然后仅应用最佳优先剪枝来选择验证树，从而将AR头推理与顺序堆操作解耦。在七个数学、代码和聊天基准测试中，DARTree在所有四种模型-温度配置中取得了最高的平均接受长度和加速比，每轮验证最多接受12.97个令牌，较同设置下的DFlash高98.6%，较Domino高27.9%，并达到相对于本地测量自回归解码最高9.73×的无损加速。

## Abstract
Speculative decoding losslessly accelerates autoregressive language models by verifying multiple draft tokens in parallel. Diffusion-based drafters further reduce proposal latency by predicting an entire token block in parallel, but their position-wise distributions are marginal rather than conditioned on tokens selected along each draft path. Existing recurrent correction incorporates causal information along a single draft chain, whereas diffusion-based tree construction broadens candidate coverage without carrying this correction along individual branches. We introduce DARTree, a training-free speculative decoding method that extends a pretrained AR correction head from chains to trees. DARTree first constructs a fixed-width candidate tree by expanding and scoring all nodes at each depth in a single batch, and then only applies best-first pruning to select the verification tree, decoupling AR-head inference from sequential heap operations. Across seven math, code, and chat benchmarks, DARTree achieves the highest average acceptance length and speedup in all four model--temperature configurations, accepting up to 12.97 tokens per verification round, 98.6\% more than DFlash and 27.9\% more than Domino in the same setting, and reaching up to 9.73$\times$ lossless speedup over locally measured autoregressive decoding.

## 1. 核心问题与整体含义（研究动机和背景）

推测解码（Speculative Decoding）通过并行验证多个草稿 token 来无损加速自回归语言模型推理，但其效率受限于草稿生成方式：

- **自回归草稿器**：逐 token 预测，延迟随草稿长度线性增长。
- **扩散式块草稿器**（如 DFlash）：一次前向预测整个 token 块，降低延迟，但其逐位置分布是**边缘分布**，未沿具体草稿路径进行条件化，与目标模型的因果条件分布存在偏差。
- **现有因果修正**（如 Domino）：仅沿**单一草稿链**传播条件信息，无法对树中不同分支提供路径特定的修正。
- **扩散树构建**（如 DDTree）：扩大候选覆盖范围，但**未携带**沿分支的因果修正。

**DARTree 的核心贡献**：将预训练的自回归修正头从**链（chain）**扩展到**树（tree）**，在无需训练的前提下，同时兼顾扩散模型的并行候选覆盖能力与自回归模型的因果条件化能力，显著提升推测解码的接受长度与端到端加速比。

## 2. 方法论

**核心思想**：将修正头推理从顺序堆操作中解耦——先以深度方式批量构建固定宽度候选超树，再通过延迟最佳优先剪枝选出紧凑验证树，最后用树注意力一次前向验证。

**关键技术细节**：

1. **深度并行超树构建**：
   - 块并行骨干网络执行一次，生成共享表示和基础 logits。
   - 每个深度从 top-K 候选 token 中扩展节点，逐深度批量调用修正头。
   - 依赖顺序跨深度保持，但每一深度内的修正、评分、选择、状态更新均张量化并行。
   - 使用固定层宽 W 控制每层保留节点数。

2. **路径特定评分函数**：
   $$s_\beta(u_{1:d}) = \sum_{i=1}^{d} \log e_{q_i}(u_i) + \beta d$$
   其中 $\beta \le 0$ 为深度惩罚，保证祖先得分不小于后代，从而满足前缀封闭性。

3. **延迟最佳优先剪枝**：
   - 先构造比最终验证树更宽的候选超树，待全部节点得分计算完毕后。
   - 再执行一次全局 top-B 选择（单次操作），替代顺序堆操作。
   - **引理 1** 保证：在 $\beta \le 0$ 且平局时优先祖先的条件下，全局 top-B 与顺序 best-first 堆选择得到的树完全一致。

4. **树验证**：使用树注意力掩码，单次前向并行评分所有分支，与标准树验证流程一致。

**算法流程**（Algorithm 1）：
- 初始化根节点和根修正状态。
- 对每个深度 d = 1 到 γ：
  - 选取 top-K 候选 token。
  - 批量修正所有活跃前缀在候选集上的分布。
  - 按 s_β 分数保留全局 top-W 个子前缀。
  - 并行更新修正状态。
- 超树构建完成后，按 s_β 全局 top-B 剪枝，输出验证树。

## 7. 优点

1. **无需训练**：直接复用预训练修正头，即插即用，适用范围广。
2. **构建与搜索解耦**：将修正头推理与顺序堆操作分离，消除节点级串行瓶颈，首次使路径条件化修正可在树中批量执行，这是对现有方法的重要结构性改进。
3. **稀疏性合理**：通过深度惩罚保证前缀封闭性，使全局 top-B 操作与 best-first 搜索等价，理论上严谨。
4. **通用性强**：不依赖特定修正架构（循环头或 Markov 头均可适配），兼容性优于 Domino 等专有方法。
5. **实验设计扎实**：覆盖多领域基准、两种采样温度、多个消融维度和并发场景，且对超参数敏感性进行了系统分析。

## 8. 不足与局限

1. **依赖预训练修正头**：对没有修正头的朴素扩散草稿器不适用，额外训练成本需计入实际部署考虑。
2. **计算开销增加**：树验证比非树方法消耗更多 FLOPs；并发场景下高负载时收益迅速递减（C=32 时部分配置加速比低于 1.1×），适用范围偏受限。
3. **实验覆盖有限**：未与主流自回归草图树方法（EAGLE-2/3、Medusa）对比；仅在 4B/8B 模型上验证，未覆盖更大规模模型；未报告多次运行的置信区间。
4. **单点例外**：AIME25 + Qwen3-8B + T=1 时加速比略逊于 DDTree，显示在高难度数学+大模型+随机采样组合下收益存在不确定性。
5. **并发评估后端不一致**：主实验在 HF Transformers 上进行，并发实验在 SGLang 上进行，可能引入框架偏倚。
6. **验证阈值未分析**：没有系统讨论可接受长度饱和时是否应调整块长度或深度（仅作为未来工作提及）。
