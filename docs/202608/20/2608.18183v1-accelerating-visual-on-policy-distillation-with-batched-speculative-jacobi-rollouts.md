## 摘要
视觉在线策略蒸馏（OPD）通过从当前学生模型生成的轨迹中学习，改进了紧凑视觉自回归模型的训练。然而，这些在线展开仍然以自回归解码逐词生成，这为每次在线策略训练步骤增加了大量成本。推测雅可比解码（SJD）提供了一种替代方案，因为它可以在没有辅助草稿模型的情况下并行处理多个令牌，但原始方法是为单序列推理设计的。我们引入了HB-SJD，一种用于视觉OPD的批量SJD展开后端。HB-SJD允许每个图像根据其自身的解码进度独立推进，而不同序列位置的图像仍然在批量模型前向传播中进行验证。当图像完成时，HB-SJD在全量执行和紧凑执行之间切换，以减少后续展开轮次的成本。HB-SJD仅替换学生模型的展开后端，而教师模型、蒸馏目标和优化过程保持不变。与LlamaGen的实验表明，HB-SJD在保持蒸馏学生模型生成质量的同时，大幅减少了展开和端到端的训练时间。

## Abstract
Visual on-policy distillation (OPD) improves the training of compact visual autoregressive models by learning from trajectories generated by the current student. However, these online rollouts are still produced token by token with autoregressive decoding, which adds substantial cost to every on-policy training step. Speculative Jacobi Decoding (SJD) provides an alternative because it can process multiple tokens in parallel without an auxiliary draft model, but the original method is designed for single-sequence inference. We introduce HB-SJD, a batched SJD rollout backend for visual OPD. HB-SJD allows each image to advance independently according to its own decoding progress, while images at different sequence positions are still verified in batched model forwards. As images finish, HB-SJD switches between Full and Compact execution to reduce the cost of later rollout rounds. HB-SJD only replaces the student rollout backend and leaves the teacher, distillation objective, and optimization procedure unchanged. Experiments with LlamaGen show that HB-SJD substantially reduces rollout and end-to-end training time while preserving the generation quality of the distilled student.

## 1. 核心问题与整体含义（研究动机与背景）

- **研究背景**：视觉自回归（Visual Autoregressive, AR）模型在图像生成上表现出色，但模型规模庞大。知识蒸馏是将大模型能力迁移到紧凑学生模型的有效手段。近年来的视觉在线策略蒸馏（On-Policy Distillation, OPD）方法（如 GKD、VarKD）让学生模型在训练过程中自行生成轨迹，再由教师模型监督，以缓解训练与推理之间的分布不匹配问题。
- **核心问题**：OPD 将自回归生成直接引入了训练循环。学生模型必须先逐 token 地生成一段后缀轨迹（Rollout），之后才能进行教师-学生蒸馏计算。即使使用 KV 缓存，生成长度为 L 的后缀仍需 L 次串行解码步骤。该 Rollout 过程位于训练关键路径上，是每次 on-policy 更新的主要开销来源，显著拖慢训练速度。
- **研究空白**：现有加速方法（如使用辅助草稿模型的推测解码）在 OPD 场景中有局限——训练中学生策略持续变化，辅助草稿模型需要不断同步和适应，引入额外成本。而 Speculative Jacobi Decoding（SJD）无需辅助草稿模型，通过复用同一学生模型的 Jacobi 迭代预测作为草稿，但原始 SJD 仅面向单序列推理，不适用于大批量训练的视觉 OPD。
- **核心挑战**：如何将 SJD 高效扩展到大批量视觉 OPD 场景：既不能逐图像单独运行（丢失 GPU 并行性），也不能同步锁步运行（快的图像必须等待慢的图像）。

## 2. 方法论：HB-SJD

### 2.1 核心思想

HB-SJD（Hybrid Batched Speculative Jacobi Decoding）是面向视觉 OPD 的批量 SJD 滚动后端。**它仅替换学生模型的 rollout 后端，不改变教师模型、蒸馏目标和优化过程**。核心设计包括三部分：

### 2.2 关键技术细节

1. **独立推进（Independent Progress）**：
   - 每个图像维护自己的已提交游标（committed cursor）和 Jacobi 窗口（W 个草稿 token）。
   - 不同图像可处于不同的序列位置，在一次批量前向中共同验证。
   - 验证完成后，各图像独立提交各自接受的 token 数，互不等待。
   - 草稿初始化复用前一次验证的预测，并用固定历史偏移 H 的已提交 token 填充剩余位置，利用视觉 token 的空间局部性而非随机初始化。

2. **批量验证（Batched Verification）**：
   - 对每个活跃图像，用最后一个已提交 token 后接草稿窗口构成验证输入。
   - 通过位置索引和 KV-cache 定位，将不同进度的图像合并到一个批量学生前向中处理。
   - 支持两种验证策略：
     - **贪心验证**：草稿 token 等于学生贪心预测时接受（公式 4），第一个不匹配处停止，匹配的前缀全部提交，当前学生 argmax 作为替换 token 提交。
     - **概率验证**：参照原始 SJD 的接受概率 α = min(1, p/q)（公式 5），拒绝时按 [p−q]+ 校准分布重采样。兼容未来 SJD 优化。
   - 使用融合后的引导 logits 进行验证，拒绝后的替换 token 作为下一轮起始 token，无需额外 cache-repair 步骤。

3. **混合全量/紧凑执行（Hybrid Full/Compact Execution）**：
   - 独立推进导致图像在不同时间完成，活跃图像数逐渐减少。
   - **Full 执行**：保持原始物理批形状，已完成图像视为逻辑不活跃，不更新 rollout 状态。
   - **Compact 执行**：仅处理活跃图像，访问其对应的 KV-cache 行，但子集索引操作有额外开销。
   - 实测表明：活跃图像多时 Full 更高效，活跃图像少时 Compact 更优。
   - HB-SJD 在训练前通过轻量级、与数据无关的延迟测试确定硬件开关阈值 γ，并在训练中固定：活跃数 > γ 时用 Full，≤ γ 时用 Compact（公式 6）。

## 6. 主要结论与发现

- **HB-SJD 显著加速 rollout**：在 GKD 上实现 1.48×（LlamaGen-B）和 1.56×（LlamaGen-L）的 rollout 加速；在 VarKD 上达到 1.58× 和 1.65×。端到端训练时间加速约 1.18×。
- **生成质量无损**：FID、IS、Precision、Recall 均与 AR rollout 基线持平。例如 GKD+FID 4.95 vs. 4.96，VarKD 4.75 vs. 4.73。
- **独立进度是关键**：批量同步 SJD（4239ms）甚至慢于 Cached AR（3982ms），而独立进度（3275ms）带来 1.216× 加速。
- **混合执行优于单一模式**：Hybrid 比 Full 降低 15.4% 延迟，比 Compact 降低 10.3% 延迟。
- **加速效果随 rollout 变长更显著**：后缀从 144 tokens 增至 461 tokens 时，加速比从 1.392× 提升至 1.699×。
- **对超参数不敏感**：H 和 γ 在合理范围内波动时性能稳定，验证了数据无关硬校准的可行性。
- **训练全程有效**：在 2K、12K、22K 步均保持 1.48–1.53× 加速。
- **贪心优于概率验证**：贪心验证加速比（1.613×）高于概率验证（1.500×），但概率验证兼容未来 SJD 优化。

## 7. 优点

- **即插即用设计**：仅替换 rollout 后端，不改变蒸馏目标、教师模型和优化流程，易于集成到现有视觉 OPD 方法中。
- **无附加模型成本**：SJD 复用学生自身预测作为草稿，无需训练或维护辅助草稿模型，特别适合策略持续变化的训练场景。
- **工程洞察扎实**：通过实测数据（图 2、图 3）揭示批同步调度和固定执行模式的低效，设计了有数据支撑的独立进度 + 混合执行方案。
- **验证策略灵活**：同时支持贪心验证和概率验证，后者与标准 SJD 流程兼容，为后续集成更先进的 SJD 变体留有余地。
- **系统性能优化全面**：利用视觉 token 空间局部性改进草稿初始化；KV-cache 无需额外修复步骤；训练前进行一次性硬件校准。
