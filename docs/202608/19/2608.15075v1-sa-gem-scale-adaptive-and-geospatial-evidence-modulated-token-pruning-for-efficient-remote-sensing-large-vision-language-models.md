## 摘要
遥感大型视觉语言模型（RS-LVLMs）推进了地球观测图像的多模态理解，但其性能从根本上受限于高分辨率处理，因为视觉令牌数量随线性输入分辨率呈二次方增长，而重要的视觉证据本质上稀疏且在扩展序列中被不断稀释。现有令牌剪枝方法大多依赖与尺度无关的分辨率策略和孤立的显著性线索，限制了任务对齐的粒度适应性和整体证据保留。为解决这一问题，我们提出了尺度自适应与地理空间证据调制令牌剪枝（SA-GEM），这是一种即插即用框架，将任务自适应的令牌粒度分配与整体的地理空间令牌重要性调制统一起来。具体而言，一个轻量级路由器根据查询依赖的令牌粒度选择分辨率，而令牌重要性调制器联合建模任务相关性、空间结构和局部冗余，以保留整体的地理空间证据。我们表明，更高分辨率并非普遍有益，一旦达到足够的粒度，令牌质量比令牌数量更为重要。跨多个基准的实验表明，SA-GEM在准确性和效率上均优于现有剪枝方法。在XLRS-Bench上，它以2.4倍的总推理加速在准确性上超过GeoLLaVA-8K 2.3%。

## Abstract
RS-LVLMs have advanced multimodal understanding of Earth observation imagery, yet their performance is fundamentally constrained by high-resolution processing, as visual token counts grow quadratically with linear input resolution while important visual evidence is inherently sparse and increasingly diluted across the expanded sequence. Existing token pruning methods largely rely on scale-agnostic resolution policies and isolated importance cues, limiting task-aligned granularity adaptation and holistic evidence preservation. To address this, we present Scale-Adaptive and Geospatial Evidence-Modulated Token Pruning (SA-GEM), a plug-and-play framework that unifies task-adaptive token granularity allocation with holistic geospatial token importance modulation. Specifically, a lightweight router selects the resolution based on query-dependent token granularity, while a token importance modulator jointly models task relevance, spatial structure, and local redundancy to preserve holistic geospatial evidence. We show that higher resolution is not universally beneficial and, once sufficient granularity is reached, token quality matters more than token quantity. Experiments across various benchmarks demonstrate that SA-GEM achieves consistent gains in both accuracy and efficiency over existing pruning methods. On XLRS-Bench, it surpasses GeoLLaVA-8K by 2.3% in accuracy with a 2.4 times total inference speedup.

## 2. 论文提出的方法论：核心思想与关键技术细节

### 总体框架
SA-GEM 是一个**即插即用**（plug-and-play）框架，包含两大模块：
1. **任务自适应粒度路由（Task-Adaptive Granularity Routing）**
2. **整体地理空间证据调制（Holistic Geospatial Evidence Modulation）**

### 模块一：任务自适应粒度路由
- 训练一个**轻量级 MLP 路由器**，将查询（query）嵌入映射到四种有序粒度级别：**全局（global）、区域（regional）、组合（compositional）、细粒度（fine-grained）**。
- **伪标签生成**：由多个基础模型独立预测粒度级别，通过**多数投票**聚合，分歧时取向下平均级别，无需人工标注。
- 查询表示通过**掩码均值池化**获得：$\bar{q} = \frac{\sum_{j=1}^{M} m_j q_j}{\sum_{j=1}^{M} m_j}$。
- 路由器输出软分布 $p = \text{softmax}(f_r(\bar{q}))$，推理时选择粒度组 $\hat{g} = \arg\max_g p_g$，并检索对应的运行配置 $(R, \rho, \psi)$（分辨率、剪枝比、小波设置），这些配置在留出集上选定。

### 模块二：整体地理空间证据调制
对每个视觉令牌计算综合重要性得分，由三种互补证据组成：

**证据1：任务相关语义对齐得分（$E_t$）**
- 将最后一层自注意力的输出**解耦**为残差分量和注意力分量，利用注意力分量保留更细粒度视觉语义的特性；
- 计算注意力令牌特征 $a_i$ 与查询表示 $q$ 的**余弦相似度**：$E_t^i = \cos(a_i, q)$；
- 用于在复杂遥感背景中定位关键目标，防止被视觉显著但任务无关的区域主导。

**证据2：尺度自适应空间结构得分（$E_s$）**
- 对输入图像进行 **L 级离散小波变换（DWT）**，提取水平、垂直、对角方向的高频子带；
- 聚合多尺度高频响应得到令牌级结构得分：$E_s = \sum_{\ell=1}^{L} U_t(\sum_{s \in \{LH,HL,HH\}} |I_\ell^s|)$；
- 使边界、结构和地理过渡区域的令牌获得更高重要性，并根据所选分辨率自适应调整小波基和分解层数。

**证据3：动态局部冗余掩码（$E_d$）**
- 计算令牌与其 $w \times w$ 局部窗口内邻居的**特征差异 + 空间距离**归一化代价：$D_{ij} = \frac{\|v_i - v_j\|_2^2}{\sigma_v + \epsilon} + \lambda \frac{\|p_i - p_j\|_2^2}{\sigma_p + \epsilon}$；
- 通过**四分位距（IQR）准则**（$\alpha = 1.5$）自适应判定局部冗余令牌，生成二值掩码 $M_d$；
- 抑制水体、农田、森林等大面积同质区域中的冗余令牌。

### 最终得分与令牌选择
$$S_i = \mathcal{N}(E_t^i \cdot E_s^i) - M_d^i$$
- 乘法耦合使显式查询时任务相关性主导、弱关联查询时结构引导主导；
- 冗余掩码通过降低最终得分抑制冗余令牌；
- 最后通过 **Top-K 选择**保留得分最高的 $K = \lfloor (1-\rho)N \rfloor$ 个令牌送入 LLM 解码。

### 整体流程
图像输入 → 视觉编码器 → 路由器选择分辨率与剪枝比 → DWT/特征仿射/解耦注意力分别建模结构、冗余、任务相关性 → 融合得分 → Top-K 剪枝 → 投影器 → LLM 生成答案。

## 6. 论文的主要结论与发现

1. **更高分辨率并非普遍有益**：在 XLRS-Bench 上，4032×4032 的 HR 输入（12.5% 保留率）优于 8064×8064 的 UHR 输入，说明单纯提高分辨率会稀释证据而损害性能。
2. **任务依赖的粒度趋势**：全局任务偏好低分辨率，区域/组合/细粒度任务逐步偏好更高分辨率；UHR 仅对细粒度感知类任务（如 OCL、OMS、OSR）有明显收益。
3. **令牌质量 > 令牌数量**：一旦保留足够的证据，增加保留比例反而可能降低性能（如 4032 分辨率下 12.5% 保留优于 25% 保留）。
4. **三证据互补性**：结构线索单独贡献最大（40.45%），任务相关性 + 结构联合提升 2.09%，冗余抑制在结合结构时增益更大。
5. **方法有效性**：SA-GEM 在 XLRS-Bench 上超越 GeoLLaVA-8K **2.3%**（53.8% vs 51.5%），同时实现 **2.4 倍总推理加速**、2.8 倍编码端加速、TFLOPs 降低 **60.8%**；在 MMERealWorld-RS 和 LRS-VQA 上也优于 RFM-DIP 所有分辨率设置。

## 7. 优点与亮点

- **问题发现新颖**：通过系统性实验揭示了"分辨率–任务粒度"的非单调关系，纠正了"越高分辨率越好"的默认假设，为 RS-LVLM 部署提供实用指导。
- **即插即用架构**：无需重新训练 LLM 或视觉编码器，可替换现有剪枝模块，落地成本低。
- **整体性证据建模**：将任务语义、空间结构（频域）、局部冗余（空域）三方面证据统一，避免了单一准则的盲区，特别是 DWT 捕获地理结构信息的设计很有遥感特色。
- **动态自适应机制**：按查询动态选择分辨率 + 按图像内容动态判定冗余（IQR），实现了图像级和查询级的双重自适应。
- **实验系统性与可视化质量高**：多维度消融、效率-精度联合报告、可视化清晰展示了方法相对基线的优势（如正确回答"船在左下角"而基线错误）。
- **结论可操作性强**：给出了不同任务类型的分辨率选取建议，对工程实践有直接参考价值。
