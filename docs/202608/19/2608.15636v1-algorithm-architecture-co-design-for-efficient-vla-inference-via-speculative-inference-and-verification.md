## 摘要
视觉-语言-动作（VLA）模型在具身AI领域展现了显著能力，但其高计算成本和有限的动作预测长度阻碍了实时部署。尽管Dadu-Corki作为面向高效具身AI的专用加速器已被提出，但它并未利用机器人与环境之间的固有交互模式，导致预测动作长度相对较短。我们观察到，机器人环境自然地在主动状态（精确动作至关重要）与非主动状态（动作对任务成功影响有限）之间交替。这一洞察带来了一种新的调度机会：在非主动状态下进行长动作长度的投机预测，并在主动状态下进行选择性验证。我们提出了SpecVLA，一个算法-系统协同设计框架，能够自适应地平衡动作长度、推理延迟和任务可靠性。在算法方面，SpecVLA引入了一种状态感知的VLA推理执行范式，以及一种利用差分残差和块状混合精度量化构建更小验证模型（sVLA）的硬件友好方法。在系统方面，我们开发了一种由GPU和机器人专用硬件模块组成的异构架构，以及一种通过并行执行解耦VLA和sVLA的投机数据流。在LIBERO和ManiSkill基准上对OpenVLA和RDT的全面评估表明，SpecVLA在保持任务成功率的同时显著降低了端到端延迟。通过实现具有及时验证的长动作长度投机预测，SpecVLA实现了高效率和可靠性的实时机器人操作。

## Abstract
Vision-Language-Action (VLA) models have demonstrated remarkable capabilities in the field of embodied AI, but their high computational cost and limited predicted action length hinder real-time deployment. Although Dadu-Corki, a dedicated accelerator for efficient embodied AI, has been introduced, it does not exploit the inherent interaction patterns between the robot and its environment, which results in a relatively short predicted action length. We observe that robotic environments naturally alternate between active states-where precise actions are crucial-and inactive states-where actions have limited impact on task success. This insight enables a new scheduling opportunity: long-action-length speculative prediction in inactive states, paired with selective verification in active states.   We propose SpecVLA, an algorithm-system co-design framework that adaptively balances action length, inference latency, and task reliability. On the algorithm side, SpecVLA introduces a state-aware VLA inference execution paradigm and a hardware-friendly construction of a smaller verification model (sVLA) using differential residuals and block-wise mixed-precision quantization. On the system side, we develop a heterogeneous architecture consisting of a GPU and a robotic-specific hardware module, along with a speculative dataflow that decouples VLA and sVLA through parallel execution. Comprehensive evaluations on OpenVLA and RDT across LIBERO and ManiSkill benchmarks show that SpecVLA reduces end-to-end latency significantly while preserving task success rate. By enabling long-action-length speculative prediction with timely verification, SpecVLA achieves real-time robotic manipulation with both high efficiency and reliability.

- **问题根源**：视觉-语言-动作（VLA）模型虽在具身AI中展现强大能力，但推理延迟过高（超过600ms），无法满足实时机器人控制需求（实时要求通常 <100ms）。
- **现有方案不足**：已有的VLA专用加速器Dadu-Corki虽通过GPU服务器+FPGA的异构架构缩短了延迟，但**未利用机器人与环境交互的固有模式**，每次推理仅能预测 <4 个动作，性能提升受限。
- **关键洞察**：
  - **观察1**：机器人动作可划分为**主动状态**（需精确控制，如抓取/放置）与**非主动状态**（移动中，中间动作对结果影响有限），两者对精度的需求不对称。
  - **观察2**：连续环境帧间存在高度的**时间冗余性**，可用轻量化的量化小模型（sVLA）验证动作，但sVLA在长序列预测下精度退化明显。
  - **观察3**：云平台GPU与NPU的异构性为VLA与sVLA的并行执行提供了天然条件。
- **研究意义**：通过算法与架构的协同设计，在非主动状态大胆推测长动作序列、在主动状态用轻量模型验证，从而兼顾**低延迟**与**高任务成功率**，推动VLA模型走向实时机器人操控的实际落地。

## 2. 提出的方法论（核心思想与技术细节）

### 2.1 整体框架：Speculative VLA Inference and Action Verification (SpecVLA)
- **核心思想**：以状态感知的自适应执行范式取代传统的固定长度预测——在非主动状态用VLA预测长动作序列直接执行；在主动状态用sVLA对每个动作先验证再执行。
- **动作验证流程**：若预测动作A与sVLA生成的期望动作A'差异在阈值内则接受执行，否则拒绝该预测并重新调用VLA生成新动作序列。

### 2.2 算法核心组件

| 组件 | 技术方案 | 关键细节 |
|------|----------|----------|
| **环境状态预测** | 基于机械臂与物体的欧氏距离及抓手开合状态的阈值判断 | 距离 > 阈值且抓手张开 → 非主动状态；否则 → 主动状态 |
| **动作验证** | 加权L1距离 + min-max归一化 | 权重 w[k] = 1/σ[k]（方差倒数加权），阈值 Ts 控制接受率 |
| **sVLA构建** | 差分残差计算 + 块级混合精度量化 | 对相邻帧特征做差获得窄分布残差；按块求和与阈值Tz、Th比较，分为0位/4位/8位块；高精度块进一步拆分为低高位分量统一数据通路 |

### 2.3 系统架构设计
- **异构架构**：GPU执行全精度VLA推理，机器人专用硬件模块执行sVLA验证及状态预测。
- **推测数据流**：解耦VLA与sVLA的依赖——VLA推理**推测性提前执行**，无需等待sVLA验证结果；sVLA验证失败时发出终止/回滚信号。
- **专用硬件模块**：
  - SIMD PE阵列（8×32×32个4位×16位PE单元），统一低精度数据通路；
  - **可重构状态预测器**，将环境状态预测与动作验证两种运算统一到同一距离计算流水线，降低硬件开销；
  - **预处理模块**，集成残差生成、块级量化与块标签生成，消除中间数据搬移。

## 6. 主要结论与发现

- **效果显著**：SpecVLA相比NVIDIA A100 GPU、Dadu-Corki-ADAP分别获得**2.9×**和**1.9×**端到端加速，相比CPU加速达12.1×；
- **成功率保持**：在无噪声环境下成功率损失可忽略；在带传感器噪声的鲁棒性测试中甚至平均高出基线0.3%；

## 7. 优点（方法/实验亮点）

- **洞察深刻**：将机器人环境划分为主动/非主动状态并据此设计差异化的预测策略，视角新颖、贴合真实机器人操控需求；
- **算法-架构协同**：从残差分布特性出发设计硬件友好的量化方案，并从硬件实现角度倒推算法调整（块拆分统一精度），体现了真正的协同设计（Co-Design）而非简单拼接；
- **推测数据流创新**：通过推测执行解耦VLA与sVLA依赖，引入回滚机制保障安全性，有效隐藏验证延迟；
