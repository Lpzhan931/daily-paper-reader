## 摘要
推测解码通过草拟多个令牌以供并行验证来加速大型语言模型推理，其效率主要由每轮解码中选择的推测长度决定。现有的动态推测方法通过估计将有多少令牌被接受来选择推测长度，这对于按顺序生成令牌的自回归草拟器是合理的。然而，最近的基于扩散的草拟器以显著更低的草拟成本并行生成候选块，将关键问题从生成多少个令牌转变为验证多少个生成的令牌是值得的。因此，我们将动态推测长度选择重新表述为期望加速优化，并推导出一个边际准则，该准则仅在接受增益超过额外验证成本时扩展推测序列。基于这一准则，我们开发了LibraSpec，一种无需训练且即插即用的算法，利用草拟器置信度分数迭代确定推测长度。理论上，我们证明了LibraSpec单调收敛于最优推测长度。在六个目标模型、三种基于扩散的推测解码方法以及数学、编码和聊天基准上的实验表明，在贪婪和采样设置下均有一致改进，与基线相比进一步提高0.5~1.5倍，相对于自回归解码最高加速8.49倍。

## Abstract
Speculative decoding accelerates large language model inference by drafting multiple tokens for parallel verification, with efficiency critically determined by the speculative length selected at each decoding round. Existing dynamic speculation methods select the speculation length by estimating how many tokens will be accepted, which is reasonable for autoregressive drafters that generates tokens sequentially. The recent wave of diffusion-based drafters, however, generates candidate blocks in parallel at substantially lower drafting cost, shifting the key question from how many tokens to generate to how many generated tokens are worth verifying. We therefore reformulate dynamic speculative-length selection as expected-speedup optimization and derive a marginal criterion that extends the speculative sequence only when its acceptance gain outweighs the additional verification cost. Building on this criterion, we develop \textit{LibraSpec}, a training-free and plug-and-play algorithm that iteratively determines the speculative length using drafter confidence scores. Theoretically, we prove that LibraSpec monotonically converges toward the optimal speculative length. Experiments across six target models, three diffusion-based speculative decoding methods, and math, coding, and chat benchmarks show consistent improvements under both greedy and sampling settings, achieving a further $0.5\sim1.5\times$ improvement over baselines and up to $8.49\times$ speedup over autoregressive decoding.

# LibraSpec 论文总结

## 1. 核心问题与整体含义

- **研究背景**：投机解码（Speculative Decoding）通过轻量级草稿模型生成候选 token 序列，再由目标模型并行验证，从而在不改变输出分布的前提下加速自回归 LLM 推理。每轮解码中选择的**投机长度（speculative length）**——即提交验证的候选 token 数量——对端到端加速效果至关重要：长度过短会浪费并行验证能力，过长则可能因早期拒绝而导致验证算力浪费。
- **现有方法的局限**：已有的动态投机长度方法（如 DISCO、FailFast、Gemma 4 MTP 等）本质上是**预测“将被接受的 token 数量”**，这一范式适合顺序生成的自回归草稿器。但近年来以 DFlash、DDTree、Fast-dLLM 为代表的**扩散式草稿器**能够以极低的边际成本并行生成整块候选序列，因此核心问题不再是“生成多少 token”，而是“生成出来的 token 中有多少值得验证”。
- **本文的意义**：将动态投机长度选择从“接受长度估计”重新表述为**期望加速（expected speedup）的优化问题**，并据此提出无需训练、即插即用的算法 LibraSpec，为扩散式投机解码提供了理论驱动的动态长度决策新范式。

## 2. 方法论

- **核心思想**：以期望端到端加速（speedup）为目标，通过“单次有益调整（single beneficial adjustment）”迭代逼近全局最优投机长度。扩展投机序列的条件是**新增片段的边际收益/边际验证成本比**优于当前平均收益/成本比；类似地，截断序列只应在被移除片段表现较差时进行。
- **理论框架**：
  - 定义加速比 \(\eta_d = \tau_d L_{\text{target}} / (T_{\text{draft},d} + T_{\text{verify},d})\)；在扩散草稿器并行生成、草稿成本几乎可忽略的设定下，简化为 \(\eta_d \approx \tau_d L_{\text{target}} / T_{\text{verify},d}\)。
  - 推导**边际准则（Theorem 3.2）**：调整 \(d \to d'\) 是有益的，当且仅当新增/移除片段的“边际接受增益 / 边际验证成本”优于当前平均水平。
  - 进一步强化为位置逐点准则（Theorem 3.3 / 3.4），得到最大可扩展长度 \(\epsilon_i\) 的闭式条件；取所有位置约束的交集得到充分条件。
  - 证明期望加速比相对于投机长度是**单峰函数（Theorem 3.5）**，因此有益调整单调收敛到全局最优长度区间（Theorem 3.6）。
- **算法流程（LibraSpec, Algorithm 1）**：
  1. 生成一个初始草稿块（块大小 \(n\)）；
  2. 以当前长度为起点，用已生成 token 的**草稿模型置信度** \(q_i\) 代替未知的目标接受概率 \(p_i\)，计算候选扩展长度 \(\epsilon^* = \min_i \epsilon_i\)；
  3. 若 \(\epsilon^* \le d\)，则停止扩展；否则将长度更新为 \(\epsilon^*\)，并消耗维护的**草稿预算 \(B\)**；预算不足时再生成新的草稿块；
  4. 设置模型相关的最长投机长度 \(d_{\max}\)（防止置信度校准随长度退化）；在实践中至多执行一次“回滚”以避免震荡。
- **工程细节**：将运行时参数 \(T_{\text{verify},i}\)、\(\tau_i\)、\(c\) 合并为单一超参数 \(\alpha\)，控制扩展的激进程度；通过草稿预算减少草稿模型调用次数。

## 6. 主要结论与发现

- 扩散式草稿器的出现改变了动态投机长度选择的优化目标：不应再预测接受长度，而应直接优化“接受增益 vs. 验证成本”的权衡。
- LibraSpec 在**所有评估设置**下都带来一致加速：
  - 与 FastdLLM 结合时，相对原方法平均提速约 1.25×~1.57×；
  - 与 DFlash 结合额外提速 0.39×~0.69×；与 DDTree 结合额外提速 0.39×~0.56×；
  - 在贪心和采样设置下均有效，最大端到端加速达 **8.49×**（超过自回归解码基线）。
- LibraSpec 能动态追踪 Oracle 最优长度，平均绝对偏差仅 2.78 个 token，远低于静态长度的 9.48 个 token。
- 对超参数 \(\alpha\) 和最大投机长度 \(d_{\max}\) 的选择具有鲁棒性。

## 7. 优点

- **即插即用、无需训练**：不引入额外预测器或训练流程，可直接与现有扩散式方法（FastdLLM、DFlash、DDTree）集成。
