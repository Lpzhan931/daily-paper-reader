## 摘要
推测解码通过并行验证多个草稿 token，无损加速自回归语言模型。基于扩散的草稿者通过并行预测整个 token 块进一步降低提案延迟，但它们的逐位置分布是边缘分布，而不是以每条草稿路径上选择的 token 为条件。现有的循环校正沿着单个草稿链纳入因果信息，而基于扩散的树构建则扩大了候选覆盖范围，但并未将这种校正沿各个分支传递。我们提出了 DARTree，一种无需训练的推测解码方法，它将预训练的自回归（AR）校正头从链扩展到树。DARTree 首先通过在单个批次中扩展并评分每个深度的所有节点来构建固定宽度的候选树，然后仅应用最佳优先剪枝来选择验证树，从而将 AR 头推理与顺序堆操作解耦。在七个数学、代码和聊天基准测试中，DARTree 在所有四种模型-温度配置下都实现了最高的平均接受长度和加速比，每轮验证最多接受 12.97 个 token，比相同设置下的 DFlash 多 98.6%，比 Domino 多 27.9%，并且与本地测量的自回归解码相比，实现了高达 9.73 倍的无损加速。

## Abstract
Speculative decoding losslessly accelerates autoregressive language models by verifying multiple draft tokens in parallel. Diffusion-based drafters further reduce proposal latency by predicting an entire token block in parallel, but their position-wise distributions are marginal rather than conditioned on tokens selected along each draft path. Existing recurrent correction incorporates causal information along a single draft chain, whereas diffusion-based tree construction broadens candidate coverage without carrying this correction along individual branches. We introduce DARTree, a training-free speculative decoding method that extends a pretrained AR correction head from chains to trees. DARTree first constructs a fixed-width candidate tree by expanding and scoring all nodes at each depth in a single batch, and then only applies best-first pruning to select the verification tree, decoupling AR-head inference from sequential heap operations. Across seven math, code, and chat benchmarks, DARTree achieves the highest average acceptance length and speedup in all four model--temperature configurations, accepting up to 12.97 tokens per verification round, 98.6\% more than DFlash and 27.9\% more than Domino in the same setting, and reaching up to 9.73$\times$ lossless speedup over locally measured autoregressive decoding.

# 论文详细总结

## 1. 核心问题与整体含义（研究动机与背景）

**研究背景：**
- 自回归 LLM（如 Qwen3、GPT-4）推理速度受限于其逐 token 顺序生成特性，解码过程高度 I/O 密集，硬件并行计算能力被严重浪费。
- 推测解码（Speculative Decoding）通过轻量草稿模型先提出候选 token、再用目标模型并行验证的方式实现无损加速，已成为主流加速方案。
- 扩散式草稿模型（Diffusion-based Drafters）如 DFlash，可以在一轮前向中并行预测整个 token 块，大幅降低草案生成延迟并允许使用更高容量的草稿模型。

**核心问题：**
- 扩散式草稿模型预测的是**边缘分布（marginal distributions）**，并未沿草稿路径中实际已选中的 token 进行条件化，与目标模型的条件分布存在“因果失配”（causal mismatch）。
- 现有循环校正方法（如 Domino、DSpark）虽然能沿**单条草稿链**恢复因果依赖，但扩散式树构建方法（如 DDTree）虽扩大了候选分支覆盖率，却未将校正沿各个分支传递。
- 将因果校正与堆式最佳优先树构建结合会产生**严重效率瓶颈**：因每个子节点的校正分数依赖于父节点路径状态，每次堆弹出后必须执行一次校正头推理才能继续扩展，导致校正头推理只能逐节点串行进行，无法批量并行。

**核心解决思路：**
- 提出 **DARTree**，一种无需训练的推测解码方法，将预训练的 AR 校正头从“单链”扩展到“树”，兼顾因果校正与树形候选覆盖，同时消除顺序堆操作带来的延迟瓶颈。

## 2. 方法论

### 2.1 核心思想

DARTree 的核心理念是：**在保持路径条件化校正的同时，将树构建过程从“逐节点串行”转化为“逐深度批量并行”**，从而解耦校正头推理与顺序堆操作。

### 2.2 关键技术细节

**（1）深度并行超树构建（Depth-Wise Parallel Supertree Construction）**

- 块并行扩散骨架先执行一次前向，产生共享表征 {Hd} 及各位置基本 logits {Lbase_d}。
- 每个位置仅取 top-K 个候选 token（K=64）作为扩展候选集。
- 从根节点出发，将当前深度的活跃分支**批量送入校正头**，同时获取所有候选扩展的校正后分布。
- 依据校正后的累计分数保留 top-W 个扩展（W 为层宽），形成固定宽度的候选超树。
- 校正状态沿保留的路径传递到下一深度。
- 依赖关系仅在**跨深度**间保持顺序，同一深度内的校正、评分、选择与状态更新全部张量化。

**（2）延迟最佳优先剪枝（Deferred Best-First Pruning）**

- 超树构建完成后，所有已生成前缀均具有校正后分数，因此可以一次性做全局 top-B 选择，而无需在构建过程中穿插堆操作。
- 前缀得分定义为（其中 β≤0 为深度惩罚项）：
  - sβ(u1:d) = Σ_{i=1}^{d} log e_qi(u_i) + βd
- **引理1（堆—top-B 等价性）**：当 β≤0 且平局时祖先优先，则 DDTree 式的最佳优先堆选择与全局 top-B 选择返回相同的树。原因是子节点分数 = 父节点分数 + log(校正概率≤0) + β≤0，得分沿路径单调不增，全局 top-B 集合天然满足前缀封闭性。

**（3）与现有方法的关系**

- DARTree 继承了 DDTree 的树验证流程（tree attention mask 一次前向验证全树）。
- 算法仅修改候选树构建阶段，目标模型侧的树验证流程完全不变。
- 可适用于**任意带因果校正头的并行块草稿器**，不局限于 Domino。

## 6. 主要结论与发现

1. **DARTree 在所有四个模型-温度配置中均实现最高平均接受长度和加速比**。
2. **最佳成绩**：GSM8K + Qwen3-4B + T=0 下，接受 12.97 token/轮，达 9.73× 加速；接受长度比 DFlash 高 98.6%、比 Domino 高 27.9%。
3. **固定变体已超越基线**：DARTree (fixed) 的 τ 比 DDTree 最高多 22.9%、比 Domino 最高多 37.9%。
4. **剪枝变体进一步增益**：延迟剪枝相比固定宽度额外提升 τ 最高 6.5%、加速比最高 7.1%。
5. **T=1 下同样有效**：优势不限于贪心解码，随机采样同样适用。
6. **通用性验证**：除 Domino 外，DARTree 也可迁移至 DSpark 的 Markov 校正头，τ 提升 14.6–40.6%、加速比最高提升 34.3%。
7. **与顺序堆方案对比**：DARTree 获得相近的接受长度，但每轮延迟从约 65 ms 降至约 28–29 ms（约为顺序方案的 44%）。
8. **接受模式**：DARTree 同时保留了 DDTree 早期位置的强接受率和 Domino 后期位置的延续能力，在块末端达到近 50% 的接受概率。

## 7. 优点

1. **训练无关设计**：直接复用预训练的校正头，无额外训练成本，部署门槛低。
2. **有效解耦延迟瓶颈**：将校正头推理与顺序堆操作解耦，使树构建从逐节点（约 70 ms/轮）变为逐深度批量（约 28 ms/轮），延迟降低一半以上。
3. **批量化扩展**：同一深度的所有分支一次性批量推理校正头，充分利用硬件并行能力；层宽增加仅带来极小额外延迟。
4. **定理保障的最优剪枝**：引理 1 严格证明了在 β≤0 条件下堆选择与全局 top-B 的等价性，为延迟剪枝提供理论支撑。
5. **通用性强**：不依赖特定校正架构，适用于 Domino 的 RNN 头和 DSpark 的 Markov 头。
6. **无损加速**：保持了目标模型输出分布，无质量损失。
7. **实验设计细致**：从树形分布、接受模式到可视化示例，多角度验证方法有效性。

## 8. 不足与局限

1. **依赖预训练校正头**：训练无关性仅适用于已配备校正头的扩散草稿器，对朴素扩散草稿器不直接适用，需要先训练一个校正头。
2. **不减少总 FLOPs**：方法使用额外计算换取低延迟，树验证计算开销比非树方法更大。
3. **并发场景优势减弱**：随着并发请求增加（C≥16 时），批处理使计算趋于受限，大树的验证开销更为昂贵——实验显示 DARTree 在 C=32 时加速比已降至约 1.06–2.25×。因此论文建议将其用于低并发个人部署或延迟敏感场景。
4. **实验仅覆盖 Qwen3-4B/8B**：未涉及更大规模模型或其他模型家族，可能限制结论普适性。
5. **技术局限性**：当前块长度固定为 16，部分解码轮次已触达草稿块末端，可能截断了本可继续接受的路径（论文在 Future Work 中承认此问题）。
6. **超参数敏感**：层宽 W、预算 B、深度惩罚 β 需要针对运行场景调节，且随并发水平需采用不同配置（需自适应调整）。
