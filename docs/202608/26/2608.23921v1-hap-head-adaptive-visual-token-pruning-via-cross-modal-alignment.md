## 摘要
最近的视觉-语言模型将高分辨率图像编码为长视觉令牌序列，导致高昂的预填充成本。为了压缩它们，现有方法通过对所有头部的文本到视觉注意力进行均匀平均来为每个视觉令牌打分，这假设每个头部都与查询匹配。然而，我们的实证分析表明，不对齐的头部主导了平均值，放大了背景令牌并淹没了细粒度线索。为了解决这个问题，我们提出了PAQ（提示接地注意力质量），一个量化每个头部如何将提示与图像区域对齐的度量。基于PAQ，我们的剪枝过程分三个阶段进行。给定目标FLOPs预算，我们首先将Transformer层划分为组，并为每组分配视觉令牌预算。在每个组内，我们通过PAQ加权的softmax将每个头的注意力图聚合为组级矩阵。最后，我们根据该矩阵的幅值对视觉令牌进行评分，并保留每组分配的预算。通过用PAQ加权头部，我们的方法通过更忠实地反映提示相关性的注意力信号对令牌进行评分，而不是通过均匀平均稀释它们。在18个基准测试中，我们的方法提供了最先进的权衡。具体来说，在LLaVA-1.5-7B（9个任务）上，仅保留5.6%的令牌即可保持99.1%的原始性能，超过最强基线AutoPrune 4.2个百分点。代码可在https://github.com/baokou-fw2/HAP获取。

## Abstract
Recent Vision-Language Models encode high-resolution images into long visual token sequences, incurring prohibitive prefill costs. To compress them, existing methods score each visual token by averaging text-to-visual attention uniformly across all heads, which assumes every head matches the query. However, our empirical analysis shows that misaligned heads dominate the average, amplifying background tokens and drowning out fine-grained cues.   To address this, we propose PAQ (Prompt-Grounded Attention Quality), a metric quantifying how well each head aligns the prompt with image regions. Built on PAQ, our pruning proceeds in three stages. Given a target FLOPs budget, we first partition the transformer layers into groups and allocate a visual token budget to each. Within each group, we then aggregate per-head attention maps via PAQ-weighted softmax into a group-level matrix. Finally, we score visual tokens by this matrix's magnitude and retain the allocated budget per group. By weighting heads with PAQ, our method scores tokens by attention signals that more faithfully reflect prompt relevance, rather than diluting them through uniform averaging.   Across 18 benchmarks, our method delivers state-of-the-art trade-offs. Specifically, on LLaVA-1.5-7B (9 tasks), retaining only \textbf{5.6\%} tokens preserves \textbf{99.1\%} of the original performance, surpassing the strongest baseline AutoPrune by 4.2 points. Code is available in https://github.com/baokou-fw2/HAP.

- **现有方法的缺陷**：已有视觉 token 剪枝方法（如 SparseVLM、PDrop、AutoPrune 等）虽然利用跨模态注意力统计来筛选重要 token，但普遍隐含一个关键假设——同一层内所有注意力头对提示相关区域的关注程度一致，因而对所有头部的注意力分数进行**均匀平均**。
- **实证发现**：论文通过实验揭示，注意力头实际呈现三种截然不同的模式：
  - **Sink 头**：无论文本提示如何，都固定关注某些区域（如背景或边缘）；
  - **Dispersed 头**：注意力弥散分布，没有清晰的提示对应关系；
  - **Optimal 头**：能随查询变化而聚焦于任务相关区域。
  均匀平均会使错位的 sink/dispersed 头主导打分，放大背景 token 噪声，淹没细粒度的任务线索。进一步实验表明，由平均注意力选出的 token 在准确率和空间定位上始终逊于由单个最佳对齐头选出的 token。
- **核心思想**：提出一种**基于提示接地（prompt-grounded）注意力质量**的头部自适应剪枝机制，用可靠的对齐信号替代粗粒度的均匀头部平均，在保持性能的同时大幅压缩视觉 token。

## 2. 论文提出的方法论

### 2.1 PAQ（Prompt-Grounded Attention Quality）指标

- 基于**不确定性系数（Theil's uncertainty coefficient）**定义：
  \[
  \text{PAQ} = \frac{I(V; T)}{H(V)}
  \]
  其中 \(I(V;T)\) 衡量视觉分布受文本查询驱动的程度，\(H(V)\) 衡量视觉总体不确定性，比值介于 0 到 1。
- 计算完全基于注意力头内在的 post-softmax 注意力统计，无需额外参数或训练。
- 将交叉注意力权重视为软相关分配 \(\hat{p}(v_i|t_j)=\alpha_{ji}\)，配合均匀文本先验，即可从注意力矩阵直接推导出 PAQ。
- **三种注意力模式的对应关系**：
  - Sink 头和 dispersed 头的注意力权重对文本 token 不敏感，条件分布退化为边缘分布，互信息趋近于 0，PAQ 接近于 0，被有效抑制；
  - Optimal 头随文本查询呈现尖锐的集中分布，\(I(V;T)>0\) 且 \(H(V)\) 较低，PAQ 显著较高。

### 2.2 HAP（Head-Adaptive Visual Token Pruning）框架

给定目标 FLOPs 预算，HAP 分三个阶段进行剪枝：

1. **分组与预算分配**：将 \(L\) 层 Transformer 划分为 \(M\) 个连续层组，每组的视觉 token 预算按几何金字塔结构 \(N_v^{(g)} = V / (1+g)^2\) 递减（\(V\) 为初始 token 数）。组数 \(M\) 由闭合形式的成本函数 \(F_{\text{pruned}}(m)\) 从目标 FLOPs 预算直接推导得出，无需针对任务调参。
2. **组内 PAQ 加权聚合**：
   - 先对层内每个注意力头计算 PAQ 分数；
   - 将原始 PAQ 分数减去均值（中心化），再经 softmax 得到聚合权重 \(w_c\)；
   - 高 PAQ 的头获得更大权重，低 PAQ 的头被软性抑制；
   - 将各头注意力图加权融合为该层的聚合注意力图；
   - 再以同一 PAQ-softmax 流程将组内各层注意力图融合为组级注意力矩阵。
3. **token 评分与保留**：对组级注意力矩阵按文本位置求平均，得到每个视觉 token 的重要性分数，按分数排序保留每组分配的预算。

### 2.3 效率与兼容性

- PAQ 计算仅需遍历注意力权重，逐层开销为 \(O(HN_t N_v^{(l)})\)，总和上界为 \(O(HN_t V L/m)\)，相对完整前向传播是低阶项。
- 通过扩展**双 FlashAttention 策略**（dual-flash），无需物化完整的 \(O(N^2)\) 注意力矩阵即可计算 PAQ 所需的聚合统计量，与 FlashAttention 等优化后端完全兼容，额外内存仅每层几个标量，实测 wall-clock 开销低于 2%。
- 剪枝后总 FLOPs 由封闭形式给出：
  \[
  F_{\text{pruned}}(m) \approx \frac{L}{m}\left[A\left(1-\frac{1}{1+m}\right) + \frac{B}{3}\left(1-\frac{1}{(1+m)^3}\right)\right]
  \]
  其中 \(A=4VD^2+3VDd_{ffn}\)、\(B=2V^2D\) 为架构常数。

- **核心发现**：注意力头存在显著的跨模态对齐异质性（sink/dispersed/optimal 三种模式），均匀头部平均会稀释最优头的细粒度信号、放大噪声头的影响。
- **方法有效性**：基于 PAQ 加权的头部/层聚合能选出更忠实反映提示相关性的视觉 token。
- **性能结果**：
  - LLaVA-1.5-7B 上仅保留 5.6%（32/576）token 仍保持 99.1% 原始性能，领先最强基线 AutoPrune 4.2 个百分点；保留 128 token 时相对分达 102%，甚至超过原始模型。
  - InternVL3-8B 和 Qwen2.5-VL-7B 上保留 25% token 时分别保持 99.5% 和 99.1% 相对性能。

## 7. 优点

## 8. 不足与局限

- **适用范围限定**：HAP 仅在 prefill 阶段剪枝，解码阶段的视觉 KV cache 未做处理。虽附录分析了解码阶段的 FLOPs 收益边界（增益临界点在数万至数十万 token 的生成长度），但长输出场景下收益有限。
