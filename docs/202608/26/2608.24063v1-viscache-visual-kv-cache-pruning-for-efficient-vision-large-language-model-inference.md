## 摘要
尽管视觉大语言模型（VLLMs）在多模态推理方面取得了显著成功，但其长上下文推理仍因视觉键值（KV）缓存的巨大计算和内存开销而代价高昂。现有的KV压缩方法通常对视觉token和层进行均匀剪枝，导致大量信息丢失和性能下降。为解决这一挑战，我们提出了VisCache，一个无需训练的即插即用框架，用于从粗到细的视觉KV缓存剪枝，由两个协同阶段组成。首先，一个轻量级VLM通过选择性转发语义关键帧来过滤时间冗余。其次，我们引入了PruneKV，一种针对VLLM注意力动态定制的外科手术式KV压缩算法。与刚性剪枝策略不同，PruneKV采用抛物线型逐层预算分配，并结合不对称更新机制，选择性剪枝键同时融合值，从而保留关键上下文信息。大量实验表明，VisCache显著提升了推理效率，实现了高达2.35倍的加速和显著的内存减少，同时仅保留19–28%的KV缓存即可维持具有竞争力的性能。VisCache持续优于现有基线，为长上下文VLLM推理建立了效率与性能之间新的帕累托前沿。代码可在 https://github.com/Wlklk/VisCache 获取。

## Abstract
While Vision Large Language Models (VLLMs) have achieved remarkable success in multimodal reasoning, their long-context inference remains prohibitively expensive due to the massive computation and memory overhead of visual Key-Value (KV) caches. Existing KV compression methods often apply uniform pruning across visual tokens and layers, leading to substantial information loss and degraded performance.To address this challenge, we propose \textbf{VisCache}, a plug-and-play framework for coarse-to-fine \textbf{Vis}ual KV \textbf{Cache} pruning without training, which consists of two synergistic stages. First, a lightweight VLM filters temporal redundancy by selectively forwarding semantically informative keyframes. Second, we introduce {PruneKV}, a surgical KV compression algorithm tailored to the attention dynamics of VLLMs. Unlike rigid pruning strategies, PruneKV adopts a parabolic layer-wise budget allocation together with an asymmetric update mechanism that selectively prunes keys while fusing values, thereby preserving critical contextual information. Extensive experiments demonstrate that VisCache substantially improves inference efficiency, achieving up to {2.35$\times$ speedup} and significant memory reduction while maintaining competitive performance with only {19--28\%} KV cache retention. VisCache consistently outperforms existing baselines, establishing a new Pareto frontier between efficiency and performance for long-context VLLM inference. Code is available at https://github.com/Wlklk/VisCache

## 一、论文的核心问题与整体含义（研究动机和背景）

- **核心问题**：视觉大语言模型（VLLMs）在多模态推理任务中表现卓越，但其长上下文推理面临两大瓶颈：
  1. **KV缓存内存开销巨大**：长视频产生海量视觉token，使KV缓存膨胀，主导GPU内存消耗并加剧内存带宽争用，严重制约吞吐量。
  2. **注意力计算成本高**：注意力计算随序列长度呈二次方增长，放大延迟开销。

- **现有方法的不足**：已有KV压缩方法（如量化、低秩分解）存在以下缺陷：
  - 量化易受激活值离群点影响；低秩分解会损害注意力容量。
  - 更重要的是，现有方法多采用**跨视觉token和层的均匀剪枝**，忽视了VLLM中视觉冗余的结构化特征——即：
    - 只有部分视频帧与特定查询相关（时间相关性）；
    - 不同transformer层对下游推理贡献不均（层级异质性）；
    - 键（Key）和值（Value）在注意力计算中扮演根本不同的角色（功能不对称性）。

- **整体含义**：VisCache旨在通过**粗到细（coarse-to-fine）的双阶段压缩范式**，在无需训练的前提下，同时解决时间冗余与结构冗余问题，为长上下文VLLM推理建立效率与性能之间新的帕累托前沿。

## 二、论文提出的方法论

### 核心思想
VisCache是一个**无需训练（training-free）**、**即插即用（plug-and-play）** 的框架，包含两个协同阶段：
1. **语义过滤阶段（推理前）**：通过轻量级VLM筛选关键帧，消除输入级时间冗余。
2. **结构压缩阶段（推理中）**：通过PruneKV算法对KV缓存进行外科手术式逐层压缩。

### 阶段一：Prompt-Aware Scout（提示感知的关键帧筛选）

- 使用轻量级视觉-语言模型（如CLIP）作为"侦察兵"（scout），对视频帧和文本提示进行跨模态嵌入提取：
  - 文本嵌入：\( h_t = \text{Enc}_{\text{text}}(T) \)
  - 帧嵌入：\( h_f = \text{Enc}_{\text{vis}}(f) \)
- 采用**最大边际相关（MMR）判据**，在提示相关性与帧间多样性之间取得平衡：

  \[
  \text{MMR}(f) = \lambda \cdot \text{sim}(h_f, h_t) - (1-\lambda) \cdot \max_{f' \in \Omega} \text{sim}(h_f, h_{f'})
  \]

  其中 \(\lambda \in [0,1]\) 控制相关性与多样性的权衡，\(\Omega\) 为已选帧集合。
- 迭代选择最高MMR得分的帧，直到达到目标保留比 \(p\)，形成紧凑、查询相关且冗余最小的关键帧序列。

### 阶段二：PruneKV（层级感知的视觉KV缓存压缩）

PruneKV围绕两个结构属性设计：

#### 1. Token评分与抛物线程级预算分配

- **Token重要性评分**：聚合所有层和所有查询对该视觉token的注意力权重：
  \[
  s_v = \frac{1}{L} \sum_{l=1}^{L} \sum_{i=1}^{N} A^l_{i,v}
  \]
  基于 \(s_v\) 保留top-q的视觉KV条目。

- **抛物线程级预算分配**：设 \(h \in (1, L]\) 为截断阈值，\(l > h\) 层的视觉KV条目被完全丢弃。对于剩余层 \(l \in [1, h]\)，预算比例为：
  \[
  b_l = 1 - \frac{(l-1)^2}{2(h-1)^2}
  \]
  满足 \(b_1 = 1\)、\(b_h = 0.5\)。该抛物线衰减在浅层保留更多token（编码细粒度空间细节），深层压缩更激进（表征足够抽象可容忍重剪枝）。

#### 2. 非对称键值更新（Asymmetric Key-Value Update）

- **核心洞察**：注意力权重仅由 \(QK^\top\) 决定，因此**键是相关性选择器**；而**值是信息载体**，决定最终聚合的内容。
- **策略——剪键融合值（prune-keys, fuse-values）**：
  - 对丢弃集 \(C_d\)：完全移除键向量（因其注意力贡献可忽略）。
  - 对值向量：不丢弃，而是通过基于相似度的加权聚合重新分配到保留token：
  
  计算重分配矩阵：
  \[
  \Phi = \text{Softmax}\left(\frac{V_k V_d^\top}{\tau}\right) \in \mathbb{R}^{b_l \times (n-b_l)}
  \]
  
  融合后的新值：
  \[
  V^{\text{new}}_k = \mu V_k + (1-\mu)(\Phi V_d)
  \]
  
  其中 \(\mu \in [0,1]\) 平衡原始信息与重分配信息的贡献（\(\mu=1\) 退化为标准剪枝）。

## 六、论文的主要结论与发现

1. **显著的效率提升**：VisCache实现最高**2.35倍**端到端推理加速，仅保留19-28%的KV缓存；在3B模型28% RR下FLOPs降至全缓存的7%。
2. **性能保持甚至超越**：在Qwen2.5-VL-3B上，28% RR时平均准确率（45.64%）**超过全缓存（44.16%）**；在32B模型上，28% RR时准确率（56.86%）超过所有40% RR的基线。
3. **抛物线程级预算优于其他策略**：相比算术级数（PyramidKV）、几何级数（PDrop）、固定预算，抛物线分配在激进压缩下更好地保留必要信息。
4. **非对称键值更新有效**：剪键融合值策略显著优于简单剪枝，尤其在配合抛物线预算时效果最佳。
5. **双阶段协同互补**：Scout粗粒度过滤 + PruneKV细粒度压缩的组合，在低RR下优势更加明显。
6. **共享全局token排名更优**：跨层聚合注意力得分比逐层独立排名更稳定、效果更好。
7. **强兼容性**：可与量化方法（KIVI、FlatQuant）无缝结合，也适用于不同VLLM架构。

## 七、优点

### 方法亮点
- **无需训练、即插即用**：可灵活应用于现有VLLM，无需重训练或微调。
- **粗到细双阶段设计**：在输入级（帧过滤）和模型级（KV压缩）同时发力，协同效果好。
- **抛物线预算分配**：契合视觉表征随层加深而日益抽象的特性，比固定/算术/几何策略更优。
- **非对称键值更新**：首次明确区分键和值在注意力中的不同角色，通过值融合保留被剪token的信息，避免不可逆信息丢失。
- **共享全局token排名**：提供更稳定的重要性估计，同时保留逐层预算的灵活性。

### 实验亮点
- 实验覆盖面广：2个VS数据集 + 3个VQA数据集 + 20任务MVBench benchmark。
- 模型规模从3B到32B，验证了方法在不同规模上的可扩展性。
- 报告了真实系统效率（内存、TPS、延迟）而非仅理论FLOPs。
- 对关键超参数（μ、截断层、Scout模型选择）进行了系统分析。

## 八、不足与局限

### 方法层面的局限
1. **Scout与主模型对齐问题**：轻量级VLM（如CLIP）的视觉编码器与主LLM骨干可能存在表征差异，导致所选关键帧未必是下游模型的最优选择。
2. **注意力分数存储开销**：PruneKV在预填充阶段需要存储所有层的注意力分数，引入额外内存开销。
3. **截断层h的确定依赖经验**：虽然通过实验确定3/4层深度最优，但缺乏自适应机制。
4. **融合权重μ的敏感性**：实验显示μ=0.7最优，但不同任务/模型可能需要不同设置，泛化性有待验证。

### 实验覆盖的局限
1. **模型多样性不足**：主要实验集中在Qwen2.5-VL系列，其他架构（Qwen3-VL、LLaVA-OneVision）的验证较为简短且数据集较少。
2. **消融实验覆盖不均匀**：部分消融仅在单一数据集（如EgoSchema）或单一模型规模上进行。
3. **未与训练式压缩方法对比**：基线均为即插即用方法，未与需要训练的压缩/剪枝方法进行对比。

### 潜在应用风险
- **偏差传播**：压缩基于预训练模型的注意力模式，底层基础模型中的偏差可能通过压缩过程传播。
- **安全与隐私问题**：效率提升可能助长大规模视频分析应用，需遵守隐私、同意和算法公平性的伦理准则。
