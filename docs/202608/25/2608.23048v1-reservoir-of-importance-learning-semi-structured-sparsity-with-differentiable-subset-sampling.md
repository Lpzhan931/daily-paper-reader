## 摘要
半结构化N:M稀疏性已成为加速大型语言模型（LLM）的实用方向。然而，现有的可学习掩码方法会带来大量的参数和内存开销，限制了它们在大模型和高稀疏度场景下的可扩展性。在这项工作中，我们从兼顾效率与可扩展性的视角重新审视半结构化剪枝。我们提出了重要性储备（RoI），一种通过可微子集采样学习稀疏掩码的轻量级半结构化剪枝框架。与先前对所有可行的N:M模式建模完整类别分布的方法不同，RoI引入了一种紧凑的logit参数化来进行稀疏掩码学习，并执行无放回采样来选择掩码，从而将可训练参数从组合复杂度降低到O(M)。因此，RoI需要的可训练参数减少1.5-8.75倍，内存成本显著降低，同时与硬件友好的稀疏模式完全对齐。在Qwen2.5 LLM系列的多个规模（0.5-7B参数）上的广泛评估表明，RoI在强内存效率、稳定性和对更激进的N:M稀疏模式的可扩展性方面实现了具有竞争力的性能，为高效LLM部署提供了一条实用路径。

## Abstract
Semi-structured $N$:$M$ sparsity has emerged as a practical direction for accelerating large language models (LLMs). However, existing learnable-mask approaches incur substantial parameter and memory overhead, limiting their scalability to large models and aggressive sparsity regimes. In this work, we revisit semi-structured pruning from a perspective that reconciles efficiency with scalability. We propose Reservoir of Importance (RoI), a lightweight semi-structured pruning framework that learns sparsity masks through differentiable subset sampling. Unlike prior methods that model full categorical distributions over all feasible $N$:$M$ patterns, RoI introduces a compact-logit parameterization for sparsity mask learning and performs sampling without replacement to select masks, thereby reducing trainable parameters from combinatorial complexity to $\mathcal{O}({M})$. As a result, RoI requires 1.5-8.75$\times$ fewer learnable parameters and significantly lower memory cost, while remaining fully aligned with hardware-friendly sparsity patterns. Extensive evaluations across multiple scales of the Qwen2.5 LLM family (0.5-7B parameters) demonstrate that RoI achieves competitive performance with strong memory efficiency, stability, and scalability to more aggressive $N$:$M$ sparsity patterns, offering a practical path toward efficient LLM deployment.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **研究背景**：随着大型语言模型（LLM）规模不断增长，推理成本成为部署的主要瓶颈。剪枝技术分为三大类：非结构化剪枝（灵活但难以利用硬件加速）、结构化剪枝（硬件友好但灵活性差）和半结构化剪枝（在两者之间取得平衡）。其中，**N:M 半结构化稀疏**（如 2:4）可在现代 GPU（如 NVIDIA Ampere/Hopper）上获得硬件级加速，因此成为实用化部署的重要方向。
- **核心问题**：现有的可学习掩码方法（如 MaskLLM、HyperPrune）将每个剪枝组建模为所有可行 N:M 配置上的类别分布，需要 `C(M, N)` 个参数来描述每个组的掩码分布。这种**组合级参数化**导致：
  - 可训练参数量随 M 增大呈指数增长（如 4:8 模式需要 70 个参数/组，是 M=8 的 8.75 倍）；
  - 内存开销大，难以扩展到大模型和更激进的稀疏率；
  - 优化器的状态（动量、方差等）随之膨胀。
- **研究目标**：提出一种轻量级、可扩展的半结构化剪枝框架，在保持模型性能的同时，大幅降低掩码学习的参数和内存开销，使可学习掩码方法能适用于大规模 LLM 及更激进的稀疏模式。

## 2. 论文提出的方法论

### 2.1 核心思想
作者提出 **RoI（Reservoir of Importance, 重要性储备）** 框架，其核心创新在于：**放弃在"掩码空间"上建模分布，转而将 N:M 掩码视为从 M 个模型参数中无放回采样 N 个子集的结果**。具体来说：

- 每个剪枝组仅需要 **M 个可学习 logit**（每个参数一个），而不是 `C(M, N)` 个；
- 通过 **加权蓄水池采样（Weighted Reservoir Sampling, WRS）** 的概率分布隐式地诱导出掩码上的分布；
- 利用 **Gumbel-Top-K 技巧** 实现可微采样，使掩码学习可以通过反向传播进行端到端优化。

### 2.2 关键技术细节

**(1) 问题形式化**：
- 剪枝目标：在 N:M 约束下，为每个连续的 M 参数组选择恰好 N 个非零权重，以最小化校准集上的交叉熵损失。
- 由于组合搜索空间（`C(M, N)^G`）巨大，作者将其重述为随机变分优化问题：最小化关于掩码变分分布的期望损失。

**(2) WRS 分布**：
- WRS 的概率定义：按权重比例依序无放回采样，第 k 个样本的概率为 `wyk / (W - Σw_yj)`。
- 关键定理（Theorem 1）：将每个 N-hot 掩码看作从 WRS 分布采样的有序子集的和，二者的期望损失完全等价。这一等价性保证了对 WRS 分布的优化等价于直接优化掩码分布，但参数从 `C(M, N)` 降至 M。

**(3) Gumbel-Top-K 可微采样**：
- 对每个 logit 添加 Gumbel 噪声：`κij = φij + gij`；
- 递归更新校正键：`α(k) = α(k-1) + log(1 - μ(k-1))`，以确保无放回采样；
- 通过 softmax 松弛获得连续化的 one-hot 向量：`μ(k) = softmax(α(k)/τ)`；
- 将 N 步的松弛 one-hot 向量求和，得到连续松弛的 N-hot 掩码。

**(4) 温度退火**：
- 引入两个温度参数：Gumbel-Softmax 温度 τ 和采样温度 λ；
- 采用指数退火策略，训练开始时温度较高鼓励探索，后期温度降低使采样趋近确定性；
- 默认从 τ=1.0→0.05、λ=1.0→0.002，退火步数为 1500/2000。

### 2.3 与 MaskLLM 的区别
- **MaskLLM**：每个可行掩码（`C(M, N)` 个配置）分配一个独立 logit，梯度更新仅影响被采样到的单一配置，参数利用率低。
- **RoI**：每个参数一个 logit，梯度通过参数共享隐式传递到包含该参数的所有掩码。给定某个权重重要性高时，所有包含它的掩码概率同时增加，从而获得更好的**统计效率和优化几何**。

1. **RoI 在 2:4 稀疏下性能与 MaskLLM 相当或略优**：如 7B 模型平均准确率 64.54%（RoI）vs 64.44%（MaskLLM）；全部规模下 WikiText-2 PPL 为最优。

3. **RoI 在极端稀疏（2:8）下依然有效**：当幅度剪枝、Wanda 等方法的 PPL 超过 10^4 甚至无穷大时，RoI 仍能在 7B 模型上维持 32.33 的 PPL。
4. **可学习掩码方法优于启发式方法**：在所有模型规模下，MaskLLM 和 RoI 都显著优于 Wanda、SparseGPT、Magnitude 等传统方法。
5. **RoI 的数据可扩展性更好**：随着训练 token 数增加，RoI 和 MaskLLM 持续改善，而 ProxSparse 在约 0.5B tokens 后陷入平台期，显示出正则化方法的收敛限制。
6. **2:4 稀疏可带来实际的推理加速**：在 vLLM 部署下获得约 1.26-1.3× 吞吐提升。

## 7. 优点

- **参数效率高**：将掩码学习参数从组合级 `C(M, N)` 降至线性级 O(M)，这是最核心的贡献，理论意义明确（提供了 Theorem 1 的等价性证明）。
- **方法论优雅**：将 N:M 掩码建模为无放回子集采样，利用 WRS 和 Gumbel-Top-K 将离散优化转化为可微的变分优化，与已有理论（随机变分优化）衔接自然。
- **直接兼容硬件**：学习的掩码天然满足 N:M 模式，无需后处理转换步骤，与 NVIDIA/AMD 的硬件稀疏加速对齐。
- **梯度传播的归纳偏置**：参数共享使单一权重的信息可传递到所有包含它的掩码，在统计效率上优于独立参数化每个掩码配置的方法。
- **可扩展性验证充分**：从 0.5B 到 7B（甚至 Gemma-2-9B 的跨家庭验证）一致有效；2:8 压力测试证明其在更激进稀疏率下仍然稳健。
- **实用性强**：报告了推理吞吐量（vLLM 部署）和训练时间（GPU 小时），让读者能直观理解端到端收益。

## 8. 不足与局限

- **硬件依赖性强**：当前真正的推理加速仅在有原生 2:4 稀疏内核的平台上实现（如 NVIDIA Ampere/Hopper、AMD ROCm）。对于其他 N:M 比例或 CPU/异构设备，稀疏化只会减少内存占用而无法带来实际加速。这一限制在硬件生态成熟之前，制约 RoI 在生产环境中的广泛部署。
- **评估范围有限**：实验仅覆盖英语、稠密模型，未涉及多语言模型、MoE 架构、代码生成、长上下文或更复杂的推理任务。对 RoI 在更广泛场景下的泛化性仍需验证。
- **性能提升幅度温和**：RoI 在最终精度上与 MaskLLM 的差距并非本质性的（差距约 0.1-0.4 个百分点），其主要优势在于成本而非精度大幅超越。在精度敏感的场景中，若预算允许，MaskLLM 仍可能有竞争力。
- **未报告方差**：论文未提供多次随机种子实验的标准差，无法判断性能差异的统计显著性。
- **ProxSparse 在 3B 模型上失败且未解释原因**：3B 规模的对比不完整（ProxSparse 数据缺失），且论文未深入分析其失败机制，影响该规模下对比的完整性。
- **辅助参数虽然减少但并未消除**：RoI 仍需为每个剪枝组维护 M 个 logits（总量与模型参数相当），在大模型上仍是一笔不小的额外存储开销，未解决"零额外参数"的剪枝需求。
- **理论分析深度有限**：论文给出了 WRS 与掩码分布等价性的形式化证明，但对可微松弛带来的梯度偏差、退火策略如何影响收敛等方面缺少理论分析（仅依赖经验消融）。
