## 摘要
多模态推测解码通过允许轻量级草稿模型提出候选令牌，并由更大的目标模型进行并行验证，从而加速视觉-语言模型。现有方法通常将草稿器固定在固定的视觉接口上，例如预定义的视觉令牌预算或静态压缩表示。然而，我们的受控视觉预算分析表明，视觉需求在不同任务和解码阶段之间存在显著差异，这意味着更多的视觉输入并不总是有益的。实际上，证据不足可能削弱视觉基础，而过多的上下文会增加开销并可能干扰草稿生成。我们提出了FOVEA（聚焦按需视觉证据自适应），一种缓存友好的方法，它构建可重用的视觉记忆，并针对草稿状态动态检索有界子集。累积质量规则决定选择多少条目以及选择哪些条目。选中的条目被聚合为视觉读出，并通过轻量级门控残差校正与当前草稿隐藏状态融合。校正不将视觉令牌插入自回归上下文，而仅修改传递给语言模型头部的表示。在多个视觉-语言骨干和多模态基准上的实验表明，FOVEA提高了草稿接受率和端到端解码速度，相比自回归解码实现了高达2.13倍的加速。这些结果表明，状态条件证据检索是在整个多模态生成过程中重用固定视觉表示的有效替代方案。

## Abstract
Multimodal speculative decoding accelerates vision-language models by allowing a lightweight draft model to propose candidate tokens for parallel verification by a larger target model. Existing methods typically condition the drafter on a fixed visual interface, such as a predefined visual-token budget or a static compressed representation. However, our controlled visual-budget analysis shows that visual demand varies substantially across tasks and decoding stages, which means more visual input is not always beneficial. Actually, insufficient evidence may weaken visual grounding, while excessive context adds overhead and may disrupt drafting. We propose FOVEA (Focused On-demand Visual Evidence Adaptation), a cache-friendly approach that builds a reusable visual memory and dynamically retrieves a bounded subset for a draft state. A cumulative-mass rule determines both how many and which entries are selected. The selected entries are aggregated into a visual readout and fused with the current draft hidden state through a lightweight gated residual correction. Rather than inserting visual tokens into the autoregressive context, the correction modifies only the representation passed to the language-model head. Experiments across multiple vision-language backbones and multimodal benchmarks show that FOVEA improves draft acceptance and end-to-end decoding speed, achieving up to $2.13\times$ speedup over autoregressive decoding. These results demonstrate that state-conditioned evidence retrieval is an effective alternative to reusing a fixed visual representation throughout multimodal generation.

- **核心问题**：现有多模态草稿方法通常依赖**固定的视觉接口**——例如预定义的视觉 token 预算或静态压缩表示。但论文的受控分析表明，**视觉需求在不同任务、不同解码阶段、甚至不同草稿分支之间变化显著**，更多视觉输入并不总是更好：证据不足会削弱视觉基础，证据过量则增加开销并可能干扰草稿生成。
- **整体含义**：论文挑战了“单个全局固定视觉接口适用于所有解码状态”的假设，提出**状态条件证据检索**（state-conditioned evidence retrieval）作为更高效、更灵活的多模态推测解码范式，为 VLM 加速提供了新方向。

## 2. 方法论

### 2.1 核心思想

FOVEA 构建一个**每图像一次的可复用视觉记忆**，在每个草稿节点根据当前隐藏状态动态检索**有界子集**的视觉证据，并通过**门控残差校正**融合到当前打分表示中，**不向自回归上下文插入任何视觉 token**，因此不破坏历史 KV 缓存。

### 2.2 关键技术细节

- **视觉记忆构建**：目标模型对输入图像编码后得到投影视觉 token \(V = \{v_i\}_{i=1}^N\)，FOVEA 一次性构建：
  \[
  M_{img} = \{(k_i, u_i, m_i)\}_{i=1}^N, \quad k_i = W_K \mathrm{LN}(v_i),\ u_i = W_U \mathrm{LN}(v_i)
  \]
  其中 \(k_i\)、\(u_i\) 分别为 key 和 value，\(m_i\) 为有效位置掩码，记忆在所有解码迭代和树节点间共享。

- **状态条件检索**：对草稿节点 \(n\)，由隐藏状态 \(h_n\) 和树深度 \(\ell_n\) 构造查询：
  \[
  q_n = W_Q(\mathrm{LN}(h_n) + E_{dep}[\ell_n]),\quad s_{n,i} = \frac{q_n^\top k_i}{\sqrt{d_k}}
  \]
  对得分做 softmax 归一化后，使用**累积质量规则**动态决定检索数量 \(K_{r,n}\)（不引入额外可训练参数）：
  \[
  K_{raw} = \min\left\{k : \sum_{t=1}^k \tilde{\alpha}_{n,\pi(t)} \ge \rho\right\}, \quad K_{r,n} = \min(|V|, K_{\max}, \max(K_{\min}, K_{raw}))
  \]
  其中 \(\rho=0.8, K_{\min}=32, K_{\max}=256\)。选中的条目重新归一化后加权求和得到视觉读出 \(r_n\)。

- **缓存友好校正**：将 \(r_n\) 与 \(h_n\) 拼接送入两个网络：
  \[
  c_n = f_\theta([h_n; r_n]),\quad g_n = \sigma(g_\theta([h_n; r_n]))
  \]
  然后应用 RMSNorm 门控残差校正：
  \[
  \hat{h}_n = \mathrm{RMSNorm}(h_n + g_n c_n),\quad z_n = W_{LM}\hat{h}_n
  \]
  该过程仅改变打分表示，**不修改 token 序列、注意力掩码、位置标识或历史 KV 缓存**。

- **训练目标**：使用预计算的目标模型伪影，损失由三部分组成：
  - **隐藏状态对齐** \(L_{hid}\)：对齐最终和中间表示（β 加权）。
  - **分布蒸馏** \(L_{KL}\)：匹配教师分布 \(p_T\) 与草稿分布 \(p_D\)。
  - **令牌级候选形状** \(L_{tok}\)：交叉熵 + 候选边界 margin（提升候选集合质量）。
  总损失为加权求和，且对深位置施加指数衰减权重。

## 6. 主要结论与发现

- **固定视觉接口并非最优**：视觉预算敏感度随解码状态变化，且呈非单调关系。25% 预算在 56.0% 的状态下最优，而默认 75% 和全量预算仅分别对 4.0% 和 2.9% 的状态最优。
- **FOVEA 显著加速**：在三个骨干上平均加速分别达到 **1.68×、1.66×、1.60×**（相对 AR 基线），最高为 **2.13×**；相对最强基线平均提高 11.3%、13.7%、13.5%。
- **FOVEA 同时提升接受长度**：平均 \(\tau\) 为 3.960、3.882、3.925，比最强竞争方法高 8.1%、6.0%、5.6%。
- **接受长度 ≠ 端到端加速**：Vispec 虽有较高 \(\tau\)，但速度提升较低；FOVEA 在两者上同时取得最好成绩，说明其额外接受的 token 并未带来不成比例的草稿侧开销。
- **动态检索优于固定基数**：累积质量规则在多个任务上给出更均衡的加速与接受率折中；固定 K 表现出任务依赖且非单调的行为。
- **状态条件证据检索是有效替代**：不修改上下文、不破坏 KV 缓存，即可实现动态视觉聚焦，验证了该方法的通用有效性。

## 7. 优点

- **问题发现深入**：通过受控的视觉预算诊断，明确指出固定视觉接口的缺陷，并给出状态级别的量化证据（图 1、图 2）。
- **设计巧妙且缓存友好**：视觉记忆仅构建一次，检索只改变当前打分表示，不改写历史 KV 缓存，避免重复预填充和缓存失效。
- **动态检索无额外参数**：累积质量规则不引入可训练参数，易于实现且开销低。
- **实验广泛且严谨**：覆盖 3 种骨干、9 个基准、多种消融和控制实验，训练与评估分离、去污染，并报告重复运行标准差。
- **性能提升显著**：在速度与接受长度上同时取得最优，且在不同任务上均有加速（每个组合平均 >1×）。

## 8. 不足与局限

- **生成长度限制**：仅评估最多 200 tokens 的贪心解码，未覆盖长文本生成、采样式解码等更实际场景。
- **骨干覆盖有限**：仅使用 LLaVA-Next-7B/13B 和 Qwen2.5-VL-7B，缺少更大规模（如 70B 级）或更多架构（如基于 MoE）的验证。
- **诊断分析泛化性**：视觉预算诊断基于特定目标模型（LLaVA-Next-7B），结论是否普遍适用于其他 VLM 尚需验证。
- **超参数敏感性**：累积质量规则中的 \(\rho\)、\(K_{\min}\)、\(K_{\max}\) 为固定值，未系统研究其对不同任务/模型的影响。
- **校正

- **校正深度范围有限**：实验中视觉校正仅应用于树深度 \(\ell_n \le 1\)，即只对浅层草稿节点进行视觉调节。更深的草稿分支依然完全依赖纯语言模型分布，可能限制了在更长依赖任务上的候选质量收益。虽然论文在附录中分析了深度敏感性，但未提出或验证针对深度节点的自适应校正策略。

- **视觉记忆构建依赖目标模型**：视觉记忆由目标模型的视觉编码器和视觉-语言投影层产出，其质量直接受上游骨干影响。若目标模型本身对细粒度视觉信息的编码不足，FOVEA 的检索与校正效果也会被"天花板"所限制，无法弥补骨干模型的感知缺陷。

- **记忆存储开销未充分报告**：虽然每张图像只构建一次视觉记忆，但 \(M_{img}\) 需在解码期间常驻显存并与所有草稿节点共享；当图像分辨率高、视觉 token 数量大（如 576 及以上）时，key/value 记忆的显存占用与带宽开销未被系统量化，对显存受限场景的适配性有待验证。

- **任务覆盖偏向短答案型基准**：所选 9 个基准以多选、短文本答案（如 VQA、图表问答、OCR）为主，缺乏长文生成、多轮对话或视觉故事生成等任务，难以判断 FOVEA 在长上下文或需要持续视觉参考的解码场景下的收益是否依然显著。

- **与采样式解码的兼容性未验证**：所有实验均采用贪心解码。推测解码在实际部署中常配合温度采样、top-p 等随机策略使用，FOVEA 的蒸馏目标与门控机制在采样分布下的行为（如检索质量、接受长度分布）尚不明确。

- **训练数据规模与多样性的一般性局限**：训练集以 LLaVA-v1.5-Mix-665K 和 6,000 条任务数据为主，主要覆盖英文视觉指令数据。对中文、低资源视觉任务以及领域特定场景（如医疗影像、自动驾驶视觉）的适应能力未被检验。

## 9. 总结与展望

FOVEA 识别并实证了一个此前被忽视的关键事实——**多模态推测解码中的视觉需求是状态相关的**，并据此提出一种不修改上下文、不破坏 KV 缓存的轻量级状态条件证据检索机制。它用每图像一次的视觉记忆和动态有界检索，取代了固定视觉 token 预算的静态方案，在三个骨干模型和九个基准上同时取得了端到端加速与接受长度的最优成绩。

该工作的启示是多方面的：一方面，它表明**"视觉信息并非越多越好"**，证据供给应与解码状态的即时需求相匹配；另一方面，它的设计哲学——"在固定表征上做外挂式校正，而非重写序列"——对未来的高效多模态推理架构具有借鉴意义。后续工作可在以下方向延伸：

- **更大尺度与更多架构验证**：在 70B 级稠密模型和 MoE 架构上测试 FOVEA 的收益，并探索视觉 token 数量进一步提升时的记忆压缩策略。
- **与采样式解码和长上下文生成结合**：研究在温度采样、多轮对话、长视觉故事生成中，动态视觉检索是否能持续带来稳定加速。
- **自适应超参数**：让累积质量阈值 \(\rho\) 与检索上下界 \(K_{\min}, K_{\max}\) 随任务或解码进度自适应，减少人工调参。
- **将状态条件证据检索推广至纯文本推测解码**：类似机制或有潜力用于长文档推理，检索"文本证据"而非视觉证据。

总体而言，FOVEA 在问题发现、方法设计与实验论证上都呈现出较高的完成度，是一个兼具学术价值与工程实用潜力的工作。
