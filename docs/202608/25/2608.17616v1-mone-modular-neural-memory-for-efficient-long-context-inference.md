## 摘要
我们提出了MoNe，一种轻量级的模块化神经记忆，可附加到任何冻结的预训练Transformer上，无需重新训练即可实现长上下文推理。MoNe通过测试时学习快速权重神经记忆网络，并使用层局部梯度更新，以固定大小的分段读取上下文；在推理时，记忆仅从查询令牌生成键和值，不重新读取上下文令牌。这种两阶段设计将推理成本与上下文长度解耦，实现了O(N)预处理和O(1)查询成本，峰值GPU内存不随N增长。在128K令牌时，与ICL相比，MoNe将计算和峰值GPU内存均减少了约80%，而参数开销仅为6.4%。MoNe能够泛化到远超主干网络原生窗口的上下文长度，在RULER的针扎草堆和单词提取基准上表现强劲，而ICL在这些基准上性能急剧下降。

## Abstract
We present MoNe, a lightweight modular neural memory that attaches to any frozen pretrained Transformer to enable long-context inference without retraining. MoNe reads context in fixed-size segments via test-time learning of fast-weight neural memory networks with layer-localized gradient updates; at inference, the memory generates keys and values from the query tokens alone, with no context tokens re-read. This two-phase design decouples inference cost from context length, achieving $O(N)$ preprocessing and $O(1)$ query cost with peak GPU memory that does not grow with $N$. At 128K tokens, MoNe reduces both compute and peak GPU memory by approximately 80% compared to ICL with only 6.4% parameter overhead. MoNe generalizes to context lengths far beyond the backbone's native window, achieving strong performance on needle-in-a-haystack and word extraction benchmarks from RULER, where ICL degrades sharply.

## 1. 核心问题与整体含义（研究动机与背景）
- **长期上下文推理**是LLM实际应用的关键需求，例如个人助手、文档QA、智能体系统等。
- **标准方法ICL（In-Context Learning）**：将全部上下文作为提示喂给模型，计算复杂度为 \(O(N^2)\)，KV缓存随长度线性增长，在资源受限设备上不可行；小型模型即使在窗口内也容易丢失遥远信息，出现“上下文腐烂”（context rot）现象。
- **RAG（Retrieval-Augmented Generation）**：通过检索降低开销，但嵌入检索难以处理需要跨多个分散片段综合推理的任务。
- **现有线性复杂度模型（如Mamba、TTT、Titans）**：需要从头训练新架构，无法直接集成到已经预训练好的Transformer。
- **MoNe的目标**：为任意冻结的预训练Transformer附加一个轻量级模块化神经记忆，在不重新训练骨干的前提下，实现高效、可外推的长上下文推理，并将推理成本与上下文长度解耦。

## 2. 方法论：核心思想、关键技术细节
### 核心思想：两阶段设计
- **测试时学习（预处理阶段）**：将上下文 \(C\) 划分为固定大小段（\(T=512\)），逐段读取，并利用“层局部梯度更新”训练快速权重的神经记忆网络。
- **推理阶段**：查询token仅通过记忆网络生成固定数量的记忆token（作为键和值），不再读取任何上下文token。
- 效果：预处理 \(O(N)\)，查询成本 \(O(1)\)，峰值GPU内存不随 \(N\) 增长。

### 关键技术细节
- **记忆模块结构**：每层解码器附加一个SwiGLU MLP作为快速权重记忆 \(M(x; W)\)，其中 \(W = \{W_{in}, W_{gate}, W_{out}\}\)，每层4个快权重头，每头维度 \(d_h=224\)。
- **联想记忆损失**：给定段内token，先用冻结骨干的 \(W_k, W_v\)（带LoRA适配器）生成键 \(k\) 和目标值 \(v\)，损失定义为负内积：
  \[
  \ell = -v^T M(k; W)
  \]
  最大化记忆输出与目标值的内积，从而把“键→值”关联印入快速权重。
- **局部更新**：每个段的梯度只在该层内部计算，不跨层传播，因此更新高效且模块化。
- **推理时的注入**：查询token经 \(W_q\) 投影后读取最终快速权重，生成记忆token，再经 \(W_k, W_v\) 投影后与查询自身注意力拼接。
- **位置编码**：使用段内RoPE位置，位置索引始终在 \([0, T)\) 内，因此无需位置插值即可外推到任意长上下文。
- **元学习**：LoRA适配器（rank=128）和学习率、动量衰减等元参数离线训练，测试时固定，快速权重更新即是一个固定的学习算法。
- **额外特性**：支持多查询复用、增量扩展新上下文，无需重处理旧内容。

- **外推能力**：训练上下文仅4K，却能泛化到128K（32倍外推），得益于段内RoPE。
- **设计选择**：全层覆盖 + 段大小 \(T=512\) 是性能-效率最优配置；减少层数或缩小段大小都会显著损害长上下文性能，而FLOPs节省有限。
- **意义**：MoNe证明了“冻结骨干 + 测试时记忆学习”可以实现与ICL相媲美甚至更优的长上下文推理，同时成本恒定，特别适合设备端和持续学习场景。

## 7. 优点
- **即插即用**：不修改骨干权重，仅增加6.4%参数，可适配任何预训练Transformer。
- **成本解耦**：推理查询成本 \(O(1)\)，与上下文长度无关，峰值内存恒定。
- **模块化高效更新**：层局部梯度更新，无需跨层反向传播。
- **强长度外推**：无需重训练或位置插值，即可从4K泛化到128K。
- **实用性**：支持多查询复用、增量上下文扩展，适合资源受限的移动端和实时应用。
- **实验清晰**：在RULER三类检索/提取任务上给出了系统性的性能与成本对比，消融设计有助于理解关键因素。
