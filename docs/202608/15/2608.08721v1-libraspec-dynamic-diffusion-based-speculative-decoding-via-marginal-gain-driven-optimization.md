## 摘要
投机解码通过草拟多个令牌以供并行验证来加速大语言模型推理，其效率关键取决于每轮解码所选的投机长度。现有的动态投机方法通过估计将有多少令牌被接受来选择投机长度，这对于按顺序生成令牌的自回归草拟器是合理的。然而，最近的基于扩散的草拟器以显著更低的草拟成本并行生成候选块，将关键问题从生成多少个令牌转变为验证多少个生成的令牌是值得的。因此，我们将动态投机长度选择重新表述为期望加速优化问题，并推导出一个边际准则，仅当接受增益超过额外验证成本时扩展投机序列。基于此准则，我们开发了LibraSpec，一种无需训练且即插即用的算法，利用草拟器置信度分数迭代确定投机长度。理论上，我们证明LibraSpec单调收敛于最优投机长度。在六个目标模型、三种基于扩散的投机解码方法以及数学、编码和聊天基准上的实验表明，在贪心采样和随机采样设置下均有一致改进，相比基线进一步提升了$0.5\sim1.5\times$，相比自回归解码最高可实现$8.49\times$加速。

## Abstract
Speculative decoding accelerates large language model inference by drafting multiple tokens for parallel verification, with efficiency critically determined by the speculative length selected at each decoding round. Existing dynamic speculation methods select the speculation length by estimating how many tokens will be accepted, which is reasonable for autoregressive drafters that generates tokens sequentially. The recent wave of diffusion-based drafters, however, generates candidate blocks in parallel at substantially lower drafting cost, shifting the key question from how many tokens to generate to how many generated tokens are worth verifying. We therefore reformulate dynamic speculative-length selection as expected-speedup optimization and derive a marginal criterion that extends the speculative sequence only when its acceptance gain outweighs the additional verification cost. Building on this criterion, we develop \textit{LibraSpec}, a training-free and plug-and-play algorithm that iteratively determines the speculative length using drafter confidence scores. Theoretically, we prove that LibraSpec monotonically converges toward the optimal speculative length. Experiments across six target models, three diffusion-based speculative decoding methods, and math, coding, and chat benchmarks show consistent improvements under both greedy and sampling settings, achieving a further $0.5\sim1.5\times$ improvement over baselines and up to $8.49\times$ speedup over autoregressive decoding.

# LibraSpec：基于边际增益驱动的动态扩散投机解码

## 1. 核心问题与研究动机

投机解码（Speculative Decoding）通过轻量级草稿模型并行生成候选 token，再由目标模型一次性并行验证，从而在不改变目标输出分布的前提下打破自回归解码的串行瓶颈。其加速效果的关键在于每轮解码时所选择的**投机长度**（speculative length，即提交验证的候选 token 数量）：

- 长度过短 → 并行验证能力利用不足；
- 长度过长 → 前面 token 一旦被拒绝，后续 token 全部作废，浪费目标模型算力；
- token 可预测性在解码过程中不断变化，最优长度也随之变化，因此需要**动态投机长度选择**。

**本文指出现有方法的一个范式性缺陷：**

- 现有动态投机长度方法（如 DISCO、FailFast、G4-style 等）的思路是"预测下一轮会接受多少 token"，这在**自回归草稿器**下是合理的——因为自回归草稿每个候选 token 都有逐 token 的顺序生成成本，生成多少个本身就构成关键决策；
- 但**扩散式草稿器**（如 FastdLLM、DFlash、DDTree）是并行生成整个候选块，草稿成本极低且基本不随长度增加而线性增长，此时关键问题不再是"生成多少"，而是"**已经生成的这些 token 有多少值得送入验证**"；
- 仅仅估计接受长度不足以回答这个新问题：即使某个扩展片段很可能被接受，其边际接受收益也可能不足以抵消额外的验证开销。

## 2. 方法论

### 2.1 核心思想

将动态投机长度选择从"接受长度预测问题"重构为"**期望加速优化问题**"：扩展投机序列只有在"新增片段的接受收益/验证成本之比"高于"当前序列的平均收益/成本比"时，才是有益的。

### 2.2 关键定义与公式

**加速比模型（式 2，简化后）：**

\[
\eta_d \approx \frac{\tau_d \cdot L_{\text{target}}}{T_{\text{verify},d}}
\]

其中 \(\tau_d\) 为接受长度，\(T_{\text{verify},d}\) 为验证延迟。扩散式草稿下，草稿成本可视为固定、与投机长度无关，因此优化焦点完全落在"接受增益 vs 验证开销"的权衡上。

**单次有益调整（Definition 3.1）：** 调整 \(d \to d'\) 当且仅当 \(\mathbb{E}[\eta_{d'}] > \mathbb{E}[\eta_d]\) 时称为有益调整。

**边际准则（Theorem 3.2）：** 扩展（\(d < d'\)）当且仅当
\[
\frac{\mathbb{E}[\tau_{d:d'}]}{T_{\text{verify},d:d'}} > \frac{\mathbb{E}[\tau_d]}{T_{\text{verify},d}}
\]
即新增片段的边际收益比要优于当前平均收益比；截断则反向要求。

**位置感知必要条件（Theorem 3.3）与充分条件（Theorem 3.4）：** 在前缀接受假设下，对每个位置 \(i\) 定义最大可允许长度
\[
\epsilon_i = \max\left\{ d' \;\middle|\; d' < \frac{T_{\text{verify},i}}{\tau_i c} \sum_{j=i}^{d'} \prod_{k=i}^{j} p_k + i \right\}
\]
取 \(d' = \min_i \epsilon_i\) 即得到满足充分条件的最优调整长度。

**单峰性（Theorem 3.5）：** 期望加速是投机长度的单峰函数——条件边际收益随长度非增、边际验证成本近似恒定，因此扩展越过某阈值后不可能再恢复增长。

**收敛性（Theorem 3.6）：** 反复迭代有益调整，投机长度在有限步内单调收敛到全局最优长度区间。

### 2.3 算法流程（Algorithm 1: LibraSpec）

1. 生成一个大小为 \(n\) 的初始草稿块；
2. 将当前投机长度 \(d\) 设为初始块大小，维护一个草稿预算 \(B\)；
3. 循环直到 \(d \ge d_{\max}\)：
   - 用草稿模型的置信度分数 \(q_k\) 代替未知的目标接受概率 \(p_k\)，计算逐位置约束 \(\epsilon_i\)；
   - 若 \(\min_i \epsilon_i \le d\)，则回退到该值并终止调整；
   - 否则将 \(d\) 扩展到 \(\min_i \epsilon_i\)，消耗草稿预算；
   - 预算耗尽时才调用草稿模型生成新块（减少不必要的草稿调用与 I/O）；
4. 提交 \(d\) 个 token 进行验证。

**实践中的两个近似处理：**

- 假设 3.7：草稿模型置信度 \(q_i\) 与目标模型接受概率 \(p_i\) 足够校准（calibrated），用前者作为后者的在线代理；
- 引入超参数 \(\alpha = T_{\text{verify},i} \tau_i^{-1} c^{-1}\)（吸收运行时相关的验证开销项），控制调整的激进程度；
- 引入模型相关的最大投机长度上限 \(d_{\max}\)（因校准质量随推演长度增加而下降）；
- 设计上最多允许一次回退（rollback），防止迭代振荡。

## 6. 主要结论

- 扩散式草稿器改变了动态投机长度选择的优化目标：从"预测接受长度"转为"直接优化接受增益与验证成本之比"；
- 推导的边际准则（Theorem 3.2~3.6）为动态长度调整提供了理论保证：单峰性 + 有限步收敛到全局最优区间；

## 8. 不足与局限

- **依赖校准假设**：方法建立在"草稿模型置信度 ≈ 目标接受概率"（Assumption 3.7）之上，当草稿-目标分布偏差较大（如长投机距离）时校准退化，文中仅通过 \(d_{\max}\) 上限做硬约束，没有自适应校准机制；
- **超参数需要手动调节**：\(\alpha\) 和 \(d_{\max}\) 需要按草稿器特征人工设定（FastdLLM 用 60，DFlash/DDTree 用 24），且 \(\alpha\) 最优值在不同草稿器间不一致，缺少自动调参策略；

- **算力信息不透明**：未报告 GPU 型号细节、数量、总测时间、吞吐等完整算力信息，影响复现性评估；

- **可迁移性待验证**："边际收益/边际成本"框架理论上可扩展至自回归草稿器，但论文未做此验证，其泛化边界不清晰。
