## 摘要
推测性解码通过并行验证多个草稿令牌，无损地加速自回归语言模型。基于扩散的草稿者通过并行预测整个令牌块进一步减少提案延迟，但其逐位置分布是边缘分布，而非以沿每条草稿路径选择的令牌为条件。现有的循环校正沿单一草稿链纳入因果信息，而基于扩散的树构建拓宽了候选覆盖范围，却未沿各分支携带这种校正。我们提出DARTree，一种无需训练的推测性解码方法，将预训练的自回归校正头从链扩展到树。DARTree首先通过单批次展开并评分每个深度的所有节点来构建固定宽度的候选树，然后仅应用最佳优先剪枝选择验证树，从而将自回归头推理与顺序堆操作解耦。在七个数学、代码和聊天基准测试中，DARTree在全部四种模型-温度配置下实现了最高的平均接受长度和加速比，每轮验证最多接受12.97个令牌，比相同设置下的DFlash高98.6%，比Domino高27.9%，并相对于本地测量的自回归解码达到最高9.73倍的无损加速。

## Abstract
Speculative decoding losslessly accelerates autoregressive language models by verifying multiple draft tokens in parallel. Diffusion-based drafters further reduce proposal latency by predicting an entire token block in parallel, but their position-wise distributions are marginal rather than conditioned on tokens selected along each draft path. Existing recurrent correction incorporates causal information along a single draft chain, whereas diffusion-based tree construction broadens candidate coverage without carrying this correction along individual branches. We introduce DARTree, a training-free speculative decoding method that extends a pretrained AR correction head from chains to trees. DARTree first constructs a fixed-width candidate tree by expanding and scoring all nodes at each depth in a single batch, and then only applies best-first pruning to select the verification tree, decoupling AR-head inference from sequential heap operations. Across seven math, code, and chat benchmarks, DARTree achieves the highest average acceptance length and speedup in all four model--temperature configurations, accepting up to 12.97 tokens per verification round, 98.6\% more than DFlash and 27.9\% more than Domino in the same setting, and reaching up to 9.73$\times$ lossless speedup over locally measured autoregressive decoding.

## 1. 核心问题与整体含义（研究动机）

- **背景**：现代自回归（AR）大语言模型（LLM）推理本质上是逐 token 顺序进行的，严重受限于内存带宽（I/O-bound），硬件并行计算能力得不到充分利用，推理延迟明显。
- **现有加速思路的局限**：
  - **推测性解码（Speculative Decoding）**：用轻量草稿器生成多个候选 token，由目标模型并行验证，无损加速。但自回归草稿器仍需逐 token 顺序生成，草稿延迟随长度增长。
  - **扩散式块草稿器（Diffusion-based Block Drafter）**：一次前向生成整个 token 块，大幅降低提案延迟。但其逐位置分布是**边缘分布**，没有以块内前面已选 token 为条件，与目标模型的条件分布不匹配——即"因果失配"（causal mismatch）。
  - **因果校正头**（如 Domino、DSpark）：通过循环状态沿单一草稿链传播因果信息，部分弥补块内依赖缺失，但**仅限单链**。
  - **草稿树验证**（如 DDTree）：用树结构拓宽候选覆盖范围，但构建树时**没有携带分支级因果校正**。
- **关键矛盾**：将"因果校正"与"最佳优先树构建"结合时，产生严重效率瓶颈——每个栈节点弹出后都依赖其路径特定状态，校正头推理必须逐节点串行执行，无法批量并行。
- **DARTree 的核心意义**：首次将预训练的自回归校正头**从链扩展到树**，在保持路径因果校正的同时实现批量并行树构建，将扩散草稿器的高并行性与树验证的高覆盖度结合起来。

## 2. 方法论：核心思想、关键技术细节与算法流程

### 2.1 总体框架
DARTree 是**无需训练（training-free）**的推测性解码方法，工作流程为：块并行草稿 → **深度并行自回归展开** → **延迟最佳优先剪枝** → 单次目标模型树验证。

### 2.2 核心思想：解耦因果校正与顺序堆操作
- 传统的精确最佳优先树构建要求：堆弹出最高分前缀 → 校正头为该前缀的子节点评分 → 压入堆 → 重复。校正无法跨节点批量。
- DARTree 的洞察：**放松节点级搜索顺序，保留路径级因果校正**。同一深度的所有活动分支一次性批量校正、评分、选择，将顺序堆操作延迟到整个超树构建完成之后。

### 2.3 深度并行超树构建（Depth-Wise Parallel Supertree Construction）
- 块并行骨干网络**只执行一次**，产出整个草稿块的共享表示 \(\{H_d\}_{d=1}^\gamma\) 与基础 logits。
- 每位置仅取 top-K 候选 token 作为候选扩展，控制校正头开销。
- 从根开始，对每个深度 \(d\)：
  1. 选出候选集 \(C_d \leftarrow \text{TopK}(L_d^{\text{base}}, K)\)
  2. **批量**对前一层所有保留前缀 \(u_{<d} \in S_{d-1}\) 在 \(C_d\) 上执行校正头推理：\(eq_d(C_d | u_{<d}) = g_{C_d}(H_d, r(u_{<d}))\)
  3. 按校正累计分数评分每个子前缀：\(s_\beta(u_{1:d}) = s_\beta(u_{<d}) + \log eq_d(u_d | u_{<d}) + \beta\)
  4. 保留全局 top-W 子前缀作为下一层 \(S_d\)
  5. 并行更新其校正状态 \(r(u_{1:d})\)
- 固定层宽 W 保证每层是规整的批量任务：跨层串行，层内全张量化。

### 2.4 延迟最佳优先剪枝（Deferred Best-First Pruning）
- 超树完成后，每个前缀已有校正分数，此时可用**单次全局 top-B 操作**替代顺序最佳优先堆。
- 前缀分数公式：\(s_\beta(u_{1:d}) = \sum_{i=1}^d \log eq_i(u_i) + \beta d\)，其中 \(\beta \le 0\) 为深度罚项。
- **Lemma 1（堆-top-B 等价性）**：当 \(\beta \le 0\) 且平局时偏好祖先，最佳优先堆选择与全局 top-B 选择等价——因为父节点分数总不低于子节点，全局 top-B 集合天然前缀封闭。

### 2.5 算法流程（Algorithm 1 文字说明）
1. 初始化根层（空前缀）、根校正状态、根分数为 0。
2. 对深度 \(d = 1\) 到 \(\gamma\)：
   - 选取 top-K 候选。
   - 批量校正并评分当前层所有前缀的候选扩展。
   - 保留全局 top-W 子前缀，更新状态，存入超树。
3. 超树构建完毕，对全部节点做单次 top-B 剪枝，得到最终验证树。
4. 用树注意力掩码在目标模型中单次前向验证整棵树。

1. **全面最优**：DARTree（pruned）在所有 4 种模型-温度配置下均取得最高平均接受长度 τ 和最高加速比。在 GSM8K + Qwen3-4B + T=0 设置下，每轮接受 **12.97 个 token**，比 DFlash 高 **98.6%**、比 Domino 高 **27.9%**；加速比达 **9.73×**。

3. **延迟剪枝有效**：相对于 fixed 变体，pruned 变体进一步提升 τ 最高 6.5%、加速比最高 7.1%。

6. **适用场景明确**：低并发、内存带宽受限、计算资源富余的推理场景收益最大；高并发时需自适应调整 B 和 W。

## 8. 不足与局限

- **依赖预训练校正头**：DARTree 的"training-free"性质不适用于朴素扩散草稿器（如 DFlash），需要额外训练才能搭配校正头；评估也仅限于公开可用的兼容模型。
- **不减少总计算量**：DARTree 用额外计算换取低延迟，本质上是"计算换延迟"；树验证开销大于非树方法，在所有环境下并非最优。
- **应用场景受限**：仅适合低并发、计算资源富余的环境；高并发下（C≥8）固定 B=64 的加速比迅速退化，甚至低于基线（表 4 中 DDTree 与 DARTree 在 C=16~32 时的相对收益明显收缩）。
