## 摘要
基于Transformer的大型语言模型（LLM）在许多任务上表现出色，但其键值（KV）缓存随序列长度线性增长，为长上下文推理带来了严重的内存瓶颈。现有的启发式驱逐方法（如H$_2$O和SnapKV）依赖静态注意力或位置信号，往往无法捕捉token未来的预测影响力。我们提出了DistillCache，一个将KV缓存驱逐建模为序贯决策问题的强化学习框架。DistillCache利用丰富的内部模型信号（注意力统计量、值范数、熵和位置）学习一个轻量级策略网络，并通过基于每步KL散度奖励的REINFORCE算法训练，以保持完整缓存的输出分布。在70亿参数的指令微调Transformer（Mistral-7B-Instruct-v0.3）上，DistillCache在25%缓存预算下保留了LongBench上94.2%的完整缓存准确率，在长上下文任务上比强启发式基线（H$_2$O、SnapKV）高出最多2.7个绝对百分点，并在我们的复现实现下，比并行的基于RL的方法（ForesightKV、RLKV）高出最多1.4个绝对百分点。在推理基准上，DistillCache与最佳并行方法相当，并在激进压缩下超越它。它还实现了最高2.1倍的完整缓存吞吐量，同时保持了有竞争力的实际效率。这些结果凸显了学习型、分布感知策略在内存高效的长上下文LLM推理中的有效性。

## Abstract
Transformer-based large language models (LLMs) achieve strong performance across many tasks, but their Key-Value (KV) cache grows linearly with sequence length, creating a severe memory bottleneck for long-context inference. Existing heuristic eviction methods (e.g., H$_2$O and SnapKV) rely on static attention or positional signals that often fail to capture a token's future predictive influence. We propose DistillCache, a reinforcement learning framework that formulates KV-cache eviction as a sequential decision problem. DistillCache learns a lightweight policy network using rich internal model signals (attention statistics, value norms, entropy, and position) and trains it with REINFORCE via a per-step KL-divergence reward to preserve the full-cache output distribution. On a 7B-parameter instruction-tuned Transformer (Mistral-7B-Instruct-v0.3), DistillCache retains 94.2% of full-cache accuracy on LongBench at a 25% cache budget, outperforming both strong heuristic baselines (H$_2$O, SnapKV) by up to 2.7 absolute points and, under our re-implementations, concurrent RL-based methods (ForesightKV, RLKV) by up to 1.4 points on long-context tasks. On reasoning benchmarks, DistillCache is competitive with the best concurrent method and surpasses it under aggressive compression. It also delivers up to 2.1x full-cache throughput while maintaining competitive practical efficiency. These results highlight the effectiveness of learned, distribution-aware policies for memory-efficient long-context LLM inference.

## 论文总结

### 1. 论文的核心问题与整体含义

- **研究背景**：Transformer大语言模型在自回归解码中依赖KV缓存来避免重复计算之前的token表示，但随着上下文窗口的扩展，KV缓存大小随序列长度线性增长，成为严重的内存和吞吐瓶颈。
- **现有方法局限**：已有的KV缓存压缩方法（如H₂O、SnapKV）基于注意力统计或位置信号，采用固定的启发式重要性评分来保留token。但这些方法假设过去的注意力模式能可靠预测未来效用，在长程依赖或结构化推理场景中可能失效，无法捕捉token的**未来预测影响力**。
- **核心问题**：如何在一个固定的内存预算下，选择保留哪些KV缓存条目，使得修剪后的模型与完整缓存模型的输出分布保持尽可能接近？
- **本文方案**：提出**DistillCache**，一个基于强化学习的KV缓存驱逐框架，将缓存管理建模为序贯决策过程，直接优化token保留决策以保持完整缓存输出分布的保真度。

### 2. 方法论

- **核心思想**：训练一个轻量级策略网络，在每一解码步骤动态决定哪些KV缓存token应被保留，优化目标是最小化修剪模型与完整缓存模型之间的每步KL散度，而非依赖启发式代理信号。
- **问题建模**：将KV驱逐建模为序贯决策过程——每一步政策观察当前缓存的token特征，选择保留的子集，并根据修剪模型匹配完整缓存模型的奖励进行优化。
- **状态空间**：对缓存中的每个token i构造五维特征向量：`x_i = [αi, ∥vi∥₂, σi, Hi, posi]`，包括：
  - αi：token i作为key在所有头/层上接收的平均注意力
  - ∥vi∥₂：token i的值向量L2范数
  - σi：各头间注意力接收量的方差
  - Hi：基于64个最近查询的注意力加权平均熵（反映token被集中还是弥散注意力选中）
  - posi：归一化序列位置
- **动作空间**：MLP策略网络为每个token打分，训练时通过Gumbel扰动（Gumbel噪声+Top-B选择）从Plackett–Luce分布中采样子集；推断时确定性选择Top-B。
- **训练架构**：维护**教师缓存**（不剪枝，计算完整分布P_t）和**学生缓存**（按策略剪枝，计算分布P̂_t），两个前向通过的KL散度作为奖励。
- **奖励函数**：`R_t = -D_KL(P_t ∥ P̂_t)`，即完整缓存与剪枝缓存下一token分布之间的负KL散度。
- **理论依据**：论文推导了每步KL散度与驱逐注意力质量ε_t之间的上界关系：`D_KL ≤ 2C'²ε_t²/σ²_min`，为KL奖励提供了理论基础。
- **策略优化**：使用REINFORCE加熵正则化和方差缩减基线（RLOO留一基线 + EMA基线），折扣因子γ=0.99，熵系数β=0.01。Gumbel-Top-B的log-概率通过动态规划精确计算log-配分函数。
- **训练vs推断**：训练时双缓存双前向（内存翻倍），离线执行；推断时只保留单前向，策略剪枝为下一步做准备，不改变当前token生成。
