## 摘要
大语言模型（LLM）的日益部署加剧了自回归解码的计算和内存瓶颈，其中低计算强度和带宽受限的内核主导了推理成本。权重剪枝提供了一种有前景的解决方案，但现有方法要么局限于静态剪枝（SP），即永久移除冗余权重但缺乏自适应性，要么局限于动态剪枝（DP），即适应输入稀疏性但引入运行时不规则性。本文提出SPDP，一种统一的稀疏推理框架，将非结构化SP与输入自适应DP相结合，用于在GPU上高效进行LLM推理。SPDP协同设计了一种新的平铺列式位图压缩（Tiled-CBC）格式和两个互补的GPU内核：（1）一个CUDA核心的spMspV内核，具有混合激活感知动态共享内存位图解码（HAD-SMBD），用于细粒度的运行时激活跳过；（2）一个针对预填充计算优化的Tensor-Core SpMM内核。这种联合格式-内核设计协调了静态和动态稀疏性，在LLM推理的两个阶段都保持了带宽高效的内存访问和高计算强度。在推理优化GPU上的综合评估表明，与SpInfer等最先进的稀疏框架相比，SPDP实现了1.24倍至1.37倍的平均加速（最高可达2.51倍），同时以高达25%的更高稀疏性匹配困惑度。SPDP推进了推理效率-质量帕累托前沿，表明统一的静态-动态剪枝可以在大规模LLM服务中带来显著的吞吐量和每瓦特性能提升。

## Abstract
The increasing deployment of large language models (LLMs) has magnified the computational and memory bottlenecks of autoregressive decoding, where low compute intensity and bandwidth-bound kernels dominate inference cost. Weight pruning offers a promising remedy,   but existing methods remain confined to either static pruning (SP), which permanently removes redundant weights but lacks adaptivity, or dynamic pruning (DP), which adapts to input sparsity but introduces runtime irregularity. This paper presents SPDP, a unified   sparse-inference framework that integrates unstructured SP with input-adaptive DP for efficient LLM inference on GPUs. SPDP co-designs a new Tiled-Column-wise Bitmap Compressed (Tiled-CBC) format and two complementary GPU kernels: (1) a CUDA-core spMspV kernel   featuring Hybrid Activation-aware Dynamic Shared-Memory Bitmap Decoding (HAD-SMBD) for fine-grained, runtime activation skipping, and (2) a Tensor-Core SpMM kernel optimized for prefill computation. This joint format-kernel design harmonizes static and dynamic   sparsity, maintaining bandwidth-efficient memory access and high compute intensity under both phases of LLM inference. Comprehensive evaluations on inference-optimized GPUs demonstrate that SPDP achieves 1.24x-1.37x average speedup (up to 2.51x) over state-of-the-   art sparse frameworks such as SpInfer, while matching. perplexity with up to 25% higher sparsity. SPDP advances the inference efficiency-quality Pareto frontier, showing that unified static-dynamic pruning can deliver substantial throughput and performance-per-watt   improvements in large-scale LLM serving

## 1. 论文的核心问题与整体含义

- **背景与动机**：大语言模型（LLM）的自回归解码阶段存在严重的计算与内存瓶颈。该阶段本质上是 **内存带宽受限**（memory-bound）的任务，尤其在 batch 较小、交互式推理场景下，权重矩阵加载占比大、计算强度低，导致推理效率低下。同时，test-time scaling 与 agentic AI 的兴起进一步加剧了解码阶段 token 生成量，使得单次推理会话消耗的时间和能耗急剧增长。
- **核心问题**：权重剪枝是缓解上述瓶颈的有效手段，但现有方法呈现两难局面：
  - **静态剪枝（SP）**：离线移除冗余权重，显著减小模型内存占用与带宽需求，但缺乏输入自适应性，可能误剪对特定上下文重要的参数，影响模型质量。
  - **动态剪枝（DP）**：依据输入动态跳过不重要的激活，具备上下文感知能力，但其结构化粒度较粗、灵活性有限，且不减少权重存储，还会引入运行时 mask 生成和控制流的额外开销。
  - 更重要的是，**静态剪枝与动态剪枝在系统层面难以直接组合**：SP 的稀疏核按行主序优化 SpMM（稀疏矩阵-矩阵乘法），而 DP 将解码计算转化为列稀疏的 spMspV（稀疏矩阵-稀疏向量乘法），两者在内存布局、warp 调度和 Tensor Core 利用上存在根本性冲突。
- **论文整体含义**：论文提出 **SPDP** 统一稀疏推理框架，首次从系统层面融合非结构化静态剪枝与输入自适应动态剪枝，通过**联合格式-内核协同设计**，在解码和预填充两个阶段同时实现带宽高效访问和高计算强度；实验表明，SPDP 在同等模型质量下实现更高的压缩率和更低的推理延迟，推动了大模型推理的**效率-质量帕累托前沿**。

## 2. 论文提出的方法论

### 2.1 核心思想
- **SP 与 DP 的互补性**：SP 沿行方向剪枝权重，DP 沿列方向跳过激活；两者作用维度正交，重叠极小（实验测得重叠率接近理论独立乘积水平），因此联合使用可**成倍**提升有效稀疏度。
- **系统层面需要协同设计**：理论稀疏增益并不自动转换为实际加速，必须解决三个关键挑战：(1) SP 与 DP 的内存布局不匹配；(2) Tensor Core 在动态稀疏场景下利用率急剧下降；(3) 同一格式需同时满足预填充（SpMM）阶段的高效执行。

### 2.2 Tiled-CBC 压缩格式
- **Tiled-CBC**（Tiled-Column-wise Bitmap Compressed）是 SPDP 的核心稀疏表示：
  - 权重矩阵被分层划分为 **GTiles**（外层，行主序排列），每个 GTile 包含多个**列瓦片**（256×1），列瓦片是压缩与剪枝的最小单位。
  - 每个列瓦片的稀疏位置用 4 个 `uint64_t` 位图（共 64 位对齐）编码，非零值按列顺序紧凑存储。
  - 引入轻量级元数据 **ColInfo**（每列打包存储起始偏移 `TileOffset_Col` 和非零个数 `NNZ_Column`），支持运行时按列跳过、连续访存，实现低开销的输入自适应访问。
  - 总体存储开销公式：  
    `Store_Tiled-CBC = 4B×(NGT+1) + 4B×(NGT×TILE_K) + 8B×NBM + 2B×NNZ`

### 2.3 解码阶段：SPDP-spMspV 内核
- **执行路径**：选用 **CUDA Core** 而非 Tensor Core，因为动态稀疏将计算退化为 GEMV/spMspV，Tensor Core 利用率极低，CUDA Core 反而更适合细粒度列级跳过。
- **HAD-SMBD 解码机制**：在 SpInfer 的 SMBD 基础上扩展出 "混合激活感知动态共享内存位图解码"：
  - 按列主序将压缩瓦片解码为寄存器中的 warp-level 片段，匹配 GEMV 的累加模式。
  - **两阶段解码**：第一阶段基于 `MaskedPopcount` 计算前缀秩，解码当前 FP16 lane；第二阶段复用相同元数据解码配对的第二个 lane，避免重复计算。
  - 动态剪枝下非激活列被整体跳过，不参与解码。
- **异步流水线**：
  - 采用三级独立 `cp.async` 异步复制组，分别管理 **ColInfo 加载**、**XTile 加载**、**GTile 加载**，最大化访存与计算重叠。
  - **元数据预取**机制：先预取下一迭代的列激活模式，再按需加载数据，形成"元数据在前、数据在后"的两步预取流水线，避免无关内存事务。
  - 使用双缓冲（GTile/XTile 各两份）+ 寄存器预取（HAD-SMBD），实现近零开销的动态剪枝。

### 2.4 预填充阶段：SPDP-SpMM 内核
- 预填充阶段仅应用 SP，对应 **SpMM** 计算，适合 Tensor Core 执行。
- 复用同一 Tiled-CBC 格式，增加 **Layout Alignment** 阶段：将列主序的 WTile 转换为 Tensor Core 所需的行主序操作数布局，该转换完全在共享内存内完成，并通过填充（padding）避免 bank conflict，配合 `ldmatrix` 指令实现无冲突转置。
- 异步流水线中去除了 DP 相关阶段，并调整 XTile 加载与寄存器传输以适配矩阵输入。

## 6. 论文的主要结论与发现

- **核级性能**：SPDP-spMspV 在 A10G 上平均加速 1.88×（最高 3.32×）对比 cuBLAS；1.24×（最高 1.70×）对比 SpInfer。L4 上平均加速 2.11×（最高 3.52×）对比 cuBLAS；1.37×（最高 2.52×）对比 SpInfer。
- **端到端性能**：SPDP 在同等稀疏率下 TPOT 优于 SpInfer（平均约 1.34×），且 PPL 更低（维持在 5.4 以下）；在同等 PPL 下，SPDP 可实现比 SpInfer 高最多 **25% 的稀疏率**，同时 TPOT 更低或相当。
- **硬件效率**：SPDP 获得最高的 SM 利用率（66.0% vs. SpInfer 的 38.2%–48.0%），最低的 bank conflicts（74 vs. 3817–4491），同时维持相当的 DRAM 带宽利用率。
- **模型质量**：联合 SP 与 DP 在各类稀疏率下均优于单一方法；在 4-bit RTN 量化下质量保持稳定。
- **联合稀疏性有效性**：SP 与 DP 的剪枝决策重叠接近理论独立水平，确认两者可组合出预期的累积稀疏度。
- **特定适用范围**：SPDP 面向 LLM 中等稀疏度（30%–50%）的推理场景，并不适用于极端稀疏（>95%，如 SuiteSparse 矩阵）通用稀疏线性代数；预填充阶段主要价值在于统一格式与减小内存占用，而非计算加速。

## 7. 优点

## 8. 不足与局限

- **实验覆盖的局限**：
  - 端到端实验仅报告 7B 级别模型（Llama-2-7B）；虽然 kernel 层涵盖更大规模矩阵形状，但缺少更大模型（如 70B、120B）的整机端到端验证。
  - 所有实验限于 NVIDIA 推理 GPU，未在 HBM 高端数据中心 GPU（如 A100/H100）上验证，也未实际在 CPU/NPU 上实现。
- **预填充阶段收益有限**：论文承认在较大输出宽度下，LSCD 式稀疏预填充无法超越稠密 cuBLAS，实际部署可能需"预填充用稠密、解码用 SPDP"的组合策略。
- **动态剪枝范围受限**：DP 主要基于阈值式（如 TEAL）逐 token 列跳过；对明确 mask/bitmap 形式的 DP 变体需要额外适配；**不支持 batch 维度上的批量动态剪枝**（batched DP），需后续扩展。
- **量化叠加的收益非乘性**：低比特量化仅压缩 Values，位图/元数据/填充开销不变，导致量化与稀疏联合时实际增益受限（论文已坦诚指出）。
- **算力资源数据缺失**：未报告具体 GPU 数量、功耗实测值、训练/标定总时长等资源消耗数据。
- **SuiteSparse 表现不佳**：验证了 SPDP 并非通用稀疏核，适用范围明确限于中等稀疏度 LLM 场景；在极高稀疏度下，Tiled-CBC 的位图与元数据开销反而拖累性能。
