## 摘要
投机解码通过草拟多个令牌进行并行验证来加速大语言模型推理，其效率关键取决于每轮解码所选择的投机长度。现有的动态投机方法通过估计将接受多少令牌来选择投机长度，这对于按顺序生成令牌的自回归草稿模型来说是合理的。然而，最近一波基于扩散的草稿模型以大幅降低的草稿成本并行生成候选块，将关键问题从生成多少令牌转变为验证多少生成的令牌是值得的。因此，我们将动态投机长度选择重新表述为期望加速优化，并推导出一个边际标准，仅当其接受增益超过额外验证代价时才扩展投机序列。基于这一标准，我们开发了LibraSpec，一种无需训练且即插即用的算法，利用草稿模型置信度分数迭代地确定投机长度。理论上，我们证明LibraSpec单调收敛于最优投机长度。在六个目标模型、三种基于扩散的投机解码方法以及数学、编程和聊天基准上的实验表明，在贪婪和采样设置下均有持续改进，相比基线进一步实现了$0.5\sim1.5\times$的提升，并相对于自回归解码实现了最高$8.49\times$的加速。

## Abstract
Speculative decoding accelerates large language model inference by drafting multiple tokens for parallel verification, with efficiency critically determined by the speculative length selected at each decoding round. Existing dynamic speculation methods select the speculation length by estimating how many tokens will be accepted, which is reasonable for autoregressive drafters that generates tokens sequentially. The recent wave of diffusion-based drafters, however, generates candidate blocks in parallel at substantially lower drafting cost, shifting the key question from how many tokens to generate to how many generated tokens are worth verifying. We therefore reformulate dynamic speculative-length selection as expected-speedup optimization and derive a marginal criterion that extends the speculative sequence only when its acceptance gain outweighs the additional verification cost. Building on this criterion, we develop \textit{LibraSpec}, a training-free and plug-and-play algorithm that iteratively determines the speculative length using drafter confidence scores. Theoretically, we prove that LibraSpec monotonically converges toward the optimal speculative length. Experiments across six target models, three diffusion-based speculative decoding methods, and math, coding, and chat benchmarks show consistent improvements under both greedy and sampling settings, achieving a further $0.5\sim1.5\times$ improvement over baselines and up to $8.49\times$ speedup over autoregressive decoding.

### 1. 核心问题与整体含义（研究动机与背景）

- **背景**：投机解码（Speculative Decoding）利用轻量级草稿模型生成候选 token 序列，再由目标模型并行验证，从而在不改变输出分布的前提下加速大语言模型推理。整个过程的效率高度依赖于每轮选择的**投机长度（speculative length）**——即提交验证的候选 token 数量。
- **现有方法的局限**：动态投机长度方法（如 DISCO、FailFast、Gemma 4 MTP 等）的核心思路是**预测期望接受长度**（expected accepted length）。这对自回归草稿器是合理的，因为每个额外候选 token 都伴随顺序生成成本。然而，以 FastdLLM、DFlash、DDTree 为代表的**扩散式草稿器**以并行方式生成候选块，草稿成本极低，使得关键问题从"生成多少个 token"转变为"有多少已生成 token 值得验证"。
- **核心洞察**：仅估计接受长度不足以决定投机长度，因为**即使新增段落很可能被接受，其边际增益也可能不足以覆盖额外验证成本**。论文据此将动态投机长度选择重新表述为一个**期望加速优化问题**，并推导出相应的边际准则。

### 2. 方法论（核心思想、技术细节与算法流程）

**核心思想**：将投机长度选择视为期望加速（expected speedup）的迭代优化，而非接受长度的预测。长度调整只有在"接受增益超过验证成本"时才是值得的。

**关键技术细节**：

- **加速模型**：给定长度 $d$ 的草稿块，投机解码加速比为
$$\eta_d = \frac{\tau_d L_{\text{target}}}{T_{\text{draft}}^d + T_{\text{verify}}^d}$$
其中 $\tau_d$ 为被接受的连续 token 数，$L_{\text{target}}$ 为目标模型单 token 延迟，$T_{\text{draft}}^d$ 和 $T_{\text{verify}}^d$ 分别是草稿生成与验证时间。在扩散式草稿器下草稿成本可忽略，因此 $\eta_d \approx \tau_d L_{\text{target}} / T_{\text{verify}}^d$，即效率主要由**接受的 token 数与验证成本之比**决定。

- **单次有益调整（Definition 3.1）**：长度从 $d$ 调整为 $d'$ 当且仅当 $\mathbb{E}[\eta_{d'}] > \mathbb{E}[\eta_d]$。

- **边际准则（Theorem 3.2）**：有益调整等价于**新增/删除段落的边际收益必须高于/低于当前平均收益**：
  - 扩展（$d < d'$）：要求 $\mathbb{E}[\tau_{d:d'}] / T_{\text{verify}}^{d:d'} > \mathbb{E}[\tau_d] / T_{\text{verify}}^d$
  - 截断（$d > d'$）：要求 $\mathbb{E}[\tau_{d':d}] / T_{\text{verify}}^{d':d} < \mathbb{E}[\tau_d] / T_{\text{verify}}^d$

- **充分必要条件（Theorem 3.3 与 3.4）**：在位置级强化准则下，通过展开边际增益（$\mathbb{E}[\tau_{i:d'}] = \sum_{j=i}^{d'} \prod_{k=i}^{j} p_k$）和边际验证成本（$T_{\text{verify}}^{i:d'} = c(d'-i)$），推导出每个位置 $i$ 的允许最大长度 $\epsilon_i$，取所有位置的下确界 $d' = \min_i \epsilon_i$ 即为充分条件。

- **单峰性与收敛性（Theorem 3.5 与 3.6）**：由于 $\prod_{i=1}^{d} p_i$ 随 $d$ 单调非增，期望加速是投机长度的**单峰函数**；迭代应用有益调整可在有限步内收敛到全局最优区间。

- **实际算法（Algorithm 1: LibraSpec）**：
  1. 生成大小为 $n$ 的初始草稿块，设置 $d = n$，维护草稿预算 $B$；
  2. 用草稿模型置信度 $q_i$ 作为目标接受概率 $p_i$ 的代理（假设校准良好），计算 $\epsilon^* = \min_i \epsilon_i$；
  3. 若 $\epsilon^* \leq d$，回退并终止；否则更新 $d = \epsilon^*$，消耗预算，预算不足时按需生成新草稿块；
  4. 提交 $d$ 个 token 验证。
  - 引入**最大投机长度 $d_{\max}$** 约束校准随投机距离增大而退化的问题；引入**超参数 $\alpha$** 吸收运行时验证代价参数，控制调整激进程度。

### 8. 缺点与局限性

- **理论推导基于较强的理想化前提**：Theorem 3.3–3.6 假设位置级接受概率互不相关且验证成本与长度呈线性关系（$T_{\text{verify}}^{i:d'} = c(d'-i)$）。真实系统中验证成本可能受批量大小、显存带宽、并行度等非线性因素影响，导致理论最优长度与实际最优长度存在偏差。

- **对比基线不够全面**：未与 BlockPilot、BanditSpec 等基于强化学习或 bandit 的最新动态投机长度方法直接对比；也缺少与"静态最优长度"的公平对比细节（如静态长度如何选取）。

- **理论框架有进一步推广空间**：论文的加速比模型 $\eta_d = \tau_d L_{\text{target}} / (T_{\text{draft}}^d + T_{\text{verify}}^d)$ 是一个简化模型，未显式建模调度开销、内存拷贝、token 生成的批量并行度等。若将这些因素纳入，边际准则的形式可能发生变化，这也可能是后续工作可探索的方向。
- **算法设计体现了工程与理论的平衡**：充分必要条件给出了理论下界，实际算法在此基础上引入预算、$d_{\max}$、$\alpha$ 等工程化修正，在保证理论性质的同时兼顾了系统鲁棒性。这种"理论指导设计、工程修正偏差"的策略值得借鉴。
- **对扩散式投机解码的启示**：论文明确指出了扩散式草稿器与自回归草稿器的成本结构差异，这意味着未来针对扩散式草稿器的优化应更多关注**验证阶段的成本控制**而非**生成阶段的长度预测**，为后续研究指明了方向。

### 10. 总结

LibraSpec 针对扩散式草稿器（FastdLLM、DFlash、DDTree 等）的并行低成本特性，提出了一种基于边际加速分析的无训练动态投机长度选择算法。它将投机长度决策从"预测接受长度"重构为"期望加速优化"，通过完整的理论推导（必要条件、充分条件、单峰性、收敛性）保证了算法的正确性，并借助草稿预算、$d_{\max}$ 约束、超参数 $\alpha$ 等工程机制增强了实用性。实验在 6 个目标模型、4 个基准、2 种解码设置下一致验证了其有效性，最高达到 8.49× 端到端加速比，并展现出对思考模式、超参数变化的高度鲁棒性。尽管存在置信度校准假设理想化、统计显著性证据不足、部署场景覆盖有限等局限，LibraSpec 仍不失为扩散式投机解码领域一项具有理论深度和实用价值的重要工作。
