## 摘要
基于Transformer的大型语言模型（LLM）在许多任务上表现出色，但其键值（KV）缓存随序列长度线性增长，给长上下文推理带来了严重的内存瓶颈。现有的启发式驱逐方法（如H$_2$O和SnapKV）依赖静态注意力或位置信号，往往无法捕捉token未来的预测影响力。我们提出DistillCache，一种强化学习框架，将KV缓存驱逐建模为序贯决策问题。DistillCache利用丰富的内部模型信号（注意力统计、值范数、熵和位置）学习轻量级策略网络，并通过REINFORCE算法结合每步KL散度奖励进行训练，以保持完整缓存的输出分布。在7B参数指令调优的Transformer（Mistral-7B-Instruct-v0.3）上，DistillCache在25%缓存预算下保留了LongBench上94.2%的完整缓存准确率，比强启发式基线（H$_2$O、SnapKV）高出最多2.7个绝对百分点，并且在我们重新实现的基线中，比并行的基于RL的方法（ForesightKV、RLKV）在长上下文任务上高出最多1.4个百分点。在推理基准上，DistillCache与最佳并行方法相当，并在激进压缩下超越它。它还提供最高2.1倍的完整缓存吞吐量，同时保持有竞争力的实际效率。这些结果凸显了学习型、分布感知策略在内存高效的长上下文LLM推理中的有效性。

## Abstract
Transformer-based large language models (LLMs) achieve strong performance across many tasks, but their Key-Value (KV) cache grows linearly with sequence length, creating a severe memory bottleneck for long-context inference. Existing heuristic eviction methods (e.g., H$_2$O and SnapKV) rely on static attention or positional signals that often fail to capture a token's future predictive influence. We propose DistillCache, a reinforcement learning framework that formulates KV-cache eviction as a sequential decision problem. DistillCache learns a lightweight policy network using rich internal model signals (attention statistics, value norms, entropy, and position) and trains it with REINFORCE via a per-step KL-divergence reward to preserve the full-cache output distribution. On a 7B-parameter instruction-tuned Transformer (Mistral-7B-Instruct-v0.3), DistillCache retains 94.2% of full-cache accuracy on LongBench at a 25% cache budget, outperforming both strong heuristic baselines (H$_2$O, SnapKV) by up to 2.7 absolute points and, under our re-implementations, concurrent RL-based methods (ForesightKV, RLKV) by up to 1.4 points on long-context tasks. On reasoning benchmarks, DistillCache is competitive with the best concurrent method and surpasses it under aggressive compression. It also delivers up to 2.1x full-cache throughput while maintaining competitive practical efficiency. These results highlight the effectiveness of learned, distribution-aware policies for memory-efficient long-context LLM inference.

## 2. 方法论

**核心思想：** 用强化学习训练一个轻量级策略网络，在每一步解码时根据 token 的内部信号打分并选择 top-B 子集保留，**以完整缓存（teacher）与剪枝缓存（student）的每步 KL 散度作为奖励**，直接优化"分布保真度"。

**关键技术细节：**

1. **状态表示（特征工程）**：对每个缓存中的 token i 构造 5 维特征向量：
   - αi：跨头/跨层的平均注意力质量（被关注程度）
   - ‖vi‖₂：value 向量的 ℓ2 范数
   - σi：注意力质量跨头的方差
   - Hi：注意力加权熵（对近期查询的注意力熵做加权平均）
   - posi：归一化序列位置

2. **动作空间**：轻量级两层 MLP（约 200K 参数）为每个 token 输出标量分数；训练时加 Gumbel 噪声得到随机排序采样（等价于 Plackett–Luce 分布上的 top-B 子集采样），推理时直接确定性地选 top-B。

3. **Teacher-Student 双缓存训练架构**：
   - Teacher 缓存从不剪枝，用于计算完整缓存分布 Pt；
   - Student 缓存按策略逐步剪枝，用于计算剪枝后分布 P̂t；
   - 每步奖励 Rt = −DKL(Pt ∥ P̂t)，即负 KL 散度。

4. **理论基础**：论文证明了每步 KL 散度上界与驱逐注意力质量平方成正比（通过 Lipschitz 连续性 + softmax 局部 Lipschitz 推得），为该奖励设计提供了理论基础。

5. **策略优化**：REINFORCE + Gumbel-Top-B（Plackett–Luce 分布策略梯度）+ RLOO 基线 + 熵正则（β=0.01）+ 折扣因子 γ=0.99。逐步给出结果：

   - 训练时的分布形成是通过**两步前向传播**获得，推理时仅需要一次前向传播，策略网络在剪枝阶段运行。

**推理流程（Algorithm 1）：**
- 每步仅一次前向传播 → 生成 logits、更新 KV 缓存 → 提取特征 → 策略网络打分 → 确定性 top-B 剪枝 → 用于下一步；当前 token 由未剪枝的前向 logits 选出，剪枝不影响当前预测。

## 6. 主要结论与发现

1. **准确率-预算权衡**：在 25% 缓存预算下，DistillCache 在 LongBench 上保留 94.2% 的完整缓存准确率（39.1 vs 41.5），优于 H₂O（36.4）和 SnapKV（37.0）各 2.7 和 2.1 个绝对百分点，也优于 ForesightKV（38.2）和 RLKV（37.7）；在 12.5% 的激进压缩下优势更大。
2. **推理任务**：RLKV 在中等预算（50%/25%）下略强，但 DistillCache 在 12.5% 下反超（39.9 vs 38.9），说明 token 级分布保真在极端压缩下更关键。
3. **上下文长度**：DistillCache 在 8K token 长度下优势最明显（38.1 vs ForesightKV 37.0、RLKV 36.4），说明学习式策略在预算真正吃紧时方显优势。
4. **Perplexity**：25% 预算下 perplexity 增加仅 +0.35，为所有方法中最低。
5. **吞吐量**：相较完整缓存约 2.1 倍加速；与 RL 方法吞吐相当，略低于启发式方法。
6. **跨模型迁移**：Mistral-7B 训练的 policy 零样本迁移到 Llama-3-8B 后，仍优于 native 启发式基线，且无需重训。
7. **RL 对比监督**：监督蒸馏排序器（37.8）低于完整 RL（39.1），证实 RL 优化的增量收益不仅来自特征工程。
8. **定性行为**：策略倾向于保留否定词、从句主导动词等逻辑一致性 token，且不依赖硬编码保护即能学到 attention-sink + 近期窗口模式，同时补充了固定规则遗漏的上下文敏感 token。

## 7. 优点

- **问题重新定义**：将 KV 驱逐从静态启发式/代理标签问题重构为**分布保真度上的序贯决策问题**，目标与生成质量直接对齐。
- **理论上界支撑**：通过注意力输出误差 → logit 误差 → softmax KL 上界的推导链，为 KL 奖励提供了理论依据。
- **每步 KL 奖励的优势**：KL 散度天然对低熵分布更敏感，从而自动惩罚最易受驱逐影响的峰值预测，无需显式的低熵 token 过滤机制。
- **轻量策略与在线部署**：仅 200K 参数、推理期单次前向、确定性 top-B 选择，实际开销可控且与系统级优化（offloading、PagedAttention、FlashDecoding++）正交可组合。
- **优秀的跨模型泛化能力**：Mistral 训练的 policy zero-shot 迁移至 Llama-3-8B 仍具竞争力，显著摊销训练成本。
- **实验透明度高**：明确披露对比方法的实现为 re-implementation；报告 5 种子的均值±标准差；有完整的消融体系。
- **可组合性**：与头级门控方法（RLKV）混合可进一步提升 (+0.7)，说明方法论之间的互补性。

## 8. 不足与局限

- **训练成本高**：约 130 GPU-hours（2×RTX 4090），且训练内存翻倍（双缓存），明显高于零训练的启发式方法。
- **RL 稳定性问题**：REINFORCE 存在高方差，虽有 RLOO 基线、熵正则、多种子平均等缓解措施，但 PPO/GRPO 等可能更稳定（代价是更复杂）。
- **对标方法对比的偏差风险**：与 ForesightKV 和 RLKV 的对比基于**最佳努力的重新实现**，而非官方模型/代码，原始论文的超参设置可能不同，数值差距存在不确定性。
- **推理开销**：约 +1.4 ms/token 相对 H₂O 的额外延迟，吞吐略低于启发式方法（38.0 vs 42.8 tokens/s）。
- **独立评分假设**：策略对每个 token 独立打分，未显式建模 token 间的交互；特征设计耦合 transformer 注意力机制，迁移到非注意力架构需重新设计。
- **评估规模有限**：仅在 7B/8B 模型、最长约 8K 上下文的设置下验证，未涉及 13B+ 或 32K–128K 超长上下文；仅单个 GPU 节点，未在分布式多租户环境中验证系统级收益。
