## 摘要
投机性解码通过并行验证多个草稿标记，无损加速自回归语言模型。基于扩散的起草者通过并行预测整个标记块进一步降低提议延迟，但其逐位置分布是边缘分布，而非以每条草稿路径上选定的标记为条件。现有的循环校正沿着单一草稿链引入因果信息，而基于扩散的树构建则拓宽了候选覆盖范围，但未沿各分支携带这种校正。我们提出DARTree，一种无需训练的投机性解码方法，将预训练的自回归校正头从链扩展到树。DARTree首先通过单批次扩展并评分每个深度的所有节点来构建固定宽度的候选树，然后仅应用最佳优先剪枝来选择验证树，将自回归头推理与顺序堆操作解耦。在七个数学、代码和聊天基准测试中，DARTree在所有四种模型-温度配置下均实现了最高的平均接受长度和加速比，每轮验证最多接受12.97个标记，在相同设置下比DFlash多98.6%，比Domino多27.9%，并相对于本地测量的自回归解码达到最高9.73倍的无损加速。

## Abstract
Speculative decoding losslessly accelerates autoregressive language models by verifying multiple draft tokens in parallel. Diffusion-based drafters further reduce proposal latency by predicting an entire token block in parallel, but their position-wise distributions are marginal rather than conditioned on tokens selected along each draft path. Existing recurrent correction incorporates causal information along a single draft chain, whereas diffusion-based tree construction broadens candidate coverage without carrying this correction along individual branches. We introduce DARTree, a training-free speculative decoding method that extends a pretrained AR correction head from chains to trees. DARTree first constructs a fixed-width candidate tree by expanding and scoring all nodes at each depth in a single batch, and then only applies best-first pruning to select the verification tree, decoupling AR-head inference from sequential heap operations. Across seven math, code, and chat benchmarks, DARTree achieves the highest average acceptance length and speedup in all four model--temperature configurations, accepting up to 12.97 tokens per verification round, 98.6\% more than DFlash and 27.9\% more than Domino in the same setting, and reaching up to 9.73$\times$ lossless speedup over locally measured autoregressive decoding.

# DARTree 论文深入分析

## 1. 核心问题与研究动机

投机性解码（Speculative Decoding）通过轻量级草稿模型提出多个候选令牌、再由目标模型并行验证，从而在不改变输出分布的前提下加速自回归 LLM 推理。然而，现有方法面临以下核心矛盾：

- **扩散式并行草稿**（如 DFlash）能一次生成整个令牌块，极大降低提议延迟，但其逐位置分布是**边缘分布**，未按已选择的前缀令牌进行条件化，与目标模型的自回归条件分布存在“因果失配”（causal mismatch）。
- **因果修正头**（如 Domino、DSpark 的循环修正）可沿单条草稿链恢复部分因果依赖，但**只能处理单一链**，无法覆盖多条候选分支。
- **草稿树**（如 DDTree）能拓宽候选覆盖范围，但基于扩散边际分布构建，未能携带各分支自身的因果修正信息。
- 若将因果修正与堆式最优优先树构建**直接耦合**，每个堆弹出后必须执行一次修正头推理，导致修正头只能逐节点串行运行，形成严重延迟瓶颈（论文实测约 70 ms/轮，是 DARTree 的 2 倍以上）。

**核心挑战**：如何在保持路径依赖修正的前提下，对多条分支进行**批量并行**扩展，从而兼顾因果修正质量与树构建效率。

## 2. 方法论：DARTree

### 2.1 核心思想

DARTree 是一种**免训练**的投机解码方法，将预训练好的自回归（AR）修正头从**单链**扩展到**树结构**。其核心思路是：在每一深度**批量**扩展并评分所有候选节点，先构建一个比最终验证树更宽的候选超树（supertree），再通过延迟的全局 top-B 剪枝得到紧凑的验证树，从而**将 AR 头推理与顺序堆操作解耦**。

### 2.2 关键技术细节

- **深度方向并行超树构建**（Depth-Wise Parallel Supertree Construction）
  - 块并行扩散主干只执行一次，得到共享表示 {H_d} 和各位置 base logits；每个位置只保留 top-K 个候选令牌作为扩展候选项。
  - 从根节点开始，每个深度 d 将当前活跃分支**批量打包**，并行应用预训练修正头（基于各分支自身的前缀 token 历史）计算条件分布 eq_d(C_d | u_{<d})。
  - 按修正后的累积对数概率给每个子节点打分，保留全局 top-W 的子节点进入下一深度。
  - 深度之间仍然串行依赖，但**同一深度内的修正、评分、选择、状态更新全部张量化**，因此增加层宽 W 的额外延迟很小。

- **延迟最佳优先剪枝**（Deferred Best-First Pruning）
  - 超树构建完成后，所有节点已有修正分数，可直接用一次全局 Top-B 选择代替逐节点的堆操作。
  - 每个前缀的得分为：**s_β(u₁:d) = Σᵢ log eqᵢ(uᵢ) + βd**，其中 β ≤ 0 为深度惩罚项。
  - **Lemma 1**（堆–Top-B 等价性）：当 β ≤ 0 且平局时优先祖先时，顺序堆选择与全局 Top-B 选择结果等价（因为父节点分数恒不小于子节点，全局 Top-B 集合天然前缀封闭）。

- **候选覆盖率与预算控制**
  - 设置验证预算 B 控制最终传给目标模型的节点总数；可用更宽的超树进行起草，最后再剪枝到 B。
  - 默认配置：K=64（候选词表大小），W=12（层宽），B=64（验证预算），β=-0.2。

### 2.3 算法流程（Algorithm 1）

1. 输入：一次块并行传递得到共享表示和 base logits；修正头 g；候选词数 K；层宽 W；预算 B；深度惩罚 β。
2. 初始化根层 S₀={∅}，根修正状态 r(∅)，根分数 s_β(∅)=0。
3. 对深度 d=1 到 γ：
   - 选择 C_d ← TopK(base logits, K)；
   - 对所有前缀 u_{<d} ∈ S_{d-1} 在 C_d 上批量计算修正分布 eq_d；
   - 计算每个子节点的分数 s_β = 父分数 + log eq_d + β；
   - 保留全局 top-W 子前缀作为 S_d，并行更新修正状态；
   - 将所有保留节点加入超树 S。
4. 全部深度完成后，对 S 中所有节点执行全局 Top-B 剪枝，返回最终验证树 T。
5. 目标模型使用树注意力掩码一次性验证整棵树。

## 6. 主要结论与发现

- **DARTree (pruned) 在所有 4 种模型–温度配置下均取得最高的平均接受长度和加速比**，无例外。

- **在 T=1 随机采样下收益同样稳健**，不仅限于贪心解码。
- **通用性验证**：DARTree 同样适用于 DSpark-Markov 修正头（τ 提升 14.6%~40.6%），说明它不是 Domino 专属方法。

## 7. 优点与亮点

1. **免训练即插即用**：直接复用现有预训练修正头，无需任何额外训练即可扩展到树结构。
2. **高效解耦设计**：深度方向批量扩展将修正头推理与堆操作分离，避免逐节点串行修正，是方法的核心创新；实测每轮延迟仅约 28-29 ms（vs 顺序堆方法约 63-66 ms）。
3. **理论保障**：Lemma 1 证明了负深度惩罚下全局 Top-B 等价于顺序堆选择，为延迟剪枝提供了理论基础，保证无损加速性质。
4. **通用架构**：不假设特定修正头结构，可适配 RNN、Markov 等多种因果修正方案。
5. **兼顾质量与覆盖**：融合了扩散并行草稿的效率、AR 修正头的因果保真度和树验证的候选覆盖优势；接受率曲线显示它兼具 DDTree 的早期接受率和 Domino 的后期延伸能力。
6. **坦诚的部署分析**：附录明确讨论适用场景并给出并发实验数据，不回避方法在特定环境下的局限。
7. **效率扩展性好**：层宽从 4 增至 12 时接受长度明显提升而延迟增长很小（图 1 显示 16 路并行宽度下 AR 树增长延迟仅为 0.87→1.29 ms）。

## 8. 不足与局限

1. **依赖预训练修正头**：免训练性质不适用于没有修正头的朴素扩散草稿器；纯 DFlash 需要额外训练才能适配 DARTree。这限制了方法的直接适用范围。
2. **计算开销更大**：作为树方法，DARTree 比非树方法验证更多候选令牌，总 FLOPs 和计算量反而增加——它用额外计算换延迟降低，在计算受限环境不适用。
3. **高并发场景收益衰减**：并发数增加时（C≥8），固定大树的验证开销使加速比快速下降；需自适应调整 B 和 W 才能维持性能（DARTree adaptive 在高并发下仍有较好表现，但低于低并发时的增益）。
4. **固定宽度非最优**：层宽 W 统一应用于所有深度，无法像真正的自适应搜索那样根据各深度的不确定性动态分配节点；W>12 后收益饱和，存在效率天花板。
5. **模型和基准覆盖面有限**：仅用 Qwen3-4B/8B 两个目标模型，未在更大模型（如 70B+）或其他模型家族上验证；也缺少与 EAGLE-2/3 等启发式树构建方法的直接对比。
6. **AIME25 上的微小例外**：Qwen3-8B + T=1 时 DDTree 的加速比略高于 DARTree（4.56× vs 4.50×），说明在特定数据集上仍有优化空间。
7. **未探索更长草稿块**：论文自身指出，相当比例的轮次到达草稿块边界（16 tokens），更长块可能进一步提升接受率——这是未来工作方向。
8. **深度惩罚是人工超参**：β 需要手动调节（最优约 -0.2 到 -0.1），不同数据集或模型可能需要重新调整。
