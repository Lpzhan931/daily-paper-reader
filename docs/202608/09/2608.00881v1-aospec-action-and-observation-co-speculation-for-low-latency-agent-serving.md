## 摘要
大语言模型智能体越来越多地通过有状态工具进行操作，然而模型生成与环境执行在每一步仍然是串行的。随着解码速度的加快，工具执行成为日益增长的瓶颈。现有的仅动作或仅观察的推测方法暴露了大量延迟：价值集中在少数缓慢的调用上，某些结果只能通过执行才能显现，而更长的前瞻通常需要越来越不可能的动作预测链。我们提出了AOSpec，一个无损框架，在整个智能体-环境循环中协同推测动作和观察。期望价值解码（EVD）引导观察推测朝向具有最大期望延迟收益的结果，优化期望隐藏时间而非命中率。对于只有执行才能揭示的结果，AOSpec在包含其效果的隔离分叉中启动延迟关键的目标动作，而联合动作-状态验证（JASV）在重用前验证动作及其来源状态与已提交的执行是否一致。JASV将长视野动作依赖从全链预测重构为目标动作-状态验证，打破了前瞻-准确性权衡，在不牺牲串行语义的情况下解锁长距离重叠。在涵盖四个测试框架、五个行动者模型和五种服务速度的Terminal-Bench服务设置中，AOSpec优于所有实际基线，将平均端到端延迟降低11.8-32.5%，p99延迟降低最高42.8%。其收益随着解码加速而增加，并且其观察模型无需重新训练即可从Terminal-Bench迁移到SWE-bench Verified。

## Abstract
Large language model agents increasingly act through stateful tools, yet model generation and environment execution remain serialized at every step. As decoding accelerates, tool execution becomes a growing bottleneck. Existing action- or observation-only speculation leaves much of this latency exposed: value is concentrated in a few slow calls, some outcomes emerge only through execution, and longer lookahead typically requires an increasingly unlikely chain of action predictions. We present AOSpec, a lossless framework that co-speculates actions and observations across the full agent-environment loop. Expected Value Decoding (EVD) directs observation speculation toward outcomes with the greatest expected latency benefit, optimizing expected time hidden rather than hit rate. For outcomes only execution can reveal, AOSpec launches latency-critical target actions in isolated forks that contain their effects, while Joint Action-State Verification (JASV) verifies both the action and its origin state against committed execution before reuse. JASV recasts long-horizon action dependency from full-chain prediction into target action-state verification, breaking the lookahead--accuracy tradeoff and unlocking long-range overlap without sacrificing serial semantics. Across Terminal-Bench serving settings spanning four harnesses, five actor models, and five serving speeds, AOSpec outperforms every practical baseline, reducing mean end-to-end latency by 11.8-32.5% and p99 latency by up to 42.8%. Its gains increase as decoding accelerates, and its observation model transfers from Terminal-Bench to SWE-bench Verified without retraining.

## 1. 核心问题与研究动机

LLM 智能体越来越依赖有状态工具（如文件操作、进程管理）完成任务，但在典型的“演员-环境”循环中，模型生成（decoding）与环境工具执行是逐步骤串行的。随着解码速度不断提高（如 1 ms/token），工具执行时间成为端到端延迟的主要瓶颈。现有研究仅从单侧入手：

- **动作推测**：预测未来的工具调用并提前执行，但长链条预测精度呈乘性坍塌；
- **观察推测**：从临时观察继续生成，但无法处理环境依赖型结果。

论文通过 profiling 发现三个关键挑战：延迟集中（少数长调用占据绝大多数工具时间）、环境依赖（部分观察只有执行才能揭示）、前瞻权衡（更长的预测链带来更多重叠机会但准确率急剧下降），因此需要一种同时覆盖“动作—观察”全循环的推测机制。

## 2. 方法论核心

### 核心思想
AOSpec 是**无损（lossless）**的协同推测框架，同时推测动作和观察，跨越整个智能体—环境循环，在不牺牲串行语义的前提下将工具执行时间隐藏到模型生成期间。

### 关键技术细节

**（1）Expected Value Decoding（EVD）**
- 目标：优化**期望隐藏时间**而非命中率。
- 候选观察排序公式：Vo(c) = pθ(c | Ht, at) · T̂(c)，其中 T̂ 由历史相似结果的工具耗时加权估计。
- EVD 将“预测正确性”与“该预测能隐藏多少延迟”解耦，优先推进延迟关键的高价值观察。

**（2）隔离分叉执行（Isolated Fork Execution）**
- 对只有执行才能揭示的环境依赖型观察，AOSpec 在隔离沙箱分叉中启动延迟关键的目标动作，利用快照/拷贝/回滚能力容纳其副作用；
- 无法隔离的效果不参与推测，保证安全性。

**（3）Joint Action–State Verification（JASV）**
- 验证条件：ValidAct(f, ai, Si) = [âf = ai] ∧ [ν(Sf) = ν(Si)]，即预测动作与目标动作一致，且分叉来源环境版本与已提交环境版本一致；
- 将长视野动作依赖从“全链条预测”重构为“目标动作—状态验证”，无需预测中间动作链，即可实现跨步骤重叠，极大缓解长链预测准确率坍塌问题；
- 验证过程基于 copy-on-write 文件系统镜像的版本号比较，计算开销小。

### 算法流程（简化文字描述）
AOSpec 在每一轮中：启动演员生成 → 根据历史启动推测性动作分叉 → 当演员输出动作时，用 JASV 验证是否存在可用分叉；若有则复用其结果，否则现场执行 → 执行等待期间，用 EVD 启动多个观测草稿，每个草稿可继续推进演员生成 → 真实观察返回后，仅保留与该观察字节一致的推测分支，其余全部丢弃并提交当前环境。

## 3. 实验设计

### 数据集与场景
- **Terminal-Bench 2.0**：主要评测基准，涵盖 4 个智能体 harness（mini-swe-agent、OpenHands、Gemini CLI、Judy）× 5 个演员模型，共 9 种 harness–模型组合。
- **SWE-bench Verified**：用于跨基准迁移测试，观测模型仅用 Terminal-Bench 轨迹训练，不做重新训练。

### 对比方法
- **Serial**：串行执行基线；
- **Spec-Actions**：仅动作推测（Qwen3.6-35B-A3B-FP8 预测下一动作）；
- **SpecHop-cache / SpecHop-LLM**：两种仅观察推测变体（缓存复用 vs. LLM 草拟）；
- **Oracle-action**：从轨迹获得正确下一动作的一步动作推测上界。

### 评测方式
采用 trace replay，固定相同演员轨迹，扫描 5 种 TPOT（20/15/10/5/1 ms/Token），共 45 个配置组合，报告端到端延迟降低、工具时间隐藏量、精确预测率等指标。

## 6. 主要结论与发现

1. AOSpec 在全部 45 个配置中**优于所有实用基线**，平均端到端延迟降低 11.8%（20 ms TPOT）至 32.5%（1 ms TPOT）；
2. p99 延迟最高降低 **42.8%**，且尾部收益显著大于中位数收益（与“延迟集中”观察一致）；
3. 增益随解码加速而**增大**，与工具执行逐渐主导延迟的趋势相符；
4. 观测模型可**跨基准迁移**到 SWE-bench，无需重新训练；
5. EVD 相比纯概率或纯耗时排序，在相同预测数量下隐藏更多工具时间；
6. JASV 成功打破“前瞻深度—准确率”权衡，远距离动作推测仍然可用。

## 7. 优点

- **问题刻画透彻**：通过 profiling 数据明确论证三个直觉性但未被量化的挑战，有据可依；
