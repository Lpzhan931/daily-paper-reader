## 摘要
现代视觉语言模型（VLM）将高分辨率图像转化为长序列的视觉标记。每个标记都经过语言解码器，并持续存在于其提示的KV缓存中，从而推高推理成本，并促使进行激进的视觉压缩。现有的基于评分的方法为每个标记分配独立的显著性分数，并保留Top-K。然而，文本查询消耗的是来自视觉群体的集体、有符号的注意力消息，而非孤立的补丁。因此，同样大小的Top-K集合可能会重复覆盖一个显著区域，遗漏稀疏但互补的证据，并丢弃被移除群体所携带的信息。为此，我们将忠实的视觉压缩表述为构建解码器消息的紧凑核心集，并引入我们无需训练的grounded消息核心集剪枝（GMC），它在查询grounded、外观和坐标感知证据之间联合分配支持，然后在物理压缩和原生注意力恢复之前，将丢弃的状态转移到选定的代表中，并置于其原始的多模态位置。这将忠实的压缩分解为两个耦合的组成部分，包括选择覆盖所需消息模式的载体，以及在这些载体上实现带符号的群体消息。我们进一步推导了将它们与带符号消息失真、视觉创新性和候选边缘稳定性联系起来的界限。在多个VLM家族和不同基准上的实验证明了强大的性能，其中GMC-H2在Qwen2.5-VL-7B上使用减少80.2%的视觉标记保留了97.78%的Full-relative平均能力，而GMC-L16达到了100.36%。受控干预验证了集体支持和群体实现共同驱动这些增益。

## Abstract
Modern vision language models (VLMs) turn high-resolution images into long sequences of visual tokens. Every token traverses the language decoder and persists in its prompt KV cache, inflating inference cost and motivating aggressive visual compression. Existing score-based methods assign each token an independent importance score and retain the Top-K. However, text queries consume collective, signed attention messages from the visual population, not isolated patches. Consequently, equally sized Top-K sets can repeatedly cover one salient region, omit sparse but complementary evidence and discard information carried by the removed population. We therefore formulate faithful visual compression as constructing a compact coreset for decoder messages, and introduce our training-free Grounded Message Coreset Pruning (GMC) which jointly allocates support across query-grounded, appearance, and coordinate-aware evidence, then transports discarded states into selected representatives at their original multimodal positions before physical compaction and native attention resume. This decomposes faithful compression into two coupled components, including selecting carriers that cover the required message modes and realizing the signed population message on those carriers. We further derive bounds connecting their errors to signed-message distortion, visual innovation, and candidate-margin stability. Experiments across multiple VLM families and diverse benchmarks demonstrate strong performance, with GMC-H2 retaining 97.78% Full-relative mean capability on Qwen2.5-VL-7B using 80.2% fewer visual tokens, while GMC-L16 reaches 100.36%. Controlled interventions verify that collective support and population realization jointly drive these gains.

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：现代 VLM（如 Qwen2.5-VL、LLaVA）将高分辨率图像编码为长序列视觉 token（可达上千甚至上万）。每个视觉 token 都需经过语言解码器，并常驻于 prompt KV cache 中，导致推理成本（算力与显存）随图像分辨率急剧膨胀。因此，视觉 token 压缩成为降低多模态推理开销的关键手段。
- **现有方法的缺陷**：主流方法将压缩归结为"每个 token 有多重要"的标量问题，通过注意力分数、特征范数或敏感性估计保留 Top-K 个 token。论文指出这类方法存在**结构性盲区**：
  - 文本查询消费的是**视觉群体的集体、有符号（signed）注意力消息**，而非孤立 patch 的独立贡献；
  - 相同预算的 Top-K 集合可能**重复覆盖同一显著区域**，遗漏稀疏但互补的证据（如数字、坐标端点、图表刻度）；
  - 硬删除（hard deletion）会**丢失被删除群体的全部信息**，而先择后合并（merge after selection）又使"证据保留在哪里"与"每个代表应携带什么"脱钩。
- **核心观点**：忠实的视觉压缩不应是"挑选重要 token"，而应被重新定义为**为解码器消息构建一个紧致核心集（grounded message coreset）**。支持分配（where to keep evidence）与消息实现（what each carrier carries）是两个耦合的组件，必须联合优化。

## 2. 方法论：GMC（Grounded Message Coreset Pruning）

### 2.1 核心思想

GMC 是**训练无关（training-free）** 的框架，不依赖任务标签、参数更新、外部检测器或 OCR。它将压缩分解为两个耦合的子问题：

1. **选择载体（Carrier Selection）**：在 N 个视觉 token 中选取 K 个代表，使其共同覆盖三种互补的证据模式——查询驱动（query-grounded）、外观（appearance）、空间坐标（coordinate-aware）；
2. **实现群体消息（Population Realization）**：将未选中 token 的状态通过加权质心传输（transport）到选定代表上，保留其原始多模态位置，随后在物理压缩后的序列上恢复原生注意力（native attention）。

### 2.2 关键技术细节

- **边界消息几何（Boundary Message Geometry）**：在压缩边界层 p，利用原生 RMS 归一化、M-RoPE、因果注意力掩码计算 Q/K/V。取视觉列注意力切片 \(A_h\)（包含与所有非视觉 key 的竞争，而非视觉-only 重归一化），构造 headwise 齐次坐标 \(\sigma_{c,h}\)，形成带符号贡献向量 \(u^{c,h,t}_i\) 与概率化载体责任分布 \(P^G_{c,h,t}(i)\)。
- **三种客户端（Clients）**：
  - **Grounded clients**：由原生 head-query 注意力贡献诱导，覆盖已被文本查询访问的证据；
  - **Appearance clients**：基于归一化边界特征的 Gibbs 核 \(\propto \exp(x_m^\top x_i / \tau_v)\)，保护尚未被 prompt 激活的未来内容；
  - **Spatial clients**：基于原始网格坐标的径向 landmark 核，防止支持坍缩到单一显著区域，保护空间关系证据。
- **互补覆盖（Complementary Coverage）**：最大化加权 facility-location 目标 \(F(S) = \sum_m \max_{i \in S} \bar{C}_{mi}\)。该目标归一化、单调、子模（submodular），一个 token 的价值仅通过其**未覆盖残差**体现，因此高分的冗余 patch 会迅速失去边际增益。采用分批贪心求解（batch size \(b=16\)，候选池 \(4b\)），并用式 (4) 的 softmax 责任分配加速。
- **群体运输（Population Transport）**：每个未选中 token 分配给同图内最相似的选中代表（余弦相似度 + 空间门控项），然后计算加权质心 \(c_j = M_j^{-1} \sum_{i \in C_j} m_i h_i\)，再经 RMS 恢复保持原始尺度。**关键性质**：在 RMS 恢复前，运输精确保持有符号群体一阶矩 \(\sum_j M_j W c_j = \sum_i m_i W h_i\)（对任意线性 W）。
- **物理压缩（Physical Compaction）**：删除未选中的视觉位置，保留每个代表**原始的多模态位置 ID**，文本状态不变。计算从第 p 层恢复，后续所有层以 K 个视觉 token 运行。
- **理论分析**：
  - **Proposition 1**：给出分批贪心求解器的实际覆盖率证书 \(F(S_T) \ge c_B F(S^*)\)，其中 \(c_B\) 可在不访问最优解的情况下记录；
  - **Proposition 2**：将消息误差分解为**载体量化项**（覆盖控制）与**紧致注意力质量失配项**（运输与原生注意力控制），二者**加法式**进入同一上界，说明选择与实现不可互相替代；
  - **Lemma 1（候选边缘稳定性）**：当压缩诱导的 logit 失真 \(d_C < \gamma_{ab}/\sqrt{2}\) 时，候选排序不会翻转。并给出全词汇表翻牌概率的事件包含上界。

## 6. 主要结论与发现

- **性能**：GMC-H2 在 Qwen2.5-VL-7B 上以 80.2% 更少的视觉 token 保留 **97.78%** Full-relative 平均能力（K=256）；GMC-L16 达 **100.36%**（略超 Full）。K=128 时两者分别保留 93.51% 与 **99.11%**。
- **LLaVA 迁移**：GMC-L16 在 K=64/128 处获得 99.82% / 99.76% 六任务平均保留率，无需架构特定调参。
- **幻觉控制**：GMC-L16 在 K=128 下 POPE、AMBER、HallusionBench、CHAIRs、CHAIRi 全面优于 VisionZip 与 MMTok，且差异经 Holm 校正后仍显著。
- **效率-质量平衡**：H2 在相同 token 层工作量下领先 MMTok 2.40–2.87 个百分点，同时最终保留 token 更少；L16 则以更高保真的紧凑 prompt 接近 Full 行为。
- **机制验证**：
  - 支持构建（而非运输）是主要增益来源；GMC 支持优于全部四个对照选择器；
  - 群体运输在稀疏支持下增益最大（+0.19 点宏平均），与历史视图存在 +0.32 点交互效应；
  - 候选 logit 误差是翻牌的最强预测因子（AUROC 最高），验证了理论分析中"消息误差 → 排序失真 → 答案翻牌"的链条。
- **理论证书**：21.6% 的评估样例满足确定性无翻牌条件且零违规；450 个前瞻性候选条件中 0 个逃逸，覆盖全部 27 次 top-1 翻牌。

## 7. 优点

- **问题定义深刻**：把压缩从"挑重要 token"重构为"构建有符号消息核心集"，切中 Top-K 剪枝的本质局限（集体消费、符号抵消、互补证据）。
- **训练无关且即插即用**：无需训练、梯度、外部模型、OCR 或检测器，直接接入原生 Q/K/V 投影与注意力计算。
- **支持与实现解耦**：将非负覆盖（选择载体）与有符号消息实现（运输 + 原生注意力）分离，两者误差进入同一上界且可分别审计，理论框架清晰严格。
- **保留原始位置**：物理压缩后保留原始 M-RoPE 坐标，使紧凑注意力在正确的多模态坐标系中计算，避免了位置扰动带来的隐性信息损失。
- **实验严谨**：多模型、多预算、多任务、同路径受控对比、配对置信区间、Holm 校正、多层级机制诊断（覆盖 → 消息误差 → VIE → 翻牌），统计规范值得借鉴。
- **效率证据扎实**：同时报告 token 层工作量、prompt-KV 字节、峰值显存与端到端延迟，明确区分"表示容量"与"解码器工作量"。

## 8. 不足与局限

- **算力细节不透明**：未披露评测所用 GPU 的数量与集群规模、具体功耗或成本，读者难以精确复现推理比对的绝对硬件环境。
- **基座模型覆盖有限**：主实验只在 Qwen2.5-VL-7B 与 LLaVA-1.5-7B 两个模型上验证，未涵盖更大规模（如 72B）或多模态组织（如 LLaVA-NeXT、InternVL）系列，泛化结论的宽度受限。
- **L16 的冗余性**：L16 保留了 61.38% 的 token 层工作量（K=128），其端到端加速接近 1.0× 甚至略低于 Full；它更多作为"高保真紧凑 prompt"而非"显著加速"的运行点，实用性定位需要读者自行权衡。
- **部分组件增益有限**：空间 bank 在聚合宏平均上近乎中性（−0.08 / +0.05 点），其价值集中于特定 MME 类别；说明坐标先验在深层混合后边际贡献减弱。
- **依赖内部状态访问**：GMC 需要中间层 Q/K/V 与注意力切片，对"黑盒 API"型部署不适用；长前缀路径虽做了复杂度控制，但仍需获取边界层内部表示。
- **无训练方法的天花板**：与可学习的压缩方法（如基于蒸馏或微调适配器的方法，文中未系统对比）相比，GMC 不改变解码器权重，压缩后表示可能受限于原生特征的线性组合表达能力。
- **缓存与无缓存一致性**：两种执行路径的答案一致性约为 98%，仍有 2% 的样例因缓存语义产生差异，其来源（数值截断或实现细节）未完全追查。
