## 摘要
混合注意力大语言模型将全注意力与循环线性注意力相结合，以降低长上下文推理成本，但其自回归解码仍然受内存限制。树推测解码提供了一条有吸引力的加速路径，但现有的树推测系统是围绕全注意力模型的键值缓存设计的。在混合模型上，它们逐分支地遍历循环层，并为每个提议节点物化完整状态，导致验证延迟和瞬时内存随树和批次大小扩展不佳。我们提出了Bole，一种内核-运行时协同设计，为混合注意力LLM实现高效树推测。Bole将线性注意力循环转化为树结构闭式形式，并通过资源高效的GPU内核实现，并行验证所有提议节点，将线性注意力树验证加速3.4--7.7倍。它将推测状态更新无损编码为令牌级因子，并仅重建采样后选择的状态，将瞬时状态内存减少82--99倍，释放GPU容量用于KV缓存。它与广泛部署的生产级LLM服务引擎SGLang的集成，将高效状态管理与针对完整混合前向传播校准的批级验证预算相结合。在四个模型、两个GPU平台和多样化数据集上，Bole的离线解码吞吐量达到自回归解码的4.72倍，以及最强树推测基线的2.03倍。在在线代理工作负载下，与最强树推测基线相比，它分别将TTFT和TPOT降低了67.6%和49.9%。

## Abstract
Hybrid-attention large language models combine full attention with recurrent linear attention to reduce long-context inference costs, yet their autoregressive decoding remains memory-bound. Tree speculative decoding offers an attractive acceleration path, but existing tree-speculation systems are designed around the key--value caches of full-attention models. On hybrid models, they traverse recurrent layers branch by branch and materialize a full state for every proposal node, causing verification latency and transient memory to scale poorly with tree and batch sizes. We present Bole, a kernel--runtime co-design that enables efficient tree speculation for hybrid-attention LLMs. Bole transforms the linear-attention recurrence into a tree-structured closed form and realizes it with a resource-efficient GPU kernel, verifying all proposal nodes in parallel and accelerating linear-attention tree verification by 3.4--7.7$\times$. It losslessly encodes speculative state updates as token-level factors and reconstructs only the state selected after sampling, reducing transient state memory by 82--99$\times$ and freeing GPU capacity for KV caches. Its integration into SGLang, a widely deployed production LLM serving engine, couples efficient state management with a batch-wide verification budget calibrated to the complete hybrid forward. Across four models, two GPU platforms, and diverse datasets, Bole delivers up to $4.72\times$ the offline decode throughput of autoregressive decoding and up to $2.03\times$ that of the strongest tree-speculative baseline. Under online agent workloads, it reduces TTFT and TPOT by up to $67.6%$ and $49.9%$, respectively, over the strongest tree-speculative baseline.

## 1. 核心问题与整体含义

- **背景**：混合注意力大语言模型（如 Qwen3.5、Kimi Linear）将全注意力与循环线性注意力（如 Gated DeltaNet）结合，以降低长上下文推理成本，但其自回归解码仍受内存带宽限制。
- **研究动机**：树推测解码能有效利用空闲算力加速解码，但现有树推测系统（如 SpecInfer、DeFT、STree）主要针对全注意力模型的 KV 缓存设计，难以高效支持混合注意力模型中的循环线性注意力层。
- **核心问题**：如何在混合注意力模型上实现高效的树推测解码，克服三大瓶颈：
  1. **串行递归**：线性注意力依赖父节点到子节点的状态传播，无法像全注意力那样用祖先掩码并行化，树规模增大时验证延迟显著增长。
  2. **状态爆炸**：为每个提议节点物化完整线性注意力状态，瞬时内存随树和批次大小线性增长，挤压 KV 缓存容量。
  3. **可变验证容量**：GPU 和批量配置不同时，额外提议令牌不再是“近免费”，需要硬件感知的预算控制。
- **整体含义**：Bole 通过内核-运行时协同设计，首次为混合注意力模型提供了高效、内存友好、生产可用的树推测解码方案。

## 2. 方法论：核心思想、关键技术细节

### 2.1 并行树求解器（算法核心）

- 将线性注意力的节点级递归执行转化为**闭式形式**，使所有提议节点可从单一“树前状态”并行计算输出。
- 核心定理（Theorem 1）：

  \[
  O = D_P Q S_{pre} + C(I + G)^{-1} D_\beta (V - D_P K S_{pre})
  \]

- 三个关键引理：
  - **路径因子化状态**：将每个节点状态分解为树前状态和祖先贡献的加权和。
  - **祖先掩码线性系统**：把节点更新堆叠为 \((I+G)U = R\)，其中 \(G\) 为严格下三角矩阵，仅包含祖先依赖。
  - **深度有界幂零性**：基于树最大深度 \(d\)，有 \(G^{d+1}=0\)，因此逆可用有限多项式 \((I+G)^{-1} = \sum_{m=0}^d (-G)^m\) 精确计算。

### 2.2 价值分块 GPU 内核

- 将值维度划分为多个 tile，每个 tile 由一个 CTA（线程块）处理，共享树相关的因子 \(G\) 和 \(C\)。
- 使用张量核心操作执行有限诺伊曼展开，传播过程全部在片上完成，避免中间数据写回 HBM。
- 通过二维资源分块（值宽度 \(b_v\)、键维度块宽 \(b_k\)）平衡单 CTA 效率与并发度。

### 2.3 融合树验证流水线

- 树级拓扑预处理（父映射、掩码、最大深度）只需每轮一次，跨层复用。
- 三层 GPU 阶段：
  1. 树并行卷积和门控准备；
  2. 因子构造（生成 \(G\)、\(C\)）；
  3. 价值分块求解与读出。

### 2.4 因子化状态生命周期

- 只保留一个不可变提交状态，候选分支用 token 级因子（\(P, K, U\)）表示，空间复杂度从 \(\Theta(T H d_k d_v)\) 降为 \(\Theta(H d_k d_v + T H(d_k + d_v + 1))\)。
- 采样后，仅对接受路径执行一次批量矩阵乘法重建状态：
  \[
  S_{new} = P_a S_{pre} + (D_a K_a)^\top U_a
  \]
- 被拒绝的分支无需回滚，也不占用状态缓存。

### 2.5 硬件感知的批级验证预算

- 离线对每种配置（模型、GPU、批次、KV 长度、树深度）扫描总验证节点数，选择目标延迟不超过普通解码一定阈值的最大容量 \(B_{ver}(c)\)。
- 运行时按草稿模型的累计路径概率跨请求分配预算，保持树前缀连通性。

### 2.6 生产引擎集成

- 集成到 SGLang，支持 CUDA Graphs、扁平化不规则森林、连续批处理、GPU 上的采样与状态提交，实现无气泡执行。

## 7. 优点

- **理论严谨**：闭式求解精确等价于顺序执行，无近似误差，并提供了明确的算法复杂度分解。
- **内核高效**：价值分块、因子复用、片上有限诺伊曼传播，充分利用张量核心，减少 HBM 流量。
- **内存设计巧妙**：因子化状态生命周期使瞬时内存从状态规模降为令牌规模，且无损。
- **系统完整性**：从算法、内核到生产引擎（SGLang）全链路优化，支持 CUDA Graphs、连续批处理、跨层统一提交。
- **硬件自适应**：通过离线校准确定批级验证预算，适应不同 GPU 架构。
- **实验扎实**：覆盖多模型、多平台、多任务、在线与离线场景，且对比基线较强。
