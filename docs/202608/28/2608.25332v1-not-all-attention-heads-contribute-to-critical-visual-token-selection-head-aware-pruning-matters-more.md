## 摘要
视觉语言模型（VLMs）在各种视觉场景中展现了令人印象深刻的性能。然而，这一成功是以视觉标记的爆炸式增长为代价的，这会在推理过程中带来大量的内存和计算开销，最终增加延迟。为了提高VLM推理效率，一类典型的视觉标记剪枝方法通过聚合大语言模型（LLM）主干中剪枝层所有注意力头的注意力分数来估计标记重要性，并根据聚合分数剪枝标记。然而，在本文中，我们揭示了一个引人注目的现象：定位关键视觉标记的能力集中在一小部分注意力头中。仅在这些头上进行聚合可以提高任务性能。受这一观察的启发，我们提出了ProViP，一种无需训练的分步视觉标记剪枝框架。ProViP首先在LLM主干推理之前，基于输入标记的嵌入相似性移除冗余视觉标记，然后在推理过程中通过头部感知剪枝进一步剪枝标记。实验表明，ProViP在任务性能和推理效率方面表现出色。例如，当应用于LLaVA-1.5-7B时，ProViP保留了95.9%的原始性能，并在88.9%的剪枝率下实现了1.62倍的推理加速。

## Abstract
Vision-Language Models (VLMs) have exhibited impressive performance across diverse visual scenarios. However, this success comes at the cost of explosive growth in visual tokens, which imposes substantial memory and computational overhead during inference, ultimately increasing latency. To improve VLM inference efficiency, a typical class of visual token pruning methods estimates token importance by aggregating attention scores across all heads in the pruning layer of the Large Language Model (LLM) backbone and prunes tokens based on aggregated scores. However, in this paper, we reveal a compelling phenomenon: the capability to pinpoint critical visual tokens is concentrated within a small fraction of heads. Aggregation exclusively on these heads can improve task performance. Inspired by this observation, we propose ProViP, a training-free progressive visual token pruning framework. ProViP first removes redundant visual tokens based on the embedding similarity of input tokens before reasoning of the LLM backbone, and then further prunes tokens during reasoning via head-aware pruning. Experiments demonstrate that ProViP delivers outstanding task performance and inference efficiency. For instance, when applied to LLaVA-1.5-7B, ProViP retains 95.9% of the original performance and achieves 1.62x inference speedup under an 88.9% pruning ratio.

# 论文详细总结

## 1. 核心问题与研究动机

**背景**：视觉语言模型（VLM）在各类视觉任务中表现优异，但视觉输入被转化为大量视觉 token 后，在 LLM 主干推理时会造成巨大的内存和计算开销，显著增加推理延迟。

**核心问题**：现有的注意力引导式视觉 token 剪枝方法，通常将剪枝层中**所有注意力头**的注意力分数进行平均聚合来估计 token 重要性，这隐含假设了所有头对关键视觉 token 的识别有同等贡献。作者质疑这一假设，并通过实验发现：**定位关键视觉 token 的能力高度集中在一小部分"视觉头"（visual heads）上**，大量其他头反而引入冗余甚至有害的噪声。

**意义**：若能在剪枝时仅依赖视觉头进行重要性估计，可在保持性能的同时更高效地剪枝，为 VLM 推理加速提供新思路。

## 2. 方法论：ProViP 框架

ProViP 是一个**无需训练**的渐进式视觉 token 剪枝框架，分为三个阶段：

### （1）关键文本 token 选择
- 利用文本 token 自相似性矩阵计算排序准则，保留语义核心 token（排除介词等无语义对应内容的干扰）作为跨模态语义锚点：
  - 排序准则：`r = (1/Nt) Σ Softmax(Et · Etᵀ)`，保留均值以上的 token 构成关键集合 T。

### （2）LLM 主干前的剪枝（基于相似性）
- 构建关键文本 token 与视觉 token 的**跨模态余弦相似度矩阵** M；
- 对矩阵进行**校准**：减去每个文本 token 在所有视觉 token 上的平均相似度，抑制"普遍高分但无区分度"的文本 token 干扰；
- 对每个视觉 token 在文本维度上做**最大池化**得到重要性分数，保留前 N₁ 个 token；
- 采用类似 ApET 的策略，将未选中 token 的嵌入**聚合到最近的保留 token（质心）**，减少信息损失。

### （3）LLM 主干内剪枝（基于注意力，分两层进行）
- **视觉头识别**：对每个注意力头，计算其跨模态注意力图在关键文本 token 上的方差之和作为置信度，选取 Top-N_vis 个头作为视觉头：
  `C_h^l = Σ_{i∈T} Variance(A_cross^{l,h,t_i})`
- **浅层剪枝（第 7 层）**：仅聚合视觉头的注意力图，计算每个视觉 token 的平均注意力作为重要性，保留 Top-N₂；
- **中层剪枝（第 15 层）**：由于该层视觉信息已充分融合、视觉头优势减弱，改用全部注意力头聚合进行剪枝。

## 6. 主要结论与发现

1. **核心现象**：识别关键视觉 token 的能力集中于少量"视觉头"，全头聚合会引入噪声，仅使用视觉头聚合可提升剪枝后的任务性能。
2. **层依赖性**：视觉头的优势在**浅层剪枝**时显著（如 POPE 上 F1 差距最高达 13.7），在深层剪枝时优势减弱——因为视觉 token 在深层已趋于同质化。
3. **ProViP 效果**：
   - LLaVA-1.5-7B 上，66.7% 剪枝率仅损失 0.7% 性能；88.9% 剪枝率下保留 95.9% 性能，并实现 **1.62× 加速**；
   - 在所有剪枝率下均优于全部 10 个基线方法，且剪枝越激进优势越大；
   - LLaVA-NEXT-7B 高分辨率场景下取得 95.9% 平均性能保持率；
   - Qwen2.5-VL-7B 上验证了跨架构泛化性，80% 剪枝率下 POPE 甚至超过原模型。

## 7. 优点

- **发现新颖**：首次系统揭示"头部异质性"对视觉 token 选择的影响，挑战了"所有头等权聚合"的默认假设；
- **轻量高效**：完全无需训练，可即插即用，与现有 VLM 架构兼容；
- **渐进式设计合理**：在 LLM 前用低成本相似度剪枝，在浅层用高精度视觉头注意力剪枝，在中层用全头注意力剪枝，层次递进、分工明确；
- **信息保全机制**：将被剪 token 嵌入聚合到保留质心，而非直接丢弃，降低信息损失；
- **实验全面**：多模型、多基准、多剪枝率、多种消融，且有理论 FLOPs 分析支撑效率声明。

## 8. 不足与局限

- **仅适用于开源白盒模型**：剪枝需要访问 LLM 内部中间结果（注意力图和中间层嵌入），无法应用于闭源黑盒 VLM（如 Gemini、GPT-5）；
- **无法绕过注意力计算**：在剪枝层必须显式计算注意力分数，部分抵消了 FlashAttention 等高效注意力实现带来的加速收益；
- **超参数调优依赖**：视觉头数量、浅/中层剪枝位置需按模型架构手动设定，缺乏自适应选择机制；
- **实验覆盖有限**：模型仅验证了 LLaVA 系列和 Qwen2.5-VL，未覆盖 MoE 架构、更大参数量模型或更多 VLM 家族（如 InternVL、DeepSeek-VL）；
- **部署场景单一**：效率测量仅在单张 A40 GPU 上进行，未扩展到多卡、边缘设备、批处理等生产环境；
- **部分基准优势微弱**：在 66.7% 剪枝率下相对最优基线的优势仅 0.4%，且个别单项指标（如 SQA 上的部分结果）并未领先，可能需要更精细的统计显著性检验。
