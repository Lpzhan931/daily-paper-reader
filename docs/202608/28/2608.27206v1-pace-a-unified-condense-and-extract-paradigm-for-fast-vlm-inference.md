## 摘要
视觉语言模型（VLMs）展现出卓越的视觉推理能力，然而随着视觉标记（visual tokens）数量的激增，其推理成本迅速攀升。现有的视觉标记剪枝方法存在两个根本性局限。首先，大多数方法仅在视觉编码器之后进行操作，未能优化视觉编码阶段的大量延迟。其次，在严格的标记预算下，这些方法往往无法同时保留整体视觉上下文和细粒度细节，导致性能下降。为了解决这些瓶颈，我们提出了PACE（像素自适应压缩与提取），这是一个无需训练的推理框架，通过统一的压缩与提取范式加速视觉编码器和大型语言模型（LLM）。在压缩阶段，自适应像素压缩器（APC）在编码前评估视觉信息密度，自适应地下采样冗余输入，在保留全局上下文和关键视觉线索的同时削减编码器计算量。在提取阶段，动态双注意力提取器（DDAE）通过融合来自编码器的内部视觉信号和来自LLM的语义信号，选择性地保留视觉标记，以保护任务关键细节。通过将PACE集成到Qwen2.5-VL-7B中，模型在仅使用10%视觉标记的情况下保留了93.8%的原始性能，同时实现了3.1倍的首个标记时间（TTFT）加速。我们的代码可在 https://github.com/jjL357/PACE 获取。

## Abstract
Vision-Language Models (VLMs) demonstrate exceptional visual reasoning capabilities, yet their inference costs escalate rapidly with the proliferation of visual tokens. Existing visual token pruning methods exhibit two fundamental limitations. First, most approaches operate exclusively post-vision encoder, leaving the substantial latency of the visual encoding phase unoptimized. Second, under strict token budgets, these methods often fail to jointly preserve holistic visual contexts and fine-grained details, leading to performance degradation. To address these bottlenecks, we propose PACE (Pixel-Adaptive Condense and Extract), a training-free inference framework that accelerates both the vision encoder and the Large Language Model (LLM) via a unified Condense-and-Extract paradigm. During the Condense stage, an Adaptive Pixel Compressor (APC) evaluates visual information density prior to encoding, adaptively downsampling redundant inputs, curtailing encoder computation while preserving global context and essential visual cues. In the Extract stage, a Dynamic Dual-Attention Extractor (DDAE) selectively retains visual tokens via a fusion of internal visual signals from the encoder and semantic signals from the LLM, safeguarding task-critical details. By integrating PACE into Qwen2.5-VL-7B, the model retains 93.8% of its original performance while utilizing only 10% of the visual tokens, yielding a 3.1x speedup in time to first token (TTFT). Our code is available at https://github.com/jjL357/PACE.

## 1. 论文的核心问题与整体含义

**研究动机与背景**：视觉语言模型（VLM）在视觉推理任务中表现卓越，但随着输入分辨率提升和动态分辨率机制的引入，视觉 token 数量急剧膨胀。例如，Qwen2.5-VL 处理 4K 图像时，ViT 需要生成超过 42,000 个 patch，经空间池化后仍产生超过 10,500 个视觉 token 进入 LLM context。由于 self-attention 的二次计算复杂度，这构成了严重的推理瓶颈。

**现有方法的双重缺陷**：
- **第一**：主流视觉 token 剪枝方法（如 FastV、VisionZip 等）几乎全部在视觉编码器之后操作，只优化 LLM 侧的计算，而忽略了视觉编码阶段本身的高额延迟。论文的延迟剖析（图 2）显示，随着输入分辨率从 512² 增至 4096²，视觉编码与 LLM prefill 共同占据主导地位，仅削减其中一侧最多只能解决一半的瓶颈。
- **第二**：在严格的 token 预算下（如 10% 或 5%），现有方法无法同时保留整体视觉上下文与细粒度细节。实验表明，DivPrune 和 VisionZip 在通用 benchmark 上保持一定精度，但在 ChartQA、DocVQA 等细节敏感任务上出现严重性能滑坡，因为它们无法保护文本笔画、对齐锚点等高密度视觉线索。

**核心思路**：视觉 token 压缩必须超越简单的"编码后序列缩减"，应在昂贵计算之前压缩视觉表示（Condense），在编码之后提取最关键的信息（Extract），实现"先保全局、再保细节"的双阶段范式。

## 2. 论文提出的方法论

论文提出 **PACE（Pixel-Adaptive Condense and Extract)**，一个无需训练、即插即用的推理加速框架，包含两个阶段：

### 2.1 Condense 阶段：自适应像素压缩器（APC）

**目标**：在视觉编码器前减少像素预算，降低 ViT 计算成本，同时保留全局布局和关键视觉线索。

**核心机制**：
- **浅层特征预览（Shallow Feature Preview）**：仅使用 ViT 第一个 block（K=1）产生 token 嵌入 Tᵥ，并经 ℓ2 归一化，以此作为信息密度估计的依据。
- **全局信息密度（ρg）**：计算所有视觉 token 的平均成对余弦相似度 φ，定义 ρg = 1 − φ。φ 越高表示冗余越严重。
- **局部细节对比（ρd）**：以全局均值 token 为基线，计算每个 token 到基线的欧氏距离，取 top 10% 的 token 距离均值 ¯d_top，经线性缩放得到 ρd = min(¯d_top/γ, 1.0)。
- **自适应压缩**：综合全局与局部信号得到目标保留比 ρ = αρg + (1−α)ρd，据此对输入图像进行自适应缩放（bicubic 插值），并在硬性内存约束下取 min。

### 2.2 Extract 阶段：动态双注意力提取器（DDAE）

**目标**：在编码之后、LLM prefill 之前，从剩余视觉 token 中提取最关键的子集。

**核心机制**：
- **语义注意力信号（Sllm）**：从指定的 LLM 层（L_ext=2）提取交叉注意力分数，构建语义相关性图。
- **视觉注意力信号（Svis）**：从 ViT 末端层提取 self-attention 图，构建视觉密度图。
- **置信度加权融合**：以两种注意力分布的标准差 σllm、σvis 作为无监督置信度代理，通过 softmax 动态分配融合权重：α_weight, β_weight = Softmax([σllm, σvis]/τ)，最终显著性分数 S_final = α_weight·Sllm + β_weight·Svis，保留 top-K token。

**理论优势**：仅依赖 LLM 注意力容易忽略未被显式提及但关键的区域；仅依赖 ViT 自注意力则缺乏任务对齐。DDAE 通过动态加权弥补单一信号的偏差。

## 6. 论文的主要结论与发现

1. **现有视觉 token 剪枝方法存在双重瓶颈**：既忽略了视觉编码器的高昂成本，又无法在低预算下同时保留全局上下文和细粒度细节。

2. **PACE 在 10% token 预算下表现显著优于现有方法**：Qwen2.5-VL-7B 上保留 93.8% 的原始性能，平均比 VisionZip 高 12.7 个百分点、比 FastV 高 13.9 个百分点。

3. **效率提升显著**：在 10% 预算下，视觉编码器延迟降低 3.01 倍（148.84ms → 49.47ms），LLM prefill 延迟降低 6.64 倍（217.05ms → 32.69ms），TTFT 总体加速 3.13 倍（365.89ms → 116.79ms）。

4. **APC 具有正交可组合性**：将 APC 叠加到 VisionZip 和 MMTok 上，在 10% 预算下 ChartQA 和 OCRBench 提升超过 15 个百分点，DocVQA 提升约 10 个百分点。

5. **DDAE 动态融合优于任何单一注意力信号**：仅用 LLM 注意力在 ChartQA 上掉 10 分以上，说明文本引导信号会忽略未显式提及但关键的视觉信息。

6. **DDAE 提取深度存在质量-延迟权衡**：层 2 提取将 prefill 加速 2.11×，层 24 提取仅加速 1.09×，但能显著提升 ChartQA 等视觉推理任务性能。

## 7. 优点

- **方法创新性强**："编码前压缩 + 编码后提取"的统一范式跳出了既有方法"只剪编码后 token"的思维定式，同时优化了 ViT 和 LLM 两侧的瓶颈。
- **无需训练、即插即用**：APC 和 DDAE 均不改变模型权重，可以无缝集成到现有 VLM 和剪枝框架中，实用价值高。
- **信息密度估计有理论依据**：使用浅层特征而非像素统计来估计信息密度，在 RealWorldQA 和 ChartQA 上均优于 RGB 统计、颜色熵、边缘密度和 Laplacian 等方案。
- **动态置信度加权设计巧妙**：利用注意力分布的标准差作为无监督置信度代理，避免了人工设定融合权重的盲目性。
- **实验严谨性较好**：区分了固定/动态分辨率、详细剖析了不同阶段延迟、对超参数做了敏感性分析，并承认了 80% 预算下加速有限的事实。
- **透明披露**：论文专门声明使用 LLM 辅助语言编辑和代码调试，并承担内容的科学责任，学术诚信意识好。

## 8. 不足与局限

- **APC 的加速收益有前提条件**：APC 只在减少像素/tile 预算同时能减少编码器 token 数量的架构上有效。对固定网格（fixed-grid）VLM，APC 无法带来编码器侧加速，只有 DDAE 在 LLM prefill 侧有效。
- **查询无关的一次性压缩可能丢失关键证据**：APC 是查询无关（query-agnostic）的单次压缩，可能遗漏微弱或极小的字符、小型图表标签、细线或低对比度物体。一旦压缩导致证据模糊，DDAE 无法重建。高利害场景需要更高的保留下限或调整 α 来侧重局部细节。
- **跨架构可迁移性未充分验证**：虽然 InternVL3.5-4B 上的实验证明了多 tile 架构的可用性，但作者也承认速度提升可能无法原样迁移到其他 backbone，预览开销随架构和分辨率变化较大。
- **未覆盖更前沿的模型**：实验中只用了 Qwen2.5-VL（3B/7B）和 InternVL3.5-4B，未在更大规模模型（如 70B 级）或更近期发布的其他 VLM 上验证。
- **细节敏感任务仍存在性能差距**：在 10% 预算下 DocVQA 仍明显低于 Vanilla（69.55 vs 94.74），论文将其归因于压缩后微观字符和布局关系的模糊化，说明该场景尚未完全解决。
- **效率评估聚焦 TTFT**：PACE 不加速自回归解码，论文的加速比集中在 TTFT 上，端到端生成延迟的改善程度取决于生成 token 数，未给出完整端到端对比。
- **未来方向尚需探索**：论文提出的"autoregressive recovery"（动态获取高分辨率裁剪）、"query-aware pixel allocation"（查询条件下的分配）、以及与量化/局部 patch 方法结合的路径都尚未实现，仅作为展望。
