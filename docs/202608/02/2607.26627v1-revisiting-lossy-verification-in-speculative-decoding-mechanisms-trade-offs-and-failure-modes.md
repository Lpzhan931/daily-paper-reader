## 摘要
投机解码（Speculative Decoding, SD）通过允许轻量级草稿模型提出标记，随后由更大的目标模型并行验证，从而加速大型语言模型的推理。近期的方法引入了有损验证方案，通过放宽严格分布匹配来进一步提升效率。然而，这种放宽会悄然重写解码分布，由此带来的加速可能以不稳定甚至严重退化的生成质量为代价。在本工作中，我们对有损验证方法所诱导的分布进行了原理性分析。我们表明，许多看似不同的方法仅存在表面差异，可归类为两种类型：基于截断的验证和协作验证。我们进一步在精选基准测试中构建了诊断性评估框架。对于基于截断的方法，我们识别出一个根本性陷阱：由于分布失真，其性能相比真实截断采样基线可能显著下降。对于协作验证，我们发现了一个关键原则：控制草稿概率相对于目标概率的过度超出对于防止低质量输出至关重要。我们的代码可在 https://github.com/ZhouYuxuanYX/Fast-HSD 获取。

## Abstract
Speculative Decoding (SD) accelerates large language model inference by allowing a lightweight draft model to propose tokens that are subsequently verified in parallel by a larger target model. Recent approaches introduce lossy verification schemes to further improve efficiency by relaxing strict distributional matching. Yet such relaxation silently rewrites the decoding distribution, and the resulting acceleration can come at the cost of unstable, sometimes severely degraded generation quality. In this work, we present a principled analysis of the distributions induced by lossy verification methods. We show that many seemingly distinct approaches differ only superficially and can be classified into two categories: truncation-based verification and collaborative verification. We further construct a diagnostic evaluation framework across curated benchmarks. For truncation-based methods, we identify a fundamental pitfall: performance can degrade significantly compared to the true truncation sampling baseline due to distributional distortion. For collaborative verification, we uncover a key principles: controlling the overshoot of draft probabilities relative to target probabilities is essential to prevent low-quality outputs. Our code is available at https://github.com/ZhouYuxuanYX/Fast-HSD.

### 1. 论文的核心问题与整体含义

- **研究背景**：投机解码（Speculative Decoding, SD）通过让轻量级草稿模型生成候选 token，再由大模型目标模型进行并行验证，在不改变生成分布的前提下加速 LLM 推理。然而，严格的分布匹配约束限制了进一步的加速潜力。
- **核心问题**：近期出现的**有损验证**方法通过放宽分布匹配约束来获取更高加速，但这种放宽会**静默地改变目标模型的解码分布**，可能导致生成质量不稳定甚至严重退化。现有研究对此缺乏系统的机制分析和客观的对比评估，常常在特定超参数和简单基准上夸大其优势。
- **研究目标**：对有损验证方法进行**原理性分类**，揭示其内在机制，通过诊断性评测框架识别其真实的加速-质量权衡和失败模式，为该领域的研究提供原则性指导。

### 2. 论文提出的方法论

**核心思想**：对现有有损验证方法进行数学建模和统一形式化，证明它们在机制上可归结为两大类：

1. **截断式验证（Truncation-based Verification）**
   - **定义**：用一个截断策略 Θ 确定允许集合 AΘ，当草稿 token 落在 AΘ 内即被接受，否则拒绝且不重采样：
     - h(x) = 1[x ∈ AΘ]
     - 生成分布为 AΘ 上的重归一化草稿分布 q(x)/ZΘ(q)
   - **典型方法**：SpecCascade（基于 min-p 采样允许集）、Medusa 的 typical acceptance（基于 η-sampling 允许集）。
   - **核心问题**：这种机制使得生成分布完全由草稿分布决定而非目标分布，产生分布扭曲（distributional distortion），导致性能劣于直接使用对应截断采样的"真实基线"。

2. **协作式验证（Collaborative Verification）**
   - **定义**：通过插值草稿分布与目标分布来放松验证目标。
   - **代表方法**：
     - CoS（Collaborative Decoding via Speculation）：h(x) = (λp(x) + (1−λ)q(x))/q(x)，生成分布退化为 λp + (1−λ)q。
     - Lenience-based relaxation：h(x) = min{1, p(x)/(ℓq(x))}。论文推导出其诱导分布的闭式解，揭示其存在两个机制：
       - **欠估计区的自适应插值**：q(x) ≤ p(x) 时使用基于总变差距离的自适应系数 ∆ 进行插值。
       - **过冲区的天花板截断（overshoot ceiling）**：当 q(x) ≥ p(x)/ℓ 时将生成概率硬性限制在 p(x)/ℓ。
   - **关键发现（消融实验）**：真正保证质量的是**过冲天花板**，而非自适应插值；抑制草稿概率相对目标概率的"过冲"是协作式验证保证质量的关键原则。

### 6. 论文的主要结论与发现

1. **统一分类框架**：看似不同的有损验证方法本质上只有两类——截断式验证和协作式验证，其差异更多是表面的而非机制的。
2. **截断式验证的性能陷阱**：截断式验证的生成分布是截断草稿分布而非截断目标分布，存在本质性的分布扭曲。相比直接使用相同截断在目标模型上采样（"真实基线"），其任务精度显著下降（标准 SD 下平均差距−0.38~−0.32 pp，EAGLE-3 下扩大至−1.68~−6.32 pp，具体如表 7）。此前文献宣称的性能优势主要来自截断采样本身而非验证机制。
3. **EAGLE-3 放大缺陷**：理论上证明（Proposition 1）标准 SD 的分布差距在草稿趋近目标时收敛到 0，而 EAGLE-3 树验证的差距不消失。实验证实 EAGLE-3 下典型接受的精度差距达到−6.32 pp（INCLUDE 上甚至−8.82 pp），且典型接受在所有基准上均劣于 EAGLE-3 基线。
4. **协作式验证的关键原则**：过冲控制（overshoot ceiling）是保证生成质量的核心机制。删除过冲天花板而保留自适应插值会导致与 CoS 类似的严重质量退化；仅保留过冲天花板即可达到近乎无损验证的质量，同时获得效率提升。
5. **截断效率的二分类**（Lemma 1）：截断对接受率的影响是"保留区的增益"与"丢弃区的损失"的平衡。η-sampling 在所有参数范围内增益为正且随 ε 单调递增；min-p 采样在 pbase 较小时增益为正，但接近 0.9 时增益消失甚至转负。
6. **推荐方向**：将截断策略（限制在允许集内接受）与过冲天花板（控制允许集外的过冲）结合，可以在无损质量的条件下提高效率（表 6，BE +3.7%，Pass@1 持平）。
