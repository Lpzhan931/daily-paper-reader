## 摘要
推测解码通过并行验证多个草稿标记，无损地加速自回归语言模型。基于扩散的草稿生成器通过并行预测整个标记块来进一步减少提议延迟，但它们的逐位置分布是边缘分布，而不是以沿每条草稿路径选择的标记为条件。现有的循环校正沿单一草稿链整合因果信息，而基于扩散的树构建拓宽了候选覆盖范围，却不沿各个分支携带这种校正。我们提出了DARTree，一种无需训练的推测解码方法，将预训练的自回归校正头从链扩展到树。DARTree首先通过单批次扩展和评分每个深度的所有节点来构建固定宽度的候选树，然后仅应用最佳优先剪枝来选择验证树，将自回归头推断与顺序堆操作解耦。在七个数学、代码和聊天基准测试中，DARTree在所有四种模型-温度配置中实现了最高的平均接受长度和加速比，每轮验证最多接受12.97个标记，在相同设置下比DFlash多98.6%，比Domino多27.9%，并且相对于本地测量的自回归解码实现了高达9.73倍的无损加速。

## Abstract
Speculative decoding losslessly accelerates autoregressive language models by verifying multiple draft tokens in parallel. Diffusion-based drafters further reduce proposal latency by predicting an entire token block in parallel, but their position-wise distributions are marginal rather than conditioned on tokens selected along each draft path. Existing recurrent correction incorporates causal information along a single draft chain, whereas diffusion-based tree construction broadens candidate coverage without carrying this correction along individual branches. We introduce DARTree, a training-free speculative decoding method that extends a pretrained AR correction head from chains to trees. DARTree first constructs a fixed-width candidate tree by expanding and scoring all nodes at each depth in a single batch, and then only applies best-first pruning to select the verification tree, decoupling AR-head inference from sequential heap operations. Across seven math, code, and chat benchmarks, DARTree achieves the highest average acceptance length and speedup in all four model--temperature configurations, accepting up to 12.97 tokens per verification round, 98.6\% more than DFlash and 27.9\% more than Domino in the same setting, and reaching up to 9.73$\times$ lossless speedup over locally measured autoregressive decoding.

# DARTree 论文总结

## 1. 核心问题与整体含义

- **背景**：自回归大语言模型（LLM）推理受限于逐 token 生成，具有高延迟和低硬件利用率。投机解码（Speculative Decoding）通过轻量草稿模型并行提议多个 token，再由目标模型并行验证，实现无损加速。
- **现有方法的问题**：基于扩散的草稿器（如 DFlash）可以一次并行预测整个 token 块，显著降低提议延迟；但其逐位置分布是“边缘分布”，没有以同一块内先前 token 为条件，造成与目标模型条件分布之间的因果失配。已有方法如 Domino 使用循环校正头恢复单链上的因果依赖，而基于扩散的树构建（如 DDTree）仅利用边缘分布扩展候选覆盖，无法沿分支携带路径条件校正。
- **核心挑战**：若将因果校正与 DDTree 式的最佳优先堆搜索结合，校正头必须逐节点处理，导致树构建过程高度串行化，成为新延迟瓶颈。
- **论文含义**：提出 DARTree，一种无需训练的投机解码方法，将预训练的自回归（AR）校正头从“链”推广到“树”，在保留路径条件校正的同时实现批量并行树构建，进一步提升接受长度与端到端加速。

## 2. 方法论

- **核心思想**：将校正头推断与顺序堆操作解耦。DARTree 按“深度”批量扩展固定数量的候选节点，先生成更宽的候选超树（supertree），再通过延迟的最佳优先剪枝选取紧凑的验证树，交给目标模型做单次树注意力验证。
- **关键技术细节**：
  - 块并行骨干网络单次前向得到共享表示和基础 logits。
  - 每个深度只考虑每个位置 top-K 的候选 token。
  - 对当前深度的所有活动分支批量应用预训练校正头，得到路径条件化的校正概率。
  - 按校正累计分数保留每层最 top-W 的扩展节点，并携带其校正状态进入下一深度。
  - 所有深度完成后，对整个超树执行一次全局 top-B 选择作为最终验证树。
- **评分公式**：前缀 \(u_{1:d}\) 的分数为  
  \[
  s_\beta(u_{1:d}) = \sum_{i=1}^d \log e_{q_i}(u_i) + \beta d
  \]
  其中 \(e_{q_i}(u_i)\) 是校正后的条件概率，\(\beta \le 0\) 为深度惩罚。
- **关键引理**：当 \(\beta \le 0\) 时，子节点分数不会高于父节点，因此全局 top-B 选择与最佳优先堆展开结果等价（Lemma 1），从而可以用一次性 top-B 操作取代串行堆操作。
- **算法流程**（Algorithm 1）：初始化根层与状态 → 对 \(d=1\) 到 \(\gamma\)：选 top-K 候选 → 并行校正所有活跃前缀 → 计算子前缀分数 → 保留 top-W → 更新状态 → 累积超树 → 最终全局 top-B 剪枝返回验证树。
- **变体**：DARTree (fixed) 均匀分配节点到每层；DARTree (pruned) 构造更宽超树后再剪枝。不改变目标模型树验证部分，训练无关，可直接使用现成 Domino 校正头。

## 6. 主要结论与发现

- DARTree 在全部四种模型–温度配置中取得最高平均接受长度和加速比。
- 以 GSM8K + Qwen3-4B + T=0 为例，每轮接受 12.97 token，比 DFlash 高 98.6%，比 Domino 高 27.9%，端到端无损加速达 9.73×。

- 位置级接受率显示 DARTree 同时保留了早期高接受率和后期更长的接受延续。

## 7. 优点

- **训练无关**：直接复用现成的扩散草稿器和 AR 校正头，无需任何额外训练。
- **并行化设计合理**：按深度批量扩展，将路径依赖的校正头推断张量化，避免逐节点堆操作带来的串行延迟。
- **延迟剪枝具有理论保证**：通过非正深度惩罚保证分数沿路径单调不增，使堆展开与全局 top-B 等价，简化实现。
- **通用性强**：不依赖特定校正头架构，可移植到不同的修正头（如 Domino、DSpark-Markov）。
- **性能提升显著**：在所有基准和温度配置下均超过现有扩散草稿方法，并且在低并发/延迟敏感场景下尤为有效。
- **可视化与分析充分**：对树形状、接受概率分布、示例树形态做了详细对比，清楚说明方法优于基线的机制。

## 8. 不足与局限

- **依赖预训练校正头**：对于没有校正头的朴素扩散草稿器无法直接使用，必须先训练相应模块，因此“训练无关”并非对一切扩散草稿器成立。
- **不减少总计算量（FLOPs）**：以额外并行计算换取延迟降低，树验证开销较大，可能不适用于所有部署环境；在计算资源已高度利用的高并发场景收益会下降。
- **实验范围较窄**：仅在 Qwen3-4B/8B 上验证，未评估其他模型族或更大规模模型。
- **默认超参数可能非全局最优**：层宽 W、预算 B、深度惩罚 β 需要根据场景调整；高并发下固定大树反而有害，需自适应配置。
- **潜在偏差**：接受长度和加速比主要依赖本地测量，未报告真实在线服务中的端到端用户延迟；模型温度和采样策略也可能影响推广性。
