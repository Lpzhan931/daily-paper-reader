## 摘要
视觉-语言-动作（VLA）模型已在具身人工智能领域展现出卓越的能力，但其高计算成本和有限的预测动作长度阻碍了实时部署。尽管已推出了专门用于高效具身AI的加速器Dadu-Corki，但它并未利用机器人与环境之间固有的交互模式，导致预测动作长度相对较短。我们观察到，机器人环境自然地在主动状态与被动状态之间交替——在主动状态下精确动作至关重要，而在被动状态下动作对任务成功的影响有限。这一洞察带来了新的调度机会：在被动状态下进行长动作长度的推测性预测，并在主动状态下进行选择性验证。我们提出了SpecVLA，一个算法-系统协同设计框架，能够自适应地平衡动作长度、推理延迟和任务可靠性。在算法方面，SpecVLA引入了一种状态感知的VLA推理执行范式，以及使用差分残差和逐块混合精度量化构建硬件友好的较小验证模型（sVLA）的方法。在系统方面，我们开发了一种由GPU和机器人专用硬件模块组成的异构架构，以及一种通过并行执行解耦VLA和sVLA的推测性数据流。在LIBERO和ManiSkill基准上对OpenVLA和RDT的全面评估表明，SpecVLA显著降低了端到端延迟，同时保持了任务成功率。通过实现长动作长度推测性预测与及时验证，SpecVLA实现了兼具高效率和可靠性的实时机器人操作。

## Abstract
Vision-Language-Action (VLA) models have demonstrated remarkable capabilities in the field of embodied AI, but their high computational cost and limited predicted action length hinder real-time deployment. Although Dadu-Corki, a dedicated accelerator for efficient embodied AI, has been introduced, it does not exploit the inherent interaction patterns between the robot and its environment, which results in a relatively short predicted action length. We observe that robotic environments naturally alternate between active states-where precise actions are crucial-and inactive states-where actions have limited impact on task success. This insight enables a new scheduling opportunity: long-action-length speculative prediction in inactive states, paired with selective verification in active states.   We propose SpecVLA, an algorithm-system co-design framework that adaptively balances action length, inference latency, and task reliability. On the algorithm side, SpecVLA introduces a state-aware VLA inference execution paradigm and a hardware-friendly construction of a smaller verification model (sVLA) using differential residuals and block-wise mixed-precision quantization. On the system side, we develop a heterogeneous architecture consisting of a GPU and a robotic-specific hardware module, along with a speculative dataflow that decouples VLA and sVLA through parallel execution. Comprehensive evaluations on OpenVLA and RDT across LIBERO and ManiSkill benchmarks show that SpecVLA reduces end-to-end latency significantly while preserving task success rate. By enabling long-action-length speculative prediction with timely verification, SpecVLA achieves real-time robotic manipulation with both high efficiency and reliability.

## 2. 论文提出的方法论：核心思想、关键技术细节、公式或算法流程

SpecVLA 是一个算法-系统协同设计框架，核心技术分为算法与架构两个层面：

### 算法层面
- **状态感知推测执行（State-aware Speculative Inference）**：
  - 根据机械臂-物体距离 \( D_i = \sqrt{\sum_{k=1}^{3} (G_c[k] - O_i^c[k])^2 } \) 和机械臂夹爪状态 \( G_s \)，判定当前环境为**主动**或**非主动**状态：
    - 夹爪张开且附近无物体 ⇒ 非主动状态 ⇒ 直接执行 VLA 的长动作序列，不做逐动作验证。
    - 否则 ⇒ 主动状态 ⇒ 对每个预测动作先由 sVLA 生成期望动作，再进行验证，仅在验证不通过时才回滚并重新调用 VLA。
  - 动作验证使用加权 L1 距离（每维先做 min-max 归一化，权重为 \( w[k]=1/\sigma[k] \)），距离小于阈值 \( T_s \) 则接受该预测动作，否则拒绝触发重生成。

- **sVLA：差分残差 + 分块混合精度量化**：
  - 对连续帧间的特征计算残差 \( \Delta X_i = X_i - X_{i-1} \)，残差分布显著收窄，更适合量化。
  - 将残差矩阵分块，按块内绝对值之和与阈值 \( T_z \)、\( T_h \) 比较，分配三种位宽：
    - 低于 \( T_z \)：置为 0（0-bit 零块）；
    - 高于 \( T_h \)：8-bit 高精度块；
    - 其他：4-bit 低精度块。
  - 高精度块进一步拆分为低比特位和高比特位两部分，使所有块由统一的低精度 SIMD 数据通路处理；最后按层累加残差输出实现推理。

### 系统架构层面
- **异构架构**：GPU 负责全精度 VLA 推理，机器人专用硬件模块（含 SIMD 型 PE 阵列、可重构状态预测器、预处理模块）负责 sVLA 推理、环境状态预测与动作验证。
- **投机数据流**：将 VLA 推理与 sVLA 验证解耦：VLA 无需等待验证结果即开始下一轮预测；验证方若通过则不浪费等待周期（提前终止 VLA 空闲部分），若不通过则让 VLA 继续执行剩余计算并返回修正动作，同时引入机械臂回滚机制保证物理状态一致性。
- **可重构状态预测器**：统一环境状态预测（欧氏距离）和动作验证（L1 距离）的公共距离计算流水线，通过多路选择器切换模式，降低硬件面积开销。

- **性能显著提升**：与 A100 GPU 相比端到端速度为 2.9 倍，与 Dado-Corki 相比为 1.9 倍，与 CPU 相比为 12.1 倍；单动作产生间隔约 61ms，满足实时控制（<100ms）要求。

- **结论**：通过“非主动态长动作推测 + 主动态选择性验证 + 异构并行数据流”，SpecVLA 能在几乎不损失成功率的前提下大幅缩短 VLA 推理延迟，是一种面向 VLA 实时虚拟操控的有效算法-系统协同设计范式。

## 7. 优点：方法或实验设计上的亮点

1. **观察到状态不对称性并加以利用**：将机器人执行过程按主动/非主动状态区分，自适应地调整预测与验证策略，是对“预测长度-延迟-成功率”权衡的一种有效建模。
2. **算法-架构深度协同**：不是单纯算法剪枝或堆硬件，而是从环境状态预测、动作验证、差分量化到硬件 PE 阵列/数据流统一设计，形成一个闭环可部署系统。
3. **硬件友好的差分量化**：通过块级拆分（高精度块拆分为低/高位部分）、零块剔除、单精度数据通路，大幅简化硬件控制复杂度，解决了高/低精度混合计算在 GPU 上的调度开销问题。
4. **投机数据流打破依赖链**：让 VLA 提前推进预测、sVLA 并行验证，同时以“提前终止/继续执行”方式避免无谓等待，挖掘硬件并行性。
5. **高效的可重构硬件设计**：将环境状态预测（欧氏距离）与动作验证（L1 距离）统一到同一距离计算管线，减小面积成本。
6. **实验覆盖较全面**：两类 VLA 模型、多种基准、多次消融、阈值敏感性分析及硬件开销统计均包含在内，考虑了传感器噪声的影响，增强了工程可用性结论的可信度。

## 8. 不足与局限：实验覆盖、偏差风险、应用限制

1. **缺乏真实机器人验证**：所有实验均为 LIBERO/ManiSkill 仿真环境；仿真中的低层次动作量化噪声和回滚机制一般比真实物理环境更理想，真实部署时成功率与延迟数值可能有所偏差。
2. **IID 假设较强**：环境状态预测依赖对象坐标和机械臂距离阈值 \( T_d \)，在非结构化、动态变化环境中（例如物体被遮挡、多机协作、光照突变）需要额外感知能力，部署风险较高。
3. **验证模型 sVLA 的鲁棒性有限**：差分残差+量化方法依赖“连续帧间冗余大”的前提，若机械臂突然高速移动或传感器噪声剧烈，残差特征分布可能扩大，导致 sVLA 验证质量显著下降。
4. **物理不可逆动作的回滚限制**：尽管论文论述“在 1 个运动基元内验证可避免不可逆状态”，但真实任务中涉及完全闭合夹爪、释放物体等不可逆操作时，回滚失败风险仍存在，论文未给出充分实验支撑。
5. **对比基准的软硬件环境不完全统一**：算法级加速往往在 GPU 上实现，而 SpecVLA 使用 GPU+NPU/专用硬件；硬件差异会放大综合性能优势，难以区分“算法贡献”与“硬件加速贡献”，存在一定的对比偏差风险。
6. **对超参的敏感性高**：阈值 \( T_s, T_d, T_z, T_h \) 以及预测长度 \( L \) 都需要针对任务/环境调优；当前采用“先固定其他再单维扫描”的启发式方法，可能在复杂多任务环境下全局最优性不足。
7. **计算成本信息披露不完整**：未报告 VLA 原始训练/微调费用，未量化云端传输带宽假设，也未报告较长动作序列（>8）在真实传感器噪声下的退化程度，限制了复现和部署成本估算的可信度。
