## 摘要
投机解码（Speculative Decoding, SD）通过允许轻量级草稿模型提出令牌，随后由更大的目标模型并行验证，从而加速大语言模型推理。近年来的方法引入有损验证方案，通过放宽严格分布匹配来进一步提升效率。然而这种放宽会悄然改写解码分布，由此带来的加速可能以生成质量不稳定甚至严重退化为代价。在本工作中，我们对有损验证方法所诱导的分布进行了原理性分析。我们表明，许多看似不同的方法仅在表面上有所差异，可归为两类：基于截断的验证与协作式验证。我们进一步构建了一套跨精选基准的诊断评估框架。对于基于截断的方法，我们识别出一个根本性陷阱：由于分布扭曲，其性能可能相比真实的截断采样基线显著下降。对于协作式验证，我们发现了一个关键原则：控制草稿概率相对于目标概率的超调量，对于防止低质量输出至关重要。我们的代码可在 https://github.com/ZhouYuxuanYX/Fast-HSD 获取。

## Abstract
Speculative Decoding (SD) accelerates large language model inference by allowing a lightweight draft model to propose tokens that are subsequently verified in parallel by a larger target model. Recent approaches introduce lossy verification schemes to further improve efficiency by relaxing strict distributional matching. Yet such relaxation silently rewrites the decoding distribution, and the resulting acceleration can come at the cost of unstable, sometimes severely degraded generation quality. In this work, we present a principled analysis of the distributions induced by lossy verification methods. We show that many seemingly distinct approaches differ only superficially and can be classified into two categories: truncation-based verification and collaborative verification. We further construct a diagnostic evaluation framework across curated benchmarks. For truncation-based methods, we identify a fundamental pitfall: performance can degrade significantly compared to the true truncation sampling baseline due to distributional distortion. For collaborative verification, we uncover a key principles: controlling the overshoot of draft probabilities relative to target probabilities is essential to prevent low-quality outputs. Our code is available at https://github.com/ZhouYuxuanYX/Fast-HSD.

## 2. 论文提出的方法论：核心思想、关键技术细节与公式

### 2.1 两类有损验证的统一定义与归类

论文指出，看似多样的有损验证方法实质上可分为**两类范式**：

#### （1）基于截断的验证（Truncation-based Verification）

- **定义**：设 AΘ ⊆ V 为由截断策略 Θ 定义的可允许 token 集合，该方法将标准接受规则 h(x) = min(1, p(x)/q(x)) 替换为：

  ```
  h(x) = 1 若 x ∈ AΘ；否则 0
  ```

  即草稿 token 只要落在允许集合 AΘ 内即被接受，集合外则直接拒绝且**不进行重采样**。最终生成分布为受限草稿分布的再归一化：  
  P(generate x) = q(x)/ZΘ(q)（x ∈ AΘ），其中 ZΘ(q) = Σ_{v∈AΘ} q(v)

- **代表性方法**：
  - **SpecCascade**（Narasimhan et al., 2024）：允许集合由 **min-p sampling** 定义：A = {x : p(x) ≥ p_base · max_v p(v)}
  - **Medusa 中的典型接受（typical acceptance）**（Cai et al., 2024）：允许集合由 **η-sampling** 定义：A = {x : p(x) ≥ min(ε, δe^{-H(p)})}

#### （2）协作式验证（Collaborative Verification）

- **核心机制**：将草稿与目标分布的某种组合分布作为验证目标，通过插值或对比方式结合两个模型的预测。
- **代表性方法**：
  - **CoS**（Collaborative Decoding via Speculation, Fu et al., 2025）：接受概率变为 h(x) = [λp(x) + (1-λ)q(x)] / q(x)，生成分布退化为凸组合 P(x) = λp(x) + (1-λ)q(x)——均匀插值，无方向性
  - **宽松松弛（Lenience-based Relaxation）**（Leviathan et al., 2023）：接受规则为 h(x) = min(1, p(x)/(ℓ·q(x)))，其诱导的生成分布可分解为三区域：欠估计区 (q ≤ p) 采用自适应插值；中等过冲区 (p < q ≤ p/ℓ) 保持不变；严重过冲区 (q ≥ p/ℓ) 被**封顶**为 p(x)/ℓ。该机制通过两个途径约束草稿：自适应插值系数 ∆（与分布散度相关）和局部概率差上的硬阈值（超调天花板）

### 2.2 核心理论结果

- **引理 1（截断采样的效率效应分解）**：截断采样对单 token 接受概率的改变 ∆BE 可分解为保留集合上的非负增益项与丢弃区域上的损失项之和，其符号决定了截断对 SD 效率的净影响。这解释了 min-p 在中等阈值下获益但 p_base→0.9 时优势收窄，而 η-sampling 在测试范围内始终收益为正。
- **引理 2 与命题 1（KL 散度分析）**：刻画了截断验证与匹配截断采样基线之间的逐 token KL 散度：
  - 标准 SD 下：KL_SD = E[Σ_{x∈AΘ} (q(x)/ZΘ(q)) log(q(x)ZΘ(p)/(ZΘ(q)p(x)))]，当 q→p 时趋于 0
  - EAGLE-3 树验证下：KL_EAGLE = E[log(ZΘ(p)/p(x))]，即使 q→p 也恒为正（当 |AΘ| > 1）
  - **理论预测**：草稿模型越好，标准 SD 下分布失真趋向消失，但 EAGLE-3 下失真持续存在，性能差距被放大

### 2.3 消融实验设计

为分离宽松松弛中两个机制（欠估计区的自适应插值 vs. 过冲区的封顶）的贡献，论文构造了两种变体：

- **仅保留自适应插值**（过冲区用 CoS 插值规则）
- **仅保留过冲封顶**（低于封顶时保持 CoS 混合，超过 p(x)/λ 时截断）

结果明确显示：**过冲封顶是主要贡献来源**，自适应插值继承了 CoS 的严重质量退化。

## 6. 论文的主要结论与发现

### 6.1 截断验证的根本陷阱

- 截断验证方法的"性能可比"**很大程度上来自截断采样本身带来的基线提升**，验证机制反而进一步扭曲分布并降低任务性能
- 在标准 SD 下，每个匹配对中截断采样（min-p、η）都在任务性能上压过对应的截断验证方法（SpecCascade、典型接受）
- **性能差距随任务难度扩大**：GSM8K 上仅 +0.38 pp，AIME 上扩大到 +6.67 pp（图 1）
- **EAGLE-3 树验证放大了这一缺陷**：平均性能差距从标准 SD 下的 -0.38/-0.32 pp 分别扩大到 -1.68/-6.32 pp（SpecCascade/典型接受），典型接受在 INCLUDE 上跌幅高达 -8.8 pp，甚至低于 EAGLE-3 无损基线；理论上这是因为 EAGLE-3 的 KL 散度即使在草稿收敛到目标分布时也不消失（命题 1）

### 6.2 协作验证的关键原则

- CoS 的均匀插值导致"效率↑ → 质量↓"的严重权衡曲线；宽松松弛则保持质量的同时略有效率提升
- **消融实验揭示**：过冲封顶（overshoot ceiling）是宽松松弛有效性的主要来源；自适应插值继承 CoS 的严重权衡
- 核心原则：**控制草稿概率对目标概率的超调**是协作验证在兼顾加速与质量时的关键；低质量生成主要由过冲 token 驱动，与近期研究结论一致

### 6.3 截断采样本身对 SD 效率的影响

- 引理 1 将截断效应分解为增益与损失；min-p 在中低阈值下获益但高阈值下劣势显现，η-sampling 在整个范围内稳定为正
- 合成模拟、理论分析与基准实验三者的趋势一致，互相印证

## 7. 优点

1. **统一理论视角**：首次将有损验证方法系统归类为两种机制（截断式、协作式），揭示表面差异下的共性，为领域提供了清晰的概念地图
2. **严谨的公平评估方法论**：提出"匹配截断采样基线"对照标准，纠正了以往研究中将截断收益误归因于验证机制的问题
3. **理论-模拟-实验三层互证**：KL 散度命题（引理 2/命题 1）给出 EAGLE-3 下差距扩大的理论解释，并预测实验现象，而非事后拟合
4. **可操作的工程指导**：识别"过冲封顶"为关键设计原则，消融实验证明仅靠封顶即可在保持质量的同时提升效率（表 6：BE +3.7%、Pass@1 完全持平），甚至可与 min-p 门控结合获得更好效果
5. **透明性**：公开代码、消融设置和定性失败案例分析（如 BFCL 中"x^2" vs "x**2"的符号错误），帮助社区快速复现和诊断
