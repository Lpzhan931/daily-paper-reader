## 摘要
投机解码在不改变目标分布的情况下加速大语言模型推理，但没有任何单一的草稿结构在真实工作负载上表现最佳。自回归多令牌预测（MTP）是一种轻量级、稳定的提议机制，而块并行扩散则将草稿延迟分摊到更长的候选序列上；更好的选择在很大程度上取决于输出分布。我们提出 AngelSpec，一个用于 MTP 和块并行投机解码的统一训练框架，在三个层面解决这种异构性。在训练层面，我们不是将一种通用的草稿模型拟合到统一的数据混合上，而是联合特化结构和数据：MTP 草稿模型在多样化对话数据上训练，用于高熵开放域聊天，而块扩散草稿模型在代码和数学数据上训练，用于更长的可预测续写。在架构层面，我们提出 DFly，一个块扩散框架，结合了混合目标条件主干和前趋条件自回归头，改善了目标特征利用和块内依赖建模，同时保持生成并行。在推理层面，接受长度和验证成本都随领域、请求、在线负载和硬件而变化，因此 DFly 将验证视为共享的批处理级资源：它将计算重新分配给跨请求的高置信度前缀，并将预期效用与性能分析成本模型相结合，在线调整验证深度。在 Hy3 系列中，DFly 在 Hy3-A21B 上将平均接受长度提高了约 30%，并在 4 到 64 的所有测试并发下获得最高平均吞吐量，较自回归解码加速 1.98-2.40 倍，比 DFlash 吞吐量高 10.5-11.8%。我们发布 AngelSpec 以支持这些方法的训练和扩展。

## Abstract
Speculative decoding accelerates large language model inference without changing the target distribution, but no single drafting structure performs best across real-world workloads. Autoregressive multi-token prediction (MTP) is a lightweight, stable proposal mechanism, whereas block-parallel diffusion amortizes drafting latency over much longer candidate sequences; the better choice depends strongly on the output distribution. We present AngelSpec, a unified training framework for MTP and block-parallel speculative decoding that addresses this heterogeneity at three levels. At the training level, rather than fitting one universal drafter to a uniform data mixture, we co-specialize structure and data: the MTP drafter is trained on diverse conversational data for high-entropy open-ended chat, and the block-diffusion drafter on code and mathematics data for longer predictable continuations. At the architecture level, we propose DFly, a block-diffusion framework combining a hybrid target-conditioning backbone with a predecessor-conditioned autoregressive head, improving target-feature utilization and intra-block dependency modeling while keeping generation parallel. At the inference level, both acceptance length and verification cost vary with domain, request, online load, and hardware, so DFly treats verification as a shared batch-level resource: it reallocates compute toward high-confidence prefixes across requests and combines expected utility with a profiled cost model to adapt verification depth online. Across the Hy3 series, DFly raises the average accepted length on Hy3-A21B by roughly 30% and attains the highest average throughput at every tested concurrency from 4 to 64, a 1.98-2.40x speedup over autoregressive decoding and 10.5-11.8% higher throughput than DFlash. We release AngelSpec to support training and extending these methods.

## 2. 方法论

### 2.1 核心思想

- **工作负载特化**：不训练一个通用草稿器，而是让 MTP 草稿器专攻高熵对话数据，让块扩散草稿器专攻代码与数学数据。
- **架构改进**：DFly 在 DFlash 基础上提出混合目标条件主干 + 前趋条件自回归头，兼顾并行生成效率与块内依赖建模。
- **推理自适应**：D-cut 根据前缀置信度和运行时成本模型动态调整每个请求的验证深度，将目标验证视为跨请求的共享资源。

### 2.2 MTP 草稿器（第 2 节）

- **共享参数多深度 MTP**：
  - 保留 D 个逻辑预测深度（k = 0, ..., D−1），所有深度共享同一物理 MTP 模块。
  - 深度 k 的输入为上一深度输出的隐藏状态与最新 token 嵌入的融合，通过 RMSNorm 和线性投影后经一层 Transformer 处理：
    - u^(k) = W_proj([RMSNorm(h^(k−1)); RMSNorm(E(e_x_k))])
    - h^(k) = F_θ(u^(k), K^(<k))，q_k = softmax(W_lm h^(k))
  - 训练时自回归展开 D 步，每一深度使用独立的移位未来 token 作为监督目标。
- **训练时测试（TTT）**：
  - 解决训练/推理不匹配问题：训练时深度 k+1 接收深度 k 的 argmax 预测（而非 ground-truth），使草稿器暴露于自生成轨迹。
  - 通过因果前缀 + 对角草稿注意力模式复现推理时的依赖结构。
  - 支持长上下文训练（最长 128k），采用 Ulysses 序列并行 + 文档边界感知的移位掩码。
- **接受对齐蒸馏**：
  - 使用 TV 距离（总变差距离）直接连接拒绝采样接受率：α(p, q) = 1 − TV(p, q)。
  - 使用 LK Loss（KL 与 TV 的自适应混合）作为冷启动目标，然后切换到端到端 TV 损失：
    - L_e2e = 1 − (1/|I|) Σ_i (1/D) Σ_m Π_{k=0}^m α_{i,k}
  - 该乘法形式使浅层位置影响力更大，因为早期拒绝会使得后续所有草稿 token 失效。
- **训练数据策略**：
  - 多样化任务覆盖（对话、知识、数学、代码、指令遵循、智能体交互）。
  - 长上下文与代码智能体轨迹（含仓库上下文、工具调用、多步反馈）。
  - 目标模型 rollout：用冻结的目标模型生成响应来训练草稿器，减少教师分布与数据分布的不匹配。

### 2.3 DFly 块扩散框架（第 3 节）

- **混合目标条件主干**：
  - 结合 DFlash 的共享全连接投影（c_t = W_fc[h_t^(1); ...; h_t^(T)] + b_fc）与 DFlare 的逐层特异性融合（f_t^(i) = Σ_j α_j^(i) h_t^(j)）。
  - 最终条件表示为 g_t^(i) = RMSNorm(c_t + f_t^(i))，既保留全局跨层特征交互，又提供深度相关的细化。
- **前趋条件自回归头**（两种实现）：
  - **Markov 头**：低秩转移偏置 b_{t+i} = W_1[x_{t+i−1}] W_2，有效抑制与已采样前趋不兼容的续写。
  - **隐藏修正头**（最终采用）：将前趋 token 嵌入与位置特定隐藏状态融合：
    - bz^(D)_{t+i} = z^(D)_{t+i} + SwiGLU([ez^(D)_{t+i}; e_{t+i−1}])，q_i = softmax(LMHead(bz^(D)_{t+i}))
  - 隐藏修正头更强大，因为其联合使用了前趋嵌入和混合主干产生的位置特定表示。
- **损失设计**：
  - 两阶段训练：先使用 D-PACE 加权的混合 LK 损失冷启动，再切换至端到端 TV 损失。
  - D-PACE 权重对深位置赋予递乘置信度，使模型聚焦于对最终接受长度贡献更大的浅层位置。

### 2.4 D-cut 动态验证预算管理（第 4 节）

- **问题定义**：对于 B 个请求，每请求建议 D 个草稿 token；全深度验证需要处理 B(D+1) 个位置。不同请求的接受长度差异大，且验证成本随批大小、硬件和负载变化。
- **方法流程**：
  1. 根据草稿器的 token 级置信度估计前缀生存概率：s_{i,k} = Π_{t=1}^k c_{i,t}
  2. 估计每个请求的预期进度：Â_i(n_i) = Σ_{k=0}^{n_i} s_{i,k}
  3. 从少量离散比例 R = {0.25, 0.50, 0.75, 1.00} 中选择全局预算 K_ρ(B) = max(B, ⌈ρ·B(D+1)⌉)
  4. 通过全局 top-K 选择（并列时偏向浅位置）确定每请求保留深度，保证前缀连续性。
  5. 在服务器启动时分析端到端投机步延迟 C(B, ρ)，运行时选择 ρ* = argmax U(B, ρ)/C(B, ρ)，即最大化预测吞吐。
- **正确性保证**：仅改变草稿被验证的深度，保留的 token 仍通过原目标验证流程，因此不改变目标模型输出分布。

## 6. 主要结论与发现

1. **工作负载异构性是真实世界投机解码的一等设计考量**：高熵对话适合 MTP，结构化代码/数学适合块扩散；按数据域特化草稿器显著优于统一训练。
2. **TTT 对 MTP 至关重要**：TTT+目标模型 rollout 将 Hy3 MTP 的平均接受率从 52.8% 提升至 66.4%（T=0），提升集中在第 2/3 草稿位置，首位置保持稳定。
3. **DFly 架构改进有效**：混合目标条件主干 + 隐藏修正头在 Hy3-A21B 上较 DFlash 平均接受长度提升 29.8%（3.69→4.79），在代码和数学基准上尤其明显。
4. **领域数据扩展带来额外增益**：加入代码/数学数据后，平均接受长度从 4.60 提升至 4.75，代价是对话基准 MT-Bench 微降，符合预期的领域特化方向。
5. **5 层草稿器 + 块大小 8 是最优配置**：较 3 层/块 5 大幅提升，继续加深到 7 层无额外收益。
6. **思考模式需要匹配训练/推理**：无思考草稿器在无思考推理下最优（4.79），高思考草稿器在高思考推理下最优（4.27）；跨模式使用会导致显著退化（降到 3.29）。
7. **D-cut 扩展了有用并发范围**：在 DFly 饱和的并发 48 之后，D-cut 继续将负载转化为吞吐（c64 时 +15.7%），且几乎不损失接受长度（2.50→2.46，约 1.5%）。
8. **端到端收益**：在 Hy3-A21B 上，DFly 在 4–64 所有测试并发下取得最高平均吞吐，较自回归解码加速 1.98–2.40 倍，比 DFlash 高 10.5–11.8%。

## 7. 优点

- **系统视角完整**：从训练数据、模型架构到推理调度，全链路解决真实世界负载异构问题，而非仅优化单一环节。
- **需求驱动、动机扎实**：用实测数据支撑"没有单一草稿结构最优"的判断，并针对不同负载特点设计不同的草稿器。
- **模块化方法设计**：主干、AR 头、损失函数、数据扩展均可插拔，消融实验逐层验证每个组件的贡献。
- **直接优化接受率**：通过 TV 距离/负 log-overlap 损失将训练目标与投机解码的接受行为对齐，而非仅优化 KL 散度代理。
- **推理调度创新**：D-cut 将验证视为跨请求的共享资源，以全局视角做预算分配，是对现有请求局部自适应方案的实质性改进。
- **工程完整体现**：开源 AngelSpec 框架，支持分离式隐藏状态生成、TTT rollout、长上下文训练、在线接受率评估等完整训练流程。
- **实验深度与真实场景验证并重**：不仅有标准基准的系统评测，还用生产流量回放验证了方法的实际部署价值。

## 8. 不足与局限

- **硬件覆盖有限**：吞吐实验仅在 8× H20 上运行，未涵盖 A100/H100 等更主流硬件；D-cut 的成本表可能在不同硬件上有不同特性。
- **模型规模覆盖局限**：在两个目标模型（Qwen3-8B 和 Hy3-A21B）上验证，缺少更大规模模型的普适性证据。
- **对比公平性的潜在偏差**：MTP 使用 1 层草稿器 vs 并行方法 5 层；并行方法受益于更多参数量。D-cut 对比中分段 CUDA graph 的限制虽有利于保守估计，但也说明 D-cut 的完整潜力尚未充分展示。
- **领域特化的代价**：DFly 在 MT-Bench 上略低于 DSpark，领域特化可能牺牲部分对话性能；真实流量中

“真实流量中”对话类请求占比较高时，DFly 的端到端优势可能收窄，用户需依据实际流量组成选择草稿器类型，这对开箱即用的部署提出了额外要求。

- **训练成本与资源细节缺失**：论文未报告训练 GPU 数量、总训练时间、显存占用等关键资源信息，无法评估 AngelSpec 在可复现性上的实际门槛；10 个 epoch 的训练设置是否造成过拟合也缺乏详细分析。
- **D-cut 的预算选择粒度较粗**：预算比例仅从四个离散值（0.25/0.50/0.75/1.00）中选取，未验证更细粒度搜索是否带来额外收益；全局 top-K 选择依赖草稿器置信度估计的可靠性，在分布偏移场景下可能存在鲁棒性风险。
- **思考模式实验范围有限**：仅验证了“无思考/高思考”两组配置的交叉组合，未覆盖中等思考模式或更强思考推理模型，结论的泛化性有待进一步检验。
- **缺少与现有多草稿器混合方案的直接对比**：论文论证了单一草稿结构不适用于所有负载，但在实验中未对比“同时部署 MTP 与 DFly 并按请求路由”的显式混合方案，D-cut 的全局预算调度与简单路由之间的增益边界尚不清晰。

## 9. 结论与总体评价

- **总体定位**：AngelSpec 是首个系统性地将真实世界负载异构性纳入投机解码全链路设计的训练/推理框架，其核心贡献在于论证了“草稿器结构必须与工作负载条件熵匹配”这一设计原则，并提供了从训练目标到推理调度的完整实现方案。
- **主要贡献**：
  1. 提出统一训练框架 AngelSpec，按数据域特化 MTP 与块扩散两类草稿器，打破了“单一通用草稿器”的假设。
  2. 在 MTP 中加入 TTT 与接受对齐蒸馏，直接优化拒绝采样接受率，解决了训练/推理分布不匹配问题。
  3. 设计 DFly 块扩散架构，通过混合目标条件主干 + 前趋条件自回归头，将接受长度提升至超过 DFlash 与 DSpark。
  4. 提出 D-cut 动态验证预算管理，将验证视为跨请求共享资源，显著扩展了高并发下的有效吞吐范围。
- **客观评价**：论文的实验设计系统、消融充分、工程实现完整，结论可靠；但其硬件覆盖面窄、对比条件存在参数量不对称、混合路由对比缺失等局限，使得“真实世界高性能推理”的普适性主张仍需在更多硬件与更大规模模型上进一步验证。总体而言，AngelSpec 在投机解码的现实部署方向上迈出了实质性一步，具有明确的工程借鉴价值。
