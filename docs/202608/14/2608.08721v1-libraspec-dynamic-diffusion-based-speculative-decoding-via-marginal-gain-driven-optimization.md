## 摘要
推测解码通过草拟多个令牌进行并行验证来加速大语言模型推理，其效率关键取决于每一轮解码所选择的推测长度。现有的动态推测方法通过估计将被接受的令牌数量来选择推测长度，这对于按顺序生成令牌的自回归草拟器是合理的。然而，最近的扩散式草拟器以显著更低的草拟成本并行生成候选块，将关键问题从应生成多少令牌转变为应验证多少生成的令牌。因此，我们将动态推测长度选择重新表述为期望加速优化问题，并推导出一个边际准则：仅当接受增益超过额外验证成本时，才扩展推测序列。基于此准则，我们开发了LibraSpec，一种无需训练且即插即用的算法，它利用草拟器置信度分数迭代地确定推测长度。理论上，我们证明了LibraSpec单调收敛于最优推测长度。在六个目标模型、三种基于扩散的推测解码方法以及数学、编码和聊天基准上的实验显示，在贪婪采样和随机采样设置下均有一致改进，相比基线进一步提升了0.5到1.5倍的速度，相比自回归解码实现了最高8.49倍的加速。

## Abstract
Speculative decoding accelerates large language model inference by drafting multiple tokens for parallel verification, with efficiency critically determined by the speculative length selected at each decoding round. Existing dynamic speculation methods select the speculation length by estimating how many tokens will be accepted, which is reasonable for autoregressive drafters that generates tokens sequentially. The recent wave of diffusion-based drafters, however, generates candidate blocks in parallel at substantially lower drafting cost, shifting the key question from how many tokens to generate to how many generated tokens are worth verifying. We therefore reformulate dynamic speculative-length selection as expected-speedup optimization and derive a marginal criterion that extends the speculative sequence only when its acceptance gain outweighs the additional verification cost. Building on this criterion, we develop \textit{LibraSpec}, a training-free and plug-and-play algorithm that iteratively determines the speculative length using drafter confidence scores. Theoretically, we prove that LibraSpec monotonically converges toward the optimal speculative length. Experiments across six target models, three diffusion-based speculative decoding methods, and math, coding, and chat benchmarks show consistent improvements under both greedy and sampling settings, achieving a further $0.5\sim1.5\times$ improvement over baselines and up to $8.49\times$ speedup over autoregressive decoding.

# LibraSpec 论文详细总结

## 1. 核心问题与研究动机

- **背景**：大语言模型（LLM）自回归解码逐 token 生成，推理速度成为长上下文场景（如代码生成、交互应用）的主要瓶颈。推测解码（Speculative Decoding）通过轻量草稿模型并行生成候选 token，再由目标模型并行验证，可在保 lossless 的前提下显著加速推理。
- **关键矛盾**：每轮解码的**推测长度**（speculative length）直接影响加速效果——过短则并行验证能力未充分利用，过长则早期拒绝会浪费大量验证计算，且最优长度随解码上下文动态变化。
- **范式转变**：现有动态推测长度方法面向**自回归草稿模型**（需顺序生成、草拟成本高），通过预测接受长度来选择推测长度。而新兴的**扩散式草稿模型**（如 FastdLLM、DFlash、DDTree）以极低代价并行生成整个候选块，问题从"生成多少 token"变为"**多少已生成 token 值得验证**"。仅估计接受长度不足以最大化端到端加速，因为即使扩展部分很可能被接受，其收益也可能不足以抵消额外验证开销。
- **研究目标**：提出一种面向扩散式草稿模型的动态推测长度选择算法，将长度选择建模为**期望加速优化**问题，在无需训练、即插即用的前提下显著提升解码效率。

## 2. 方法论

- **核心思想**：将动态推测长度选择从"预测接受长度"重构为"**期望加速优化**"。扩展推测序列的充要条件是：新增片段的**边际收益**（接受增益）优于当前序列的**平均收益**（验证成本），即满足"边际增益准则"。
- **形式化建模**：
  - 定义加速比 $\eta_d = \tau_d L_{target} / (T_{draft}^d + T_{verify}^d)$，其中 $\tau_d$ 为接受 token 数，$L_{target}$ 为目标模型单 token 延迟，$T_{draft}$ 与 $T_{verify}$ 分别为草拟与验证耗时。
  - 在扩散式草稿模型下，草拟成本可忽略，加速优化退化为平衡**接受增益**与**验证成本**的问题。
  - 定义"单次有益调整"（Single Beneficial Adjustment）：调整后期望加速严格提升。
- **关键定理**：
  - **定理 3.2**：长度调整有益的充要条件为边际收益/边际成本比值优于当前平均值（扩展时需高于，截断时需低于）。
  - **定理 3.3**（必要性）：位置级约束——每个位置 $i$ 的边际增益/成本比必须优于当前位置累计均值，推导出最大可接受长度 $\epsilon_i$ 的闭式上界。
  - **定理 3.4**（充分性）：令 $d' = \min_i \epsilon_i$ 即可保证单次有益调整成立。
  - **定理 3.5**：期望加速比是推测长度的**单峰函数**，保证迭代优化不会陷入局部最优。
  - **定理 3.6**：迭代应用有益调整可在**有限步内收敛到全局最优推测长度区间**。
- **LibraSpec 算法流程**：
  1. 生成一个初始 draft block（大小 $n$），以默认块大小作为初始推测长度 $d$。
  2. 维护"草稿预算" $B$，避免频繁调用草稿模型。
  3. 迭代计算 $\epsilon^* = \min_i \epsilon_i$（用草稿模型置信度 $q_k$ 近似未知的接受概率 $p_k$），若 $\epsilon^* \leq d$ 则回退并终止；否则扩展长度并消耗预算，预算不足时按需生成新 draft block。
  4. 将最终确定的 $d$ 个 token 提交验证。
  - 设计细节：最多执行一次回滚以防止振荡；引入超参数 $\alpha$ 统一吸收运行时相关的 $T_{verify}$、$\tau_i$、$c$，控制扩展激进程度。
- **实践假设**：假设草稿模型置信度分数 $q_i$ 与目标模型接受概率 $p_i$ 良好校准（Assumption 3.7），并设置模型相关的最大推测长度 $d_{max}$（FastdLLM 取 60，DFlash/DDTree 取 24）以限制长程校准退化。
