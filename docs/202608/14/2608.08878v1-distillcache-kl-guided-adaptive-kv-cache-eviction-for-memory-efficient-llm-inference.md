## 摘要
基于Transformer的大型语言模型（LLM）在许多任务上表现出色，但其键值（KV）缓存随序列长度线性增长，造成长上下文推理中的严重内存瓶颈。现有的启发式驱逐方法（如H₂O和SnapKV）依赖静态注意力或位置信号，往往无法捕捉标记未来的预测影响力。我们提出DistillCache，一种强化学习框架，将KV缓存驱逐建模为序列决策问题。DistillCache利用丰富的内部模型信号（注意力统计量、值范数、熵和位置）学习轻量级策略网络，并通过逐步骤KL散度奖励使用REINFORCE进行训练，以保留完整缓存的输出分布。在7B参数指令微调Transformer（Mistral-7B-Instruct-v0.3）上，DistillCache在25%缓存预算下于LongBench上保留了94.2%的全缓存准确率，在长上下文任务上，分别比强启发式基线（H₂O、SnapKV）高出最多2.7个绝对百分点，并且在我们重新实现的对比中，比并行的基于RL的方法（ForesightKV、RLKV）高出最多1.4个百分点。在推理基准测试中，DistillCache与最佳并行方法相当，并在激进压缩设置下超越它。它还实现了最高2.1倍的全缓存吞吐量，同时保持了具有竞争力的实际效率。这些结果凸显了学习型、分布感知策略在内存高效的长上下文LLM推理中的有效性。

## Abstract
Transformer-based large language models (LLMs) achieve strong performance across many tasks, but their Key-Value (KV) cache grows linearly with sequence length, creating a severe memory bottleneck for long-context inference. Existing heuristic eviction methods (e.g., H$_2$O and SnapKV) rely on static attention or positional signals that often fail to capture a token's future predictive influence. We propose DistillCache, a reinforcement learning framework that formulates KV-cache eviction as a sequential decision problem. DistillCache learns a lightweight policy network using rich internal model signals (attention statistics, value norms, entropy, and position) and trains it with REINFORCE via a per-step KL-divergence reward to preserve the full-cache output distribution. On a 7B-parameter instruction-tuned Transformer (Mistral-7B-Instruct-v0.3), DistillCache retains 94.2% of full-cache accuracy on LongBench at a 25% cache budget, outperforming both strong heuristic baselines (H$_2$O, SnapKV) by up to 2.7 absolute points and, under our re-implementations, concurrent RL-based methods (ForesightKV, RLKV) by up to 1.4 points on long-context tasks. On reasoning benchmarks, DistillCache is competitive with the best concurrent method and surpasses it under aggressive compression. It also delivers up to 2.1x full-cache throughput while maintaining competitive practical efficiency. These results highlight the effectiveness of learned, distribution-aware policies for memory-efficient long-context LLM inference.

## 1. 核心问题与整体含义（研究动机与背景）

- **核心问题**：Transformer 大语言模型（LLM）在自回归解码时必须依赖 KV 缓存（Key-Value Cache）避免重复计算，但 KV 缓存随序列长度**线性增长**，导致长上下文推理过程中出现严重的内存瓶颈和吞吐量下降。
- **现有方法的不足**：已有的启发式驱逐方法（如 H₂O、SnapKV、StreamingLLM、Keyformer）依赖静态的注意力统计或位置信号来判定 token 的重要性。这类方法隐含假设“过去的注意力模式能可靠预测未来效用”，但在长距离依赖、结构化推理或需要前瞻性判断的场景中，这一假设往往失效——一个 token 的长期预测影响力无法仅靠历史注意力信号捕捉。
- **整体含义**：论文提出将 KV 缓存驱逐问题重新定义为**序列决策问题（Sequential Decision Problem）**，通过强化学习直接优化“保留哪些 token 能使压缩后模型的输出分布最接近完整缓存模型的输出分布”，从而在固定内存预算下实现比启发式方法更优的生成质量保持。

## 2. 方法论

### 2.1 核心思想
- **核心目标**：在给定固定缓存预算 B 的条件下，构造一个被剪枝的缓存 C′ₜ ⊆ Cₜ（|C′ₜ| ≤ B），使得剪枝模型与全缓存模型的下一步 token 预测分布尽可能接近。
- **关键思路**：把 token 驱逐决策交由一个经过强化学习训练的策略网络来完成，用**逐步骤 KL 散度**衡量剪枝模型与完整模型输出分布之间的距离，并以此作为奖励信号。

### 2.2 状态空间（Token 特征设计）
每个缓存中的 token i 构建一个 5 维特征向量：

| 特征 | 含义 |
|------|------|
| αᵢ | 平均注意力质量（token i 作为 key 在所有头/层上的累积注意力均值） |
| ‖vᵢ‖₂ | 值向量的 ℓ2 范数 |
| σᵢ | 注意力质量跨头的方差 |
| Hᵢ | 近期查询端注意力上下文的熵（注意力加权平均熵） |
| posᵢ | 归一化序列位置 |

这些特征均可在解码过程中已有的中间量中直接计算，无需额外大幅开销。

### 2.3 动作空间与策略网络
- 策略网络为轻量级 MLP（约 **20 万参数**，两层 128 隐藏单元 + ReLU + LayerNorm），为每个 token 输出一个标量分数 sᵢ = fφ(xᵢ)。
- **训练阶段**：对分数施加 i.i.d. Gumbel 噪声（s̃ᵢ = sᵢ + gᵢ），取 top-B 子集，即从 Plackett–Luce 分布中采样；子集对数概率通过动态规划精确计算 log 配分函数（O(L·B) 复杂度）。
- **推理阶段**：确定性取 top-B，无需 Gumbel 噪声。

### 2.4 理论动机（KL 界）
- 论文通过三角不等式证明：当驱逐集合 E 的注意力质量 εₜ 被移除并重新归一化后，输出向量的扰动上限为 ‖oₜ − ôₜ‖₂ ≤ 2Cεₜ。
- 由于 logits 是注意力输出的线性投影，且 softmax 局部 Lipschitz 连续，可得 **逐步骤 KL 散度被驱逐注意力质量的平方所上界约束**，这为“保留高注意力 token”的直觉提供了理论支撑，但 KL 奖励通过完整 softmax 端到端衡量，能捕捉线性界限无法反映的非线性交互效应。

### 2.5 奖励与优化
- **奖励**：Rₜ = −D_KL(Pₜ ‖ P̂ₜ)，其中 Pₜ 为全缓存模型分布（teacher），P̂ₜ 为剪枝模型分布（student）。
- **优化算法**：REINFORCE + 熵正则（β=0.01）+ 折扣回报（γ=0.99）+ RLOO（留一法）基线 + 指数滑动平均基线。
- **训练架构**：维护两个并行缓存——
  - Teacher 缓存：从不过滤，提供完整分布 Pₜ；
  - Student 缓存：按策略逐步骤驱逐，提供剪枝分布 P̂ₜ；
  - 每步通过两个前向传播的 logits 计算 KL 散度作为奖励。
- **优势论证**：论文通过与监督蒸馏排序器对比说明，强化学习直接优化“下游分布保真度”能学到静态排序目标无法捕捉的长期权衡。

## 6. 主要结论与发现

1. **核心成果**：在 Mistral-7B 上、25% 缓存预算下，DistillCache 在 LongBench 上保留了 **94.2%** 的全缓存准确率（39.1 vs 41.5 绝对准确率）。
2. **对启发式方法的优势**：在 LongBench 上最高超过 H₂O 2.7 个百分点（25% 预算）、超过 SnapKV 2.1 个百分点；在 12.5% 激进压缩下优势更大（+6.8 vs H₂O）。
3. **对并发 RL 方法的对比**：LongBench 上超越 ForesightKV 和 RLKV 0.9–1.4 个百分点（25% 预算）；推理任务上 RLKV 在中度预算下略强，但 12.5% 激进压缩下 DistillCache 反超。
4. **跨模型泛化**：零样本从 Mistral-7B 迁移到 Llama-3-8B 时仍能超越启发式基线（LongBench 89.7% vs H₂O 86.9%、SnapKV 88.6%），而并发 RL 方法需逐模型重训。
5. **性能效率**：25% 缓存预算下实现约 **2.1× 全缓存吞吐量**（38.0 vs 18.0 tokens/s），与并发 RL 方法吞吐相当，略低于启发式方法。
6. **KL 奖励有效性**：消融证实，逐步骤 KL 散度奖励优于 ForesightKV 风格长期贡献奖励（+2.3 点）和整体未来效用排序（+1.6 点）。
7. **定性发现**：策略自动学会保留否定词（如 "not"）、句法关键动词（如 "say"）、初始 attention sink token 和近期 token，无需硬编码保护。

## 7. 优点

- **问题建模清晰**：首次将 KV 缓存驱逐明确建模为强化学习序列决策问题，奖励直接来自“分布保真度”这一下游生成质量指标，而非启发式代理信号。
- **理论与实践结合**：给出了 KL 散度上界与驱逐注意力质量之间的理论推导，为奖励设计提供了理论依据，同时说明 KL 奖励能捕捉理论界限之外的软化非线性效应。
- **特征设计丰富**：融合注意力、值范数、注意力方差、熵、位置五种互补信号，相比仅使用注意力统计的方法更精细。
- **实用性强**：推理阶段仅需一次前向传播，策略为 20 万参数轻量 MLP，引入约 1.4 ms/token 的额外开销，可实现 2.1× 吞吐提升。
- **实验规范透明**：5 个种子的均值±标准差、完整训练细节公开、明确披露重实现对比的局限、附带 NeurIPS Checklist。
- **跨模型泛化能力**：零样本迁移无需重训，显著降低了部署成本。

## 8. 不足与局限

- **训练成本高**：约 130 GPU 小时 + 双缓存带来的训练显存翻倍，远高于零训练启发式方法。
- **RL 稳定性风险**：REINFORCE 天然存在高方差，虽以熵正则、RLOO 基线和多种子平均缓解，但更先进的优化器（PPO/GRPO）可能更稳定但代价更高。
- **推理任务存在短板**：RLKV 在中度预算（50%、25%）的推理任务上仍略强于 DistillCache，仅在 12.5% 激进压缩下被反超。
- **token 独立性假设**：策略独立评分每个 token，未显式建模 token 间交互。
- **架构耦合**：特征设计依赖 Transformer 注意力模式，迁移到非注意力架构需重新设计。
- **对比公平性的固有局限**：ForesightKV 与 RLKV 为作者重实现而非官方代码，实际差距可能因训练配置差异而改变。
- **实验覆盖有限**：未在 13B+ 更大模型、32K–128K 超长上下文、多机多卡服务环境验证；未评估量化或 offloading 等系统级组合效果。
- **响应长度偏差**：DistillCache 生成的响应平均为全缓存的 1.03 倍，而 H₂O 为 0.87 倍，需注意评估指标（ROUGE-L）可能对更长输出存在潜在偏差。
