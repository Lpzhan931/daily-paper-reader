## 摘要
投机性解码通过并行验证多个草稿token，以无损方式加速自回归语言模型。基于扩散的草稿器通过并行预测整个token块进一步减少了提议延迟，但其逐位置分布是边缘分布，而非以每条草稿路径上选定的token为条件。现有的循环校正沿单一草稿链引入因果信息，而基于扩散的树构建则拓宽了候选覆盖范围，却未沿各分支携带这种校正。我们提出DARTree，一种无需训练的投机性解码方法，将预训练的自回归校正头从链扩展到树。DARTree首先通过单批次扩展并评分每个深度处的所有节点来构建固定宽度的候选树，然后仅应用最佳优先剪枝来选择验证树，从而将AR头推理与顺序堆操作解耦。在七个数学、代码和聊天基准上，DARTree在所有四种模型-温度配置中均实现了最高的平均接受长度和加速比，每轮验证最多接受12.97个token，比同设置下的DFlash多98.6%，比Domino多27.9%，并相对于本地测量的自回归解码达到最高9.73倍的无损加速。

## Abstract
Speculative decoding losslessly accelerates autoregressive language models by verifying multiple draft tokens in parallel. Diffusion-based drafters further reduce proposal latency by predicting an entire token block in parallel, but their position-wise distributions are marginal rather than conditioned on tokens selected along each draft path. Existing recurrent correction incorporates causal information along a single draft chain, whereas diffusion-based tree construction broadens candidate coverage without carrying this correction along individual branches. We introduce DARTree, a training-free speculative decoding method that extends a pretrained AR correction head from chains to trees. DARTree first constructs a fixed-width candidate tree by expanding and scoring all nodes at each depth in a single batch, and then only applies best-first pruning to select the verification tree, decoupling AR-head inference from sequential heap operations. Across seven math, code, and chat benchmarks, DARTree achieves the highest average acceptance length and speedup in all four model--temperature configurations, accepting up to 12.97 tokens per verification round, 98.6\% more than DFlash and 27.9\% more than Domino in the same setting, and reaching up to 9.73$\times$ lossless speedup over locally measured autoregressive decoding.

## 1. 核心问题与整体含义（研究动机与背景）

- **研究背景**：现代自回归大语言模型（LLM）在推理时逐 token 生成，每次解码仅生成一个 token 却需访问几乎全部模型参数，推理过程以 I/O 为瓶颈，无法充分利用现代硬件的并行能力。
- **投机性解码**：通过轻量级草稿模型（drafter）提出多个候选 token，再由目标模型并行验证，可无损加速推理。但自回归草稿器仍顺序生成 token，延迟随草稿长度增长。
- **扩散式块草稿器**：DFlash 等通过一次前向传播预测整个 token 块，降低提议延迟并允许更高容量的草稿器；但逐位置分布是边缘分布（marginal），缺乏同一块内先验 token 的条件依赖，与目标模型的条件分布不匹配。
- **现有方法的不足**：
  - Domino / DSpark 通过轻量级因果校正头沿**单条草稿链**恢复部分块内依赖；
  - DDTree 通过扩散边缘分布构建前缀树拓宽候选覆盖，但**不沿分支携带因果校正**。
  - 若将因果校正与 DDTree 式堆搜索结合，会产生顺序瓶颈——每个节点出堆后都需校正头推断，才能扩展子节点，使树构建成为主要延迟来源。
- **核心问题**：如何在保留路径相关评分（path-dependent scoring）的同时，批量并行构建草稿树，从而兼顾因果校正质量与树构建效率。

## 2. 方法论：DARTree

### 2.1 核心思想
- 将预训练的自回归（AR）校正头从单链扩展到树结构——**无需任何训练**。
- 采用**深度方向的批量扩展（depth-wise batched expansion）**：在每个深度同时扩展和评分所有活跃分支，将校正头推理与顺序堆操作解耦。
- 构建一个**比最终验证树更宽的候选超树（supertree）**，待全部候选评分完成后，通过**延迟的最佳优先剪枝（deferred best-first pruning）** 一次性选出验证树。

### 2.2 关键技术细节
1. **块并行骨干网络单次执行**：产生共享表示 $\{H_d\}_{d=1}^\gamma$ 和基础 logits $\{L_d^{\text{base}}\}_{d=1}^\gamma$。
2. **候选词表裁剪**：每个位置仅保留 top-K token 预测作为候选扩展（默认 $K=64$）。
3. **深度方向批量校正**：在每一深度 $d$，对所有活跃前缀 $u_{<d}$ 上的候选 token 批量应用校正头 $g$，得到校正后的条件分布 $\tilde{q}_d(C_d \mid u_{<d})$。
4. **评分与选择**：每个子前缀 $u_{1:d}$ 的分数为累积对数校正概率加深度惩罚：$s_\beta(u_{1:d}) = \sum_{i=1}^{d} \log \tilde{q}_i(u_i) + \beta d$，其中 $\beta \le 0$。每层保留全局 top-W 个子前缀（默认 $W=12$）。
5. **延迟剪枝**：超树构建完成后，一次 top-B 全局选择（B=64）获得最终验证树。Lemma 1 证明当 $\beta \le 0$ 时，全局 top-B 等价于顺序 best-first 堆选择，且保证前缀闭合性质。
6. **目标模型树验证**：使用标准的树注意力掩码在单次前向传播中验证所有分支，验证过程与现有方法完全一致。

### 2.3 算法流程（Algorithm 1）
- 初始化根节点、校正状态和根分数；
- 对深度 $d=1$ 到 $\gamma$：
  - 选择 top-K 候选 token；
  - 批量校正所有前缀-候选对；
  - 计算子前缀分数；
  - 保留全局 top-W 子前缀并更新校正状态；
- 对完整超树执行 top-B 剪枝，返回验证树。

## 6. 主要结论与发现

1. **性能全面领先**：DARTree（pruned）在所有 4 种模型-温度配置中均取得最高的平均接受长度和加速比。在 GSM8K、Qwen3-4B、T=0 下，τ=12.97，加速比达 9.73×，τ 比 DFlash 高 98.6%，比 Domino 高 27.9%。
2. **深度并行扩展有效**：DARTree（fixed）已分别将 τ 较 DDTree 和 Domino 提升最多 22.9% 和 37.9%，证明无剪枝条件下多分支因果校正也有显著增益。
3. **延迟剪枝带来增量收益**：pruned 较 fixed 在 τ 上最多提升 6.5%、加速比上最多提升 7.1%，说明从更宽校正分支集合中选择验证树是有益的。
4. **通用性验证**：DARTree 不仅适用于 Domino 的 RNN 校正头，也能推广到 DSpark 的 Markov 校正头（τ 提升 14.6%–40.6%）。
5. **位置接受率改善**：DARTree 结合了 DDTree 的早期接受优势和 Domino 的深位置延续优势，大幅提高完整草稿块接受的概率。
6. **结构差异**：DARTree 形成的树更窄更深，DDTree 偏好宽而浅的结构；DARTree 树分支的语义连贯性更好。
7. **适用场景明确**：在低并发（单请求或少请求）场景收益最大；高并发计算受限时需调整预算 B 和宽度 W。

## 7. 优点

- **无需训练**：直接复用已有扩散草稿器的预训练校正头，零训练开销，即插即用。
- **创新性地解耦了校正与搜索**：将原本顺序交织的堆搜索与校正头推理改为"深度并行扩展 + 延迟剪枝"，从算法层面识别并解决了关键的性能瓶颈（并给出了 Lemma 1 的严格证明）。
- **方法通用**：不假设特定校正架构（RNN 或 Markov 均可），是通用的树构建框架而非 Domino 专属修改。
- **近似损失极小**：与精确顺序搜索相比，DARTree 的 τ 几乎相同（12.967 vs 12.840），但每轮延迟降低超过一半（28.5ms vs 62.7ms），近似策略的性价比极高。
- **实验扎实**：覆盖多领域、多温度、多模型，附带并发场景分析和超参数敏感性分析，以及树结构和语义的定性可视化（不仅看数字，还展示树质量差异）。
- **损失无风险**：验证过程完全继承标准投机采样，无损地保持目标分布。

## 8. 不足与局限

- **依赖校正头**：训练免费的性质不适用于朴素扩散草稿器（如纯 DFlash），必须配备因果校正头，限制了适用范围。
- **计算开销不低**：不减少总 FLOPs，反而因树验证较大候选集产生比非树方法更高的计算负担；在计算受限（高并发）场景下加速收益会显著下降。
- **适用场景受限**：主要为低并发、延迟敏感的部署场景设计；高并发批处理时，可能需要根据负载动态调整 B 和 W 才能维持优势（论文附录中的并发实验显示，固定大树的收益随并发度增加而骤减）。
- **候选词表裁剪**：K=64 的 top-K 约束虽高效，但理论上可能剪掉低概率却最终被接受的长尾 token；论文实验显示 K 从 32 到 512 影响很小，但未测试多语言或分布更分散的任务。
- **未报告端到端系统收益**：主实验基于 HuggingFace Transformers 内部延迟，仅并发实验使用 SGLang；未包含工业级服务框架下的标准端到端 latency/throughput 对比。
- **评估范围**：仅覆盖 Qwen3 系列两个模型尺度，未测试更大模型（如 70B 级别）或更多模型家族（如 Llama、DeepSeek）上的泛化性。
- **温度依赖**：T=1 下的增益小于 T=0，且 AIME25 上 8B @ T=1 的 DDTree 加速比略超 DARTree（尽管 τ 更高），说明随机采样模式下树方法优势略有削弱。
- **超参数敏感性**：性能对 W 和 B 较敏感，且最优配置可能随目标模型或任务分布变化，实际部署需要重新调参。
