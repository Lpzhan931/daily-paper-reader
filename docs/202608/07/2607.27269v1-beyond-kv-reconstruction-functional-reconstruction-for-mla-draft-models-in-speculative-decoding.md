## 摘要
多头潜在注意力（MLA）对于长上下文大语言模型（LLM）推理越来越重要，因为紧凑的潜在状态取代了不断增长的键值（KV）缓存，并减少了解码内存流量。然而，大多数有能力的开放检查点使用多头或分组查询注意力（MHA/GQA），因此需要进行转换，以便在不从头重新训练的情况下获得MLA的缓存效率。投机解码提供了互补的加速，但其加速效果取决于草稿提议与目标验证之间的一致性。我们发现，直接的MHA/GQA到MLA转换会急剧降低这种一致性：低秩分解和RoPE处理引入了注意力函数误差，这些误差对于独立生成或许可以容忍，但会显著降低草稿标记的接受率。因此，我们将MLA草稿构建表述为功能重构，而非缓存压缩。我们的端到端（E2E）方法优化每个转换后的MLA注意力模块，以在校准隐藏状态上重现其原始MHA/GQA对应模块的输出投影后响应。这种与转换器无关的转换后过程保留了转换后的缓存和推理图，并且既不需要验证器logits，也不需要验证器监督。我们评估了192种模型-转换器-后端-方法-任务配置，涵盖四对Llama/Qwen草稿-目标对、TransMLA和MHA2MLA、HF和vLLM，以及四个包含200个提示的任务。在0.5个百分点的报告容差下，功能重构在64个匹配任务单元中的37个中显著提高了接受率，26个几乎没有变化，一个显著下降。代码和评估工件可在https://github.com/swyhahaha/FunctionalMLA获取。

## Abstract
Multi-head latent attention (MLA) is increasingly important for long-context LLM inference because compact latent states replace the growing key-value (KV) cache and reduce decoding memory traffic. Yet most capable open checkpoints use multi-head or grouped-query attention (MHA/GQA), so conversion is needed to obtain MLA's cache efficiency without retraining from scratch. Speculative decoding offers complementary acceleration, but its speedup depends on agreement between draft proposals and target verification. We find that direct MHA/GQA-to-MLA conversion can sharply reduce this agreement: low-rank factorization and RoPE handling introduce attention-function errors that may be tolerable for standalone generation but substantially lower draft-token acceptance. We therefore formulate MLA draft construction as functional reconstruction rather than cache compression. Our end-to-end (E2E) method optimizes each converted MLA attention module to reproduce the post-output-projection response of its original MHA/GQA counterpart on calibration hidden states. This converter-agnostic post-conversion procedure preserves the converted cache and inference graph and requires neither verifier logits nor verifier supervision. We evaluate 192 model-converter-backend-method-task configurations spanning four Llama/Qwen draft-target pairs, TransMLA and MHA2MLA, HF and vLLM, and four 200-prompt tasks. With a 0.5-percentage-point reporting tolerance, Functional Reconstruction materially improves acceptance in 37 of 64 matched task cells, leaves 26 practically unchanged, and materially decreases one. Code and evaluation artifacts are available at https://github.com/swyhahaha/FunctionalMLA.

## 1. 核心问题与整体含义

- **研究动机**：大语言模型推理的瓶颈正从计算转向内存访问。自回归解码需要读取不断增长的 KV 缓存，因此缓存表征方式直接影响服务延迟和吞吐。MLA（多头潜在注意力）通过缓存低维潜在向量替代显式 KV 缓存，可显著降低内存流量；但现有强开源模型大多基于 MHA/GQA 预训练，需要将其转换为 MLA 才能获得缓存优势。
- **关键矛盾**：投机解码（speculative decoding）依赖草稿模型与目标模型之间的分布或排名一致性。论文发现，直接 MHA/GQA→MLA 转换在独立生成场景下可能可容忍，但在投机解码中会显著降低草稿标记接受率。原因包括：
  - 低秩 KV 分解无法精确复现原始拼接后的 K/V 投影；
  - RoPE 处理会引入位置路径误差、键重建误差和查询扰动；
  - 这些注意力函数误差会改变草稿分布或 top-1 排名，导致验证拒绝更多标记。
- **核心转变**：论文提出应将“MLA 草稿构建”视为**功能重构**问题，而非“缓存压缩”问题。转换后的 MLA 模块应在校准隐藏状态上重现原始 MHA/GQA 注意力模块的完整输出响应，从而在不改变缓存结构、不引入验证器监督的前提下提升投机解码接受率。

## 2. 方法论

- **核心思想**：端到端（E2E）功能重构，聚焦于注意力函数的完整输入-输出映射，而非仅重建 K/V 投影的低秩因子。
- **关键技术细节**：
  - 从任意 MLA 转换器（TransMLA 或 MHA2MLA）生成的缓存可用检查点作为初始化；
  - 对每一层，将同一校准隐藏状态分别送入**冻结的原始 GQA 注意力块**和**可训练的转换后 MLA 注意力块**；
  - 比较两者经过输出投影 \(W^O\) 后的响应，用带掩码的均方误差作为损失；
  - 梯度通过原路径时使用 stop-gradient，仅更新转换器引入的 query 投影和 KV 投影；输出投影 \(W^O\) 及非注意力参数保持冻结；
  - 不依赖验证器 logits、验证器激活、任务标签或生成目标。
- **损失函数（文本形式）**：
  \[
  \mathcal{L}_{\mathrm{E2E}}^{(\ell)}
  =
  \mathbb{E}_b
  \left[
  \frac{
  \| M_b \odot (A^{\mathrm{MLA}}_\ell(H_{\ell b}) - \operatorname{sg}[A^{\mathrm{orig}}_\ell(H_{\ell b})]) \|_F^2
  }{
  D \sum_t M_{b,t}
  }
  \right]
  \]
  - 其中 \(M_b\) 标记有效 token；
  - \(A\) 为注意力层经过固定输出投影后的完整输出；
  - 分母按所有隐藏维度和有效 token 数平均；
  - 该方法同时覆盖低秩 KV 压缩误差和 RoPE 处理误差，是转换器无关的后处理阶段。
- **与既有方法的区别**：
  - TransMLA 和 MHA2MLA 解决的是“如何从 MHA/GQA 初始化出有效的 MLA 参数”；
  - 本文解决的是“在固定 MLA 参数化内部，如何让注意力函数更接近原始函数”，不改变中间件缓存拓扑或推理图。
- **理论动机**：原始拼接 K/V 矩阵秩超过潜伏秩时，精确重建不可能；但减少局部功能残差仍可改善 token 排名。论文明确承认：该局部损失对接受率的影响是经验性的，而非理论上保证单调成立。

## 6. 主要结论与发现

- **核心结论**：MLA 转换与草稿实用性是不同目标；直接转换可能得到有效生成器，却成为低质量草稿模型。
- **重构效果**：
  - 在 64 个匹配任务单元中，37 个接受率显著提升（>0.5pp），26 个基本不变，1 个显著下降（Qwen-3B + TransMLA + vLLM + CNN/DM，仅 -0.55pp）；
  - 37 个显著提升中，12 个同时也显著提升吞吐；
  - 最大提升：+4.23pp（Llama-1B, TransMLA, vLLM, CNN/DM）、+3.92pp（HumanEval）、+3.78pp（NQ）等。
- **跨因素规律**：
  - Llama–TransMLA 组合全面受益（16/16 单元提升）；Llama–MHA2MLA 组合基本无改善（16/16 不变）；
  - Qwen–MHA2MLA 组合 15/16 单元改善；Qwen–TransMLA 组合改善较少且受后端影响明显；
  - 后端差异主要集中在 Qwen–TransMLA；任务类型之间没有系统性差异，说明改进来自共享注意力函数校正而非基准标签；
  - 草稿大小不是独立驱动因素，3B 的额外收益来自 Qwen 与转换器初始化的交互。
- **重要边界**：功能重构只能修复转换后参数内可表达的误差，无法弥补潜伏秩信息丢失，也无法修复不兼容的张量并行或 kernel 实现；因此对严重不匹配的转换器/后端路径，恢复幅度有限，且从不超越 Original GQA 接受率。

## 7. 优点

- **问题定义清晰、动机强**：将“转换有效性”与“草稿有效性”分离，指出结构性转换成功并不等于功能匹配，有深刻工程意义。
- **方法简洁且通用**：
  - 转换器无关：同一目标可同时用于 TransMLA 和 MHA2MLA；
  - 无需验证器 logits 或任务标签，规避了可能的数据污染和监督泄漏；
  - 不改变缓存结构、推理图或参数预算，训练时后处理，部署零额外开销；
  - 使用 post-\(W^O\) 的完整注意力函数作为目标，覆盖低秩与 RoPE 两类误差。
- **实验矩阵设计严谨**：在固定模型-转换器-后端-任务单元内比较 Partial 与 Ours，隔离重构目标的贡献；192 个配置规模在同类工作中属于较完整。

## 8. 不足与局限

- **规模有限**：目标模型最大仅 8B，草稿模型 ≤3B；未覆盖更大的开源模型（如 13B/70B）或更广泛架构；缺乏长上下文（>128 token）评测。
- **统计稳健性不足**：固定一个 seed、单次生成批次，没有置信区间或显著性检验；吞吐差可能受运行时序和 kernel 成熟度影响。
- **绝对改进有限**：重构只收复部分相对 Original GQA 的损失，从未超过未转换草稿的接受率；对严重不匹配的路径（如 Qwen–TransMLA + vLLM）几乎无法补救。
- **局部损失与端到端接受率脱节**：Eq. (11) 是连续、逐层代理，无法保证最终离散 token 排名单调改善，论文也承认存在一个临界负例。
- **训练开销未报告**：缺少训练步骤数、优化器、硬件需求、逐层重构时间等，影响工程复现。
- **吞吐结论受限**：未实现相较于未转换草稿的端到端系统级加速，因 MLA kernel 不成熟且 TP 配置不同；作者明确将系统速度视为待解决事项。
- **命名和对比范围**：只对比了 Partial RoPE 这一局部目标，没有对比其他训练时后补偿方法（如逐层蒸馏、层敏感加权等），因此无法证明该目标是最优的。
