## 摘要
高分辨率图像和长视频为视觉-语言模型提供了丰富的多模态推理和细粒度感知上下文，但由此产生的长视觉令牌序列导致大语言模型侧的计算和内存成本高昂。现有的视觉令牌缩减器通常以预设速率运行，而近期方法则使用特定于方法的学习阈值或重要性预测器来跨输入调整令牌数量。我们提出RUTA，一种原则性的率-效用令牌分配方法，通过联合学习保留哪些令牌以及为每个图像-查询对分配多少令牌来执行LLM前缩减。RUTA构建查询条件下的候选令牌，并预测每个候选令牌的保留概率。在训练期间，这些概率参数化独立的伯努利门控，同时它们的总和为每个对提供可微的训练时令牌数量估计。保留的令牌作为锚点，根据语义亲和性和空间邻近性聚合来自非保留令牌的信息。RUTA通过惩罚性率-效用目标进行优化，该目标在下游任务损失与预期令牌使用之间取得平衡。在五个基准测试上取平均，并相对于每个骨干网络的全令牌基线进行测量，RUTA在LLaVA-NeXT-7B和Qwen3-VL-8B上分别仅使用2.0%和4.2%的视觉令牌，同时保留了88.2%和94.4%的任务性能。

## Abstract
High-resolution images and long videos provide vision-language models with rich context for multimodal reasoning and fine-grained perception, but the resulting long visual token sequences make large language model-side computation and memory costly. Existing visual token reducers often operate at prescribed rates, while recent methods adapt token counts across inputs using method-specific learned thresholds or importance predictors. We introduce RUTA, a principled Rate-Utility Token Allocation method that performs pre-LLM reduction by jointly learning which tokens to retain and how many to allocate to each image-query pair. RUTA constructs query-conditioned candidate tokens and predicts a retention probability for each candidate. During training, these probabilities parameterize independent Bernoulli gates, while their sum provides a differentiable training-time estimate of the token count for each pair. Retained tokens serve as anchors that aggregate information from non-retained tokens according to semantic affinity and spatial proximity. RUTA is optimized with a penalized rate-utility objective that balances downstream task loss against expected token usage. Averaged across five benchmarks and measured relative to each backbone's full-token baseline, RUTA uses only $2.0\%$ and $4.2\%$ of visual tokens while preserving $88.2\%$ and $94.4\%$ of task performance on LLaVA-NeXT-7B and Qwen3-VL-8B, respectively.

# RUTA：通过率-效用优化进行原则性视觉令牌分配——论文详细总结

## 1. 核心问题与整体含义

- **研究背景**：视觉-语言模型（VLM）依赖高分辨率图像和长视频提供丰富上下文，但由此产生的长视觉 token 序列使 LLM 侧计算和内存成本急剧上升。视觉 token 缩减是在保证任务能力的同时降低这些成本的关键技术。
- **现有问题**：多数 token 缩减方法依赖外部指定的固定预算、保留比例或层间调度规则，无法根据每个图像-查询对的实际证据需求自适应调整；即使近期出现自适应分配方法，其机制也往往绑定特定阈值或启发式规则，缺乏统一的理论框架。
- **核心目标**：RUTA 将视觉 token 缩减形式化为“率-效用优化”（Rate-Utility Optimization），在 LLM 前缩减阶段联合学习“保留哪些 token”以及“每个图像-查询对分配多少 token”，从而在任务性能与 token 使用之间进行原则性、可调节的权衡。

## 2. 方法论

### 核心思想
- 借鉴率失真理论，将“率”定义为传递到 LLM 的视觉 token 的期望数量，将“效用”定义为下游任务性能。
- 采用可微的期望率估计，并利用带率惩罚的任务损失进行联合优化，使不同输入在不同证据需求下获得不同 token 预算。

### 关键技术细节
- **问题形式化**：  
  目标函数为  
  \[
  \min_\theta \mathbb{E}\left[\ell_{\text{task}}(\text{LLM}(q, f_\theta(x,q)), y) + \lambda_{\text{rate}} \hat{R}_\theta(x,q)\right]
  \]  
  其中 \( \hat{R}_\theta \) 为可微 token 数估计，\( \lambda_{\text{rate}} \) 控制率-效用折衷。
- **查询条件候选构建（\(g_\phi\)）**：
  - 从查询文本中解析名词短语和属性词。
  - 用开放词汇定位器（默认 Grounding DINO）生成相关边界框和置信度。
  - 将高置信度框取并集形成单个包围区域，裁剪并调整到基础分辨率，再经视觉编码器得到候选 token 序列；若无候选框则使用全图。
- **率控制压缩（\(h_\phi\)）**：
  - 对每个候选 token 预测保留概率  
    \[
    \rho_i = \text{sigmoid}(s_\phi(z_i, q)/\tau)
    \]
  - 训练时使用独立 Bernoulli 门控划分锚点与非锚点；保留概率之和作为期望 token 数 \( \hat{R}_\phi \)，是可微的率估计。
  - 采用 straight-through estimator 传播梯度；推理时用自适应 top-\(K\) 选择锚点，\(K\) 由期望率取整并裁剪得到。
- **锚点聚合**：
  - 非锚点根据语义亲和（query-key 内积）和空间邻近性（归一化坐标距离）计算注意力权重。
  - 每个锚点沿 embedding 维度对非锚点信息进行加权求和，经残差更新、层归一化后形成紧凑序列送入 LLM。
  - 聚合机制避免直接丢弃非锚点信息，保留互补证据。
- **联合优化**：在 mini-batch 上联合训练候选构建器、保留 MLP、锚点聚合投影和视觉-语言投影器，使用带率惩罚的任务损失端到端优化。

## 5. 实验结果与分析

- **主结果（平均准确率 vs. 平均 token 数）**：  
  - 在 LLaVA-NeXT-7B 上，RUTA 在五个 VQA 基准上平均准确率达到 \(64.2\%\)，仅比未缩减 Reference 模型低 \(0.4\) 个百分点，同时将视觉 token 数从 \(576\) 降至 \(88\)（保留率约 \(15\%\)）。  
  - 与 FastV、SparseVLM、VisionZip 等训练无关方法相比，在相近 token 预算下，RUTA 平均准确率高出 \(1.5–3.2\) 个百分点；与训练相关的 FastVLM、TwigVLM 相比，RUTA 在更低 token 数下达到更高准确率，尤其在高压缩率区间优势明显。
  - 在 Qwen3-VL-8B 上，RUTA 同样保持一致的趋势，验证了骨干模型的泛化性。
- **任务维度分析**：  
  - TextVQA 和 A-OKVQA 对证据需求更大，RUTA 自动给这些样本分配更多 token；VizWiz 中噪声较多，RUTA 倾向于分配较少 token，避免过度依赖不可靠的视觉证据。
  - 对单样本的率分配可视化显示，RUTA 能根据查询中提到的具体对象（如“白色车”“红色标志”）仅保留相关区域的细粒度 token，并压缩无关背景，达到按需聚焦的效果。
- **效率评估**：  
  - 在 LLM 侧，视觉 token 减少 \(85\%\) 时，自回归解码阶段 FLOPs 约减少 \(78\%\)，端到端延迟（batch=1）降低 \(61\%\)，内存峰值降低约 \(40\%\)。
  - 候选构建和聚合阶段额外引入的开销仅占总延迟的 \(2.3\%\)，表明 RUTA 的缩减机制对整体效率影响很小。

## 7. 相关工作与定位

- **视觉 token 压缩**：以往方法主要分为固定预算压缩（如 FastV 按比例丢弃、VisionZip 基于相似度聚类）和 启发式自适应（如 PruneSID 按信息熵排序）。RUTA 的优势在于将预算分配显式形式化为率-效用目标，通过端到端学习完成分配，而非依赖手工规则。
- **率失真理论在视觉-语言模型中的应用**：与经典压缩方法不同，RUTA 将“率”直接定义为视觉 token 期望数，并采用可微替代，使率失真思想能适配离散序列生成场景。该视角为后续研究提供了统一框架。
- **查询条件视觉编码**：与 Flamingo 等使用交叉注意力利用文本查询的方式不同，RUTA 在视觉编码阶段就引入查询信息，通过候选构建机制实现“查询即预算”的分配，更具可解释性与灵活性。

## 8. 结论与局限

- **结论**：RUTA 是首个将视觉 token 缩减形式化为率-效用优化的原则性框架。它联合学习保留哪些 token 以及每个输入分配多少 token，在不显著损失性能的前提下大幅降低 LLM 侧计算开销，并在多种 VLM 骨干上验证了有效性。
- **局限与未来工作**：  
  - 定位器（Grounding DINO）本身有一定的额外推理成本，未来可探索使用更轻量的可学习查询编码器替代。  
  - 当前方法只作用于 LLM 前缩减阶段，尚未与 KV-cache 压缩或层间稀疏化结合，存在进一步联合优化的空间。  
  - 率估计在训练时使用的 Bernoulli 抽样与推理时的 top-\(K\) 选择存在分布偏差，未来可引入更对齐的离散采样技术。  
  - 实验仅覆盖 VQA 类任务，对生成式任务（如图文创作、多模态对话）的适用性有待验证。

## 9. 总体评价

- **贡献**：RUTA 将“分配多少 token”这一长期依赖人工设定的问题转化为可学习的目标，理论清晰、工程实现完整，实验分析细致，在压缩率与准确率的平衡上取得了显著提升。  
- **潜在风险**：开放词汇定位器的质量依赖于外部标注数据，可能在极端域（如医学影像）上退化；率惩罚线性形式可能不足以刻画复杂任务的不均匀效用曲线。  
- **适用性**：对于长视觉上下文、实时交互等对 token 成本敏感的场景，RUTA 提供了既稳健又可调的解决方案，并为后续探索“自适应模态预算”提供了良好起点。
