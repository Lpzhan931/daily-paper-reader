## 摘要
循环 Transformer 在多个循环深度上复用共享块，使得自回归解码开销高昂，因为每生成一个 token 都需要许多顺序的循环前向传递。自推测解码器通过在早期深度起草并在全深度验证来降低这一开销，但通常将起草计算绑定到来自同一循环深度的前缀表示。我们发现，查询和键比值更早接近其最终深度表示，而受控的前缀通道干预表明，成熟的值可显著改善浅层起草预测。受这种不对称性启发，我们提出深度异步自推测（DAS），它将起草计算的深度与其读取的已验证前缀表示的深度解耦。其 Mature-V 原语使浅层查询无需额外循环计算即可检索全深度前缀值。我们进一步开发了 DAS-Wave，它将深度异步前缀读取与携带式并行精化、渐进式块增长以及独立的全深度验证器相结合。在四个循环模型检查点以及数学与代码工作负载上，DAS-Wave 在同一推理栈中相对于配对的全深度自回归解码实现了 4.00--6.96 倍的平均吞吐加速。这些结果将前缀信息深度确定为循环自推测的一个有效设计轴。

## Abstract
Looped Transformers reuse a shared block across recurrent depths, making autoregressive decoding expensive because every generated token requires many sequential recurrent passes. Self-speculative decoders reduce this cost by drafting at an early depth and verifying at full depth, but typically bind draft computation to prefix representations from the same recurrent depth. We find that queries and keys approach their final-depth representations earlier than values, and controlled prefix-channel interventions show that mature values substantially improve shallow draft predictions. Motivated by this asymmetry, we introduce Depth-Asynchronous Self-Speculation (DAS), which decouples the depth of draft computation from the depth of verified-prefix representations it reads. Its Mature-V primitive lets shallow queries retrieve full-depth prefix values without additional recurrent computation. We further develop DAS-Wave, which combines depth-asynchronous prefix reads with carried parallel refinement, progressive block growth, and an independent full-depth verifier. Across four recurrent-model checkpoints and mathematics and code workloads, DAS-Wave achieves 4.00--6.96$\times$ mean throughput speedup over paired full-depth autoregressive decoding in the same inference stack. These results identify prefix-information depth as an effective design axis for recurrent self-speculation.

# 论文总结：《浅层查询，成熟值：用于循环 Transformer 的深度异步自推测》

## 1. 核心问题与整体含义

- **背景**：循环 Transformer（Looped Transformers）通过在多个循环深度上反复应用同一共享块来扩展推理时计算量，但自回归解码时每生成一个 token 都需顺序执行大量递归前向传递，成为主要延迟来源。
- **现有方案**：自推测解码（self-speculative decoding）用早期深度的廉价草稿提议未来 token，再用全深度目标一次性验证，从而摊销成本。
- **核心问题**：现有自推测方法通常将草稿计算绑定到**同一循环深度**的前缀表示（depth-aligned），即"浅层草稿只能读取浅层前缀"。论文质疑这种耦合的必要性。
- **关键发现**：注意力表示并非均匀成熟——查询（Q）和键（K）更早接近最终深度表示，而**值（V）成熟较晚**。受控干预表明，仅将浅层草稿可读的前缀 V 替换为全深度 V，就能大幅提升草稿与目标的 token 一致性（如 Huginn 上从 47.22% 升至 66.93%）。
- **整体含义**：提出将**前缀信息深度**作为循环自推测的一个独立设计轴——草稿计算深度与其所读前缀表示深度可以解耦，从而在几乎不增加草稿递归计算的前提下提升草稿质量。

## 2. 方法论

### 核心思想
- **深度异步自推测（DAS）**：解耦草稿计算的递归深度与所读取的已验证前缀表示的深度。
- **Mature-V 原语**：让浅层草稿查询检索已由全深度目标物化的成熟前缀 V，无需额外递归传递，且训练免费（training-free）、不改变验证流程。

### 关键技术细节
- **注意力形式化**：设 C 为已物化的验证前缀，U 为草稿侧活跃位置；用 κ 表示前缀 K 的读取深度，ν 表示前缀 V 的读取深度：
  - 注意力权重：`[Π_C, Π_U] = softmax(Q_cur,ℓ [K^κ,ℓ_C ; K^cur,ℓ_U]^T / √d_h + M)`（式 2）
  - 注意力输出：`O_ℓ = Π_C V^ν,ℓ_C + Π_U V^cur,ℓ_U`（式 3）
  - 只有验证前缀的读取深度可被改变，草稿侧 K/V 始终来自当前草稿计算。
- **2×2 读取策略设计空间**（式 4）：
  - Aligned：`(κ,ν)=(r,r)`（深度对齐）
  - Mature-V / Deep V：`(κ,ν)=(r,R)`（K 对齐、V 取全深度）
  - Deep K：`(κ,ν)=(R,r)`
  - Deep K/V：`(κ,ν)=(R,R)`
  - 由于跨深度读取仅限已验证前缀 token，其全深度表示已被目标验证物化，不产生额外递归开销。

### DAS-Wave（端到端解码器）
- **携带式并行精化**：每轮活跃宽度按 `W_j = min(γ, W_init + j)` 增长（式 5，每轮 +1 位置），活跃位置并行执行 k 次递归更新并做移位读出（式 6），latent 状态跨轮携带而非重启。
- **关键区分**：token 猜测（guess）与 latent 状态分离；携带的是计算历史而非某个固定深度的目标状态。
- **渐进块增长**：J 轮后输出 w 个草稿提议。
- **独立全深度验证**：目标对 `[x_t, y_1, ..., y_{w-1}]` 执行全部 R 步，产生 `p_i = p_R(·|x_≤t, y_<i)`；贪婪解码下按序接受直到首个不匹配，输出目标预测并丢弃后缀。验证器不使用任何携带草稿状态。
- **目标保持性**（Prop. 1）：因只改提议构造与前缀读取、不改目标计算与验证规则，精确算术下贪婪目标序列得以保持（沿用标准推测解码论证）。

## 6. 主要结论与发现

- **加速效果**：DAS-Wave 在四个循环模型、四个任务上相对配对全深度 AR 实现 **4.00–6.96× 平均吞吐加速**，在全部 16 个设置中均为最大加速，且接受长度最长（GSM8K 上每次验证接受 15.6–18.1 个草稿 token，远超顺序自推测的 5.2–12.2）。
- **机制结论**：
  - 顺序草稿中，成熟前缀读取（Deep K/V）已能提升接受长度与速度。
  - **成熟读取与 latent 携带强互补**：单独任一干预仅小幅改善，二者结合则增益巨大（如 Huginn/GSM8K：对齐/无携带 0.65×，Deep K/V 无携带 0.93×，携带+对齐 0.71×，二者结合达 4.11×）。
  - 携带改变了提议轨迹，使**联合 Deep K/V 显著优于单独 Deep V**（Huginn/GSM8K：0.71×、1.07×、4.11×）。
  - 三阶交互 E_cKV 在所有模型–任务上为正，说明 carry 强化了 K/V 的互补性。
- **成本–接受权衡**：增加每轮更新 k 提升接受长度但降低速度（Huginn k 从 2→8：A 16.49→19.56，加速 4.33×→2.37×）；增大验证容量 γ 在调度能激活并精化相应位置时才有效。
- **总体结论**：前缀信息深度是循环自推测的有效独立设计轴；提议成本与前缀信息质量可独立优化。

## 7. 优点

- **洞察新颖且机制清晰**：从 Q/K/V 成熟速度不对称出发，用受控通道替换实验将"成熟 V"这一最小干预孤立验证，动机到方法逻辑连贯。
- **训练免费、不改验证规则**：Mature-V 可直接叠加到常规顺序自推测；DAS-Wave 保持目标模型与标准验证规则不变，并提供贪婪目标保持性论证。
- **方法组合系统**：将深度异步前缀读取与携带式并行精化、渐进块增长、独立全深度验证器结合，兼顾草稿质量与提议效率。
- **实验全面且规范**：4 架构 × 4 任务，含多种外部基线、完整 carry/K/V 因子分析、预算扫描、置信区间与配对计时，报告细致。
- **实用价值**：在相同推理栈下获得数倍吞吐提升，对循环深度模型的部署有直接意义。

## 8. 不足与局限

- **适用范围受限**：方法依赖循环/递归深度模型存在中间预测与深度索引 K/V 缓存；对非循环 Transformer 或缺乏此类结构的模型不直接适用。
- **实验硬件单一**：仅在单张 NVIDIA L20X、batch size 1、bf16 下测量，未评估更大 batch、多 GPU 或分布式场景，吞吐结论的泛化性存疑。
- **仅贪婪解码**：主结果全部为贪婪解码，未验证采样解码、beam search 或 temperature 场景下的表现与目标保持性。
- **诊断实验规模较小**：机制探针仅用 8–12 个 prompt、数百个预测位置，统计代表性有限；部分对照为不等计算量比较。
- **配置需调参**：k、γ、J、W_init 等调度参数需按模型选择（Huginn k=2、Raven k=1），未给出自动选择策略；部分扫描显示性能对参数较敏感。
- **有限精度风险**：目标保持性仅在精确算术下成立，论文承认有限精度可能引入数值差异。
- **缺少与训练类加速方法的比较**：未涉及量化、蒸馏等正交加速手段的叠加效果。
- **外部基线强度不一**：部分基线（如 Lookahead、PLD）在部分设置下接受长度接近 0，其调优程度可能影响对比的公平观感。
