## 摘要
推测解码是一种成功的技术，它通过一个快速的草稿模型来加速目标自回归语言模型的推理。有损推测解码允许相对于目标模型发生漂移，以进一步提高速度。有趣的是，实验观察到所得模型在质量上也能胜过目标模型。我们的论文通过一种称为指导解码的有损推测解码形式化方法，正式证明了这种壮举何以可能。为此，我们将推理与著名的机器学习训练理论 Boosting 联系起来，并通过将指导解码推广到整个 f-散度集合来推进。我们揭示了指导解码的关键性质，其中包括：(i) 全变差情形特别吸引人的几何性质；(ii) 对任意 f-散度的简单近似，且与 Boosting 符合性直接相关；(iii) 一个与散度无关的 O(n) 空间、O(sort(n)) 时间的数据结构，它构建在草稿模型和目标输出之上，允许在 O(log n) 时间内查询对偶问题的最优参数，并对任意 f-散度在 O(n) 时间内构造最优指导分布。

## Abstract
Speculative decoding is a successful technique speeding up inference of a target autoregressive language model via a fast drafter model. Lossy speculative decoding allows a drift with respect to the target to further improve speed. Interestingly, it has been observed experimentally that the resulting model can $\textit{also}$ beat the target $\textit{quality-wise}$. Our paper formally proves how such a feat is possible with a formal approach to lossy speculative decoding called $\textit{mentored decoding}$. To get there, we connect inference to a celebrated ML training theory, $\textit{boosting}$, and proceed via the generalization of mentored decoding to the whole set of $f$-divergences. We uncover key properties of mentored decoding, among which (i) the particularly appealing geometric nature of the total variation case, (ii) simple approximations for any $f$-divergence in direct relation with boosting compliance, and (iii) a $\textit{divergence independent}$ $O(n)$ space and $O(\mathrm{sort}(n))$ time data structure built on drafter and target outputs, which allows to query the optimal parameters of the dual problem in $O(\log n)$ time and constructing optimal mentored distributions in $O(n)$ time for any $f$-divergence.

# 论文总结：Mentored Decoding: Faster Inference meets Boosting

## 1. 核心问题与整体含义

- **背景**：大语言模型（LLM）自回归推理常受内存带宽限制。投机解码（Speculative Decoding, SD）通过快速草稿模型提出候选 token，再由目标模型并行验证来加速推理。
- **瓶颈**：SD 严格要求输出分布与目标模型一致，因此接受率被草稿与目标之间的散度紧约束；Sun et al. (2023) 证明在精确匹配目标分布下 SD 达到最优接受率，无法突破这一上限。
- **有损投机解码**：允许输出相对目标发生一定漂移，以进一步提升速度。Tran-Thien (2023) 首次将"指导解码"（Mentored Decoding, MD）形式化为约束优化问题——在目标与输出的散度有界下最大化草稿接受率，此时目标模型成为"导师"，最终输出是两模型的集成分布。
- **关键观察与缺口**：多项实验（Li et al. 2026a; Qin et al. 2025; Zhong et al. 2025）发现，MD 的复合输出有时在**质量上也能胜过目标模型**。然而，同时兼顾"推理加速"与"质量提升"的形式化分析此前完全缺失。
- **整体含义**：本文首次从理论上证明"加速推理同时提升模型质量"这一现象是可能的，方法是将推理与机器学习经典训练理论 **Boosting** 建立联系，并把 MD 推广到全部 f-散度族。

## 2. 方法论

### 2.1 问题形式化与两种参数化

- **f-MD-2（直接参数化）**：在 `r ∈ [0,1]^n`（接受概率向量）与 `s ∈ Δ_n`（重采样分布）上，最小化 `-pᵀr`，约束为 `D_f(p∘r + (1-pᵀr)·s ‖ q) ≤ D`；`D=0` 时退化为 SD。
- **f-MD-1（单参数化）**：直接以指导分布 `π` 为变量，最小化 `D_TV(π‖p)`，约束为 `D_f(π‖q) ≤ D`。
- **Lemma 3.2**：两种参数化之间存在双射，且目标函数满足 `pᵀr = 1 - D_TV(π‖p)`，可自由切换。
- **假设 3.3**：`0 < D < D_TV(p‖q)`、`p ≠ q`、`p, q > 0`（对 softmax 输出合理）。

### 2.2 全变差（TV）情形：优雅几何刻画

- **Theorem 3.4**：TV-MD 的最优解集为
  `md¹_{fTV}(p,q;D) = Δ_n ∩ {D_TV(·‖q)=D} ∩ [min{p,q}, max{p,q}]`
  即"超矩形 ∩ 单纯形 ∩ 激活散度约束"，是两个 L1 球的交集（见图 1）。
- 该最优集**足够大**，可容纳所有严格凸散度的最优解，且解常呈现简单的凸组合形式（与 DIVERSED、Zhong et al. 等使用的形式一致）。

### 2.3 一般 f-散度的解

- **Theorem 3.7**：在 KKT 条件下，`md²_f` 与"等散度集" `is_f(p,q;D)` 之间存在双射，最优解落在 `clampset(p, L_β(-f')·q, L_α(-f')·q)` 中。
- **Corollary 3.10**：若 f 严格凸，最优指导分布**唯一**且形式极简：
  `π* = max{(1-b)·q, min{p, (1+a)·q}}`（`0 ≤ α < 1 < β`），即在单纯形中连接目标 q 到草稿 p 的**一维轨迹**，且该轨迹**与 f 无关**。
- **Theorem 3.12**：通过集合 `C(p,q)` 中的参数对 `(a,b)` 给出近似解，并给出接受概率提升的显式表达：
  `P_acc(MD) = P_acc(SD) + a·q(A) + (p(I_{>1}) - q(I_{>1}))`，对应散度阈值 `D = q(A)f(1+a) + q(B)f(1-b) + q(I)f(u)`。
- **Theorem 3.13**：所有满足轻量条件的 f-MD 最优解同时是 TV-MD 的最优解；且**所有严格凸 f 的最优分布集合相同**。

### 2.4 与 Boosting 的连接

- **自归一化多分类 Boosting**：对 Nock & Nielsen (2007) 做多分类推广，权重更新 `w^{(t+1)}_i ∝ w^t_i · (1-μ_t yᵢᵀh_t(xᵢ)/2h_{t,∞}) / (1-μ_t²)`，**无需归一化系数**，比 AdaBoost 更简单高效。
- **Theorem 4.2（主定理）**：提升后的输出 `π̃_T ∝ ∏_t p_t^{c_t/Σc}` 满足几何平均意义下的指数收敛：
  `P(⟨π̃_T,j, j∈Y_i⟩_G ≤ ρ⟨π̃_T,j, j∈Y_i⟩_G) ≤ exp(-1/6 Σ_t μ_t²)`，其中 `ρ ≤ exp(2Q/3)`，`Q = E[μ] + V[μ]/E[μ]`。
- **两条连接路径**：
  1. **通用路径**：MD 的复合输出"隐藏"了具备 boosting 性质的模型组合，可评估草稿与目标如何从质量角度互补，从而指导模型选择。
  2. **TV 专属路径**：利用 TV 最优解集之大，直接在其中"雕出"对应 boosted 集成的分布。
- **Theorem 4.7**：`α = c₂/(c₂+c_target)` 同时保证 `v_α` 是 TV-MD 最优解，且 boosting 优势 `A ≥ (1+ϱ²ε²)μ²_target`，并有 `D_fTV(v_α‖q) ≤ ϱ·ε`。
- **Theorem 4.8**：一般 f-MD 的近似解天然具有 boosting 性质，几何平均比值受系数 `k_i = √((1+a_i)/(1-b_i))` 控制。

### 2.5 高效算法

- **数据结构 `c(p,q)`（断点集）**：大小 ≤ n，**与散度无关**，构建时间 `O(sort(n))`，空间 `O(n)`。
- **查询（Algorithm 3）**：对任意 `ã` 在 `O(log n)` 时间内返回对应 `b̃`，得到 `C(p,q)` 中的点；构造最优指导分布 `O(n)`。
- **Theorem 5.4**：`D_f(P)` 在 `P_acc(SD)` 处的右导数为 `max ∂f(1) - min ∂f(1)`；若 f 在 z=1 可微，则该导数为 **0**——意味着总能在**散度代价可忽略**的前提下提升接受概率。
- **Top-k 适配（Lemma 6.1）**：目标被掩码到 k 个 token 时，最优解支撑集可限制在这 k 个坐标内，排序复杂度降至 `O(k log k)`，几乎零额外开销。

## 6. 主要结论与发现

- **首次形式化证明**：通过 MD 设定，确实可以"既加速推理、又提升模型质量"。
- **TV 情形的几何之美**：最优解集是超矩形与单纯形的交集，且足够大以容纳所有严格凸散度的最优解。
- **最优解的极简形式**：任意严格凸 f 下，最优指导分布唯一，呈坐标级 clamp 形式 `π* = max{αq, min{p, βq}}`，且轨迹与 f 无关。
- **散度无关的高效算法**：存在大小 ≤ n 的断点数据结构，与 f 无关，可在 `O(log n)` 查询对偶最优参数、`O(n)` 构造最优分布。
- **低代价提升接受率**：对 z=1 处可微的散度，`D_f(P)` 在 `P_acc(SD)` 处右导数为 0，可显著提升接受概率而几乎不增加散度代价（模拟中 >10%）。
- **Boosting 视角**：MD 复合输出隐含具备 boosting 性质，可量化草稿与目标的互补性，用于从模型池中选择草稿/目标；在 WCA 假设下 boosting 优势可随模型数指数增长。

## 8. 不足与局限

- **实验严重不足**：仅有玩具模拟，无真实 LLM 端到端实验，缺少与实际加速比、生成质量指标（如困惑度、下游任务准确率）的对照，**"质量反超目标"缺乏实证幅度支撑**。

- **应用限制**：理论保证依赖 boosting 的边缘（edge）为正等条件，在草稿与目标高度相似（ε→0）时，boosting 保证退化为仅与目标相当。
