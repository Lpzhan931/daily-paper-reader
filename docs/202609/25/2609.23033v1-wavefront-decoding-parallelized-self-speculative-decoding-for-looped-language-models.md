## 摘要
循环语言模型通过重复应用权重共享块来增加有效深度而不增加参数量，但由此导致每生成一个 token 需要 T 次串行循环块调用，显著增加了解码延迟。为解决该问题，我们提出 Wavefront 解码（WFD），一种面向循环语言模型的免训练自推测解码框架。WFD 利用此类架构的两个特性：中间循环输出可提供有效的草稿预测；权重共享允许不同位置和循环深度的 token 状态在一次批量循环块调用中处理。WFD 将这些混合深度状态组织成对角波前，在浅层深度持续草拟新位置，同时将较早位置推进至全深度验证。与分阶段的“先草拟后验证”调度不同，WFD 因此将草拟与验证共同批处理于同一循环调用中，而被拒绝的草稿则利用全深度预测进行修正。在六个 Spec-Bench 任务类别上，WFD 在 Ouro-2.6B 上相比自回归解码实现 2.42 倍加速，在 Huginn-3.5B 上实现 3.54 倍加速，且持续优于“先草拟后验证”。跨循环 KV 共享进一步减少波前 KV 传输量，并将 WFD 在 Huginn-3.5B 上的加速提升至 4.81 倍。

## Abstract
Looped language models repeatedly apply a weight-shared block to increase effective depth without increasing parameter count, but the resulting T sequential recurrent-block calls per generated token substantially increase decoding latency. To address the issue, we introduce Wavefront Decoding (WFD), a training-free self-speculative decoding framework designed for looped language models. WFD exploits two properties of these architectures: intermediate recurrence outputs provide effective draft predictions, and weight sharing allows token states at different positions and recurrence depths to be processed in one batched recurrent-block call. WFD organizes these mixed-depth states into a diagonal wavefront, continuously drafting new positions at shallow depth while advancing earlier positions toward full-depth verification. Unlike the phase-separated draft-then-verify schedule, WFD therefore co-batches drafting and verification within the same recurrent calls, while rejected drafts are corrected using full-depth predictions. Across six Spec-Bench task categories, WFD achieves 2.42x speedup on Ouro-2.6B and 3.54x on Huginn-3.5B over autoregressive decoding, consistently outperforming draft-then-verify. Cross-recurrence KV sharing further reduces wavefront KV traffic and increases WFD's speedup to 4.81x on Huginn-3.5B.

# WaveFront Decoding 论文深度总结

## 1. 核心问题与研究动机

- **背景**：循环语言模型（Looped LM，又称 recurrent-depth / universal transformer）通过重复调用权重共享的层块来增加有效深度，在参数量不变的前提下获得接近大模型的表达能力。代表性架构分为两类：
  - **全栈型（full-stack）**：如 Ouro，重复整个 Transformer 堆叠；
  - **Prelude–Recurrent–Coda（P/R/C）型**：如 Huginn，仅重复中间的递归块 R。
- **核心痛点**：参数效率并未转化为低解码延迟。每生成一个 token 需要 **T 次串行递归块调用**；在小 batch 下自回归解码受内存带宽限制，每一步都重复流式加载相同权重，延迟随 T 近似线性增长，抵消了小参数量的优势。
- **机遇**：循环结构天然提供了自推测解码（self-speculative decoding）的素材——
  - 中间递归输出常与最终 next-token 预测一致，可作为**草稿**；
  - 权重共享使得不同位置、不同递归深度的状态可在**一次批量调用**中处理。
- **现有方案不足**：作者将先前工作提出的“浅层草稿 + 全深度验证”具体化为两阶段基线 **Draft-then-Verify（DtV）**。DtV 虽然无需外部草稿模型，但草稿阶段与验证阶段严格分离，草稿阶段仍按自回归串行生成，未能利用跨深度批处理的并行机会。

## 2. 方法论：Wavefront Decoding（WFD）

### 2.1 核心思想

- 将草稿与验证**融合为一条连续流水线**，消除阶段边界。
- 在每一步，一个**对角波前（diagonal wavefront）**在递归深度中推进：新位置在浅层被草拟，同时较早的位置被加深并验证。
- 被拒绝的草稿用**全深度预测**修正，因此 WFD 在构造上保持自回归输出（贪心解码下与 AR 一致）。

### 2.2 关键技术细节

- **统一抽象 (P, R, C)**：P 为 prelude（输入嵌入映射），R 为递归块，C 为 coda（输出 logits）。状态演化：s⁰ᵢ = P(xᵢ)，sᵗᵢ = R(sᵗ⁻¹ᵢ, eᵢ)，ℓᵗᵢ = C(sᵗᵢ)。
- **调度器（Algorithm 1）**：维护三个待处理集合 A_P、A_R、A_C 与已提交序列 G。每次迭代：
  1. 若有新位置，P 块运行；
  2. R 块将波前中的 token 推进**一步**（一次批量调用）；
  3. 到达草稿点（t = T_d）或提交点（t = T）的 token 进入 C 块；
  4. C 块产生 token：草稿点 token 送入 P 加入波前；提交点 token 与已有波前同位置 token 验证——接受则提交，拒绝则提交修正 token、**冲刷**其后的在途位置并从修正 token 重新生长波前。
- **稳态波前宽度**：W = ⌈T / T_d⌉。

### 2.3 成本模型与加速分析

- **关键假设**：解码阶段 R 受内存带宽限制，一次批量调用多位置与单位置调用延迟几乎相同（附录 B.1 用算术强度分析证明，两个模型在 A6000/B200 上均远离 compute-bound 区域）。
- **延迟公式**（α = 1 全接受时）：
  - AR：L_AR = L_P + T·L_R + L_C
  - DtV：L_DtV = L_P + L_R·[T_d/γ + (T−T_d)/(γ+1)] + L_C → (γ→∞) L_P + T_d·L_R + L_C
  - WFD：L_WFD = L_P + T_d·L_R + L_C
- **结论**：WFD 用**有限的波前宽度 W** 即达到 DtV 在 γ→∞ 时的渐进每 token 延迟。L_P + L_C 每 token 只付一次，限制了加速上限 < T / T_d。
- **拒绝代价**：
  - DtV 拒绝会丢弃草稿块的后缀，浪费量随 γ 增长，需在验证摊销与拒绝代价间权衡最优 γ；
  - WFD 拒绝最多冲刷 **W − 1 个在途位置**，且 W ≤ T 为架构常数，与草稿激进度无关，因此对接受率更鲁棒。

### 2.4 跨递归 KV 共享

- **问题**：WFD 中不同深度的位置访问**不同的递归专属 KV 缓存**，KV 流量随波前宽度 W 增长；长上下文下逐渐侵蚀加速收益（DtV 验证时所有位置处于同一递归步，访问同一缓存，故不受影响）。
- **方案**：跨递归 KV 共享让混合深度位置访问**公共缓存**，与权重共享互补（权重共享摊销权重读取，KV 共享降低递归维度 KV 流量）。
- **注意**：这是**近似扩展**——共享 KV 状态可能被更新，波前位置观察到的更新阶段可能与串行 AR 不同，需单独验证精度。

## 6. 主要结论与发现

- **吞吐提升**：Spec-Bench 六类任务上，WFD 在 Ouro-2.6B 上达 **2.42×**、Huginn-3.5B 上达 **3.54×** 加速，全面优于 DtV（相对 DtV 再提升约 **1.27×**）。
- **低接受率下优势更明显**：如 Ouro 翻译任务 α = 0.78 时 DtV 仅 1.06×，WFD 在 α = 0.80 时仍有 1.92×——源于 WFD 拒绝代价有界（≤ W−1 个在途位置），而 DtV 会丢弃整个草稿后缀。
- **KV 共享协同增益**：Huginn 上将 32 个递归专属 KV 槽减至 4 或 1 个共享槽，AR 精度基本不变，WFD 精度在匹配配置下差距 ≤ 0.70 个百分点；接受率从 0.88 提升至最高 0.98，加速提升至 **4.81×**（GSM8K）/ **4.46×**（MATH-500）。
- **长上下文瓶颈被 KV 共享缓解**：无共享时 WFD 加速随上下文长度下降（Huginn 因 W = 8 比 Ouro 更明显）；共享后 WFD 在 64k 上下文下仍维持约 3.2×（Ouro）/ 4.4×（Huginn）。
- **精度保持**：GSM8K / MATH-500 上与 AR 相当；fp32 下使用递归专属 KV 槽时 WFD 与 AR 生成**完全相同的 token 序列**。
- **调度分析**：WFD 在 α ∈ [0.6, 0.95] 全程优于所有测试的 DtV 配置，且无需引入草稿块长度 γ 这一超参数。

## 7. 优点

- **免训练、零改动**：不需要辅助草稿模型、不需要重新训练、不修改模型权重，直接应用于已有预训练循环 LM。
- **架构通用**：通过 (P, R, C) 统一抽象，同时适用于全栈型（Ouro）和 P/R/C 型（Huginn）。
- **调度创新性强**：首次将草稿与验证跨位置、跨递归深度**协同批处理**，用对角波前把两阶段流水线变为连续流水线。
- **理论分析扎实**：给出闭式延迟成本模型，证明 WFD 以有限波前宽度即达到 DtV 的 γ→∞ 渐进极限；并给出拒绝代价的有界性论证。
- **鲁棒性好**：拒绝恢复代价与草稿激进度解耦，在低接受率、不同 batch、不同上下文下均优于 DtV。
- **与 KV 共享正交互补**：明确指出 WFD 的主要长上下文瓶颈（递归维度 KV 流量），并用跨递归 KV 共享直接解决，形成完整的性能画像。

## 8. 局限与不足

- **加速上限受架构常数约束**：每 token 仍需支付一次 L_P + L_C，理论上限为 T / T_d；对 Ouro（T = 4, T_d = 1）天花板仅约 4×，对递归深度更大的模型才更有利。T_d 的选取需在草稿质量与波前宽度之间权衡，且论文中为每个模型手工固定（Huginn 用 T_d = 4、W = 8），缺少自动调优机制。
- **依赖内存带宽受限假设**：核心成本模型建立在“单次批量 R 调用与单位置调用延迟近似相同”之上。当 batch size 增大、算术强度上升后，该假设失效，WFD 相对 AR 的优势会收缩；论文虽用 batch 扫描（图 5）部分覆盖，但未在真正 compute-bound 区间给出定量边界。
- **KV 共享是近似扩展，非无损**：共享后波前位置观察到的 KV 更新阶段与串行 AR 不同，理论上不再保证与 AR 输出一致；实测虽仅有 ≤ 0.70 个百分点的精度差，但这一差距在长上下文、复杂推理任务上是否会被放大，缺少更大规模验证。
- **评估面较窄**：仅 2 个公开 checkpoint（Ouro-2.6B、Huginn-3.5B）、单块 A6000、仅贪心解码。未评估采样解码（温度 / top-p）下草稿接受率下降的影响，也未与外部草稿模型的投机解码（EAGLE、Medusa、Lookahead）做横向对比——虽然 WFD 定位是“免外部模型”，但缺少这条基线使得“相对通用投机解码的竞争力”不明确。
- **内存开销未充分讨论**：波前宽度 W 意味着同时保留 W 个位置的递归中间状态，KV 共享降低的是流量而非容量；长上下文 + 大 W 时的显存占用与 OOM 边界未报告。
- **B200 roofline 仅为推算**：附录中的新硬件分析未做实测，跨硬件可移植性结论属于外推。
- **实现复杂度**：调度器需要维护 A_P / A_R / A_C 三个集合、冲刷与重生长逻辑，并与 CUDA graph 兼容（表 7 仅为 spot check）；论文未给出完整开源实现细节，复现门槛高于“直接调用”的直觉描述。

## 9. 可复现性与方法学评价

- **可复现性较好**：方法免训练、不改权重，仅依赖公开 checkpoint；关键超参数（T、T_d、W、γ、batch、生成长度、prompt 上限）均在正文或附录中明确；精度协议（GSM8K 8-shot CoT、MATH-500）与速度协议（含 prefill 的墙钟时间、Spec-Bench 风格六任务）描述清晰。
- **对比公平性**：DtV 的 γ 在实测接受率附近调至最优，避免了“弱基线”质疑；受控 α 实验把调度开销与草稿质量解耦，使“WFD 在低接受率下更鲁棒”的结论有因果支撑而非仅相关性。
- **正确性论证充分**：在递归专属 KV 槽 + fp32 下验证 WFD 与 AR 生成完全相同的 token 序列，这是自推测解码类方法最有说服力的正确性证据；也说明 bf16 下的微小差异源于数值非确定性而非算法缺陷。
- **统计口径**：加速比以总生成 token 数除以墙钟时间计算，聚合方式（按任务平均还是按 token 加权）已说明，减少了“挑最好任务”的空间。

## 10. 启示与展望

- **核心洞见具有迁移性**：循环 / 迭代式架构的“参数效率 ≠ 延迟效率”是普遍问题（扩散 LM、迭代精炼模型、自适应深度 Transformer 同样存在）。WFD 展示了一条通用路径——**把迭代结构本身当作推测素材，并用对角调度把串行深度转成批量并行度**。
- **权重共享与 KV 共享是互补的两个维度**：前者摊销权重读取，后者降低激活/KV 流量；论文将二者并列分析，为后续“循环 LM 推理栈”的系统优化提供了清晰框架。
- **潜在组合方向**：与量化、KV 压缩、chunked prefill、连续批处理（continuous batching）叠加时的交互效应尚待研究；多请求场景下波前宽度 W 与用户 batch 的联合调度，可能是下一个有实际价值的优化点。
- **待回答问题**：T_d 能否随接受率在线自适应（而非手工固定）？KV 共享的近似误差能否被形式化界定？在采样解码与更长上下文（>64k）下，WFD 的鲁棒性边界在哪里？

## 11. 一句话总评

WaveFront Decoding 把循环语言模型的“自推测”潜力从两阶段流水线升级为连续对角波前，在免训练、不改权重的约束下，以闭式延迟模型论证了有限波前宽度即可逼近 DtV 的渐进极限，并在低接受率、长上下文、不同 batch 等困难区间保持鲁棒；其主要代价是加速上限受 T / T_d 与 prelude/coda 固定开销限制，且依赖内存带宽受限前提，KV 共享带来的精度影响仍需更大规模验证。
