## 摘要
推测解码通过使用草稿模型生成候选令牌，并由目标模型在单次前向传递中验证，从而加速大型语言模型的推理。验证过程是顺序进行的，并从第一次拒绝的位置起丢弃所有后续位置，然而现有的草稿训练依赖于对目标的令牌级模仿，并采用固定的逐位置权重，既不反映上述任一特性。我们提出验证感知训练（VAT），一个即插即用的框架，在每一步训练中模拟验证，并将由此产生的接受与拒绝模式转化为监督信号。VAT包含两个组成部分：（i）验证头，一个轻量级的联合训练二元分类器，用于监督草稿模型在每个位置是否能在顺序验证中存活；（ii）验证自适应加权，它通过保留每个样本直至其首次拒绝点的完整权重，并将衰减重新锚定到该点开始，从而取代固定加权方案。VAT仅修改训练目标，因此可以叠加在现有方法之上，无需改变草稿架构、目标模型或推理过程。将VAT应用于EAGLE-3和DFlash，并基于Qwen3-4B、Qwen3-8B和LLaMA-3.1-8B，VAT平均接受长度提升高达11.4%，加速比（墙钟时间）提升高达8.7%，在数学、代码和聊天基准测试中均取得一致增益。代码将发布于https://github.com/naver-ai/vat

## Abstract
Speculative decoding accelerates large language model inference by using a draft model to generate candidate tokens, which are verified by the target model in a single forward pass. Verification proceeds sequentially and discards every position from the first rejection onward, yet existing draft training relies on token-level imitation of the target with a fixed per-position weighting that reflects neither property. We introduce Verification-Aware Training (VAT), a plug-in framework that simulates verification at every training step and turns the resulting accept and reject patterns into supervision. VAT consists of two components: (i) a verification head, a lightweight jointly trained binary classifier that supervises the draft model on whether each position survives sequential verification; (ii) verification-adaptive weighting, which replaces the fixed weighting schedule by keeping full weight up to each sample's first rejection point and re-anchoring the decay to start there. VAT modifies only the training objective, so it can be layered on top of existing methods without changing the draft architecture, the target model, or the inference procedure. Applied to EAGLE-3 and DFlash on Qwen3-4B, Qwen3-8B, and LLaMA-3.1-8B, VAT improves average acceptance length by up to 11.4% and wall-clock speedup by up to 8.7%, with consistent gains across math, code, and chat benchmarks. Code will be available at https://github.com/naver-ai/vat

# 论文深度总结：验证感知的推测解码训练 (Verification-Aware Training for Speculative Decoding)

## 1. 核心问题与整体含义（研究动机与背景）

推测解码是大语言模型推理加速的一项关键技术，其流程为：轻量级草稿模型先低开销生成多个候选令牌，再由目标模型单次前向批量验证。若拒绝发生，则该位置之后的所有候选令牌**一律被丢弃**，因此加速效果直接取决于“平均接受长度”（有多少连续令牌通过验证）。现有草稿模型训练普遍遵循“逐位置模拟目标输出 + 固定/预定义逐位置权重（如 EAGLE-3 用 0.8^(k-1)、DFlash 用 exp(-(k-1)/γ)）”的统一范式，存在**两个关键错位**：
- 验证是**顺序且截断式**的，但训练只提供了局部的逐令牌模仿信号，模型无法感知其生成是否真正能“存活”过验证；
- 权重表为**样本无关、事先固定**，无法针对每条样本实际**首次拒绝位置**的差异进行自适应调整，也未反映“位置 k 的贡献依赖于前面所有位置都被接受”的累积属性。

## 2. 方法论：核心技术思想与实现

论文提出 **VAT（Verification-Aware Training，验证感知训练）**：一个只修改训练目标、即插即用的训练框架，在**每个训练步模拟目标验证**，将接受/拒绝模式转成额外监督信号。

### 2.1 训练时验证模拟与标签构造
- 利用草稿分布 p̂_k 与目标分布 p_k，遵循推测采样接受规则计算逐位置接受指示 m_k；
- 定义**首次拒绝点 k\***= min{k : m_k=0}（全部接受时为 K+1）；
- 得到累积接受标签 \(v_k = \prod_{j≤k} m_j = [k < k^*]\)。该标签反映推理中真正的截断式验证结果。

### 2.2 构建1：验证头（Verification Head）
- 在草稿模型最后一层隐状态上附加一个**轻量级二分类器**（单层 dense）；
- 以累积接受标签 v_k 为监督，在训练中与草稿联合优化（二元交叉熵损失 L_VH）；
- 目的：向草稿模型注入“哪些位置能真正通过顺序验证”的梯度信号，弥补逐位置交叉熵缺乏全局验证信息的不足。
- 仅训练期使用；推理时可弃用，也可作为“提前退出（early-exit）”代理信号以节省开销。

### 2.3 构建2：验证自适应加权（Verification-Adaptive Weighting）
将固定权重改为**以样本实际首次拒绝点为锚**的自适应调度：

\[
\hat{w}_k = 
\begin{cases}
1, & k < k^* \\
w_{k-k^*+1}, & k \ge k^*
\end{cases}
\]

| 区域 | 权重处理 | 设计原理 |
|---|---|---|
| k < k\* （首个拒绝前） | 保持 1.0（全权重） | 该段令牌真实贡献了接受长度 |
| k ≥ k\* （首个拒绝后） | 重用基线衰减曲线但**平移至从 k\* 起衰减** | 该段已被截断，不应再获全额信号 |
| k\* 本身 | 全权重 | 是最接近“可修复失败点”，改进此处可延伸接受前缀 |
- 与原先从 k=1 就机械衰减的固定调度相比，该机制将“贡献衰减”与样本实际“验证崩溃点”对齐；因 k\* 每条样本不同，此调度具有**逐样本自适应性**，非任意样本无关曲线可比。

### 2.4 总训练目标
\[
L = \sum_{k=1}^K \hat{w}_k ( \ell_k^{soft} + \ell_k^{hard}) + \beta L_{VH}
\]
- \(\ell_k^{soft}\)：目标模型输出分布（软标签）交叉熵；\(\ell_k^{hard}\)：目标模型采样令牌（硬标签）交叉熵；
- β 所有实验固定为 1.0；
- VAT 不改草稿架构、目标模型、推理过程，可叠加于 EAGLE-3、DFlash 等现有方法之上。

## 7. 优点

- **即插即用、侵入性极低**：只改训练目标，草稿架构、目标模型、推理流程全不变，能直接叠在自回归和扩散两大主流草稿范式之上；
- **直击本质的“顺序截断”建模**：以累积接受标签 v_k 取代独立位置信号，首次将“顺序验证→首个拒绝即截断”的真实推理语义有效编码进训练；
- **样本自适应的加权设计**：将权重锚从“固定 k=1”移到“每个样本实际首次拒绝点”，形式简洁但有清晰概率/工程动机；
- **辅助头物尽其用**：验证头训练期提供监督，推理期还能做早退，一石二鸟；
- **验证充分细致**：消融多、替代策略对比全面、训练过程可视化、代价量化清晰，论证严密；
- **收益幅度明确且可复现**：在 3 个主流模型上全维度提升，结果可信度高。

## 8. 不足与局限

- **模型规模覆盖不足**：论文自述“评估限制在 8B 参数以下”，尚未披露 VAT 在 Qwen3-14B/32B 或 DeepSeek/LLaMA-70B 等更大模型上的有效性与训练代价，规模化推广证据有限；
- **对 DFlash 存在额外显存/开销负担**：由于 DFlash 原训练不计算目标 LM Head，VAT 需在每步额外增加一次目标 LM Head 前向（峰值显存 +7.7GB，时间 +6.1%）；在更大模型或更小显存卡上代价可能放大；
- **验证模拟依赖目标分布可得性**：训练时需每步获取目标模型的完整输出分布或采样令牌，在 API 白盒受限/超大模型场景中工程成本较高；
- **语料与任务多样性相对局限**：虽涵盖数学/代码/聊天，但均基于单一大规模英文指令混合生成，对多语言、长文档、结构化/检索增强场景的泛化性未验证；
- **早期退出机制有一定代价**：验证头阈值预测平均误差仍存在，早期退出会小幅降低平均接受长度（如 DFlash 数学 7.67→7.35），实际收益取决于计算节省与令牌损失的折中；
- **与最新并发工作的区分度分析有限**：对 PARD-2、D-PACE 等并发方法仅在讨论中做机制性对比，缺少同设置下的直接数值对标，无法严格说明“自适应锚定”相对“置信度代理类加权”的绝对优势幅度。
