## 摘要
尽管多模态大语言模型（MLLMs）具有强大的多模态理解能力，但在处理长视觉标记序列时会产生大量计算开销。为降低推理成本，近年研究探索了通过视觉中心或文本引导策略进行视觉标记剪枝。然而，这些方法往往忽略高范数离群标记（即特征范数异常大的标记），导致次优的剪枝决策。本工作表明，此类高范数离群标记在特征和空间维度上均高度冗余，但现有方法却常误将其保留为信息线索。基于这一观察，我们提出SinkPruner——一种用于高效MLLM推理的免训练视觉标记剪枝框架。SinkPruner采用由粗到细的设计，包含两个关键模块：视觉净化器（visual sanitizer），用于过滤高范数冗余并缓解注意力汇（attention sink）与注意力分散；以及文本引导剪枝器（text-guided pruner），用于进一步保留与文本查询语义对齐的标记。在十二个图像-语言和四个视频-语言基准上的大量实验证明了该框架的有效性、效率和泛化能力。值得注意的是，在减少89%标记的情况下，SinkPruner仍保留了LLaVA-1.5（Qwen2.5-VL）原始性能的96.5%（91.8%）。实验进一步表明，所提视觉净化器在增强现有剪枝方法性能方面展现出良好的可迁移性。代码见 https://github.com/LaVi-Lab/SinkPruner。

## Abstract
Despite their strong multimodal understanding ability, multimodal large language models (MLLMs) incur substantial computational overhead when processing long visual token sequences. To reduce inference costs, recent studies have explored visual token pruning through vision-centric or text-guided strategies. However, these methods often overlook high-norm outlier tokens, i.e., tokens with abnormally large feature norms, leading to suboptimal pruning decisions. In this work, we show that such high-norm outlier tokens are highly redundant in both feature and spatial dimensions, yet are often mistakenly preserved as informative cues by existing methods.   Motivated by this observation, we propose SinkPruner, a training-free visual token pruning framework for efficient MLLM inference. SinkPruner follows a coarse-to-fine design with two key modules: a visual sanitizer that filters high-norm redundancies and alleviates attention sink and attention dispersion, and a text-guided pruner that further retains tokens semantically aligned with the text query.   Extensive experiments on twelve image-language and four video-language benchmarks demonstrate the effectiveness, efficiency, and generalizability of our framework. Notably, SinkPruner preserves 96.5% (91.8%) of the original performance of LLaVA-1.5 (Qwen2.5-VL) under an 89% token reduction. Experiments further indicate that our visual sanitizer exhibits promising transferability in enhancing the performance of existing pruning methods. Our code is available at https://github.com/LaVi-Lab/SinkPruner.

# SinkPruner：面向多模态大语言模型的无注意力汇视觉标记剪枝 —— 论文总结

## 1. 核心问题与整体含义

- **问题背景**：多模态大语言模型（MLLMs）在图像与视频理解中需要处理极长的视觉 token（视觉标记）序列，这些序列会在预填充（prefill）和生成阶段带来高昂的计算与内存开销。
- **已有尝试**：为降低推理成本，已有工作尝试视觉 token 剪枝，大致可分为视觉中心剪枝（vision-centric）与文本引导剪枝（text-guided）两类，试图删去对最终答案“不重要”的视觉 token。
- **关键缺陷**：现有剪枝方法普遍忽略了特征**范数极大**的一类离群 token，即“高范数 outlier token”。传统直觉往往会认为它们携带着显著的信息，因而在剪枝时更容易被保留；本文却揭示，这类 token 在**特征层面和空间层面**都高度冗余，属于“伪线索”，保留它们反而可能误导注意力分配。
- **核心问题**：如何在无训练条件下，准确识别真正的关键视觉 token，消除冗余和高范数毒害，从而在压缩率极高时仍能稳定保留模型性能？
- **提出方案**：SinkPruner，一个免训练（training-free）的视觉 token 剪枝框架，以“由粗到细”的两级流程，先清洗冗余与注意力病态 token，再依据文本语义精筛。

## 2. 方法论：核心思想、关键技术细节

- **整体框架**：SinkPruner 不修改或微调 MLLM 权重，而是利用模型本身（如视觉编码器与 LLM 层）的中间表示来去做剪枝决策；流程是先“净化”再“精剪”。

### 模块一：视觉净化器（Visual Sanitizer）

- **目的**：滤除“高范数冗余”，并同时缓解两类注意力异常现象：
  1. **注意力汇（attention sink）**：少数 token（常为初始/位置靠前的 token）吸收了过多注意力权重，但它们不代表核心视觉内容。
  2. **注意力分散（attention dispersion）**：高范数离群 token 会使注意力矩阵在整个序列上趋于弥散/平滑，降低模型对关键区域的聚焦度。
- **做法（依据文本描述推断）**：对视觉 token 的特征范数进行异常值检测，并按阈值（或启发式规则）将高范数 token 标记为“sink/离群”类别并先行移除或抑制；由于这些 token 不包含稠密、可分的信息内容，先剔除可为后续 token 选择创造更纯粹的注意力环境。
- **意义**：不是单纯“丢掉冗余”，而是通过过滤来**修复注意力分配**，间接地放大其余重要 token 之间的区分度。

### 模块二：文本引导剪枝器（Text-Guided Pruner）

- **目的**：在净化后的序列中，进一步保留与文本查询（文本指令/问题）语义最接近的视觉 token。
- **做法**：利用跨模态交互（如注意力分数、视觉-文本特征相关度）来计算每个视觉 token 对当前文本输入的贡献度，只保留语义对齐的 token，删去不相关的背景与冗余区域。
- **整体流程总结**：
  1. 输入图像/视频 → 获取视觉 token；
  2. 第一阶段（粗筛）：视觉净化器过滤高范数离群 token，缓解注意力 sink 和分散；
  3. 第二阶段（精筛）：文本引导器依据语义相关性裁剪剩余 token；
  4. 将保留下来的少量 token 送往 LLM 层进行解码/生成。
- 该“净化→剪枝”的设计，本质是在“语义显著性”之外引入“高范数异常检测”作为新的剪枝判据，使剪枝空间从“只看哪些 token 有用”迁移为“先防毒、再选优”。

## 6. 主要结论与发现

- **发现 1**：高范数离群 token 在特征空间和空间分布上都是冗余的，现有剪枝方法把它们视为信息线索，从起点上就是错误估计。
- **发现 2**：将“高范数检测/剔除”与“文本语义引导”结合起来，可以在极高剪枝率下（如删去89%的视觉 token）仍保留绝大多数模型能力，其中：
  - LLaVA-1.5：保留原有性能的 96.5%；
  - Qwen2.5-VL：保留原有性能的 91.8%。
- **发现 3**：视觉净化器是一个可迁移模块，将其嵌入其他剪枝方法可增强这些方法在低预算下的性能表现，说明其对注意力异常的一般性解释与抑制能力。
- **总体结论**：通过“过滤冗余汇 + 文本引导精剪”的组合，SinkPruner 能让 MLLM 在长序列场景下显著节约推理开销，并具备在多个模型和任务上的泛化性与可扩展性。

## 7. 优点

- **无训练设计**：直接用于现有 MLLM 的推理，不增加训练成本，实际部署友好，具备较强的应用潜力。
- **方法结构简洁**：“由粗到细”的双阶段流水线，将“全局净化”与“语义精修”结合，逻辑清楚、组件解耦度高。
