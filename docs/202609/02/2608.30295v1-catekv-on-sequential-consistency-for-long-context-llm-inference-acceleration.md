## 摘要
大型语言模型（LLM）在处理长上下文任务方面展现出强大的能力，但由于巨大的内存需求和推理延迟，处理此类长上下文仍然具有挑战性。在这项工作中，我们发现某些注意力头在其注意力模式中表现出顺序一致性，这可以通过基于变异系数的算法进行持续识别。受此观察启发，我们提出了CateKV，一种混合KV缓存方法，它仅保留一致性头的关键token信息，从而减少KV缓存大小和计算开销，同时保留自适应头中的大部分KV对以确保高精度。我们展示了我们算法的独特特性及其与现有加速方法的扩展。对长上下文基准的综合评估表明，在保持与全注意力相当的精度的同时，CateKV在单样本输入中将内存使用量减少高达2.72倍，解码速度提升2.18倍，并在批处理场景中将吞吐量提升3.96倍。

## Abstract
Large language models (LLMs) have demonstrated strong capabilities in handling long-context tasks, but processing such long contexts remains challenging due to the substantial memory requirements and inference latency. In this work, we discover that certain attention heads exhibit sequential consistency in their attention patterns, which can be persistently identified using a coefficient-of-variation-based algorithm. Inspired by this observation, we propose CateKV, a hybrid KV cache method that retains only critical token information for consistent heads, thereby reducing KV cache size and computational overhead, while preserving the majority of KV pairs in adaptive heads to ensure high accuracy. We show the unique characteristics of our algorithm and its extension with existing acceleration methods. Comprehensive evaluations on long-context benchmarks show that, while maintaining accuracy comparable to full attention, CateKV reduces memory usage by up to $2.72\times$ and accelerates decoding by $2.18\times$ in single-sample inputs, and boosts throughput by $3.96\times$ in batch scenarios.

- **现有方法的两难**：
  - **KV驱逐类方法**（如StreamingLLM、SnapKV、PyramidKV）通过丢弃KV对节省资源，但容易丢失关键信息，造成显著精度损失。

## 2. 论文提出的方法论：核心思想、关键技术细节、公式与算法流程

### 2.1 核心思想

提出 **CateKV**，一种**混合KV缓存方法**：
- **一致性头（Consistent Heads）**：仅保留少量关键token的KV对，实现高压缩率。
- **自适应头（Adaptive Heads）**：保留大部分KV对（通常η=1.0，即全保留），确保全局信息不被丢失。

该方法以预填充阶段的观察窗口识别头类型和关键token，将“经验”迁移到解码阶段。

### 2.2 关键技术细节

**（1）观察矩阵构建**：在预填充阶段取最后$L_{obs}$个query token作为观察窗口，暂时排除初始与最近token（避免注意力汇聚干扰分类），构建观察矩阵：

$$A = \text{softmax}\left(\frac{Q[-L_{obs}:,:]\,K^T_{[L_{init}:-L_{rec},:]}}{\sqrt{d}}\right)$$

其中$A \in \mathbb{R}^{L_{obs} \times (n - L_{rec} - L_{init})}$。

**（2）基于变异系数的评分（CV Score）**：
- 首先用百分位阈值$k$和缩放因子$\alpha$对A进行二值化：$B = I(A \geq \Phi(k,\alpha))$；
- 然后沿观察窗口维度累加得到关键token频率向量$C = \sum_i B_{i,:}$；
- 最后计算变异系数作为该头在样本上的得分：
$$\text{score} = \frac{\sqrt{\frac{1}{M}\sum_i (C_i - \mu(C))^2}}{\mu(C)}$$
得分较高意味着各行注意力高度相似且集中在少量token上——即一致性头。

**（3）头类型判定**：设定自适应头比例$r$，将CV得分高于阈值$\Gamma(r)$的头归为一致性头，低于阈值归为自适应头。

**（4）基于参考集的静态识别**：论文观察发现同一头在不同样本间的分类结果高度一致（重叠率超过80%），因此可以基于参考数据集（由RULER的Variable Tracking任务构造，与测试集不同）为模型确定**固定的头类型配置**，避免每个样本动态分类带来的额外开销。

**（5）算法流程（单头视角）**：
- **预填充阶段**：计算token重要度→分块取最大值（chunk size=8）→一致性头取top-b块缓存，自适应头按保留比例η取top-k块缓存（同时保留观察窗口对应的尾部KV）。
- **解码阶段**：一致性头直接使用已缓存的关键KV（无需检索）；自适应头可进行全量关注，或与Quest/ShadowKV等检索方法集成。

## 6. 论文的主要结论与发现

- **核心发现**：LLM中存在两类注意力头——一致性头和自适应头，这种区分在不同模型、不同层中广泛存在，且分类结果跨样本高度稳定。一致性头的注意力模式在预填充与解码阶段保持稳定，可用预填充阶段信息指导解码阶段的缓存策略。
- **精度保持**：在仅保留约41% KV缓存的情况下，CateKV在RULER-128K上平均精度与全注意力相当甚至略高（如Llama-3：84.61 vs 84.10；Yi-9B：65.76 vs 64.52）。
- **效率提升**：
  - 单样本推理：内存降低最高2.72×，解码延迟降低最高2.18×；
  - 批处理场景：batch size扩大最高4.33×，吞吐量提升最高3.96×；
  - LongBench上5个模型平均精度下降不超过0.3%。
- **即插即用**：可与预填充加速方法（MInference）、检索方法（Quest、ShadowKV）自然集成，且在集成后精度不降或微降，效率进一步提升。
- **与DuoAttention的本质区别**：DuoAttention的streaming head主要关注初始和最近token的覆盖，而CateKV的一致头捕捉的是不同query之间关键token的相似性，因此在低全注意力头比例下仍能保持精度——CateKV可补充DuoAttention的性能短板。
