## 摘要
长上下文大语言模型应用（如文档摘要和多轮智能体）需要从数万token的前缀进行生成，使解码延迟成为主要瓶颈。推测解码（SD）在不改变模型输出的情况下降低延迟，但其加速效果既取决于被接受的草稿token数量，也取决于草稿步骤的延迟：轻量级草稿速度快，但缺乏捕捉长距离依赖的能力，而强独立草稿虽能恢复接受率，但在长前缀下会带来不断增长的KV访问成本。我们引入了用于长上下文SD的记忆增强草稿生成，为强独立草稿配备压缩的草稿侧KV记忆：一个轻量级适配器构建并增量更新该记忆，以保留遥远信息及精确的近期上下文。目标验证器保留其完整KV缓存并应用标准接受/拒绝规则，从而保持SD的无损保证。在Llama~3.1-8B和70B目标上，前缀长度高达32K的实验表明，我们的方法将草稿侧记忆减少了超过70%，相比自回归解码分别实现了最高2.08倍和3.33倍的加速。

## Abstract
Long-context LLM applications such as document summarization and multi-turn agents require generation from prefixes spanning tens of thousands of tokens, making decoding latency a major bottleneck. Speculative decoding (SD) reduces latency without changing model outputs, but its speedup depends on both accepted draft tokens and draft-step latency: Lightweight drafts are fast but lack the capacity to capture long-range dependencies, whereas strong independent drafts recover acceptance but incur growing KV-access cost at long prefixes. We introduce memory-augmented drafting for long-context SD, equipping a strong independent draft with compressed draft-side KV memory: A lightweight adaptor constructs and incrementally updates this memory to retain distant information and exact recent context. The target verifier retains its full KV cache and applies the standard accept/reject rule, preserving SD's lossless guarantee. Experiments on Llama~3.1-8B and 70B targets at prefix lengths up to 32K show that our method reduces draft-side memory by over 70%. It achieves speedups of up to 2.08x and 3.33x , respectively, over autoregressive decoding.

  - 轻量级草稿（如 EAGLE 风格的单层草稿）速度快，但在长上下文下容量不足，难以捕捉远距离依赖，接受率随前缀长度增加而显著下降。
  - 强独立草稿（如 Llama 3.2-3B 作为草稿）能维持较高接受率，但每个草稿步骤都需要读取完整历史 KV 缓存，KV 访问量随前缀长度线性增长，最终侵蚀端到端加速收益。
- **论文定位**：在长上下文 SD 中同时追求“高接受率”和“低草稿延迟”。作者指出理想设计应保留草稿模型的足够容量，同时让其访问**大幅缩短的 KV 记忆**，从而避免随前缀长度线性增长的 KV 访问开销。论文提出 **Memory-Augmented Sliding-Window (MASW) Drafting**，即用压缩的草稿侧 KV 记忆替代完整历史 KV 缓存，实现长上下文下的高效推测解码。

## 2. 方法论：核心思想、关键技术细节、公式或算法流程

### 核心思想
- 独立草稿模型不维护完整前缀的 KV 缓存，而是维护一个紧凑的**三段式工作记忆**：
  - **sink token KV**（前 S 个原始 token 的精确 KV）
  - **局部窗口 KV**（最近的 W 个非 sink token 的精确 KV）
  - **记忆槽 KV**（periodically materialized memory slots，压缩编码较远历史）
- 目标验证器仍保留完整前缀的完整 KV 缓存，并使用标准接受/拒绝规则，因此 SD 的**无损保证不变**。

### 关键技术细节
1. **记忆结构定义**：
   \[
   M_t = M_{\text{sink}} \cup M_{\text{local},t} \cup M_{\text{slot},t}
   \]
   - \(M_{\text{sink}}\)：前 \(S\) 个位置（sink tokens）。
   - \(M_{\text{local},t}\)：最近 \(W\) 个非 sink token 的原始 KV。
   - \(M_{\text{slot},t}\)：记忆槽的多层 KV，以固定间隔 \(r\) 生成，形成压缩链条。

2. **记忆材料化（memory materialization）**：
   - 每隔 \(r\) 个 token（压缩边界 \(\tau_m = mr\)）插入一个记忆槽 token \(g_m\)。
   - \(g_m\) 通过草稿的 transformer 所有层前向传播获得，其注意力可以访问当前局部窗口、sink tokens 以及之前的记忆槽：
     \[
     g_m \leftarrow f_\theta(M_{\text{local},\tau_m}, M_{\text{sink}}, M_{\text{slot},<m})
     \]
   - **结构化注意力掩码**作为写入策略：后续 token 只能通过记忆槽访问历史信息，槽被训练为“对未来预测最有用的压缩载体”，而非单纯摘要。
   - 新槽的隐藏状态经**专用的镜像投影矩阵** \(W^{(l)}_{K,g}, W^{(l)}_{V,g}\) 生成 KV 条目，写入 \(M_{\text{slot},t}\)。原始 token 仍使用冻结的原始投影 \(W^{(l)}_{K,r}, W^{(l)}_{V,r}\)。
   - 原始 token 在滑窗之外的 KV 被立即丢弃，不等待目标验证。

3. **推理流程（MASW 集成到 SD）**：
   - **Prefill 阶段**：目标模型预填充完整前缀以建立完整 KV；草稿模型在并行前向中用自己的记忆掩码构建初始压缩记忆。由于草稿是独立模型，草稿 prefill 可与目标 prefill 并行，隐藏额外开销。
   - **解码阶段**：每轮推测解码中，草稿只读取紧凑记忆（sink tokens + 局部窗口 + 记忆槽），目标验证器使用完整 KV 做并行验证。
   - **回滚机制**：若目标拒绝某个推测块，草稿丢弃推测产生的局部 KV 以及拒绝位置之后生成的记忆槽，并用保留的“回滚窗口”恢复最近上下文。

4. **训练**：
   - 仅训练镜像投影矩阵，冻结草稿主干；目标是最小化原始 token 的下一 token 预测损失：
     \[
     L = \sum_t - \log p(x_t \mid D_t, x_{<t}), \quad D_t = (M_{\text{sink}}, M_{\text{local},t}, M_{\text{slot},t})
     \]
   - 记忆槽位置不参与损失计算。

## 6. 主要结论与发现

- 长上下文 SD 存在两难：轻量草稿接受率低；强独立草稿 KV 访问成本高。
- MASW 通过在强独立草稿上引入压缩 KV 记忆，大幅**降低草稿侧内存与延迟**，同时保持较高的接受长度：
  - 草稿侧内存减少超 70%（额外峰值从 17–18 GB 降至约 4–5 GB）。
  - 草稿单步延迟从 41–55 ms 降至 12–15 ms（32K 前缀）。
  - Llama 3.1-8B 目标最高获得 **2.08×** 加速；Llama 3.1-70B 目标最高获得 **3.33×** 加速（相对 AR）。
- 在 70B 目标上 MASW 的加速比随上下文增加仍保持稳定或增长，而完整 KV SD 会因草稿侧 KV 流量增大而性能下降。
- 复制权重初始化镜像投影、采用“预训练 + SFT”两阶段训练、使用 8K 训练上下文均为较优选择。
- 目标验证器保留完整 KV，因此 SD 的**无损保证不变**。

## 7. 优点

- **问题洞察清晰**：将长上下文 SD 的瓶颈分解为“容量 vs KV 访问成本”，并给出公式化解释，切中要害。
