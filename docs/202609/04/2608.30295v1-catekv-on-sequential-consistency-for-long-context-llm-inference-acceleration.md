## 摘要
大型语言模型（LLM）在处理长上下文任务方面展现出强大能力，但由于巨大的内存需求和推理延迟，处理此类长上下文仍然具有挑战性。在这项工作中，我们发现某些注意力头在其注意力模式中表现出顺序一致性，这种一致性可以通过基于变异系数的算法进行持续识别。受此观察启发，我们提出了CateKV，一种混合KV缓存方法，该方法仅保留一致性头的关键令牌信息，从而减少KV缓存大小和计算开销，同时保留自适应头中的大部分KV对以确保高准确性。我们展示了我们算法的独特特性及其与现有加速方法的扩展。对长上下文基准测试的综合评估表明，在保持与全注意力相当的准确性的同时，CateKV在单样本输入中将内存占用减少高达2.72倍，解码速度提升2.18倍，并在批量场景中将吞吐量提升3.96倍。

## Abstract
Large language models (LLMs) have demonstrated strong capabilities in handling long-context tasks, but processing such long contexts remains challenging due to the substantial memory requirements and inference latency. In this work, we discover that certain attention heads exhibit sequential consistency in their attention patterns, which can be persistently identified using a coefficient-of-variation-based algorithm. Inspired by this observation, we propose CateKV, a hybrid KV cache method that retains only critical token information for consistent heads, thereby reducing KV cache size and computational overhead, while preserving the majority of KV pairs in adaptive heads to ensure high accuracy. We show the unique characteristics of our algorithm and its extension with existing acceleration methods. Comprehensive evaluations on long-context benchmarks show that, while maintaining accuracy comparable to full attention, CateKV reduces memory usage by up to $2.72\times$ and accelerates decoding by $2.18\times$ in single-sample inputs, and boosts throughput by $3.96\times$ in batch scenarios.

## CateKV：面向长上下文LLM推理加速的顺序一致性研究 — 详细总结

### 1. 论文的核心问题与整体含义（研究动机与背景）

**核心问题：**
长上下文大语言模型（LLM）推理过程中，KV缓存（Key-Value Cache）随输入长度线性增长，导致严重的内存占用和推理延迟问题。即使采用如FlashAttention等高效算子，从1K扩展到1M token也会使推理延迟增加超3000倍。

**研究动机与观察：**
- 现有方法分为两类：**KV eviction**（早期驱逐）和 **KV retrieval**（全保留+检索）。前者易损失精度，后者不减轻内存压力。
- 本文发现新现象：**部分注意力头表现出"顺序一致性"（Sequential Consistency）**——在预填充阶段（pre-filling）和推理阶段（decoding）中，注意力始终集中在一小组关键token上；而其他头则展现出动态变化的注意力分布（自适应头）。
- 利用这一现象，将预填充阶段识别的模式用于指导解码阶段，可在不损失精度的前提下大幅压缩KV缓存，同时与现有加速方法正交、可组合。

### 2. 论文提出的方法论

**核心思想：** 提出 CateKV（Cate为Categorize之意），一种混合KV缓存管理方法。区分两类注意力头：

- **一致性头（Consistent Heads）**：注意力模式跨预填充、解码阶段稳定集中于少数token，只保留关键KV对。
- **自适应头（Adaptive Heads）**：注意力分布动态多变，需保留大多数KV对以保证精度。

**关键技术流程：**

1. **观察矩阵构造**
   - 引入观察窗口 `L_obs`，使用预填充阶段最后 `L_obs` 个token作为查询，计算注意力矩阵：
     `A = softmax(Q[-L_obs:,:] * K^T[L_init : -L_rec,:] / √d)`
   - 排除初始token（`L_init`）和最近token（`L_rec`），避免影响分类判断。

2. **CV变异系数打分**
   - 对观察矩阵做**分位数二值化**：`B = I(A ≥ Quantile_k(A) × α)`
   - 统计每个token被标记为关键的出现频率向量 `C`。
   - 基于**变异系数（Coefficient of Variation）** 计算每个头的分数，衡量各行间的相似度与集中度：
     `score = std(C) / mean(C)`
   - 得分高的头判定为一致性头，得分低（分布分散）的头判定为自适应头。

3. **基于参考集的静态头分类**
   - 对每个模型使用参考数据集（论文用RULER的Variable Tracking任务构建，与测试集不同），统计每个头被判定为一致头的频率，确定**固定的模型级头类型划分**。
   - 关键参数：
     - `r`：自适应头比例（用于设定阈值 `Γ(r)`），大于阈值为一致头，小于等于阈值为自适应头
     - `η`：自适应头的KV保留率
     - `b`：一致性头的稀疏预算（以chunk为粒度取top-k）
     - `cs`：chunk_size（论文设为8）

4. **存储与解码策略**
   - 预填充时按头类型选择性缓存KV：
     - 一致性头：按chunk块最大注意力分数提取top-b个chunk的KV
     - 自适应头：保留前 `n_η` 个chunk（η=1.0时即全保留），解码时支持进一步检索
   - 解码阶段直接使用缓存或按查询动态检索。
   - 支持GQA（Grouped Query Attention），取同组头的观察矩阵均值。

**理论分析：**
- 通过Rademacher复杂度界（Lemma 1）描述参考集分类误差上界。
- Theorem 1给出token保留精度与λ（查询注意力分数排序有效性）、预算控制、头分类精度 `P_head` 三个因素的下界关系，为方法提供理论支撑。

### 6. 论文的主要结论与发现

**核心结论：**
1. **顺序一致性是普遍存在的**：在多个流行LLM（Llama、Phi、Yi）跨层中同时存在一致性头与自适应头。
2. **CateKV显著提升效率且保持精度**：
   - RULER-128K平均84.61 vs. 全注意力84.10（Llama-3-8B-1M），在多文档QA、变量追踪等复杂任务上超越全注意力
   - LongBench上精度损失≤0.3%，与检索方法组合损失≤0.2%
   - NIAH图中从20K到1M均保持高检索成功率
3. **效率收益量化**：
   - 单样本推理中内存最大减少2.72倍，解码延迟最大减少2.18倍
   - 批场景中批大小扩大4.33倍，吞吐提升3.96倍（Llama-3-8B-1M）
4. **顺次一致性模式优于流式模式**：注意力回溯率高于StreamingLLM的Streaming pattern，接近Quest pattern（且零额外检索计算）；与DuoAttention相比更具压缩优势。
5. **可组合性**：与DuoAttention组合可从68.46提升至87.26（RULER平均），与MInference组合无精度损失并略有提升。

### 8. 不足与局限

1. **参考集依赖**：头分类在推理前需构建参考数据集并预计算，若参考集分布与真实场景差异极大，分类可能退化；非全自动在线决定头类型的方案对动态数据场景适配不够灵活。
