## 摘要
视觉令牌剪枝降低了视觉语言模型（VLM）的推理成本，但大多数方法只考虑保留哪些令牌。这种保留令牌的视角可能保留冗余的高分令牌，同时让被丢弃的证据没有接近的代表。我们提出CoverPruner，一种无需训练的剪枝器，它提出了互补的需求方问题：当一个令牌被移除后，哪个存活的原始令牌为目标VLM代表它？CoverPruner将剪枝表述为表示覆盖最大化（RCM），用查询加权的需求覆盖完整的投影视觉令牌集。它通过投影器空间覆盖和轻量级第一层注意力探针实例化RCM。在多种VLM架构和压缩率下，CoverPruner在所有比较方法中实现了最佳平均准确率，最大的提升通常出现在激进压缩下。

## Abstract
Visual token pruning reduces the inference cost of vision-language models (VLMs), but most methods only ask which tokens to keep. This retained-token view can keep redundant high-scoring tokens while leaving discarded evidence without a close representative. We propose CoverPruner, a training-free pruner that asks the complementary demand-side question: after a token is removed, which surviving original token represents it for the target VLM? CoverPruner formulates pruning as Representational Coverage Maximization (RCM), covering the full projected visual-token set with query-weighted demand. It instantiates RCM with projector-space coverage and a lightweight first-layer attention probe. Across multiple VLM architectures and compression rates, CoverPruner achieves the best average accuracy among all compared methods, with the largest gains usually appearing under aggressive compression.

## 一、核心问题与研究动机

- **背景**：视觉语言模型（VLM）将图像编码为数百乃至数千个视觉 token，注意力复杂度随序列长度呈平方增长，视觉 token 的数量因此主导推理成本。视觉 token 剪枝通过仅保留一小部分视觉 token 来降低推理开销，是提升 VLM 推理效率的重要手段。
- **现有方法的盲区（供给侧视角）**：已有剪枝方法大多只回答一个问题——“该保留哪些 token？”这类方法在决策时单独对 token 打分（如注意力重要性或特征冗余），容易**保留多个来自同一显著物体的冗余高分 token**，同时让某些低分却关键的补丁（如小段文字、图表标签、上下文区域）被删除后**没有任何存留 token 能接近地代表它**。
- **本文的视角转换（需求侧视角）**：作者提出剪枝还应当回答一个被忽略的互补问题——**“一个 token 被移除后，哪个存活的原始 token 为目标 VLM 代表它？”** 剪枝不仅是决定什么存活，更是决定“谁为消失的证据代言”。
- **核心问题定义**：一个天空区域仅需一个 token 即可覆盖，而路牌上各不相同的文字补丁则需要各自独立的代表。基于这一直觉，需要一种以“被覆盖需求”为核心的集合级选择目标，而非简单的逐 token 打分。

## 二、方法论：CoverPruner

### 2.1 核心思想

- 将视觉 token 剪枝形式化为**代表性覆盖最大化（Representational Coverage Maximization, RCM）**：完整投影视觉 token 集定义“需求”，保留子集提供“代表”，每个需求 token 按查询相关性加权。
- 方法**完全免训练（training-free）**，不修改模型参数，不引入可训练模块，保留原始 token 的表征（不做融合）。

### 2.2 关键技术与公式

1. **覆盖的数学定义（式 1、2）**
   - 投影视觉 token：V = g(f_v(X_v)) ∈ R^{n×d}（视觉编码器 f_v 与投影器 g 的输出，即进入 LLM 的输入空间）。
   - 代表 i 被集合 S 覆盖的程度：cov(i,S) = max_{j∈S} sim(v_i,v_j)，其中 sim 为投影空间的余弦相似度。
   - RCM 目标：f(S) = Σ_{i=1}^n w_i · max_{j∈S} sim(v_i,v_j)，|S|=m，w_i ≥ 0 为需求权重。
   - 该目标**单调子模（monotone submodular）**，可用标准贪心获得 (1−1/e) 近似。

2. **LLM 锚定的相似度校准**
   - 相似度在**投影器输出空间**（即 LLM 实际消费的表征空间）计算，而非视觉编码器特征空间——两个对编码器冗余的 patch，投影后可能提供可区分的证据，反之亦然。
   - 原始投影空间的余弦相似度动态范围有限，因此进行**逐行均值中心化**：fM_ij = M_ij − (1/n)Σ_k M_ik，再取非负截断 A_ij = max(0,fM_ij)，低于图像内平均匹配度的 token 视为不提供覆盖。

3. **查询需求估计：第一层注意力探针**
   - 使用**第一解码器层**（layer-0）的输入 LayerNorm 及 W_Q、W_K，以用户指令文本位置为 query、视觉 token 位置为 key，计算缩放点积注意力，对所有指令位置和注意力头取平均得到 r_i。
   - 经 min-max 归一化并施加指数温度：w_i = e^{τ·r̃_i}。τ=0 退化为均匀覆盖，τ 越大预算越偏向查询相关区域（默认 τ=0.3）。

4. **需求加权覆盖选择（式 6，贪心算法）**
   - 初始化 c_i = 0（当前覆盖度），每步选择边际覆盖增益最大的候选，即 k* = arg max_{k∉S} Σ_i w_i · max(0, A_ik − c_i)，随后更新 c_i ← max(c_i,A_ik*)，直至 |S|=m。
   - 每一步的选择取决于“还有什么未被覆盖”，而非静态 token 分数：区域已有代表后，相似 token 增益很小，而覆盖未表征证据的 token 始终有价值。
   - 选择完成后**按原视觉 token 顺序**保留子集 V_S，与原指令 token 拼接待入未修改的解码器。

## 六、主要结果

### 6.1 总体结论

- CoverPruner 在绝大多数（模型 × 数据集 × 压缩率）组合下，**整体准确率优于此前最先进的打分型与融合型剪枝方法**；在 90% 以上剪枝率（如 576→32 token）下优势尤其明显，说明其“需求侧覆盖”机制能保住打分法平均化后丢失的稀疏但关键补丁。
- 在 OCR/文本密集任务（TextVQA、OCRBench、ChartQA）上，CoverPruner 与其他方法的差距最大——这类任务中不同文字 patch 需要各自独立代表，恰好与覆盖目标的建模优势吻合。
- 在幻觉基准（POPE 等）上，CoverPruner 因保留全局分散 token，减少了模型对单一显著物体过自信的倾向， hallucination 率相对更低。
- 在 Qwen2.5-VL 上，Visual Token 压缩是模型原生稀疏注意力的一部分，CoverPruner 在已有 1,296 token 的情况下进一步压缩至 128 而不显著掉点，表明其可叠加现有能力。

### 6.2 与对比方法的行为差异（可视化）

- **FastV/SparseVLM 等打分法**：保留 token 高度集中于图像中少量显著区域，被剪掉的文字或边缘上下文无代表。
- **ToMe/PruMerge 等融合法**：若后期 token 被平均/拼接，原始 token 分布被破坏，模型与预训练分布偏移。
- **DivPrune/MMTok**：追求特征空间中的距离多样性，但不以 LLM 消费表征空间（投影后空间）为准，且不关联指令需求。
- **CoverPruner**：分配呈现“显著区域多 token、背景少 token、但任何局部纹理都有 1 个代表”的空间分布，与人类视觉注意力覆盖模式更接近。

### 6.3 消融要点

- **校准操作不可缺少**：无均值中心化时，所有 token 的原始余弦相似度集中在 0.8–0.99，覆盖区分度低，剪枝掉点显著；减去图像内平均相似度后覆盖信号才变得有判别力。
- **相关性来源**：第一层注意力优于 CLIP 特征和 LLM 嵌入；后者混合了位置信息与语言先验，噪声较大。
- **相关性权重排序效果有限**：仅用相关性对 token 排序并截断，不如将相关性作为需求权重乘入覆盖目标，因为前者重新退化为“静态排序”问题，无法解决同物体冗余 token 竞争的问题。
- **温度 τ**：默认 0.3 附近鲁棒；τ 过大导致预算过度集中在某一局部物体上，牺牲远端覆盖，在 VQA 上反而掉点。

## 七、论文贡献

1. **提出新视角**：从“保留哪些 token”转向“被移除 token 由谁代表”，将剪枝从逐点打分转换为集合级覆盖问题，填补需求侧建模空白。
2. **形式化 RCM 目标**：将覆盖定义为 LLM 投影空间中的 max-similarity，结合查询相关性权重，证明其单调子模性，可保证贪心算法的 (1−1/e) 近似。
3. **免训练、即插即用**：不插入任何额外参数，仅用第一层注意力与投影表征的相似度，适用于 LLaVA 与 Qwen2.5-VL 等多种动态分辨率架构。
4. **系统性实验**：在 13 个基准、5 个模型变体（7B/13B）、3 档压缩率下验证优越性，并与融合/打分/集合多样性三类方法对比，揭示“多样性≠覆盖”这一关键区别。

## 八、局限与改进方向

- **子模近似效率**：标准贪心每步需扫描全部剩余 token 与已有集合的相似度，尽管借助矩阵运算实现约 1.5 ms/example，理论复杂度仍高于纯打分方法；连续松弛或哈希近似可作为加速方向。
- **平均相似度中心化的粒度**：当前以整幅图像的平均为阈值，对包含多个异构子图的高分辨率图像可能过于粗糙；可尝试聚类级/段级校准。
- **自回归解码阶段的覆盖率保持**：目前仅在 prefill 阶段做一次剪枝；若在 decode 阶段按需恢复 token（如遇到关键问题词时）可能进一步提升能力。
- **未扩展到具 token 合并机制的新一代 VLM**（如 Qwen2.5-VL 已内建合并，或未来多模态 MoE 架构），方法在 token 层级改变更深时的适应性有待检验。

## 九、个人评价与总体判断

### 9.1 优点

- **问题定义优雅而有力**：将“剪枝后谁代表被删证据”这一看似抽象的问题落到可计算的集合覆盖上，是一种难得的视角转换，而非单纯调参改进。
- **方法简洁透明**：无训练模块、无额外蒸馏、无复杂门控，核心逻辑一页可讲清，复现成本低。
- **与认知直觉高度一致**：人类略读地图时会同时保证“多数区域至少扫到一眼”，CoverPruner 的 max-coverage 正是这种“确保每个区域都有落脚点”的数学化表达。

### 9.2 不足

- **有效性论证偏“经验压倒理论”**：尽管证明了子模性，但没有给出在 VLM 上下文下为什么最大相似度覆盖恰好对应语义证据保存的理论解释；“投影空间相似”与“模型可识别等价”之间的 gap 靠实验掩盖。
- **计算开销报告不够透明**：未报告完整实验总 GPU 时数，只报告了每样本剪枝开销；对于在高分辨率输入（2,880 token）上运行贪心时的峰值内存也没有给出。
- **对比方法的选择偏向近两年工作**：未与更早期的 token pruning（如 EVIT、VTW 等）比较；附录中 DidPrune/MMTok 实现细节较少，复现时可能依赖作者仓库。

## 十、总体结论

CoverPruner 提出“谁为被剪枝的 token 代言”这一概念性转向，将视觉 token 剪枝归结为受查询权重约束的**代表性覆盖最大化**。方法数学基础清晰（单调子模）、计算过程完全免训练，且在 LLaVA-1.5、LLaVA-NeXT、Qwen2.5-VL 上，于 60%–94% 压缩范围内一致优于 SOTA 对比方法；尤其在中高压缩率与 OCR/文本密集场景中优势显著。这一工作通过揭示“保留集不仅应多样，还应确保每个被删除 token 都有语义上的最近代表”，为 VLM 高效推理中的 token 选择提供了新的设计原则，具有较高的借鉴价值与后续扩展空间。
