## 摘要
尽管多模态大语言模型（MLLMs）在多种任务中表现出色，但其可扩展性仍然受到KV缓存存储的内存与计算开销的限制。近期的KV缓存淘汰方法将基于余弦相似度的多样性度量与重要性度量相结合，以选择性保留关键的键值对。然而，余弦相似度涉及归一化，会丢弃幅度信息，并且由于隐藏表示的各向异性特性，它往往在各层产生一致的高相似度值。在我们的ECOKV研究中，我们严格解构了现有多样性度量的能力。超越简单的度量，我们提出了一种几何感知的复合度量，它联合利用欧氏距离和余弦相似度，从互补视角捕获token的多样性。此外，我们使用这两种度量来估计每个注意力头的冗余程度，从而在token选择过程中对多样性分数和重要性分数进行自适应加权。最后，我们证明了通常用于保留最近token的观察窗口可以被大幅缩减，从而将更多缓存容量分配给富含信息的token，并带来持续的性能提升。大量实验表明，ECOKV在各种压缩比下均达到了最先进性能，并且能够无缝集成到现有的KV缓存淘汰方法中。我们进一步分析了重要性与多样性之间的关系，并考察了跨层和注意力头的冗余模式。

## Abstract
Although multimodal Large Language Models (MLLMs) excel in diverse tasks, their scalability remains limited by the memory and computational overhead of KV cache storage. Recent KV cache eviction approaches incorporate a cosine similarity-based diversity metric with importance metrics to selectively retain critical key-value pairs. However, cosine similarity involves normalization that discards magnitude information, and it often yields uniformly high similarity values across layers due to the anisotropy property of hidden representations. In our study ECOKV, we rigorously deconstruct the capabilities of existing diversity metrics. Moving beyond simple measurement, we propose a geometry-aware composite metric that jointly leverages Euclidean distance and cosine similarity to capture token diversity from complementary perspectives. Furthermore, we use these two metrics to estimate the redundancy level of each attention head, allowing adaptive weighting between diversity and importance scores during token selection. Finally, we demonstrate that the observation window commonly employed to preserve recent tokens can be substantially reduced, thereby allocating more cache capacity to informative tokens and yielding consistent improvements. Extensive experiments demonstrate that ECOKV achieves state-of-the-art performance under various compression ratios and can be seamlessly integrated with existing KV cache eviction methods. We further analyze the relationship between importance and diversity, and examine redundancy patterns across layers and attention heads.

  - 重要性打分：H2O、SnapKV 等利用历史注意力分数或 key/value 范数估计 token 对最终生成的重要性。
  - 多样性打分：KeyDiff、MixKV 等通过“保留与全局均值差异最大的 token（即偏离中心最远）”来最大化保留集合的语义覆盖度。

  - 由于 transformer 表征具有**各向异性（anisotropy）**特征，高维 embedding 集中在一个狭窄空间锥体内，使余弦相似度跨层普遍偏高，造成对冗余度的系统性高估。

## 2. 论文提出的方法论

### 2.1 核心思想
论文提出 **ECOKV**：一种几何感知的 KV 缓存淘汰框架，抓住三个技术支柱：
1. 基于欧氏距离的多样性打分——补充余弦相似度丢失的幅度信息；
2. 头自适应的冗余估计器——在逐头层面将“幅度冗余”与“方向冗余”融合，合理调整多样性/重要性权重；
3. 极小的观测窗口策略——释放更多缓存预算，使基于智能打分的选择发挥更大作用。

### 2.2 关键流程与公式（文字版推导）

**A. 多样性的复合打分**

对给定层 \(l\) 注意力头 \(h\) 的全部 key：

1. 计算所有 key 的质心 \( \bar{k} \)（所有键向量的全局均值）；
2. 计算每个 key 到质心 \( \bar{k} \) 的欧氏距离 \( d_E(i) = \|k_i - \bar{k}\|_2 \)；
3. 对距离做 min-max 归一化到 0~1：\( s_E(i) = [d_E(i)-\min(d_E)] / [\max(d_E)-\min(d_E)+\epsilon] \)；
4. 同时沿用 MixKV 式余弦多样性分数 \( s_C(i) \)（即归一化键与全局质心的点积取负并做平移）；
5. 用组合系数 α 将两者合并为统一多样性得分：
   \[
   S_{div}(i) = \alpha \cdot s_E(i) + (1-\alpha)\cdot s_C(i)
   \]
   其中 α 默认取 0.8。

**B. 每个注意力头的“冗余度”（自适应权重 λ）**

- 计算本层/头平均欧氏距离 \( D_E^h \)（所有 key 与质心距离的平均值），作为**幅度维度上的冗余信号**；
- 经缩放的 sigmoid 映射为冗余度：
  \[
  r_E = 2 - 2\sigma(D_E^h / \tau) \;,\quad \tau = \sqrt{d_k}
  \]
  （距离越小 → 头分布越集中 → 冗余度越大 → r_E 越高）
- 结合 MixKV 基于余弦相似度的对角冗余打分 \( r_C \)，再以 β 系数融合，得每头的多样性权重：
  \[
  \lambda = \beta \cdot r_E + (1-\beta)\cdot r_C\;, \quad \beta \text{默认取 } 0.6
  \]
- λ 越大 → 该头越侧重多样性选择；λ 越小 → 越侧重重要性打分。

**C. 最终评分与淘汰**

- 先将多样性分数归一化并按重要性分数幅值缩放，得到 \( \tilde{S}_{div} \)；
- 重要性分数 \( S_{imp} \) 按前工作（SnapKV 类）计算（ℓ2 norm + 观测窗口内平均注意力）；
- 最终评分：\( S(i) = \lambda \cdot \tilde{S}_{div}(i) + (1-\lambda)\cdot S_{imp}(i) \)；
- 对每个注意力头保留下 top-K 的键值对。

**D. 观测窗口缩减**

- 此前方法把最近 32 个 token 无条件保留（观测窗口），并利用这些 token 的查询来计算历史 token 的重要性；
- ECOKV 通过实验发现，在 MLLM 场景下大窗口反而是有害的——它消耗了大量缓存预算，造成可被智能挑选的空间变小；
- ECOKV 将窗口缩减为 4 甚至 1，必要时可用最近的一个查询评估重要性——结果显示模型性能反而持续提高。

## 6. 论文的主要结论与发现

1. **复合几何多样性明显优于单度量多样性**：在几乎所有模型与基准上，α、β 均不在端点（即既不纯欧氏也不纯余弦）时效果最好——实证两种几何信息的互补性（正文图 3）。
2. **ECOKV 性能提升幅度随压缩比增大而更明显**：将预算从 256 降到 64 时，它相对于 MixKV 的提升往往从零点几个点到最高約 10+ 分——尤其在 SnapKV + MixKV 类基线（Qwen2-VL 上在 64 预算时提升可达近 14 分），说明欧氏距离的高鲁棒性使保留策略在极限压缩下更为稳健。
3. **极小观测窗口可以几乎无偿地带来性能收益**：在多个模型/数据集组合上，将窗口从 32 缩到 4 稳定提升性能；窗口设为 1（只留最后一个 token 参与重要性估计）也很有效，这挑战了“最新 token 必须无条件大量保留”的既有假设。
4. **冗余度在各层不均匀，且多样性的贡献存在规律**：重要性和多样性排序的低-中相关表明这两种信号确实互补；
5. **跨层冗余规律**：早期层冗余度高，中间层最低，后段逐渐回升——多样性在中间层作用最突出，可以适配不同层的注意模式。

## 7. 方法或实验设计的亮点

- **诊断很直观**：作者从余弦相似度随层数都在高位、却用 PCA 表明 embedding 分散这两张图并行切入，让“余弦高≠真冗余”的问题能一目了然地被读者感知，并直接为欧氏距离补充提供合理诉求。

- **互补度量的规范组合路线**：论文没有以拍脑袋方式“混用”，而是通过数学分解 \(ECD^2 = \|a\|^2+\|b\|^2 - 2\|a\|\|b\|\cos\theta\) 提供理论依据，说明距离天然结合幅度与方向，使组合更具可解释性。

- **头自适应粒度细分**：在“逐头（per-head）”层面估计冗余度并调控 λ，而不是用全模型单一权重，能更好地适配不同头形状的 attention 模式，较此前全局或层级的处理更细。

- **对现有框架的即插即用设计**：它有意识地只“替换打分函数”，所以论文可以直接把 ECOKV 嵌进 SnapKV/PyramidKV/AdaKV/SparseMM 中做正交验证，保证了复用性和公平对比。

- **附带公开的效率验证**：既有在合成长序列上的 E2E 时间/显存统计，也有在实际 TextVQA 子集上的统计结果，可从系统角度看实际增益。并且在相同条件下反复强调“因为省了窗口，总计算量与纯基线持平/更少”。

- **附带了便于复现的完整算法描述**：补充文件中有类似伪代码的整体联合算法（Algorithm 1），详尽而不含糊。

## 8. 不足与局限性

- **未能从理论上点明最优权重为何是 0.8 / 0.6**：论文以实验得出该默认值，但其正确性可能需要在不同规模的模型或更陌生的语言/视觉场景下重新调试，说明该阈值的选择仍有一定启发式色彩。

- **对观测窗口的机理解释仍停留在经验水平**：论文已经提出可以压缩窗区的证据，但没有给出明确的结构性解释——例如是否与 attention sink、最近 token 的效用函数或生成步态差异相关，使它的普适性有一定未知风险。

- **模型规模类别相对集中在一种量级（7B 级别）**：实验在两模型、同为 7B 规模、相似架构族里进行，对于更大 MLLM（例如 70B 级）或将来的推理时情况（批量解码、投机解码）表现如何，尚待更广的覆盖。

- **长上下文评估维度还可以更完整**：虽然测试了 MP-DocVQA，但主流生态中真正超长视频、超长图文交错、几十万 token 输入的基准（如 LongBench-Video、MileBench 等量级）并未在论文中触及；在更大 KV 规模的极端情形下的收益曲线尚不清楚。

- **对最极端压缩下数值的波动性缺少进一步解释**：例如系统它在很小预算（64）下提升最多，但不同 backbone 的收益却有大幅差异（如对 SparseMM 提升较弱），这种结构差异的潜在诱因并未进一步深挖。

- **需要实际内存调度系统的落地验证**：KV cache 淘汰常与系统层面的分页、重计算以及算子优化交织；论文的效率验证仍停留在 GPU 端整体时间的层面，未描述与 vLLM/SGLang 等主流推理框架的深度结合，其系统层面收益幅度有待确认。

- **运行成本的透明度**：主要结论的算力规模没有被整合成统一的汇总口径（只给 GPU·小时的近似表，未说明用于主实验预算的总额），若需专门二次复现，用户在总开销估算上还是会遇到困难

## 9. 延伸讨论与未来可能方向

- **将“几何互补”推广到其他缓存结构**：本次方法主要作用于 MLLM 的注意力 Key 缓存，而实际上几何度量（尺度敏感距离 + 方向相似度）同样适用于 Value、跨层共享缓存、以及 MoE 专家路由中的 token 选择问题。相比在“打分函数”上原地替换，未来可考虑将这套框架抽象为“缓存选择器”，嵌入更多以 token 为中心的稀疏推理方案中。

- **与训练阶段联合设计的前景**：ECOKV 是推理期即插即用策略，不需要重新训练模型。一个有趣的问题是：若在使用 ECOKV 作为训练时的模拟缓存压缩器，让模型在自监督阶段就学会适应这种几何感知淘汰，是否能进一步提升缓存保留集合的稳定性？这种“训练感知的淘汰”可能会带来超越纯推理侧优化的增益。

- **在线自适应超参数**：当前 α、β 通过离线网格搜索确定，对架构变化不敏感是其优势，但这不代表它在所有分布漂移（如数据域、语言、图像分辨率突变）下都保持最优。未来可以将每层每头的“实际冗余度”与一个轻量在线预测器结合，让权重随输入动态变化，进一步降低人工调参成本。

- **对更细粒度的跨 token 冗余建模**：ECOKV 用单点到质心的距离表示多样性，尚未显式建模 token 两两之间的相关性矩阵。如果以线性代数方式来动态逼近 token 子集的秩或条件数，也许能更精确地逼近“最小信息损失子集”，但代价是更复杂的求解，需要权衡实时性。

- **系统级协同验证的必要性**：论文展示了算子和端到端时延层面的节省，但真正部署到 batch serving 场景还需要与 PagedAttention、prefix caching、推测解码等机制结合。建议后续工作给出一个在 vLLM 或 SGLang 上可复现的 benchmark，才能验证该方法在生产系统的实际吞吐收益，而不仅是单条请求的峰值内存下降。

- **更强的理论支撑**：本质性的疑问仍然存在——为什么最小化到质心的欧氏距离（即保留远离中心的点）能够大概率保留生成所需的信息？这与高维空间的距离集中性、注意力分布的稀疏性有什么关系？若能在理论上建立“被淘汰键对最终回答正确性的误差影响”的近似上界，将使方法的合法性从实验启发式上升为可证明的近似保证，这是较有意义但颇具挑战的方向。

## 10. 总结性评价

ECOKV 通过在级联的 token 选择中引入“欧氏距离 + 余弦相似度”的互补几何信号，结合头自适应的冗余估计和极小的观测窗口，在多个视觉-语言理解任务与四种流行缓存框架上展示了明确的增益，其价值不仅在于指标提升，更在于提醒社区：**高维表征的“冗余性”不能被单一归一化后的余弦距离所概括，尺度信息与各层各向异性的几何结构需要被显式建模**。同时，论文的缺口也相当清晰：阈值的经验性、大规模 / 真实推理系统的验证欠缺、超长上下文基准覆盖不足等，决定了它目前更多是一份高质量的研究起点，而非终端产品中的最终解法。

总体而言，这篇工作在问题诊断的直观性、方法设计的可解释性、实验覆盖的系统性以及与其他框架组合的便利性方面都可圈可点，值得对 token 压缩、推理效率、以及多模态大模型部署感兴趣的读者精读，并可作为后续继续向“更真实的超大模型 + 更完整的系统栈 + 更自适应的选择机制”方向推进的参照系。
