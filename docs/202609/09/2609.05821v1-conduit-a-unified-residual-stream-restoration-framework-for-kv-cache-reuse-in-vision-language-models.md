## 摘要
视觉语言模型（VLM）在面对关于重复出现的视觉内容的新问题时，重用键值（KV）缓存可以避免重新编码昂贵的视觉前缀。然而，当相同的视觉内容在改变的前缀下出现时，精确前缀重用会失效。选择性重计算能够在较小的视觉令牌预算下恢复质量，但前提是正确刷新过时的令牌。原始注意力选择可能会将预算浪费在具有较小值范数代理分数的高注意力令牌上，以及查询无关的图像上。为了解决这些失败模式，我们提出了CONDUIT，一种无需训练的刷新策略，它将单图像和多图像重用统一为残差流恢复。基于范数加权注意力，CONDUIT使用缓存的键查询注意力和可访问的输出前缓存值范数代理对缓存的视觉令牌进行排名，然后在一次全局选择之前应用经验性的图像级相关性放大。对于单图像，系数为1，该规则简化为图像内令牌选择。该方法保留了模型架构和权重，仅在推理时增加了单次查询条件评分过程。在10%的刷新预算下，CONDUIT在三个VLM骨干网络上实现了相应全预填充五数据集平均值的97.0%-99.5%，并在平均性能上领先于预算方法；在MMLongBench-Doc延迟子集上，它使用了全预填充FLOPs的13.5%，并实现了2.99倍的首次令牌时间加速。

## Abstract
Vision-language models (VLMs) often answer new questions about recurring visual content, where reusing the key-value (KV) cache can avoid re-encoding expensive visual prefixes. Exact-prefix reuse, however, fails when the same visual content appears under a changed prefix. Selective recomputation can recover quality under a small visual-token budget, but only when the right stale tokens are refreshed. Raw-attention selection can waste budget on high-attention tokens with small value-norm proxy scores and on query-irrelevant images. To address these failure modes, we propose CONDUIT, a training-free refresh policy that unifies single- and multi-image reuse as residual-stream restoration. Building on norm-weighted attention, CONDUIT ranks cached visual tokens using cached-key query attention and an accessible pre-output cached-value-norm proxy, then applies empirical image-level relevance amplification before one global selection. With one image, the coefficient is one and the rule reduces to intra-image token selection. The method preserves model architecture and weights, adding only a single query-conditioned scoring pass at inference. At a 10% refresh budget, CONDUIT achieves 97.0-99.5% of the corresponding full-prefill five-dataset average across three VLM backbones and leads budgeted methods on average; on the MMLongBench-Doc latency subset, it uses 13.5% of full-prefill FLOPs and achieves a 2.99x time-to-first-token speedup.

## 1. 核心问题与整体含义

- **研究背景**：视觉语言模型（VLM）常需处理“同一视觉内容、不同查询”的任务（如文档问答、多轮视觉对话、检索增强生成等）。由于视觉前缀编码昂贵，业界用 KV 缓存复用避免重复预填充。
- **关键挑战**：
  - 当查询前缀改变后，原缓存的 KV 不再对应精确前缀，直接复用会破坏质量；
  - 选择性重计算可以只刷新少量“陈旧”视觉 token，但**应该刷新哪些 token** 是关键问题；
  - 原始注意力选择有两个失效模式：
    1. 高注意力 token 的“值写回”可能很小（值范数代理分数低），刷新后收益有限；
    2. 多图像场景下，注意力归一化会导致来自“与查询无关图像”的突出 patch 占用全局注意力集，从而浪费预算。
- **整体含义**：CONDUIT 将这些挑战统一为“残差流恢复”问题，用无需训练的方式，在少量刷新预算下恢复接近全预填充的质量，同时大幅节省重复预填充开销。

## 2. 提出的方法论

### 2.1 核心思想

- 将 Transformer 隐状态视为**残差流**：各层从该通道读取、向该通道写入。
- KV 缓存复用下的选择性重计算，等价于恢复残差流中被过期视觉 token“扰动”的部分。
- 提出**范数加权注意力**作为 token 重要性的代理：需要同时考虑当前查询“读”该 token 的强度，以及该 token 自身“写”回残差流的规模。

### 2.2 关键技术细节

- **Token 级吞吐得分**：用缓存的 key 与当前查询计算注意力，再乘以缓存 value 的预输出范数：
  - 多层、多头、多查询位置聚合后平均：
    - `a_t^(l)` = 在评分查询跨度上、各头上平均的缓存 key 查询注意力
    - `score_t = (1/|L|) Σ_l a_t^(l) * ||V_c,t^(l)||_2`
  - 其中 `V_c,t^(l)` 为层 ℓ 中 token t 的拼接多头缓存值向量；
  - 默认对所有 decoder 层取平均。
- **图像级相关性放大**：
  - 定义图像 j 的查询注意力均值 `g_j`，以及跨图像均值 `g_bar`；
  - 图像系数 `c_j = (1−λ) + λ * g_j / g_bar`；
  - 最终得分 `s_hat_t = score_t * c_{π(t)}`，再对所有视觉 token 一次性全局 top-k 选刷新集合；
  - λ ∈ [0,1]，论文实验固定 λ=1；当单图像 K=1 时 `c=1`，退化为单纯 token 内选择。
- **方法本质**：
  - 无需训练、不修改模型结构或权重，只增加一次“查询条件评分前向过程”；
  - 生成一个二进制刷新 mask，仅重算得分最高的视觉 token，其余直接复用缓存。

### 2.3 公式或算法本质（文字描述）

- 输入的视觉 token 集合为 `V`，预算 `k = floor(r*N_vis)`；
- 先运行一次辅助评分：计算各层、各头的缓存 key 注意力与缓存 value 范数；
- 平均得到每 token 得分；
- 对每图像计算平均注意力 `g_j`，并构造图像系数；
- 相乘得到全局得分，按全局 top-k 选择刷新 token；
- 单图时图像系数恒为 1，统一规则涵盖单图与多图。

## 7. 优点

- **统一视角**：把单图像与多图像下的 KV 缓存刷新问题统一成“残差流恢复”，逻辑一致且简洁。

## 8. 不足与局限

- **应用范围有限**：未测试视频、流式观测和长时 agent 工作流；静态图像/文档之外的效果未知。
