## 摘要
长上下文推理在解码过程中会保留不断增长的键值（KV）缓存，这消耗大量GPU内存并可能降低生成吞吐量。这一瓶颈在混合语言模型中依然存在，因为其残差全局注意力层可能主导依赖于上下文的缓存需求。我们研究如何在总KV驻留预算下分配这种状态。我们提出HeadWiseKV，一种无需训练的框架，压缩混合语言模型的残差全局KV缓存，同时保留其原生的局部、循环和线性路径。它为每个物理KV头分配一个静态的多级历史窗口，使得服务前缓存需求可预测。我们将此分配表述为一个受限的运行速率-失真问题，并提出SeqCalib作为HeadWiseKV中的核心策略生成算法。SeqCalib按执行顺序处理层，并将每个决策基于部署时使用的较低层策略进行条件化，从而考虑跨深度的交互。分组缓存运行时将所选策略实现为实际的按头KV驻留，而不是完整缓存上的掩码。我们在四个混合长上下文模型上评估下游质量，并在Qwen3.6-27B上研究物理驻留和服务行为。HeadWiseKV在评估的模型上保持了接近全KV RULER和LoCoMo的质量。在固定模型系统研究中，它在112K上下文长度下将采样峰值设备内存减少了8.59%，并将最大验证成功上下文从114K扩展到161K。

## Abstract
Long-context inference retains a growing key--value (KV) cache during decoding, which consumes substantial GPU memory and can reduce generation throughput. This bottleneck remains in hybrid language models because their residual global-attention layers can dominate context-dependent cache demand. We study how to allocate this state under an aggregate KV-residency budget. We introduce HeadWiseKV, a training-free framework that compresses the residual global KV caches of hybrid language models while preserving their native local, recurrent, and linear paths. It assigns each physical KV head a static, multilevel history window, making cache demand predictable before serving. We formulate this allocation as a restricted operational rate--distortion problem and propose SeqCalib as the core policy-generation algorithm in HeadWiseKV. SeqCalib processes layers in execution order and conditions each decision on the lower-layer policy used at deployment, thereby accounting for interactions across depth. A grouped-cache runtime materializes the selected policy as actual per-head KV residency rather than a mask over a full cache. We evaluate downstream quality across four hybrid long-context models and study physical residency and serving behavior on Qwen3.6-27B. HeadWiseKV retains near-Full-KV RULER and LoCoMo quality across the evaluated models. In the fixed-model systems study, it reduces sampled peak device memory by 8.59\% at a 112K context length and extends the largest verified successful context from 114K to 161K.

## 1. 核心问题与研究动机

- **KV 缓存瓶颈**：长上下文自回归推理中，KV 缓存随上下文长度与并发度增长，大量消耗 GPU 显存，并降低生成吞吐量。这是大模型长上下文服务的核心瓶颈之一。
- **混合模型并未消除瓶颈**：Gemma 2/3、Qwen3-Next、Qwen3.6 等混合语言模型通过局部滑动窗口注意力、循环 Gated-DeltaNet 等路径减少了 KV 缓存压力，但其中残存的全局注意力层仍保留随上下文增长的历史状态，成为新的瓶颈来源。少量残差全局层便可决定长请求能否装入显存。
- **压缩策略的两个关键维度**：
  - 保留策略何时决定（请求前静态决定 vs. 请求时动态决定）；
  - 策略如何实现（物理驻留压缩 vs. 仅逻辑稀疏掩码）。
- **现有方法不足**：请求相关（prompt-dependent）方法（如 Ada-KV、HeadKV、KV-Compress）可针对单条请求选取关键 token，但往往先构建全量缓存再压缩，无法降低 prefill 内存峰值，且需在线打分、索引和 KV 搬运，增加请求时开销。静态方法（如 StreamingLLM、DuoAttention、RazorAttention）虽可预分配内存，但多采用“全历史 vs. 压缩流”的二值切分，粒度过粗，难以适配混合模型中各全局注意力头不同的历史长度需求。
- **核心未解问题**：如何在固定 KV 驻留预算下，为混合语言模型的残差全局注意力头分配细粒度、静态、可预测的多级历史窗口，且分配须考虑跨层相互依赖——较早层的截断会改变后续层接收到的表示。

## 2. 方法论

### 2.1 总体框架：HeadWiseKV

HeadWiseKV 是一个无需训练（training-free）的离线到在线（offline-to-online）流水线，包含三个核心组件：

1. **结构化驻留模型**（定义选择空间与成本）；
2. **SeqCalib**（离线策略生成算法）；
3. **分组缓存运行时**（将策略实现为物理驻留）。

### 2.2 结构化驻留模型

- 仅对**残差全局全注意力层**参与压缩；局部/循环/线性路径保持原样。
- 决策单元是**物理 KV 头**（而非 query 头）；GQA 下同一组 query 头共享同一 KV 头缓存。
- 每个物理 KV 头 (ℓ, h) 被分配一个历史窗口：

  aℓh ∈ W = {w₁, …, w_K, full}

  其中 wk 表示连续的 suffix 长度（如 8K、16K、32K），full 表示完整历史。
- 总存储成本为：

  N_C(a; p_KV) = Σ_(ℓ,h)∈U n_ℓh,C(a_ℓh; p_KV)

  其中 n_ℓh,C 将保留 token 数、KV 维度、量化精度转换为名义存储字节数。
- 归一化速率（normalized rate）：

  R_C(a; p_KV) = N_C(a; p_KV) / N_C(a_F; p_KV)

  即压缩后 KV 存储占全量 KV 存储的比例。
- 理想目标被形式化为受限运行速率–失真问题：

  D* (β) = min_{a: R_C(a) ≤ β} E_x[δ(a, x)]

但直接求解 (K+1)^|U| 空间不可行，故提出 SeqCalib。

### 2.3 SeqCalib：前缀条件化的顺序校准算法

**核心思想**：按层执行顺序处理，每一层的决策都基于**部署时实际使用的低层策略**进行条件化，从而计入跨深度交互。

**具体流程**（对应论文图 2 中间面板）：

1. 对层 ℓ，冻结其之前所有已确定的较低层策略 a_{<ℓ}；
2. 在该前缀下，以完整历史（full）trace 一遍层 ℓ 的 Q/K/V 张量；
3. 对每个候选窗口 w ∈ W，从同一 trace 中重放 restricted suffix，并重新归一化注意力权重；
4. 计算候选窗口 attention 输出与条件化全历史 attention 输出的平均余弦相似度：

   Ŝ_ℓh(w | a_{<ℓ}) = (1/|I_ℓh|) Σ cos( o^(w), o^(full) )

5. 为每个物理 KV 头选择满足相似度阈值 τ 的**最低成本窗口**：

   â_ℓh,τ = argmin_{w∈W} { n_ℓh,C(w) : Ŝ_ℓh(w | â_{<ℓ,τ}) ≥ τ }

- 由于 full ∈ W，每步必然可行；算法有限终止。
- 该算法是**逐层条件最优**（fixed-prefix minimality），而非全局联合最优。
- 在有限阈值网格 T = (τ₁, …, τ_G) 上独立运行，得到多组“策略–速率–最低相似度”记录；给定预算 β 时，按确定性字典序规则选择记录：先最大化最低平均相似度 Φ，再最小化速率 β，最后取最小网格索引 g。

### 2.4 分组缓存运行时

- 运行时一次性加载策略矩阵，不随请求内容或在线注意力分数变化。
- 每个可配置 KV 头仅分配其对应窗口长度的物理缓存，而非在全量缓存上施加掩码。
- 同一窗口长度的头共享组配置，但 KV 内容相互独立；GQA 组内 query 头读取其映射的物理 KV 头切片，随后拼接经原始门控和输出投影。
- 原生局部/循环层路径不变。
- 校准与部署共享同一层–头索引、窗口语义和注意力缩放；部署前通过全窗口重建检查保证执行契约兼容性。

## 6. 主要结论与发现

- **HeadWiseKV 是唯一在 68.95% 匹配 KV 保留率下持续接近 Full-KV 质量的方法**：RULER 从 100.00 仅降至 99.65（−0.35），LoCoMo 保持 94.55 不变。
- 在 Agent 任务（τ²-Bench Airline/Retail）上 HeadWiseKV 甚至**超过 Full-KV**（79.50 vs. 77.00；82.24 vs. 82.02），说明按头细粒度分配可能在滤除干扰历史的同时保留敏感头所需长程上下文，帮助模型聚焦任务相关内容。
- **物理内存确实降低**：Qwen3.6-27B 在 112K 上下文下采样峰值显存降低 8.59%（−2.01 GiB）。
- **上下文容量显著扩展**：最大验证成功上下文从 Full-KV 的 114K 拓展至 HeadWiseKV 的 161K（1.41×）。
- Decode 吞吐在共有成功上下文内保持接近 Full-KV（0.954–1.017×），prefill 吞吐上下文相关（0.810–1.092×）。
- **质量对压缩水平不敏感**：Qwen3.6-27B 上保留率从 96.00% 到 68.95% 的质量几乎不变，说明全局 KV 头中存在大量异构冗余，可被安全去除。
- **跨模型迁移在检索任务上稳定**：4 个模型 RULER 下降不超过 0.61 分；LoCoMo 上迁移不够均匀，提示部署时需在目标工作负载上验证最终操作点。

## 7. 优点

1. **定位精准**：专门针对混合语言模型的残差全局注意力层，保留局部/循环/线性路径，问题定义清晰且实用。
2. **静态可预测**：策略在请求前固定，缓存需求可预测；运行时按物理驻留分配而非掩码，真正降低 prefill 峰值。
3. **细粒度多级分配**：突破二值全历史/压缩流的粒度限制，支持 8K/16K/32K/full 等多级连续历史窗口，表达能力更强。
4. **前缀条件化校准（SeqCalib）处理跨层依赖**：认识到较早层截断会改变后续层输入，校准在部署时实际使用的低层策略下进行——这是简洁且富有洞察力的设计。
5. **有理论支撑**：将有限分配建模为运行速率–失真问题，提供了固定前缀最优性命题和校准误差界。
6. **无需训练、无架构改动**：对模型权重和结构零侵入、易于部署；在线推理无请求时开销。
7. **评测多维度**：同时覆盖任务质量、物理显存、吞吐、上下文容量与模型迁移，且对系统测量与质量评估作了清晰分层（matched cohort vs. absolute campaign），实验报告较规范严谨。
8. **对质量/系统分离报告的意识良好**：明确区分匹配队列比率与其他基线绝对测量，降低误导性结论风险。

## 8. 不足与局限

1. **静态策略的固有限制**：无法恢复已被驱逐的证据，无法自适应典型长程依赖异常的请求；对需从隔离历史位置取证的 prompt 可能失效。
2. **非全局最优**：SeqCalib 的逐层条件选择是 stage-wise 最优而非全局联合最优；高层层的策略可能在全局视角下并非最佳。
3. **校准指标为替代指标**：用 attention 输出的余弦相似度近似端到端质量下降（Eq. 8 替代 Eq. 5 的端到端失真），局部高相似度不等于全局输出保真。
4. **模型/工作负载变化需重新验证与校准**：更换模型、缓存格式（p_KV）、目标上下文或大幅偏移的新工作负载时，策略需重新校准和任务级验证。
