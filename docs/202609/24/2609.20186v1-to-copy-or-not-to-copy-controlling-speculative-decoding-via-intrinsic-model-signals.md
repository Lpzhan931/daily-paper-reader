## 摘要
推测解码（SD）显著加速了大语言模型（LLM）推理，然而现有方法面临两种草稿策略之间的根本性权衡：神经草稿与基于上下文的复制。神经草稿（如 EAGLE3）在各种文本设置下提供稳健性能，而基于复制的方法在复制密集型场景中通过更快生成候选，并利用长重复片段实现近乎完美的推测，从而获得更高加速。我们分析现有基于复制的方法，发现它们容易受到偶然重复的影响：此时表面层面的 n-gram 重叠并不反映结构性的复制意图，导致假阳性触发，最终降低吞吐量。我们提出 SwitchSD，一个自适应框架，将复制视为 LLM 的潜在控制信号。通过在目标模型的内部表示上训练轻量级探针，SwitchSD 以高精度（AUC > 0.99）识别真正的复制意图。这使系统能够在神经草稿（如 EAGLE）与基于上下文的复制之间动态切换。我们在 Llama 和 Qwen 系列上的结果表明，相比 EAGLE3 等最先进基线，吞吐量提升最高可达 15%，有效地将复制从一种嘈杂的启发式方法转变为一种有原则、模型感知的解码范式。

## Abstract
Speculative Decoding (SD) has significantly accelerated Large Language Model (LLM) inference, yet existing approaches face a fundamental tradeoff between two drafting strategies: neural drafting and context-based copying. Neural drafts (e.g., EAGLE3) provide robust performance across diverse text settings, while copy-based methods achieve higher speedups in copy-intensive regimes by generating candidates faster and exploiting long repetition spans for near-perfect speculation. We analyze existing copy-based methods and find that they are prone to accidental repetitions where surface-level n-gram overlap does not reflect a structural intent to copy, leading to false-positive triggers that ultimately degrade throughput. We introduce SwitchSD, an adaptive framework that treats copying as a latent control signal of the LLM. By training lightweight probes on the target model's internal representations, SwitchSD identifies genuine copy-intent with high precision (AUC > 0.99). This allows the system to dynamically switch between neural drafting (e.g., EAGLE) and context-based copying. Our results across Llama and Qwen families demonstrate throughput gains of up to 15% over state-of-the-art baselines like EAGLE3, effectively turning copying from a noisy heuristic into a principled, model-aware decoding regime.

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：大语言模型（LLM）的自回归解码是推理延迟的主要瓶颈，在测试时扩展（如长链思维 CoT）场景下尤为突出。推测解码（Speculative Decoding, SD）通过轻量草稿模型并行提议候选 token、再由目标模型并行验证，已成为主流加速方案。
- **两条草稿路线及其权衡**：
  - **神经草稿**（如 EAGLE3）：在各种文本场景下稳健，但草稿策略对所有 token 一视同仁，未利用文本结构。
  - **基于上下文的复制**（如 PLD、CopySpec）：在复制密集型场景中更快，可利用长重复片段实现近乎完美的推测。
- **核心问题**：现有复制方法依赖**表层 n-gram 重叠**作为触发条件，存在一个脆弱假设——"n-gram 重叠等于结构性复制意图"。实际上，许多重复是**偶然重复**（accidental repetition），例如数学推理中反复出现的变量名 "n"，此时模型真实意图是生成新内容，复制草稿会被立即拒绝，造成"推测税"（speculation tax），反而拖累吞吐。
- **关键洞察**：作者提出，复制并非表层现象，而是由模型内部表示中编码的**潜在控制信号**（latent control signal）驱动。在推理密集型任务中，超过 50% 的复制尝试属于假阳性触发。
- **整体含义**：SwitchSD 首次将"复制"从噪声启发式转变为基于模型内在表示的原则化、模型感知的解码机制，为自适应 SD 提供了"白盒"信号驱动的控制范式。

## 2. 方法论

### 2.1 核心思想
- 将复制意图检测建模为**二分类任务**，在目标模型的隐藏表示上训练轻量级线性探针，以高精度识别真正的"复制模式"，从而在神经草稿与上下文复制之间动态切换。

### 2.2 关键技术细节

- **复制意图探针（Copy-Intent Probe）**：
  - **标签构造**：采用保守代理标签——若某 token 位置属于一段至少 `n_train = 5` 个 token 的逐字重复序列且该序列在上下文中先前出现过，则标记为复制模式（Y=1），否则为非复制（Y=0）。长逐字片段仅作为"潜在复制模式"的实用指示器，而非复制意图的完整定义。
  - **探针架构**：严格的线性投影（无偏置项）：`p_ℓ(j) = σ(w_ℓ^T H_ℓ(j))`，其中 `H_ℓ(j)` 为第 ℓ 层第 j 个 token 的隐藏表示。使用二元交叉熵损失 + L2 正则化训练。极简架构保证预测仅由潜空间中的向量方向决定，计算开销可忽略。
  - **经验发现**：在自注意力子层之后提取的表示训练的探针，持续优于 MLP 子层之后的表示，印证了复制意图主要由注意力驱动的归纳头（induction heads）电路承载。

- **层与阈值选择**：
  - 使用贪心 F1 最大化在验证集上选择单一最优层，通常位于**中间层**（如 Llama-3.1-8B 的第 14 层）。
  - 在同一验证集上通过最大化 F1 固定决策阈值 τ（约 0.4）。

- **SwitchSD 的决策规则**：
  - 复制推测启用当且仅当：`P_R(H_ℓ(i)) ≥ τ` **且** 当前 token 结尾的 κ-gram（κ=5）在上下文中至少匹配一次先前出现。
  - 若探针激活但无 κ-gram 匹配，则回退到神经草稿。仅当"内部意图"与"外部结构"同时对齐时才触发复制。

- **复制式推测生成**：
  - 检索最多 W 个候选续写（每段长度 D），按**近因（recency）**排序，优先最近的语言模式，无需额外草稿模型参数。
  - **块三角注意力（Block-Triangular Attention）**：将 W 个候选依次拼接在锚点位置之后，注意力掩码使每个候选可关注完整原始前缀及自身内部 token，但与其他候选隔离，从而在**单次目标模型前向传播**中并行验证所有候选，选取最长验证续写。

- **非复制场景**：回退到传统 SD 机制，实验同时验证了 vanilla 推测采样（SPS）和 EAGLE3，证明"编排器优先"设计对具体神经草稿模型具有正交性。

- **KV Cache 同步**：采用**惰性传播（lazy propagation）**——被接受的 token 在下一次前向传播中通过草稿模型，将同步成本与下一步草稿合并摊销，保持目标与草稿缓存一致且延迟开销极小。

### 2.3 算法流程（文字说明）
1. 目标模型完成一步验证，得到最终接受 token；
2. 判断当前上下文是否存在包含该 token 的重复；
3. 若不存在 → 使用神经草稿；
4. 若存在 → 查询探针：若探针判定为复制意图（≥τ）且 κ-gram 匹配 → 从上下文复制草稿；否则 → 回退神经草稿。

## 6. 主要结论与发现

- **吞吐量提升**：SwitchSD 在全部 9 组配置中取得最高吞吐量，平均加速比 HumanEval 2.31×、Math500 2.03×、CNN/DM 1.83×；相比 EAGLE3 最高提升 **15%**。
- **探针精度极高**：复制意图识别 AUC > 0.99，呈现近乎完美的线性可分性，说明复制意图是残差流中的一阶特征。
- **"少即是多"（Less is More）**：相比 CopySpec，SwitchSD 触发复制的频率更低但接受长度显著更长（如 HumanEval 上 5.88 vs. 1.83），证明其增益来自**精度而非频率**。
- **解码模式近乎完全分离**：探针激活时，30.0% 的轨迹达到最大推测长度 20 token，而未激活时仅 4.7%，约 6.3× 的差距，证实探针捕获的是内部复制意图信号而非表层重复。
- **优于统计探索方法**：BanditSpec 因"探索惩罚"在 Llama-3.3-70B Math500 上几乎崩溃（0.99×，91% 过度选择复制但接受长度仅 0.28），而 SwitchSD 达到 1.48×，且更选择性（仅 8.9% 触发）却高产（4.45 平均接受长度）。
- **对最优 lookahead γ 的影响**：将高概率复制 token 分流后，神经草稿面对的平均 token 更难，最优 γ 从 7 降至 5（Llama-3.3-70B），实现更精细的资源分配。
- **架构无关性**：在 SPS 与 EAGLE3 两种不同 SD 架构上均保持最优，证明信号感知编排与草稿模型类型正交。

## 7. 优点

- **方法创新性**：首次将"复制"从表层启发式提升为基于模型内部表示的潜在控制信号，提出"白盒"信号探测范式，与现有 SD 方法正交且互补。
- **极低开销**：线性探针架构简单，仅依赖单 token 单时间步的隐藏表示，计算开销可忽略；训练数据由模型自身生成，任务无关。
- **机制可解释性**：将探针性能与注意力驱动的归纳头电路相联系，层/子层消融结果与机制解释一致，增强了可信度。
- **工程完备性**：块三角注意力实现单次前向并行验证 W 个候选，惰性传播解决 KV cache 同步问题，工程细节考虑周全。
- **实验说服力**：多模型族、多任务、多基线、多温度、多架构的验证矩阵较为完整；"少即是多"与模式分离分析直观有力。
- **鲁棒性**：在高温采样（T=1.0）下仍保持 1.54× 加速并优于 EAGLE3。

## 8. 不足与局限

- **弱监督标签的固有局限**：复制意图无直接真值标注，使用 ≥5 token 逐字重复作为代理标签，存在探针学到"表层重复"而非真正"复制意图"的风险。作者虽以表示瓶颈、数据质量、正则化三方面辩护，但仍属间接论证。
- **训练数据依赖合成生成**：CopyDiversity 由 Claude Sonnet 生成 1000 条 prompt，虽覆盖 17 种 prompt 类型，但合成数据的分布可能无法完全代表真实部署场景。
- **温度升高时收益递减**：T=1.0 时加速比降至 1.54×，高随机性削弱重复频率，方法优势缩小。
- **算力信息不完整**：未报告 GPU 数量、总计算量与探针训练成本，难以评估实际部署门槛。
- **白盒访问要求**：方法需要访问目标模型的中间隐藏表示，对仅提供 API 的黑盒部署场景不适用。
- **模型规模覆盖有限**：主要在 8B 与 70B 规模验证，未涉及更小或更大模型（如 1B 以下或 100B 以上），可扩展性未知。
- **消融覆盖不均衡**：层/子层、阈值、训练数据消融主要基于 Llama-3.1-8B，跨模型族的一致性验证不足。
- **应用限制**：在重复性弱的任务（如 CNN/DailyMail）增益较有限（约 2.1%–5.4% 触发复制），方法价值主要集中在编程、数学等结构化且复制密集的领域。
