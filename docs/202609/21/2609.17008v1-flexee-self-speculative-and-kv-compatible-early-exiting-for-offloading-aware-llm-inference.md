## 摘要
大语言模型（LLM）推理通常同时受计算和内存约束，尤其是在基于卸载的部署中，模型权重在自回归解码过程中跨内存层级传输。在这种设置下，减少执行的层数可以降低每 token 延迟，同时避免代价高昂的权重移动。受此观察启发，我们提出 FlexEE，一个面向资源受限且基于卸载的 LLM 推理的提前退出框架。FlexEE 通过逐层退出监督以实现可靠的中间层预测、基于 Top-K 局部词汇表的自推测解码以进行低成本退出决策，以及动态隐藏状态管理以实现 KV 缓存正确且内存感知的执行，使提前退出在 LLM 解码中变得实用。在生成任务和下游任务上，FlexEE 能够以最小的精度下降实现高效提前退出，在 0%/50% 权重卸载下，分别在 Llama2-7B 和 Llama3-8B 上实现最高 1.27×/3.16× 和 1.25×/2.83× 的端到端加速。

## Abstract
Large language model (LLM) inference is often constrained by both computation and memory, especially in offloading-based deployments where model weights are transferred across memory hierarchies during autoregressive decoding. In this setting, reducing the number of executed layers can lower per-token latency while also avoiding costly weight movement. Motivated by this observation, we present FlexEE, an early exiting framework for resource-constrained and offloading-based LLM inference. FlexEE makes early exiting practical for LLM decoding through layer-wise exit supervision for reliable intermediate-layer prediction, self-speculative decoding over a Top-K local vocabulary for low-cost exit decisions, and dynamic hidden state management for KV-cache-correct and memory-aware execution. Across generative and downstream tasks, FlexEE enables efficient early exit with minimal accuracy degradation, delivering up to 1.27$\times$/3.16$\times$ and 1.25$\times$/2.83$\times$ end-to-end speedups on Llama2-7B and Llama3-8B under 0\%/50\% weight offloading, respectively.

# FlexEE 论文中文总结

## 1. 核心问题与整体含义（研究动机与背景）

- **研究背景**：Transformer 架构的大语言模型（LLM）参数规模持续膨胀，导致在资源受限环境（如边缘设备）中部署困难，模型参数常超出片上内存容量。
- **主流方案**：将部分层参数卸载（offloading）到片外内存，推理时按需加载。这使推理瓶颈从计算转移到片外内存访问，因此加速的关键在于减少参数加载的数量和频率。
- **核心洞察**：早退（early exiting）通过动态在中间层终止计算，可减少执行的层数，在卸载式推理中同时降低计算量与权重搬运开销。
- **三大挑战**：
  - **挑战 1（算法层）**：LLM 中间层隐藏状态语义可解码性弱，直接对现成模型早退会严重损害生成质量；且需将隐藏状态投影到完整词表空间（如 Llama2-7B 的 32K 词表），开销高昂。
  - **挑战 2（系统层）**：早退中断了后续层 KV 缓存的构建，导致未来 token 的 KV 缓存缺失或不一致。
  - **挑战 3（卸载场景）**：已有解决方案（状态复制、KV 复制、KV 驱逐）要么仍需加载后续层权重，要么损害语义一致性，均无法真正发挥卸载场景下早退的优势。

## 2. 方法论：核心思想与关键技术

FlexEE 是一个基于**系统–算法协同设计**的卸载感知早退框架，核心由三部分组成：

### 2.1 逐层早退监督（Layer-wise Early-Exit Supervision）
- 在预训练阶段将共享 LM head 连接到多个关键 Transformer 层，用统一语言建模目标对齐中间层表示与最终层解码能力，不引入额外推理开销。
- 训练目标（式 1）：对每层隐藏表示 $g(x_{l+1})$ 计算交叉熵损失 $J_{CE}$，并以归一化层权 $\tilde{e}(t,l)$ 控制监督从深层逐步向浅层转移。
- 效果：显著降低中间层的熵与 WikiText 困惑度（PPL），同时几乎不影响最终层性能。

### 2.2 基于自推测的轻量级早退预测器
- **退出特征选择**：通过离线统计（30 万 WikiText token）比较 Top Prob、Gap、Top Logit、Prob Shift 四种特征。最终选用 **Top Prob 与 Gap**，因其层间阈值平滑、覆盖率高、跨模型一致性强。
- **自推测层设计**：选取一个中间层作为 self-speculation layer，保留其 Top-K token 作为局部候选词表（Llama2：K=30；Llama3：K=80），后续早退层仅在该紧凑候选集上做 LM head 投影。
- **退出判定**：每层计算局部 Top-1 概率与局部 gap，二者同时超过离线预计算的逐层阈值时才触发退出。阈值在局部候选集下搜索，保证校准数据集上早退准确率 > 0.99（τ=0.99）。
- **关键统计依据**：Top-N 覆盖概率 $H_l(N)$ 随 N 快速提升，近似误差 $E_l(N)$ 快速下降，N=30 是较好权衡点。

### 2.3 动态隐藏状态管理（KV 兼容）
- **核心机制**：当某 token 在中间层退出时，保留其退出层隐藏状态；在生成下一个 token、前向传播到达退出层之后的第一层时，将保留的隐藏状态与当前 token 表示联合参与计算；该层 KV 缓存更新完成后立即清除缓存隐藏状态以回收内存。
- **优势**：
  - 不强制跨层复制 KV 缓存，保持跨 token 语义连续性；
  - 仅在必要时引入额外隐藏状态参与，避免对所有剩余层进行冗余 KV 重建；
  - 在系统层面，早退后无需更新后续层 KV 缓存，从而**无需加载后续层权重**，非常适合卸载式推理。

### 2.4 计算开销分析
- FlexEE 每 token 额外 FLOPs ≈ 0.264 GFLOPs（Llama2-7B，B=1, K=30, n=16, m=24.9）。
- 相比 AdaInfer（约 8.13 GFLOPs，30.74×）和 SpecEE（约 0.666 GFLOPs，2.52×），预测开销显著更低。

## 6. 主要结论与发现

- **加速效果**：
  - 0% 卸载：Llama2-7B 1.27×、Llama2-13B 1.25×、Llama3-8B 1.25×
  - 50% 卸载：Llama2-7B 3.16×、Llama2-13B 2.67×、Llama3-8B 2.83×

  - 相比 HF 基线最高 1.18× 加速
- **精度保持**：多数任务上性能与 Dense 解码接近甚至持平，PPL 下降可控。
- **自适应退出**：token 退出层呈分布特征，大量 token 在 self-spec 层后不久退出，困难 token 延后至更深层或最终层。
- **自推测优势**：Top-K 局部词表在更早退出的同时保持与全词表相当的性能，且吞吐更高，在卸载场景下优势更明显。
- **KV 策略优势**：动态隐藏状态管理在长序列下 PPL 更低、延迟更小，优于 KV Eviction、KV Copy、State Copy。
- **批量推理**：batch size 增大时早退收益递减，但 FlexEE 目标场景（on-device、交互式、batch=1）受益最大。

## 7. 优点

- **系统–算法协同设计**：同时解决算法层（中间层可解码性弱、全词表投影开销高）与系统层（KV 缓存冲突、权重卸载）问题，设计针对性强。
- **训练零额外推理开销**：逐层监督在预训练阶段完成，推理时不增加额外模块。
- **预测开销极低**：相比 AdaInfer 降低约 30×、相比 SpecEE 降低约 2.5× 的额外 FLOPs。
- **KV 兼容性设计巧妙**：动态隐藏状态管理避免了强制 KV 复制或重建，既保持语义一致性又避免加载后续层权重，是卸载场景的关键创新。
- **实验覆盖全面**：跨 4 个模型、约 15 个数据集、4 种卸载比例、多 batch size，并包含开放式生成质量评估。
- **离线阈值校准泛化性好**：跨数据集阈值余弦相似度 0.997–0.999，说明校准方案稳健。

## 8. 不足与局限

- **依赖预训练监督**：FlexEE 基于带逐层早退监督的模型（LayerSkip checkpoint），对未做该监督的现成模型效果不确定，通用性受限。
- **场景局限**：主要受益于小 batch、内存受限/卸载式服务；大 batch 下收益明显减弱，异构退出深度降低有效跳过机会。
- **卸载场景边际收益递减**：从 50% 到 75% 卸载时加速增益递减，因早退多发生在深层，无法充分利用额外卸载的层。
- **校准集单一**：阈值仅用 WikiText 估计，虽验证一致性，但对领域外文本的鲁棒性仍需更多验证。
- **未报告训练算力**：论文未明确说明层监督训练/微调的算力开销与时长，可复现性受一定影响。
- **风险继承**：早退可能改变输出分布，继承基座模型的幻觉、偏见、隐私泄露等风险，高风险领域需谨慎部署。
- **硬件平台单一**：实验仅在单张 RTX PRO 6000 + Xeon CPU 上完成，未验证多 GPU、其他边缘设备或异构硬件上的表现。
