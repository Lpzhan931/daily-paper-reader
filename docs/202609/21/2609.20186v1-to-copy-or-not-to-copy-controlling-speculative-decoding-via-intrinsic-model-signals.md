## 摘要
推测解码（SD）显著加速了大语言模型（LLM）推理，但现有方法面临两种草稿策略之间的根本性权衡：神经草稿与基于上下文的复制。神经草稿（如 EAGLE3）在各种文本场景下提供稳健性能，而基于复制的方法在复制密集型场景中通过更快生成候选，并利用长重复片段实现近乎完美的推测，从而获得更高加速比。我们分析了现有基于复制的方法，发现它们容易受到偶然重复的影响：表面级的 n-gram 重叠并不反映结构性的复制意图，导致假阳性触发，最终降低吞吐量。我们提出 SwitchSD，一种自适应框架，将复制视为 LLM 的潜在控制信号。通过在目标模型的内部表示上训练轻量级探针，SwitchSD 以高精度（AUC > 0.99）识别真正的复制意图。这使系统能够在神经草稿（如 EAGLE）与基于上下文的复制之间动态切换。我们在 Llama 和 Qwen 系列上的结果表明，相较于 EAGLE3 等最先进基线，吞吐量提升最高可达 15%，有效地将复制从一种含噪启发式方法转变为有原则、模型感知的解码范式。

## Abstract
Speculative Decoding (SD) has significantly accelerated Large Language Model (LLM) inference, yet existing approaches face a fundamental tradeoff between two drafting strategies: neural drafting and context-based copying. Neural drafts (e.g., EAGLE3) provide robust performance across diverse text settings, while copy-based methods achieve higher speedups in copy-intensive regimes by generating candidates faster and exploiting long repetition spans for near-perfect speculation. We analyze existing copy-based methods and find that they are prone to accidental repetitions where surface-level n-gram overlap does not reflect a structural intent to copy, leading to false-positive triggers that ultimately degrade throughput. We introduce SwitchSD, an adaptive framework that treats copying as a latent control signal of the LLM. By training lightweight probes on the target model's internal representations, SwitchSD identifies genuine copy-intent with high precision (AUC > 0.99). This allows the system to dynamically switch between neural drafting (e.g., EAGLE) and context-based copying. Our results across Llama and Qwen families demonstrate throughput gains of up to 15% over state-of-the-art baselines like EAGLE3, effectively turning copying from a noisy heuristic into a principled, model-aware decoding regime.

## 1. 核心问题与研究动机

- **背景**：自回归解码是 LLM 推理的主要瓶颈，推测解码（SD）通过轻量草稿模型提出候选、目标模型并行验证来加速。
- **两类草稿策略的权衡**：
  - **神经草稿**（如 EAGLE3）：跨场景稳健，但存在模型与计算开销；
  - **上下文复制**（如 Prompt Lookup Decoding、CopySpec）：在复制密集场景中直接从上下文检索 n-gram 续写，速度快、接受长度可接近完美。
- **核心痛点**：现有复制类方法依赖**表层 n-gram 重叠**作为触发条件，无法区分"真实复制意图"与"偶然重复"。例如数学推理中反复出现的变量名 `n` 造成的假阳性触发，会产生 0 接受长度的"投机税"（speculation tax），反而拖慢吞吐。作者统计发现推理类任务中这类假阳性占全部复制尝试的 50% 以上。
- **核心论点**：复制不是表层文本现象，而是目标模型内部表征中编码的**潜在控制信号（latent copy-intent）**；应以"白盒"方式探测内部状态，而非依赖启发式或统计黑盒。

## 2. 方法论（SwitchSD）

### 2.1 核心思想
- 将复制意图检测建模为**二分类任务**，在目标模型某一中间层的隐状态上训练**线性探针**，作为高精度门控，动态在"上下文复制草稿"与"神经草稿（EAGLE3 或 SPS）"之间切换。

### 2.2 复制意图探针的训练
- **弱监督标签**：某 token 位置若属于在上下文中此前出现过的、长度 ≥ 5 的逐字重复片段，则标为 copy-mode（Y=1），否则为 0；该阈值用于过滤偶发短 n-gram 重叠。
- **探针数据集 CopyDiversity**：用 Claude Sonnet 生成 1000 条具有多样重复结构的提示（代码样板、模板化语言等），再由目标模型生成补全，抽取隐状态 H 与标签配对，得到数十万 token 级样本；正式划分为 800 训练 / 200 验证，覆盖 17 类提示（重复制 10.6%、中复制 11.7%、轻/无复制 77.7%）。
- **探针结构**：严格线性、无偏置，`p_ℓ(j) = σ(w_ℓᵀ H_j^(ℓ))`，用二元交叉熵 + L2 正则训练；结构极简以保证开销可忽略，且只依赖单个 token 的隐向量方向。
- **层与阈值选择**：逐层训练后，用留出验证集上的 F1 贪心选择最优层（Llama-3.1-8B 为第 14 层，属中间层）与阈值 τ（约 0.4）。实验发现 **attention 子层后**的表示显著优于 MLP 子层，呼应 induction head 假说。

### 2.3 决策规则与草稿生成
- **双条件触发**：仅当 `PR(H_i) ≥ τ` **且** 当前 token 结尾的 κ-gram（κ=5）在上下文中存在先前匹配时，才启用复制草稿；若探针激活但无 κ-gram 匹配，则回退神经草稿。
- **复制候选生成**：从上下文中检索最多 W 条候选续写（每条长度 D），按**最近出现优先**排序，无需额外草稿模型参数。
- **非复制场景**：委托给传统 SD，可插拔地使用 SPS 或 EAGLE3，体现"编排优先"设计。

### 2.4 并行验证与 KV 缓存同步
- **块三角注意力掩码**：将 W 条候选顺序拼接在锚点后，每个候选只能注意原前缀与自身内部 token，彼此隔离，从而在**单次目标模型前向**中并行验证全部候选，取最长通过验证的续写。
- **KV 缓存同步**：采用**惰性传播**——复制路径接受后，把已接受 token 在下一步前向中顺带过一遍草稿模型，使同步开销被摊薄，保证正确性不受影响。

- **内部信号优于统计探索**：BanditSpec 作为黑盒优化器存在探索惩罚，在 Llama-3.3-70B 的 Math500 上甚至退化到 0.99×（91% 迭代选择复制，MAL 仅 0.28）；SwitchSD 仅触发 8.9% 却达 1.48× 加速、MAL 4.45。

- **温度鲁棒性**：T=0.0 时 2.57×，T=1.0 时仍保持 1.54×，全程优于 EAGLE3。

## 7. 优点

- **范式创新**：把"复制"从表层启发式提升为模型内在潜在状态，将 SD 的策略选择问题转化为内部表征的可分性问题，属"白盒编排"思路，与既有 SD 方法正交、可叠加。
- **设计极简高效**：线性探针 + 无偏置，计算开销可忽略；复制候选直接取自上下文，无额外草稿参数。
- **工程细节完备**：块三角注意力实现单次前向并行验证多候选；惰性 KV 传播摊薄同步成本，兼顾正确性保证。
- **机制解释性强**：不仅报告吞吐，还给出接受长度条件分布、层/子层消融

、ROC/AUC 与阈值分析，使“探针为何有效”具备可解释证据。

- **对“投机税”有直接缓解**：双条件触发与内部信号门控减少假阳性复制，提升 MAL 与吞吐，切中复制类 SD 的核心失效模式。

## 8. 局限与不足

- **白盒依赖**：方法需要访问目标模型中间层隐状态，无法直接用于仅提供 API 的闭源模型；这限制了在商业黑盒服务中的落地。
- **弱监督标签的边界**：以“上下文中此前出现过的、长度 ≥ 5 的逐字重复片段”定义 copy-mode，仍属表层启发式。对于语义复制、改写式复用、跨语言/跨格式迁移等“意图复制但表面不重复”的情形，标签可能漏标；反之，某些长 n-gram 偶然重复仍可能被标为正类。
- **探针训练数据的分布风险**：CopyDiversity 由 Claude Sonnet 合成，虽覆盖 17 类重复结构，但与真实用户请求、领域语料之间可能存在分布差异。论文未系统报告跨域泛化实验，探针在真实服务流量中的鲁棒性仍需验证。
- **逐模型校准成本**：最优层、阈值 τ 均通过留出验证集贪心选择，换模型或换微调版本后可能需要重新扫描层与阈值；部署时存在额外校准流程。
- **超参敏感性与实现复杂度**：κ=5、W、D、τ 等超参共同影响触发率与候选质量；块三角注意力掩码、惰性 KV 传播虽设计精巧，但增加了实现与调试复杂度。
- **实验统计严谨性不足**：主要结果为单次运行，未报告方差、置信区间或显著性检验；主实验多在 T=0 贪婪解码下进行，对随机采样、温度扰动下的稳定性虽有消融，但覆盖仍有限。
- **算力与复现信息不完整**：仅说明使用 H100、单次运行 45 分钟至 17 小时，未给出 GPU 数量、总卡时、探针训练成本与完整超参，复现规模不够透明。
- **场景覆盖有限**：评测集中于代码、数学、摘要三类任务，未覆盖多模态、长上下文、多轮对话、工具调用、结构化生成等更复杂场景。
- **归因需谨慎**：SwitchSD 的收益是叠加在 EAGLE3/SPS 之上的增量收益，部分提升来自“编排层 + 更强基线”的组合，需区分探针本身贡献与工程实现贡献。

## 9. 启示与展望

- **白盒编排范式可扩展**：若内部隐状态能稳定区分“复制意图”，也可能用于区分其他解码策略适用场景，如检索增强草稿、工具调用草稿、缓存复用草稿、结构化模板草稿等。
- **从表层重复走向语义复制**：未来可引入更语义化的弱监督信号、对比学习或跨层探针，识别改写、抽象复用与跨语言复制，减少对逐字 n-gram 的依赖。
- **在线自适应与校准**：可研究在线更新阈值、按任务/请求动态校准探针，或结合轻量 bandit 与内部信号形成混合门控，降低分布漂移风险。
- **与 KV 缓存和调度协同**：复制路径天然适合与前缀缓存、上下文复用、批处理调度结合；惰性 KV 同步可进一步与连续批处理、PagedAttention 等系统优化融合。
- **动态候选与超参策略**：W、D、κ、γ 可按探针置信度、上下文重复密度、神经草稿负载动态调整，而非固定超参。
- **真实负载评估**：后续工作应在生产级请求分布、混合任务、多租户场景中评估吞吐、尾延迟、成本与鲁棒性。
