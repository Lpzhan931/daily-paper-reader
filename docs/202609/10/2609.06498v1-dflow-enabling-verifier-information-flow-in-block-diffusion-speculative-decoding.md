## 摘要
块扩散投机解码通过并行提出一个未来 token 块，并通过目标模型的一次前向传播对其进行验证，从而提升 LLM 推理效率。然而，现有方法仅保留被接受的前缀并丢弃被拒绝的后缀，使得花费在这些位置上的计算无法惠及后续起草轮次，并迫使起草器反复从头重建未来 token 的表示。我们观察到，拒绝仅决定一个提出的 token 能否被提交，而被拒绝位置处的验证器表示仍可为后续预测提供有用信息。基于这一观察，我们提出 DFlow，一个简单而有效的框架，使验证器信息能够在起草轮次之间流动。DFlow 复用目标验证器针对被拒绝后缀产生的隐藏状态来指导后续起草，而无需额外的目标计算。为了有效学习跨起草轮次的这种信息流，我们引入一种自条件训练策略，将来自较早预测的验证器表示反馈到后续预测中。在 Qwen3 模型上跨多种基准的实验表明，DFlow 在草稿质量和接受长度上持续优于 DFlash。

## Abstract
Block diffusion speculative decoding improves LLM inference efficiency by proposing a block of future tokens in parallel and verifying them with a single forward pass through the target model. However, existing methods retain only the accepted prefix and discard the rejected suffix, preventing the computation spent on these positions from benefiting subsequent drafting rounds and forcing the drafter to repeatedly reconstruct representations for future tokens from scratch. We observe that rejection only determines whether a proposed token can be committed, while the verifier representations at rejected positions can still provide useful information for subsequent predictions. Based on this observation, we propose DFlow, a simple yet effective framework that enables verifier information to flow across drafting rounds. DFlow reuses the hidden states produced by the target verifier for the rejected suffix to guide subsequent drafting without additional target computation. To effectively learn this information flow across drafting rounds, we introduce a self-condition train strategy that feeds verifier representations from earlier predictions back into subsequent predictions. Experiments on Qwen3 models across diverse benchmarks demonstrate that DFlow consistently improves draft quality and acceptance length over DFlash.

# DFlow 论文总结

## 1. 核心问题与研究背景

- **背景**：LLM 自回归解码本质串行，是推理主要瓶颈。投机解码用轻量 drafter 提出多个未来 token，再由目标模型并行验证，实现无损加速。
- **块扩散投机解码**（如 DFlash）进一步并行预测整个未来 token 块，大幅降低起草的串行开销，但实际加速比高度依赖每轮的接受长度，即草稿质量。
- **核心问题**：现有方法在精确匹配验证后只提交「接受前缀 + bonus token」，把「拒绝后缀」及其中间表示全部丢弃。
  - 下一轮草拟窗口中与拒绝后缀重叠的位置被重置为 mask embedding，从头重建表示。
  - 论文将这一现象命名为**跨轮次的信息不连续（information discontinuity）**：拒绝边界不仅是 token 提交边界，还成了不必要的信息边界。
- **关键观察**：拒绝只是对离散 token 能否提交的判定，并不代表该位置的验证器隐藏状态无价值。验证器隐藏状态是目标模型在因果计算中产生的连续上下文表示，即使对应离散提案被拒，仍可能包含关于后续续写的有效信息。
- **研究问题**：能否把已经为拒绝位置算出的验证器信息带到下一轮草拟中，而不增加额外目标模型前向？

## 2. 方法论

### 2.1 核心思想
- **DFlow**：把目标验证器在拒绝后缀位置产生的隐藏状态，中继（relay）到下一轮草拟的对应重叠位置，作为辅助信息指导预测，使这些位置继承上一轮验证信息而非从零重建。
- 所有复用表示均来自验证阶段已有的前向计算，**不引入额外目标模型前向**。

### 2.2 关键技术细节
- **验证器表示对齐（Verifier Representation Alignment）**
  - 复用 DFlash 已有的目标上下文特征投影：将选定目标层（浅到深采样若干层）在拒绝后缀上的隐藏状态拼接，经共享投影矩阵 `W_c` + RMSNorm 得到可复用的验证器表示 `h_i`。
  - **因果错位校正**：目标模型是 next-token 预测（位置 i 的隐藏状态预测 i+1 的 token），而 drafter 是 mask token 预测（每个 mask 位置预测同位置 token）。因此需对验证器表示做位移对齐，使二者对应同一被预测 token。
  - 因复用 DFlash 的投影，仅多处理少量可复用位置，开销极小。

- **拒绝条件化草稿初始化（Reject Conditioned Draft Initialization）**
  - 验证时的上下文（拒绝后缀跟在首个被拒提案 `ŷ^(r)_{a_r+1}` 之后）与下一轮上下文（从目标修正 bonus token `b^(r)` 继续）不同，需按边界变化校正。
  - 用轻量 MLP 融合「bonus token 嵌入、首个被拒提案嵌入、验证器表示 `h_i`」，生成通道级缩放向量 `β_i` 和加性校正向量 `γ_i`：
    `[β_i ; γ_i] = MLP( [E(b^(r)) ; E(ŷ^(r)_{a_r+1}) ; h_i] )`
  - 下一轮输入为：`x_i^(r+1) = E_mask + β_i ⊙ LN(h_i) + γ_i`
  - 该增强输入仅在存在有效可复用验证器表示的位置使用；首轮或上一轮无拒绝后缀时，仍用标准 mask embedding。

- **多轮自条件训练（Multi-Round Self-Conditioned Training）**
  - **动机**：DFlash 训练每轮独立、均从 mask embedding 初始化，而 DFlow 推理时后续轮依赖前序验证器表示，存在训练-推理错配。
  - **Multi-Round Rollout**：把单轮训练扩展为连续多轮草拟-验证展开。初始轮为标准 DFlash mask 预测（保持基础能力并产生提案）；提案经冻结目标模型验证，提取拒绝后缀验证器表示并中继到下一轮；后续轮执行拒绝条件化预测。所有轮共享同一 drafter 参数，默认展开 `k=2` 个拒绝条件化轮。
  - **Trajectory-Guided Transition**：用草稿提案与预计算目标轨迹精确匹配来决定下一轮起点（首个不匹配处的目标 token 作为 bonus token），使各轮对齐同一目标轨迹并复用目标上下文；轨迹仅用于确定轮次转换，中继的验证器信息仍绑定当前轮实际提案。
  - **损失**：`L_DFlow = L(0) + Σ_{q=1}^{k} L(q)`，各轮损失求和后联合反传，优化同一共享参数；沿用 DFlash 的位置指数衰减交叉熵。目标模型全程冻结，验证器表示与轮次转换均从计算图 detach，避免梯度流经目标验证或跨轮传播。

- **低并发接受长度**：在 Qwen3-1.7B/4B/8B 上，DFlow 在全部六个基准、两种解码温度下均优于 DFlash 与 EAGLE-3，平均接受长度 τ 取得一致的相对提升；提升在采样解码（T=1）下同样成立，说明中继验证器信息对随机采样场景亦有效，而非仅对贪心解码有利。
- **消融验证贡献可分离**：
  - DFlash 基线 → DFlash + 多轮自条件训练：接受长度已有提升，说明多轮展开训练本身缓解了训练-推理错配。
  - 再加入验证器表示中继（即完整 DFlow）：进一步提升，表明「拒绝后缀的连续验证信息」确实携带超越单纯多轮训练的额外有效信号，而非仅是训练轮次增加带来的收益。

- **运行时开销**：单轮开销分解显示，draft 与 verify 仍占主导，relay 阶段因复用已有前向的隐藏状态、仅增加少量投影与 MLP 计算，占比很小，符合「不引入额外目标模型前向」的设计目标。

- **与 Domino 的兼容性**：DFlow 可与 Domino 叠加使用并取得进一步加速，且实验表明 online rollout 对维持该组合的收益是必要的，验证了方法在更强 drafter 之上的可组合性。

## 7. 主要贡献与创新点

1. **问题刻画**：明确提出「跨轮次信息不连续」这一被忽视的现象——拒绝边界被不必要地当作信息边界，导致每轮从 mask 重建表示，造成验证阶段已算出的信息被浪费。
2. **方法创新**：提出验证器表示中继机制，将拒绝后缀上的目标模型隐藏状态经因果错位校正与拒绝条件化校正后，作为下一轮草拟的辅助初始化信号，且完全复用已有前向、零额外目标模型计算。
3. **训练策略**：设计多轮自条件训练与 trajectory-guided transition，将单轮独立训练扩展为多轮连续展开，缓解训练-推理错配，并保证各轮对齐同一目标轨迹。
4. **实证价值**：在多模型规模、多任务类型、两种解码温度及真实高并发服务场景下验证有效性，并证明与 Domino 等更强 drafter 的可组合性。

## 8. 局限性与可改进方向

- **模型家族单一**：仅在 Qwen3 系列上验证，跨模型家族（如 Llama、DeepSeek 等）的泛化性未知。
- **训练成本未披露**：多轮 rollout 训练相对单轮训练的实际额外开销（显存、时间、样本效率）未量化，影响对其训练性价比的判断。
- **超参数敏感性缺失**：验证器层的选择、投影配置、展开轮数 `k`、MLP 结构等关键设计未做敏感性分析。
- **统计严谨性**：未报告多次运行的方差或显著性检验，收益的稳健性缺少统计支撑。
- **基线对等性**：EAGLE-3 使用官方 checkpoint，与自训方法在训练数据与预算上不完全对等，可能影响比较的公平性解读。
- **中继信息的下界**：论文未分析在何种拒绝比例、何种序列结构下中继收益最大，缺少对适用边界的理论或经验刻画。

## 9. 总体评价

DFlow 的核心洞见简洁而有力：投机解码中的「拒绝」只是离散 token 的提交判定，并不等于该位置的连续表示失去价值。通过把验证阶段已然算出的隐藏状态跨轮中继，论文以极低运行时开销换取了草拟质量的提升，并配合多轮自条件训练解决了由此引入的训练-推理错配。方法设计上对因果错位、上下文边界变化、梯度隔离等细节处理得当，消融实验能够清晰分离各组件贡献，实验覆盖面在同类工作中较为充分。

其主要短板在于验证范围的单一性（仅 Qwen3）、训练开销与超参数敏感性的信息缺失，以及统计层面的严谨性不足。总体而言，这是一项问题刻画清晰、方法轻量且工程可行性较强的贡献，若能在跨模型家族泛化与训练成本量化上进一步补强，说服力会更为完整。
