## 摘要
在边缘设备上部署大型语言模型（LLM）通常依赖模型压缩或拆分推理。然而，压缩会损害推理能力，而拆分推理则面临严重的广域网（WAN）通信瓶颈。边云推测解码作为一种有前景的替代方案，利用边缘小模型草拟 token 交由云端验证。但在波动剧烈的广域网上，不可避免的预测拒绝会引发灾难性的流水线停顿和全网回滚，抵消协同收益。为解决这一问题，我们提出 AceSpec，一种非对称边云协同框架。AceSpec 利用未饱和的边缘算力主动构建概率状态缓存，有效地将全网流水线冲刷转化为 O(1) 本地内存查找。为节省带宽，它采用非对称通信协议，在上行链路传输极简主链索引，在下行链路传输紧凑稀疏分布。此外，我们引入一种网络感知的、拉格朗日优化的资源分配策略，动态最大化本地缓存命中率。评估表明，AceSpec 实现了高达 3.52 倍的吞吐量加速，并展现出卓越的带宽免疫性，即使在严重受限的 50 Kbps 广域网条件下也能维持接近峰值的推理性能。

## Abstract
Deploying Large Language Models (LLMs) on edge devices typically relies on model compression or split inference. However, compression degrades reasoning capabilities, while split inference suffers from severe Wide Area Network (WAN) communication bottlenecks. Edge-cloud speculative decoding emerges as a promising alternative, leveraging an edge small model to draft tokens for cloud verification. Yet, over volatile WANs, inevitable prediction rejections trigger catastrophic pipeline stalls and network-wide rollbacks, neutralizing collaborative gains. To overcome this, we propose AceSpec, an asymmetric edge-cloud collaborative framework. AceSpec utilizes un-saturated edge compute to proactively construct a probabilistic state cache, effectively transforming network-wide pipeline flushes into $\mathcal{O}(1)$ local memory lookups. To preserve bandwidth, it employs an asymmetric communication protocol that transmits minimal main-chain indices uplink and compact sparse distributions downlink. Furthermore, we introduce a network-aware, Lagrangian-optimized resource allocation strategy that dynamically maximizes the local cache hit rate. Evaluations demonstrate that AceSpec achieves up to a 3.52$\times$ throughput speedup and exhibits exceptional bandwidth immunity, sustaining near-peak inference performance even under severely constrained 50 Kbps WAN conditions.

## 一、核心问题与研究动机

- **背景**：在边缘设备上原生部署 LLM 是支撑实时推理应用的必要路径，但资源受限节点难以独立承载大模型。
- **既有路线及其缺陷**：
  - **模型压缩**：显著损害模型的推理与生成能力；
  - **拆分推理（Split Inference）**：需在广域网（WAN）上传输大规模中间隐状态张量，形成"通信墙"，低带宽高延迟下加速收益被通信开销抵消；
  - **推测解码（Speculative Decoding）**：将通信载荷从连续稠密张量压缩为离散 token 序列，是更有前景的替代方案，但其原始设计假设节点内/高速互联（NVLink、PCIe）下通信开销可忽略。
- **核心矛盾**：在 WAN 上直接部署推测解码时，同步"停等"（stop-and-wait）依赖造成严重通信瓶颈。近年异步流水线工作（PicoSpec、PipeSD、E2-SCI）虽部分隐藏 RTT，但仍存在关键问题：
  - **PicoSpec**：单链异步流水线，支持随机 nucleus 采样，但草稿与目标模型分布差异导致频繁预测拒绝，单链范式下引发流水线停顿与全网回滚惩罚；
  - **PipeSD / E2-SCI**：为规避上行星 vocab 级概率分布饱和带宽，退化为确定性贪婪解码，丧失生成多样性；PipeSD 的批量传输对早期拒绝极脆弱（一个误预测使整批作废），E2-SCI 依赖频繁控制信令、协议开销大；
  - 二者还常需额外微调或辅助网络，通用性与部署灵活性受限。
- **论文目标**：提出一种**免训练（training-free）、通用、原生支持随机 nucleus 采样**的边云协同推测解码框架，把"灾难性 WAN 回滚"转化为本地 O(1) 内存查找。

## 二、方法论

### 1. 核心思想
- **非对称协同**：把计算与决策负担尽量转移到边缘侧可用的并行算力上，从而最小化 WAN 上交换的数据量。
- **以算力换网络**：利用边缘在云验证窗口（T_cloud）内的空闲算力，主动构建**多分支概率 token 树缓存**，用本地冗余计算覆盖可能的拒绝结果，把网络级流水线冲刷变为本地内存查询。
- **系统构成**：
  - 边缘客户端：轻量草稿 SLM + 三大子系统（Tree-based Drafter、Probabilistic KV Cache Manager、Local Resampler）；
  - 云端：目标 LLM 执行高度并行的 Verify Loop，仅作为"评估者"校验提案并返回失败处的概率分布。

### 2. 关键技术细节
- **非对称通信协议**：
  - 上行：只发送主链（main chain）token 索引（标量数组），而非整棵多分支树；
  - 下行：拒绝时返回拒绝位置索引 + 该位置的**稀疏化（sparsified）目标概率分布**，而非全 vocab 分布。
- **非对称树构建（Asymmetric Branch Caching）**：
  - 在每个潜在拒绝深度 k ∈ {0,…,γ−1}，剔除主链 token 后，从残差概率质量中取 Top-F_k 候选构建替代分支；
  - 使用**定制 Tree Attention Mask** 将 N 个分支打包进单次并行前向（避免 N 次串行前向），掩码含三个子块：Shared Prefix Block（共享已验证上下文）、Main-Path Branch Block（限制分支只关注主草稿前 s_j 个 token）、Suffix Diagonal Block（对角线隔离，每个投机 token 只关注自身祖先序列），使多分支扩展在 **O(1) wall-clock** 内完成。
- **O(1) 状态恢复（Algorithm 1）**：
  1. 草稿并压缩概率 → 异步发送 ⟨主链、压缩分布、γ⟩；
  2. 并行构建多分支树 T；
  3. 等待并接收 (π, P̂_target)；
  4. 本地重采样得到 x_resampled，组成验证结果 w = (π, x_resampled)；
  5. 若 w ∈ dom(T)，直接以 w 为查询键命中本地缓存，取预计算的下一状态，并执行 COMPACT_KV（内存 scatter/gather 对齐命中分支 KV 条目、作废未选分支）；
  6. 未命中则执行 ROLLBACK_KV 与顺序重草稿（作为惩罚路径保留）。

### 3. 理论分析要点
- 基线周期：T_naive = T_draft(γ) + RTT + T_verify；期望接受长度 E[L] = (1−α^γ)/(1−α)；
- 回滚惩罚：E[Penalty] = (1−α^γ)·(RTT + T_redraft(γ))，实际吞吐 R_pipe = E[L] / (T_ideal + E[Penalty])；
- 加速比下界：S ≥ S_ideal / [1 + (1 − P_hit(T))·ρ]，其中 ρ = T_bubble / T_ideal 为回滚惩罚比，把物理限制与算法性能分离。

### 4. 两级约束优化（核心理论贡献）
- **网络感知预算（Network-Aware Budgeting）**：要求 T_tree_draft(B) ≤ RTT(t) + T_verify，从而
  **B*(t) = min{ B_max, ⌊T⁻¹_tree_draft(RTT(t) + T_verify)⌋ }**，即网络差时扩大树、网络好时收缩树以省能耗。
- **任务感知形状分配（Task-Aware Shape Allocation）**：命中概率 p(F_k) = α + (1−α)R(F_k)，整体命中率 P_hit = ∏ p(F_k)；
  优化目标 max Σ log(α + (1−α)R(F_k))，约束 Σ F_k ≤ B_alloc(t) = B*(t) − γ。
- **拉格朗日求解**：考虑自回归验证的顺序依赖，用前缀存活概率 α^k 加权目标；利用 LLM 词表分布的长尾幂律 R(F_k) ≈ 1 − c·F_k^(−β)，构造拉格朗日函数并求偏导为零，得
  **F*_k = Φ(λ)·η^k，η = α^(1/(β+1)) ∈ (0,1)**；
  代入预算约束的等比数列求和得闭式解：
  **F*_k = B_alloc(t)·[(1−η)/(1−η^γ)]·η^k**。
- **结论性洞见**：预算不应均匀分配，而应按几何衰减向浅层（k=0,1）倾斜——因为到达深层的概率指数级下降，早期拒绝才是流水线最脆弱的环节。

## 七、理论贡献的价值与局限

**价值**：
- 把"树形状/分支预算分配"这一此前依赖启发式或均匀扩展的设计问题，转化为一个**带预算约束的凸/可分离优化问题**，并用词表长尾幂律给出闭式几何衰减解 F*_k ∝ η^k，具有清晰的可解释性——即"预算向浅层倾斜"不仅是经验技巧，而是最优解的结构性推论。
- **网络感知预算 B*(t)** 把"何时扩树"与"网络状况"解耦为可计算判据，直接解释了 Qwen-1.7B/HumanEval 的反常退化（T_tree_draft > RTT + T_verify），使论文的负面结果与理论自洽，是较扎实的贡献。
- **O(1) 状态恢复**把 WAN 上的回滚惩罚（RTT + 重草稿）转换为本地内存查找 + KV scatter/gather，是"以算力换网络"的核心落地机制。

**局限**：
- 理论推导依赖若干理想化假设：词表分布长尾幂律 R(F_k) ≈ 1 − c·F_k^(−β) 中 β 视为常数、各深度命中事件近似独立（P_hit = ∏p(F_k)），而实际自回归验证中分支命中存在强相关性，理论最优与实际最优之间可能存在偏差。
- 拉格朗日求解用前缀存活概率 α^k 加权，隐含 α 在树内各分支一致，忽略了非均匀分支对后续接受概率的动态影响。
- 未给出命中率、加速比与**内存占用**的联合界：多分支树缓存的 KV 条目随 B 线性（甚至超线性）增长，边缘设备 32GB 显存下的可行 B 上界未做理论刻画，O(1) 查找的"内存代价"未纳入优化目标。

## 八、总体评价

**优点**：

2. **方法设计有层次**：非对称通信协议（上行标量主链、下行稀疏分布）+ 非对称树构建（定制 Tree Attention Mask 单次前向）+ O(1) 状态恢复，三者环环相扣，工程与理论结合度高。
3. **保持训练无关与随机采样**：无需微调或辅助网络，且原生支持 nucleus 采样，相比 PipeSD/E2-SCI 退化为贪婪解码，通用性与实用性更强。
4. **负面结果诚实**：对 0.98× 的反常案例给出机制性归因而非回避，并用理论约束反向验证，学术态度值得肯定。

**不足**：
1. **对比公平性存疑**：未与点名的 PipeSD、E2-SCI 直接对比，最关键的 SOTA 基线缺失，削弱"state-of-the-art"论断；同时各方法的批大小、并发配置未充分披露。
2. **评测环境理想化**：`tc` 模拟 WAN 难以刻画真实网络的抖动、丢包与异构路由；单一 Jetson 节点、两种模型族限制了泛化性结论。
3. **内存/能耗维度缺失**：论文以"省能耗"为卖点却无能耗实测；多分支 KV 缓存的内存开销未量化，而这是边缘部署的硬约束。
4. **缓存未命中路径代价高**：ROLLBACK_KV + 顺序重草稿作为惩罚路径保留，在命中率不足时性能可能骤降，文中未系统报告未命中率及其对长尾延迟（P99 TTFT）的影响。

**适用场景与延伸**：该方法最契合**网络受限（中低带宽、高 RTT）、边缘有一定空闲算力、且需保持随机采样多样性**的边云协同推理；对超小带宽（<25 Kbps）或边缘算力极弱（无法承载多分支树）的场景收益递减。未来可探索：多边缘节点协同扩树、将内存/能耗纳入预算优化、在真实跨地域 WAN 上验证、以及把几何衰减分配推广到非平稳词表分布（如代码/数学等领域自适应 β）。
