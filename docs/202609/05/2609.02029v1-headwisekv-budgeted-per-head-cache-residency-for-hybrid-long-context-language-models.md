## 摘要
长上下文推理在解码过程中会保留不断增长的键值（KV）缓存，这消耗大量GPU内存并可能降低生成吞吐量。这一瓶颈在混合语言模型中依然存在，因为其残差全局注意力层可能主导与上下文相关的缓存需求。我们研究如何在总KV驻留预算下分配这种状态。我们引入HeadWiseKV，一种无需训练的框架，它在保留混合语言模型原生的局部、循环和线性路径的同时，压缩其残差全局KV缓存。它为每个物理KV头分配一个静态的多级历史窗口，使得缓存需求在服务之前即可预测。我们将此分配问题形式化为受限的操作速率-失真问题，并提出SeqCalib作为HeadWiseKV中的核心策略生成算法。SeqCalib按执行顺序处理层，并根据部署时使用的较低层策略对每个决策进行条件化，从而解释跨深度的交互。分组缓存运行时将所选策略实现为实际的每头KV驻留，而不是完整缓存上的掩码。我们在四个混合长上下文模型上评估下游质量，并在Qwen3.6-27B上研究物理驻留和服务行为。HeadWiseKV在评估的模型中保持了接近全KV的RULER和LoCoMo质量。在固定模型系统研究中，它在112K上下文长度下将采样峰值设备内存减少了8.59%，并将最大验证成功上下文从114K扩展到161K。

## Abstract
Long-context inference retains a growing key--value (KV) cache during decoding, which consumes substantial GPU memory and can reduce generation throughput. This bottleneck remains in hybrid language models because their residual global-attention layers can dominate context-dependent cache demand. We study how to allocate this state under an aggregate KV-residency budget. We introduce HeadWiseKV, a training-free framework that compresses the residual global KV caches of hybrid language models while preserving their native local, recurrent, and linear paths. It assigns each physical KV head a static, multilevel history window, making cache demand predictable before serving. We formulate this allocation as a restricted operational rate--distortion problem and propose SeqCalib as the core policy-generation algorithm in HeadWiseKV. SeqCalib processes layers in execution order and conditions each decision on the lower-layer policy used at deployment, thereby accounting for interactions across depth. A grouped-cache runtime materializes the selected policy as actual per-head KV residency rather than a mask over a full cache. We evaluate downstream quality across four hybrid long-context models and study physical residency and serving behavior on Qwen3.6-27B. HeadWiseKV retains near-Full-KV RULER and LoCoMo quality across the evaluated models. In the fixed-model systems study, it reduces sampled peak device memory by 8.59\% at a 112K context length and extends the largest verified successful context from 114K to 161K.

## 1. 核心问题与研究动机

- 长上下文自回归推理中，KV 缓存随上下文长度和并发数增长，成为显存占用与吞吐瓶颈。即便在混合架构模型（如局部注意力 + 循环/线性注意力）中，少量残余的全局注意力层仍会保留完整历史，使 KV 瓶颈被“转移”而非“消除”。
- 已有 KV 压缩方法存在两类局限：
  - **动态/请求相关方法**（AdaKV、HeadKV、KV-Compress 等）能按需保留关键证据，但常以预填充时的完整缓存为基础做掩码或后置压缩，未必降低实际峰值显存，且引入在线评分、索引、搬运开销。
  - **静态方法**（StreamingLLM、DuoAttention、RazorAttention 等）在请求到达前固定容量，内存行为可预测，但多采用“全量 vs 压缩”的二元划分或固定 sink+recent 策略，粒度较粗，难以适配混合模型中不同全局注意力头对历史长度的差异化需求。
- HeadWiseKV 的核心主张：将 KV 压缩重新定义为**静态、逐物理注意力头、多级历史窗口的物理驻留分配**问题。它放弃逐请求的 token 选择，以换取“预填充前已知、且真正落地为物理存储”的可预测内存收益。

## 2. 方法论

### 2.1 结构化驻留模型

- 决策单元是“物理 KV 头”（而非 query 头）。GQA 下多个 query 头共享同一个 KV 头。
- 每个物理 KV 头 (ℓ, h) 分配一个窗口 aℓh ∈ W = {w₁, …, w_K, full}，其中 wk 表示保留最近的连续 wk 个 token。
- 存储成本定义为名义 KV 存储：nℓh,C(w) = r_C(w) × (每 token 字节数)，其中 r_C(w) = min(w, C)，归一化压缩率为：
  - R_C(a) = N_C(a) / N_C(a_F)，即压缩后全局 KV 成本与全量 KV 成本之比。
- 理想目标被写成受预算 β 约束的**操作速率–失真问题**：在 R_C(a) ≤ β 下最小化压缩模型与全 KV 模型的端到端输出失真。但搜索空间为 (K+1)^|U|，不可直接求解。

### 2.2 SeqCalib：前缀条件下的逐层校准

- 按层执行顺序处理，**冻结已选定的下层策略**后，再校准当前层。
- 对每个要校准的层：先用 full history 对该层 trace 一次 Q/K/V 张量；随后对每个候选窗口 w 从同一份 trace 中“重放”，只保留 w 对应的 key/value 后缀并重新归一化 attention，得到候选注意力输出。
- 相似度指标：候选输出与“同一前缀条件下的 full-history 输出”之间的 stabilized cosine，平均到每个物理 KV 头对应的校准样本、query 位置和 GQA query 头上。
- 选择规则：在满足平均相似度 ≥ τ 的候选中，选择名义成本最低的历史长度。由于 full ∈ W，每步必有可行解。
- 关键性质与声明：
  - 该算法是给定已实现前缀条件下的**逐层最小成本**选择，而非全局联合最优；
  - 通过将早前层的截断纳入条件，SeqCalib 显式建模“下层截断会改变上层表示”的跨层耦合；
  - 在多个 τ 值上独立运行得到“τ 网格策略库”，再按预算 β 用确定性的字典序规则（最大最低头相似度 → 最小压缩率 → 最小网格索引）选出部署策略。

### 2.3 物理缓存运行时

- 策略矩阵在服务开始时加载一次，不依赖请求内容或在线注意力分数。
- 实现方式为**分组物理 KV 缓存**：按“窗口类型”分组分配实际 K/V 存储；每个可配置 head 只读写分配给它的 K/V 切片，而不是在全量缓存上加逻辑掩码。
- 原生局部/循环注意力路径保持不变；GQA query 头读取共享物理 KV 头，输出经原有拼接、门控和输出投影完成。
- 因此，策略直接决定预填充前
