## 摘要
大型语言模型（LLMs）在处理长上下文任务方面展现了强大的能力，但由于巨大的内存需求和推理延迟，处理如此长的上下文仍然具有挑战性。在这项工作中，我们发现某些注意力头在其注意力模式中表现出序列一致性，并且可以通过基于变异系数的算法持续识别这种一致性。受此观察启发，我们提出了CateKV，一种混合KV缓存方法，它仅为一致性头保留关键的token信息，从而减少KV缓存大小和计算开销，同时在自适应头中保留大部分KV对以确保高准确性。我们展示了我们算法的独特特性及其与现有加速方法的扩展。在长上下文基准上的全面评估表明，在保持与全注意力相当的准确性的同时，CateKV在单样本输入中减少了高达2.72倍的内存使用，并将解码速度提升了2.18倍，在批量场景中将吞吐量提高了3.96倍。

## Abstract
Large language models (LLMs) have demonstrated strong capabilities in handling long-context tasks, but processing such long contexts remains challenging due to the substantial memory requirements and inference latency. In this work, we discover that certain attention heads exhibit sequential consistency in their attention patterns, which can be persistently identified using a coefficient-of-variation-based algorithm. Inspired by this observation, we propose CateKV, a hybrid KV cache method that retains only critical token information for consistent heads, thereby reducing KV cache size and computational overhead, while preserving the majority of KV pairs in adaptive heads to ensure high accuracy. We show the unique characteristics of our algorithm and its extension with existing acceleration methods. Comprehensive evaluations on long-context benchmarks show that, while maintaining accuracy comparable to full attention, CateKV reduces memory usage by up to $2.72\times$ and accelerates decoding by $2.18\times$ in single-sample inputs, and boosts throughput by $3.96\times$ in batch scenarios.

## 1. 论文的核心问题与整体含义

- **研究动机**：大语言模型在长上下文任务中表现出色，但随着输入长度增加，KV 缓存带来的显存占用和推理延迟迅速增长，成为制约推理效率的主要瓶颈。例如，使用 Llama-3-8B-Instruct-262k 模型时，上下文从 1K 扩展到 1M，推理延迟增加超过 3000 倍。
- **现有方法的不足**：
  - **KV 驱逐方法**（如 StreamingLLM、SnapKV、PyramidKV）通过丢弃 KV 对减少缓存规模，但容易丢失关键信息，导致精度明显下降。
  - **KV 检索方法**（如 Quest、ShadowKV）保留全部 KV，虽精度较高，却无法缓解高内存占用问题，限制了批处理吞吐量。
  - **头级分类方法**（如 DuoAttention、MInference）虽考虑了头部异构性，但未能充分利用预填充阶段与解码阶段之间的关联。
- **核心发现**：论文首次系统性地观察到，部分注意力头在预填充和解码阶段表现出**序列一致性**（sequential consistency）——即在解码全过程中始终关注同一小部分关键 token；而另一类注意力头则动态变化，需要较宽的注意力范围。这种一致性可用于指导解码阶段的 KV 缓存压缩。

## 2. 论文提出的方法论

### 2.1 核心思想：混合 KV 缓存策略

CateKV 将注意力头划分为两类：

- **一致性头（Consistent Heads）**：注意力模式稳定，始终聚焦于少量关键 token，只需保留少数关键 KV 对即可。
- **自适应头（Adaptive Heads）**：注意力分布随解码步变化，需要保留大部分（乃至全部）KV 对以保证精度。

通过对两类头分别采取不同的缓存策略，CateKV 在保持精度的同时，大幅降低 KV 缓存大小与注意力计算量。

### 2.2 关键技术细节

- **观察窗口**：在预填充阶段，仅使用倒数 `Lobs` 个 query token（窗口大小为 64）与中间部分键（排除开头的 `Linit` 和结尾的 `Lrec` token）构造观察矩阵 A，压缩计算开销。
- **CV 评分**：基于变异系数（Coefficient of Variation）设计评分函数。先将观察矩阵行向量按分位数阈值二值化，统计每个 token 被识别为关键的次数（向量 C），再计算 C 的变异系数作为该注意力头的得分。
- **头部分类**：
  - 通过参考数据集对所有头部计算 CV 得分，得到全局头部类型。
  - 用 `score > Γ(r)`（r 为自适应头比例）判为一致性头，否则为自适应头。
  - 实验发现头部分类结果在不同样本间高度稳定（重叠率 >80%），故可在模型层面静态确定每个头的类型，避免动态分类带来的内存管理负担。
- **Token 选择**：将 token 的频次向量 C 按块大小（chunk size=8）做 BlockMax 处理，再取 top-k 关键 KV 对：
  - 对一致性头：分配较小的稀疏预算（如 2048 个 token，约占 1.56%）。
  - 对自适应头：按保留比例 η（通常为 1.0，即保留全部）进行缓存，也可与查询感知检索（如 Quest/ShadowKV）结合。
- **理论分析**：用 Rademacher 复杂度给出了头部分类和 token 保留精度的概率下界，指出分类准确率 P_head、预算控制以及评分排序质量 λ 是影响最坏情况精度的三个关键因素。

### 2.3 兼容性设计

CateKV 可无缝集成到预填充加速（如 MInference）与检索式 KV 方法（如 Quest、ShadowKV），并作为其缓存压缩插件使用。

## 3. 实验设计

### 3.1 数据集 / Benchmark

- **RULER**：共 12 个合成任务（检索、多跳、推理等），主要测试 128K 上下文，也延伸至 8K~256K。
- **LongBench**：覆盖 6 大类别、21 个任务，选取长度超过 4096 token 的样本进行评测。
- **Needle in A Haystack (NIAH)**：极长上下文检索任务，测试范围 20K~1M token（Llama-3 模型）。

### 3.2 评测模型

- LLaMA-3-8B-Instruct-1048K
- Phi-3-Mini-128K
- Llama-3.1-8B
- Yi-9B-200K
- Qwen2.5-7B
- 更大模型：Qwen2.5-32B、Yi-34B-200K、Phi-4-14B

### 3.3 对比方法

- **KV 驱逐**：StreamingLLM、SnapKV、PyramidKV
- **KV 检索**：Quest、ShadowKV
- **头部级分类**：Duoattention
- 与预填充加速方法 MInference 也进行了集成对比。

### 3.4 主要结果

- **RULER-128K**：在一致缓存大小（41%）下，CateKV 平均准确率优于所有基线，接近全注意力表现（如 Llama-3：84.61 vs 84.10；Yi：65.76 vs 64.52）。
- **LongBench**：缓存降至 42% 时，五个模型平均精度下降不超过 0.3%；与 Quest/ShadowKV 集成时，在相同计算预算下精度损失小于 0.2%。
- **NIAH**：Llama-3 在 20K~1M 范围内保持与全注意力相当的高检索率。
- **与 Duoattention 对比**：Duoattention 在低比例的检索头（<0.3）下显著退化；CateKV 即使自适应头降到 0.1 仍接近全注意力性能。将 CateKV 引入 Duoattention 的 streaming 头部分可大幅提升后者性能。
- **与 MInference 集成**：RULER 8K~256K 上无性能退化甚至略有提升。

## 6. 论文的主要结论与发现

- 注意力头中普遍存在**序列一致性**现象：一致性头在预填充和解码阶段均关注固定关键 token，且这一模式在不同模型、不同层均存在，可被稳定识别。
- 基于此提出的 **CateKV** 是一种即插即用的混合 KV 缓存加速方法，将头部分类为一致性头与自适应头，分别采用“仅保留关键 KV”与“保留大部分 KV”策略，兼顾显存节省与精度。
- 与全注意力相比，CateKV 在保证精度基本持平的前提下：
  - 单样本显存占用降低最高 2.72×；
  - 解码延迟降低最高 2.18×；
  - 批量推理吞吐量提升最高 3.96×。
- 与 Duoattention、Quest、ShadowKV、MInference 等方法兼容良好，可进一步强化现有加速策略。

3. **缺乏统计分析**：结果未报告多次运行的标准差或置信区间，无法判断某些精度差异是否显著。
