## 摘要
投机解码通过使用草稿模型生成候选词元，并由目标模型在单次前向传播中验证，从而加速大型语言模型的推理。验证过程是顺序进行的，从首次拒绝位置起丢弃所有后续位置，然而现有的草稿训练依赖于对目标模型的词元级模仿，并使用固定的逐位置权重，这既不反映验证过程的顺序性，也不反映其丢弃特性。我们引入了验证感知训练（VAT），这是一个即插即用的框架，它在每个训练步骤模拟验证过程，并将产生的接受与拒绝模式转化为监督信号。VAT包含两个组件：（i）验证头，一个轻量级的联合训练二元分类器，用于监督草稿模型判断每个位置是否能通过顺序验证；（ii）验证自适应权重，它取代了固定的权重调度，在每次样本的首次拒绝点之前保持全权重，并重新锚定衰减起始点。VAT仅修改训练目标，因此可以叠加在现有方法之上，无需改变草稿架构、目标模型或推理过程。将VAT应用于EAGLE-3和DFlash在Qwen3-4B、Qwen3-8B和LLaMA-3.1-8B上，平均接受长度最多提升11.4%，墙钟加速最多提升8.7%，在数学、代码和聊天基准测试中均获得一致增益。代码将在https://github.com/naver-ai/vat 提供。

## Abstract
Speculative decoding accelerates large language model inference by using a draft model to generate candidate tokens, which are verified by the target model in a single forward pass. Verification proceeds sequentially and discards every position from the first rejection onward, yet existing draft training relies on token-level imitation of the target with a fixed per-position weighting that reflects neither property. We introduce Verification-Aware Training (VAT), a plug-in framework that simulates verification at every training step and turns the resulting accept and reject patterns into supervision. VAT consists of two components: (i) a verification head, a lightweight jointly trained binary classifier that supervises the draft model on whether each position survives sequential verification; (ii) verification-adaptive weighting, which replaces the fixed weighting schedule by keeping full weight up to each sample's first rejection point and re-anchoring the decay to start there. VAT modifies only the training objective, so it can be layered on top of existing methods without changing the draft architecture, the target model, or the inference procedure. Applied to EAGLE-3 and DFlash on Qwen3-4B, Qwen3-8B, and LLaMA-3.1-8B, VAT improves average acceptance length by up to 11.4% and wall-clock speedup by up to 8.7%, with consistent gains across math, code, and chat benchmarks. Code will be available at https://github.com/naver-ai/vat

# Verification-Aware Training for Speculative Decoding（VAT）论文总结

## 1. 论文的核心问题与研究动机

### 背景
- **投机解码（Speculative Decoding）** 是加速大语言模型（LLM）推理的关键技术，其核心流程为：轻量级草稿模型（Draft Model）以低成本提出 K 个候选 token，目标模型（Target Model）在单次前向传播中顺序验证这些候选项；一旦出现首个拒绝，该位置之后的所有候选 token 被丢弃，从最后一个被接受的位置开始新一轮草稿。
- 投机解码的**加速收益取决于平均接受长度（acceptance length τ）**——即每轮验证中被接受并保留的 token 数量。

### 核心问题
- **验证的本质特性**：验证是**顺序执行**的，每个位置 k 的 token 对被接受前缀的贡献以**其之前所有位置都通过验证为前提条件**；位置 k 之后如有拒绝，该 token 无论本身质量如何都会被丢弃。
- **现有训练与验证过程不匹配**：
  1. 现有草稿模型训练仅通过**token 级模仿目标输出**（交叉熵），给予每个位置同等的学习信号，完全没有反映“该位置的预测是否能在顺序验证中存活”这一真正决定推理加速的关键信号。
  2. 虽然已有方法引入固定位置的损失加权（如 EAGLE-3 使用 wk = 0.8^(k−1)，DFlash 使用 wk = exp(−(k−1)/γ)），但这类调度是**预先固定、跨样本共享**的，无法针对每个样本中首次拒绝发生的实际位置进行调整，导致在不同样本上权重分配与真实贡献脱节。

## 2. 方法论：Verification-Aware Training (VAT)

VAT 是一个仅修改训练目标的即插即用框架，不改变草稿模型架构、目标模型和推理过程。其核心思路是**在每一步训练中模拟验证过程，并将所产生的接受/拒绝模式转化为两类监督信号**。

### 2.1 训练时模拟验证

- 在训练过程中，草稿模型的分布 p̂_k 与目标模型的分布 p_k 在每个位置都是可获取的，因此可在每个训练步**模拟投机采样**的验证结果。
- 遵循投机采样接受准则：token x 以概率 min(1, p_k(x)/p̂_k(x)) 被接受，由此得到逐位置接受指示变量 **m_k**。
- 定义**首次拒绝点 k\*** = min{k : m_k = 0}（若全部接受则 k* = K+1）。
- 定义逐位置**接受标签 v_k = 1[k < k\*]**（等价于 ∏_{j≤k} m_j），该标签只有在所有前序位置均被接受时才为 1——这精确反映了推理时的真实验证结果。相比仅由各个位置独立决定的 m_k，v_k 反映的是顺序验证的累积后果。

### 2.2 组件一：验证头（Verification Head）

- **动机**：交叉熵目标无法区分两类位置——(1) 前缀全部被接受、纠正该位置可直接延长接受前缀；(2) 前缀已被更早拒绝抹除、该位置预测对接受长度无影响。
- **设计**：在草稿模型的最后一层隐藏状态之上连接一个**轻量级二元分类器**（单层全连接），预测每个位置被顺序验证接受的概率 v̂_k，使用**二元交叉熵损失**进行训练：
  - L_VH = −(1/K) Σ_{k=1}^{K} [v_k log v̂_k + (1−v_k) log(1−v̂_k)]
- **机制**：该辅助损失产生的梯度反向传播至草稿模型，引导其隐藏状态编码与目标模型一致性的特征，为标准的 token 级预测提供互补的验证信号。
- **推理时零额外成本**：验证头在推理时不被使用（除非用于可选的提前退出，见 §5.3）。

### 2.3 组件二：验证自适应加权（Verification-Adaptive Weighting）

- **设计原则**：替换固定的预定义权重调度，改为**以每个样本的实际首次拒绝点 k\* 为锚点**的实例自适应调度：
  - ŵ_k = 1（若 k < k\*）
  - ŵ_k = w_{k−k\*+1}（若 k ≥ k\*）
- 其中 w_k 是基线方法原有的固定调度曲线（如 EAGLE-3 的 0.8^(k−1) 或 DFlash 的 exp(−(k−1)/γ)），但此处在 k\* 处重新锚定，衰减从 k\* 才开始。
- **直觉**：
  - k\* 之前的位置：为本样本真实贡献了接受长度 → 保持全权重；
  - k\* 本身：是“最近的可纠正失败点”，改进该位置的预测可直接延长接受前缀 → 也给予全权重（因 w_1 = 1）；
  - k\* 之后的位置：已被验证过程丢弃 → 权重随同一衰减曲线递减，而不是完全移除（保留一定的学习信号）。

### 2.4 最终训练目标

- 使用软标签（目标分布）+ 硬标签（目标采样 token）两类交叉熵损失，配合验证自适应权重再加上验证头损失：
  - **L = Σ_{k=1}^{K} ŵ_k (ℓ_k^soft + ℓ_k^hard) + β·L_VH**
- 实验中将 β 设为 1.0；软+硬标签的结合在经验上优于单独使用任何一种。
- VAT 只改变训练目标，因此可叠加在现有投机解码方法之上，推理时的草稿与验证流程保持完全不变。

## 5. 主要结论与发现

- **VAT 在两个 SOTA 投机解码方法上均带来稳定一致的改进**（无论目标模型和草稿机制）：
  - 平均接受长度最高提升 **11.4%**（DFlash + VAT on Qwen3-8B），墙钟加速最高提升 **8.7%**。
  - 以 Qwen3-4B 为例：EAGLE-3 的加速比从 4.07× 提升至 4.39×（+7.9%），接受长度从 6.28 提升到 6.78（+8.0%）；DFlash 从 4.54× 提升至 4.81×（+5.9%），τ 从 5.73 提升到 6.08（+6.1%）。
- **每项组件独立生效，组合效果最佳**：
  - 验证头独立提升（5.73→5.87），验证自适应加权独立提升更大（5.73→5.91），软+硬标签也独立贡献（5.73→5.82）；
  - 三因素组合后平均接受长度达 6.08、加速比达 4.81×，各任务类别均取得最佳结果。
- **验证自适应的增益来自自适应机制本身而非衰减函数的具体形式**：
  - 将 EAGLE-3 式与 DFlash 式的衰减函数分别适配到验证自适应权重上后，两者性能几乎相同（τ = 6.09 与 6.08），均远超各自的固定调度版本。
- **验证头改变了训练动态**：
  - 验证头使首次拒绝位置 k\* 随训练推进明显后移（更多连续 token 通过验证）；
  - 首次拒绝后依旧与目标匹配的 token 数量保持稳定，相较基线后期出现明显下滑。
- **验证头可在推理时用于提前退出**（额外可选收益）：
  - EAGLE-3 上预测首次拒绝位置的平均绝对误差最小为 1.18 个 token（p=0.5），DFlash 为 1.76（p=0.6）；
  - 提前退出策略在 DFlash 上收益较大（如代码任务从 4.83× 提升至 4.97×），且接近 Oracle 上界，表明验证头具有推理期利用的潜力。
- **VAT 对实现细节不敏感**：贪心验证与随机采样验证规则在训练信号层面相关性 >0.92；语料温度为 0 或 1 时产生几乎一致的最终性能。

## 6. 主要优点

- **即插即用、侵入性极小**：仅修改训练目标，不改变草稿架构和目标模型，也不改变推理流程，可以直接叠加在各类现有投机解码方法之上。
- **针对要害问题、设计动机清晰**：直指预测目标与验证过程不匹配的核心矛盾——草稿模型只学模仿、不学“能否通过验证”，且固定权重与样本真实拒绝位置脱节。
- **方法简洁有效**：两个组件（轻量分类头 + 自适应加权）都非常简单，没有增加推理延迟或复杂性，却带来了持续且显著的加速收益。
- **实验验证扎实、充分**：多基线×多模型×多任务 × 多温度的完整主实验，加上 3 因子消融、加权方案对比、训练动态可视化、推理期扩展应用等多组分析实验，互为补充。
- **创新且清晰的加权设计洞察**：对比 hard cutoff（丢弃拒绝后全部位置）、prefix-only 等极端方案，VAT 选择在 k\* 后保留衰减的学习信号是一种精细且经验上最优的折中——它在“不浪费有参考价值的后拒绝位置信息”和“不分散对关键前缀的学习”之间取得平衡。

## 7. 不足与局限

- **模型规模覆盖局限**：实验仅覆盖 4B—8B 参数的目标模型，缺乏在更大规模（如 70B、上百 B 级）模型上的验证。更大模型的草稿模型训练动态可能不同，VAT 的收益是否保持未知（作者也在结论中承认了这一方向）。
- **训练开销（尤其 DFlash）** ：DFlash 的原始训练不计算目标模型的 LM 头分布，VAT 模拟验证需额外执行一次 LM head 前向传播，导致每步训练时间增加 6.1%、峰值显存上升 7.7 GB（23.8 → 31.5 GB）。虽然是一次性训练开销，但在大规模训练中不容忽视。
- **验证头的预测误差限制**：验证头与目标验证之间并非完全一致（EAGLE-3 MAE 为 1.18 tokens），存在误判的风险。在推理期使用验证头做提前退出时会因假拒绝损失部分接受长度（如 DFlash 数学任务 τ 从 7.67 降到 7.35），虽然墙钟总体加速仍为正值。
- **训练语料规模与多样性有限**：训练语料来自 Perfectblend + 目标模型自生成，未在大规模多样化语料上的表现进行充分讨论；语料质量对 VAT 效果的影响未分层次探究。
- **未讨论采样解码中的极端分布情况**：虽然实验覆盖了 temperature = 1 的情形，但对 top-p、top-k 等不同采样参数组合、以及低概率接受区域内 v_k 标签的噪声影响，没有做更深入的鲁棒性分析。
- **与并发工作（PARD-2 等）的对比不足**：文中仅将 PARD-2/D-PACE 放在相关工作部分，并未在实验中与这两种同为自适应权重方法的并发工作直接做实证比较（PARD-2 的对比缺失）。

## 8. 总结

VAT 是一个简洁有力的即插即用训练框架，它将投机解码的真实验证过程引入草稿模型训练目标，通过验证头和验证自适应加权两个互补组件，系统性解决了传统训练目标与顺序验证过程之间的脱节问题。在多样化的实验组合（两种草稿范式 × 三种目标模型 × 八种基准 × 两种解码温度）中表现出一致的收益，兼具实用性和通用性。尽管实验规模上限（8B 模型）与部分训练开销问题仍有待后续研究解决，但其核心思想为

……但其核心思想为：**“让草稿模型的训练目标直接向推理时的验证过程看齐”**。这一思想体现为两个层面的精准对齐——一是通过验证头让模型特征显式编码“顺序验证下是否会被接受”的二值结果，二是通过验证自适应加权沿真实首次拒绝点锚定每个 token 对加速贡献的实际边界。两者共同作用，将训练从“逐位置均匀模仿”重塑为“关键位置重点强化、冗余位置衰减学习”的贡献感知范式，解决了此前投机解码训练中长期存在的信号错位问题。

VAT 的全部贡献最终可浓缩为一句话：**在不改动任何推理基础设施的前提下，以最低限度的训练成本，将草稿模型的预测行为与投机解码的顺序验证逻辑对齐，从而获得稳定、可叠加、可持续的端到端加速收益**。其方法论上的"模拟验证—提取信号—反哺训练"闭环具有较强的可迁移性，不仅适用于本文涉及的 EAGLE-3 与 DFlash 两类范式，原则上也可推广至任何带顺序接受判定的多 token 投机生成框架（如多头投机采样、并行草稿验证等）。该工作为投机解码研究打开了一个此前被忽视的重要维度：**加速不仅取决于草稿模型“生成得像不像”，更取决于它“生成得能否在验证中存活”**，而后者恰恰是可以通过训练目标设计主动优化的。

### 附录性质的补充说明

（以下为对正文未覆盖细节的补充性交代，与原总结主结构并行）

- **与现有方法的兼容性（进一步说明）**：VAT 由于只作用于损失函数，正交于草稿模型的架构演进（层数、特征维度、并行头数目均不受影响），也正交于验证端的算法改进（如动态草稿长度调整、多元接受树），因此可预期与未来更先进的投机解码组件持续叠加而不产生冲突。

- **理论层面的启示**：虽然论文未给出形式化证明，但其思想可从 RLHF 式视角类比——验证头本质上是一种在线的“过程奖励模型”，验证自适应加权则类似于按时间差分意义下的 credit assignment（将接受长度的增量归因到 k\* 附近的位置）。这为后续将强化学习、过程监督等技术引入草稿模型训练指出了可能的方向。

- **潜在风险提示（补足局限）**：若目标模型的分布本身存在系统性偏差（如某些领域幻觉率高），VAT 将更高效地让草稿模型“学会”这些偏差以求通过验证，此时的加速是以对齐错误为代价的；论文未对此类分布退化风险设计防御机制，值得在应用中注意。

## 9. 总体评价与展望

VAT 是一篇动机明确、设计精巧、验证扎实的工作。它的核心贡献不在于提出新的投机解码架构，而在于从一个被普遍忽视的训练目标缺陷切入，用两个轻量组件撬动了显著的推理性能提升。其问题意识——"训练时预测目标与推理时验证信号不匹配"——具有广泛的代表性和启发性，几乎可以无障碍地移植到其他自回归生成加速管线中。

未来值得探索的方向包括：在超大模型（70B+）上检验 VAT 的扩展性；将验证头推广为一个可递归更新的“在线判别器”以应对目标模型的动态部署版本；将验证自适应加权的思想引入整个目标模型的蒸馏/对齐流程；以及探索如何借鉴 VAT 的信号构造方式，设计不依赖目标分布显式可得的更通用的验证感知目标。

总体而言，VAT 以其简洁性、有效性和通用性，为投机解码的草稿模型训练设定了新的参照标准，是该研究方向上值得关注的方法论里程碑。
