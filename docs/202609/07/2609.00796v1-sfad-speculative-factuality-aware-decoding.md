## 摘要
作为大型语言模型中最关键的挑战之一，上下文忠实性直接决定了其在知识密集型应用中的可靠性。这一任务尤为困难，因为它需要在事实一致性与生成效率之间取得平衡。对比解码方法需要双重前向传播（分别有上下文和无上下文）来比较模型输出，使推理计算开销翻倍，而训练后对齐则需要大量的强化学习，带来巨大的计算成本。为了解决这一挑战，我们提出了\textbf{SFAD}，一种推测性解码框架，在不降低推理性能的情况下增强上下文忠实性。我们首先构建了\textbf{ConFide}，一个带有细粒度原子扰动的偏好数据集，通过直接偏好优化训练上下文忠实的草稿模型。在推理过程中，认知摩擦通过量化由专家确定性加权的分布张力来检测潜在的幻觉。当摩擦超过阈值时，非对称逻辑转向通过基于残差的逻辑注入来细化目标分布；否则，继续进行标准推测。大量实验表明，SFAD在实现$2.48\times$加速的同时显著提高了忠实性，为高效LLM提供了一种实用解决方案。

## Abstract
As one of the most critical challenges in large language models, contextual faithfulness directly determines their reliability in knowledge-intensive applications. This task is particularly challenging as it requires balancing factual consistency with generation efficiency. Contrastive decoding methods require dual forward passes (with and without context) to compare model outputs, doubling inference computational overhead, while post-training alignment demands extensive reinforcement learning with substantial computational overhead. To address this challenge, we present \textbf{SFAD}, a speculative decoding framework that enhances contextual faithfulness without inference degradation. We first construct \textbf{ConFide}, a preference dataset with fine-grained atomic perturbations, to train a context-faithful draft model via Direct Preference Optimization. During inference, Epistemic Friction detects potential hallucinations by quantifying distributional tension weighted by specialist certainty. When friction exceeds the threshold, Asymmetric Logit Steering refines the target distribution through residual-based logit injection; otherwise, standard speculation proceeds. Extensive experiments demonstrate that SFAD substantially improves faithfulness while achieving $2.48\times$ speedup, offering a practical solution for efficient LLMs.

### 一、核心问题与研究动机

- 大型语言模型（LLM）在知识密集型应用中常因**知识冲突**而倾向于依赖参数记忆，而非任务提供的上下文证据，导致**上下文忠实性（contextual faithfulness）**不足，即产生“忠实性幻觉”（faithfulness hallucination）。
- 现有提升忠实性的方法存在明显效率瓶颈：
  - **对比解码方法**（如 CAD、AdaCAD）需要“有上下文/无上下文”的**双前向传播**，推理计算开销近乎翻倍，速度显著下降；
  - **后训练对齐方法**（基于强化学习）需要大量计算资源与大规模偏好数据，部署成本高。
- 因此，论文的核心问题是：**如何在不大幅牺牲推理效率的前提下，增强 LLM 对给定上下文的忠实性？**

### 二、方法论

- 论文提出 **SFAD（Speculative Factuality-Aware Decoding）**，首次将**推测性解码（Speculative Decoding）**与幻觉缓解统一到同一框架中，兼顾事实一致性与生成速度。

#### 2.1 训练阶段：ConFide 偏好数据集与上下文忠实草稿模型
- 构建偏好数据集 **ConFide**：
  - 源数据来自 LLM-AggreFact 与 CG2C；
  - 对候选响应进行**原子事实分解（Atomic Fact Decomposition）**，将句子拆分为可验证的“(主体, 关系, 客体)”三元组；
  - 通过三种**可控扰动算子**生成细腻且流畅的负样本：实体替换（τent）、数值扰动（τnum）、关系反转（τrel）；
  - 正样本通过释义重构（对正确样本）或教师模型修正（对错误样本）获得；
- 使用约 36K 条偏好数据（ConFide 18K + ConFiQA 18K），通过 **DPO（Direct Preference Optimization）** 训练一个较小规模的**上下文忠实草稿模型**（Qwen3-1.7B），作为“事实性哨兵”。

#### 2.2 推理阶段：动态检测与选择性修正
- **专家确定性（Specialist Certainty κt）**
  - 用归一化熵定义：κt = (1 − H(Pm)/log|V|)γ，用于衡量草稿模型当前预测的置信度，避免在不确信时注入噪声。
- **认知摩擦系数（Epistemic Friction Ft）**
  - Ft = DJS(PM ∥ Pm) · κt，即通用模型与草稿模型分布之间的 JS 散度，再乘以草稿模型的确定性。
  - 只有当两模型分歧大**且**草稿模型高置信时，Ft 才超过阈值，从而高效区分真实知识冲突与良性语言风格差异。
- **自适应门控（Adaptive Gating）**
  - 通过平移 sigmoid 得到门控标量 λt = σ(β(Ft − τ))，实现软切换：低摩擦进入标准推测路径，高摩擦进入转向路径。
- **非对称逻辑转向（Asymmetric Logit Steering）**
  - 修正目标分布：z*t = zM,t + λt · ReLU(zm,t − zM,t) · I(x ∈ VCPC)；
  - ReLU 保证**单向知识注入**：只增强草稿模型更确信（且上下文正确）的 token，而不惩罚目标模型的语法流畅性；
  - 上下文似然掩码 VCPC 进一步限制只能转向目标模型“语义流形”上合理的 token，避免语法断裂。
- **混合解码策略**
  - Ft ≥ τ：从修正后的分布中采样（Steering Path，修正路径）；
  - Ft < τ：执行标准推测验证（Fast Path，快速路径），保持推测解码的加速特性。

### 三、实验设计

#### 3.1 数据集与评测任务
覆盖五类任务、十余个公开 benchmark：
1. **事实检索**：TriviaQA、HotpotQA、PopQA（用 EM 评估）；
2. **摘要忠实性**：XSum、TofuEval（用 ROUGE-L、BERT-P、AlignScore 评估）；
3. **长文本生成（RAG 场景）**：CLAPNQ、ExpertQA、HAGRID（用 ROUGE-L、FaithScore/MiniCheck）；
4. **知识冲突**：LLM-AggreFact 留出的 200 条样本与 ConFiQA 指标（Pc、Po、MR）；
5. **通用能力保持**：GSM8K、Just-Eval。

#### 3.2 对比基线
- **解码级基线**（同目标模型 Qwen3-14B）：Greedy、CAD、COIECD、AdaCAD；
- 另设 **Llama-3.1-70B-Instruct**（约 5 倍于 14B 参数的前沿模型）作为性能参考；
- 还测试了标准推测解码（Standard SD）与不同目标模型（Llama-3.1-8B）下的跨族泛化。

#### 3.3 主要评估结果
- **Foundation QA**：Qwen3-14B + SFAD 达到 TriviaQA 85.12、HotpotQA 52.19、PopQA 86.39，相对延迟仅 0.82×，显著优于 CAD/AdaCAD/COIECD，并大幅缩小与 Llama-3.1-70B 的差距；
- **摘要任务**：接近 Llama-3.1-70B 的 AlignScore（87.37 vs 87.48），相对延迟 0.85×；
- **长文本 QA**：CLAPNQ、ExpertQA、HAGRID 上 Faith 分别提升到 90.93、71.13、81.99，接近 70B 模型，相对延迟仅 0.78×；
- **加速指标**：SFAD 达到 **2.48× 平均生成加速（ATGA）**。

### 七、方法亮点与优点

1. **创新视角**：将草稿模型重新定义为“事实哨兵”，在推测解码框架内用较小的专家模型动态监督并修正大模型，首次把幻觉抑制与推理加速结合在同一框架中；
2. **数据质量机制**：ConFide 通过原子级三元组扰动制造细粒度硬负样本（实体交换/关系反转等），显著增强了草稿模型的上下文辨别力；
3. **理论严谨性**：论文提供了多项数学证明：
   - 上下文似然掩码可以约束转向不脱离语言流形（Semantic Integrity）；
   - DPO 带来的偏好间隔会在推理时指数放大忠实 token 的后验优势（Factuality Amplification）；
   - 非对称 ReLU 注入避免“零概率陷阱”，保证分布支持集合稳定（Support Preservation）；
   - 混合策略满足 Neyman-Pearson 式最佳风险切换。
4. **推理效率极优**：相对延迟低于 1×（甚至低于贪婪解码），同时保证事实性增益；
5. **通用性较好**：在 Qwen3、Llama-3.1 上均有收益，适用于检索问答、摘要、长文生成等多种知识密集型场景。

### 八、不足与局限

1. **需要额外训练专用草稿模型**：相比标准推测解码，SFAD 需要先在 DPO 上用 ConFide + ConFiQA 数据训练领域对齐的草稿模型，数据构建与训练过程存在不可忽略的额外开销；
