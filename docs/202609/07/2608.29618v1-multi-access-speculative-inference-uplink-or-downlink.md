## 摘要
多接入推测推理（Multi-SPIN）将SPIN扩展到多设备边缘网络，以加速协作式token生成。它允许设备端的小语言模型（SLM）为各个生成任务自回归地草拟多个token，而边缘服务器上的大语言模型（LLM）并行验证这些token。主要的通信开销出现在当草拟的token被服务器拒绝时，在这种情况下，采样修正token需要同时访问SLM输出的草拟分布和LLM输出的目标分布，且两者覆盖整个token词汇表。现有设计通常通过上传草拟分布到服务器来执行修正，但传输词汇表范围的分布会造成关键的上行链路（UL）瓶颈。或者，修正可以在设备端通过下载目标分布来完成，利用下行链路（DL）可用的高传输速率。受此启发，我们将通信模式选择引入为Multi-SPIN的一个新设计维度。具体而言，每个设备可以自适应地在UL和DL模式之间切换，以在UL瓶颈和共享DL资源约束之间取得平衡，从而减轻整体通信负担。我们提出了一个总token有效吞吐量最大化问题，该问题联合考虑模式选择、草稿长度控制和功率分配。对于模式选择，我们揭示了一种简单的优化结构，使得能够高效搜索UL设备数量，并相应优化对应的发射功率。对于草稿长度控制，我们开发了一种贪心搜索算法，使设备特定的草稿长度适应异构的计算和通信能力。在Qwen2.5和DeepSeek-R1模型对上的实验结果表明，所提出的框架显著提高了token有效吞吐量。

## Abstract
Multi-access speculative inference (Multi-SPIN) extends SPIN to multi-device edge networks to accelerate cooperative token generation. It allows on-device small language models (SLMs) to autoregressively draft multiple tokens for individual generation tasks, while an edge-server large language model (LLM) verifies them in parallel. The major communication overhead arises when a drafted token is rejected by the server, in which case sampling the correction token requires access to both the SLM-output draft distribution and the LLM-output target distribution over the full token vocabulary. Existing designs typically perform correction at the server by uploading the draft distribution, but transmitting a vocabulary-wide distribution creates a critical uplink (UL) bottleneck. Alternatively, the correction can be performed at the device by downloading the target distribution, leveraging the high transmission rates available on the downlink (DL). Motivated by this insight, we introduce communication-mode selection as a new design dimension for Multi-SPIN. Specifically, each device can adaptively switch between the UL and DL modes to balance the UL bottleneck against the shared DL resource constraint, thereby relieving the overall communication burden. We formulate a sum-token-goodput maximization problem that jointly accounts for mode selection, draft-length control, and power allocation. For mode selection, we reveal a simple optimal structure that enables efficient search over the number of UL devices, with the corresponding transmit powers optimized accordingly. For draft-length control, we develop a greedy-search algorithm that adapts device-specific draft lengths to heterogeneous computation and communication capabilities. Experimental results on Qwen2.5 and DeepSeek-R1 model pairs demonstrate that the proposed framework significantly improves token goodput.

## 1. 核心问题与整体含义（研究动机与背景）

- 本文研究边缘计算场景下的大模型（LLM）协作推理加速问题。大模型在服务器端推理存在集中式瓶颈，而设备端自身算力往往不足以运行完整 LLM。
- 推测推理（SPIN）是一种新兴范式：设备端部署轻量级小模型（SLM），先自回归地草拟多个 token，再由服务器端 LLM 并行验证这些草拟 token，从而将多次顺序解码合并为一次并行验证，显著降低服务器计算开销。
- 当草拟 token 被拒绝时，需要生成修正 token（correction token），该操作必须访问覆盖整个 token 词汇表的草拟分布和目标分布。由于现代 LLM 词表规模极大（如 Qwen2.5 含 15 万+ 词元），传输完整分布会带来严重的通信开销，即“token 修正开销”。
- 现有研究通常采用上行（Uplink, UL）方式：设备将草拟分布上传至服务器，由服务器采样修正 token。但上行速率受限，形成 UL 瓶颈。
- 一种替代方案是利用下行（Downlink, DL）速率更高的特点：服务器将目标分布下载至设备，由设备自行完成修正（DL 模式）。
- 然而在多设备多接入系统中，所有设备都走 DL 会争抢服务器有限的共享 DL 功率，导致整体性能下降。
- 因此，本文核心问题是：在多接入推测推理（Multi-SPIN）系统中，如何选择每个设备的通信方向（UL 或 DL），并联合优化草稿长度与发射功率，以最大化期望总 token 有效吞吐量（sum token goodput）。

## 2. 方法论：核心思想、关键技术细节、公式与算法流程

### 2.1 核心思想
- 提出 **通信模式选择**（communication-mode selection）作为 Multi-SPIN 的新设计维度。
- 每个设备在发生 token 拒绝时，可自适应选择 UL 模式（上传草拟分布至服务器修正）或 DL 模式（下载目标分布至设备修正），以平衡 UL 瓶颈与共享 DL 资源约束。
- 问题建模为两阶段随机优化：先“主动”选择草稿长度，后“反应式”确定模式与功率。

### 2.2 系统协议与建模
- 系统包含 K 个设备和一个边缘服务器，每个设备执行独立生成任务。
- 每轮流程：设备用本地 SLM 自回归草拟 γ_k 个 token → 上传草拟 token 及其标量概率 → 服务器用 LLM 并行验证（跨设备和跨位置）→ 若全部接受，则采样 bonus token；若存在拒绝，则对拒绝设备执行修正操作。
- 定义验证结果向量 o，拒绝设备集合 R(o)。

### 2.3 优化问题
- 目标为最大化期望总 token 有效吞吐量：
  - \( G(\gamma, \chi) = \bar{L}(\gamma) / \bar{T}(\gamma, \chi) \)
  - \(\bar{L}(\gamma)\) 为期望输出 token 数：\(\bar{L}(\gamma) = \sum_{k} (1-\alpha_k^{\gamma_k+1})/(1-\alpha_k)\)，其中 \(\alpha_k\) 为每设备 token 接受概率。
  - \(\bar{T}(\gamma, \chi)\) 为期望轮延迟，包括计算延迟 \(T_{comp}(\gamma)\)（草稿生成延迟 + 批量验证延迟）和期望通信延迟。
- 通信延迟取决于拒绝设备的分布传输，传输内容量为 \(V_{eff}(\lceil \log_2 V\rceil + Q)\) bits。
- 约束包括：每个设备草稿长度为非负整数；UL 设备发射功率不超过各自上限；DL 总功率不超过服务器预算。

### 2.4 反应式模式选择与功率分配优化
- 对于已发生的验证结果，将最小化期望通信延迟分解为独立子问题：给定拒绝设备集合 R，最小化最大分布传输延迟。
- DL 功率分配的最优解在给定 DL 用户集合下具有“最大延迟均衡”结构（Lemma 1）：
  \[
  p_k^* = \frac{N_{0,k}^{\text{dev}} B_k}{|h_k|^2} \left( 2^{\frac{V_{eff}(\lceil \log_2 V\rceil+Q)}{B_k \tau_{dl}}} - 1 \right)
  \]
  其中 \(\tau_{dl}\) 通过总功率方程二分求解。
- 模式选择的关键结构性质（Lemma 2）：将设备按“最小 UL 延迟”非降序排序后，最优 UL 设备集合具有**前缀结构**：UL 延迟较小的设备优先分配 UL 模式，其余设备分配 DL 模式。
- 由 UL 延迟单调不减、DL 延迟单调不增，可推导“DL-UL 延迟差”单调性，从而用**二分搜索**寻找最优分割点（Proposition 1），而非指数组合搜索。

### 2.5 主动草稿长度控制算法
- 目标函数非凸、随机、无闭式解。
- 采用 **SAA（样本平均近似）** 估计期望通信延迟，采样 N_SAA 个验证结果（N_SAA=1000）代替穷举 2^K 种结果。
- 开发**贪心搜索算法**（Algorithm 1）：
  1. **同步全一更新阶段**：从 γ=0 开始，重复尝试 γ←γ+1，若有效吞吐量提升则接受，否则终止。
  2. **坐标贪心精化阶段**：每次尝试对单个设备增加 1 个草稿长度，更新能带来最大有效吞吐量提升的设备；若无提升则算法终止。
- 算法将模式选择、功率分配和草稿长度控制联合考虑。

## 6. 主要结论与发现

- 提出的多接入推测推理框架（Multi-SPIN with mode selection）能通过自适应 UL/DL 模式切换显著提升总 token 有效吞吐量。
- 最优模式选择具有**前缀结构**：UL 延迟小的设备优先使用 UL，其余使用 DL；该结构使组合优化降为二分搜索。
- DL 功率预算增大时，系统会主动增加草稿长度并将更多拒绝设备转向 DL；但并非所有设备都转 DL，因为共享 DL 资源仍然约束性能。
- 固定模式（全 UL 或全 DL）均不是普适最优：功率受限时 DL 竞争严重，UL 受单设备功率限制；自适应模式优于两者。
- 联合草稿长度控制比“统一草稿长度”和“仅计算感知”策略更优，说明设备异构性和通信条件必须纳入草稿长度决策。

## 7. 优点

- **问题新颖**：首次将通信模式选择引入多接入推测推理，将“传输方向”变为可优化自由度，突破了传统通信“源–宿–方向固定”的范式。

- **实验较全面**：使用两种主流模型对、四种代表性任务，并系统对比多种基线，验证了模式选择和草稿长度控制两部分的独立贡献。

## 8. 不足与局限

- **实验层面**：
  - 全部基于仿真，没有真实无线网络或软硬件协同实验，实际延迟和吞吐收益有待验证。
  - 未考虑非理想信道估计、有限反馈精度、同步失配等实际系统偏差。
  - 草稿长度搜索的上限/步长、SAA 样本数量等超参数对最优性的影响分析不足。
  - 与现有通信压缩方案（量化、稀疏化、不确定性跳过）没有进行联合比较，无法体现方法在“通信压缩生态”中的相对优势。
- **模型假设层面**：
  - 同设备各 token 接受概率独立同分布、跨设备独立假设较简化；真实 LLM 的接受概率随上下文高度变化，可能影响延迟建模精度。
  - 验证延迟建模为 \(T_0+T_1\cdot K\)，忽略了批次内草稿长度差异对实际运算时间的二阶影响。
  - 带宽分配被当作给定输入，未与模式选择联合优化，可能错过进一步增益。
- **算法层面**：
  - 贪心搜索只保证局部最优，不具备全局最优性。
  - 模式选择的最优前缀结构依赖“设备最小 UL 延迟排序”和 DL 延迟的单调性，扩展场景（如多天线、异构带宽分配、频分复用下用户间干扰）可能需要重新推导。
- **应用限制**：
  - 高度依赖 SLM 与 LLM 共享 tokenizer 且词表一致的前提，若草拟模型和验证模型词表不同，则修正采样需要额外的词汇映射，可能改变整体设计。
