## 摘要
长上下文推理在解码过程中会保留不断增长的键值（KV）缓存，这消耗大量GPU内存并可能降低生成吞吐量。这一瓶颈在混合语言模型中依然存在，因为其残差全局注意力层可能主导上下文相关的缓存需求。我们研究如何在总KV驻留预算约束下分配这种状态。我们提出HeadWiseKV，一种免训练框架，在保留混合语言模型固有的局部、循环和线性路径的同时，压缩其残差全局KV缓存。它为每个物理KV头分配一个静态的多级历史窗口，使得服务前的缓存需求可预测。我们将此分配问题形式化为受限的速率-失真问题，并提出SeqCalib作为HeadWiseKV的核心策略生成算法。SeqCalib按执行顺序处理层，并将每个决策基于部署时使用的低层策略进行条件化，从而考虑跨层交互。一种分组缓存运行时将所选策略实现为实际的每头KV驻留状态，而非完整缓存上的掩码。我们在四个混合长上下文模型上评估下游质量，并在Qwen3.6-27B上研究物理驻留和服务行为。HeadWiseKV在评估模型中保持接近全KV的RULER和LoCoMo质量。在固定模型系统研究中，它在112K上下文长度下将采样峰值设备内存降低了8.59%，并将最大验证成功上下文从114K延长至161K。

## Abstract
Long-context inference retains a growing key--value (KV) cache during decoding, which consumes substantial GPU memory and can reduce generation throughput. This bottleneck remains in hybrid language models because their residual global-attention layers can dominate context-dependent cache demand. We study how to allocate this state under an aggregate KV-residency budget. We introduce HeadWiseKV, a training-free framework that compresses the residual global KV caches of hybrid language models while preserving their native local, recurrent, and linear paths. It assigns each physical KV head a static, multilevel history window, making cache demand predictable before serving. We formulate this allocation as a restricted operational rate--distortion problem and propose SeqCalib as the core policy-generation algorithm in HeadWiseKV. SeqCalib processes layers in execution order and conditions each decision on the lower-layer policy used at deployment, thereby accounting for interactions across depth. A grouped-cache runtime materializes the selected policy as actual per-head KV residency rather than a mask over a full cache. We evaluate downstream quality across four hybrid long-context models and study physical residency and serving behavior on Qwen3.6-27B. HeadWiseKV retains near-Full-KV RULER and LoCoMo quality across the evaluated models. In the fixed-model systems study, it reduces sampled peak device memory by 8.59\% at a 112K context length and extends the largest verified successful context from 114K to 161K.

# HeadWiseKV：混合长上下文语言模型的预算化每头缓存驻留管理

## 1. 核心问题与整体含义（研究动机与背景）

长上下文自回归推理期间，每一层全注意力（full attention）都会为所有已缓存 token 保存对应的 Key/Value 向量。KV 缓存随上下文长度与并发量不断增长，可以轻易耗尽 GPU 显存并降低生成吞吐。

混合语言模型（hybrid LM，如 Gemma 2/3 将全局注意力和滑动窗口注意力交错、Qwen3-Next/Qwen3.6 将全注意力和循环 Gated-DeltaNet 块交错）虽然部分缓解了这一问题，但并未消除瓶颈——残差全局注意力层（residual global-attention layers）仍然会随 prompt 保留历史，其缓存体量甚至可以主导 KV 缓存需求。换言之，混合化只是转移了瓶颈位置：一小部分残留全局层就可能决定一个长请求能否装入显存。

论文从两个正交维度定位 KV 压缩问题：
1. **策略时机（policy timing）**：保留策略是在服务前静态确定，还是根据当前请求/注意力动态选择；
2. **缓存实现（cache realization）**：策略是否真正改变物理驻留状态，还是仅在逻辑访问层面做稀疏掩码（mask）或压缩（compaction）。

动态（prompt-adaptive）方法能保留对特定 prompt 重要的孤立远处证据，但逻辑稀疏掩码不减少分配，补偿或压缩往往发生在已构建完整缓存之后，不降低 prefill 阶段的显存峰值，还引入在线索引/搬移开销。静态方法让容量可预测，但传统做法只有"全历史 vs 压缩/流式缓存"的二元划分，对混合模型中不同全局 KV 头需求差异大、各层敏感性不同的情况过于粗糙。

**HeadWiseKV** 的核心主张是：为每个物理 KV 头静态指定一个多级历史窗口长度，在服务前就能完全确定缓存需求；配合"部署条件化校准"（高层决策在低层实际采用的策略下做出）和"物理驻留实现"（按窗口分配实际存储），在可预测的内存预算下尽量逼近全缓存模型质量。

## 2. 方法论（核心思想与技术细节）

### 2.1 结构化驻留模型（Structured Residency Model）

- 决策单元是**物理 KV 头**（ℓ, h），而非单个 query 头——因为 GQA（分组查询注意力）下多个 query 头共享同一组 K/V。
- 每个决策单元分配一个窗口长度 aℓh ∈ W = {w₁, …, w_K, full}，w_k 表示连续后缀长度。
- 在上下文长度 C 下，有限窗口 w 的实际驻留 token 数 r_C(w) = min(w, C)，full 则为 C。
- 归一化驻留率：R_C(a; p_KV) = N_C(a; p_KV) / N_C(a_F; p_KV)，其中 N_C 是本策略下名义 KV 存储总和，a_F 是全满策略。该比率只衡量可配置的全局 KV 头部分，不包含权重、workspace 等。
- 理想目标被表述为一个**受限速率-失真问题**：

  > 在 R_C(a) ≤ β 的预算约束下，最小化策略输出与全 KV 模型端到端输出的期望失真。

  由于全集搜索空间含 (K+1)^|U| 个策略矩阵、每个都要端到端评估，直接优化不现实，于是提出 SeqCalib 近似。

### 2.2 SeqCalib：顺序前缀条件化校准（核心算法）

**设计动机与两层校准原理：**

- **逐头截断的非均匀影响**：截断历史时，注意力权重归一化导致的输出偏差上界是 ∥o_F − o_w∥₂ ≤ m_w·ΔV，其中 m_w 是丢弃概率质量、ΔV 是保留/丢弃值向量的最大差距——这两者对每个 KV 头都不同，因此窗口分配须逐头化。
- **跨层耦合**：早期层截断会改变后续所有层的输入，满足递推 Δ_{b+1} ≤ L_b·Δ_b + ε_b^op。所以校准高层时必须让低层策略已经处于部署时的状态。

**算法流程（逐层执行）：**

1. 按前向执行顺序处理每个全局注意力层 ℓ；
2. 冻结已选定的低层策略 a_<ℓ，在其上执行 prefix；
3. 对当前层以全历史（full）跑一次完整 trace，得到 Q/K/V 向量；
4. 从同一份 trace 回放（replay）每个候选有限窗口 W；
5. 对候选窗口 w，计算注意力输出 o^{(w)}_ℓhq 与条件全历史输出 o^{(full)}_ℓhq 之间的**余弦相似度（含稳定化处理）**，并对校准数据样本、采样查询位置和 GQA 组内 query 头求平均，得到得分 Ŝ_ℓh(w | a_<ℓ; C, p_KV)；
6. 在满足相似度阈值 τ 的前提下，选择**成本最低**的窗口：

   > â_ℓh,τ ∈ argmin_w { n_ℓh,C(w; p_KV) : Ŝ_ℓh(w | â_<ℓ,τ; C, p_KV) ≥ τ }

7. 由于 full ∈ W，每阶段必然可行；处理后进入下一层。

由于每一层的选择是在固定前缀下的逐头独立最小化，且层内名义成本可加，SeqCalib 能保证**"条件于已实现低层前缀的层内最小成本"**（locally minimal，命题给出），但不保证全局联合最优——论文对此明确声明。

**预算选择：** 在有限阈值网格 T = (τ₁,…,τ_G) 上独立运行 SeqCalib，得到记录集（策略矩阵、速率、瓶颈头得分、阈值、索引）。给定预算 β 时，确定性选择规则按字典序：优先最大化最低选中头均值（记录质量下限）→ 再最小化速率 → 再取最小的网格索引。

### 2.3 从策略到物理驻留（分组缓存运行时）

- 运行时只**加载一次**策略矩阵，不根据 prompt、请求历史或在线注意力重新计算。
- 将可配置的全局注意力存储划分为活跃的（window, KV head）分组；分配相同窗口各头共享组配置，但 KV 内容保持隔离。
- 每个被配置的 KV 头只读写自己分配的切片；full 走全长单头组，有限窗口走对应的局部窗口组。
- 每头注意力输出经拼接后进入模型原有门控与输出投影——prompt 不被全局截断，本地/循环层保持在原始缓存路径上。
- 校准和部署共用同一套层头索引、窗口语义和注意力缩放；校准前通过全窗口子集回放做 trace 兼容性检查。

## 6. 主要结论与发现

1. **质量保值效果好**：在 Qwen3.6-27B 上，68.95% 全局 KV 保留率下，RULER 99.65/100、LoCoMo 94.55/94.55（与全 KV 持平），τ2-Bench Airline 和 Retail 甚至反超全 KV（79.50 vs 77.00；82.24 vs 82.02）——精细的逐头窗口可能去掉干扰性历史而保留敏感头的长距离证据。
2. **压缩位点存在平滑的冗余区**：τ=.999/τ=.998 时 RULER 和 LoCoMo 完全不变；最激进压缩（τ=.995）也只有小幅 RULER 下降（−0.35 分）。说明全局 KV 头中存在可消除的异构冗余。
3. **名义压缩确实转化为物理显存收益**：Qwen3.6-27B 在 112K 上下文采样峰值显存降低 8.59%（−2.01 GiB），prefill 为全 KV 的 0.810–1.092×，decode 为 0.954–1.017×。
4. **上下文容量显著扩展**：最大验证成功上下文从 114K（Full-KV）提升到 161K（HeadWiseKV），1.41×（OOM 边界分别在 115K/162K）。
5. **跨模型迁移**：τ=.995 在 4 模型上保持 RULER 接近全 KV（≥99.29），LoCoMo 因模型而异（−2.08 到 +0.07）→ τ 是保真度阈值而非固定压缩率，部署应基于每模型的产出策略做容量规划并在目标任务上验证。

## 7. 优点（方法/实验设计亮点）

1. **问题刻画清晰**：用"策略时机 × 缓存实现"矩阵把动态/静态、掩码/物理驻留做了明确区分，把 HeadWiseKV 的定位讲得很清楚。
2. **静态可预测性**：窗口在服务前固定，无需在线打分/索引/搬移，缓存需求在 prefill 前已知——对服务系统资源规划有实质价值（对于动态方法在线开销的批评有说服力）。
3. **细粒度多于二元划分**：多级窗口相对 retrieval/streaming 二元划分更灵活，条件于部署前缀的逐层校准显式处理了跨层传播，这在工程上是静态方法里较细的做法。
4. **物理缓存实现而非逻辑掩码**：分组缓存让策略落到真实 KV 驻留，直接减少分配字节（不只减少注意力计算量），并保持 GQA/投影结构不变，porting 边界明确。
5. **分析诚实且完整**：明确声明层内最小化不等于全局最优；质量对比和系统对比刻意不作不配对比率声称；系统队列只在全 KV/HeadWiseKV 间作比率，统计纪律较好。
6. **收益的双路径验证**：既有质量面板、又有固件面板（显存峰值、prefill/decode 吞吐、OOM 网格），能相互印证名义保留率与物理显存的关系。

## 8. 不足与局限

1. **对异常长距离依赖不敏感**：窗口一旦固定，被逐出的证据无从恢复；无法像动态方法那样按 prompt 保留孤立的远处线索。单点故障场景（如 RULER 远距离细节）容易暴露这一弱点。
2. **下游质量保证有限**：SeqCalib 用的是注意力输出余弦，是**局部激活相似度**而非端到端概率一致性的严格保证；附录 A.3 用 log-loss 给出预测性解释，但承认 SeqCalib 用的是局部准则。
3. **局部最优而非全局最优**：层内最小可行成本是在固定前缀条件下的，整体策略不保证在全部 W^|U| 中成本最优或质量最优；τ 网格的枚举也不是普适的连续优化。
4. **逐模型/任务验证成本**：τ 对每模型的诱导保留率差异很大（58.01%–91.89%），LoCoMo 迁移效果不统一——每个新模型需重新校准并以目标任务验证，材料变化
