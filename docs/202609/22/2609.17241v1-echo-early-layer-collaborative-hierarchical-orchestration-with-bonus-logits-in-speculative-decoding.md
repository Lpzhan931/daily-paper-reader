## 摘要
尽管免草稿模型的推测解码为高效 LLM 推理提供了一条有前景的路径，但它常常受限于过时的草稿候选以及验证的高计算成本。为应对这些挑战，我们提出 ECHO，一种利用 LLM 各层之间功能不对称性的分层双循环框架。借助早期层的高判别效率与最终层的权威分布，ECHO 将推理分为高频内循环和低频外循环。在内循环中，早期层 Bonus Logits 以极低开销驱动快速、多步的草稿树探索。同时，外循环通过状态复用机制执行权威的全模型验证。关键的是，外循环还利用最终层 Bonus Logits 来修正已有路径，并为后续循环向树中补充高置信度候选。在多种基准上的实验结果表明，ECHO 显著提升了平均接受 token 数，并实现了 2.4× 到 2.9× 的加速，在工程开销可忽略且无需额外部署参数的情况下优于现有最先进基线，但为了达到最优加速仍依赖一次性微调。代码见 https://github.com/whucs21Mzy/ECHO。

## Abstract
While draft-model-free speculative decoding offers a promising path to efficient LLM inference, it is frequently constrained by stale draft candidates and the high computational cost of the verification. To address these challenges, we propose ECHO, a hierarchical dual-loop framework that exploits the functional asymmetry between LLM layers. Leveraging the high discriminative efficiency of early layers and the authoritative distribution of final layers, ECHO bifurcates inference into a high-frequency inner loop and a low-frequency outer loop. Within the inner loop, early-layer bonus logits drive rapid, multi-step draft-tree exploration at a minimal cost. Simultaneously, the outer loop performs authoritative full-model verification through a state-reuse mechanism. Crucially, the outer loop also utilizes final-layer bonus logits to correct existing paths and supplement the tree with high-confidence candidates for subsequent cycles. Experimental results across diverse benchmarks demonstrate that ECHO significantly boosts mean accepted tokens and achieves a 2.4$\times$ to 2.9$\times$ speedup, outperforming existing state-of-the-art baselines with negligible engineering overhead and no extra deployment parameters, albeit with a one-shot fine-tuning dependency for optimal acceleration. The code is available at https://github.com/whucs21Mzy/ECHO.

## 1. 核心问题与整体含义

- **研究背景**：大语言模型自回归解码受限于内存带宽，顺序 token 生成延迟高。推测解码（Speculative Decoding）通过“先草稿、后并行验证”实现无损加速，已成为关键范式。
- **问题定位**：现有推测解码方法分为两类，各有缺陷：
  - **基于草稿模型**的方法：引入辅助模型，带来显著的计算与内存开销，与加速初衷相悖。
  - **无草稿模型**的方法：依赖历史上下文或目标模型输出 logits 构建草稿，但存在 **时效性悖论**——草稿信息来自最终层，需完整前向传播才能刷新，导致草稿信息密度低、候选陈旧，平均接受长度受限。
- **验证墙问题**：标准验证中每个草稿树/序列都必须遍历整个目标模型架构；当草稿质量波动时，加速效率在不同任务上极不稳定。
- **信息衰减观察**：论文发现现有无模型方法在草稿深度超过几个 token 后质量急剧下降（Figure 1），早期退出自推测方法虽能保持深度质量，却因多次前向传播而开销巨大。
- **整体含义**：ECHO 利用 LLM 各层之间的 **功能不对称性**（早期层判别效率高、最终层分布权威），重新定义无草稿模型推测解码，以分层双循环结构同时提升草稿质量与验证效率。

## 2. 方法论

### 2.1 核心思想

- 将目标模型 M 划分为 **敏捷早期层验证器 Ve**（第 1 至 Le 层）与 **鲁棒后续层验证器 Vs**（第 Le+1 至 L 层），构建 **高频内循环 + 低频外循环** 的分层双循环框架。
- 复用早期层与最终层的 **Bonus Logits**（奖励 logits）作为草稿树锚点，避免额外推理成本，实现“动态语义预测”而非静态历史匹配。

### 2.2 分层验证机制

- **阶段一：早期层树验证**
  - 将候选 token 组织为分支树 T，使用 **树注意力（Tree Attention）** 处理。
  - 位置编码 `Ptree = Lcurr + depth(T)` 按树深度对齐；树掩码 `Mtree` 确保每个子节点只关注其祖先与自身，隔离不同语义分支。
  - 迭代 T 次直至满足阈值，输出累积序列 `Sacc` 与隐藏状态 `H(Le)_acc`。
- **阶段二：后续层因果验证**
  - Vs 对线性序列 `Sacc` 执行全局因果注意力，复用 `H(Le)_acc` 作为输入，跳过前 Le 层，消除冗余计算。
  - 数学恒等式：`M(Sacc) ≡ Vs(Ve(Sacc))`，保证输出分布与标准前向完全一致。
- **无损验证**：最终 logits 与标准前向完全一致，采用标准拒绝采样（rejection sampling）确保输出严格服从目标分布 `P(xi|x<i)`。
- **增量自动机更新**：每个被接受 token 的 n-gram 模式插入 trie 型参考自动机 R，扩展检索索引：`R ← UPDATE(R, x<i, xi)`。

### 2.3 非对称 Bonus Logits

- **定义**：验证器在最后一个被接受或纠正 token 处产生的预测分布。
- **早期层 Bonus Logits（p̂(Le)）**：由 Ve 在退出层生成，深度低、成本低、频率高，提供适应局部上下文的语义引导。
- **最终层 Bonus Logits（p(L)）**：由 Vs 用完整模型参数生成，分布精度高，作为后续循环的高保真锚点，尤其在验证失败后用于纠错。
- 两层的 top-1 token 均作为下一轮草稿树的根节点，确保推测始终从已验证或高置信度分布出发。

### 2.4 草稿树构建与集成

- 混合草稿树：`T = MATCH(R, q) ∪ Top-k(pt)`，即检索自动机匹配结果与 bonus logits 采样结果的并集。
- 内循环中早期层 **同时充当草稿源与验证器**，这种重叠非冗余，反而通过反复强化高概率未来轨迹来增强基于 LRU 的自动机。

### 2.5 ECHO 推理流水线

- **Phase I 上下文初始化**：完整前向传播处理提示前缀，填充全局 KV cache，生成首个 oracle bonus logits，初始化自动机 R。
- **Phase II 敏捷探索（内循环）**：高频循环，以最新 bonus logits 为根构建混合草稿树，Ve 执行树注意力验证；被接受 token 立即索引入 R。
- **Phase III 权威对齐（外循环）**：内循环缓冲达到阈值后，同步跨层状态转移；Vs 复用 `H(Le)_acc` 与同步 KV cache 执行因果验证，发出最终 oracle bonus logits 并高保真更新自动机。

### 2.6 算法流程（Algorithm 1 概要）

1. 全模型前向传播处理提示，生成首个 oracle bonus 作为锚点；
2. 内循环：构建混合树 → 早期层验证 → 累积缓冲 → 采样 Inter Bonus 作为新锚点，直到缓冲满或遇到 EOS；
3. 状态复用桥：同步 KV cache，加载 `H(Le)_acc`，跳过前 Le 层；
4. 外循环：后续层验证缓冲序列；若出现认知分歧则回滚 KV cache 至 oracle 决策位置，否则全接受；
5. 更新自动机 LRU，发出新 oracle bonus 作为下一轮锚点。

## 6. 主要结论与发现

- **性能提升**：ECHO 在多个基准上实现 **2.4× 至 2.9× 加速**，峰值达 **3.01×**（Llama-2-13B），MAT 显著优于所有基线（Llama-2-7B 上 MAT 约 5.07）。
- **信息衰减破解**：ECHO 通过持续回收 Early Bonus Logits 作为草稿树种子，打破了理论接受长度上限，在所有草稿深度维持高质量候选。
- **验证墙瓦解**：分层设计将 512 token 生成的平均验证深度从 32 层降至约 26 层，总层通过数减少 21%，执行时间减少 12%，中位数 FLOPs 减少 17.4%。
- **无额外参数优势**：相比 EAGLE-2（需辅助层），ECHO 以更高平均加速（3.79× vs 2.84×）和更长匹配长度胜出，且无额外部署参数、VRAM 与内存带宽开销。
- **规模扩展性**：CodeLlama-34B 平均加速 3.13×，Llama-2-70B 达 2.32×，大模型上加速效果更优。
- **分布式开销可忽略**：State-reuse 同步桥在高并发下仅占总执行时间约 1.15%。
- **缓冲大小存在最优值**：过大缓冲（如 9）会导致早期层累积偏差，触发新验证墙，速度反而下降。
- **2 级分层为 8B 规模最优**：3 级级联虽能过滤低质量草稿，但同步开销翻倍且低质量 logits 导致更多重验证，整体收益为负。

## 7. 优点

- **方法创新性**：
  - 首次将 **早期层 Bonus Logits 作为高频生成信号** 主动生长草稿树，将草稿从静态历史匹配转变为动态语义预测。
  - 提出 **非对称双 Bonus Logits** 机制，同时利用早期层低成本探索与最终层权威纠错。
  - **分层双循环 + 状态复用** 有效绕过验证墙，且保持数学无损性。
- **工程友好性**：不引入额外部署参数，兼容现有早期退出架构，KV cache 回滚机制简单，同步开销极低。

## 8. 不足与局限

- **微调依赖**：最优加速依赖一次性微调（LayerSkip 权重），在 vanilla 未微调模型上性能下降（8B 模型从 2.71× 降至 2.44×），限制了即插即用的通用性。
- **部署场景局限**：当前实现主要针对 **本地/边缘端推理** 优化，分布式云环境的潜力仅作为未来工作探讨，尚未充分验证。
- **3 级级联未成功**：更深层级结构因早期 logits 质量低、同步开销翻倍而性能下降，2 级分层在 8B 规模为最优，但大规模模型上是否适用更深级联仍待探索。
- **超参数敏感性**：缓冲大小、早期退出层选择、n-gram 深度与 logits top-k 均需调优，过大或过小均导致性能退化。
- **实验覆盖偏差风险**：
  - 主要与无草稿模型方法对比，与 EAGLE-2 的对比仅在 Llama-3-8B 上进行；
  - 未涉及多模态、长上下文超长序列等场景；
  - 未报告微调数据规模、训练时长与能耗，算力透明度有限。
- **潜在应用限制**：早期层与最终层语义对齐依赖模型残差结构，对架构差异较大的模型（非 Transformer 或特殊注意力机制）可能不适用。
- **分布式扩展仅为理论探讨**：Limitations 中提出异步预生成与验证的构想，但未给出实验验证。
