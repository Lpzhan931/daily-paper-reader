## 摘要
推测解码通过使用轻量级草稿模型生成多个候选词元，并由目标模型在单次前向传播中验证，从而加速大语言模型（LLM）推理。其加速比在很大程度上取决于接受长度，然而现有草稿模型训练方法主要将交叉熵或 Kullback-Leibler（KL）散度作为代理目标进行优化。这些目标鼓励分布匹配，但并不直接优化接受长度，而且贪婪解码与基于采样的解码在接受机制上也存在差异。在这项工作中，我们提出了接受长度感知的训练损失，直接优化推测窗口内被接受词元的期望数量。对于贪婪验证，我们推导了期望接受长度（EAL）损失，显式最大化期望接受长度。对于基于采样的解码，我们引入了窗口全变差（WTV）损失，在考虑顺序接受依赖的同时，优化温度缩放后的草稿分布与目标分布之间的重叠。这两个目标还可以进一步与使用模拟接受长度作为奖励的组相对强化学习阶段（GRPO）相结合。在不同目标模型和草稿模型、任务以及解码设置上的实验表明，我们的损失在基于 KL 的训练基础上持续提升接受长度。WTV 在基于采样的解码下带来尤其显著的增益，而 EAL 更契合贪婪验证。这些结果表明，直接优化接受目标，并根据解码模式定制损失，比传统的分布匹配目标更为有效。

## Abstract
Speculative decoding accelerates large language model (LLM) inference by using a lightweight draft model to generate multiple candidate tokens that are verified by the target model in a single forward pass. Its speedup is largely determined by the acceptance length, yet existing draft-model training methods mainly optimize cross-entropy or Kullback-Leibler (KL) divergence as proxies. These objectives encourage distribution matching but do not directly optimize acceptance length, and the acceptance mechanism also differs between greedy and sampling-based decoding.   In this work, we propose acceptance-length-aware training losses that directly optimize the expected number of accepted tokens within a speculative window. For greedy verification, we derive an expected accepted length (EAL) loss that explicitly maximizes expected acceptance length. For sampling-based decoding, we introduce a window total variation (WTV) loss that optimizes the overlap between temperature-scaled draft and target distributions while accounting for sequential acceptance dependencies. Both objectives can be further combined with a group-relative reinforcement learning stage (GRPO) using simulated acceptance length as the reward.   Experiments across different target and draft models, tasks, and decoding settings show that our losses consistently improve acceptance length over KL-based training. WTV provides particularly strong gains under sampling-based decoding, while EAL better matches greedy verification. These results show that directly optimizing the acceptance objective, with losses tailored to the decoding mode, is more effective than conventional distribution-matching objectives.

# 论文总结：面向推测解码的接受感知草稿模型训练

## 1. 核心问题与研究动机

- **背景**：大语言模型（LLM）的自回归生成逐词元串行，推理效率低下。推测解码（Speculative Decoding）通过一个轻量级草稿模型一次性预测多个候选词元，再由目标模型在一次前向传播中并行验证，从而加速推理。
- **核心指标**：推测解码的加速比主要由**接受长度**（acceptance length，即每次验证中连续被接受的草稿词元数）决定。
- **关键矛盾**：
  - 现有草稿模型训练方法主要优化交叉熵或 KL 散度，这本质上只是"分布匹配"的**代理目标**。
  - 当草稿模型容量远小于目标模型时，无法完美复现目标分布，此时"最小化分布差异"与"最大化被接受词元数"的目标并不一致，KL 最优解未必是接受长度最优解。
- **被忽视的差异**：接受机制在**贪婪解码**与**基于采样的解码**下根本不同：
  - 贪婪验证：草稿词元需与目标模型 top-1 预测完全一致才被接受。
  - 采样验证：接受概率等于温度缩放后草稿分布与目标分布的**重叠度**（即 1 − TV 距离）。
  - 因此，单一训练目标难以在两种解码模式下都达到最优。
- **研究意义**：论文主张应直接围绕"接受长度"这一真实目标来设计草稿模型训练损失，并针对不同解码模式定制目标，从而比传统分布匹配方法更有效地提升推测解码效率。

## 2. 方法论

### 2.1 核心思想

- 将草稿模型训练从"分布匹配"转向"**直接最大化推测窗口内的期望接受长度**"。
- 利用一个统一的窗口模板：窗口大小为 γ，起点为 t，验证在首次拒绝处停止，故前 k 个词元被接受当且仅当每个都单独被接受。在条件独立假设下：
  - P(L_t ≥ k) = ∏_{j=0}^{k-1} a_{t+j}
  - E[L_t] = Σ_{k=1}^{γ} ∏_{j=0}^{k-1} a_{t+j}（尾和恒等式）
- 两种解码模式只是将上式中的单步接受概率 a_t 替换为对应的量。

### 2.2 关键技术细节

**（1）期望接受长度（EAL）损失——面向贪婪验证**

- 贪婪验证下单步接受概率：a_t = q_t(x*_t)，即草稿模型在目标模型选定词元 x*_t 上的概率。
- 由于训练序列由冻结目标模型贪婪生成，x*_t 即 ground-truth 词元，a_t 即草稿分配给真值续写的概率。
- 窗口接受长度分布（含"窗口耗尽"情形）：
  - P(L_t = 0) = 1 − a_t
  - P(L_t = ℓ) = (∏_{j=0}^{ℓ-1} a_{t+j})(1 − a_{t+ℓ})，1 ≤ ℓ ≤ γ−1
  - P(L_t = γ) = ∏_{j=0}^{γ-1} a_{t+j}
- 期望接受长度可化为紧凑尾和形式：E[L_t] = Σ_{k=1}^{γ} ∏_{j=0}^{k-1} a_{t+j}。
- 训练损失为其相反数：L_EAL(θ) = −(1/|W|) Σ_{t∈W} Σ_{k=1}^{γ} ∏_{j=0}^{k-1} a^greedy_{t+j}。

**（2）窗口全变差（WTV）损失——面向采样解码**

- 采样验证下单步拒绝率：r_t = TV(p̃_t, q̃_t)，接受概率 a_t = 1 − TV(p̃_t, q̃_t)。
- 其中 p̃、q̃ 为温度 T 缩放后的目标/草稿分布：p̃(v) ∝ exp(log p(v)/T)。
- 将 a_t 代入窗口模板，得到期望接受长度：
  - E[L_t] = Σ_{k=1}^{γ} ∏_{j=0}^{k-1} (1 − TV(p̃_{t+j}, q̃_{t+j}))
- WTV 损失即该期望值的相反数，直接优化温度相关的分布重叠，并显式建模跨窗口位置的**顺序依赖**（早接受对长序列的乘性影响）。
- TV 是 q̃ 的分段线性函数，故损失可微；梯度只流入草稿参数 θ，目标分布冻结。

**（3）GRPO 强化学习阶段（可选叠加）**

- 将接受长度作为不可微奖励，用组相对策略优化（GRPO）直接优化。
- **奖励构建**：单次前向三路计算——目标模型给出 x*_j、当前草稿 π_θ 给出 argmax、冻结参考草稿 π_ref 给出 argmax；按窗口切片得到模拟贪婪验证的接受长度 τ。
- **去偏奖励**：R^(t) = τ_{π,θ}^(t) − τ_{ref}^(t)，消除前缀难度影响，只保留相对增量；奖励停止梯度。
- **策略比**：沿当前策略轨迹计算 π_θ 与 π_ref 的对数概率比，用逐词元几何平均保持数值稳定，并裁剪到 [−10, 10]。
- **分组与优势归一化**：每条序列采样 G 个组锚点，每组 m 个窗口；组内标准化并裁剪得到优势 A^(t)。
- **GRPO 损失**：组内采用 PPO 式裁剪代理目标，再对 G 组平均。
- 该 RL 阶段在监督检查点之上叠加，权重 λ_GRPO = 0.1，与两种代理损失互补。

### 2.3 算法流程概述

1. 用冻结目标模型在目标生成的序列上对草稿做一次教师强制前向，得到各位置分布。
2. 计算逐位置接受概率 a_t（贪婪模式用 top-1 概率；采样模式用 1 − TV）。
3. 按窗口滑动累加乘积项，得到 EAL 或 WTV 损失，反向传播更新草稿参数。
4. 可选：在 SFT 结束后进入 GRPO 阶段，用模拟接受长度奖励进一步微调。

### 3.3 对比方法

- **L_KL**：基线，仅用前向 KL 散度锚点损失。
- **L_KL + L_TV**：KL 加逐位置 TV 距离辅助损失。
- **L_KL + L_EAL**：KL 加 EAL 辅助损失。

## 6. 主要结论与发现

- **贪婪验证下**：
  - 在 KL 锚点上加入 L_EAL 相比纯 L_KL 有**一致但幅度较小**的提升（如 Qwen3-8B/0.6B 树式：4.503 vs 4.494）。
  - 叠加 GRPO 后通常取得最佳结果（4.514）。
  - L_WTV 在贪婪验证下表现最弱（4.428），符合其接受模型与贪婪机制不匹配的预期。
  - 草稿模型越大，各目标在贪婪下的差距越小（Qwen3-1.7B 时均在 0.05 以内）。
- **采样验证下**：
  - L_WTV 取得**显著大幅领先**（Qwen3-8B/0.6B 树式：T=0.5 时 4.780 vs L_KL 4.304；T=1.0 时 5.750 vs 4.998）。
  - 在 Qwen3-32B/4B 上差距最大（T=1.0：6.671 vs 5.960）。
  - 叠加 GRPO 进一步带来小幅提升。
- **总体规律**：EAL 与贪婪验证对齐，WTV 与采样解码对齐，两者**互补**；按解码模式定制训练目标比统一使用分布匹配更有效。

## 7. 优点

- **问题定位精准**：明确指出"分布匹配"与"接受长度"之间的目标错配，并从理论上说明 KL 与接受率仅在草稿能完美复现目标时才共享最优解。
- **理论推导清晰**：从接受机制出发，分别推导贪婪与采样下的单步接受概率，并用统一的窗口尾和模板给出期望接受长度，形式优雅、可解释性强。
- **方法针对性强**：EAL 与 WTV 分别精确对应两种解码机制的接受行为，并显式建模窗口内顺序依赖（早接受对长序列的乘性影响）。
- **RL 阶段设计合理**：GRPO 用去偏奖励（减去参考策略接受长度）消除前缀难度，奖励停止梯度、策略比几何平均等细节考虑周到。
- **实验矩阵全面**：跨模型家族、模型规模、草稿结构、解码温度、多任务基准，结论一致且可复现性好。
- **工程可行性**：WTV 损失可微，且仅需一次草稿前向和一次目标前向即可并行计算所有位置的 a_t。

## 8. 不足与局限

- **训练数据偏差**：训练序列全部由目标模型**贪婪生成**，在采样解码（T>0）场景下，训练分布与推理分布可能存在不匹配，可能削弱 WTV 在更高温度下的泛化性。

- **算力与成本未披露**：未说明训练时长、总 GPU 小时或不同损失收敛速度的差异，难以评估实际训练开销。
- **超参数敏感性**：λ_GRPO、窗口大小 γ、温度 T 等关键超参的影响缺乏系统消融；GRPO 仅在 SFT 后叠加，未探索联合训练或更大权重。
- **模型覆盖有限**：主要基于 Qwen3 系列与 Gemma4，未涉及更多架构或混合专家模型；草稿模型最小仅 0.6B，极端小容量场景的结论可能不同。

- **基准与语言覆盖**：评测集中于英文任务，多语言、长上下文等场景未涉及。
