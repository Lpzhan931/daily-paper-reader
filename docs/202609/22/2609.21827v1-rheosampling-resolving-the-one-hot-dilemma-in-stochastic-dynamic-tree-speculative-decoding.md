## 摘要
推测解码通过并行草拟多个 token 来加速 LLM 推理，而基于树的方法进一步借助层次结构提升效率。诸如 EAGLE-3 之类的动态树方法通过确定性 top-K 扩展和全局剪枝，在贪心解码下表现良好。然而，在随机解码（T>0）中，该机制会将草拟分布坍缩为独热概率，导致接受率严重下降。这造成了一个两难：动态树方法为了保留上下文感知的拓扑结构而牺牲随机采样，静态树方法则以上下文无关的结构保留随机采样。该问题源于同一概率分布被用于两个相互冲突的任务：构建树和验证 token。这种耦合使得直接注入随机性因由此产生的随机过程而变得困难。我们通过解耦这些角色来解决该问题：RheoSampling 为从草拟分布中采样出的 token 赋予一个用于树扩展和剪枝的代理概率，同时保留其用于验证的真实采样概率。具体而言，我们在确定性的 top-K 槽位中注入一个采样 token，并在构建和验证阶段以不同概率对待它，使 RheoSampling 成为首个同时具备上下文感知 top-K 构建与随机采样且保持无损性的动态树方法。我们通过等价类分析建立无损性保证，该分析将随机树空间压缩为可处理的类别。基于 OT 的验证策略和稀疏草拟机制确保理论收益转化为实际效率。在多种 LLM 和基准上的实验表明，相较于最先进的动态树方法，该方法在接受率和加速比方面均有提升。该框架可能为分析随机树结构提供一个模板。

## Abstract
Speculative decoding accelerates LLM inference by drafting multiple tokens in parallel, with tree-based methods further improving efficiency through hierarchical structures. Dynamic-tree methods such as EAGLE-3 perform well under greedy decoding via deterministic top-K expansion and global pruning. However, in stochastic decoding (T>0), this mechanism collapses the draft distribution into one-hot probabilities, causing a severe drop in acceptance rate. This creates a dilemma: dynamic-tree methods sacrifice stochastic sampling to preserve context-aware topology, while static-tree methods preserve stochastic sampling with context-agnostic structures. The issue arises because the same probability distribution is used for two conflicting tasks: constructing the tree and verifying tokens. This coupling makes direct injection of randomness challenging due to the resulting stochastic process. We resolve this by decoupling these roles: RheoSampling assigns a token sampled from the draft distribution a proxy probability for tree expansion and pruning alongside its true sampling probability for verification. Specifically, we inject a sampled token among the deterministic top-K slots and treat it with different probabilities during construction and verification, making RheoSampling the first dynamic-tree method with both context-aware top-K construction and stochastic sampling while maintaining losslessness. We establish the lossless guarantee through an equivalence-class analysis that compresses the stochastic tree space into tractable classes. An OT-based verification strategy and a sparse draft mechanism ensure that theoretical gains translate into practical efficiency. Experiments across LLMs and benchmarks demonstrate improvements in acceptance rate and speedup over state-of-the-art dynamic tree methods. This framework may provide a template for analyzing stochastic tree structures.

# RheoSampling 论文总结

## 1. 核心问题与整体含义

- **背景**：推测解码（Speculative Decoding）通过轻量草稿模型并行预测多个 token，再由目标模型一次性验证，从而加速 LLM 自回归推理。基于树的方法（tree-based speculative decoding）将多个候选序列组织为树结构，进一步提升每步匹配概率。
- **动态树 vs 静态树的两难**：
  - 动态树方法（如 EAGLE-2/3）采用"扩展—重排"范式：按路径概率确定性选择 top-K token 扩展，再做全局剪枝。在贪心解码（T=0）下表现优异。
  - 但在随机解码（T>0）下，由于候选 token 完全由 top-K 确定性选取，草稿分布被坍缩为一组点质量（one-hot），丢弃了长尾概率信息，导致接受率严重下降。
  - 静态树方法虽保留随机采样，但树结构上下文无关，效率较低。
- **根本原因**：同一概率分布被同时用于两个相互冲突的任务——**构建树**（扩展、重排、剪枝）与**验证 token**。这种耦合使得随机性注入极为困难，因为树拓扑与采样 token 身份紧密纠缠，形成一个概率空间过大的复杂随机过程。
- **论文含义**：RheoSampling 是首个在动态树中同时实现上下文感知 top-K 构建与随机采样、且保持无损性的方法，为随机树结构分析提供了通用模板。

## 2. 方法论

### 核心思想：双身份解耦（Dual-Identity Decoupling）

为单个随机采样 token 赋予两个独立概率身份：
- **代理概率（proxy probability）**：用于树构建（扩展、重排、剪枝）；
- **真实采样概率（true sampling probability）**：用于验证。

### 混合采样机制

在每个扩展步骤的 K 个候选槽位中：
1. 确定性选取 top-m 个草稿概率最高的 token（lead tokens）；
2. 从残差分布 ˜q（top-m 之外的尾部）中采样 1 个代表性 token x_s；
3. 用剩余词汇表中排名最高的 token 填充剩余 K−m−1 个槽位（fill tokens）。

### 采样 token 的双重处理

- **树构建阶段**：代理概率设为
  q_proxy(x_s) = min{ q(x_m), z }，其中 z = 1 − Σ_{i=1}^{m} q(x_i) 为残差质量。
  该设计保证 x_s 在候选池中排在所有 fill token 之前，使其**存活与自身实现身份无关**（关键无损性条件）。
  - 当 m=0 时，代理概率设为 q(x_1)+ε，锚定在第一位。
- **验证阶段**：使用真实采样概率 ˜q(x_s)，而非代理概率，从而保证无损性。

### 流变参数 m（Rheostat Parameter）

- m 控制代理概率大小与前置确定性 token 数量：
  - m 越小 → 代理概率越大 → 采样 token 存活率越高，但确定性骨干减少；
  - m 越大 → 树拓扑质量越高，但采样节点可能被剪枝。
- m 起到"流变器"作用，平衡随机存活与结构质量。

### 稀疏草稿分布

- 在 softmax 前将 logits 截断至 top-128，其余设为 −∞，得到稀疏分布，实现大词表高效采样。
- 只要验证使用与草稿相同的截断分布，无损性保持；top-128 已覆盖 91% 以上概率质量。

### RheoVerification（基于最优传输的验证）

给定剪枝后候选集 C = {u_1,…,u_n}：
1. 若采样 token u_s 存活（s ≠ −1）：
   - 先以 min(1, p(u_s)/˜q(u_s)) 独立验证，接受则进入其子树；
   - 若拒绝，计算残差分布 r = norm(max(0, p − ˜q))，在剩余候选上做递归拒绝；
   - 若全部拒绝，从最终残差采样。
2. 若无采样 token（s = −1），退化为标准 top-K 验证。

### 理论保证

- **定理 1（无损性）**：对任意剪枝预算 R 与任意序列 Seq，E_{T_R}[Pr(Rheo(T_R)=Seq)] = p(Seq)。
- **引理 4（局部排序保持）**：q_proxy(Y) = min{q(x_m), z} ≥ q(x_{m+1})，保证采样 token 在兄弟组内固定在 rank m+1。
- **定理 3（单层接受率）**：给出闭式表达，并证明在温和近似下 Rheo 几乎总优于 RRSw。
- 证明方法：**等价类分析**，将随机树空间压缩为可处理类别，对 R 做数学归纳。

## 6. 主要结论与发现

- RheoSampling 在所有模型与任务上均一致提升平均接受长度 τ，增益范围 +0.14（Vicuna-13B）至 +0.22（DeepSeek-R1-Distill-8B）。
- 加速比提升略小于 τ 提升（如 Llama-3.1-8B：τ +4.2%，加速 +3.2%），原因是采样与验证的额外开销；但净加速在所有模型上均为正。
- **m=1 为最佳甜点**：既保证代理质量足以存活重排，又充分利用 OT 验证优势；m=0 与 m=2 仍优于 Top-K，m≥3 收益递减。
- 温度降低时各方法趋近，Rheo 与 Top-K 差距收窄；m=0 具有"双重退化"（采样与结构均退化为 Top-K），m=1 仅"单重退化"（采样退化但结构仍不同）。
- RheoVerification 在受控实验中达 85.4% 接受率，高于 RRSw 的 83.5% 与 Top-K 的 80.0%。
- 稀疏支持 128–1024 与 Full 的 τ 相当（4.78–4.85 vs 4.89），延迟稳定在 ±0.2 ms。
