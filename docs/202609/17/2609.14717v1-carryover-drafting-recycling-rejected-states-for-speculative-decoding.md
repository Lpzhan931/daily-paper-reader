## 摘要
投机解码通过并行验证多个草稿 token 来加速大语言模型推理，使单次目标模型前向传播能够接受多个 token。按照其构造，验证会同时计算被接受和被拒绝 token 的表示。然而，传统草稿模型只保留被接受 token 的表示，使得花费在被拒绝 token 上的大量验证器计算实际上被浪费。我们发现，目标模型前向传播期间产生的这些被丢弃隐藏状态保留了关于未来 token 的有用信息，可用于改进后续草稿。然而，实现这一机会面临两个不同挑战。在推理时，回收开销可能增加草稿延迟，从而削弱由接受长度增加带来的加速。在训练时，标准并行草稿模型训练不会产生与推理对齐的被拒绝状态，而通过顺序展开获得这些状态又会牺牲跨训练位置的并行性。我们提出 Carryover Drafting，以解决这两个挑战。Carryover 将被拒绝的目标隐藏状态回收为临时 KV 上下文，使草稿模型能够有选择地关注它们。它复用草稿模型已有的接口，仅添加一个可学习嵌入来区分被拒绝状态与已提交上下文。额外的 KV 上下文在每轮草稿中被替换，使其长度限制在一个提议块内。我们提出并行的草稿—验证—草稿训练，使草稿模型接触到与推理对齐的被拒绝状态，同时保持跨训练位置的并行性。在 DFlash 以及一个源自 DSpark 的半自回归草稿模型上、跨两个目标模型的实验表明，这一简单的 Carryover 机制将平均接受长度提高了 6.5--14.7%，将端到端 vLLM 加速比相对于相应基线提高了 7.9--14.4%，在翻译任务上加速增益达到 28.8%。

## Abstract
Speculative decoding accelerates LLM inference by verifying multiple drafted tokens in parallel, allowing a single target forward pass to accept several tokens. By construction, verification computes representations for both accepted and rejected tokens. Yet, conventional drafters retain only the representations of accepted tokens, leaving the substantial verifier computation spent on rejected tokens effectively wasted. We find that these discarded hidden states generated during target forward retain useful information about future tokens that can improve subsequent drafts. However, realizing this opportunity poses two distinct challenges. At inference, recycling overhead can increase drafting latency, diminishing the speedup gained from increased acceptance length. During training, standard parallel drafter training does not produce inference-aligned rejected states, while obtaining them through sequential rollouts would sacrifice parallelism across training positions. We introduce Carryover Drafting, which addresses both challenges. Carryover recycles rejected target hidden states as temporary KV context, allowing the drafter to selectively attend to them. It reuses the drafter's existing interface and adds only a single learned embedding to distinguish rejected states from committed context. The additional KV context is replaced each drafting round, keeping its length bounded by one proposal block. We introduce parallel draft--verify--draft training that exposes the drafter to inference-aligned rejected states while preserving parallelism across training positions. Experiments with DFlash and a DSpark-derived semi-autoregressive drafter across two target models show that this simple Carryover mechanism improves average acceptance length by 6.5--14.7% and end-to-end vLLM speedup by 7.9--14.4% over the corresponding baselines, with speedup gains reaching 28.8% on translation.

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：自回归 LLM 每次前向只生成一个 token。投机解码（speculative decoding）通过轻量 drafter 并行提出多个 token，再由目标模型（target）单次前向并行验证，从而一次接受多个 token 来加速推理。
- **核心矛盾**：验证过程**天然地**为被接受和被拒绝的 token 都计算了表示（hidden states）。但传统 drafter（如 EAGLE、EAGLE-3、DFlash、DSpark）只保留**被接受 token** 的隐藏状态作为后续草稿条件，**被拒绝 token 的隐藏状态被直接丢弃**，导致大量验证计算被浪费。
- **关键观察**：作者发现，这些被丢弃的目标隐藏状态中，仍保留着关于**未来 token** 的有用信息，可以改善后续草稿质量。
- **两个待解挑战**：
  - **推理侧**：回收拒绝状态会增加草稿延迟（投影 + 注意力开销），若开销过大，会抵消接受长度提升带来的加速；若跨轮累积保留，KV 上下文会无限增长。
  - **训练侧**：标准并行 drafter 训练基于录制好的目标响应，**不会产生与推理对齐的被拒绝状态**；若改用顺序 rollout 获取，则会破坏跨训练位置的并行性。
- **整体意义**：论文把"验证阶段的废弃物"（rejected states）转化为"可利用的上下文"，在不改变目标分布与接受规则的前提下提升接受长度与端到端加速，属于对既有投机解码接口的**轻量级增强**。

## 2. 方法论

### 核心思想
- **Carryover Drafting**：将上一轮验证中产生的**被拒绝目标隐藏状态**回收为下一轮草稿的**临时 KV 上下文**，让 drafter 通过其**已有的注意力层**选择性地关注它们。
- 设计原则：**复用现有接口**（复用同一个投影 F 与 K/V 投影）、**每轮替换**（长度上界为一个 proposal block）、**仅新增一个可学习嵌入**（`E_carry`）来区分拒绝状态与已提交上下文。

### 关键技术细节

- **接口与符号**：
  - 第 r 轮目标隐藏状态 `H_r = (h_{r,1},...,h_{r,B})`，由选定目标层隐藏状态拼接而成。
  - 接受前缀 `H_acc = h_{r,1:m_r}`，拒绝部分 `H_rej = h_{r,m_r+1:B}`。
  - 现有投影：`Φ_ℓ(H) = (K_ℓ(F(H)), V_ℓ(F(H)))`。
- **Carryover 更新（式 1–2）**：
  - 对拒绝状态先加嵌入再投影：`U_{r+1,ℓ} = Φ_ℓ(H_rej + E_carry)`。
  - 新上下文：`ctx_{r+1,ℓ} = [C_{r+1,ℓ} ; U_{r+1,ℓ}]`，其中 `C` 为基线更新后的已提交 drafter KV 上下文。
  - **每轮用新 `U` 替换旧 `U`**；全部接受时 `U = ∅`。额外上下文**上界为 B 行/层**，存储复用验证窗口。
- **语义边界**：被拒绝状态只是 drafter 的**只读上下文**，不替换接受 token 的隐藏状态，**不进入目标 KV cache**，也不改变目标概率与接受规则（因此采样正确性不受影响）。
- **位置编码**：每个拒绝状态保留其被计算时的绝对位置，RoPE 仅在投影成 key 时应用一次。

### 训练：Parallel Draft–Verify–Draft（图 2 / 算法 2）
1. 在录制好的目标响应 `y` 上随机采样 512 个 anchor `a_i`。
2. **Draft（无梯度）**：drafter 生成 proposals（detached）。
3. **Verify（无梯度）**：冻结目标以 **block-diagonal causal mask** 并行验证各分支；贪心验证得到接受长度 `m_i` 与被拒绝隐藏状态 `H_rej_i`。
4. **位置平移**：anchor 移到 `a'_i = a_i + m_i + 1`（下一个 correction/bonus 位置）。
5. **Draft（有梯度）**：第二遍草稿读入录制前缀与 `H_rej_i`（经式 2），对 `y_{>a'_i}` 的录制续写进行监督。梯度只流经第二遍，包括共享投影与 `E_carry`。
- **并行性保持**：各 anchor 的 draft–verify–draft 转换相互独立，所有 anchor 在同一阶段内并行处理；不采样新目标续写，监督来源仍是原始录制响应。
- **全接受情形**：`H_rej = ∅`，第二遍退化为平移 anchor 处的基线训练，仍然贡献监督。

### 延迟模型
- `L_carry ≈ (t_draft + t_verify + t_reuse) / τ`，`S_carry ≈ τ · t_AR / (t_draft + t_verify + t_reuse)`；加速的前提是接受长度提升能覆盖 `t_reuse`。

## 6. 主要结论与发现

- **主结论**：回收被拒绝的目标隐藏状态可稳定提升草稿质量。
  - 平均接受长度提升 **6.5%–14.7%**；相对基线的端到端 vLLM 加速提升 **7.9%–14.4%**；翻译任务最高 **+28.8%**（Qwen3-4B Markov, T=1）。
- **增益具有普适性**：在全部数据集设定中都有接受长度提升；从完全并行的 DFlash 到半自回归的 Markov 都受益，说明 Carryover 与块内依赖建模**互补**。
- **任务差异**：翻译增益最大（相对提升最高），作者用 **re-convergence** 解释——被拒绝状态是否"预测最终续写"比"拒绝状态数量"或"拒绝后接受率"更能决定增益。
- **机制验证**：
  - 匹配 anchor 下，ON 比 OFF 在**每个位置** Recall@1 高 1.28–5.60 点、Recall@16 高 0.29–1.89 点，且增益从位置 0 即出现。
  - 注意力诊断显示约 **19.78%** 的全 softmax 注意力落在 carried 行上（15 个拒绝状态子集为 23.40%），证明 drafter 确实读取了该接口。
  - 归一化 re-convergence 与数据集级增益相关性 r=0.96（去掉翻译 0.90），显著高于"拒绝后接受"的 r=0.52（0.71）和"拒绝状态数"的 r=0.74（0.84）。
  - Markov 的 re-convergence（2.76/轮）高于 DFlash（2.51/轮），在 8 个数据集中的 7 个获得更大 Carryover 增益——暗示**更强的 drafter 会留下更有用的拒绝状态**。
- **接口选择**：回收**目标隐藏状态**优于回收 token 提示；单个 `E_carry` 嵌入与 19.7M 独立投影器效果接近，但前者更轻量。

## 7. 优点

- **方法极简且轻量**：完全复用已有投影与 KV 接口，只新增一个可学习嵌入；每轮替换使额外上下文上界固定为一个 proposal block（B 行/层），工程集成成本低。
- **不破坏正确性**：拒绝状态仅作为 drafter 的只读上下文，不写入目标 KV、不改变目标概率与接受规则，采样正确性有清晰论证。
- **训练方案巧妙**：parallel draft–verify–draft 在**不牺牲 anchor 间并行性**、不采样新目标续写的前提下，构造出与推理对齐的拒绝状态；全接受样本也被复用为平移 anchor 处的基线监督。
- **实验覆盖广且对照严格**：2 目标 × 2 drafter 范式 × 8 任务 × 2 温度 + 并发扫描；Baseline/Carryover 共享数据与配置，增量训练仅 3 epochs，结论可信度较高。
- **分析深入**：不止报告增益，还通过匹配 anchor 的 Recall 分析、注意力诊断和 re-convergence 相关性，解释了"增益从何而来"以及"为何任务间差异大"，并给出可证伪的机制假设。
- **实用导向**：给出延迟模型与开销上界分析，并展示高并发下相对增益依然保持。
