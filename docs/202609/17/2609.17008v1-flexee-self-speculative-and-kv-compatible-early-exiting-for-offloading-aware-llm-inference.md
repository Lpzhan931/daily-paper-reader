## 摘要
大型语言模型（LLM）推理通常同时受到计算和内存的制约，尤其是在基于卸载的部署中，模型权重在自回归解码期间需要在不同内存层级之间传输。在这种情况下，减少执行的层数可以降低每token延迟，同时避免代价高昂的权重移动。受此观察启发，我们提出FlexEE，一种面向资源受限和基于卸载的LLM推理的提前退出框架。FlexEE通过逐层退出监督以实现可靠的中间层预测、基于Top-K局部词表的自推测解码以降低退出决策成本，以及动态隐藏状态管理以实现KV缓存正确且内存感知的执行，使提前退出在LLM解码中变得实用。在生成任务和下游任务上，FlexEE能够在精度损失最小的情况下实现高效提前退出，在0%/50%权重卸载下，分别在Llama2-7B和Llama3-8B上实现高达1.27×/3.16×和1.25×/2.83×的端到端加速。

## Abstract
Large language model (LLM) inference is often constrained by both computation and memory, especially in offloading-based deployments where model weights are transferred across memory hierarchies during autoregressive decoding. In this setting, reducing the number of executed layers can lower per-token latency while also avoiding costly weight movement. Motivated by this observation, we present FlexEE, an early exiting framework for resource-constrained and offloading-based LLM inference. FlexEE makes early exiting practical for LLM decoding through layer-wise exit supervision for reliable intermediate-layer prediction, self-speculative decoding over a Top-K local vocabulary for low-cost exit decisions, and dynamic hidden state management for KV-cache-correct and memory-aware execution. Across generative and downstream tasks, FlexEE enables efficient early exit with minimal accuracy degradation, delivering up to 1.27$\times$/3.16$\times$ and 1.25$\times$/2.83$\times$ end-to-end speedups on Llama2-7B and Llama3-8B under 0\%/50\% weight offloading, respectively.

# FlexEE 论文总结

## 1. 核心问题与研究背景

- **研究动机**：LLM 推理同时受计算与内存约束。在基于权重卸载（offloading）的部署中，模型参数超出片上内存，需在自回归解码过程中按需从 CPU 内存/磁盘加载层权重，推理瓶颈由计算转移到**片外内存访问**。
- **关键洞察**：减少实际执行的层数，不仅能降低每 token 计算量，还能**减少需要加载的层参数数量**，从而直接缓解数据搬运瓶颈。因此“提前退出”（early exiting）在卸载场景下具有独特价值。
- **现有方法的三类挑战**（论文图 1a）：
  - **挑战 1：中间层建模能力弱**。标准 LLM 仅对最终层做解码训练，中间隐藏状态的语义可解码性差，直接早退会导致质量严重下降。
  - **挑战 2：退出决策开销高**。传统方法需在每个候选退出层将隐藏状态投影到完整词表（如 Llama2 的 32K），大矩阵乘与搜索开销抵消了跳层收益。
  - **挑战 3：KV 缓存不兼容**。早退会跳过后续层，导致后续 token 所需 KV 缓存缺失或不一致。
- **整体含义**：论文提出 **FlexEE**，一个面向卸载感知、算法与系统协同设计的早退框架，目标是在资源受限设备上让早退真正可用——既提速，又保持 KV 缓存正确性与生成质量。

## 2. 方法论

### 2.1 核心思想

- 采用“**逐层早退监督 + 自推测局部词表 + 动态隐藏状态管理**”三件套：
  - 用逐层监督把最终层的解码能力“下放”到浅层；
  - 用 Top-K 局部词表替代全词表投影，降低退出决策开销；
  - 用动态隐藏状态缓存替代强制 KV 复制/重建，兼顾语义连续性与卸载效率。

### 2.2 逐层早退监督（算法基础）

- 训练时在多个关键 Transformer 层共享同一个 LM head，对中间层隐藏状态施加统一语言建模目标，使中间表示与最终层解码分布对齐，且**不引入额外推理开销**。
- 训练目标（式 1）为各层交叉熵损失的加权和，权重 $\tilde{e}(t,l)$ 随训练逐步从深层向浅层迁移，避免过度正则化浅层表示。
- 实验表明该监督显著降低中间层熵与 WikiText 困惑度，而最终层性能几乎不变。

### 2.3 退出特征选择（统计分析驱动）

- 比较四类候选特征：Top Prob、Gap（Top-1 与 Top-2 概率差）、Top Logit、Prob Shift。
- 通过离线统计（30 万 WikiText token）计算每层最小阈值 $\lambda_l^*$（式 2），使满足退出条件的 token 中至少 $\tau$ 比例与最终层预测一致；并定义覆盖率 $r_{\lambda_l}$（式 3）。
- 结论：**Top Prob 与 Gap** 阈值平滑、覆盖率高、跨模型一致，被选为主特征；Top Logit 不稳定，Prob Shift 覆盖率低。

### 2.4 自推测轻量预测器（Top-K 局部词表）

- 观察到经逐层监督后，中间层预测高度集中，最终层 Top-1 token 常落在浅层的 Top-N 候选集内。
- 定义命中率 $H_l(N)$（式 4）与局部—全局 Top-1 概率偏差 $E_l(N)$（式 5）；实验显示 $N=30$ 是覆盖率与近似误差的较优折中（Llama2 取 K=30，Llama3 因 128K 词表取 K=80）。
- **两阶段设计**（图 2c）：
  1. **自推测层**：做一次全词表投影，选出 Top-K token 构成局部候选词表；
  2. **早退层**：仅在 K 个候选上做投影，计算局部 Top-1 概率与局部 Gap，二者同时超过离线标定阈值才触发退出。
- 阈值在局部候选空间内离线搜索，保证校准数据集上早退准确率 > 0.99（附录 A）。

### 2.5 动态隐藏状态管理（KV 兼容）

- 问题：早退跳过后续层，导致后续 token 的 KV 缓存缺失。已有方案包括状态复制、KV 复制、KV 驱逐，但要么增加计算，要么损害语义一致性。
- FlexEE 方案（图 5）：
  - token 在中间层退出时，**保留该退出层的隐藏状态**；
  - 生成下一个 token 时，当计算到达退出层之后的第一层，将保留的隐藏状态与当前 token 表示联合参与计算；
  - 该层 KV 缓存更新完成后，立即清除缓存隐藏状态以回收内存。
- 优势：不强制跨层复制 KV，保持跨 token 语义连续性；仅在必要时引入额外状态参与，避免对所有剩余层做冗余 KV 重建；在卸载场景下**无需为当前 token 加载后续层权重**，直接减少片外权重流量。
- 附录说明隐藏状态缓存内存可由未被更新的下一层 K/V 缓存区域复用，实际额外内存开销有限。

## 6. 主要结论与发现

- **精度保持良好**：在多数下游任务上 FlexEE 与 Dense 解码精度相当，部分任务（如 SST）甚至略优；PPL 有所上升但幅度可控（如 Llama2-7B WikiText 从 5.32 到 6.10–6.42）。
- **显著加速**：
  - Llama2-7B：0% 卸载 **1.27×**，50% 卸载 **3.16×**，75% 卸载 **3.29×**；
  - Llama2-13B：0% **1.25×**，50% **2.67×**，75% **2.68×**；
  - Llama3-8B：0% **1.25×**，50% **2.83×**，75% **3.10×**。
- **卸载比例越高收益越大**：因早退同时减少计算与权重搬运；但从 50% 到 75% 边际收益递减，原因是早退多发生在较深层，无法充分利用额外卸载层。
- **优于现有早退方法**：在 PPL 与多项任务上显著优于 AdaInfer、SpecEE、ShortGPT；在 HF 实现下吞吐提升最高约 1.18×。
- **自适应退出分布**：token 并不固定在某一层退出，简单 token 在自推测层后不久即退出，困难 token 延后至更深层或最终层。
- **开放式生成质量接近 Dense**：AlpacaEval-LC 胜率约 49%–50%，MT-Bench 分数几乎一致。
- **小批场景优势最大**：批大小增大后收益减弱，符合其面向单用户交互式、内存受限推理的定位。

## 7. 优点

- **系统—算法协同设计**：不是单纯算法早退，而是针对卸载场景的权重搬运瓶颈做联合优化，问题定位精准。
- **KV 缓存处理有新意**：动态隐藏状态管理避免强制 KV 复制/重建，同时不加载后续层权重，语义一致性与效率兼顾。
- **自推测局部词表有效降本**：用 Top-K 候选空间替代全词表投影，显著降低退出决策 FLOPs（仅为 SpecEE 的约 1/2.52、AdaInfer 的约 1/30.74）。
- **统计驱动、可复现**：退出特征、阈值、Top-K 选择均基于离线统计与公式化定义，附录提供跨数据集阈值一致性与计算分析。
- **实验维度丰富**：涵盖精度、PPL、吞吐、开放式生成、批大小、卸载比例与多组消融，结论相互印证。
- **实用定位清晰**：明确面向小批、内存受限、边缘/端侧交互式推理场景。

## 8. 不足与局限

- **依赖底层模型质量**：需基于 LayerSkip 等带逐层早退监督的预训练模型，普通现成 LLM 无法直接获得同等效果；“训练无关”主要指预测器，而非模型本身。
- **大 batch 收益下降**：批内样本需全部退出后才能跳层，异构退出深度削弱跳层机会，故不适合高吞吐批处理服务。
- **0% 卸载加速有限**：仅约 1.25×–1.27×，说明其核心价值集中在卸载/内存受限场景。
- **卸载收益边际递减**：50%→75% 卸载时加速提升趋缓，因退出多发生在深层。
- **阈值校准依赖校准集**：需在 WikiText 等语料上离线搜索阈值，跨域泛化虽由余弦相似度支持，但未覆盖全部任务类型（如代码、多语言）。
- **评测偏差风险**：开放式生成依赖 GPT-4 类裁判，可能存在风格/长度偏差；主评测以英文任务和 Llama 系列为主，跨模型家族（如 Mistral、Qwen）与多语言验证不足。
- **系统开销未完全展开**：动态隐藏状态缓存的内存上界、异步加载重叠效率、真实边缘设备端到端能耗等未详细量化。
- **伦理与安全风险**：早退会改变输出分布，论文自身也提示需配合标准安全措施与任务特定评估，高风险领域慎用。
