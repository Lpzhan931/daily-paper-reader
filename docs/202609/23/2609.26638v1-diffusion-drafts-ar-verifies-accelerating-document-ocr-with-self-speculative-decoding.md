## 摘要
自回归 OCR 视觉语言模型能准确地将文档图像转换为文本和结构化标记，但每个输出 token 都需要一次顺序解码步骤，限制了推理速度。与开放式文本生成不同，OCR 输出与输入图像紧密关联，这使得基于扩散的并行生成颇具前景。然而，当一个扩散步骤中预测多个 token 时，每个 token 都是在其他 token 未知的情况下预测的。因此，直接提交它们可能引入错误。为此，我们提出 GravityOCR，一种参数共享的自回归块扩散模型，联合训练用于并行草稿生成和因果自回归验证。在提交之前验证草稿，使模型无需单独的草稿网络即可每轮提交多个输出 token。因果自回归路径还使 GRPO 能够使用序列级和结构级 OCR 奖励，在更新共享草稿器参数的同时避免扩散轨迹的似然估计。在 OmniDocBench v1.6 上，AR 路径 GRPO 将 Overall 分数从 94.92 提升至 95.16，且未降低扩散草稿效率，同时最终模型仍接近原始 GLM-OCR 的 95.48 分。在 SGLang 服务部署中，GravityOCR 每次前向传播平均提交 9.7 个输出 token，在区域裁剪上实现 3.94× 的仅解码加速，相比 AR 解码实现 1.32× 的端到端页面处理加速。

## Abstract
Autoregressive OCR vision-language models accurately convert document images into text and structured markup, but require one sequential decoding step per output token, limiting inference speed. Unlike open-ended text generation, OCR outputs are strongly grounded in the input image, making diffusion-based parallel generation promising. However, when several tokens are predicted in one diffusion step, each is predicted before the others are known. Committing them directly can therefore introduce errors. We therefore introduce GravityOCR, a parameter-shared AR-block-diffusion model jointly trained for parallel drafting and causal AR verification. Verifying drafts before commitment lets the model commit multiple output tokens per round without a separate drafting network. The causal AR path also enables GRPO with sequence- and structure-level OCR rewards, avoiding diffusion-trajectory likelihood estimation while updating the shared drafter parameters. On OmniDocBench v1.6, AR-path GRPO improves the Overall score from 94.92 to 95.16 without reducing diffusion drafting efficiency, while the final model remains close to the original GLM-OCR score of 95.48. In an SGLang serving deployment, GravityOCR commits an average of 9.7 output tokens per forward pass and achieves a $3.94\times$ decode-only speedup on region crops and a $1.32\times$ end-to-end page-processing speedup over AR decoding.

# GravityOCR 论文深度总结

## 1. 核心问题与研究动机

- **背景**：生成式 OCR 视觉语言模型（如 GLM-OCR、MinerU2.5、PaddleOCR-VL 等）已成为文档理解的主流方案，能将文档图像转换为纯文本及 HTML、LaTeX 等结构化标记。但主流系统普遍采用**自回归（AR）解码**，每个输出 token 都需要一次串行解码步骤，直接制约了大规模部署时的延迟与吞吐。
- **机遇**：与开放式文本生成不同，OCR 输出**强约束于输入图像**，大量输出位置由图像内容直接决定，因而天然适合扩散式并行生成。已有工作（MinerU-Diffusion、DODO）尝试用掩码扩散一次恢复多个位置。
- **核心矛盾**：视觉锚定并不能消除 OCR 输出 token 之间的**序列依赖**——文本必须保持阅读顺序，表格与公式的标签、定界符必须结构一致。在一个扩散步骤中，多个位置被同时预测时**彼此不可见**，直接提交这些预测会产生遗漏、重复或结构错误（论文图 2 给出了典型失败案例：置信度阈值 τ=0.7 时，`commercial` 与 `enter` 被同时提交，导致中间的 `vehicles` 被漏掉；行尾的 `the` 在左侧两个位置尚未确定时被提前提交，最终产生 `to the the` 的重复）。
- **整体含义**：论文主张把「并行草稿」与「token 提交」解耦——用块扩散路径并行提议一个 token 块，用因果 AR 路径在提交前验证，从而在不牺牲识别精度的前提下大幅减少顺序解码步数。

## 2. 方法论

### 2.1 核心思想：参数共享的 AR–块扩散混合模型

- 从预训练 AR OCR 模型（GLM-OCR）改造而来，**视觉编码器、语言解码器、LM head 全部共享**，唯一新增参数是一个 `[M]` 掩码 token 的嵌入向量，**不需要独立草稿网络或辅助预测头**。
- 联合训练两种预测模式：块扩散负责并行草稿，因果 AR 负责验证并决定最终提交的 token。

### 2.2 联合 AR–扩散训练（图 3）

- 每个训练步在**一次前向**中同时处理三条响应流，共享同一图像 I 与任务提示 c（图像与提示均不被破坏）：
  - **干净流（clean stream）**：提供因果下一 token 监督，训练 AR 验证器；
  - **两条互补损坏流**：对每个块采样噪声水平 t∼U(0,1)，第 1 条流遮蔽 M_t 位置（遮蔽率约 t），第 2 条流遮蔽同一块中**互补**的位置（遮蔽率约 1−t）。两条流互补后，每个响应 token（含每段响应的 B 个 EOS）恰好被监督一次，图像与提示 token 永不参与去噪监督。该互补掩码方案沿用 Fast-dLLM v2。
- **注意力模式**：干净流使用因果注意力；损坏流中，块内双向注意力，可注意已完成的干净前缀块 y(<b)，但不能注意当前或未来的干净块。两条流均从位置 i−1 的 logit 预测 y_i。
- **损失函数**：L = L_AR + λ·L_diff，实现中两条目标各占 0.5 权重（λ=1），损失按 1+λ 归一化，时间步权重 w(t)=1。

### 2.3 自推测解码（图 4）

每轮流程如下（块大小 B=32，草稿仅用**一次**前向生成，不做迭代去掩码或置信度筛选）：

1. **状态**：KV 缓存保存所有已提交 token 的因果状态，但边界 token x₀（上一轮验证器预测的最后一个 token）尚未作为输入喂入模型。
2. **草稿前向**：窗口由 x₀ 加 B 个 `[M]` 组成。边界位置因果注意缓存，掩码位置在窗口内双向注意。一次前向同时得到 a₀（与因果 AR 预测完全相同的边界预测）与草稿 d₁:ᴮ。
3. **验证前向**：将 [a₀, d₁:ᴮ] 以 token 级因果注意力再前向一次，得到 AR 预测 a₁:ᴮ₊₁。验证过程复用草稿的 KV 槽位并把双向状态覆写为因果状态，因此**无需额外的缓存构建前向**。
4. **接受规则**：接受满足 d_j = a_j 的最长草稿前缀长度 A，提交 a₀、d₁:ᴬ 以及下一个 AR token a_{A+1}；被拒后缀的 KV 状态被释放。每轮至少提交 2 个 token，最多 B+2 个。
5. **下一轮**：a_{A+1} 成为新的边界 token。

**AR 等价性**：在 top-1 贪心解码与精确算术下，提交序列可归纳地证明与同一检查点的独立贪心 AR 输出完全一致。bf16 下在 8,922 个英文 OmniDocBench 裁剪上 96.6% 完全一致，其余差异符合近似并列 argmax 翻转（首个分歧位置前两名 logit 中位差距仅 0.14 nats，305 个分歧中 65 个差距低于 0.05 nats）。

### 2.4 因果 AR 路径上的 GRPO

- OCR 质量由序列级与结构级指标评价，token 级似然训练无法直接优化。多步掩码扩散的序列似然需要对去掩码轨迹做边缘化，已有 RL 方法只能近似或沿轨迹做策略梯度。
- 由于**验证器决定最终输出**，可以直接在 AR 路径上使用精确的自回归似然做标准 GRPO，更新共享参数（草稿器通过参数共享间接受益），**完全绕开扩散轨迹似然估计问题**。
- **任务感知奖励**（均在 [0,1]）：
  - 纯文本：归一化编辑相似度 1−NED；
  - 表格：r_table = clip(0.45·TEDS_s + 0.55·s_cell)·(1−p_row)·(1−p_loop)，含行列数匹配的网格奖励、未闭合 `<table>` 直接置零；
  - 公式：canonical LaTeX 的编辑相似度乘以良构性检查的惩罚因子 0.3^v；
  - 所有奖励再乘退化防护项（基于 8-gram 多样性与最长重复字符段）。
