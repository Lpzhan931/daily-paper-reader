## 摘要
推测解码通过并行草拟多个 token 来加速 LLM 推理，而基于树的方法通过层次结构进一步提升了效率。诸如 EAGLE-3 之类的动态树方法借助确定性的 top-K 扩展和全局剪枝，在贪婪解码下表现良好。然而，在随机解码（T>0）中，该机制会将草稿分布坍缩为独热概率，导致接受率严重下降。这造成了一个困境：动态树方法为保留上下文感知的拓扑而牺牲随机采样，静态树方法则以上下文无关的结构保留随机采样。问题源于同一概率分布被用于两项相互冲突的任务：构建树与验证 token。这种耦合使得直接注入随机性因由此产生的随机过程而变得困难。我们通过解耦这些角色来解决该问题：RheoSampling 为从草稿分布中采样得到的 token 分配一个用于树扩展和剪枝的代理概率，同时保留其用于验证的真实采样概率。具体而言，我们在确定性的 top-K 槽位中注入一个采样 token，并在构建和验证阶段以不同概率对待它，使 RheoSampling 成为首个兼具上下文感知 top-K 构建与随机采样且保持无损性的动态树方法。我们通过等价类分析将随机树空间压缩为可处理的类别，从而建立无损性保证。基于 OT 的验证策略和稀疏草稿机制确保理论增益转化为实际效率。跨 LLM 和基准的实验表明，相较于最先进的动态树方法，该方法在接受率和加速比上均有提升。该框架或可为分析随机树结构提供一种模板。

## Abstract
Speculative decoding accelerates LLM inference by drafting multiple tokens in parallel, with tree-based methods further improving efficiency through hierarchical structures. Dynamic-tree methods such as EAGLE-3 perform well under greedy decoding via deterministic top-K expansion and global pruning. However, in stochastic decoding (T>0), this mechanism collapses the draft distribution into one-hot probabilities, causing a severe drop in acceptance rate. This creates a dilemma: dynamic-tree methods sacrifice stochastic sampling to preserve context-aware topology, while static-tree methods preserve stochastic sampling with context-agnostic structures. The issue arises because the same probability distribution is used for two conflicting tasks: constructing the tree and verifying tokens. This coupling makes direct injection of randomness challenging due to the resulting stochastic process. We resolve this by decoupling these roles: RheoSampling assigns a token sampled from the draft distribution a proxy probability for tree expansion and pruning alongside its true sampling probability for verification. Specifically, we inject a sampled token among the deterministic top-K slots and treat it with different probabilities during construction and verification, making RheoSampling the first dynamic-tree method with both context-aware top-K construction and stochastic sampling while maintaining losslessness. We establish the lossless guarantee through an equivalence-class analysis that compresses the stochastic tree space into tractable classes. An OT-based verification strategy and a sparse draft mechanism ensure that theoretical gains translate into practical efficiency. Experiments across LLMs and benchmarks demonstrate improvements in acceptance rate and speedup over state-of-the-art dynamic tree methods. This framework may provide a template for analyzing stochastic tree structures.

# RheoSampling 论文总结

## 1. 核心问题与研究动机

- **背景**：推测解码（speculative decoding）用轻量草稿模型并行预测多个 token，再由目标模型一次前向验证，从而缓解 LLM 自回归解码的延迟瓶颈。树式推测解码进一步把多个候选序列组织成树，提高每步命中率。
- **现状**：EAGLE-2/3 等动态树方法采用“先扩展再重排（expand-then-rerank）”范式——按路径概率 top-K 贪心扩展、再全局剪枝到验证预算 N。整个流程**本质上是确定性的**：一旦算出草稿分布，树拓扑与候选集合就完全确定。
- **核心问题（One-Hot Dilemma）**：在贪婪解码（T=0）下该范式很有效；但在随机解码（T>0）下，token 只经由 top-K 选出，实际提议分布退化为若干**点质量（one-hot）**，q 的长尾信息被完全丢弃，接受率严重下降。
- **两难困境**：
  - 动态树方法：为保留上下文感知的拓扑而牺牲随机采样；
  - 静态树方法：保留随机采样，但结构是上下文无关的。
- **根因诊断**：同一个概率分布 q 被同时用于两个相互冲突的任务——**建树**与**验证**。这种耦合使得“直接注入随机性”会破坏无损性：若按采样 token 自身的 q 值排名，其存活与否取决于它自身的取值，条件化在“存活”上会扭曲其条件分布。
- **更深的观察**：top-K 采样存在固有限制——即使草稿模型与目标模型完全一致，top-K 也无法达到 100% 接受率，违反最优传输（OT）性质；现代 RRS、OT 类多草稿验证方法都依赖候选集中**至少存在一个随机采样 token** 才有操作空间。
- **整体含义**：论文提出 RheoSampling（Rheostat Sampling），是首个同时具备“上下文感知 top-K 建树”与“随机采样”并保持**严格无损**的动态树方法，并为分析复杂随机树结构提供了通用分析模板。

## 2. 方法论

### 2.1 核心思想：双身份解耦（Dual-Identity Decoupling）

- 对同一个随机采样 token 赋予**两个相互独立的概率身份**：
  - **代理概率 q_proxy**：用于树扩展、重排与剪枝（建树）；
  - **真实采样概率 q̃(x_s)**：用于最终验证（保证无损）。
- 由此把“用来建树的概率”与“用来验证的概率”解耦，既向动态草稿过程注入了随机性，又让随机性真正保留在最终树中。

### 2.2 混合采样机制（Hybrid Sampling）

每个扩展步骤的候选池有 K 个槽位，分配方式为：
- 前 m 个槽位：确定性选择草稿概率最高的 top-m 个 token（**lead tokens**）；
- 第 m+1 个槽位：从**残差分布 q̃**（top-m 之外的尾部，q̃(Y)=q(Y)/z，z=1−Σ_{i=1}^m q(x_i)）中采样一个代表 token x_s；
- 其余 K−m−1 个槽位：从剩余词表中按概率最高填入（**fill tokens**）。

### 2.3 采样 token 的双重处理

- 建树阶段：赋予代理概率
  **q_proxy(x_s) = min{ q(x_m), z }**，其中 q(x_m) 是第 m 个确定性概率，z 为残差质量。
- 关键性质：该代理值保证 x_s 在候选池中**排在所有 fill token 之前**，其“存活”与它被采样成什么 token **无关**（这是无损性的必要条件）。
- 特例 m=0：代理概率设为 q(x_1)+ε（ε>0），把采样 token 锚定在第一槽位。
- 验证阶段：用其**真实采样概率 q̃(x_s)** 评估，而非代理概率。

### 2.4 流变参数 m（Rheostat Parameter）

- m 充当“变阻器”，在建树时权衡**随机性的存活**与**结构质量**：
  - m 小 → 代理概率大，采样 token 更易存活、随机探索更易进入最终树，但确定性主干被削弱；
  - m 大 → 保留高质量树拓扑，但代理权重排名靠后，采样节点可能在重排中被剪掉。
- 理论上代理概率必须满足**排名下界 q_proxy ≥ q(x_{m+1})**（Lemma 4），否则存活与否依赖采样 token 本身，条件分布被扭曲（论文用 {A,B,C}={0.5,0.3,0.2}、K=3、m=1 的例子对比了 Rheo-proxy 与 Adhoc-proxy）。

### 2.5 稀疏草稿分布

- 在 softmax 前把 logits 截断到 top-128，其余置 −∞，得到稀疏分布，避免在完整词表上采样。
- 无损性保持的前提：验证阶段使用与草稿阶段相同的截断分布；top-128 已覆盖草稿分布大部分概率质量（MT-bench 上约 91%，Alpaca ~96%，HumanEval ~95%）。

### 2.6 RheoVerification：基于最优传输的验证（Algorithm 1）

在某一层的剪枝候选集 C={u_1,…,u_n} 上：
1. 若采样 token 存活（s ≠ −1）：
   - 先用其真实采样概率独立验证：以概率 min(1, p(u_s)/q̃(u_s)) 接受，接受则进入其子树；
   - 若被拒，计算残差分布 **r = norm(max(0, p − q̃))**，在剩余候选上做递归拒绝采样；
   - 若所有候选均被拒，则从最终残差中采样一次。
2. 若不存在采样 token（s = −1）：退化为标准 top-K 验证，仅依赖目标分布 p。

- 与 RRSw（无放回递归拒绝采样）的区别：RRSw 顺序验证、不做全局概率质量再分配；OT 方案则**全局再分配概率质量**（使用归一化草稿 q̃），与目标 p 的重叠更大，从而提高接受率（论文 Figure 2 给出直观对比）。

### 2.7 理论保证

- **Theorem 1（无损性）**：对任意剪枝预算 R ≥ 1 与任意序列 Seq，E_{T_R}[Pr(Rheo(T_R)=Seq)] = p(Seq)。
- 证明难点：动态树中采样 token Y 既决定自身取值，又决定后续 fill token 的身份，进而影响路径分数与全局剪枝，剪枝树 T_R 的拓扑与节点填充都是随机的且相互耦合。
- 解决手段：**等价类分析**——把所有剪枝到同一棵 R 节点树的未剪枝树归为一个等价类 [U]_R，将随机树空间压缩为可处理类别，再对 R 做数学归纳。
- 支撑引理：
  - Lemma 4（局部排名保持）：q_proxy(Y)=min{q(x_m),z} ≥ q(x_{m+1})；
  - Lemma 5（祖先单调性）：子节点路径分数 ≤ 父节点路径分数；
  - Lemma 7（槽位确定性）：同一等价类中新纳入的第 (k+1) 个节点的槽位拓扑不变；若为确定性槽位则整棵树一致；若为采样槽位，则等价类按采样 token 的真实取值划分为子类，各子类占比恰为 q̃(v)。
- **Theorem 3（单层接受率）**：给出闭式表达
  A_Rheo = Σ_{v∈Top_{n−1}} p(v) + Σ_{v∉Top_{n−1}} min(p(v), q̃(v)) + r(x_n)·Σ_{v∈Top_{n−1}} max(0, q̃(v)−p(v))
  ≤ Σ_{v∈Top_n} p(v) + Σ_{v∉Top_n} min(p(v), q̃(v))；当 s=−1 时 A_Rheo = Σ_{v∈Top_n} p(v)。
- **Rheo 优于 RRSw**（Appendix D.3，在温和近似下）：A_Rheo − A_RRSw ≈ Σ_{v∉Top_n}[min(p(v),q̃(v)) − min(p(v),(1−A)q̃(v))] ≥ 0，只要存在尾部 token 满足 (1−A)q̃(v) < p(v) < q̃(v) 即为严格正。这解释了 Algorithm 1 采用“随机优先（stochastic-first）”策略的动机。
