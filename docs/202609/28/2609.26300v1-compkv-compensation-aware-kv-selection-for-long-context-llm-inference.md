## 摘要
尽管大型语言模型（LLM）性能强劲，但在长上下文推理中，其受到KV缓存内存流量的瓶颈制约。稀疏注意力被广泛用于加速LLM推理，它通过在选定的token子集上计算精确注意力。为了恢复被排除在精确注意力之外的token的贡献，近期方法对被省略的注意力尾部施加粗粒度补偿。然而，现有方法通常基于注意力权重总量选择token，然后才对未选中的token进行补偿。这种解耦设计忽略了二者之间的相互作用：选择应优先考虑那些若被省略将导致最大补偿误差的token。为解决这一局限，我们提出CompKV，这是首个补偿感知的稀疏注意力框架，它将token划分为块，并针对下游补偿机制显式优化选择。我们的理论分析表明，块级均值补偿留下的残差由块注意力权重总量和块内logit变化共同决定。我们使用紧凑的块级统计量近似该残差，从而得到一个可部署的选择准则。我们进一步开发了一种高效的异步实现。在RULER和LongBench-Pro上的实验表明，CompKV在所评估的稀疏基线中表现最佳，同时相比全注意力最高可实现6.85倍的自注意力加速。

## Abstract
Despite their strong performance, large language models (LLMs) are bottlenecked by KV cache memory traffic during long-context inference. Sparse attention is widely used to accelerate LLM inference by computing exact attention over a selected subset of tokens. To recover the contribution of tokens excluded from exact attention, recent methods apply coarse-grained compensation to the omitted attention tail. However, existing methods typically select tokens based on attention mass and only then compensate for the unselected tokens. This decoupled design overlooks their interaction: selection should prioritize tokens that would leave the largest compensation error if omitted. To address this limitation, we introduce CompKV, the first compensation-aware sparse attention framework that divides tokens into blocks and explicitly optimizes selection for the downstream compensation mechanism. Our theoretical analysis shows that the residual left by block-level mean compensation is governed by both block attention mass and within-block logit variation. We approximate this residual using compact block-level statistics, yielding a deployable selection criterion. We further develop an efficient asynchronous implementation. Experiments on RULER and LongBench-Pro show that CompKV performs best among the evaluated sparse baselines while delivering up to a $6.85\times$ self-attention speedup over full attention.

## 1. 核心问题与研究动机

- **背景瓶颈**：LLM 在长上下文推理（文档理解、软件工程、智能体推理）中，KV 缓存随上下文增长而线性膨胀，自回归解码每步都要读取整个缓存，**内存流量成为主要瓶颈**。
- **现有解法**：查询感知的稀疏注意力只读取当前查询选中少量 token（块），以降低内存流量；进一步的“尾部补偿”方法用紧凑的 token 摘要来近似被省略块的注意力贡献（如 SparQ、RESA、ResKV）。
- **核心缺陷（本文切入点）**：现有方法**将“选择”与“补偿”解耦**——先按预测相关性/注意力质量（attention mass）对块排序，再对未选块做补偿。这忽略了二者交互：一个高注意力质量的块可能很容易被补偿器重建，而一个低质量但块内 logit 变化大的块反而会留下更大的重建误差。
- **本文主张**：选择应优先保留**若被省略将产生最大补偿误差**的块，即把选择标准与下游补偿机制显式耦合。CompKV 是首个“补偿感知”的稀疏注意力框架。

## 2. 方法论

### 2.1 核心思想
- 将 KV 缓存切分为固定大小的连续块（block size=16），**以块级均值补偿（Mean compensation）**为分析对象：未选块内每个 logit 用块均值 logit 替换。
- 通过 KL 散度建模“完整块注意力分布”与“摘要近似分布”的差异，推导出选择应优先保留使补偿残差最大的块。

### 2.2 关键理论推导
- **选择目标**：最小化补偿后分布与全注意力分布的 KL 之和
  $$L(S)=\sum_{g} D_{KL}(\hat P_g(S)\,\|\,P_g)$$
- **KL 恒等式**（均值补偿）：
  $$L(S)=-\sum_{g}\log\Big[1-\sum_{b\notin S}p_{g,b}\big(1-\tfrac{|b|e^{\bar z_{g,b}}}{Z_{g,b}}\big)\Big]$$
  其中 $p_{g,b}$ 为块注意力质量，$Z_{g,b}$ 为块未归一化权重，$\bar z_{g,b}$ 为块均值 logit。
- **二阶泰勒展开**：块内小方差条件下，每个被省略块的残差正比于 **注意力质量 × 块内 logit 方差**：
  $$p_{g,b}\big(1-\tfrac{|b|e^{\bar z_{g,b}}}{Z_{g,b}}\big)=p_{g,b}\big(\tfrac12\sigma^2_{g,b}+O(\sigma^3)\big)$$
- **最优选择准则**：在预算 K 下，选择得分最大的 K 个块
  $$\max_{|S|=K}\sum_{b\in S}\sum_{g}p_{g,b}\,\sigma^2_{g,b}$$
- **附录证明**：去掉均值补偿后，该 KL 目标退化为单头下标准的“按注意力质量 Top-K”选择，说明本文是现有方法的推广。

### 2.3 从理论到可部署实现
- **分组 key 方差估计**：将 d 维 key 坐标分成 r 个组，每块仅存各组平均坐标方差 $(\bar D_b)_t$，用查询各坐标平方和加权估计 logit 方差：
  $$\hat\sigma^2_{g,b}=\frac1d\sum_{t=0}^{r-1}\Big(\sum_{i\in G_t}q^2_{g,i}\Big)(\bar D_b)_t$$
- **注意力质量估计**：利用 log-partition 二阶展开 $\log Z_{g,b}\approx\log|b|+\bar z_{g,b}+\tfrac12\hat\sigma^2_{g,b}$ 归一化得到 $\hat p_{g,b}$。
- **最终块得分**：$S_b=\sum_g \hat p_{g,b}\hat\sigma^2_{g,b}$，同一方差估计被复用两次（质量修正 + 残差幅度）。
- **解码流程**：强制集合 F（首个 sink 块 + 最近 2 块）计入预算，其余块按得分 Top-K；选中块用原始 K/V 精确计算，未选块用均值摘要，二者**联合归一化**输出（式 12）。每块摘要仅需 $2d+r+1$ 个标量。
- **异步 CPU-offload 实现**：BF16 KV + FP32 摘要存于 pinned CPU 内存；主 CUDA 流做统计与 Top-K 评分，辅助流独立传输均值并计算补偿，与 CPU 收集、选中 KV 传输、FlashInfer 精确注意力重叠，最终在 merge 前同步。

## 3. 实验设计

- **模型**：Llama-3.1-8B-Instruct、Qwen3-8B、Qwen3-32B（覆盖不同模型家族与规模）。
- **Benchmark**：
  - **RULER**（32K 配置，13 个任务，每任务 500 样本，共 6500 样本）：检索、多跳追踪、聚合、问答。
  - **LongBench-Pro**（8K–128K，625 个英文样本，每桶 125）：含 Easy/Mod./Hard/Extr. 难度与长度分桶，覆盖全局整合与局部检索。
- **对比方法**：Quest、InfLLM、Quest+RESA（λ=0.25）、Full attention（稠密参考）。
- **统一设置**：块大小 16，保留首个 sink 块与最近 2 块，均计入相同精确读预算；主实验 r=4。
- **评估维度**：准确率（任务级、平均分、相对 Full 的下降幅度）、预算敏感性（128–1024 token）、效率（CPU-offload 单层注意力步延迟）。

## 6. 主要结论与发现

- **准确率**：在 RULER（32K、512 token 预算）和 LongBench-Pro 上，CompKV 在全部三个模型上取得**所评估稀疏方法中的最高平均分**；相对 Full 的下降最小（RULER 上分别仅 ↓3.8 / ↓5.5 / ↓2.7 个百分点，而基线常下降 10–18 个百分点）。
- **难任务增益显著**：在 MK3 等困难检索任务上优势最大（如 Llama 上 73.0% vs 基线最高 22.4%；Qwen3-32B 上 93.0% vs 2.4–68.0%）。
- **预算鲁棒性**：在 128–1024 token 的多种预算下，CompKV 在多数预算、任务和模型上保持最优；部分基线随预算增加会接近 Full，但 CompKV 整体仍领先。
- **效率**：在全部 9 种长度/预算组合下，CompKV（r=4）取得**最低平均延迟**，相比 Full 最高 **6.85×** 加速（32K 4.81×、64K 5.95×、128K 6.85×）。
- **消融发现**：均值补偿贡献 0.48–2.47 分，外层方差因子再贡献 0.35–1.19 分，二阶质量修正相对一阶再提升 1.96–3.39 分；r 越大精度越高（r=128 最佳），但 r=4 仅用 1/32 方差元数据即接近该上限。
- **机制验证**：按精确补偿残差排序相比按注意力质量排序，平均降低 KL 0.660%、相对 L2 输出误差 0.582%；CompKV 的实用得分与精确残差排序的 Spearman 相关达 0.85–0.88，残差捕获率 >81%。

## 7. 优点

- **理论驱动的设计**：首次将“选择”与“补偿”显式耦合，给出 KL 恒等式 + 二阶展开的解析准则，并证明去掉补偿后退化为经典 Top-K 质量选择，理论自洽、可解释性强。
- **免训练、即插即用**：无需微调或训练，仅需紧凑块级统计（每块 $2d+r+1$ 个标量），部署成本低。
- **统计压缩巧妙**：用分组坐标方差近似查询投影方差，在极低元数据开销（r=4）下保留大部分选择信号，并提供精度—开销可调旋钮。
- **工程实现完整**：异步 CPU-offload 流水线将补偿与 KV 检索、传输、精确注意力重叠，实测延迟全面领先。
- **实验全面且对比公平**：三模型、双 benchmark、多预算、多粒度消融，统一块大小与预算口径，附录提供注意力保真度的细粒度验证。

## 8. 不足与局限

- **任务覆盖仍有盲区**：Llama-3.1 上 Full attention 的 CWE 得分仅 9.9%，所有稀疏方法（含 CompKV）均表现很差，说明某些聚合类任务在稠密模型上本身就很弱，方法增益无法体现。
- **局部误差改善幅度有限**：残差感知选择相比质量选择的 KL/相对 L2 改善仅约 0.6%，属于较小幅度；作者也承认需依赖跨层/跨步传播放大其收益。
- **粒度—精度权衡未消解**：默认 r=4 相比 r=128 在预算 256/512 下分别落后 1.87/1.08 分，说明紧凑统计仍有信息损失；r=128 的元数据开销是 r=4 的 32 倍。
- **评测规模与场景限制**：延迟测试为 batch size=1 的单层单 GPU 流水线，未评估高并发服务吞吐；准确率测试仅到 32B 规模，未覆盖更大模型或 MoE 架构。
- **补偿机制单一**：理论与实验聚焦“块均值补偿”，虽然作者声称框架不限于此，但未验证与其他补偿器（如低秩重建）结合的效果。
- **对比基线有限**：未与 ResKV 等近期尾部补偿方法直接比较；Quest+RESA 因原论文报告更高延迟而未被纳入效率对比，效率维度对比方法偏少。
- **数据与可复现性**：部分评测细节（如 LongBench-Pro 的随机解码 3 轮）增加方差，每桶 125 样本的样本量偏小；论文亦未报告总计算量。
