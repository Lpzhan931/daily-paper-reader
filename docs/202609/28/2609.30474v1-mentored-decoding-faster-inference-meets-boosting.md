## 摘要
投机解码是一种成功的技术，它通过快速的草稿模型加速目标自回归语言模型的推理。有损投机解码允许相对于目标模型发生漂移，以进一步提升速度。有趣的是，实验观察到所得模型在质量方面也能超越目标模型。我们的论文通过一种称为导师式解码的有损投机解码形式化方法，正式证明了这种壮举何以可能。为此，我们将推理与著名的机器学习训练理论——Boosting——联系起来，并通过将导师式解码推广到整个 f-散度集合来展开。我们揭示了导师式解码的关键性质，其中包括：(i) 全变差情形特别吸引人的几何性质；(ii) 对任意 f-散度，与 Boosting 相符性直接相关的简单近似；以及 (iii) 一个与散度无关的 O(n) 空间、O(sort(n)) 时间的数据结构，它基于草稿模型和目标模型的输出构建，允许在 O(log n) 时间内查询对偶问题的最优参数，并能在 O(n) 时间内为任意 f-散度构造最优导师式分布。

## Abstract
Speculative decoding is a successful technique speeding up inference of a target autoregressive language model via a fast drafter model. Lossy speculative decoding allows a drift with respect to the target to further improve speed. Interestingly, it has been observed experimentally that the resulting model can $\textit{also}$ beat the target $\textit{quality-wise}$. Our paper formally proves how such a feat is possible with a formal approach to lossy speculative decoding called $\textit{mentored decoding}$. To get there, we connect inference to a celebrated ML training theory, $\textit{boosting}$, and proceed via the generalization of mentored decoding to the whole set of $f$-divergences. We uncover key properties of mentored decoding, among which (i) the particularly appealing geometric nature of the total variation case, (ii) simple approximations for any $f$-divergence in direct relation with boosting compliance, and (iii) a $\textit{divergence independent}$ $O(n)$ space and $O(\mathrm{sort}(n))$ time data structure built on drafter and target outputs, which allows to query the optimal parameters of the dual problem in $O(\log n)$ time and constructing optimal mentored distributions in $O(n)$ time for any $f$-divergence.

## 1. 核心问题与整体含义
- **背景**：投机解码（Speculative Decoding, SD）通过小型快速草稿模型提出候选 token，再由目标模型并行验证，从而加速 LLM 自回归推理。标准 SD 要求输出分布与目标分布完全一致，因此接受率受草稿模型与目标模型差异限制。
- **核心问题**：有损投机解码允许输出分布偏离目标模型，以进一步提高速度。近期实验观察到，这种偏离不仅可能加速，还可能使最终组合模型在质量上反超目标模型。但此前缺乏形式化理论解释。
- **整体含义**：本文首次将有损投机解码形式化为“导师式解码”（Mentored Decoding, MD），并将其与机器学习经典训练理论 Boosting 联系起来，证明“更快推理”与“更好质量”可以同时发生。论文将 MD 从反向 KL 散度推广到全体 f-散度，给出最优解结构、几何性质、近似算法和高效数据结构。

## 2. 方法论
- **核心思想**：把有损投机解码建模为约束优化问题：在输出与目标分布之间的 f-散度不超过阈值 \(D\) 的约束下，最大化草稿 token 的接受概率。目标模型成为“导师”，允许一定偏离，但限制偏离幅度。
- **两种等价参数化**：
  - **f-MD-2**：直接优化接受概率向量 \(r\) 和重采样分布 \(s\)，最大化 \(p^\top r\)，约束 \(D_f(\pi\|q)\le D\)，其中 \(\pi=p\odot r+(1-p^\top r)s\)。
  - **f-MD-1**：等价地寻找导师式分布 \(\pi\)，最小化 \(D_{\mathrm{TV}}(\pi\|p)\)，约束 \(D_f(\pi\|q)\le D\)。
  - Lemma 3.2 证明两种参数化一一对应，且接受概率 \(P_{\mathrm{acc}}(MD)=p^\top r=1-D_{\mathrm{TV}}(\pi\|p)\)。
- **全变差（TV）特例**：
  - TV-MD 的最优解集合具有简洁几何形式：\(\Delta_n\cap\{D_{\mathrm{TV}}(\pi\|q)=D\}\cap[\min(p,q),\max(p,q)]\)。
  - 即概率单纯形、以 \(q\) 为中心的 TV 球面、以及由 \(p,q\) 坐标逐维夹逼形成的超矩形三者交集。
  - 该最优集合足够大，可包含所有严格凸 f-散度对应的最优解。
- **一般 f-散度最优解**：
  - 通过 KKT 条件和 `clampset` 工具，证明最优导师式分布可写成逐坐标夹逼形式：  
    \(\pi^*=\max\{(1-b)q,\min\{p,(1+a)q\}\}\)，其中 \(0\le a\)，\(0\le b<1\)。

- **与 Boosting 的连接**：
  - 论文设计了一个多类、自归一化的 Boosting 扩展，简化 AdaBoost，无需显式归一化权重。
  - 权重更新：\(w_{t+1,i}\propto w_{t,i}\cdot(1-\mu_t y_i^\top h_t(x_i)/(2h_{t,\infty}))/\sqrt{1-\mu_t^2}\)，边缘 \(\mu_t\) 衡量弱模型表现。

  - **TV 情形连接**：导师式分布可取几何平均 \(v_\alpha\propto p^\alpha q^{1-\alpha}\)，选择 \(\alpha=c_2/(c_2+c_{\text{target}})\)，可同时满足 TV-MD 最优性和 boosting 保证；Theorem 4.7 给出提升下界和 TV 散度上界。
