## 摘要
视觉前缀在多模态大语言模型（MLLMs）的逐层计算中占据主要部分，因此视觉 token 剪枝是加速推理的一种直接方法。现有的 top-K 方法通常独立评估 token，并对所有输入采用统一预算，忽略了选择相关的交互以及样本间视觉复杂度的变化。相反，我们提出 StepPrune，将视觉 token 剪枝建模为自适应序列决策过程。以先前选中的 token 和文本上下文为条件，StepPrune 逐步构建保留子集，并通过学习到的 STOP 动作自动确定其大小。在训练期间，保方差噪声门为离散选择过程提供可微替代；而在推理期间，未选中的 token 会在语言模型预填充之前被物理移除。分组选择机制进一步将 StepPrune 扩展到高分辨率输入。在 LLaVA-1.5、LLaVA-NeXT、Qwen2.5-VL 和 InternVL3 上的实验表明，StepPrune 在 LLaVA-1.5、Qwen2.5-VL 和 InternVL3 的所有评估剪枝率下均取得了最佳的平均归一化性能保持率，同时在 LLaVA-NeXT 显著更长的 AnyRes 前缀上仍具有竞争力。在 LLaVA-1.5 上，StepPrune 在剪除 88.9% 视觉 token 的同时，保持了完整前缀归一化性能的 94.6%。在平均保留数量为 64 时，StepPrune 将预填充延迟从 59.95 ms 降至 40.05 ms，对应 1.50 倍的预填充加速。

## Abstract
Visual prefixes account for a major portion of the per-layer computation in multimodal large language models (MLLMs), making visual-token pruning a direct approach to accelerating inference. Existing top-K methods typically evaluate tokens independently and apply a uniform budget to all inputs, overlooking both selection-dependent interactions and variations in visual complexity across samples. In contrast, we propose StepPrune, which formulates visual-token pruning as an adaptive sequential decision process. Conditioned on previously selected tokens and textual context, StepPrune progressively constructs the retained subset and automatically determines its size through a learned STOP action. During training, a variance-preserving noise gate provides a differentiable surrogate for the discrete selection process, whereas during inference, unselected tokens are physically removed before language-model prefill. A grouped selection mechanism further extends StepPrune to high-resolution inputs. Experiments across LLaVA-1.5, LLaVA-NeXT, Qwen2.5-VL, and InternVL3 show that StepPrune achieves the best average normalized performance retention across all evaluated pruning rates on LLaVA-1.5, Qwen2.5-VL, and InternVL3, while remaining competitive on the substantially longer AnyRes prefixes of LLaVA-NeXT. On LLaVA-1.5, StepPrune retains 94.6% of the full-prefix normalized performance while pruning 88.9% of the visual tokens. At a mean retained count of 64, StepPrune reduces prefill latency from 59.95 ms to 40.05 ms, corresponding to a 1.50x prefill speed-up.

# StepPrune 论文详细中文总结

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：在多模态大语言模型（MLLM，如 LLaVA、Qwen2.5-VL、GPT-4V）中，图像以"视觉前缀"形式注入——冻结的视觉塔将图像编码为数百个 patch token，前置到文本提示后由自回归语言模型消费。由于 Transformer 逐层开销随序列长度超线性增长，推理延迟与内存主要由视觉前缀长度而非语言模型权重决定。
- **核心问题**：视觉 token 剪枝是加速 MLLM 推理的直接手段，但现有 top-K 方法存在两个隐含假设：
  - **独立性假设**：每个 token 独立打分，一旦某 token 被选中，剩余候选（尤其是其重复项或近邻）的边际价值不再被重新评估。
  - **固定压缩比假设**：K 由外部统一指定并应用于所有输入，无法适应"近乎空白文档缩略图"与"密集自然场景"之间的视觉复杂度差异。
- **整体含义**：论文主张放弃这两个假设，将 token 选择重构为**逐步序列决策过程**：模型每步只承诺一个 token，每步以先前选择为条件，并自行决定何时停止，从而使保留数量 K 成为逐输入自适应的量。

## 2. 方法论

### 核心思想
- 将剪枝建模为自回归策略：`Pθ(A|X,Q) = ∏_{t=1}^{T} πθ(a_t | a_{<t}, X, Q)`，其中动作 `a_t ∈ {1,...,N} ∪ {∅}`，`∅` 为学习到的 STOP 动作。
- 当首次出现 STOP 时终止，保留序列 `S(A)=(a_1,...,a_{T*−1})`，长度 `K=T*−1`。**保留哪些 token 与保留多少由同一策略共同决定**。

### 关键技术细节
- **跨模态输入编码器**：两个 pre-norm ViT 块。文本嵌入先经投影 `Ẽtext = gtext·LN(Wp·Etext)` 映射到视觉特征空间（`gtext∈[0,1]` 早期训练逐步增大），再与视觉 token 联合编码 `H = Enc([X; Ẽtext])[1:N]`，仅保留视觉位置用于选择。
- **学习 STOP 动作**：将可学习嵌入 `sstop` 追加到编码视觉 token 形成候选记忆 `M=[H; sstop]`，STOP 与视觉候选共享同一指针空间。
- **指针解码器**：采用 Pointer Networks。每层含对选择历史的因果自注意力、对候选记忆 M 的交叉注意力、FFN；交叉注意力 logits 复用为指针 logits。已选位置被 mask 以防重复选择。每步更新：`ℓt = PtrAttn(qt,M)+Maskt`，`pt=softmax(ℓt/τ)`，`at=argmax`；通过 straight-through 方式 `ẽpt = eat − sg(pt) + pt` 与 `qt+1 = M⊤ẽpt` 保持可微路径。

### 轨迹感知可微优化
- **存活概率**：`At = ∏_{u=1}^{t−1}(1−pu(∅))`，`A1=1`。
- **轨迹聚合分数**：`si = Σ_{t=1}^{Tmax} At·pt(i)·βt`，`β∈(0,1)` 为几何折扣，对早期步骤赋予更大权重。
- **可微保留计数**：`K = Σ_{t=1}^{Tmax} At(1−pt(∅))`。
- **分数极化**：用可微 top-k 算子 `αi = SoftTopK_{k,τ}(s)i`，其中 `k = sg(1/B · Σ Kb)`（stop-gradient），仅用于连续训练路径，不约束推理时单样本 token 数。
- **保方差噪声门**：`x̃i = √αi·xi + √(1−αi)·εi`，`εi~N(0,I)`。αi→1 保留原 token，αi→0 被高斯噪声替代。
- **局部掩码去噪器**：噪声注入后接一个 ViT 块，自注意力限制为对角（`mask=diag`），防止强噪声 token 从邻域"泄漏"恢复内容。
- **训练–推理对齐**：训练时语言模型接收完整长度加噪序列；推理时移除噪声门与去噪器，指针策略产生硬保留子集，在 LM 预填充前物理 gather 原 token，并恢复原生视觉顺序以保留位置约定。
- **训练目标**：`L = LLM(X̃) + λ·K/N`，λ=0.03。仅优化跨模态编码器、指针解码器、局部去噪器、文本投影及 START/STOP 嵌入；视觉塔、投影器、语言模型全部冻结。
- **分组执行**：标准设置每步保留 1 个 token；高分辨率输入每轮保留 5 个（`Ur = TopG({ℓr(i): i∉Sr−1, i≤N}, 5)`），将循环更新次数从约 K+1 降至 ⌈K/5⌉+1，同时保留 STOP 决策与历史条件选择。

## 6. 主要结论与发现

- **总体性能**：在 LLaVA-1.5、Qwen2.5-VL、InternVL3 的所有评估剪枝率上取得最佳平均归一化性能保持；在 LLaVA-NeXT 更长 AnyRes 前缀上保持竞争力。
- **LLaVA-1.5 关键数字**：剪除 88.9% 视觉 token 仍保留 94.6% 归一化性能；平均保留 64 token 时预填充延迟从 59.95 ms 降至 40.05 ms（1.50× 加速），端到端从 138.37 ms 降至 98.97 ms。
- **预算越紧优势越明显**：LLaVA-1.5 上对 VisionZip 的领先从 0.1（66.7%）扩大到 2.6（88.9%）个百分点；POPE 上增益从 0.4 增至 6.1 个百分点。
- **自适应预算**：STOP 产生逐样本变化的 K，TextVQA（均值 109.6）与 ScienceQA-IMG（100.9）预算明显大于 MME、GQA、POPE（约 90）；匹配均值预算下自适应选择在 TextVQA（+0.90 pp）和 MME（+0.81 pp）上更优，但并非所有任务均获益。
- **扩展性**：选择器延迟随序列增长，但全前缀预填充增长更快；LLaVA-1.5 上加速比从 320 token 的 0.98× 增至 2240 token 的 4.10×，LLaVA-NeXT 上从 1.24× 增至 3.88×。
- **消融结论**：双向编码器（94.6%）优于因果（92.4%）；完整轨迹聚合（94.7%）显著优于仅末步（90.3%）、均匀求和（83.9%）、仅存活加权（89.5%）。
- **训练–推理对齐**：硬剪枝始终略优于噪声门诊断路径，差距 0.3–1.2 pp，且随预算收紧而增大，说明诊断未夸大实际硬剪枝性能。
- **敏感性**：λ 主要改变保留数量而对匹配预算性能影响较小；β 在 [0.8, 0.98] 稳定（93.1–93.7%），过低（0.60）显著下降至 82.4%。

## 7. 优点

- **建模创新**：首次将视觉 token 剪枝明确重构为历史条件序列决策，联合决定子集成员与子集规模，突破了 top-K 的独立性与固定预算双重限制。
- **可微优化方案**：轨迹聚合（存活概率×指针概率×几何折扣）+ SoftTopK 极化 + 保方差噪声门 + 对角掩码去噪器，为离散选择提供了自洽的可微替代，且训练–推理对齐经诊断验证。
- **架构通用性**：冻结全部 backbone，仅训练轻量选择器，跨固定分辨率、AnyRes、动态分辨率、多 tile 四种视觉组织验证，迁移性强。
- **工程实用性**：分组执行机制在长前缀下降低循环开销；推理时物理移除未选 token，带来真实预填充加速与 KV cache / 显存下降。
- **实验严谨性**：消融覆盖关键组件，含训练–推理对齐诊断、失败案例分析、超参数敏感性，并诚实报告了非全面最优的场景（如 LLaVA-NeXT）。

## 8. 不足与局限

- **细粒度局部证据难以保留**：激进压缩下文本密集输入（TextVQA）明显退化，LLaVA-NeXT 在 88.9%/94.4% 剪枝时 TextVQA 降至 49.6/43.3；失败案例显示 STOP 过早触发会导致相关局部证据从未进入保留子集。
- **训练–推理表示差异**：训练用完整长度噪声门序列，推理用硬 gather，二者差距随预算收紧增大（0.3→1.2 pp），更直接的硬选择优化仍是开放问题。
- **评估覆盖有限**：仅图像基准与 7B–8B 规模开源模型，未涵盖视频输入（时空冗余可能需要分层选择）和更大语言模型。
- **多预算需多次训练**：不同全局效率–精度区间依赖分别训练的 selector，单一 checkpoint 支持多操作点尚未实现。
- **选择器开销的边界**：短序列下选择器开销可抵消大部分预填充节省（如 320 token 的 0.98×），且选择器占比随序列增长升至约 65–68%。
- **自适应 K 的语义解释需谨慎**：论文明确指出 K 不应被解读为语义难度的通用度量，它依赖 backbone、prompt、训练选择器与

训练数据分布、任务类型以及剪枝率目标。因此，K 更适合被理解为选择器在特定部署配置下学到的预算分配行为，而不是跨模型、跨任务的通用难度度量；在比较不同方法的平均保留 token 数时，也应同时交代 selector 训练集、backbone 与剪枝目标。

- **部署侧仍需额外工程考量**：选择器本身引入参数与串行/分组循环，在短视觉前缀或高并发批处理场景下，其开销与调度复杂度可能部分抵消预填充收益；论文虽报告了分组执行和延迟，但尚未给出与 vLLM、FlashAttention 等生产级推理栈的完整集成评估。
- **评估与统计显著性**：主结果以平均归一化性能保持为主，未系统报告多次运行的方差或显著性检验，因此部分小幅领先（如若干 0.1–0.9 个百分点）是否稳定仍需更多复现验证。
- **方法组合空间未穷尽**：StepPrune 与 token 合并、KV cache 量化、推测解码等正交加速手段的叠加效果尚未探索，可能限制其在实际系统中的上限收益。

## 9. 总体评价

总体而言，StepPrune 的核心贡献不是提出又一个 top-K 评分器，而是把视觉 token 剪枝改写为“何时停止 + 下一步选谁”的序列决策问题，并用轨迹感知的可微松弛使该离散过程可端到端训练。它在多个 MLLM backbone 上验证了自适应预算的可行性，尤其在紧预算下优势更明显；其主要风险集中在细粒度局部证据保留、训练–推理一致性、选择器开销以及评估范围仍偏图像问答。若后续能在硬选择优化、多预算单模型、视频/长上下文场景和生产推理栈集成上继续推进，该方法有潜力成为 MLLM 视觉前缀压缩的通用组件。
