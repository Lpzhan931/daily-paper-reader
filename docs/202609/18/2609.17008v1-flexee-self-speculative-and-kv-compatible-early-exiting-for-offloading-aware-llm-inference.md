## 摘要
大型语言模型（LLM）推理通常同时受计算和内存制约，尤其是在基于卸载的部署中，模型权重在自回归解码过程中需要在内存层级之间传输。在这种情况下，减少执行的层数可以降低每 token 延迟，同时避免代价高昂的权重移动。受此观察启发，我们提出了 FlexEE，一个面向资源受限且基于卸载的 LLM 推理的提前退出框架。FlexEE 通过逐层退出监督以实现可靠的中间层预测、基于 Top-K 局部词表的自推测解码以低成本做出退出决策，以及动态隐藏状态管理以实现 KV 缓存正确且内存感知的执行，使提前退出在 LLM 解码中变得切实可行。在生成任务和下游任务上，FlexEE 能够以最小的精度损失实现高效提前退出，在 0%/50% 权重卸载下，分别在 Llama2-7B 和 Llama3-8B 上实现最高 1.27×/3.16× 和 1.25×/2.83× 的端到端加速。

## Abstract
Large language model (LLM) inference is often constrained by both computation and memory, especially in offloading-based deployments where model weights are transferred across memory hierarchies during autoregressive decoding. In this setting, reducing the number of executed layers can lower per-token latency while also avoiding costly weight movement. Motivated by this observation, we present FlexEE, an early exiting framework for resource-constrained and offloading-based LLM inference. FlexEE makes early exiting practical for LLM decoding through layer-wise exit supervision for reliable intermediate-layer prediction, self-speculative decoding over a Top-K local vocabulary for low-cost exit decisions, and dynamic hidden state management for KV-cache-correct and memory-aware execution. Across generative and downstream tasks, FlexEE enables efficient early exit with minimal accuracy degradation, delivering up to 1.27$\times$/3.16$\times$ and 1.25$\times$/2.83$\times$ end-to-end speedups on Llama2-7B and Llama3-8B under 0\%/50\% weight offloading, respectively.

# FlexEE 论文中文总结

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：Transformer 大模型参数规模激增，在资源受限设备上常需将部分层权重**卸载（offload）**到片外内存，推理时按需加载。这使得推理瓶颈从计算转移到**片外内存访问（权重搬运）**。
- **核心洞察**：在卸载式推理中，**减少执行的层数**不仅能降低每 token 延迟，还能直接减少需要搬运的层权重，从而缓解数据移动瓶颈。
- **动机**：提前退出（early exiting）是灵活且互补的加速范式，但直接用于 LLM 解码存在三大挑战（见 Figure 1a）：
  - **挑战 1（算法层）弱中间层建模能力**：中间层隐状态语义可解码性远弱于最后一层，直接早退会导致生成质量严重下降。
  - **挑战 2（算法层）退出开销高**：需将隐状态投影到全词表（如 Llama2 的 32K token）估计置信度，矩阵乘法开销大且难搜索，抵消了跳层的收益。
  - **挑战 3（系统层）KV 缓存不兼容**：中间层退出后，后续层无法为未来 token 生成所需 KV 对；已有 state copying / KV copying 方案需加载全部剩余层权重，在卸载场景下丧失早退优势。
- **整体含义**：FlexEE 提出**算法–系统协同设计**的卸载感知早退框架，使早退在卸载式 LLM 推理中真正可用。

## 2. 方法论

### 2.1 核心思想
- 将早退预测**对齐到卸载层的实际内存与执行特性**，通过三项技术协同：逐层退出监督、自推测轻量预测器、动态隐状态管理。

### 2.2 关键技术细节

- **逐层退出监督（Layer-wise Early-Exit Supervision）**
  - 训练时把共享 LM head 连接到多个关键 Transformer 层，对不同深度隐状态施加统一语言建模目标，将最终层解码能力迁移到浅层。
  - 目标函数：对各层交叉熵损失 `J_CE(g(x_{l+1}), Y)` 按归一化层权重 `ẽ(t,l)` 加权求和；权重调度随训练从深层逐步转向浅层，避免过度正则化浅层表示。
  - 结果（Figure 3）：监督后中间层熵与 WikiText PPL 大幅下降，最终层性能几乎不变。

- **退出特征选择**
  - 候选特征：Top Prob、Gap（top-1 与 top-2 概率差）、Top Logit、Prob Shift。
  - 通过离线统计（Eq. 2）为每层求最小阈值 `λ*_l`，使满足退出条件的 token 中至少 τ 比例与最终层预测一致；再用覆盖率 `r_λl`（Eq. 3）衡量特征可用性。
  - 结论：**Top Prob 与 Gap** 阈值平滑、覆盖率高、跨模型一致；Top Logit 不稳定，Prob Shift 覆盖率低，故采用前两者。

- **自推测轻量预测器（Self-Speculative Predictor）**
  - 观察：逐层监督后中间层预测高度集中，最终层 top-1 token 常落在早期层的 Top-N 候选集中。用 `H_l(N)` 衡量覆盖率，`E_l(N)` 衡量局部与全局 top-1 概率偏差。
  - N=30 为覆盖与误差的甜点；据此选一个中间层作为**自推测层（Self-Spec Layer）**，保留其 Top-K token 构成局部词表（Llama2 取 K=30，Llama3 取 K=80）。
  - 后续早退层仅在该紧凑候选集上投影（`2BhV` → `2BhK`），每个退出层计算**局部 top-1 概率与局部 gap**，二者均超过离线预计算阈值（τ=0.99，基于 WikiText）时才退出。
  - 计算开销（Table 7）：FlexEE 每 token 额外约 0.264 GFLOPs，仅为 AdaInfer 的 1/30.74、SpecEE 的 1/2.52。

- **动态隐状态管理（Dynamic Hidden State Management）**
  - 当 token 在中间层退出时**保留该层隐状态**；生成下一 token 时，前向传播到达退出层之后的第一层时，将保留隐状态与当前 token 表示**联合参与计算**；该层 KV 缓存更新完成后清除缓存状态以回收内存。
  - 相比 state copying / KV copying / KV eviction：无需跨层强制复制 KV、无需加载全部剩余层权重，兼顾语义连续性与计算效率（Figure 6 显示 PPL 更低、相对延迟更小）。

### 2.3 算法流程（文字版）
- 逐层循环：加载隐状态与 K/V 缓存 → 计算当前层并评估退出准则（同时异步预加载下一层权重）→ 存储更新后的隐状态 → 更新 K/V 缓存 → 若满足退出条件则缓存退出隐状态并终止当前 token 解码，否则继续下一层。

## 6. 主要结论与发现

- **加速效果**：0%/50% 权重卸载下，Llama2-7B 达 **1.27×/3.16×**，Llama3-8B 达 **1.25×/2.83×**；卸载比例从 0% 增至 75% 时，Llama2-7B 加速从 1.27× 提升至 **3.29×**，Llama2-13B 至 2.68×，Llama3-8B 至 3.10×。
- **精度保持**：在多项任务上接近 Dense 解码，PPL 与准确率下降极小；开放式生成与 Dense 基本持平。
- **退出行为自适应**：退出层分布在 8–15、16–23、24–30 等区间，简单 token 早退、困难 token 延后或走满全层。
- **Self-Spec 优于全词表早退**：局部 Top-K 词表可带来更早退出且吞吐更高，全词表阈值过于保守。
- **卸载场景收益更大**：减少预测开销与执行层数可进一步避免昂贵权重传输；50%→75% 卸载边际收益递减，因早退多发生在深层。

## 7. 优点

- **算法–系统协同设计**：将早退决策与卸载式推理的内存/执行特性对齐，而非单纯算法层面优化。
- **轻量预测器设计精巧**：自推测 Top-K 局部词表将每层投影从 `2BhV` 降至 `2BhK`，额外开销仅 0.264 GFLOPs，远低于 AdaInfer 与 SpecEE。
- **KV 缓存兼容方案务实**：动态隐状态管理避免强制复制 KV 或重建所有后续层，天然适配权重卸载。
- **训练无关 + 复用现成监督 checkpoint**：降低部署门槛，阈值可离线标定且跨数据集泛化好。
- **实验覆盖较广**：多模型、多任务、多卸载比例、多批大小，并附计算量、内存开销与定性案例分析。

## 8. 不足与局限

- **依赖底层模型质量**：FlexEE 建立在带逐层早退监督的预训练模型（LayerSkip）之上，受其质量制约，未验证在无监督 checkpoint 上的适用性。
- **适用场景受限**：最适用于**小批量/内存受限**的端侧交互式服务；批大小增大时，需等整批样本退出才能跳层，异构退出深度削弱跳层收益（B=8 时加速几乎消失）。
- **边际收益递减**：50%→75% 卸载的增益下降，因早退集中在深层，无法充分利用额外卸载的浅层。
- **模型覆盖有限**：仅评测 Llama 系列（1B–13B），未覆盖更大规模、MoE 或非 Llama 架构。
- **输出分布风险**：早退可能改变输出分布，存在幻觉、偏见、隐私等继承性风险，高风险场景需额外安全措施。
- **评测细节披露有限**：未报告训练算力/时长（因训练无关），部分基线结果缺失，开放式生成胜率仅约 50%，未展示显著优于 Dense 的生成质量证据。
