## 摘要
大型语言模型（LLMs）展示了处理长上下文任务的强大能力，但由于巨大的内存需求和推理延迟，处理此类长上下文仍然具有挑战性。在这项工作中，我们发现某些注意力头表现出注意力模式的顺序一致性，并可通过基于变异系数的算法持续识别。受此观察启发，我们提出了CateKV，一种混合KV缓存方法，它仅保留一致性头中的关键标记信息，从而减少KV缓存大小和计算开销，同时在自适应头中保留大部分KV对以确保高准确性。我们展示了我们算法的独特特性及其与现有加速方法的扩展。对长上下文基准的综合评估表明，在保持与全注意力相当的精度的同时，CateKV在单样本输入中减少了高达$2.72\times$的内存使用量，并将解码加速了$2.18\times$，在批量场景中吞吐量提升了$3.96\times$。

## Abstract
Large language models (LLMs) have demonstrated strong capabilities in handling long-context tasks, but processing such long contexts remains challenging due to the substantial memory requirements and inference latency. In this work, we discover that certain attention heads exhibit sequential consistency in their attention patterns, which can be persistently identified using a coefficient-of-variation-based algorithm. Inspired by this observation, we propose CateKV, a hybrid KV cache method that retains only critical token information for consistent heads, thereby reducing KV cache size and computational overhead, while preserving the majority of KV pairs in adaptive heads to ensure high accuracy. We show the unique characteristics of our algorithm and its extension with existing acceleration methods. Comprehensive evaluations on long-context benchmarks show that, while maintaining accuracy comparable to full attention, CateKV reduces memory usage by up to $2.72\times$ and accelerates decoding by $2.18\times$ in single-sample inputs, and boosts throughput by $3.96\times$ in batch scenarios.

- **核心问题**：长上下文LLM推理面临两重挑战——巨大的KV缓存内存占用和随之而来的推理延迟。以Llama-3-8B-Instruct-262k为例，上下文从1K扩展到1M tokens时，推理延迟增长超过3000倍。
- **现有方法的局限**：
  - **KV eviction方法**（如StreamingLLM、SnapKV、PyramidKV）：通过丢弃KV对降低内存，但容易丢失关键信息，导致明显的精度下降。
  - **KV retrieval方法**（如Quest、ShadowKV）：保留完整缓存并动态检索关键token，精度有保障但无法缓解高内存占用，限制了批量规模和吞吐量。
  - **头级分类方法**（如DuoAttention、RazorAttention）：虽认识到不同注意力头的稀疏模式差异，但未充分利用预填充（pre-filling）阶段的经验来指导解码（decoding）阶段的优化。
- **本文的核心观察**：部分注意力头在预填充和解码阶段展现出**顺序一致性（sequential consistency）**——即在整个解码过程中始终关注同一小组关键token，且该模式可以被稳定识别；而另一些注意力头则呈现动态激活特性，注意力分布逐解码步变化、覆盖面广。这种存在于不同模型、不同层中的"头分工机制"暗示了利用预填充经验来优化解码阶段的可能性。
- **整体含义**：本文提出利用注意力头的顺序一致性实现混合KV缓存策略，在保证精度的前提下大幅降低KV缓存规模、加速解码推理，为长上下文推理优化提供了新的切入角度。

## 2. 论文提出的方法论

### 2.1 核心思想

CateKV将注意力头划分为两类，分别采取不同的KV缓存策略：

- **一致头（Consistent Heads）**：注意力稳定集中于少量关键token，跨解码步骤保持一致性。仅保留少量关键KV对即可。
- **自适应头（Adaptive Heads）**：注意力分布随解码步骤动态变化，需要更广泛的注意力空间。保留大部分KV对以确保精度。

### 2.2 关键技术细节

**（1）观测矩阵（Observation Matrix）**：利用预填充阶段最后 $L_{obs}$ 个query token构造观测矩阵：

$$A = \text{softmax}\left(\frac{Q[-L_{obs}:,:]K^T_{[L_{init}:-L_{rec},:]}}{\sqrt{d}}\right)$$

其中初始token与最近token因天然重要而被暂时排除在识别过程之外，以避免干扰分类。

**（2）变异系数得分（Coefficient of Variation Score）**：一致头的观测矩阵具有行间高相似度和少数列占有大部分注意力权重的特征。算法先将矩阵按百分位阈值 $k$ 和缩放因子 $\alpha$ 二值化，得到频率向量 $C$（记录每个token被识别为关键token的次数），再计算其变异系数作为分类得分：

$$\text{score} = \frac{\sqrt{\frac{1}{m}\sum_i (C_i - \mu(C))^2}}{\mu(C)}$$

**（3）基于参考集的静态头识别**：由于同一头在不同样本间表现出高度一致的模式（重叠率超过80%），论文通过参考数据集（100个128K长度的RULER Variable Tracking任务样本）统计每个头被识别为一致头的频率，从而确定与具体样本无关的固定头类型，避免了动态识别的内存管理开销。设定自适应头比例 $r$，得分高于阈值 $\Gamma(r)$ 的头为一致头，否则为自适应头。

**（4）缓存策略（Algorithm 1）**：
- 预填充阶段：基于观测窗口的注意力权重计算token重要性，将token划分为chunk并取最大值（BlockMax），选top-k chunk对应的KV对进行缓存。
- 一致头：仅缓存少量关键KV对（如$1.56\%$，2048个稀疏预算）。
- 自适应头：保留绝大多数KV对（可按保留比例 $\eta$ 调整，默认$\eta=1.0$），并支持与检索方法（如Quest、ShadowKV）集成来提升计算效率。
- 解码阶段：一致头直接使用已缓存的关键KV对；自适应头检索或使用全量KV对。

**（5）理论分析**：论文通过Rademacher复杂度给出了引用数据集上CV分类误差的泛化上界，并进一步推导出token保留精度的下界表达式，指出三个关键影响因素：token相关性度量（由注意力分数排序）的有效性概率 $\lambda$、预算控制（各类头的保留预算与最优预算的接近程度）、以及头分类精度 $P_{head}$。

## 6. 论文的主要结论与发现

- **核心发现**：LLM中存在两类不同分工的注意力头——具有顺序一致性的"一致头"与动态变化的"自适应头"，且该现象跨模型普遍存在，可通过变异系数得分稳定识别。
- **方法有效性**：在RULER-128K上，CateKV在仅保留41% KV缓存（对于一致头仅保留1.56%预算）的情况下，在多个模型上达到或超过全注意力的平均精度，全面优于StreamingLLM、SnapKV、PyramidKV和DuoAttention等基线。例如Llama-3-8B-1M上平均84.61%（全注意力84.10%）。
- **效率收益显著**：在单样本推理中最高减少2.72倍内存使用、加速2.18倍解码（Llama-3上，精度下降不超过0.25%）；批量推理中提升最高3.96倍吞吐量。内存和延迟相对上下文长度的增长斜率更缓（相比全注意力）。
- **兼容性强**：CateKV可与KV检索方法（Quest、ShadowKV）、预填充加速方法（MInference）和已有注意力头分类方法（DuoAttention）无缝集成，集成后不仅不损失精度甚至略有提升。
- **鲁棒性好**：一致头对稀疏预算非常不敏感（预算降至1024即0.78%仍保持性能），表明一致头本身只需极少量缓存，全局信息获取依赖于自适应头。
- **可扩展性强**：在30B级模型（Qwen2.5-32B、Yi-34B-200K）上与全注意力性能几乎持平，验证了在更大模型上的适用性。
