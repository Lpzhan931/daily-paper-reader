## 摘要
推测解码是一种成功的技术，它通过快速草稿模型加速目标自回归语言模型的推理。有损推测解码允许相对于目标模型发生漂移，以进一步提高速度。有趣的是，实验观察到，所得模型还可以在质量上超越目标模型。我们的论文正式证明了，通过一种称为导师式解码的有损推测解码形式化方法，这种壮举如何成为可能。为此，我们将推理与著名的机器学习训练理论——提升法（boosting）——联系起来，并通过将导师式解码推广到整个 f-散度集合来推进。我们揭示了导师式解码的关键性质，其中包括：(i) 全变差情形特别吸引人的几何性质；(ii) 与提升法符合度直接相关的任意 f-散度的简单近似；以及 (iii) 一种与散度无关的 O(n) 空间和 O(sort(n)) 时间的数据结构，它建立在草稿模型和目标模型输出之上，允许在 O(log n) 时间内查询对偶问题的最优参数，并在 O(n) 时间内为任意 f-散度构造最优导师式分布。

## Abstract
Speculative decoding is a successful technique speeding up inference of a target autoregressive language model via a fast drafter model. Lossy speculative decoding allows a drift with respect to the target to further improve speed. Interestingly, it has been observed experimentally that the resulting model can $\textit{also}$ beat the target $\textit{quality-wise}$. Our paper formally proves how such a feat is possible with a formal approach to lossy speculative decoding called $\textit{mentored decoding}$. To get there, we connect inference to a celebrated ML training theory, $\textit{boosting}$, and proceed via the generalization of mentored decoding to the whole set of $f$-divergences. We uncover key properties of mentored decoding, among which (i) the particularly appealing geometric nature of the total variation case, (ii) simple approximations for any $f$-divergence in direct relation with boosting compliance, and (iii) a $\textit{divergence independent}$ $O(n)$ space and $O(\mathrm{sort}(n))$ time data structure built on drafter and target outputs, which allows to query the optimal parameters of the dual problem in $O(\log n)$ time and constructing optimal mentored distributions in $O(n)$ time for any $f$-divergence.

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：大语言模型（LLM）自回归推理受限于内存带宽瓶颈，推测解码（Speculative Decoding, SD）通过小型快速草稿模型提出候选 token、再由目标模型并行验证来加速推理。
- **SD 的根本限制**：SD 要求输出分布严格等于目标分布，Sun et al. (2023) 证明在此约束下 SD 的接受率已达最优，无法进一步提升。
- **有损推测解码的兴起**：为突破接受率上限，一系列工作允许输出分布与目标分布之间存在有界漂移（lossy SD）。Tran-Thien (2023) 首次将此类问题形式化为"导师式解码"（Mentored Decoding, MD）：在目标分布与输出分布的散度不超过 D 的约束下，最大化草稿 token 的接受率。
- **关键实验观察**：近期多项实验（Li et al., 2026a; Qin et al., 2025; Zhong et al., 2025）观察到，有损 SD 得到的复合输出模型有时在质量指标上反而**超越目标模型本身**，但此前缺乏形式化解释。
- **本文目标**：首次对 MD 的推理效率与模型质量进行联合形式化分析，将 MD 与机器学习经典训练理论——**Boosting**——建立联系，证明"加速推理同时提升质量"这一现象在理论上确实可行。

## 2. 方法论：核心思想、关键技术细节与算法流程

### 2.1 MD 的两种等价参数化

- **f-MD-2（直接参数化）**：寻找接受概率向量 \(r \in [0,1]^n\) 与重采样分布 \(s \in \Delta_n\)，在 \(D_f(p \circ r + (1-p^\top r) \cdot s \,\|\, q) \leq D\) 约束下最大化 \(p^\top r\)。
- **f-MD-1（单参数化）**：寻找导师式分布 \(\pi \in \Delta_n\)，在 \(D_f(\pi \| q) \leq D\) 约束下最小化 \(D_{\mathrm{TV}}(\pi \| p)\)。
- **Lemma 3.2** 证明两种参数化一一对应，且目标函数满足 \(p^\top r = 1 - D_{\mathrm{TV}}(\pi \| p)\)。

### 2.2 全变差散度（TV-MD）的几何刻画

- **Theorem 3.4**：TV-MD 的最优解集为
  \[
  \Delta_n \cap \{D_{\mathrm{TV}}(\cdot \| q) = D\} \cap [\min\{p,q\}, \max\{p,q\}]
  \]
  即 n 维超矩形与概率单纯形的交集，再激活散度约束，呈现极简几何结构（L1 球的切点）。
- 该最优解集"足够大"，能够包含所有严格凸 f-散度的最优解。

### 2.3 一般 f-散度的最优解形式

- **Corollary 3.10**：对严格凸的 f，最优导师式分布唯一且具有坐标级夹紧形式：
  \[
  \pi^* = \max\{(1-b) \cdot q,\ \min\{p,\ (1+a) \cdot q\}\}, \quad 0 \leq a,\ b \in (0,1]
  \]
  即在单纯形中连接目标 q 到草稿 p 的一维轨迹上，且该轨迹**独立于 f**。
- **Theorem 3.12**：给出任意 f 下满足 KKT 条件的近似解，并给出接受概率与散度上界的显式表达。
- **Theorem 3.13**：所有严格凸 f 的最优解集合（随 D 变化）完全相同，且都包含在 TV-MD 的最优解集中（"One mentor to rule them all"）。

### 2.4 与 Boosting 的连接

- **Boosting 方案**：将 Nock & Nielsen (2007) 的自归一化 Boosting 推广到多类情形，用于分析 LLM 最后层输出的组合。
- **权重更新**（式 34）：\(w_{t+1,i} \propto w_{t,i} \cdot \frac{1-\mu_t \cdot y_i^\top h_t(x_i)}{1-\mu_t^2}\)，无需归一化系数。
- **Boosting 输出**（式 37）：\(\tilde{\pi}_T(x) \propto \prod_{t=1}^T p_t(x)^{c_t / \sum_u c_u}\)。
- **Theorem 4.2**：证明几何平均意义下"好 token"相对于"坏 token"的指数级优势，速率为 \(\exp(-16\sum_t \mu_t^2)\)。
- **两条连接路径**：
  - **TV 情形（Theorem 4.7）**：利用 TV-MD 最优解集的"大"特性，直接在其中嵌入 Boosting 组合，并给出接受概率提升与散度上界 \(D_{f_{\mathrm{TV}}} \leq \varrho_{pq}\varepsilon_{pq}\)。
  - **一般情形（Theorem 4.8）**：利用 Theorem 3.12 的近似解形式，证明其天然具有 Boosting 性质，质量提升受夹紧系数 \(k = \sqrt{(1+a)/(1-b)}\) 控制。

### 2.5 算法与数据结构

- **Breakpoints 数据结构**（Algorithm 2）：基于草稿与目标输出的概率比 \(p_i/q_i\) 排序，构建 O(n) 空间的数据结构，时间 O(sort(n))。
- **查询**（Algorithm 3）：对任意 \(0 \leq \tilde{a} \leq a_N\)，O(log n) 时间内返回 \(\tilde{b}\) 使得 \((\tilde{a}, \tilde{b}) \in C(p,q)\)。
- **最优分布构造**：给定 D，O(n log n) 找到精确最优解；利用式 (31) 的保守上界，可降至 O(log n) 得到近似解；对偶问题（给定最小接受概率 P，最小化散度）可在 O(log n) 内求解参数、O(n) 内构造分布。
- **Theorem 5.4**：散度阈值函数 \(D_f(P)\) 在 SD 接受概率处的右导数等于 \(\max \partial f(1) - \min \partial f(1)\)；对在 z=1 可微的 f，该导数为 0，说明**可以极小的散度代价换取显著的接受率提升**。
- **Top-k 扩展**（Lemma 6.1）：当目标分布被截断到 top-k 时，存在支撑集为这 k 个坐标的最优解，可将问题规模从 n 降至 k，排序复杂度降为 O(k log k)。

## 6. 主要结论与发现

1. **质量反超可行性的形式化证明**：通过将 MD 与 Boosting 联系，证明了有损推测解码在加速推理的同时，其复合输出模型在质量上超越目标模型是理论上可实现的。
2. **TV-MD 的优美几何结构**：最优解集为超矩形与单纯形的交集，且包含所有严格凸 f-散度的最优解。
3. **一般 f-散度的极简最优解**：严格凸 f 下最优导师式分布唯一，形式为坐标级夹紧 \(\pi^* = \max\{(1-b)q, \min\{p, (1+a)q\}\}\)，且轨迹独立于 f。
4. **散度阈值的右导数为零**：对在 z=1 可微的 f-散度，可以在几乎不增加散度的情况下显著提升接受概率（>10%）。
5. **与散度无关的高效数据结构**：breakpoints 数据结构支持 O(log n) 查询最优对偶参数、O(n) 构造最优分布，适用于任意 f-散度。
6. **Boosting 合规性**：MD 的复合输出"隐藏"了具有 Boosting 性质的模型组合，可用于评估草稿与目标模型的互补性，并作为模型选择的准则。
