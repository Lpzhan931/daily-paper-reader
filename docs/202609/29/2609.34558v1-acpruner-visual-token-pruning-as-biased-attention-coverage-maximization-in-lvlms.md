## 摘要
大型视觉-语言模型（LVLM）因大量视觉令牌而面临显著的计算低效问题。现有的视觉令牌剪枝方法主要关注于保留单个重要的令牌或选择彼此多样的令牌。在本工作中，我们从覆盖的角度重新审视视觉令牌剪枝，并将其形式化为一个有偏注意力覆盖最大化问题。其核心思想是选择一个紧凑的令牌子集，使其在编码器侧的输出注意力能够共同覆盖图像，同时为信息更丰富的区域分配更高的覆盖优先级。基于这一视角，我们提出了 ACPruner，一个无需训练的视觉令牌剪枝框架，用于高效的 LVLM 推理。ACPruner 首先结合模态内显著性和模态间相关性来估计令牌重要性，然后根据视觉编码器内部的注意力模式推导令牌级覆盖，最后执行贪心选择以最大化所提出的覆盖目标。在多个 LVLM 主干网络（包括 LLaVA-1.5-7B/13B、LLaVA-NeXT-7B/13B、Qwen2.5-VL-7B 和 LLaVA-OneVision-7B）上的大量实验表明，ACPruner 在实现显著端到端推理加速的同时，始终能保持强劲的性能。

## Abstract
Large Vision-Language Models (LVLMs) face significant computational inefficiencies caused by the large number of visual tokens. Existing visual token pruning methods mainly focus on either retaining individually important tokens or selecting mutually diverse ones. In this work, we revisit visual token pruning from a coverage perspective and formulate it as a biased attention coverage maximization problem. The key idea is to select a compact token subset whose encoder-side outgoing attention can jointly cover the image while assigning higher coverage priority to more informative regions. From this perspective, we propose ACPruner, a training-free visual token pruning framework for efficient LVLM inference. ACPruner first estimates token importance by combining intra-modal saliency and inter-modal relevance, then derives token-wise coverage from attention patterns within the vision encoder, and finally performs greedy selection to maximize the proposed coverage objective. Extensive experiments across multiple LVLM backbones, including LLaVA-1.5-7B/13B, LLaVA-NeXT-7B/13B, Qwen2.5-VL-7B, and LLaVA-OneVision-7B, show that ACPruner consistently achieves strong performance retention while delivering substantial end-to-end inference speedups.
