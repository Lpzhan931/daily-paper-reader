## 摘要
尽管无草稿模型的投机解码为高效 LLM 推理提供了一条有前景的路径，但它常常受限于陈旧的草稿候选以及验证的高计算成本。为解决这些挑战，我们提出了 ECHO，一种分层双循环框架，利用 LLM 各层之间的功能不对称性。借助早期层的高判别效率与最终层的权威分布，ECHO 将推理分为高频内循环和低频外循环。在内循环中，早期层 Bonus Logits 以极低代价驱动快速的多步草稿树探索。同时，外循环通过状态复用机制执行权威的全模型验证。至关重要的是，外循环还利用最终层 Bonus Logits 来纠正现有路径，并为后续循环用高置信度候选补充树。跨多个基准的实验结果表明，ECHO 显著提高了平均接受 token 数，并实现了 2.4× 到 2.9× 的加速，在工程开销可忽略且无额外部署参数的情况下优于现有最先进基线，尽管为了实现最优加速依赖于一次性微调。代码见 https://github.com/whucs21Mzy/ECHO。

## Abstract
While draft-model-free speculative decoding offers a promising path to efficient LLM inference, it is frequently constrained by stale draft candidates and the high computational cost of the verification. To address these challenges, we propose ECHO, a hierarchical dual-loop framework that exploits the functional asymmetry between LLM layers. Leveraging the high discriminative efficiency of early layers and the authoritative distribution of final layers, ECHO bifurcates inference into a high-frequency inner loop and a low-frequency outer loop. Within the inner loop, early-layer bonus logits drive rapid, multi-step draft-tree exploration at a minimal cost. Simultaneously, the outer loop performs authoritative full-model verification through a state-reuse mechanism. Crucially, the outer loop also utilizes final-layer bonus logits to correct existing paths and supplement the tree with high-confidence candidates for subsequent cycles. Experimental results across diverse benchmarks demonstrate that ECHO significantly boosts mean accepted tokens and achieves a 2.4$\times$ to 2.9$\times$ speedup, outperforming existing state-of-the-art baselines with negligible engineering overhead and no extra deployment parameters, albeit with a one-shot fine-tuning dependency for optimal acceleration. The code is available at https://github.com/whucs21Mzy/ECHO.

- **研究背景**：大语言模型（LLM）自回归解码受内存带宽限制，推理延迟高。投机解码通过“先草稿、后验证”实现无损加速，但现有方法面临两类瓶颈。
- **核心问题**：
  - **草稿候选陈旧**：无草稿模型方法依赖历史上下文或最终层 logits，需完整前向传播才能刷新，导致草稿信息密度低、接受长度受限。
  - **验证墙**：每个草稿 token 都需经过完整目标模型验证，草稿质量波动时加速比不稳定，计算开销高。

- **整体含义**：ECHO 利用 LLM 层间功能不对称性——早期层判别效率高、最终层分布权威——将推理拆分为高频内循环与低频外循环，在**不引入额外部署参数**的前提下，同时提升平均接受 token 数（MAT）并降低验证开销，目标是在边缘/本地推理场景中实现稳定加速。

## 2. 方法论：核心思想、关键技术细节与算法流程

- **核心思想**：将目标模型 \(M\) 在中间层 \(L_e\) 切分为：
  - 早期层验证器 \(V_e\)：第 1 到 \(L_e\) 层，负责高频、低成本的草稿树验证与探索。
  - 后续层验证器 \(V_s\)：第 \(L_e+1\) 到 \(L\) 层，负责低频、权威的全模型验证。
- **分层验证机制**：
  - **阶段 1：早期层树验证**。将候选 token 组织为分支树 \(T\)，用树注意力掩码 \(M_{tree}\) 保证每个子节点只关注自身祖先和自身，隔离不同语义分支。位置编码按树深度对齐。
  - **阶段 2：后续层因果验证**。内循环结束后，\(V_s\) 对累积序列 \(S_{acc}\) 做因果注意力验证，并复用早期层隐藏状态 \(H^{(L_e)}_{acc}\)，跳过前 \(L_e\) 层，降低 FLOPs 和内存带宽。
  - **无损性**：通过函数复合恒等式 \(M(S_{acc}) \equiv V_s(V_e(S_{acc}))\) 和标准拒绝采样，保证输出严格服从目标分布。
- **Bonus Logits 机制**：
  - **早期层 Bonus Logits**：由 \(V_e\) 在退出层产生，高频、低成本，用于快速刷新草稿树，提供局部语义指导。
  - **最终层 Bonus Logits**：由 \(V_s\) 在全模型验证后产生，分布权威、高保真，用于纠正已有路径、补充高置信候选，并作为下一轮草稿树根节点。
  - 两者均被回收为下一轮投机锚点，不增加额外推理成本。
- **草稿树构建**：融合检索与 logits 预测：
  - \(T = \text{MATCH}(R, q) \cup \text{Top-k}(p_t)\)
  - 其中 \(R\) 为基于 trie 的参考自动机，维护历史 n-gram 与已验证转移；\(q\) 为查询 n-gram；\(p_t\) 为回收的 bonus logits。
  - 每个被接受 token 会更新自动机：\(R \leftarrow \text{UPDATE}(R, x_{<i}, x_i)\)。
- **ECHO 推理流水线**：
  - **Phase I 上下文初始化**：全模型前向处理 prompt，填充全局 KV cache，生成首个最终层 bonus logits，初始化自动机。
  - **Phase II 敏捷探索（内循环）**：高频构造混合草稿树，早期层树注意力验证，接受 token 立即写入自动机，并采样早期层 bonus logits 作为下一锚点。
  - **Phase III 权威对齐（外循环）**：内循环缓冲区达到阈值后，同步 KV cache 和隐藏状态，后续层做因果验证；若发生分歧则回滚 KV cache 到已接受位置；更新自动机并生成最终层 bonus logits 作为下一轮锚点。
- **算法要点**：整体为双循环结构，内循环负责快速多步草稿探索，外循环负责权威验证与纠偏，形成“探索—验证—更新”的闭环。

## 6. 主要结论与发现

- ECHO 在多个 benchmark 和模型规模上取得稳定加速，整体加速比约 **2.4× 到 2.9×**，峰值达 **3.01×**（Llama-2-13B）。
- 显著提升 MAT：例如 Llama-2-7B 整体 MAT 约 5.07，Llama-3.2-1B 整体 MAT 约 5.55。
- 优于 PLD、TokenRecycling、LogitSpec、LayerSkip、Self-Speculative 等基线；在 Llama-3-8B 上整体 speedup / MAT 达 3.79× / 4.84，优于 EAGLE-2 的 2.84× / 3.37。
- 分层验证有效降低总层通过数和 FLOPs：512 token 任务中总层通过数减少约 21%，执行时间降低约 12%，中位数计算量减少 17.4%。
- 状态复用同步开销低：分布式和高并发下同步桥接仅占总执行时间约 1.15%。
- 方法无需额外部署参数，工程开销小，但最优加速依赖一次性微调。
- 3 级级联并非总是更优：在 Llama-3-8B 上 3 级结构反而增加同步开销和低质量早期 logits 带来的验证负担。

## 7. 优点：方法或实验设计亮点

- **无需额外参数**：不增加辅助 drafter 模型或额外解码头，部署友好。
- **层间功能不对称利用巧妙**：早期层做高频草稿探索，最终层做权威验证，兼顾速度与质量。
- **双 Bonus Logits 设计**：早期层和最终层 logits 分别承担“探索”和“纠偏”角色，提升草稿树信息密度。
- **状态复用降低验证墙**：复用 \(H^{(L_e)}_{acc}\) 和 KV cache，避免重复计算前 \(L_e\) 层。
- **混合草稿树**：融合检索式 n
