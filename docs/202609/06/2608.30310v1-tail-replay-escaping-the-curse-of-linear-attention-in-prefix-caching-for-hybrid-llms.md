## 摘要
混合大语言模型将全注意力层与线性注意力层交错结合，以降低长上下文推理成本。这种结构使前缀缓存复杂化：全注意力键值缓存按令牌可寻址，而线性注意力层维护的循环状态无法回滚到任意前缀边界。现有的混合前缀缓存方法通过存储循环状态检查点来解决这种不匹配问题。因此，词元级匹配仅在存储检查点对齐的位置处可直接使用，将前缀重用限制在一组离散边界上。我们提出Tail-Replay，一种前缀缓存机制，在混合大语言模型中实现无约束的词元级前缀重用。关键洞见在于，诸如Gated DeltaNet之类的线性注意力机制可视为对输入前缀的结构化有损压缩：门控循环更新逐步衰减早期输入的贡献。因此，匹配前缀的循环状态可通过仅重放该前缀的一个短近期后缀来很好地近似。Tail-Replay利用此性质，缓存精确的全注意力键值缓存，同时省略循环状态检查点。缓存命中时，通过重放匹配前缀的一个短近期后缀来重建线性注意力状态。由此，重用边界由共享词元决定，而非循环状态检查点。我们使用LongBench和RULER基准在三个基于Gated DeltaNet的混合模型上评估Tail-Replay。仅使用5–10%的重放预算，在LongBench和RULER上保留了完整预填充质量的92.8–99.9%。针对服务效率，我们评估了多个匹配前缀长度——8K、16K和32K下的首个令牌时间加速。加速随前缀长度增长，在32K时达到全预填充的9.1–14.3倍。

## Abstract
Hybrid large language models interleave full-attention layers with linear-attention layers to reduce the cost of long-context inference. This structure complicates prefix caching: full-attention key-value caches are token-addressable, whereas linear-attention layers maintain recurrent states that cannot be rolled back to arbitrary prefix boundaries. Existing hybrid prefix caching methods address this mismatch by storing recurrent-state checkpoints. As a result, token-level matches are directly usable only at positions aligned with stored checkpoints, constraining prefix reuse to a discrete set of boundaries. We present Tail-Replay, a prefix caching mechanism that enables unconstrained token-level prefix reuse in hybrid large language models. The key insight is that linear-attention mechanisms such as Gated DeltaNet can be viewed as a structured, lossy compression of the input prefix: gated recurrent updates progressively attenuate the contributions of earlier inputs. Consequently, the recurrent state of a matched prefix can be well approximated by replaying only a short, recent suffix of that prefix. Tail-Replay exploits this property by caching the exact full-attention key-value cache while omitting recurrent-state checkpoints. On a cache hit, it reconstructs the linear-attention states by replaying a short, recent suffix of the matched prefix. As a result, the reuse boundary is determined by the shared tokens rather than by recurrent-state checkpoints. We evaluate Tail-Replay on three Gated DeltaNet-based hybrid models using the LongBench and RULER benchmarks. With only a 5--10\% replay budget, it retains 92.8--99.9\% of full-prefill quality on LongBench and RULER. For serving efficiency, we evaluate time-to-first-token speedups across multiple matched-prefix lengths---8K, 16K, and 32K. The speedup grows with prefix length, reaching $9.1$--$14.3\times$ over full prefill at 32K.

## 1. 核心问题与整体含义

**研究动机与背景**

- 大语言模型应用日益复杂，从单轮指令跟随扩展到多轮对话、检索增强生成、工具调用与多智能体工作流，带来更长上下文、更高并发和更频繁的重复调用，服务效率成为关键实际挑战。
- 模型层出现了**混合架构**（混合 LLM），将少数全注意力（full-attention，FA）层与线性注意力层交错堆叠，旨在降低长上下文推理成本，代表如 Gated DeltaNet（GDN）等状态空间方式。
- 服务层出现了**前缀缓存**技术，重复请求共享前缀可避免冗余预填充，已有的 RadixAttention、Prompt Cache 等方法在纯全注意力模型中表现良好，因为 FA KV 缓存是词元（token）级别可寻址的。
- 两者天然互补，但**混合模型与现有前缀缓存机制难以直接兼容**。根本矛盾在于：FA 层的 KV 缓存可按任意词元边界复用；而线性注意力层将前缀压缩为循环状态（如 S_i），状态只在逐词元更新中前进，**无法回滚到任意更早前缀**。
- 现有混合前缀缓存方案（如 Marconi、Sparse Prefix Caching）通过额外存储“循环状态检查点”缓解此问题，但**本质上仍使复用边界由检查点位置而非真实的共享词元前缀决定**，依然受限于一组离散边界。

**论文的工作定位**

- 论文将上述不匹配称为“线性注意力对前缀缓存的诅咒”（the curse of linear attention for prefix caching），并提出 Tail-Replay 机制，力图实现**无约束、任意词元级精度的前缀重用**。

## 2. 方法论

**核心思想与关键洞察**

- 关键洞察：Gated DeltaNet 等门控线性注意力可视为对输入前缀进行的一种**结构化、有损压缩**——门控循环更新会逐步衰减早期信息的影响。因此，给定一个已匹配的前缀，其循环状态不需要重放整个前缀才能得到：**从零初始状态重放该前缀最近的一小段后缀即可得到足够好的近似**。

**技术细节与流程**

- **缓存内容**：对每个已处理输入，只保留与 FA 层相关的词元级状态：
  - 每个 FA 层的键/值向量 \((K^{FA}_i, V^{FA}_i)\)；
  - 每个 FA 层的**输出隐藏层表示** \(h_i\)（这是尾重放所需的关键输入）。
  - 不再保存任何循环状态检查点。
- **架构分组**：将混合模型按“一个 FA 层 + 紧随其后的连续线性注意力层”划分为多个独立组。缓存每个 FA 层的输出隐藏，使每组中第一个线性注意力层的输入在重放时与原始预填充时完全一致，从而将重放误差控制在组内，避免跨组传播。
- **缓存命中与尾重放（Tail-Replay）**：
  - 若前缀前 m 个词元命中缓存，则直接复用对应 FA KV；
  - 只取最近 \(k = \lceil r m \rceil\) 个缓存的 FA 输出隐藏（r 为回放比例）；
  - 对每个组独立执行：初始化回放状态为零 \(\hat{S}_{m-k}=0\)，对尾段词元 \(i = m-k+1, \ldots, m\) 应用 GDN 循环更新公式：
    - \(\hat{S}_i = T_i \hat{S}_{i-1} + \beta_i v^{LA}_i (k^{LA}_i)^\top\)
    - \(T_i = \alpha_i (I - \beta_i k_i k_i^\top)\)
  - 最终状态 \(\hat{S}_m\) 即为对匹配前缀边界处循环状态的近似。
  - 完成后，模型使用重建的线性注意力状态 + 复用的 FA KV 继续处理未匹配后缀词元。
- **两个降低开销的优化**：
  1. **尾 FFN 跳过（tail-FFN skip）**：重放组内最后一层线性注意力块之后，并不需要计算该组尾部 FFN 输出——下一组以已缓存的精确 FA 输出隐藏为起点。因此重放过程中跳过这部分 FFN 计算，仅计算线性注意力块本身。
  2. **传输/重放重叠（transfer/replay overlap）**：Tail-Replay 不依赖 FA KV 缓存，因此 FA KV 从主机内存到设备的搬运可与重放在独立拷贝流上并行，只需在查询（query）前向传播前同步即可，将大部分数据传输成本隐藏。

## 6. 主要结论与发现

- **质量保持效果好**：在 LongBench 上，r=5% 保留 Full 预填充质量的平均 92.8–98.9%（随模型不同），r=10% 对应 93.9–98.1%；RULER 上 r=5% 为 93.1–99.9%，r=10% 为 96.7–99.9%。整体质量下降远小于 Zero-only（仅复用 FA KV、零化线性状态）造成的断崖式衰减，说明短尾重放确实能有效重建线性注意力状态。
- **效率增益显著且随前缀变长而增大**：在 32K 匹配前缀下，5% 回放 + 重叠传输路径相对完整预填充的 TTFT 加速为：OLMo-Hybrid-7B 9.8×、Qwen3.5-4B 9.1×、Qwen3.6-27B 14.3×；16K 下为 6.4×/5.2×/11.1×，8K 下为 3.2×/2.6×/5.7×。加速随前缀长度增长体现了缓存机制对长上下文的放大效应。
- **优化各自有效**：相较串行 H2D 传输，重叠 + FFN 跳过路径在 32K 下进一步降低 TTFT 约 18–42%；10% 回放预算在长上下文下会因重放成本上升而显著抬高 TTFT，说明实际部署需针对延迟/质量权衡选取合适回放预算。

## 7. 优点与亮点

- **问题识别精准且角度新颖**：明确指出混合模型前缀缓存的深层矛盾不在“存储多少缓存”，而在“线性注意力状态无法回滚导致词元级匹配不再直接对应可复用状态”，并基于 Gated DeltaNet 的**门控遗忘特性**提出用短重放代替检查点的反向思考——不存储额外状态，而是用廉价计算换灵活性，思路简洁优雅。
- **机制设计上干净且实用**：
  - 缓存精确的 FA KV + FA 输出隐藏，不引入额外检查点存储开销；
  - 按组独立回放可数学上保证重放误差被限制在各组内部，不随模型加深或匹配变长而跨层累积；
  - 只回放短尾，计算开销小，并针对重放路径做了 FFN 跳过和 DMA 重叠两个行之有效的裁剪，说明作者对系统实现有清晰考量。
- **实验证据链相对完善**：质量评测采用“完整预填充（上限）–零状态缓存（下限，最差情况）–Tail-Replay（所提方法）”的三点定位方式，使读者能直观判断方法在质量谱系中的真实位置以及重放的必要性。

## 8. 不足与局限

- **缺少与现有方案的同场竞技**：论文引用并说明 Marconi、Sparse Prefix Caching 等检查点方案的局限性，但在实验部分没有与它们进行直接对比，无法从经验上说明相对现有系统能快多少或质量有多少提升，削弱了结论的“压倒性”说服力。
