## 摘要
用作列表级重排序器的大型视觉语言模型必须联合处理每个查询中数十个候选对象的视觉令牌，这使得令牌剪枝对于实际部署至关重要。现有的剪枝方法通过注意力显著性保留令牌，然而我们表明，显著性与排序贡献存在系统性错位：视觉上突出的令牌往往捕获跨候选对象共享的顺序无关模式。这种错位是依赖层级的：只有在注意力集中时，显著性才具有信息量，而归一化注意力熵可以诊断这种可靠性变化（皮尔逊相关系数r=0.87）。我们提出RaDiCal（排序判别校准），一个免训练框架，利用归一化注意力熵来决定何时可以信任显著性，将其与免注意力的排序判别先验相融合，并从相同的信任图谱中选择剪枝层。在三个检索基准和多种VLM架构上，RaDiCal在20%令牌预算下，在Flickr30K上达到与全量模型相当的MRR@10，并在MSCOCO上超过全量模型的MRR@10；在FashionIQ上所有剪枝方法中排名第一；在保留10%令牌时，在Flickr30K和MSCOCO上与全量模型的差距保持在1.2个百分点以内。它将FLOPs减少了39%至45%，并在两种VLM架构上实现了1.28倍至1.45倍的实测加速，且无需针对特定数据集重新调优。

## Abstract
Large vision-language models used as listwise rerankers must jointly process visual tokens from tens of candidates per query, making token pruning essential for practical deployment. Existing pruning methods retain tokens by attention saliency, yet we show that saliency is systematically misaligned with ranking contribution: visually prominent tokens often capture order-neutral patterns shared across candidates. This mismatch is layer-dependent: saliency becomes informative only where attention is concentrated, and normalized attention entropy diagnoses the reliability shift (Pearson r=0.87). We propose RaDiCal (Rank-Discriminative Calibration), a training-free framework that uses normalized attention entropy to decide when saliency can be trusted, fusing it with an attention-free rank-discriminative prior and selecting pruning layers from the same trust landscape. Across three retrieval benchmarks and multiple VLM architectures, RaDiCal matches Dense MRR@10 on Flickr30K and surpasses it on MSCOCO at a 20% token budget, ranks first among all pruning methods on FashionIQ, and holds within 1.2 pp on Flickr30K and MSCOCO at 10% retention. It cuts FLOPs by 39--45% and delivers 1.28--1.45$\times$ measured speedups across two VLM architectures without dataset-specific retuning.

## 1. 核心问题与整体含义

**研究动机与背景：**
- 大型视觉语言模型（VLM）越来越多地被用作**列表级重排器（listwise reranker）**：将查询与数十个候选图像放在一个共享的多模态上下文中，联合打分并排序。
- 每张高分辨率图像会贡献成百上千个视觉 token，列表级重排还要乘以候选数，导致视觉 token 成为推理瓶颈，**token 剪枝对实际部署不可或缺**。
- 现有视觉 token 剪枝基本遵循“显著性保留”范式：保留注意力权重高或在单图内“重要”的 token。这种准则在单图理解任务中自然成立，但对“输出有序列表”的重排任务可能系统性失效：
  - 视觉上突出、被反复注意的区域通常是**候选图像间共有的、对排序无判别力**的模式（如“大多数候选里都有的狗的身体”）；
  - 真正决定排序的往往是**查询相关且能区分候选**的精细证据（如“红色飞盘”和“狗接飞盘的交互”）。

**核心问题：**
- 如何在压缩视觉 token 的同时保持重排器的**查询条件下候选顺序**？哪些 token 值得保留？注意力显著性在哪些层可以信任？哪些层应该执行剪枝？

**整体含义：**
- 论文通过诊断揭示：**注意力显著性与排序贡献之间不存在简单对应关系**；该错位是分层相关的，可以用归一化注意力熵在线诊断。
- 基于此提出了一个完全免训练、免逐数据集调参的剪枝框架 **RaDiCal**，将“显著性”重新校准为“排序判别性”，在极低 token 预算下较完好地保持重排质量，并带来 1.28–1.45× 实测加速。

## 2. 方法论

**核心思想：**
- 从“保留显著性”转向“保留排序判别性”：一个 token 只有在**同时具备查询相关性（query-relevant）**与**跨候选区分性（cross-candidate distinctive）**时才可能是排序关键的。
- 但“排序特定先验”单独不足：注意力显著性在注意力集中时仍有价值，在注意力分散时不可靠，因此必须对两种信号做**可信度校准**。
- 剪枝需要通过同一个“信任图谱”同时回答三个问题：**保留什么**（token 打分）、**何时信任显著性**（逐层融合权重）、**在哪些层剪**（剪枝层选择）。

**关键技术细节：**

1. **诊断与熵作为信任信号**
   - 对每个解码器层 l，定义归一化注意力熵 H_norm(l)（将文本行的注意力在视觉 token 上归一化并按图像平均后再计算 Shannon 熵除以 log V），H_norm ≈ 1 表示注意力均匀、无判别力；H_norm ≈ 0 表示注意力集中、显著性信息度高。
   - 实验发现：逐层显著性可靠性 z-score 与信息密度 I(l)=1−H_norm(l) 呈强相关（Pearson r=0.87），因此 H_norm 可作为推理期、轻量、分层的显著性可信度代理。
   - H_norm 剖面在不同数据集间保持几乎一致（Flickr30K 与 MSCOCO 皮尔逊 r=0.9993），模型内禀，无需按数据集重算。

2. **无注意力先验：判别性 token 重要性（DTI, Discriminative Token Importance）**
   - 对候选 ck 的视觉 token tki，计算：
     - CCU(tki, C) = 1 − cos(tki, v̄)，其中 v̄ 是所有候选视觉 token 的 L2 归一化均值（全局原型），度量跨候选独特性；
     - QRel(tki, q) = max(cos(tki, q_emb), 0)，度量查询相关性；
     - **DTI ∝ CCU · QRel**，在当前候选集中可一次算出，跨所有被选中层复用。
   - 该定义将偏好从“图内显著”引向“能改变候选顺序”的判别性 token。

3. **注意力信息量显著性（AttentionInfo saliency）**
   - 借助信息分解：层级 KL 散度 1−H_norm(T) 与逐 token 贡献的关系，得到 token 级分数：
     - AttInfo_i = max [ p_i · log(V_T · p_i), 0 ]，即只有注意力权重大于均匀基线 1/V_T 时 token 才为正贡献。
   - 将此值在活动 token 上做归一化得到 Sal_i ∈ [0,1]，作为与 DTI 互补的分层信号；当全部为 0 时回退到均匀分布，避免退化剪枝。

4. **信任校准融合**
   - 设 H_min 为模型 H_norm 曲线最小值（注意力最集中的一个层），定义：
     - α(l) = (H_norm(l) − H_min)/(1 − H_min) ∈ [0,1]；
     - α(l)=1 表示注意力均匀、显著性不可信，完全由 DTI 主导；
     - α(l)=0 表示显著性最可信，完全由 AttentionInfo 决定。
   - 采用几何融合（log-linear）：
     - f_i ∝ max(d_i,ε)^{α(l)} · max(s_i,ε)^{1−α(l)}，具备尺度不变性和软否决性质。

5. **α-Maximin 层选择**
   - 在 α 曲线上做“最远点贪心”，以最可信显著性层为锚，逐步选择 K 个剪枝层，使所选层的 α 值尽可能覆盖从 DTI 主导到显著性主导的不同信任区间，并加入最小层间隔约束。
   - 给定全局保留率 R，每层统一保留 R^{1/K}，依次乘起来恰好实现 R 的全局预算。
   - 默认 K=4，α-Maximin 在 Qwen3-VL-4B 上选出 [7,22,24,29] 层，对应 α=[0.84,0.43,0.22,0.00]，覆盖四个不同融合机制阶段。

**算法流程（文字说明）：**
1. 离线阶段：对给定模型计算各层 H_norm，得到 α 曲线，用 α-Maximin 选出排序后的剪枝层序列并计算逐层 keep ratio。
2. 在线阶段：从 ViT 输出计算 DTI 并归一化；依次前向到每个被选层，基于当前活动 token 计算 AttentionInfo，与 DTI 按该层 α 做几何融合；每层取融合分数最高的 top-k 个 token；最后将保留的 token 集送完 LLM 生成排序分数。

  - 几何融合（log-linear）显著优于线性融合或简单切换；
  - α-Maximin 层选择优于均匀选层或只选最可信层。
- **诊断结论**：注意力显著性与排序贡献的错位是**分层相关的**——浅层注意力较均匀、显著性不可靠，深层注意力集中、显著性较可靠；这一规律可用归一化注意力熵 H_norm 稳定刻画，且几乎不随数据集变化。
- **机理分析**：RaDiCal 保留的 token 中“查询相关且跨候选独特”的区域占比显著更高；被剪掉的 token 主要是候选间共有、对排序无判别性的视觉内容。定性可视化显示，RaDiCal 在“狗接飞盘”这类查询下保留了狗与飞盘交互的细粒度区域，而显著性基线保留了整只狗。

## 7. 局限性

- **候选规模受限**：所有实验均基于 20 个候选的列表重排，未验证在更大候选池（如 100+）下 token 预算分配与 DTI 计算的可扩展性。
- **对 H_norm 稳定性的依赖**：方法假设 H_norm 剖面对同一模型在不同数据上高度一致；若新任务的数据分布或提示格式发生显著变化（如超长文本查询、多图交错输入），该假设可能需要重新检验。
- **仅覆盖生成式 VLM 作为重排器**：现代列表级重排也可由专门的双塔/交互式模型完成，方法未在这些架构上验证。
- **“免训练”不等于“免适配”**：虽然无需梯度训练，但仍需对每个新模型离线计算一次 H_norm 曲线并执行 α-Maximin 层选择，模型更换时需要重复该步骤。
- **实际加速有限**：实测加速为 1.28–1.45×，低于 token 数缩减比例（约 5×），瓶颈转移至 LLM 自回归解码阶段的非视觉开销，压缩带来的端到端收益受限于模型整体延迟结构。
- **未报告计算能耗与完整推理成本**：效率分析只报告了延迟、FLOPs、KV cache 三类指标，缺少对多卡吞吐、批处理效率的讨论。

## 8. 结论与启示

**核心贡献总结：**
1. 首次系统诊断视觉 token 显著性在列表级重排任务中的失效模式，提出“显著性不可无条件下信任、需按层校准”的结论。
2. 提出 H_norm 作为免训练、分层的显著性可信度信号，其与真实可靠性的相关性达 r=0.87，且跨数据集稳定。
3. 设计 DTI（判别性 token 重要性）作为不依赖注意力的排序导向先验，通过几何融合与 α-Maximin 层选择，将“保留什么、何时信任、在哪里剪”统一在同一个框架下。
4. 在 3 个基准、2 个预算水平、2 个模型架构上全面超越现有剪枝方法，并带来稳定的端到端加速。

**对领域的启示：**
- 视觉 token 压缩不应继续默认“显著性 = 价值”，而应考虑**下游任务的目标函数**——排序任务要求保留跨候选判别性与查询相关性，而显著性只能作为受限的辅助信号。
- 分层注意力熵是一个极具潜力的通用诊断工具：它无需标注即可在线反映某层注意力是否“值得信任”，可作为很多 token 选择、早退（early exit）、自适应计算方法的轻量代理指标。
- 免训练、免调参的推理期压缩策略具备实用吸引力：给定模型架构后，离线计算与层选择可复用，在线仅需少量额外开销即可完成 token 选择。

**未来工作方向：**
- 将 RaDiCal 扩展到更大的候选池（50–100 候选）与更长的多图上下文；
- 将诊断框架推广到其他任务，如视觉问答、图文对话中的多候选选择；
- 探索将 α 曲线作为可学习信号而非完全启发式，在允许少量训练预算时进一步提升；
- 结合解码阶段优化（如 speculative decoding）以突破自回归生成阶段的效率瓶颈，使 token 压缩的加速比更充分地转化为端到端收益。
