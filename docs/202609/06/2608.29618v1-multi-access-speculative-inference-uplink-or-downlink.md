## 摘要
多接入推测推理（Multi-SPIN）将SPIN扩展到多设备边缘网络，以加速协同令牌生成。它允许设备端小语言模型（SLM）为各个生成任务自回归地草拟多个令牌，而边缘服务器大语言模型（LLM）则并行验证这些令牌。主要的通信开销出现在草拟令牌被服务器拒绝时，在这种情况下，采样修正令牌需要同时访问SLM输出的草拟分布和LLM输出的目标分布（覆盖完整词表）。现有设计通常通过在服务器端上传草拟分布来进行修正，但传输词汇表级分布会产生严重的上行（UL）瓶颈。另一种方式是利用下行（DL）可用的高速传输速率，通过下载目标分布在设备端进行修正。基于这一见解，我们将通信模式选择引入为Multi-SPIN的一个新设计维度。具体而言，每个设备可以自适应地在UL和DL模式之间切换，以在UL瓶颈与共享DL资源约束之间取得平衡，从而减轻整体通信负担。我们提出了一个总令牌吞吐量最大化问题，该问题联合考虑模式选择、草拟长度控制和功率分配。对于模式选择，我们揭示了一种简单的最优结构，可以高效搜索UL设备数量，并相应优化其发射功率。对于草拟长度控制，我们开发了一种贪心搜索算法，使特定于设备的草拟长度适应异构的计算和通信能力。在Qwen2.5和DeepSeek-R1模型对上的实验结果表明，所提出的框架显著提高了令牌吞吐量。

## Abstract
Multi-access speculative inference (Multi-SPIN) extends SPIN to multi-device edge networks to accelerate cooperative token generation. It allows on-device small language models (SLMs) to autoregressively draft multiple tokens for individual generation tasks, while an edge-server large language model (LLM) verifies them in parallel. The major communication overhead arises when a drafted token is rejected by the server, in which case sampling the correction token requires access to both the SLM-output draft distribution and the LLM-output target distribution over the full token vocabulary. Existing designs typically perform correction at the server by uploading the draft distribution, but transmitting a vocabulary-wide distribution creates a critical uplink (UL) bottleneck. Alternatively, the correction can be performed at the device by downloading the target distribution, leveraging the high transmission rates available on the downlink (DL). Motivated by this insight, we introduce communication-mode selection as a new design dimension for Multi-SPIN. Specifically, each device can adaptively switch between the UL and DL modes to balance the UL bottleneck against the shared DL resource constraint, thereby relieving the overall communication burden. We formulate a sum-token-goodput maximization problem that jointly accounts for mode selection, draft-length control, and power allocation. For mode selection, we reveal a simple optimal structure that enables efficient search over the number of UL devices, with the corresponding transmit powers optimized accordingly. For draft-length control, we develop a greedy-search algorithm that adapts device-specific draft lengths to heterogeneous computation and communication capabilities. Experimental results on Qwen2.5 and DeepSeek-R1 model pairs demonstrate that the proposed framework significantly improves token goodput.

## 1. 核心问题与整体含义
- **研究背景**：边缘智能场景下，在设备端运行大语言模型（LLM）受限于计算、内存和能耗，而完全依赖边缘服务器集中推理会形成瓶颈，尤其在自回归解码需逐 token 多次前向传播的背景下更为突出。
- **核心方法背景**：推测推理（SPIN）通过在设备端部署轻量级小语言模型（SLM）草拟多个 token，由服务器端 LLM 并行验证，可大幅降低服务器前向传播次数；随后“多接入推测推理（Multi-SPIN）”将 SPIN 推广到多设备协同生成场景。
- **核心问题**：SPIN 在无线边缘部署时，当草拟 token 被拒绝后，修正 token 的采样需访问覆盖完整词表的草拟分布与目标分布，传输这种高维分布会导致严重的通信瓶颈。现有研究主要采用“上行（UL）模式”——由设备上传草拟分布到服务器端修正，但 UL 速率有限；本文提出“下行（DL）模式”——由服务器下载目标分布到设备端修正，可借助更强的 DL 能力。
- **关键矛盾**：在多用户系统中，让所有设备都走 DL 模式会过度竞争服务器共享的 DL 功率资源，形成新的瓶颈；而 UL 与 DL 之间存在资源约束与速率不对称的根本张力。
- **解决方案思想**：将“通信模式选择”引入 Multi-SPIN，使每个设备根据信道、功率预算、拒绝事件等自适应地在 UL 与 DL 修正之间切换，以此平衡上行瓶颈与共享下行资源约束，最大化端到端 token 吞吐量（goodput）。这扩展了 Multi-SPIN 的资源利用宗旨，从计算域延伸到通信域。

## 2. 方法论
### 2.1 系统与协议设计
- 提出一种基于通信模式选择的 Multi-SPIN 协议，包含公共步骤（设备端自回归草拟、草拟 token-概率对上传、服务器批量并行验证）和结果相关步骤：
  - 若某设备所有草拟 token 都被接受，服务器仅需采样一个 bonus token 并下发。
  - 若发生拒绝，则设备进入修正流程：
    - **UL 模式**：设备上传其完整草拟分布，服务器端采样修正 token 后下发给设备。
    - **DL 模式**：服务器下载目标分布到设备，设备端采样修正 token 并回传一个 token 给服务器。
- 协议采用“先主动规划、后反应式决策”的两阶段时序：每轮开始前服务器确定草拟长度 γ；验证结果揭晓后确定被拒设备的通信模式与发射功率。

### 2.2 问题建模
- 定义每个设备输出 token 数期望由公式 \( \bar{L}(\gamma)=\sum_k (1-\alpha_k^{\gamma_k+1})/(1-\alpha_k) \) 给出，其中 α_k 是接受概率。
- 总计算时延 = 最大设备草拟时延 + 批量验证时延；批量验证时延建模为 \( T_{\rm ver}=T_{\rm ver}^0+KT_{\rm ver}^1 \)。
- 通信时延来自完整分布传输，每个拒绝设备需传 \( V_{\rm eff}(\lceil\log_2 V\rceil+Q) \) 比特；通信速率依赖 UL/DL 模式及功率分配；并行传输时整体通信时延由最慢设备决定。
- 形成**两级随机优化问题**：
  - 第一级（主动草拟长度控制）：在验证前选定各设备 γ_k，最大化期望总 token goodput \( G(\gamma,\chi)=\bar{L}(\gamma)/(T_{\rm comp}(\gamma)+\mathbb{E}[T_{\rm comm}(\chi(o);o)]) \)。
  - 第二级（反应式模式选择与功率分配）：在每个验证结果 o 下，给定拒绝设备集合，最小化最大通信时延：
    \( \min_{m,p} \max_{k\in\mathcal{R}} T_k^{\rm comm}(m_k,p_k) \)，受 UL 每设备功率上限和服务器 DL 总功率约束。

### 2.3 最优反应式模式选择与功率分配
- **固定模式的功率分配**：
  - UL 模式下各设备以最大功率传输，得到最小 UL 时延 τ_ul。
  - DL 模式下需在共享总功率约束下设计功率以均衡最差时延，Lemma 1 给出闭式功率分配 \( p_k^* = \frac{N_0 B_k}{|h_k|^2}(2^{V_{\rm eff}(\lceil\log_2 V\rceil+Q)/(B_k\tau_{\rm dl})}-1) \)，τ_dl 由二分搜索确定。
- **模式选择的最优结构**（Lemma 2）：将被拒设备按最小 UL 时延升序排列后，存在最优前缀结构：前 n 个设备分配 UL 模式，剩余设备分配 DL 模式。证明通过交换论证进行。
- **最优分割点搜索**（Proposition 1）：τ_ul(n) 随 n 非减、τ_dl(n) 随 n 非增，故差值 Δτ(n) 非增；最优 n 只需在第一个 Δτ(n)≤0 的 n̄ 附近（即 n̄−1 与 n̄）取 τ(n) 最小即可，且 n̄ 可通过二分搜索高效求得。最终 O(log |R|) 复杂度得到全局最优。

### 2.4 主动草拟长度控制算法
- 目标函数含随机期望，无闭式解，因此提出 **贪心搜索算法**：
  1. **同步全 1 更新阶段**：从 γ=0 开始，逐步尝试 γ←γ+1，只要 goodput 增加就继续，直到收敛。
  2. **坐标贪心精炼阶段**：依次对每个设备尝试 γ←γ+e_k，选择使 goodput 最大的更新，若仍有增益则接受，否则终止。
- goodput 期望评估采用**样本平均近似（SAA）**：从验证结果的概率分布中抽取 N_SAA=1000 个样本近似期望，避免对 2^K 个结果逐项枚举；每个样本的通信时延由前述最优反应式策略计算。

## 6. 主要结论与发现
- 自适应 UL/DL 模式选择显著优于固定的“全 UL”“全 DL”或随机模式，且无论 DL 功率相对充裕还是受限都能保持优势。
- 随着 DL 功率预算增大，更多被拒设备从 UL 模式迁移至 DL 模式，但仍保留一部分设备在 UL 模式，因为全部走 DL 会造成不必要的共享功率竞争。
- 草拟长度随 DL 功率预算增加总体上升，因更长草拟带来的拒绝通信惩罚随着通信能力改善而降低。
- 提出的贪心草拟长度控制优于最优 uniform 草拟长度和 computation-only 控制，表明设备异构性与通信条件必须纳入草拟长度设计。
