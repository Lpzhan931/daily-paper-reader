## 摘要
投机解码通过轻量级草稿模型提出多个候选词元，并由较大的目标模型并行验证，从而加速自回归语言模型推理。然而，在首次拒绝后，基于前缀的标准验证会丢弃剩余的草稿后缀，因此生成和验证这些位置所花费的计算不会促进解码进展。聚焦于DFlash，我们表明被拒绝后缀中的被拒绝位置仍可能与目标延续对齐，这表明草稿模型尽管存在局部词元级错误，仍能保留有用的语义和结构信息。基于此观察并受条件扩散启发，我们引入了\textbf{ReTrace}，一种拒绝轨迹条件化方法，它将每个草稿块的条件设定为上一轮的被拒绝后缀，而不是仅从全新的掩码占位符生成。ReTrace保留被拒绝后缀的隐藏表示，将它们与下一个草稿块对齐，利用同一验证过程中的目标感知校正信号对它们进行细化，并通过门控残差融合将其纳入草稿器的输入嵌入。由于被拒绝的词元从未被提交，且目标端验证保持不变，ReTrace在不需要额外模型前向传播的情况下保留了投机解码的无损特性。使用Qwen3模型在数学推理、代码生成和开放域对话上的实验表明，ReTrace在平均接受长度和端到端解码速度上均持续优于其DFlash骨干。通过在不修改轮内提案生成的情况下引入跨轮条件化，ReTrace在很大程度上与现有草稿改进正交，并可能与其结合以获得进一步收益。

## Abstract
Speculative decoding accelerates autoregressive language model inference by having a lightweight draft model propose multiple candidate tokens, which are then verified in parallel by a larger target model. However, after the first rejection, standard prefix-based verification discards the remaining draft suffix, so the computation spent generating and verifying those positions does not contribute to decoding progress. Focusing on DFlash, we show that rejected positions in a rejected suffix may still align with the target continuation, indicating that the draft model can retain useful semantic and structural information despite local token-level errors. Motivated by this observation and inspired by conditional diffusion, we introduce~\textbf{ReTrace}, a rejected-trajectory conditioning method that conditions each draft block on the rejected suffix from the previous round rather than generating it from fresh mask placeholders alone. ReTrace retains the hidden representations of the rejected suffixes, aligns them with the next draft block, refines them using target-aware correction signals from the same verification pass, and admits them into the drafter's input embeddings through gated residual fusion. Because rejected tokens are never committed and target-side verification remains unchanged, ReTrace preserves the lossless property of speculative decoding without requiring an additional model forward pass. Experiments with Qwen3 models across mathematical reasoning, code generation, and open-ended dialogue demonstrate that ReTrace consistently improves average acceptance length and end-to-end decoding speed over its DFlash backbone. By introducing cross-round conditioning without modifying within-round proposal generation, ReTrace is largely orthogonal to existing drafting improvements and might be combined with them for further gains.

### 1. 核心问题与研究动机

**背景：**
- 大语言模型（LLM）的自回归解码效率严重受限于顺序生成——每个 token 都需一次依赖全部上文的前向传播，这限制了现代 GPU 并行计算能力的充分利用。
- 投机解码通过"轻量草稿模型 + 目标模型并行验证"的范式缓解这一瓶颈，但存在一个被忽视的低效问题。

**核心问题：**
- 在标准前缀验证机制中，草稿块一旦在某个 token 位置遭遇首次拒绝（first rejection），验证即终止，该位置之后的所有草稿后缀以及生成/验证这些位置所花费的全部计算资源被直接丢弃。
- 这引出一个自然的问题：**被拒绝的计算是否仍保留与目标延续相关的信息？这些信息能否被用于条件化下一轮草稿？**

**关键观察：**
- 以 DFlash（扩散式并行草稿模型）为研究对象，发现被拒绝的后缀中"被拒绝的位置"可能与目标后续的实际延续重新对齐。尽管存在局部的 token 级错误（如重复、遗漏），草稿模型仍可能保留有用的语义与结构方向（如图 1 的 MT-Bench 实例和第四节中的量化证明）。
- 基于此，作者提出一个核心命题：**被拒绝草稿轨迹不应被浪费，它可以条件化后续的草稿生成。**

### 2. 方法论：ReTrace

#### 2.1 核心思想
- 借鉴条件扩散（conditional diffusion）思想，构建一种**跨轮次（cross-round）信息流**机制：将上一轮验证中产生的"被拒绝后缀的隐藏状态"作为本轮草稿块的辅助条件输入，而非完全从空白的 mask 占位符重新生成。
- 方法面向 DFlash 设计，利用其并行生成整块草稿的特性——局部 token 错误不会在结构上使后续所有状态失效。相比之下，EAGLE 风格的自回归草稿器中早期错误会通过条件化上下文传播污染所有下游状态。

#### 2.2 方法流程

**（1）构建与对齐被拒后缀（Rejected-Trajectory Construction & Alignment）**

- 第 \(t\) 轮草稿块产生隐藏表示集合 \(\{h^D_{t,1}, \ldots, h^D_{t,B}\}\)。
- 假设接受长度为 \(A_t < B\)，首个被拒位置为 \(r_t = A_t + 1\)。
- **排除**已接受的表示 \(h^D_{t,1:A_t}\)（该部分 token 已进入上下文）和首个被拒位置的表示 \(h^D_{t,r_t}\)（该位置已由目标模型的校正 token 解决）。
- **保留**严格位于首个被拒位置之后的表示：\(\{h^D_{t,r_t+1}, \ldots, h^D_{t,B}\}\)。
- 将保留的隐藏状态序列按原始顺序**对齐到下一轮草稿块的开头位置**（式 5），若长度不足则补零，以匹配位置语义。

**（2）目标感知校正（Target-Aware Correction）**

- 利用验证阶段已生成的目标端表示对对齐后的草稿状态进行精化（无需额外前传）：
  - \(m_{t+1,j}\)：对齐的被拒草稿状态。
  - \(u_{t+1,j}\)：对应位置的目标模型表示，即在验证中预测位置 \(r_t + j\) token 的目标端状态 \(h^T_{t,r_t+j-1}\)（式 6）。
- 通过可学习投影 \(W_c\) 计算校正增量（式 7）：
  \[
  c_{t+1,j} = W_c[m_{t+1,j}; u_{t+1,j}]
  \]
- 校正后的轨迹以残差形式给出（式 8）：
  \[
  r_{t+1,j} = m_{t+1,j} + \beta c_{t+1,j}
  \]
  - \(\beta\) 为控制校正强度的系数，训练初期线性升温以稳定优化，推理时使用完全激活值（\(\beta = 1\)）。

**（3）门控残差融合（Gated Residual Conditioning）**

- 条件信号不替代当前 mask 输入，而是通过**向量级门控残差连接**注入（式 9）：
  \[
  \tilde{e}_{t+1,j} = e_{t+1,j} + W_v r_{t+1,j} \odot \sigma(W_g[e_{t+1,j}; r_{t+1,j}])
  \]
  - \(\odot\) 为逐元素乘，\(\sigma\) 为 sigmoid，实现逐维度的门控信息筛选。
  - \(W_v\) 零初始化，使初始状态精确复现原始 DFlash 行为，逐步学习何时采纳条件信号。
- 无对齐信号的锚点位置保持原输入不变。

#### 2.3 优化与推理特性
- **训练**：仅使用当前轮的预测损失联合优化草稿骨干、校正模块和门控融合模块；目标模型冻结；跨轮次复用的表示被截断（detached），防止梯度跨轮传播。
- **推理**：所有条件信号均来自标准草稿与验证过程的既有产物，**不增加任何额外模型前传**；目标模型的验证规则与 token 提交流程完全不变，保持解码结果的**无损性**。
- 条件信号仅在**一轮**内有效，被拒绝的 token 永远不会被提交。

### 6. 主要结论与发现

**（1）被拒轨迹中的信息保留性（可复用性）：**
- 约 **30.4%** 的目标 token 在草稿分布中仍是 top-1 预测，**75.2%** 位于 top-5 内——拒绝后缀保留粗粒度的 token 级预测信号。
- 被拒草稿状态与其同序列的真实目标延续之间的余弦相似度（平均 0.351）显著高于随机窗口基线（0.128），证明其保留延续特异的表示级信号，但绝对相似度中等，不适合直接接受。

**（2）ReTrace 带来的性能提升：**
- 跨所有模型规模与温度配置，ReTrace 在 DFlash 骨干上实现**平均接受长度提升约 6.97%**、**端到端加速比提升约 5.34%**（宏观平均）。
- 性能提升在每个基准上均一致，且不伴随任何额外目标模型前传。附加条件化开销仅约 **0.13 毫秒/循环**，占 DFlash 循环总延迟的 **0.40%**。
- 与 Domino 叠加后，宏观平均吞吐量从 287.17 提升到 301.39 tok/s，进一步证实了**正交性与可组合性**。

**（3）核心主张：**
- 被拒绝的草稿计算不必浪费——它可以条件化后续草稿，同时保持投机解码的无损性。

### 7. 方法的优点与亮点

**（1）视角创新性：**
- 重新审视投机解码中被直接丢弃的"废料"，将其转化为有价值的条件信号，提出了从"计算浪费"到"信息复用"的新问题框架，为后续研究开辟了新方向。

**（2）方法与机制设计务实且优雅：**
- 充分利用已有草稿/验证过程中已产生的表示，将新的条件化路径设计为与现有流程正交的模块，**不增加额外模型前传**且不修改目标侧验证逻辑，保持了**无损性**。
- 门控残差融合 + \(W_v\) 零初始化使模块以 DFlash 原始行为为起点平滑接入训练，兼顾优化稳定性与信息选择性。

**（3）理论分析扎实：**
- 通过 token 级（式 1）与表示级（式 2）双探针实验，定量刻画被拒后缀的可复用程度，以对照随机基线的差值（gap）证明不是隐藏空间的朴素相似，而是延续特异的预测信号，论证链条完整、可复现。
- 选择 DFlash 而非 EAGLE 作为条件化对象，并在方法动机中给出了清晰的理由（并行块生成 vs 自回归级联错误、单条深层块 vs 多条浅层分支树），设计选择有据可依。

**（4）实验严谨性：**
- SFT 对照实验有效剔除"更多训练带来增益"的替代解释。
- 消融实验通过逐步添加组件（原始覆盖 → 门控 → 目标感知校正），清晰分离了每个模块的边际贡献。
- 运行时微基准和并发服务实验进一步验证了实际部署的可行性。

- 评估样本量分配不均：AIME25 仅 30 题、MT-Bench 仅 80 题，而 LCB 和 Alpaca 限定了 128 个 prompt，虽然与常用社区基准实践一致，但客观上也存在测试不确定性较大的风险。
- 训练数据来源为 **Open-PerfectBlend**，该指令混合分布是否充分覆盖测试基准的分布特征并未进行核验。有一定分布偏移的领域（如长代码推理或工具调用场景）尚未纳入考察。
- 所有实验均**禁用思考模式**，对启用了 reasoning 的 Qwen3 工作流可能带来适配差异。虽然附录并发实验使用了 no-think 设定，符合一定部署事实，但现实中有大量应用依赖思考模式。

**（4）理论与效率的边界问题：**
- 条件信号仅跨越**一轮**有效，且当块被完整接受或首个被拒位置位于块末时，ReTrace 自动退化到原始行为。尚未探讨条件信号的持久化记忆是否可带来更大增益，也没有后续实验分析不同长度/不同代表性条件下该退化现象的发生频率。
- 额外训练成本（32 卡 A800 + 40K 样本、8 epochs）未在总拥有成本视角下与端到端加速收益做对比定量分析，实际部署时存在成本—收益的权衡考量。

### 9. 总体评价

ReTrace 针对投机解码中“被拒绝轨迹未被复用”的固有浪费，提出了一个概念简单、工程巧妙的解决方案。它通过将拒绝后缀的隐藏状态作为跨轮次条件信号，并辅以目标感知校正与门控残差融合，在不增加目标模型前传、不破坏投机解码无损性的前提下，稳定提升了 DFlash 草稿模型的平均接受长度与端到端加速比。论文的实验设计与分析较为扎实，特别是通过 SFT 对照、组件消融与运行时微基准，较为完整地验证了增益来源与计算开销，总体结论可信。

与此同时，方法的验证范围仍集中于 Qwen3/DFlash 这一特定技术栈，其泛化边界、训练成本权衡以及基于推理的部署适用性仍需后续工作进一步探索。ReTrace 所提出的“被拒绝计算也携带有用信号”这一视角，具有启发意义，可为未来投机解码与自回归加速研究提供新的设计空间。
