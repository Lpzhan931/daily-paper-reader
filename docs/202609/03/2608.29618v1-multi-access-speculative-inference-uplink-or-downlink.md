## 摘要
多接入推测推理（Multi-SPIN）将SPIN扩展至多设备边缘网络，以加速协作式令牌生成。它允许设备端小语言模型（SLMs）针对各个生成任务自回归地草拟多个令牌，而边缘服务器上的大语言模型（LLM）并行验证这些令牌。当草拟令牌被服务器拒绝时，会产生主要通信开销；此时采样校正令牌需要同时访问SLM输出的草稿分布和LLM输出的针对完整词表的目标分布。现有设计通常通过上传草稿分布在服务器端进行校正，但传输整个词表的分布会形成严重的上行链路（UL）瓶颈。另一种方式是利用下行链路（DL）可用的高传输速率，通过下载目标分布，在设备端进行校正。基于这一认识，我们将通信模式选择引入为Multi-SPIN的一个新设计维度。具体而言，每个设备可在UL与DL模式间自适应切换，以平衡UL瓶颈与共享DL资源约束，从而减轻整体通信负担。我们构建了一个联合考虑模式选择、草稿长度控制和功率分配的累计令牌有效吞吐量最大化问题。对于模式选择，我们揭示了一种简单的最优结构，可对UL设备数量进行高效搜索，并相应优化发射功率。对于草稿长度控制，我们开发了一种贪心搜索算法，可根据异构计算与通信能力自适应调整设备特定的草稿长度。在Qwen2.5与DeepSeek-R1模型对上的实验结果表明，所提出的框架显著提升了令牌有效吞吐量。

## Abstract
Multi-access speculative inference (Multi-SPIN) extends SPIN to multi-device edge networks to accelerate cooperative token generation. It allows on-device small language models (SLMs) to autoregressively draft multiple tokens for individual generation tasks, while an edge-server large language model (LLM) verifies them in parallel. The major communication overhead arises when a drafted token is rejected by the server, in which case sampling the correction token requires access to both the SLM-output draft distribution and the LLM-output target distribution over the full token vocabulary. Existing designs typically perform correction at the server by uploading the draft distribution, but transmitting a vocabulary-wide distribution creates a critical uplink (UL) bottleneck. Alternatively, the correction can be performed at the device by downloading the target distribution, leveraging the high transmission rates available on the downlink (DL). Motivated by this insight, we introduce communication-mode selection as a new design dimension for Multi-SPIN. Specifically, each device can adaptively switch between the UL and DL modes to balance the UL bottleneck against the shared DL resource constraint, thereby relieving the overall communication burden. We formulate a sum-token-goodput maximization problem that jointly accounts for mode selection, draft-length control, and power allocation. For mode selection, we reveal a simple optimal structure that enables efficient search over the number of UL devices, with the corresponding transmit powers optimized accordingly. For draft-length control, we develop a greedy-search algorithm that adapts device-specific draft lengths to heterogeneous computation and communication capabilities. Experimental results on Qwen2.5 and DeepSeek-R1 model pairs demonstrate that the proposed framework significantly improves token goodput.

### 1. 核心问题与整体含义（研究动机与背景）

- **研究背景**：将大语言模型（LLM）部署在无线网络边缘，可在靠近用户处执行推理，以支持低时延、隐私保护的 AI 服务。然而，直接在设备上运行大模型面临算力、内存和能耗约束；完全依赖服务器则会形成集中式推理瓶颈。推测推理（Speculative Inference, SPIN）通过设备端轻量级 SLM 先草拟（draft）多个 token，再由服务器端 LLM 并行验证（verify），以较少的前向传播次数实现 LLM 级推理质量。
- **核心挑战**：当某个草拟 token 被拒绝时，需要从残差分布中采样校正 token，这要求同时获得 SLM 草稿分布与 LLM 目标分布的完整词表级信息。词表规模通常达数十万（如 Qwen2.5 为 152,064 项），传输该高维分布会带来显著的通信开销。
- **关键洞察**：
  - 传统现有方案均采用"上行"（Uplink，UL）模式：设备上传草稿分布至服务器完成校正，造成 UL 瓶颈。
  - 另一种方式是"下行"（Downlink，DL）模式：服务器下载目标分布至设备，由设备端完成校正，利用 DL 更高的传输速率绕过 UL 瓶颈。
  - 在多设备系统中，DL 优势并非无条件成立：若所有设备均选择 DL 模式，将严重争抢共享 DL 资源。因此，需要自适应 UL/DL 模式选择作为新设计维度。
- **研究意义**：将通信模式选择引入 Multi-SPIN，将资源利用的核心哲学从计算域拓展至通信域——如同草拟生成分布到设备挖掘分布式算力，模式选择通过将部分传输负载转移至 UL 来缓解共享 DL 瓶颈，从而提升端到端 token 生成效率。

### 2. 方法论：核心思想、关键技术细节与算法流程

#### 2.1 总体框架

- 提出**基于模式选择的 Multi-SPIN 协议**，支持 20 个设备同时与边缘服务器协作完成各自的 token 生成任务。
- 整体为**两阶段随机优化问题**：每轮开始前（验证结果未知），服务器前瞻式确定各设备的草稿长度 γ_k；验证结果揭晓后，针对被拒设备反应式选择通信模式与发射功率。
- 优化目标为最大化**期望累计 token 有效吞吐量（sum-token-goodput）**，定义为每轮期望输出 token 数除以期望轮延迟。

#### 2.2 问题建模

- **协议流程**（每次生成轮）：
  1. 设备端 SLM 自回归草拟 γ_k 个 token；
  2. 设备上传草拟 token 及其标量草稿概率（轻量开销）；
  3. 服务器端 LLM 对多设备草稿块进行批量并行验证；
  4. 全部接受时：服务器采样 bonus token 并下发；
  5. 存在拒绝时：被拒设备进入校正流程，可选择 UL 模式（上传草稿分布）或 DL 模式（下载目标分布）。
  
- **关键时延模型**：
  - 计算时延：T_comp(γ) = max_k {γ_k · T_k^dft} + T_ver^0 + K · T_ver^1
  - 通信时延：由被拒设备中传输分布最慢者决定 T_comm(A;o) = max_{k∈R(o)} T_k^comm(m_k, p_k)
  - 每轮总时延：T(γ,A;o) = T_comp(γ) + T_comm(A;o)
  
- **期望输出 token 数**：假设各草拟 token 接受事件之间 i.i.d.，接受概率为 α_k，则
  L̄(γ) = Σ_k (1 − α_k^{γ_k+1}) / (1 − α_k)

- **优化问题分解**：由于期望输出数与计算时延独立于反应式策略，原问题可无损分解为：
  1. **反应式模式选择与功率分配子问题**：最小化期望通信时延（对每种验证结果独立求解）；
  2. **前瞻式草稿长度控制子问题**：在最优反应式策略基础上最大化 goodput。

#### 2.3 反应式模式选择与功率分配：最优解

- **固定模式下的最优功率分配（Lemma 1）**：
  - UL 模式设备：采用最大功率发射（最优）。
  - DL 模式设备：最优分配满足"最大时延均衡"结构，闭式解 p_k^* = (N_0,k^dev B_k / |h_k|²) · (2^{V_eff(⌈log₂V⌉+Q)/(B_k·τ_dl)} − 1)，其中 τ_dl 为总功率约束下 DL 功率方程的唯一解，可通过二分搜索求得。

- **最优模式选择的前缀结构（Lemma 2）**：
  - 将被拒设备按最小 UL 时延升序排序后，存在一个最优模式指派具有前缀结构：UL 时延较小的前 n 个设备用 UL 模式，其余用 DL 模式。
  - 此结论通过交换论证证明：若存在 i < j 但 i 在 DL、j 在 UL，交换 i 到 UL 同时将 i 移出 DL，UL 与 DL 时延均不会增加。

- **一维二分搜索（Proposition 1）**：
  - 定义 UL-DL 时延差 Δτ(n) = τ_dl(n) − τ_ul(n)，因 τ_ul(n) 随 n 非减、τ_dl(n) 随 n 非增，Δτ(n) 单调非增。
  - 最优分割点 n* 只需比较 Δτ 首次变号附近的候选值 n̄−1 与 n̄，即 n* = arg min{τ(n̄−1), τ(n̄)}，n̄ 可通过二分搜索获得。
  - 该搜索**隐式耦合最优功率分配**：每次求值 DL 时延均调用 Lemma 1 解功率分配，因此模式选择与功率分配是联合最优而非分离优化。

#### 2.4 前瞻式草稿长度控制：贪心算法

- **两阶段贪心搜索（Algorithm 1）**：
  1. **同步全一更新**：从 γ = 0 出发，持续尝试 γ ← γ + 1，只要 goodput 改善就接受，直至收敛。
  2. **坐标贪心细化**：对每个单独维度尝试 γ_k ← γ_k + 1，选取 goodput 增益最大的设备更新，直至无增益。

- **SAA（样本平均近似）评估期望**：
  - 直接枚举验证结果需要指数级复杂度（2^K 种），且 T_comm^min(o) 无闭式解。
  - 采用蒙特卡洛采样：按 Pr(o|γ) = Π_k (α_k^{γ_k})^{1−o_k}(1−α_k^{γ_k})^{o_k} 抽取 N_SAA = 1000 个验证结果样本，以样本均值近似期望最小通信时延。
  - 由大数定律保证估计的一致性。

### 6. 主要结论与发现

1. **自适应 UL/DL 模式选择可有效提升 goodput**：固定 UL 与固定 DL 策略均非普遍最优；当 DL 功率受限时，将所有被拒设备分配至 DL 会造成严重竞争，而自适应方案通过将合适子集分配到 UL 避免此问题；DL 功率充足时，自适应方案仍优于全 DL，尤其当设备数增加、DL 竞争加剧时优势更明显。
2. **草稿长度应随通信条件自适应调整**：DL 功率预算增大时，通信惩罚降低，最优草稿长度随之增长，以更充分利用并行验证增益。
3. **考虑通信时延的草稿长度优化优于仅计算优化的方案**：忽略通信时延会显著高估短草稿或低估长草稿的代价。
4. **设备异构性需要非统一草稿长度**：优于最优统一草稿长度方案说明按设备计算/通信能力个性化草稿长度有实际增益。

### 7. 方法亮点

- **新的设计维度**：将"通信方向"（UL vs DL）从物理层固定属性提升为可优化的系统级决策——在 Multi-SPIN 中，信息源、信息宿和传输方向不再被预先锁定，而是随系统条件自适应，这改变了对无线通信在边缘推理中角色的传统认识。
- **精巧的理论结构揭示**：
  - 证明最优模式指派具有前缀结构（Lemma 2），将组合优化降低为一维二分搜索，获得低复杂度全局最优解；
  - 最优 DL 功率分配具备闭式"时延均衡"形式（Lemma 1），并被嵌入模式搜索中实现联合优化；
  - 利用 τ_ul(n) 非减、τ_dl(n) 非增的单调结构设计二分搜索，结果保证全局最优而非启发式。
- **前瞻-反应式两阶段分解**：利用决策时序结构（验证前 vs 验证后）将随机混合整数问题无损拆分为递进的两个子问题，兼顾实际可实现性与理论最优性。
- **快速通信开销分析**：正确识别 token 修正为唯一的大体量通信瓶颈，其余步骤开销可忽略，突显问题核心。
- 贪心草稿长度控制配合 SAA 评估，规避指数级枚举，兼顾多种系统维度的耦合。

### 8. 不足与局限

- **假设简化**：
  - 假设各 token 接受事件为 i.i.d.，实际中接受率随上下文变化，逐位置条件概率差异未被建模；
  - 假设带宽分配为给定输入而非联合优化变量（文中明确指出"为简化视带宽分配为给定"），完整系统优化空间未被穷尽；
  - 假设信道系数在轮内恒定且服务器在草稿长度决策前已知，部分实际场景下信道估计开销与误差未纳入；
  - 通信时延建模中隐含假设已对 token 分布做了截断/稀疏化（V_eff），对尾部

概率质量造成的近似误差及对校正采样的影响未深入分析；
- 论文假设无线链路传输无误码，未考虑数据包重传、拥塞控制、信道估计误差等非理想因素，实际部署时需要额外的协议开销与鲁棒性设计；
- 目标函数完全聚焦于时延与吞吐量，未显式计入设备端与服务器端的能耗、发热与电池寿命约束，长时间运行场景下可能需要能量-时延折中；
- 所提模式选择与草稿长度控制依赖服务器对设备信道状态、计算能力、任务类型及接受率的实时估计，当这些参数存在偏差或过时时，算法的敏感性未作分析；
- 草稿长度贪心算法配合 SAA 只能得到近似最优解，文中未给出与最优解的差距上界，也未分析 SAA 样本数收敛的理论保证；
- 实验验证为纯仿真，信道采用统计衰落模型，缺乏在真实无线平台、实际部署协议栈及多用户并发场景下的端到端原型验证；
- 模型对仅覆盖 Qwen2.5 与 DeepSeek-R1 两个系列，未讨论词表大小、模型架构差异、投机采样风格改变（如动态草稿树）等对通信开销与最优策略的影响；
- 对比基准中未包括当前主流的 UL 端分布压缩/量化/剪枝方案，也未结合多用户分集、协作传输、边缘缓存等新兴机制，因此无法判断所提方案相对更广阔设计空间的绝对收益。

### 9. 未来研究方向

- **联合优化带宽分配**：当前模型将带宽分配视为固定输入，未来可将子载波/带宽分配与模式选择、草稿长度控制纳入统一优化问题，进一步挖掘频谱资源调度的增益。
- **推广至多服务器与多小区场景**：当多个边缘服务器协作或小区间存在干扰时，需要设计分布式或低信令开销的调度策略，并考虑用户切换与任务迁移。
- **更细粒度的接受率建模**：突破 i.i.d. token 假设，引入基于上下文或位置的条件接受率模型，并研究其对草稿长度与模式选择结构的影响。
- **面向非理想链路的鲁棒设计**：将传输错误、重传时延、有限的反馈信道与信道估计误差显式建模，设计在动态信道环境下依然自适应可靠的协议。
- **真实系统原型验证**：在软件定义无线电、移动端 NPU 及边缘 GPU 服务器上搭建端到端测试平台，测量实际吞吐量、能耗与延迟，验证理论算法的实用价值。
- **结合分布压缩或广播机制**：将 UL 上的词表分布压缩、排序截断、神经网络编码器与 DL 上的共享广播、多播结合，探索混合通信方式下的更大收益空间。
- **考虑能量感知与绿色目标**：将设备电量、发射功率能量消耗、服务器计算能耗纳入优化，形成通信-计算-能量三维折中的资源管理框架。

### 10. 总结

本文系统研究无线边缘多设备推测推理中的“通信方向”决策问题，提出自适应 UL/DL 模式选择与草稿长度联合优化框架。理论方面，利用最优模式指派的单调结构将难解的组合问题降为一维搜索，并得到功率分配的闭式解；算法方面，设计两阶段贪心与 SAA 结合的低复杂度方案。仿真验证显示，所提方法能显著提升 token 有效吞吐量，尤其 DL 资源竞争激烈或设备异构性明显时增益突出。为无线边缘智能推理的资源分配提供了新颖且有效的设计范式，同时也为后续在通信-计算深度耦合方向上的研究奠定了良好基础。
