## 摘要
扩散大语言模型（dLLM）近来作为一种有前景的自回归LLM替代方案出现，能够实现非自回归文本生成。然而，其实际部署仍受限于低效推理，这在很大程度上源于缺乏有效的键值（KV）缓存和可扩展的并行解码机制。现有加速方法通常孤立地研究KV缓存与并行解码，忽略了在缓存复用与并行token验证联合应用时出现的I/O瓶颈。在这项工作中，我们提出了Flash-dLLM，一个免训练的推理加速框架，用于实现快速且内存高效的dLLM。Flash-dLLM首先将GPU内存I/O识别为启用KV缓存的dLLM推理中的主要瓶颈，并通过一种I/O感知的融合KV缓存内核来减少冗余内存搬运。基于这一优化后的缓存机制，Flash-dLLM进一步提出了一种高效的KV缓存驱动的草稿-验证解码策略，其中dLLM自身同时充当草稿生成器和验证器，无需辅助模型。这种统一设计能够在保持生成质量的同时实现更快的解码，并提升对更长序列和更大批量大小的可扩展性。在数学推理和代码生成基准上的大量实验表明，Flash-dLLM在推理速度和内存效率上均持续优于现有最先进的dLLM加速方法。具体而言，在GSM8K和HumanEval上，它相比此前最强基线Elastic-Cache分别实现了5.1倍和11.0倍的加速。

## Abstract
Diffusion Large Language Models (dLLMs) have recently emerged as a promising alternative to autoregressive LLMs by enabling non-autoregressive text generation. However, their practical deployment remains limited by inefficient inference, largely due to the absence of effective Key-Value (KV) caching and scalable parallel decoding mechanisms. Existing acceleration methods typically study KV caching and parallel decoding in isolation, overlooking the I/O bottlenecks that arise when cache reuse and parallel token verification are jointly applied. In this work, we introduce $\textbf{Flash-dLLM}$, a training-free inference acceleration framework for fast and memory-efficient dLLMs. Flash-dLLM first identifies GPU memory I/O as a dominant bottleneck in KV-cache-enabled dLLM inference and addresses it with an I/O-aware fused KV-cache kernel that reduces redundant memory movement. Building on this optimized cache mechanism, Flash-dLLM further proposes an efficient KV-cache-driven draft-and-verify decoding strategy, where the dLLM itself serves as both drafter and verifier without requiring an auxiliary model. This unified design enables faster decoding while preserving generation quality and improving scalability to longer sequences and larger batch size. Extensive experiments on mathematical reasoning and code-generation benchmarks demonstrate that Flash-dLLM consistently outperforms existing state-of-the-art dLLM acceleration methods in both inference speed and memory efficiency. In particular, it achieves $5.1\times$ and $11.0\times$ speedups over prior strongest baseline Elastic-Cache on GSM8K and HumanEval, respectively.

## 2. 方法论

### 2.1 核心思想
- 免训练、无需辅助模型：通过 **Flash-Cache**（I/O 感知 KV 缓存）与 **Flash-Verify**（KV 缓存驱动的草稿-验证并行解码）两大组件协同，让 dLLM 自身同时充当草稿器与验证器。

### 2.2 Flash-Cache：I/O 感知 KV 缓存
包含三个组件：

- **（i）KV 缓存融合内核**
  - 传统实现每层启动 4 个独立 CUDA 内核（QKV 投影、RoPE、缓存写入、注意力），每个内核输出先写入 HBM 再被下一内核读取；每层 HBM 流量约 `4×O(Q·d_model) + O(N·d)`，非注意力操作算术强度低，使缓存更新路径内存受限。
  - 受 Flash Attention 启发，将 **QKV 投影 + RoPE + 缓存写入** 融合为单一内核：在 SRAM 中完成投影与 RoPE，直接将 K/V 写入 KV 缓存，**消除中间键值物化**，降低 HBM 流量与显存占用。在 RTX 3090 上取得 **1.37× 加速**。

- **（ii）调度式 Flash Attention（Scheduled Flash Attention）**
  - 针对批内序列长度动态发散问题（缓存阶段仅计算小窗口，更新阶段重算全序列，同批样本计算需求差异大）。
  - 扩展 Flash Attention：将每批划分为多个序列块，用**块表（block table）**将查询块与其对应的 KV 块对齐调度，缓解长度差异、支持灵活增删块，便于自适应决定何时缓存或更新。与传统 Flash Attention 优化注意力内部 I/O 不同，本方案**控制计算哪些块及顺序**。

- **（iii）选择性缓存更新（Selective Cache Update）**
  - 仅维护并更新一组固定的**最受关注 token（跟踪预算 βt）**。
  - 查询集定义：`Q_{t+1} = M_{t+1}[βm] ∪ T_{t+1}`，其中 `T_{t+1}` 由新解码 token `Dt` 与上一步最受关注 token 组成。
  - 注意力得分（式 2）：`a_i^t = Σ_{l=1}^L (1/H) Σ_{h=1}^H (1/|M_t^βm|) Σ_{j∈M_t^βm} S_{j,i}^{t,l,h}`，衡量当前掩码查询对已解码位置 i 的关注程度。
  - 跟踪集：`T_{t+1} = top-k({a_i^t : i ∈ D_<t}, βt − |Dt|) ∪ Dt`；新解码 token 自动纳入。其余已解码位置由缓存提供、不作为查询，**每步计算量被限制在 βt + βm**。

### 2.3 Flash-Verify：KV 缓存驱动的草稿-验证并行解码
- **动机**：置信度感知解码只接受置信度 `ci ≥ ϵ` 的 token，丢弃大量本可正确的预测，造成吞吐上限。
- **草稿阶段（Draft Pass）**：在 `Qt = Tt ∪ M_t^βm` 上以全 KV 缓存运行模型；按置信度排序，分为**置信集 Dt**（≥ϵ，直接接受）与**搜索集 St**（<ϵ，待验证）。
- **验证阶段（Verify Pass）**：构造包含三组的新查询——
  - 调整后的跟踪集 `Tv`（先前已解码 token + Dt）；
  - 搜索位置 `St` 填入草稿预测 `x̂i`（**草稿视图**）；
  - 同一位置填入 `[MASK]`（**掩码视图**）。
