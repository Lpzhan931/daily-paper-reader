## 摘要
投机解码对于加速 LLM 推理至关重要。然而，这种加速很脆弱：草稿模型通常针对单个目标模型在狭窄分布上训练，其接受率在工作负载变化时会骤降。这与现代 LLM 开发形成了鲜明反差：目标模型的价值恰恰在于其通过大规模预训练获得的广泛泛化能力。我们认为，自然的补救措施——预训练——一直难以应用于草稿模型，因为现有方案都针对特定目标：草稿模型会消费目标的隐藏状态，并基于目标的 logits 进行蒸馏，因此必须为每个目标重复预训练。我们提出 Osprey，它转而从现成的预训练小型语言模型引导构建草稿模型，将广泛的预训练视为可复用、与目标无关的资产，并将每个目标的工作缩减为轻量级适配步骤。实现这一点需要克服两个挑战：小型语言模型远比受延迟约束的草稿模型所能承受的深得多，并且草稿模型在学习接收目标隐藏状态并以目标词表生成 token 时，其预训练计算必须保持完整。Osprey 通过以下方式同时解决这两个问题：剪枝得到浅层骨干，用目标无关的下一 token 预训练恢复其语言建模能力，并通过词表对齐、零初始化 QKV 扩展以及从目标模型输出分布中蒸馏，使其适配到每个目标。实证上，单个预训练的 Osprey 骨干可以跨目标迁移，并将平均接受长度分别提升 16.1%（Qwen3-8B）、21.2%（Llama-3.3-70B-Instruct）和 22.7%（229B MiniMax-M2.5，同时每秒 token 数提高 17.5%），在域外和多语言数据上提升最大。我们的代码见 https://github.com/LeanModels/Osprey。

## Abstract
Speculative decoding is critical for accelerating LLM inference. However, the speedup is fragile: drafters are typically trained against a narrow distribution for a single target model, and their acceptance rate collapses under workload shifts. This is a striking inversion of modern LLM development, where target models are valued precisely for the broad generalization they acquire through large-scale pretraining. We argue that the natural remedy, pretraining, has been hard to apply to drafters because existing recipes are target-specific: the drafter consumes the target's hidden states and is distilled on the target's logits, so pretraining must be repeated for each target. We introduce Osprey, which instead bootstraps drafters from off-the-shelf pretrained small language models, treating broad pretraining as a reusable, target-agnostic asset and reducing per-target work to a lightweight adaptation step. Realizing this requires overcoming two challenges: small LMs are far deeper than a latency-bound drafter can afford, and their pretrained computation must remain intact while the drafter learns to ingest target hidden states and emit tokens in the target's vocabulary. Osprey addresses both by pruning to a shallow backbone, restoring its language-modeling capability with target-agnostic next-token pretraining, and adapting it to each target through vocabulary alignment, zero-initialized QKV expansion, and distillation from the target model's output distribution. Empirically, a single pretrained Osprey backbone transfers across targets and improves mean acceptance length by 16.1% for Qwen3-8B, 21.2% for Llama-3.3-70B-Instruct, and 22.7% for the 229B MiniMax-M2.5 (with 17.5% higher tokens per second), with the largest gains on out-of-domain and multilingual data. Our code is available at https://github.com/LeanModels/Osprey.

## 1. 核心问题与研究动机

- **背景**：投机解码（Speculative Decoding）是加速 LLM 推理的关键技术——轻量草稿模型（drafter）提出 K 个候选 token，大目标模型并行验证，被接受的 token 严格服从目标分布，因此兼具加速与无损性，常见 2–5× 解码加速。
- **核心痛点——加速的"脆弱性"**：草稿模型通常针对**单一目标模型、单一数据分布/领域**训练。一旦服务负载发生迁移（chat→code、通用 QA→领域推理、短答→长文本），草稿预测与目标模型失配，接受率骤降，加速收益随之崩塌。
- **实证证据**：论文图 2 显示，在 math 上训练的 EAGLE-3 在 math 数据上平均接受长度（AL）为 5.06，但在 code 数据上仅 1.86。
- **理论反差**：目标模型因大规模预训练而具备广泛泛化能力（域迁移不再是前沿 LLM 的主要叙事），但加速它们的草稿模型却依然狭窄脆弱——投机解码"继承了小模型的延迟优势，却没有继承大模型的泛化优势"。
- **为何预训练难以直接套用**：现有草稿训练配方（EAGLE 系列等）本质是**目标特定**的——草稿消费目标的隐藏状态、在目标的表示空间与 logits 上蒸馏，换一个目标就要重跑一整条昂贵训练管线，且仍不直接继承已有预训练语言模型的泛化能力。
- **论文主张**：把现成预训练小语言模型（SLM）作为**可复用、目标无关的资产**，用一次通用预训练产出可跨目标复用的浅层骨干，把每个目标的开销压缩为轻量适配。
- **两大技术挑战**：① SLM 通常 16 层以上，而受延迟约束的草稿必须足够浅；② 草稿在学习"吃入目标隐藏状态、输出目标词表 token"的同时，必须不破坏预训练已有的计算能力。

## 2. 方法论

### 2.1 核心思想

- 四阶段流水线，分为**目标无关阶段（只做一次）**与**逐目标阶段（每个目标重复）**：剪枝 → 目标无关预训练 → 目标适配（转换） → 蒸馏。
- 符号：目标模型 $p_\theta$（冻结），草稿 $q_\phi$；源模型可与目标不同族、不同 tokenizer。**验证流程本身不做任何修改**。

### 2.2 Stage 1：剪枝（Pruning）

- 从 L 层源语言模型仅保留**前 N 层 Transformer + 输入 embedding + 最终归一化 + LM head**，$N \in \{1,2,3,4\}$，因草稿自回归执行，深度直接决定延迟。
- 实例：Qwen3-4B 保留 2 层 ≈ 591M 参数；layerskip-llama3.2-1B 保留 4 层 ≈ 506M 参数。
- 有意选用 LayerSkip 等**带早退目标训练过**的模型作为初始化，因为中间层已被显式训练为下一 token 预测器（初始 loss 约 4.5 nats vs 普通截断的约 13.5 nats）。

### 2.3 Stage 2：目标无关预训练（Pretraining）

- 对浅层骨干做标准**下一 token 预测（NTP）**继续预训练；实验用 FineWeb 100B token 采样、5 个 epoch ≈ 500B token（另一处表述为 55k 步 ≈ 462B token）。
- 故意**超出 compute-optimal 配比**（Hoffmann et al., 2022），目标是获得广泛训练的语言骨干而非最小化预训练成本。
- 产出物称为 **shallow NTP backbone**，完全与目标解耦，可跨目标复用。

### 2.4 Stage 3：草稿转换（Drafter Conversion）

三个组件，其余 MLP/归一化等预训练部件原样迁移：

- **多层目标隐藏状态**：仿 EAGLE-3，取目标低/中/高三层隐藏状态拼接后线性投影到草稿隐空间：
  $$c_t = W_c\,[\,h^{(\ell_{low})}_t;\ h^{(\ell_{mid})}_t;\ h^{(\ell_{high})}_t\,]$$
  该表示 $c_t$ 输入草稿**每一层注意力**。
- **零初始化 QKV 扩展**：起草时当前 token 的目标隐藏态尚未算出，故用 $c_{t-1}$。将 $c_{t-1}$ 与草稿原 token 侧表示 $z_t$ 拼接，并把预训练 QKV 投影扩宽出零初始化列：
  $$\widehat{W}_{qkv} = [\,0 \ \ W_{qkv}\,],\qquad \widehat{W}_{qkv}\begin{bmatrix}c_{t-1}\\ z_t\end{bmatrix} = W_{qkv} z_t$$
  即**初始化时目标特征对 Q/K/V 无任何影响**，注意力层保持目标无关的预训练行为；训练中这些列与其余权重一同更新，逐步学会利用目标隐藏态。
- **词表对齐**：把草稿 embedding 与 LM head 尺寸改为 $|V_T|$，并用**草稿自身预训练权重**（而非目标权重）初始化。共享 token 直接复制原行；目标独有 token 用源 tokenizer 对其字符串分词后取源行均值：
  $$\widehat{W}[v] = \begin{cases} W_S[v], & v \in V_S \\ \frac{1}{m_v}\sum_{i=1}^{m_v} W_S[s_i], & v \notin V_S \end{cases}$$
  该过程无需任何辅助语料。

### 2.5 Stage 4：目标适配（蒸馏）

- 采用 EAGLE-3 的 **Training-Time Test（TTT）** 框架：输入 token 为 teacher-forcing，但草稿的隐藏状态轨迹按自回归方式生成，与推理对齐；目标同时提供 logits（蒸馏目标）与隐藏态（草稿输入）。
