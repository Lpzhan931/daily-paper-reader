## 摘要
块扩散投机解码通过并行提出一个未来 token 块，并利用目标模型的一次前向传播对其进行验证，从而提升 LLM 推理效率。然而，现有方法仅保留被接受的前缀，丢弃被拒绝的后缀，使得花费在这些位置上的计算无法惠及后续起草轮次，并迫使起草器反复从头重建未来 token 的表示。我们观察到，拒绝仅决定所提出的 token 能否被提交，而被拒绝位置处的验证器表示仍可为后续预测提供有用信息。基于这一观察，我们提出 DFlow，一个简单而有效的框架，使验证器信息能够在起草轮次之间流动。DFlow 复用目标验证器针对被拒绝后缀产生的隐藏状态，以指导后续起草，而无需额外的目标模型计算。为了有效学习跨起草轮次的这种信息流，我们引入一种自条件训练策略，将来自较早预测的验证器表示反馈到后续预测中。在 Qwen3 模型上跨多个基准的实验表明，DFlow 在草稿质量和接受长度上始终优于 DFlash。

## Abstract
Block diffusion speculative decoding improves LLM inference efficiency by proposing a block of future tokens in parallel and verifying them with a single forward pass through the target model. However, existing methods retain only the accepted prefix and discard the rejected suffix, preventing the computation spent on these positions from benefiting subsequent drafting rounds and forcing the drafter to repeatedly reconstruct representations for future tokens from scratch. We observe that rejection only determines whether a proposed token can be committed, while the verifier representations at rejected positions can still provide useful information for subsequent predictions. Based on this observation, we propose DFlow, a simple yet effective framework that enables verifier information to flow across drafting rounds. DFlow reuses the hidden states produced by the target verifier for the rejected suffix to guide subsequent drafting without additional target computation. To effectively learn this information flow across drafting rounds, we introduce a self-condition train strategy that feeds verifier representations from earlier predictions back into subsequent predictions. Experiments on Qwen3 models across diverse benchmarks demonstrate that DFlow consistently improves draft quality and acceptance length over DFlash.

# DFlow 论文中文总结

## 1. 论文的核心问题与整体含义

- **研究背景**：大语言模型（LLM）自回归解码本质上是串行的，成为推理效率的主要瓶颈。投机解码通过轻量 drafter 提出多个未来 token，再由目标模型并行验证来缓解该瓶颈。其中**块扩散投机解码**（如 DFlash）能一次性并行预测整个未来 token 块，显著降低起草的串行开销。
- **核心问题**：现有块扩散投机解码方法在验证后**只保留被接受的前缀，丢弃被拒绝的后缀及其全部中间表示**，造成跨起草轮次之间的**信息不连续（information discontinuity）**。由于后续轮次的起草窗口常与被拒后缀位置重叠，这些位置被迫重新从 mask embedding 从头构建表示，导致此前验证阶段已花费的目标模型计算无法被复用。
- **关键观察**：拒绝只决定某个提议 token 能否被提交（离散提交决策），并不代表该位置的验证器隐藏状态（连续上下文表示）没有价值。被拒位置在验证过程中已参与目标模型的因果计算，其表示仍可能包含对未来预测有用的信息。
- **整体含义**：论文提出 DFlow，使验证器信息能够跨越起草轮次流动，在不增加目标模型前向计算的前提下提升草稿质量与接受长度，为块扩散投机解码提供了新的信息复用视角。

## 2. 论文提出的方法论

### 核心思想
- 复用目标验证器针对**被拒绝后缀**产生的隐藏状态，将其传递到下一轮起草中对应位置，作为辅助信息指导预测，而非每轮从 mask embedding 重新构建。

### 关键技术细节

- **验证器表示对齐（Verifier Representation Alignment）**：
  - 沿用 DFlash 的特征投影矩阵 $W_c$ 与 RMSNorm，将选定目标层在被拒后缀上的隐藏状态拼接投影，得到验证器表示 $h_i^{(r)}$。
  - 因目标模型做 next-token 预测（位置 $i$ 预测 $i+1$），而 drafter 做 mask 预测（位置 $i$ 预测 $i$），需对验证器表示做**位置偏移对齐**后再注入。
  - 由于验证阶段已产生所需隐藏状态，无需额外目标前向。

- **拒绝条件化起草初始化（Reject Conditioned Draft Initialization）**：
  - 验证时的被拒后缀上下文与下一轮（从 bonus token 继续）的上下文不同，故利用边界 token 差异（目标修正 token $b^{(r)}$ 与首个被拒提议 $\hat{y}_{a_r+1}^{(r)}$）结合 $h_i^{(r)}$，经轻量 MLP 生成通道级缩放与校正向量：
    $$[\beta_i^{(r)}; \gamma_i^{(r)}] = \mathrm{MLP}_\phi([E(b^{(r)}); E(\hat{y}_{a_r+1}^{(r)}); h_i^{(r)}])$$
  - 验证器表示经 LayerNorm 后按上述向量调制并加到标准 mask embedding 上：
    $$x_i^{(r+1)} = E_{\text{mask}} + \beta_i^{(r)} \odot \mathrm{LN}(h_i^{(r)}) + \gamma_i^{(r)}$$
  - 无可用验证信息（首轮或无被拒后缀）时退化为标准 mask embedding。

- **多轮自条件化训练（Multi-Round Self-Conditioned Training）**：
  - **多轮展开（Multi-Round Rollout）**：从目标轨迹采样 anchor，将原本单轮训练扩展为连续多轮起草—验证序列；首轮为标准 mask 预测，后续轮为 reject conditioned 预测，默认展开 $k=2$ 轮。
  - **目标轨迹转移（Target Trajectory Transition）**：通过将草稿提议与目标轨迹精确匹配确定下一轮起始位置（首个不匹配处的目标 token 作为 bonus token），使后续轮次与同一轨迹对齐，并复用已计算的目标上下文。
  - **损失函数**：$\mathcal{L}_{\text{DFlow}} = \mathcal{L}^{(0)} + \sum_{q=1}^{k} \mathcal{L}^{(q)}$，各轮损失求和后联合反向传播优化同一套 drafter 参数；目标模型冻结，验证器表示与轮次转移从计算图中分离。

- DFlow 在全部模型规模与任务类别上持续优于 DFlash。贪心解码下平均接受长度分别从 **3.56→3.93（1.7B）、3.71→4.20（4B）、3.66→4.15（8B）**，提升约 **10.4%、13.2%、13.4%**；采样解码下同样提升（2.99→3.26、3.15→3.54、3.10→3.45）。

## 7. 优点

- **视角新颖**：首次指出投机解码中的“信息不连续”问题，将被拒后缀的验证器表示从“废弃计算”重新定义为“可复用信号”，洞察清晰。
- **零额外目标计算**：复用验证阶段已产生的隐藏状态，不增加目标模型前向，额外开销仅 0.51 ms / 1.2%，性价比高。
