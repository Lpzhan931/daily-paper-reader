## 摘要
大型语言模型（LLM）在处理长上下文任务方面展现出强大能力，但由于巨大的内存需求和推理延迟，处理如此长的上下文仍然具有挑战性。在这项工作中，我们发现某些注意力头在其注意力模式中表现出序列一致性，这种一致性可以通过基于变异系数的算法持续识别。受此观察启发，我们提出了CateKV，一种混合KV缓存方法，该方法仅保留一致性头的关键令牌信息，从而减少KV缓存大小和计算开销，同时保留自适应头中的大部分KV对以确保高精度。我们展示了我们算法的独特特征及其与现有加速方法的扩展。在长上下文基准上的全面评估表明，在保持与全注意力相当的准确性的同时，CateKV在单样本输入中将内存使用减少高达$2.72\times$，解码速度提升$2.18\times$，并在批量场景中将吞吐量提升$3.96\times$。

## Abstract
Large language models (LLMs) have demonstrated strong capabilities in handling long-context tasks, but processing such long contexts remains challenging due to the substantial memory requirements and inference latency. In this work, we discover that certain attention heads exhibit sequential consistency in their attention patterns, which can be persistently identified using a coefficient-of-variation-based algorithm. Inspired by this observation, we propose CateKV, a hybrid KV cache method that retains only critical token information for consistent heads, thereby reducing KV cache size and computational overhead, while preserving the majority of KV pairs in adaptive heads to ensure high accuracy. We show the unique characteristics of our algorithm and its extension with existing acceleration methods. Comprehensive evaluations on long-context benchmarks show that, while maintaining accuracy comparable to full attention, CateKV reduces memory usage by up to $2.72\times$ and accelerates decoding by $2.18\times$ in single-sample inputs, and boosts throughput by $3.96\times$ in batch scenarios.

# CateKV 论文详细总结

## 1. 核心问题与整体含义（研究动机和背景）

- **问题背景**：大语言模型（LLM）在长上下文任务（如长文档问答、信息检索、仓库级代码理解）中表现出色，上下文窗口可达 128K 甚至 1M tokens。然而，随着上下文长度增长，自回归推理需要存储和读取全部 KV cache，导致**内存开销巨大、推理延迟显著增加**（例如 Llama-3-8B 从 1K 扩展到 1M tokens 时延迟增加超 3000 倍）。
- **现有方法局限**：
  - **KV cache 淘汰策略**（如 StreamingLLM、SnapKV、PyramidKV）：通过丢弃部分 KV 对减少缓存和计算，但可能误删关键信息，导致精度明显下降。
  - **KV cache 检索策略**（如 Quest、ShadowKV）：保留全部 KV 对、在解码时动态选择关键 token，精度好但**不缓解内存压力**，限制批量吞吐。
  - **头级稀疏化方法**（如 RazorAttention、DuoAttention、MInference）：识别不同注意力头的稀疏模式，但未充分利用预填充阶段与解码阶段之间的联动。
- **核心观察**：论文发现**某些注意力头在预填充阶段和解码阶段表现出“序列一致性”**（sequential consistency），即注意力始终集中在少数关键 token 上；而另一些头则表现出动态变化的注意力分布（自适应头）。基于该观察，可利用预填充阶段的经验指导解码阶段，在不损失精度的前提下压缩缓存。
- **整体思路**：提出 **CateKV**，一种**混合 KV cache 方法**——对“一致头”只保留关键 KV 对，对“自适应头”保留大部分 KV 对，从而降低内存和计算开销，同时维持与全注意力相当的精度。

## 2. 方法论：核心思想、关键技术细节、公式与算法流程

### 2.1 核心思想

- 将注意力头分为两类：
  - **一致头（Consistent head）**：注意力模式在预填充和解码阶段稳定，只关注少量关键 token，可大幅压缩缓存。
  - **自适应头（Adaptive head）**：注意力分布随解码步骤动态变化，需要保留大部分 KV 对以保证准确性。
- 使用**基于变异系数（Coefficient of Variation, CV）的算法**对头类型进行识别，并在预填充阶段完成关键 token 的筛选。

### 2.2 关键技术细节

#### （1）观测矩阵 A

- 仅使用输入末尾的 `L_obs` 个 query token（观测窗口）来估计注意力模式，避免计算全部注意力。
- 排除初始 token（长度 `L_init`）和最近 token（长度 `L_rec`），因为它们通常重要但不影响分类。
- 观测矩阵定义为：
  ```
  A = softmax( Q[-L_obs:, :] · K[L_init : -L_rec, :]^T / √d )
  ```
  其中 `A ∈ R^(L_obs × (n - L_rec - L_init))`。

#### （2）基于变异系数的打分

- 一致头的特征：观测矩阵各行高度相似，且少数列即可覆盖大部分注意力权重。
- 先对观测矩阵二值化（阈值取 k 分位数乘以缩放因子 α）：
  ```
  B = I(A ≥ Φ(k, α))
  ```
- 统计每个 token 被标记为关键的次数，得到频率向量 C：
  ```
  C = Σ_i B_{i, :}
  ```
- 变异系数得分：
  ```
  score = sqrt( (1/N) Σ_i (C_i - μ(C))² ) / μ(C)
  ```
  其中 `N = n - L_rec - L_init`，`μ(C)` 为均值。得分高的头判定为一致头。
- 对于 GQA 模型，观测矩阵取组内头的平均。

#### （3）头类型识别

- 对单样本可动态识别：设定自适应头比例 `r`，按得分分位数阈值 Γ(r) 划分：
  ```
  Head(i,j) = consistent head  if score > Γ(r)
             = adaptive head    otherwise
  ```
- **参考数据集静态识别**：论文发现同一头在不同样本上的分类结果高度一致（重叠率 >80%），因此可用参考数据集（基于 RULER 的 Variable Tracking 任务构建，100 个 128K 样本）确定每层的头类型，推理时直接复用，避免动态识别的内存管理开销。

#### （4）缓存策略（Algorithm 1）

- 预填充阶段：
  - 计算 token 关键度向量 C。
  - 将 C 分块（chunk size = cs），每块取最大值（`BlockMax`），便于兼容检索型方法。
  - **一致头**：只保留 top-k 个块对应的 KV 对（稀疏预算 b）。
  - **自适应头**：保留按比例 η 选出的 KV 对（通常保留大部分）。
- 解码阶段：
  - 一致头：直接使用已缓存的关键 KV 对，无需检索。
  - 自适应头：可执行全量注意力或查询感知检索（query-aware retrieval）。

### 2.5 理论分析

- 论文给出了基于 **Rademacher 复杂度**的泛化误差界（Lemma 1），并在 Theorem 1 中分析了 token 保留精度的下界，指出影响性能的三个关键因素：
  - λ：打分排序正确反映 token 相关性的概率；
  - 预算控制：正确设置保留预算，最大化分类正确头部带来的收益、减轻分类错误头部的损失；
  - `P_head`：CV 方法对头部分类的准确性。

## 6. 主要结论与发现

- **序列一致性现象普遍存在**：在多种模型（Llama-3、Llama-3.1、Phi-3、Yi、LongChat-7B）的不同层中都存在一致头和自适应头，且同一头的分类结果跨样本高度稳定（重叠率 >80%）。
- **CateKV 精度可媲美全注意力**：
  - RULER-128K 上平均得分高于 SnapKV、PyramidKV、DuoAttention，接近甚至超过全注意力（如 Llama-3 上 84.61 vs 84.10）。
  - LongBench 上平均精度下降不超过 0.3%，与 Quest/ShadowKV 集成时下降不超过 0.2%。
  - NIAH 上从 20K 到 1M 均保持较好的检索能力。
- **显著效率提升**（单张 A100-80G）：
  - 单样本：内存降低最高 **2.72×**，解码延迟降低最高 **2.18×**。
  - 批量场景：batch size 增大至 **4.33×**，吞吐量提升 **3.96×**。
- **一致头模式优于流式模式**：与 DuoAttention 的 streaming head 相比，CateKV 的一致头模式在低稀疏预算下注意力召回率更高，能在更低的“全注意力头比例”下保持精度。
- **可插拔性**：CateKV 可与 MInference（预填充加速）、Quest/ShadowKV（检索加速）等正交组合，进一步加速且不损失精度。
- **消融发现**：
  - 当自适应头比例 r 降至约 0.2 时性能才开始显著下降；
  - 自适应头保留比例 η ≥ 0.6 时可维持全量 KV 的精度；
  - 一致头稀疏预算仅需 1024（约 0.78%）即可保持性能，说明一致头自身承担全局信息较少，主要依赖自适应头。
