## 摘要
投机解码通过使用草稿模型生成候选令牌，并由目标模型在单次前向传递中验证，从而加速大语言模型推理。验证按顺序进行，并从首次拒绝位置起丢弃所有后续位置，然而现有的草稿训练依赖于对目标的令牌级模仿，并使用固定的逐位置权重，这既不反映上述任一特性。我们提出了验证感知训练（VAT），这是一种即插即用框架，在每个训练步骤模拟验证，并将由此产生的接受与拒绝模式转化为监督信号。VAT包含两个组件：（i）验证头，一个轻量级联合训练的二分类器，监督草稿模型判断每个位置能否通过顺序验证；（ii）验证自适应权重，用保留每个样本首次拒绝点之前全部权重并将衰减起始点重新锚定至该处的方式，取代固定权重方案。VAT仅修改训练目标，因此可叠加在现有方法之上，无需改变草稿架构、目标模型或推理过程。将VAT应用于基于Qwen3-4B、Qwen3-8B和LLaMA-3.1-8B的EAGLE-3和DFlash，平均接受长度提升最高达11.4%，端到端加速比提升最高达8.7%，在数学、代码和聊天基准上均取得一致提升。代码将发布在 https://github.com/naver-ai/vat

## Abstract
Speculative decoding accelerates large language model inference by using a draft model to generate candidate tokens, which are verified by the target model in a single forward pass. Verification proceeds sequentially and discards every position from the first rejection onward, yet existing draft training relies on token-level imitation of the target with a fixed per-position weighting that reflects neither property. We introduce Verification-Aware Training (VAT), a plug-in framework that simulates verification at every training step and turns the resulting accept and reject patterns into supervision. VAT consists of two components: (i) a verification head, a lightweight jointly trained binary classifier that supervises the draft model on whether each position survives sequential verification; (ii) verification-adaptive weighting, which replaces the fixed weighting schedule by keeping full weight up to each sample's first rejection point and re-anchoring the decay to start there. VAT modifies only the training objective, so it can be layered on top of existing methods without changing the draft architecture, the target model, or the inference procedure. Applied to EAGLE-3 and DFlash on Qwen3-4B, Qwen3-8B, and LLaMA-3.1-8B, VAT improves average acceptance length by up to 11.4% and wall-clock speedup by up to 8.7%, with consistent gains across math, code, and chat benchmarks. Code will be available at https://github.com/naver-ai/vat

# Verification-Aware Training for Speculative Decoding 论文总结

## 1. 核心问题与整体含义（研究动机与背景）

**研究背景：**
- 大语言模型（LLM）自回归生成需要逐 token 前向传播，推理延迟成为实际部署中的关键瓶颈。
- 投机解码（Speculative Decoding）通过轻量草稿模型生成候选 token，再由目标模型单次前向验证，实现无损加速，成为主流推理加速方案。

**核心问题（训练与推理的错配）：**
- 投机解码的加速效果取决于**平均接受长度**（一次验证周期中通过验证的 token 数）。
- 验证是**顺序执行**的：一旦某位置被拒绝，该位置之后的所有 token 全部丢弃，无论后续 token 单独质量如何。
- 然而，现有草稿模型训练存在两大错配：
  1. **监督信号错配**：训练仅要求逐位置模仿目标模型输出分布，草稿模型得不到“该 token 能否通过验证”的信号；
  2. **权重分配错配**：逐位置损失权重是**预先固定的、样本间共享的**，无法适应每个样本首个拒绝点位置的差异。

**论文含义：**
提出 Verification-Aware Training（VAT），首次将验证过程本身纳入草稿模型的训练信号，使训练目标与实际推理时决定加速效果的因素（顺序验证与拒绝点）对齐。

## 2. 方法论：核心思想与技术细节

### 2.1 整体框架
VAT 是**即插即用**的训练框架，仅修改训练目标，不改变草稿架构、目标模型或推理流程。在每一步训练中模拟目标验证，将接受/拒绝模式转化为监督信号。

### 2.2 训练时验证模拟
- 草稿模型和目标模型在每个位置 k 产生分布 p̂k 和 pk，可随时模拟投机采样验证。
- 逐位置接受指示器：mk = 1[位置 k 的草稿 token 被接受]，接受概率为 min(1, pk(x)/p̂k(x))。
- 首个拒绝点：k\* = min{k : mk = 0}（全部接受时 k\* = K+1）。
- 顺序接受标签：vk = 1[k < k\*]，只有当所有前序位置均被接受时才为 1，反映推理时顺序验证的真实标准。

### 2.3 组件一：验证头（Verification Head）
- 一个轻量级二分类器（单层稠密层），接在草稿模型最后一层隐藏状态之上。
- 用二元交叉熵损失训练，监督草稿模型预测每个位置能否通过顺序验证。
- 梯度通过草稿模型反向传播，迫使隐藏状态编码与目标模型一致性相关的特征。
- 该头**仅在训练时使用**，推理时无额外开销；但可选用作早期退出代理（见实验）。

### 2.4 组件二：验证自适应权重（Verification-Adaptive Weighting）
- 将固定权重 wk 替换为样本自适应的 ŵk：

  ŵk = 1（k < k\*），ŵk = w_{k−k\*+1}（k ≥ k\*）

- **k\* 之前**：保留全权重（这些位置实际贡献接受长度）。
- **k\* 之后**：沿用基础衰减曲线但重锚定到 k\* 处开始衰减（被丢弃的位置信号衰减但不清零）。
- **k\* 本身**：保持全权重，这是最近的可纠正失败点。

### 2.5 总训练目标
L = Σ_{k=1}^{K} ŵk (ℓ_k^soft + ℓ_k^hard) + β·L_VH

- ℓ_k^soft：对目标输出分布的交叉熵（软标签）
- ℓ_k^hard：对目标采样 token 的交叉熵（硬标签）
- β = 1.0（所有实验）
- 软硬标签联合使用优于单独任一损失

## 6. 主要结论与发现

1. **VAT 一致提升性能**：在所有基线（EAGLE-3/DFlash）×所有目标模型（Qwen3-4B/8B、LLaMA-3.1-8B）×所有基准类别上，均提升平均接受长度 τ 和墙钟加速比。

   - 典型示例：Qwen3-4B 上，EAGLE-3 加速 4.07×→4.39×（+7.9%），DFlash 加速 4.54×→4.81×（+5.9%）。

2. **两个组件互补**：验证头与验证自适应权重各自独立有效，组合后增益叠加，全组件配置取得最佳结果（4.81× / τ=6.08）。

3. **验证头重塑训练动态**：使首个拒绝点逐步后移（更多连续 token 通过验证），并维持拒绝后位置 token 的匹配稳定性。

4. **自适应权重是增益的主要来源**：表 3 显示，无论基础权重函数形式如何，验证自适应化后都能达到相近的优异效果（τ≈6.08–6.09），说明增益主要来自自适应机制而非衰减函数形式。

5. **验证头可用于推理早期退出**：低阈值下（p=0.5/0.6），验证头预测首个拒绝点的平均绝对误差仅 1.18–1.76 token，用以提前终止草稿可提升额外加速（代价是 τ 的小幅下降）。

6. **VAT 对训练细节鲁棒**：对验证规则（greedy vs. sampling）和语料温度（T=0 vs. T=1）不敏感，结果差异不超过 0.02。

VAT 是一篇**动机清晰、设计简洁、实验充分**的训练目标改进工作。它准确诊断了投机解码训练中的错配问题，提出的两个组件——验证头与验证自适应权重——直指问题的两个维度（监督信号与权重分配），实验覆盖足以支撑其结论。虽然受限于模型规模、数据来源和训练预算，但其即插即用的特性、一致的性能提升以及低推理开销使其具有较强的实用价值。未来探索包括更大模型上的可扩展性验证、不同训练数据分布下的鲁棒性分析，以及验证头与推理期优化（如动态候选长度）的联合使用。
