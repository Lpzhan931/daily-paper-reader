## 摘要
自回归大语言模型（LLM）解码在每一步都会重新读取不断增长的键值（KV）缓存，因此长上下文注意力受限于图形处理单元（GPU）内存带宽。块稀疏注意力会跳过低贡献的 KV 块，但一个在当前查询-键（QK）乘积之后才做决定的选择器（例如最大相对块阈值化（BLASST））仍会读取每个 K 块，而一个根据当前查询做决定的存内计算（PIM）过滤器会在关键路径上引入串行 PIM 阶段。我们提出 AMEND，一种消除这两种依赖的 GPU-PIM 注意力设计。AMEND 根据在较早步骤审计的裕度预测每个块的 BLASST 判定，因此 GPU 只获取预测为存活的块，而高带宽内存（HBM）中的近存储体 PIM 单元同时为被省略的补集打分。栈级控制器融合这两种观测，更新预测器，并提前生成下一步的掩码，从而使每个预测丢弃都被重新观测，而不会阻塞当前 token。工作点通过受约束的贝叶斯优化在误丢弃预算下离线选择。在 LongBench 和 RULER 运行中，AMEND 保持接近基线的任务质量；在批大小为 8 的仿真中，它在 8K-64K 上下文范围内实现了相比稠密注意力 1.40–3.63 倍的端到端解码加速，以及 28-66% 的动态解码能耗降低。

## Abstract
Autoregressive large language model (LLM) decoding re-reads a growing key-value (KV) cache at every step, so long-context attention is bound by graphics processing unit (GPU) memory bandwidth. Block-sparse attention skips low-contribution KV blocks, but a selector that decides after the current query-key (QK) product, such as max-relative block thresholding (BLASST), still reads every K block, and a processing-in-memory (PIM) filter that decides from the current query places a serial PIM stage on the critical path. We present AMEND, a GPU-PIM attention design that removes both dependencies. AMEND predicts each block's BLASST verdict from margins audited at earlier steps, so the GPU fetches only predicted survivors while near-bank PIM units in high-bandwidth memory (HBM) concurrently score the omitted complement. A stack-level controller merges both observations, updates the predictor, and eagerly generates the next step's mask, so every predicted drop is re-observed without blocking the current token. Operating points are selected offline by constrained Bayesian optimization under a false-drop budget. Across LongBench and RULER runs, AMEND preserves near-baseline task quality; in simulation at batch size 8, it achieves $1.40$-$3.63\times$ end-to-end decode speedup and 28-66% lower dynamic decode energy than dense attention across 8K-64K contexts.

## 1. 核心问题与整体含义

- **研究背景**：自回归 LLM 解码每步只生成一个 token，却要重新读取随序列增长的 KV 缓存。长上下文解码因此受 GPU 内存带宽限制，注意力路径成为瓶颈。
- **现有块稀疏注意力的两类问题**：
  - **后 QK 选择器**（如 BLASST）：虽然能跳过被丢弃块的 softmax、V 加载和 PV，但必须先把所有 K 块读入并完成 QK，才能得到判决。论文指出，在 90% 块稀疏下，K 仍占剩余 K+V 逻辑流量的约 91%；附录 C 中 BLASST 的 K 字节等于 Dense，K 占其剩余 K+V 流量的 91.1–93.3%。
  - **当前查询驱动的 PIM 过滤器**：虽然可在 GPU 取 K 前形成掩码，但仍依赖当前 query，PIM 阶段处在 query→scores→mask→attention 的串行关键路径上。
- **整体含义**：AMEND 试图同时消除“GPU 侧 K 流量”和“PIM 串行阶段”两个依赖。它用历史审计的 margin 预测当前 BLASST 判决，让 GPU 只读取预测存活块，同时让近存 PIM 并行计算被全局省略块的 QK 最大值，并把审计结果反馈到下一步预测中，实现非阻塞丢弃。

## 2. 方法论：核心思想与关键技术

- **核心思想**：
  - 不预测原始注意力分数或 Top-K 排名，而是预测 **BLASST 的二值 KEEP/DROP 判决**。
  - 预测依据是之前步骤中 **被审计过的 margin**，即块最大值与 exclusive-prefix 阈值之间的距离。
  - GPU 与 PIM 并行工作：GPU 对预测存活块做 QK、softmax、PV；PIM 对全局省略块做 QK，仅返回块最大值。
  - 栈级控制器合并 GPU/PIM 观测，重构完整 BLASST 证据，更新预测器状态，并**提前生成下一步 mask**。
- **BLASST 参考判决**：
  - 对 token \(t\)、层 \(\ell\)、query head \(h\)、块 \(b\)，计算当前 query 的块最大值 \(m^\star_{t,\ell,h,b}\)。
  - exclusive-prefix 最大值 \(p^\star\) 与上下文偏移 \(\eta_t=\log(\mathrm{TSF}/S_t)\) 构成 margin：
    \[
    \gamma^\star_{t,\ell,g,b}=\max_{h\in G(g)}(m^\star_{t,\ell,h,b}-p^\star_{t,\ell,h,b}-\eta_t)
    \]
  - 若 \(\gamma^\star<0\) 且 \(S_t\ge \mathrm{TSF}\)，则 BLASST 判决为 DROP，否则 KEEP。
- **预测器状态与五维工作点**：
  - 每个 cell（层、KV head、块）维护：margin EMA \(\mu\)、二阶矩 \(M_2\)、drop-run age \(a\)、2-bit Schmitt counter \(c\)。
  - 由 \(M_2\) 和 \(\mu\) 导出波动率 \(\sigma=\sqrt{\max(M_2-\mu^2,0)}\)。
  - 五维工作点 \(\theta=(r,\delta,\alpha,R,z)\)，由离线 SCBO 选择。
- **决策规则**：
  - base eligible 条件：该层使用预测、不是 block 0、不在最后 \(R\) 个块内。
  - 基础预测：
    \[
    u_t=1[a^-_t\ge r]\cdot 1[\mu^-_t+z\sigma^-_t<-\delta]\cdot 1[\text{base eligible}]
    \]
  - 2-bit Schmitt counter 抑制孤立翻转，只有饱和时才发出 drop：
    \[
    c^+_t=\mathrm{clip}(c^-_t+(2u_t-1),0,3),\quad \tilde D_t=1[u_t=1\land c^+_t=3]
    \]
  - mask 形成：\(P^{\mathrm{keep}}_t=1-D^{\mathrm{pre}}_t\)，其中 \(D^{\mathrm{pre}}_t=\tilde D_t\land 1[\text{seam allows drop}]\)。
- **互补审计与状态更新**：
  - 预测丢弃会造成“观测空洞”：被丢块不再被 GPU 评分，预测器若只看存活块会形成选择性标签问题。
  - AMEND 审计逻辑补集 \(A_t\)，即所有预测丢弃的 full block cell：
    \[
    O^{\mathrm{online,full}}_t\cup A_t=F^{\mathrm{full}}_t
    \]
  - 两个观测通道：
    - GPU 路径：对 union 内预测丢弃块，用 GPU 最大值重构 \(\gamma^\star\)。
    - PIM 路径：对全局省略块，用近存 QK 得到最大值并参与重构。
  - 状态更新：\(\mu^+=\alpha x+(1-\alpha)\mu^-\)，\(M_2^+=\alpha x^2+(1-\alpha)M_2^-\)；age \(a\) 和 counter \(c\) 按规则更新。
- **执行契约与系统映射**：
  - 五条不变量：mask 只用 \(t-1\) 及以前反馈；预测丢弃在当前步不回滚；所有预测丢弃 full cell 被 GPU–PIM 观测分区覆盖；当前输出 \(O_t\) 不依赖当前审计；当前审计生成下一步 mask。
  - GPU 负责 survivor QK、survivor BLASST、softmax、PV；AttAcc 派生近存 GEMV 负责省略块 QK；控制器负责合并、前缀、GQA 归约、状态更新和下一步 mask。
  - 工作量守恒：\(\mathrm{QK_{surv}}+\mathrm{QK_{omit}}=\mathrm{QK_{full}}\)。
- **工作点选择**：
  - 将五参数校准视为带约束的混合变量黑盒优化，采用 SCBO。
  - 目标：在误丢弃率约束 \(F_{\mathrm{drop},N}(\theta)\le\tau\) 下最大化 drop recall。
