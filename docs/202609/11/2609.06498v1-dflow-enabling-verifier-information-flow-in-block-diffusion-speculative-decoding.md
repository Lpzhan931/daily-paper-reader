## 摘要
块扩散投机解码通过并行提出一个未来 token 块，并用目标模型的一次前向传播对其进行验证，从而提升 LLM 推理效率。然而，现有方法仅保留被接受的前缀，而丢弃被拒绝的后缀，使得在这些位置上所耗费的计算无法惠及后续的起草轮次，并迫使起草器从头反复重建未来 token 的表示。我们观察到，拒绝仅决定所提议的 token 能否被提交，而被拒绝位置处的验证器表示仍可为后续预测提供有用信息。基于这一观察，我们提出 DFlow，一个简单而有效的框架，使验证器信息能够在各起草轮次之间流动。DFlow 复用目标验证器为被拒绝后缀产生的隐藏状态来指导后续起草，而无需额外的目标模型计算。为有效学习跨起草轮次的这种信息流动，我们引入一种自条件训练策略，将来自较早预测的验证器表示反馈到后续预测中。在 Qwen3 模型上跨多个基准的实验表明，DFlow 相比 DFlash 能持续提升起草质量与接受长度。

## Abstract
Block diffusion speculative decoding improves LLM inference efficiency by proposing a block of future tokens in parallel and verifying them with a single forward pass through the target model. However, existing methods retain only the accepted prefix and discard the rejected suffix, preventing the computation spent on these positions from benefiting subsequent drafting rounds and forcing the drafter to repeatedly reconstruct representations for future tokens from scratch. We observe that rejection only determines whether a proposed token can be committed, while the verifier representations at rejected positions can still provide useful information for subsequent predictions. Based on this observation, we propose DFlow, a simple yet effective framework that enables verifier information to flow across drafting rounds. DFlow reuses the hidden states produced by the target verifier for the rejected suffix to guide subsequent drafting without additional target computation. To effectively learn this information flow across drafting rounds, we introduce a self-condition train strategy that feeds verifier representations from earlier predictions back into subsequent predictions. Experiments on Qwen3 models across diverse benchmarks demonstrate that DFlow consistently improves draft quality and acceptance length over DFlash.

# DFlow 论文中文结构化总结

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：LLM 自回归解码本质上是串行的，成为推理瓶颈。投机解码（Speculative Decoding）通过轻量 drafter 并行提出多个未来 token、再由目标模型一次性并行验证来缓解该瓶颈。其中**块扩散投机解码**（如 DFlash）可同时预测整个 token 块，显著降低起草的串行开销。
- **核心瓶颈**：块扩散投机解码的实际加速比高度依赖**接受长度**（每轮被接受 token 数），因此草稿质量成为关键因素。
- **被忽视的“信息不连续”问题**：精确匹配验证后，只有**接受前缀**和 **bonus token** 被提交，**被拒绝后缀**及其中间表示被直接丢弃。而下一轮起草窗口往往与被拒绝位置重叠，这些位置却被重置为 mask embedding、从头重建。
- **关键观察/假设**：拒绝只是对“离散 token 能否提交”的判定，并不意味着该位置上的**验证器隐藏状态**无用。验证时每个草稿 proposal 都参与了目标模型的因果计算，产生了融合上下文信息的连续表示，即使离散 proposal 被拒，这些表示仍可能对后续预测有价值。
- **研究问题**：能否把目标验证器在**被拒绝位置**上已经算出的信息，带到下一轮起草中复用？——这构成了论文所称的“拒绝边界既是提交边界、也是不必要的信息边界”这一洞察。

## 2. 方法论

### 2.1 核心思想
- **DFlow**：让验证器信息在连续起草轮次之间“流动”。将目标验证器为被拒绝后缀产生的隐藏状态，**中继（relay）**到下一轮中对应的未决位置，作为辅助信息增强 mask embedding，而非从头重建；且**不增加额外的目标模型前向**（隐藏状态在验证时已产生）。

### 2.2 关键技术细节

- **验证器表示对齐（Verifier Representation Alignment）**
  - 复用 DFlash 用于目标上下文条件化的**同一特征投影 Wc**（拼接多个目标层的隐藏状态 → 投影 → RMSNorm），得到被拒绝后缀的验证器表示 $h_i^{(r)}$，几乎不引入额外参数。
  - **因果错位修正**：目标模型是 next-token 预测（位置 $i$ 的隐藏状态预测 $i+1$），而 drafter 是 mask token 预测（位置 $i$ 预测位置 $i$ 的 token）。因此需对验证器表示做**位置偏移**，使二者对应同一预测目标。

- **拒绝条件化草稿初始化（Reject Conditioned Draft Initialization）**
  - 由于验证时被拒绝后缀是在“首个被拒 proposal”之后计算的，而下一轮上下文从目标修正 token（bonus token $b^{(r)}$）继续，二者边界 token 的差异是上下文变化的直接信号。
  - 用轻量 MLP 结合 bonus token 嵌入、首个被拒 proposal 嵌入与 $h_i^{(r)}$，生成**通道级缩放向量 $\beta_i$** 与**加性修正向量 $\gamma_i$**：
    $$[\beta_i^{(r)}; \gamma_i^{(r)}] = \mathrm{MLP}_\phi\left(\left[E(b^{(r)});\, E(\hat{y}^{(r)}_{a_r+1});\, h_i^{(r)}\right]\right)$$
  - 增强后的草稿输入为：
    $$x_i^{(r+1)} = E_{\text{mask}} + \beta_i^{(r)} \odot \mathrm{LN}(h_i^{(r)}) + \gamma_i^{(r)}$$
  - 仅在有有效可复用验证器表示的位置使用；首轮或无被拒后缀时回退为标准 mask embedding。

- **多轮自条件训练（Multi-Round Self-Conditioned Training）**
  - **Multi-Round Rollout**：把标准单轮训练扩展为连续多轮——初始轮为标准 mask 预测（保持基础能力），其 proposal 经冻结目标模型验证后提取被拒绝后缀的验证器表示，中继给下一轮做“拒绝条件化预测”；实践中在初始 mask 轮后展开 **k = 2** 轮。
  - **Target Trajectory Transition**：通过与目标轨迹**精确匹配**确定下一轮起点（首个不匹配处的目标 token 作为 bonus token），使各轮对齐同一目标轨迹，目标上下文可直接复用；验证器信息仍绑定于当前轮真实 proposal。
  - **训练目标**：$L_{\text{DFlow}} = L^{(0)} + \sum_{q=1}^{k} L^{(q)}$，各轮损失相加后统一反传，共享同一套 drafter 参数；沿用 DFlash 随位置指数衰减的交叉熵权重；目标模型全程冻结，验证器表示与轮间转移均**从计算图中 detach**。

## 6. 主要结论与发现

- **验证器信息可跨拒绝边界复用**：被拒后缀的隐藏状态对后续起草有实质帮助，拒绝边界不应成为信息边界。
- **接受长度持续提升**（对比 DFlash）：
  - 贪心解码（T = 0）：Qwen3-1.7B 3.56 → 3.93；Qwen3-4B 3.71 → 4.20；Qwen3-8B 3.66 → 4.15（平均接受长度提升约 **10.4% / 13.2% / 13.4%**）。
  - 采样解码（T = 1）：2.99 → 3.26；3.15 → 3.54；3.10 → 3.45。
  - 各任务（GSM8K、MATH-500、HumanEval、MBPP、MT-Bench、Alpaca）均一致优于 DFlash 与 EAGLE-3。
- **吞吐收益可落地**：在高并发服务负载下 DFlow 相对 DFlash 仍保持更高 TPS；例如 Qwen3-8B GSM8K 在并发 32 时，DFlow 达 2198.17 TPS（1.35×），而 DFlash 为 1891.10（1.16×），说明其在中高负载下仍有效。
- **消融结论**：多轮 mask 训练仅带来小幅提升（3.56 → 3.67），仅用 mask 的 DFlow 为 3.66，而**开启验证器中继后升至 3.93**，说明**验证器信息复用是主要增益来源**，且 DFlow 建立在强 mask 预测能力之上。
- **开销极低**：relay 仅增加 0.51 ms 延迟（约 1.2% 开销），因为隐藏状态在验证阶段已产生、且复用了 DFlash 的目标特征投影。
- **与 Domino 兼容**：配合在线 rollout 训练可叠加增益（3.56 → 4.02 → 4.50）；若不使用在线 rollout，会因 teacher forcing 与推理轨迹错配而使性能崩坏（降至 2.22），说明训练/推理一致性对中继机制至关重要。

## 7. 优点

- **洞察新颖且简洁**：把“拒绝边界”重新解读为“信息边界”，指出验证器连续表示在离散 proposal 被拒后仍有价值，视角清晰、动机自然。
- **零额外目标计算**：直接复用验证阶段已产生的隐藏状态与 DFlash 已有的投影矩阵，工程上非常轻量（0.51 ms / 1.2% 开销），性价比高。
- **训练与推理对齐设计严谨**：通过 Multi-Round Rollout 显式展开多轮推理过程，并用 Trajectory-Guided Transition 解决训练/推理轨迹不一致；同时对目标模型冻结、对跨轮信息 detach 梯度，避免不稳定的梯度传播。
- **细节处理到位**：注意到 next-token 与 mask-token 预测的位置错位并做偏移对齐；用 bonus token 与首个被拒 proposal 的嵌入差异来条件化调制（通道

通道级缩放与加性修正，兼顾上下文变化信号），比单纯替换 embedding 更稳健。
- **对训练/推理一致性的重视**：论文明确指出并验证了 teacher forcing 与推理轨迹错配会导致中继机制失效（组合 Domino 时不使用在线 rollout 会崩到 2.22），这一负面结果的报告增加了结论可信度。
- **公平性意识**：DFlow 与 DFlash 严格共享训练数据、drafter 结构、优化超参与目标模型，使增益可归因于方法本身而非训练配方。

## 8. 局限与不足（客观评价）

- **模型家族覆盖单一**：全部结论建立在 Qwen3-1.7B/4B/8B 上，未在 Llama、Mistral、DeepSeek、Gemma 等架构上验证；不同目标模型的隐藏状态质量与层间特征分布差异可能影响中继效果的可迁移性。

- **跨方法比较的公平性略弱**：EAGLE-3 使用官方 checkpoint，而 DFlash/DFlow 为自训练，训练数据规模与配方差异可能影响对比结论；论文仅保证 DFlash 与 DFlow 之间同设置。

- **“信息边界”论证偏经验**：论文主要以接受长度提升作为证据，缺少对“为何被拒位置的隐藏状态仍然有用”的可解释性分析（如表示相似度、信息论度量或可视化）。

## 9. 更广泛的意义与可迁移性

- **概念层面**：把“拒绝”从“丢弃”重新定义为“可复用信号”，这一视角具有普适性——任何 draft-verify 框架在验证阶段都会产生被浪费的中间计算，DFlow 提供了一种系统化的回收范式。
- **工程层面**：证明“复用已有中间表示”可以以极低开销（约 1.2%）换取稳定的接受长度提升，为推理加速研究提供了“低成本高回报”的改进方向。
- **训练层面**：多轮 rollout + 轨迹引导转移 + 梯度 detach 的组合，为“跨轮条件化”类方法的稳定训练提供了可借鉴模板。
- **兼容性层面**：与 Domino 等正交方法的可叠加性表明，验证器信息中继可能成为投机解码流水线中的一个通用组件，而非与特定方法绑定的技巧。

## 10. 总体判断

DFlow 的核心贡献在于提出了一个**动机清晰、实现轻量、验证较充分**的改进：将目标验证器为被拒绝后缀产生的隐藏状态跨轮中继，配合拒绝条件化初始化和多轮自条件训练，在不增加目标模型前向的前提下显著提升块扩散投机解码的接受长度与高并发吞吐。其主要短板在于模型家族覆盖窄、统计严谨性与超参敏感性分析不足，以及跨方法比较的训练配方不完全对齐。总体而言，这是一项**洞察有新意、工程性价比高、但泛化性仍有待更广验证**的工作。
